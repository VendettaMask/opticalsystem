# 分步装调与最差样件复算

2026-11-06。操作方法和文件版本见[公差说明](../../../../docs/TOLERANCING.md)。

- 用两个耦合变量验证阶段升序。第一阶段把 X 调到 2，第二阶段只调 Y 到 0.5。阶段 2 保持 X，循环总预算超限时拒绝执行。
- Cooke 三片镜研究同时启用同面 ISOB/ISOC 和组装偏心。依次执行镜组 X 平移、带机械支点的 Y 倾斜、末端 COMP 像距调整。名义与三次试验均记录三个阶段。检查每阶段调整在行程内，先前阶段的量在后续调整后保留。
- 按最小验收余量保存最差样件，从打开 Tessar 的另一工作区复算。评价值、可调量和阶段与记录相同，两份活动处方均保留。故意修改记录的评价值时明确报告不一致。越界试验编号被拒绝。
- 离屏验证补偿阶段控件、机械支点、480 宽度和 150% 缩放，以及 v6 往返与旧版读取。[窄窗补偿页](mtf-tolerance-light-480-compensation.png) · [暗色补偿页](mtf-tolerance-dark-720-compensation.png)
