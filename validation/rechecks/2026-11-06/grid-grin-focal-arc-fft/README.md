# Grid GRIN 一阶焦距、网格体弧长与 FFT 参考

## 一阶焦距和 F 数

此前沿几何轴线性化，遗漏探针斜率与轴向折射率变化的耦合。固定高度的双探针解释了 Grid Gradient 的近轴约定。体内从高度 ±0.002 mm 出发，两条探针的初始斜率均为 +0.002。传播到出口后，横向高度与斜率的差给出高度列，和给出斜率列。原生 PARY、PATY 在独立改变瞳孔和视场后验证了两列。带梯度的折射率场允许探针在三维空间偏折。积分沿轴向推进并复用体内光学动量方程、连续梯度和现有网格折射率查询，出口折射仍走现有近轴介质链。

新约定用于正向 GGD 焦距、光焦度、F 数和基面估算。实光线追迹和瞳孔传播仍由各自的现有路径计算。常量与变化轴向折射率、正负横向梯度、二次梯度及细化网格分别作为控制。以本轮最终 Core 同原始门槛直接比较，在菜单样例的 0.00025 mm 收敛原生参考下，EFL 为 **10893.53316134 对 10893.53324894 mm**，F 数为 **30598.74905735 对 30598.74930343**。两项相对差均约 8.04×10⁻⁹，原门槛为 10⁻⁶。原 1 mm 冻结参考的焦距为 25293.0999 mm，按原门槛仍为差异。受控网格中极弱光焦度对原生积分步长敏感，独立控制账目按原始记录保留。[逐项专项复验](scoped-comparisons.json) · [逐面矩阵控制](matrix-audit.json) · [原生源和读回](native-controls.zip) · [Ansys Grid Gradient 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v251/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Grid_Gradient.html)

## 四条光线的体内弧长

490、507、511、515 的原光线使用 Hx=Hy=Px=0、Py=0.8，覆盖波长号 1、2、3。独立原生控制只移动平面出口到体内 64 个深度，记录入口和各截点。分别在 0.001 和 0.0005 mm 两档积分步长下捕获，然后比较 8、16、32、64 段弦长和，外推消除主导弦长误差。两档外推结果相差约 9.2×10⁻¹⁴ mm。外推原生弧长为 **3.803990713201 mm**，Core 为 **3.803990717573 mm**，四项差均约 **4.37×10⁻⁹ mm**。直接 64 段弦长和对 Core 的差也在原坐标门槛内。四项弧长专项通过，内建逐面报告的零值仍记为缺报。[逐光线弧长](arcs.json) · [Ansys 单光线报告定义](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v251/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Single_Ray_Trace.html)
