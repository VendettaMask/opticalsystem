# Grid GRIN 的有界 FFT 原生参考

## 内存限制下的补采

Zemax 2026 R1 的直接截线与包围能量在 16384 档均触发内存限制。8192 档的直接包围能量在原 5 µm 半径和自动半径下都报告取样不足，无数值曲线。此次从原生二维 FFT PSF 的完整像面周期读出。负像面间距让原生计算取消瞳孔拉伸，较小的名义矩阵便可保留较密的实际瞳采样。后台采集将原生全场按行写为双精度二进制，避免再生成全阵列的 JSON 对象或重复文本。验收前逐项回读波长、视场、像面、完整尺寸及物理坐标。[Ansys FFT PSF 采样约定](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/FFT_PSF.html) · [原生设置、哈希和回执](native-inputs.json)

横向截线在原物理坐标上按有限傅里叶级数重采样。包围能量用同一完整原生 PSF 计算全场总能量和质心，只对质心附近的矩形窗分块求值，再按半径积分。局部窗口沿用全场分母。低像差焦点和独立离焦镜头分别对照内建截线及包围能量，均通过对应原阈值。离焦对照 512 档分块积分对原生 2048 档实际曲线的 NRMSE 为 0.001044，原门槛为 0.003。[重建及收敛账目](native-comparisons.json) · [Ansys 包围能量定义](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Diffraction_enclosed_energy.html)

## 499 FFT PSF 截线

恢复已采集的原生 2048 档完整 4096×4096 PSF，使用文本明示的原点与坐标方向。通过同一次采集的 128×128 API 数值窗验证方向、原点与数字精度，最大差小于 5.0×10⁻¹⁰。原生 8192 截线 0.005→0.001 mm 最大差 3.0×10⁻⁶。更密的原生全场截线对直接 8192/0.001 mm 的原始 **±317.37639 µm** 全范围，32,769 个点最大差为 **3.33076×10⁻⁶**，通过原逐点门槛。最新 Core 的 8192 和 16384 档均通过，最大差分别为 2.86254×10⁻⁶ 和 2.76406×10⁻⁶。完整参考与产品比较通过原逐点条件。历史 4096→8192 的失败判定和原 32 档记录独立保留。[完整截线数据](profile-reference.csv) · [当前 Core 对照](product-comparisons.json)

## 502 衍射包围能量

新采的无拉伸 512 档原生全场与更密的历史 2048 档原生全场，在各自完整周期内独立求质心和总能量。两者的 5 µm 实际能量分别为 0.0003983306395 和 0.0003983778101。窄幅历史 1024 档有约 2.34% 的高档能量落在其周期之外，改变质心，归档为诊断控制。收敛检查使用具备足够物理范围的捕获。[周期与质心诊断](alias-diagnostics.json)

0.001 mm 完整原生场在 5 µm 处的实际能量比例为 **0.0003979999769**。最新 Core 的 65536、131072 两档对该曲线均通过，最大差分别为 1.34165×10⁻⁶ 和 1.71903×10⁻⁶。同一 512 档的 0.0025 mm 中间结果仍超原门槛，因此实际曲线的原生步长稳定性仍开放。

原生 FFT 实部和虚部独立读取后，合成强度对同档线性 PSF 的最大差为 4.07×10⁻²⁰。反变换恢复受光瞳孔，保留振幅与遮罩后仅去除相位，Parseval 总功率的相对变化为 2.22×10⁻¹⁶。衍射极限曲线的像面积分及两组瞳孔降采样均通过，5 µm 处为 **0.9476098011**。Core 两档对衍射极限的 NRMSE 分别为 2.946×10⁻⁵ 和 3.453×10⁻⁵，均通过原门槛。

独立 128 档波前的相位差重建，对已测得的 0.0025 与 0.001 mm 全场实际曲线最大差分别为 6.81×10⁻⁷ 和 2.89×10⁻⁶。该诊断只覆盖 97.67% 受光瞳孔，0.0005 mm 的推算单独保存。[实际与衍射极限数值](energy-reference.csv) · [验收范围与收敛状态](reference-certificate.json) · [相位诊断](phase-propagation-diagnostic-128.json)

## 复现

原生采集脚本、重建源代码和本轮原始数值归档在同一个包中。历史大文本保留原路径和 SHA-256。也可在同版 OpticStudio 以原 Grid GRIN 处方、GRIN 步长 0.005 mm、波长 2、视场 1、线性标量且保持理想峰值标度、瞳采样 2048、显示 4096、像面间距 0.25 µm 重采完整场，用同一读出重算。解包后可用 reproduce/RebaseRequests.py 重定位原请求和源文件，再用 reproduce/Run-BinaryNative-Portable.ps1 指定仓库根目录复采。小型原生对照在重定位后逐字节一致。数值重建使用 NumPy 2.3.5 和 SciPy 1.16.3。[复现和原生数据](native-bounded-fft.zip)
