2026-11-06，Windows x64，.NET 10，Release。使用单配置和双配置 Cooke 验证同一试验的三个独立评价目标。

| 工序 | 表及验收 |
| --- | --- |
| 阶段 1 定心 | 表 A 用 GLCX 把共用镜组定心到 0.03 mm。阶段 2 完成后核对定心调整量保持一致。 |
| 阶段 2 调焦 | 表 B 用 THIC 把两配置分别调到约 42.30778 mm。四次优化循环后与目标的差小于 0.1 nm。 |
| 最终验收 | 表 C 使用定心目标与另一像距目标，整机评价约 0.017678，高于 0.01 上限，判为未通过。 |
| 冻结与复算 | 运行前清空活动表。启动后修改调用方的表 A 数据，已运行的样件仍保留 0.03 mm 原目标。v5 样件在另一工程中逐阶段复算一致。 |
| 界面与研究 | Light 主题，480 DIP、150% 缩放。三次打开窗口，分别绑定表 1、表 2、表 3，使用实际「应用设置」按钮保留前次设置。v10 研究重开后表名、操作数和目标一致。 |
