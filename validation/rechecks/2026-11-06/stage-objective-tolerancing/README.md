# 逐阶段装调评价验收

2026-11-06，Windows x64，.NET 10，Release。用单配置及双配置 Cooke 验证不同工序使用各自的优化目标和最终验收限值。

| 项目 | 验收方式 |
| --- | --- |
| 阶段 1 | 共用镜组 X 偏心按 RMS 点列半径调整。与只运行 RMS 阶段的同种子结果比较，调整量一致。完成后锁定，阶段 2 结束后核对镜组位置。 |
| 阶段 2 | 以 18 cycles/mm 几何 MTF 独立调节两配置的空气间隔。记录实际频率、逐视场结果、调整量和行程。 |
| 最终验收 | 以 30 cycles/mm 几何 MTF 验收。双配置第 2 视场在阶段 2 均超过 0.08，配置 2 的第 2 视场从阶段评价的 0.11371895 变为最终评价的 0.00566412，整机验收余量 −0.07433588，未通过。 |
| 灵敏度及失效 | 负、正端点各执行两阶段并记录各自准则。不可评价的明确阶段终止本次装调，后续可调量保持未执行时的位置。 |
| 文件兼容 | v8 研究读回时逐项核对阶段及最终设置。v3 样件在另一工程中逐项复算；旧 v1、v2 样件和 v1–v7 研究使用已有入口。 |
| 离屏界面 | Light 主题，600 DIP、150% 缩放。用实际补偿页核对两个阶段和可编辑频率，以及最终频率独立保存。 |
