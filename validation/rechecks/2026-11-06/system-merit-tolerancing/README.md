# 系统评价函数公差验收

2026-11-06，Windows x64，.NET 10，Release。使用单配置和双配置 Cooke 验证活动评价表可用于指定装调阶段和最终验收。

| 核对项 | 本地结果 |
| --- | --- |
| 有序行与权重 | 两条零权重 THIC 提供厚度读数，DIFF 引用这两行，使用目标值和权重 4。直接残差检查验证 GOTO 跳过的行不会产生目标偏差。启用行失效时评价为无效。 |
| 单、双配置补偿 | 对像距施加固定 +0.05 mm 制造误差。双配置的第二配置另有 +0.15 mm 名义间隔，补偿前最差评价为 0.20。按系统评价函数独立补偿后，两配置像距均约为 42.20778 mm，最差评价为 7.40×10⁻¹²，低于 0.002 上限。 |
| 阶段与验收独立 | 系统评价函数作为阶段准则时，也可用 RMS 点列作最终验收。两侧灵敏度保留阶段准则，直方图使用独立评价值轴。 |
| 样件与预检 | v4 保存时活动配置为 2。之后修改编辑器目标，复算仍按原表并匹配全部记录。空表和 CONF 由预检拒绝，后者报告第 1 行。 |
| 界面与研究文件 | Light，600 DIP、150% 缩放的补偿页和评价标准页。v9 保存并读回准则，v8 继续支持原阶段配置。 |
