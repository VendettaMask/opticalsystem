## 覆盖与处理

起点为版本化及未忽略的 **1,885** 份 Markdown、RST、文本、HTML、PDF、Word、ODT 与许可资料。原检查器分为 87 份 Guide、323 份 Historical、1,406 份 Evidence、69 份 ThirdParty。先完整登记路径/哈希、核对本地链接、锚点、重复正文与源码引用，再对现行能力和计划中的疑点作实现交叉复核。

本轮更新 21 份已有说明，主要包括：

- 初始结构的检索、SPC/胶合、准备检查点、方案库/报告已实现，条件生成、自动口径和递归 SPC 仍分别保留边界；不把旧 CPU 预设范围或上游对齐目标当作当前产品全貌。
- Core 的 ILGPU/CUDA 和自动微分已存在，正式 NSC 已有 BSDF/BTDF 方向抽样，不再声称“无第三方计算包”“BSDF 未实现”。全板基板吸收/裸背面/非相干内反射显示与前面设计验收区分。
- 局部单色/镜头多波长 SFR、完整瞳孔参考、V1/V2 旧档、五条曲线和默认采样按当前契约修正。整理期间到达的物方棋盘 M0/M1 单列首批能力，原例全幅、多 ROI、正式对照及 ROM/黑盒不因此关闭。
- 旧自动网格开放项指向后续关闭依据；多配置优化已支持显式 MCE 单元格变量。旧操作数数量不再在镜头库重复维护。中英文首页的固定原图/滚动、相机与初始结构概述同步。
- 构建锁定说明遵守用户后台验证要求，保留用户正在使用的程序；不以独立测试目录代替默认 App 验证。

现行索引改为产品/任务入口，[历史索引](../../../../docs/history/README.md)接收原历史分组并补齐阶段报告；原有有用链接保留并按新目录修正。新增[维护规则](../../../../docs/DOCUMENTATION_MAINTENANCE.md)和[生命周期清单](../../../../docs/documentation-lifecycle.json)。进行中的日期计划明确为 Guide，已完成首版拓扑记录显式为 Historical；生成报告归 Evidence，不再误算为当前操作指南。
