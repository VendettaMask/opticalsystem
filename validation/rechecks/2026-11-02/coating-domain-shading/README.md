# 镀膜光谱的域外底纹

用户要求域外点背景加深，便于与原材料数据范围区分。光谱绘图区现在以更深的中性底色标记端点延用波段，先填充底纹再画网格、目标和真实曲线。浅色主题使用原绘图区底色的0.84倍RGB，暗色底色使用0.5倍，曲线/网格色与粗细均未改变。

区间由实际膜层、入射介质、基板中显式允许端点延用的材料范围推导；整片模式额外包括出射介质，前面模式不包括它。未用的材料不参与。所有域外部分取并集并裁到当前视图，覆盖左右两端、全域外以及材料有效域互不重合的情况，不按重叠材料个数加深。图下保留材料来源/非实测提示，底纹说明放在该提示的悬停中，不另加常驻说明行；悬停域外样点可见具体材料的端点延用通知。严格有效域仍按原规则报错，计算失败或无数据时不画底纹。

底纹不依赖目标开关、曲线是否可见或纵轴模式；波长边界始终用原nm坐标，nm/µm仅改变标签。实时视图与PNG导出共用相同Render路径。原n/k、有效域声明、源处方、采样值、优化和正式验收未修改。

本次仅做后台离屏验证，不启动、关闭或控制用户窗口；默认Release输出可重开查看，已运行的旧窗口不热更新。源码和App/测试引用的二进制身份见`receipt.json`；没有再复制运行时、参考数据或整套源码，之前两轮的历史收据保留原身份。
