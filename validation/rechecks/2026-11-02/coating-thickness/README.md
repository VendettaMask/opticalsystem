# 镀膜物理厚度与光学厚度分列

用户要求将膜层表原“厚度”分别显示为物理厚度和光学厚度。当前列序为层序、材料、物理厚度 (nm)、光学厚度 (nm)、变量。物理厚度继续可编辑；光学厚度为只读的 n(λ₀)d，使用当前参考波长和当前材料快照的实折射率，由共享 Core 材料模型求值，不使用复折射率模、不额外乘斜入射角因子。悬停可查看参考波长、折射率和范围说明；材料范围不覆盖参考波长、参考波长/膜厚无效时清空派生值并显示“—”。原显式端点延用按原声明执行并提示。

材料替换、物理膜厚和参考波长编辑立即更新；装载、材料快照变更、候选采用和优化结果通过原装载路径刷新。派生字段不进入实验文件，仍只保存原物理膜厚，未改共享光谱算法、优化和正式验收。表头可换行，行高/列宽保留用户字号，窄面板横向滚动。中文/英文/日文标签沿用原语言系统。
