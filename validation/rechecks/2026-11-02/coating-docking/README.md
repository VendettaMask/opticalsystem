# 镀膜工作区停靠和布局保存恢复

四类页面（膜系编辑器、光学评价、堆栈几何、设计结果）改为同一镀膜实验内的原生Dock文档。默认左右显示前两页；窗口菜单负责重开、当前浮动、全部停靠、左右/上下/标签布局、保存、恢复和重置。实现计划及验收定义见[计划文档](../../../../docs/COATING_DOCKING_PLAN_2026-11-02.md)。

## 页面状态与计算边界

页面控件独立缓存，关闭、重排、浮动、跨窗拖回和恢复布局都复用当前实例；不使用光谱或处方副本伪装同步。方向和灰色预览来自产品已有Dock引导，中央合并、四边分栏和Esc取消通过原生指针事件验证。四个页面可同时浮动，全部关闭后仍可从菜单恢复，浮窗使用同一快捷键处理和字体绑定；主窗口取消关闭保留浮窗，批准关闭才清理。

候选和指标公差继续位于单独结果页，主界面不恢复实验名或常驻完成提示。竖直堆栈保留当前剖面/数据页、选层、无效输入清图和固定2404×1804 PNG；物理/光学厚度、平均/s/p、域外底纹和谱表导出仍使用原状态与原计算。镀膜Core和本轮涉及的Engine源码对前一阶段收据逐一核对，结果记录在`receipt.json`，不改变原n/k、有效域、设计协议或密集验收。

布局使用独立的`coating-workspace-layout.json` v1，只保存Dock树、活动引用和窗口几何，不存控件、材料、膜层或计算结果。显式保存后，手动恢复和下次打开均可恢复；重置不自动覆盖保存文件。恢复先校验节点类型/规模、唯一面板身份和活动引用，失败保留原布局；安装阶段异常有原布局回退。浮窗边界按可用屏幕及缩放率修正。实际比例与旧折叠缓存同步，防止展开过程覆盖保存的分栏比例。

最终结果、逐项测试、源码与App/Core/Modules/Engine二进制身份以`receipt.json`及最终TRX为准。App和全部内置模块使用正常默认Release输出；共享根测试项目复用这批已构建依赖，不使用替代App目录。测试均为后台离屏窗口，不启动、关闭或操作用户桌面。真实系统的多显示器拖动、macOS原生交互和安装发布不计入本轮验收。

## 保留的修正记录

- 初始草稿的同名`IsOpen`警告改为`IsPageOpen`。同期相机源码或依赖暂不一致的中间构建日志保留；未修改该批源码。共享测试首次构建遇到其他进程占用，未终止其他进程，后续重试成功。
- `first/`的9项有3通过、6失败：停靠模型和持久化有效，但派生控件没有继承Dock原生主题键，缺少真实标签视图。补齐`StyleKeyOverride`并增加原生控件存在断言后，`style/`9项通过；未用模型检查代替显示验收。
- `floating/`另复验实际鼠标拖出/拖回、四窗与快捷键，3项通过，包含重复身份，不与最终计数累加。
- `coating-full/`83项中64通过、19失败，均为旧界面查找仍依赖固定分栏逻辑树，不能找到原生停靠模板内的控件。更新为实际视觉树和保留的页面内容查询，原数值/像素/编辑断言保持；`coating-adapted/`83项通过。
- `layout-detail/`、`layout-diagnostic/`保留比例从37/63恢复为50/50的失败。保存树中的实际比例正确，旧`CollapsedProportion`在重新附加内容时覆盖它；恢复时同步缓存后`proportion-fix/`定向通过。标签拖动、顺序和活动页断言保留，未降低比例精度。前述均为历史修正范围，最终同版本复验单独记录。
