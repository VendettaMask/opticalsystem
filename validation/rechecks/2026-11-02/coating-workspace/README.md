# 镀膜工作区精简、堆栈与 p 曲线

本轮对应用户截图中的五项要求：候选和指标/公差不放在光谱下方；去掉底部完成信息条；去掉顶部实验名；加入堆栈与设置；修复 p 单独选择时曲线不可见。用户进一步明确，基板和背面必须参与整块基板光谱计算。

## 交付

- 顶部“结果”打开独立结果窗口，保留候选采用、原逐项验收及公差内容，支持关闭后重开。当前名称保留在设置/文件中，主工具栏不重复。常驻信息卡移除，仅后台计算或真实失败出现紧凑反馈。保存/放弃/取消和失效任务隔离保留。
- 编辑器显示有向堆栈示意、实际前面层数/总厚度、裸背面及材料身份色；色块非统一物理比例，逐层悬停显示实际值。设置支持入射介质、基板、出射介质、基板厚度 mm、参考波长及基板/背面开关。参考波长与原设计中心波长同步。
- `CoatingStackGeometry` v1 以 schema 1 的可空字段保存。新建工作区/菜单示例默认完整基板显示，旧文件缺字段继续前表面。显示几何本身不改变既有前表面指纹；材料列表及处方仍按原规则处理。正式优化/验收保持前表面定义，完整基板曲线与原目标之间的区别在图下明示。
- 完整显示调用共享 Core `incoherent-substrate-scattering/1`：同一稳定相干散射递推求前面双向响应，组合真实基板衰减、裸背面及非相干内部多次反射。保留真实 n/k 和稳定 log(T)；T 为进入出射介质的功率，A 包括有限膜层及基板吸收。整个基板不是相干 Fabry–Pérot 条纹模型，不提供背面膜层编辑；倏逝基板、精确临界奇点及不可稳定求和明确拒绝，不用角度裁剪或归一化伪造结果。
- p 原来使用零长短划的 Dot 样式及平头线帽，Skia 中不留可见短划；改为圆头点线。s/p/平均都取自身实算数据，不偏移重合曲线；现场视图和 PNG 共用绘制路径。完整系统数值列以 `system_` 标识，原顶层正式验收导出不改为完整基板。
