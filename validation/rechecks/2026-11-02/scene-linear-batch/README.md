使用原菜单 Double Gauss 28 degree field，保留处方、未聚焦的保存像面及其材料；真实光学输入由归档内的镜头快照确定。靶标为声明的 100 m、14×14 格、2 m 格边与 5° 姿态，源总带宽辐亮度亮/暗为 1/0.1 W/(m²·sr)，像元 3 µm、每像元 1 点、瞳面 2×4。两个实验共享同一冻结镜头/场景，在活动工程已切换为另一镜头后仍完整执行，活动修订未改变。

512×512 首波段还以**同一归档快照**调用整图接口，对比全部像元得到逐像元一致；17 行分块的末尾 2 行也被覆盖。最初从文件重新导入的对照曾不一致，那条路径没有保证与应用的材料/处方快照相同，已更正为同一冻结输入；它不构成分块光学结果的失败或精度通过证据。此处只验证分块交付一致性，不是独立物理精度验证。现有两个 ZIP 是唯一任务数据原件，PNG/浮点数据保留在其中，不再展开复制。

## 数据与预算

逐节点 W/pixel、逐任务功率和 W/m² 图使用带摘要的 float64 little-endian 文件。单节点任务复用节点功率文件；有限谱保存节点、求和功率及辐照度。PNG 为完整原尺寸 Gray16、零偏移、同批共用标尺，无 Gamma/ICC/sRGB，量化误差上限为半个灰阶。读回检查文件摘要、节点求和、真实面积换算与 PNG 量化；光谱权重在源处只施加一次，未附加 QE、曝光、噪声或 ISP。

预算按全部源/波长节点和所有完整像元一起预检，保留既有上限，分块和任务不重置计数。5000×3000、0.5 µm、当前三波长和同一 2×4/单像元点控制设置，需要 360000000 条光线、最多 3960000000 次表面传播与 90000000 个 float64 值；超过像元、总工作量和存储限额，记录为未运行。预检没有将请求改为 512×512 或中央 ROI。原文相机完整幅面仍需专用资源方案，Lens 710 几何与二进制 ROM 的原有缺口也没有被本轮关闭。
