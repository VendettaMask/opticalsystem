# M3.4 原 F/8 固定口径性能验证

本目录保存原八片、50 mm、F/8、25°任务的五种子同预算对照。原口径、光阑/像面、像质、材料/面型/轴向权限和制造终验保持；F/4 继续按规格冲突停止。完整说明见[交付报告](../../../../docs/INITIAL_STRUCTURE_PERFORMANCE_2026-11-01.md)。

- `baseline/`、`candidate/`：预先冻结的真实源代码 ZIP、源/运行时 SHA-256、协议、逐种子原始检查点、活动/持久化账目与包含式性能样本。CPU、单工作线程、冷启动 v6、种子42–46，各600函数/600梯度/千万实测光线/600活动秒及原阶段配额，无热起点导入。
- `comparison.json`：两臂各5/5原规格合格，物理终点、完整QA、RNG/候选池/阶段及全部离散账目精确一致。活动时间减少6.4%–12.7%，合计约10.5%；每臂每种子一次，不是普适加速保证。
- `baseline/interrupted-disk-full/`、`baseline/disk-reentry.json`：首次种子42落盘磁盘写满及单独声明的新预算重跑。失败费用不冒充精确续跑或免费重算。
- `model-probes.json`：真实六阶阶段点的六组尺度/阻尼和1/2线程四次评价对照，额外实测362,610光线。六组完整终验均不合格，未改正式尺度/阻尼；双线程只证明局部评价吞吐，不代表启用全局并行搜索。实际为CPU，GPU光学执行为零。
- `audit-baseline/`、`audit-candidate/`、`audit-product/`：各自独立原验收重算、锚定权限与逐面口径检查、STAROPT导出/回读；各76次、零错误。重验费用单列，不加入搜索预算。
- `resume/`：冻结候选内核下原任务正常停止、跨进程恢复及连续执行的精确比较；`f4/`为原规格零工作冲突。
- `tests/`、`product-session/`：Core精确等价、模块/桌面逻辑及真实产品会话的TRX、日志、实际二进制前后哈希。首次Core夹具类型错误和改盘导致旧测试找不到仓库夹具的失败保留；`fixture-layout.json`记录原始夹具的校验复制，未修改验收。
- `default-app-build.log`：默认输出的完整Release主程序及两内置模块构建。临时输出的辅助驱动构建单独记录，不替代默认输出验证。
- `source-arm-delta.json`、`final-source.zip`、`final-source-sha256.json`、`product-runtime/`：两臂实际源差异、最终相关源与测试/文档、产品验证二进制。同期其他任务的非序列/BSDF/序列化修改保持，不声称整个Core两臂源完全相同。
- `documentation-audit.json`、`final-verification.json`：严格文档核验、最终范围和全部证据哈希。核对后者列出的实际结果，不从旧报告推导当前通过数。

所有验证均后台/离屏，没有前台GUI、安装、提交或发布。旧算法/JSON身份和计算版本保护保持；旧数值检查点不静默升级。在线漏洞审计曾因服务不可达产生NU1900，不把后续构建通过称为安全审计。历史M3.5封存内容保持。

复现时先核对输入和各臂SHA-256；冻结二进制可读取对应源ZIP。不要覆盖已封存臂或已存在输出，另建验证目录。`tools/diagnostics/InitialPerformance20261101`负责冻结、串行运行和JSON比较，光学计算均在C#共享Core；辅助审计/续跑驱动使用显式`FrozenRuntime`引用，以免无意重编译不同内核。强制结束、磁盘失败和不同计算版本不等于正常停止后的精确续接。
