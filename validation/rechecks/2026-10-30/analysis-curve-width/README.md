# 曲线线宽三档（2026-10-30）

用户要求所有曲线图加粗，并在截图相机旁提供带下箭头的“线宽”选项，细、标准、粗三档，默认为标准。

## 实现与范围

- AnalysisPlotControl 共用渲染器默认标准档，细/标准/粗分别乘原系列 LineWidth 的 1/1.5/2；原 1.5 DIP 曲线成为 1.5/2.25/3 DIP。普通曲线、ColoredLine 和曲线参考线采用同一倍率，保留线型、颜色、透明度、原有相对粗细和图例线段；坐标、网格、散点/标记、柱形和热力图保持。
- 分析页 PNG 相机右侧增加原生 DropDownButton，文字“线宽”和一个原生向下箭头；菜单细/标准/粗为单选，默认标准。包含曲线的绘图页显示，数据/文本页和纯热力图隐藏，曲线全部取消勾选时仍能设置。
- 使用可继承的独立绘制状态；不替换 DTO、系列或坐标选项，不运行光学计算，也不触发 ResetView。覆盖当前全部子图和刷新后新建的子图。每个分析窗口独立选择，重新打开默认标准，未新增跨会话持久化参数。
- PNG 捕获同一原图，保留当前选择和缩放；静态报告重新生成的图默认标准。布局/实体模型射线配置保持独立。材料、实验室等使用同一 AnalysisPlotControl 的曲线同样获得标准档默认加粗；本次工具栏菜单位于普通分析页已有相机动作旁，未为其他窗口新建相机动作。
- 新增中/英/日菜单与提示文案。更新用户指南、UI 规范与协作约定。
