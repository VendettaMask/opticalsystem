# 统一源图、显示与普通 PNG 导出

日期：2026-10-30。范围：用户确认先统一整图规格，再统一 Logo/字号，不在保存时二次排版；随后要求显示也保持一致。

## 实现

- 分析绘图、基面场景与二维/三维布局共用 `UniformDiagramPage`：1200×900 DIP，绘图区 740、图签 160；沿用正式 S.T.A.R.Labs 标志及共享文字样式。
- 工作台直接显示该固定源图，窄窗口横向/纵向滚动，改变窗口不重排子图、图签或文字。保留当前平移、缩放、波前/场景相机和曲线勾选。
- 默认直接以 2 倍像素密度渲染，整图外侧各加 1 DIP 边框，PNG 为 **2404×1804**，不依赖当前窗口及显示器缩放。2 倍密度是在目标位图上绘制，不是把已有 PNG 拉伸。显式 1 倍/1.25 倍内部检查分别为 1202×902 / 1503×1128，不代表实际切换 Windows 显示缩放。
- 保存时不改变原图大小、字号和子图排列；分析捕获原控件，布局只组合已经排布的实时场景与图签，不重新取景。隐藏图签仍保留固定图框。设置、视角按钮和焦点外观不进入图片。
- 内容超过图框时显示明确原因，并在分配/保存图片前拒绝导出。过多子图、长摘要及用户大字号均不自动缩小或裁切；源 DTO 保留，减少视场/子图或调小设置字号后可刷新重试。
- 四种设计报告使用同一源图构造器；撤去本地上一阶段 PDF 专用的拆图、静态图例替换和字号放大。PDF 的隔离浅色配色保留，纯文字分析截图继续分页。实体模型保留原来的视口、紧凑参数和完整材质图例。

## 明确边界

这次统一的是**原始图面、显示和普通 PNG**。同一源图规格不表示所有分析的内部坐标区相等：单图、点列矩阵、成对扇形图有不同语义排布，但其整图、图签、Logo/文字样式和导出像素规格一致。

PDF 当前仍将整张源图按页面剩余空间等比放置，并混用横向/纵向页面，因此最终纸面图框及文字的物理尺寸一致性仍是开放项；本次没有将“源 PNG 相同”冒称“纸面尺寸一致”。桌面原 11 页 PDF 是此前冻结样例，未覆盖或冒称本轮成品。此前测量见 [PDF 复查记录](../pdf-paper-report/README.md#用户复查图框尺寸一致性仍未解决)。
