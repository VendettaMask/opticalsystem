# Afocal Huygens circular quadrature

The explicit `GaussianPupil` mode integrates traced scalar wavelets over the
continuous normalized circular pupil. The default `NativeFiniteCell` mode,
original API, native requests and all native gates remain unchanged. This stage
does not declare universal sampling convergence or new formal native Passes.

See the [report](../../../../docs/AFOCAL_HUYGENS_QUADRATURE_2026-10-30.md),
`assessment.json` and `verification.json`. The archive contains independent-disk
source, three successful hidden native controls, native grids/settings/model,
before/final continuum comparisons, under-sampled wide-window failures,
old/current/fixed medium-scaling probes, test/build logs and relevant source.
The first native enum-binding failure and all subsequent test/harness failures
are retained. Prepared but unexecuted first-cohort requests are not results.

`entry-map.json` maps logical paths to deduplicated zip members, lengths and
SHA-256 values. Every member is verified before sealing. The six immutable
dependency archives remain in their existing stages and are pinned separately;
no proprietary native DLL/executable is included.

Final scoped tests: 410 distinct passes (124 comparison + 286 Core), zero
failures/skips; earlier runs are superseded and not added. Default App Release
and diagnostic builds have zero warnings/errors; six Core copies agree.

The new mode is explicit in the existing PSF/profile/MTF parameter workflow.
It does not silently change old captures. Scalar, smooth-pupil paraxial controls
are certified by the stated 1e-10 continuum gate; complex clipping, rapid phase,
vector transport, absolute flux and arbitrary pupil-map convergence remain open.
All work ran in the background with pure C# product computation and shared Core,
without desktop control, full-corpus reruns, commit or push.
