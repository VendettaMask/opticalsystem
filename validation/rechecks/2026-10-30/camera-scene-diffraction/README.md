# 三维场景标量衍射、传感器与混合 A/B

本轮按用户要求继续现有主程序的三维成像，保留原镜头处方、像面位置、既有 FFT/Huygens 引擎与参考容差。操作入口见[三维衍射](../../../../docs/CAMERA_IMAGING_LAB.md#三维衍射)。当前是直接照明下的小角度标量表面求积，不能视为完整 Speos/ImSym 或高 NA 矢量波场认证。

## 计算与协议

1. NSC 逐对象求交提供真实表面位置和法向，中心光线及相邻实际光线建立源面积求积。背景即便被中心视线挡住，仍可参与逐瞳面遮挡检查。
2. 每个源点/波长使用原镜头表面追迹、材料和光程；传输功率与出瞳面积映射确定绝对复振幅。有限单元 sinc、倾斜及距离因子进入 Huygens 求和。相干求和限于同一点/同一波长，不同源点和波长按强度累加。
3. 没有在几何模糊图上重复卷积完整 PSF，没有逐图峰值或截窗能量归一化。窗口外功率与未采样源区域保持为有限求积限制；保护带若小于已追迹几何偏移加窗口半径，会明确报错。
4. 最终 W/实际感光像元接入原 QE/曝光、噪声、RAW/ADC 和 ISP 一次。正反面各自光照与投影面积处理，单面材质不向背半球发光。
5. `CameraLabV8-SceneDiffraction/1` 冻结场景、原镜头、算法和全部源/瞳面/像元/窗口设置及功率诊断。V5/V6/V7 保留各自计算身份；新增真实 V7 曝光 A/B 夹具从前一轮归档逐字节复制，不能用当前模型重造它。

## 独立验证与成品

物理控制包括三波长矩形孔径 Fraunhofer 绝对峰值、截面与暗零；同点相干/反相抵消；实际有限物距薄透镜圆孔 Airy 暗环、固定采样收敛和有限窗能量；物深、遮挡、掠视正反面、功率/曝光比例、ISP 独立修改、资源/取消，以及工作处方不变。形状控制可以归一化截面作比较，运行时仍保留绝对功率，不用测试归一化向产品补能量。

圆孔控制的 32 瞳面第一暗环/峰值约 **1.38485×10⁻⁷**；24→32 瞳面总功率变化约 **0.06424%**。有限探测区域收集该点模型入瞳功率约 **84.81%**，没有强制补成 100%。这些是特定解析控制的数值，不外推为一般镜头收敛保证。

可重开的成品和原始文件位于 `artifacts/validation/camera-scene-diffraction-20261030/`：

- `numeric/scene-diffraction-32.camera-experiment.zip`：32×24、3 µm、中心像元、12×12 瞳面、源细分 1、额外 PSF 半径 4、源保护带 24 的实际镜头三维衍射实验。
- `numeric/scene-diffraction-32-export.zip`：六阶段 PNG、原始 RAW/光电子、带积分功率 CSV、完整三维输入及算法设置。
- `numeric/diffraction-mixed-AB.camera-experiment.zip`：小尺寸几何 A/衍射 B，冻结各自镜头及传感器/ISP，可在工程被替换后分别复算。
- `screenshots/diffraction-Light.png`、`diffraction-Dark.png`：真实 Skia 离屏界面及采样控件；不代表操作过用户原生桌面。

32×24 的最终样例实际追迹约 583 万条光线、约 7406 万次复场单元求和；最大几何偏移约 14.57 像元，所需最小保护带 19、实际显式设置 24。时间以数值记录为准，不能作为通用性能保证。原 128×96 几何场景保留；此衍射配置不承诺在原画幅/高细分下满足资源额度。

## 逐例账目

按完整参数身份去重 **301 个最新结果通过**，新衍射/协议/界面 **13**、既有相关 **288**。主项目首批 300 个中 297 通过/3 个新例失败，后续定向批修复；掠视新控制最后使用 4 像元保护带覆盖极小浮点位移的保守取整。失败记录保留，不能把不同批次重复项累加为额外通过数。默认 Release App 最终构建零警告/错误，源码与测试/主程序默认 Core 指纹一致。

`verification.json` 记录各批次及按完整身份去重后的最新结果、源码和默认输出/测试 Core 哈希；`evidence.zip` 收入 TRX、数值、截图、成品及所有早期失败。复核入口为 [verify_evidence.py](../../../../tools/diagnostics/CameraSceneDiffraction20261030/verify_evidence.py)，不带参数仅作只读校验。独立诊断项目链接同一测试源码，只在初始结构并行编辑阻断全图构建时使用；最终验证仍回到主程序默认输出及主测试项目，不把独立项目冒充完整构建。

保留的早期问题包括：初始结构并行代码暂缺方法导致两次未执行测试；新处方不变断言忘记允许无限物距 JSON 字面量；补充保护带检查后，12/16 像元范围被正确拒绝并改为显式 24；界面测试在改参已清除 B 后误调用“复算”，修正为按真实操作先运行 B。另保留一次并行构建输出锁定的重试告警。没有改动任何既有商业参考、通过阈值或舍弃失败记录。

## 限制

仅共轴平面/球面与同介质理想薄透镜、空气物/像方，像方方向余弦 Z≥0.95，无奇异瞳面面积映射。仍无相干激光场景、高 NA 矢量场、散射、多次反射、遮挡边缘的多次衍射、微透镜或厂商 ISP。源表面、瞳面、感光区和有限范围均需独立收敛；细小物体与材质边界存在有限网格误差。非偏振界面采用逐界面平均功率的标量约定，不等于完整 Jones 运输。没有重跑全仓或原 170 项原生矩阵，没有发布、提交或同步。
