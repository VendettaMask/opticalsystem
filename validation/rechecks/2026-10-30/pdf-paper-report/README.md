## 实现范围

- PDF 使用同一工程快照和正式共享 Core 分析结果，新增专用纸面呈现模型。紧凑首页列工程名、文件名、日期、系统概要、视场/波长与项目状态，省略完整路径、内部修订与请求指纹；不用额外目录页。
- 按分析主题分页。普通图用纵向 A4，多面板与宽系数表用横向 A4；复杂扇形组按完整子午/弧矢图对拆页，每一原始子图和点保留。图面文字加大，完整图签、正式公司标志与整图细边框保留。
- PDF 的图例保留全部系列、颜色和标签，以静态色标替代复选框；隐藏交互提示和“其余项目见数据页”等工作台提示。只修改隔离的报告控件，工作台图与相机 PNG 保持原行为；纸面浅色作用域不受工作区深色主题影响。
- 正文优先显示至多五个可读关键指标（RMS、峰谷、最大像差/畸变、截止频率等），不列内部斜率字段或原始对象名。显示精度作便于阅读的整理，不改变实际计算值、Core 或验收规则。数值分析使用可选择的原生表格，完整分析表不缩成文字截图。
- 新增 PDF 专用“附加详细计算记录（增加页数）”，默认及旧设置均关闭，保存/复制/回读保留选择；启用时添加完整分析参数、原始分析文本、数值记录和计算来源。逐面完整处方与处方 JSON 继续排除。Word/Markdown/HTML 的完整分析记录行为保留。

## 用户复查：图框尺寸一致性仍未解决

用户指出不同分析图大小不统一。对同一交付文件复核哈希及 PDF 实际放置尺寸后确认：二维/三维图框为 **184.60 × 178.30 mm**，MTF/波前图为 **184.60 × 184.60 mm**，横向点列/光线像差/场曲图为 **218.50 × 103.50 mm**，详见 `figure-size-audit.json`。

原因在本次导出排版实现：源绘图使用不同的纵/横画布，PDF 又把完整图片连同图签按当页剩余空间等比缩放，没有固定物理图框、图签高度和最终字号。同类图在此样例中一致，但不同模板的尺寸和图签比例不统一；指标换行还可能继续改变缩放。原 46 项功能用例和无越界/完整像素检查未覆盖跨页物理尺寸一致性，因此这些通过结果不能作为视觉一致性合格证明。

本次定位只记录原因，未修改导出代码或覆盖桌面文件。该视觉问题保持开放；后续应先统一纸面图框与图签/字号标准，再让图形在固定区域内保持等比，长内容用分页处理。
