# 从 95 个菜单示例中选取的六类代表

本轮按用户要求，从「文件 → 示例」的 95 个原文件中选择不同类型，只查看输出图，不进行数值误差验收。以下六个文件都已核对菜单索引身份和 SHA-256；未用另一个同名镜头代替。

| 代表类型 | 菜单中的文件 | 主要观察内容 |
| --- | --- | --- |
| 常规折射物镜 | `Objectives/Double Gauss 28 degree field.zmx` | 多片折射、轴上及离轴光斑、色差与常规成像图 |
| 折反射望远镜 | `Telescopes/Schmidt-Cassegrain.zmx` | 反射路径、非球面、中心遮拦与环形光瞳 |
| 离轴反射系统 | `Telescopes/Yolo.zmx` | 倾斜偏心、坐标变换及不对称光路 |
| 无焦系统 | `Afocal/Afocal Riflescope.ZMX` | 无焦光束、角度坐标和分析适用性 |
| 多配置变焦 | `Zoom systems/Zoom lens.zmx` | 变焦处方、配置选择和配置矩阵图 |
| 衍射光栅 | `Diffractive components/Grating.zmx` | 衍射方向与波长分离 |

这组保留一个普通折射基准，增加五种不同结构，避免只选同一类物镜。之前 Cooke、Double Gauss、Petzval 的三例也来自同一份 95 文件索引；[原三例图册](../index.html)保留原范围。

[六例并排图册](index.html) · [菜单身份及选择理由](inputs.json) · [公共采集程序集身份](assembly-identities.json)

本轮图形入口收集已完成：六例各 71 个界面位置和 59 张对应原生窗口图，共 780 个图像文件逐一完成像素解码与引用检查，未发现损坏图片。六个源文件保持原哈希。图册的全部 426 种选择已作脚本检查。[最终收集与图像校验](verification.json) · [原生图单独核对](native-image-validation.json)。这些是图像完整性结果，不是光学分析通过计数。

图册按每例 71 个图形入口组织，包括三种结构视图；纯数值和文本报告不进入图册。每一页保留当前软件真实界面和可取得的原生窗口图片。诊断页、分析失败、捕获超时、原生图片缺失与不适用各自保留，不把“保存了截图”视为分析成功。完整采集状态见各镜头的 `workbench/manifest.json`，原生执行记录见 `zemax/visual-capture-status.json`。

原始采集加载同一源文件，保留两边各自默认显示设置，尚未统一所有采样、范围、参照、归一化、物方图像和相机。后续专项修复条目采用上级 [覆盖清单](../corrections.json)，在图下注明新截图的设置与验证范围，并提供历史原图入口；未覆盖条目保留原采集。普通页面使用文件当前配置；配置矩阵入口按自身设置显示配置。图像模拟还需要额外图像输入，本轮原生侧未配置该组输入，不能将这组缺图解释成原生软件不支持。图册整体没有计算误差表、相关性或精度通过率。

变焦普通页明确固定第 1 配置，配置矩阵页保留全部配置。原生侧为变焦单独保存第 1 配置的工作副本，每个窗口打开前重新加载该副本，避免前一个窗口留下的配置状态影响后页。该组位于 `zoom-lens/zemax-config1`，复用 `zemax/` 的 CFG；初轮串行窗口截图保留原执行身份。

软件侧采用当前产品的 `AnalysisPanel` 和 `ViewerPanel` 离屏绘制，六例共用 `assembly-identities.json` 记录的程序集；本轮没有复用旧版本 Double Gauss 的软件截图。原生侧通过已安装的 OpticStudio 2026 R1 API 保存截图副本和 CFG，在独立 Windows 桌面中执行原生 ZPL。原文件不保存，不切换或操作用户桌面。

采集源码复用上一级 `capture/`。本目录的 `select.py` 固定选择并检查索引；`run-current.ps1` 用两条独立后台进程通道捕获图形，达到单页截止时保留界面并继续下一页；`run-native.py` 串行捕获原生窗口，若阻塞则只终止本任务创建且已核对身份的宏进程，并保留被跳过的窗口身份。比较工具不属于产品计算后端，不修改产品光学公式、阈值或数值验收记录。

早期原生进度监视器按 UTF-8 读取 UTF-16 进度输出，且未把新图片计入进度，导致变焦与光栅初轮受到捕获看门狗中断。原回执保留；补采后的完整图片逐一解码核对，不把初轮中断当成原生光学分析失败。后续监视器已同时处理 UTF-16、文件更新和图片进度。变焦固定配置组独立核对。

## 专项修复图片

专项截图与三例图册共用同一份覆盖清单，按菜单源文件路径、SHA-256 和分析键匹配；程序重建图册时继续应用。双高斯扩展光源页已对齐原生 CFG 的 `LETTERF.IMA`、完整源宽 19.79898987322333°、质心参照和 50000 µm 范围，左图为实际新界面；原生截图和原来的均匀方形源图均保留。设置与验证界限见图片下的专项记录。

无焦瞄准镜的垂轴色差页已使用出射角差和艾里角参考。左侧产品单位 mrad，主图范围 ±0.2908882087 mrad 与右侧 ±1 角分等效，另提供自动 ±0.5 mrad 界面；最低点约 −0.9648 角分，艾里参考约 ±0.6114 角分。轴向像差页改用屈光度 D，自动 ±0.5 D，避免把近准直光束的有限轴交距极点作为图轴。新图均来自实际 `AnalysisPanel` 离屏渲染，旧原生图和旧软件图未覆盖；各项定向检查与数值验证边界分别链接在图下。

在本目录运行 `python ../capture/refresh-gallery.py .` 可只更新 HTML/JSON，`node ../capture/verify-gallery.cjs .` 检查全部 426 种选择、图片路径、嵌入数据一致性和历史图保留。仅刷新不重新捕获窗口，也不重写原批次 `contact-sheets/`；浏览器缩略图使用修复后的当前引用。验证结果汇总见上级 [覆盖校验记录](../corrections-verification.json)。
