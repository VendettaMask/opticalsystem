# 无焦轴向像差使用屈光度

2026-11-21，针对用户提供的 `Afocal Riflescope.ZMX` 轴向像差对比图。

## 原因与修复

原实现对有焦和无焦系统都绘制轴交距 `z = -y·dz/dy`，横轴始终标为毫米。无焦光束的某些光瞳带接近准直，`dy` 经过零，实际轴交距从正无穷变为负无穷；将它作为横轴会制造约 ±10⁶ mm 的尖峰，并把其余曲线压在零附近。

无焦分析现以最终像面局部坐标直接计算 `D = -1000·dy/(y·dz)`，即以米为单位的轴交距倒数。准直光线的值为 0 D，无须先生成巨大焦距再取倒数。轴上零光瞳点保持近轴极限，非零光瞳点保持原共享实际追迹及工程瞄准开关。`AnalysisAxisUnit.Diopter`、数据单位和手动量程同步采用 D；有焦系统保留原毫米定义。自动无焦量程由实际最大值向上取原有 1/2/5 刻度，保留所有曲线；有焦原有余量规则不变。

这一物理量选择与[原生软件官方轴向像差定义](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v242/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Longitudinal_Aberration.html)一致。未按镜头名或截图形状选择算法。
