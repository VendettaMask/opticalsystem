# 其他分析的光线瞄准设置审查

用户要求检查离焦点列之外的分析是否也漏用工程的光线瞄准设置。本次检查实际传参、共享接口及快照继承，不以界面标签判断物理行为。

## 检查范围与发现

用[编译器扫描工具](../../../../../tools/diagnostics/AnalysisAiming20261121/Program.cs)解析当前Core源文件，并绑定调用的实际参数，覆盖分析、共享服务和视图中的270处瞄准敏感调用。清单同时记录显式表达式、是否省略及被调函数默认值；还核对了快照中的开关保存/恢复、分析副本、Application参数分派和无瞄准参数的专用生成器。

确认并修复9处行为问题，未改动底层求交、折射、光阑目标、物理口径或通用API默认值：

| 路径 | 问题 | 修复 |
| --- | --- | --- |
| 几何MTF | 1处点列生成省略瞄准参数 | 沿用当前工程开关 |
| 非相干照度 | 1处入瞳采样省略瞄准参数 | 沿用当前工程开关 |
| 辐射强度 | 1处入瞳采样省略瞄准参数 | 沿用当前工程开关 |
| 实像高视场的畸变转换 | 1处反求发射场时省略瞄准参数 | 以同一瞄准方式反求场坐标 |
| 图像模拟 | 像素间距1处、畸变网格的实际/参考波长2处省略瞄准参数 | 三处均沿用工程开关 |
| 单色惠更斯MTF求值 | 1处将瞄准错误绑定到显示约定 | 物理瞄准与显示约定独立 |
| 公共子午光线接口 | 1处入瞳采样省略瞄准参数 | 沿用当前工程开关；该接口目前不是桌面布局生成器 |

另将受“瞄准关闭”前置条件保护的轴上惠更斯快速积分调用写成显式 `aimAtStop: false`，仅明确已有策略，不计入9处行为修复。

## 其他路径的处理

| 分析或接口族 | 检查结果 |
| --- | --- |
| 标准/全视场/矩阵/多配置点列、光线扇、足迹 | 已传递工程开关或委托到同一正确入口；离焦修复保留 |
| 波前、OPD、参考球、Zernike、干涉图、刀口 | 已传递当前或快照工程开关 |
| FFT/Huygens/MMDFT PSF、剖面、MTF图与扫描、RMS、几何/衍射能量 | 核对显式传参及可空参数的工程继承；本次另修复上述单色Huygens路径 |
| 相对照度 | 有限像方余弦采样遵循工程设置；完整物理入瞳积分保留其既定光阑坐标策略 |
| 单光线分析 | 保留分析自身显式瞄准选项，而不是覆盖该选项 |
| 入射角随像高 | 保留其明确的光阑瞄准取样，结果原已发布 `AimAtStop=true` |
| 专用轴上/流式衍射优化 | 明确检查要求瞄准关闭的前置条件，保持原规则 |
| FFT无法建立完整边缘锥时的回退 | 保留已实现的整套瞄准重试及实际使用状态，未更改其适用条件 |
| 有限反射共轭的入瞳参考探针 | 保留既有的几何差分参考约定；实际场主光线仍使用工程开关 |
| GPU采样、缓存瞳孔映射、无焦小扰动探针 | 由调用侧开关保护，或在接口内部检查/读取工程开关，未把“接口没有该形参”当成遗漏 |
| 材料、纯近轴/一阶等不发射实际入瞳的计算 | 不适用这项实际光线瞄准检查 |

最终[分析+共享接口清单](calls-helpers-final.json)和[检查日志](audit-helpers-final.log)确认：相关调用中隐式采用关闭瞄准默认值的数量为0。可空参数默认 `null` 的调用已沿函数体检查其继承工程设置，不被误计为关闭。工具的 `check` 模式会在再次发现省略的关闭默认值时失败；它不代替物理策略或数值审查。

## 数值复验

[定向工程](focused/Aiming.csproj)直接链接本次17项新检查与已有的点列、包络、物理遮挡、离焦、无焦像方及单光线检查，共51项全部通过，见[最终TRX](aiming-delivery.trx)。新检查覆盖开/关、探测功率与空间矩、几何MTF的实际入瞳、实像高反求、图像模拟标定、惠更斯两种显示约定及公共子午光线接口。几何MTF沿用既有分箱估计器，其算法未被本次审查替换。

首次新增测试的两项几何MTF检查误以连续逐光线傅里叶求和作为既有分箱估计器的预期值，原始[失败记录](aiming-audit.trx)保留；随后用原估计器隔离入瞳选择契约，未修改产品MTF算法。收尾构建中曾遇到同工作区多配置变量代码尚未完成的类型定义错误，已在该定义补齐后重跑最终检查，见 `tests-delivery.log` 与 `tests-delivery-final.log`。
