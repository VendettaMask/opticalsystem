# Color Fringes 非序列追迹与真彩色

用户明确要求完整追迹并显示彩色条纹。本轮从用户提供的原始
`Birefringence/Color Fringes.ZMX` 完成记录解析、真实实体/拾取、波片Jones相位、局部检偏、
源光谱、CIE/sRGB显示和保存重开。操作和模型范围以[专题说明](../../../../docs/NSC_COLOR_FRINGES.md)为准。

## 实际结果

- 原文件815条记录，5个对象，记录数量146/138/138/145/127；0个阻断项，1项非阻断的XYZ光谱拟合说明。
- 原始分析光线数1,000,000，随机种子1，最大500段、相对门限0.001、20个440–640 nm光源波段；
  Core实际运行4分39.50秒，100×100探测器记录功率 **0.446661346664945 W**。
- [逐波长像素功率及RGB](million-ray-data.json) 是本轮一次实际追迹的输出。
  [Light PNG](Light-million-ray.png)、[Dark PNG](Dark-million-ray.png)、[Isekai PNG](Isekai-million-ray.png)
  用同一组实际数据经产品绘图/PNG路径离屏导出，不插值生成条纹。
- 三张主题页面图使用200条光线验证真实查看器控件、真彩色/标量切换和中英日显示；
  这是交互及主题验证，不代表低采样图的光谱收敛。
- [106文件检查](import-audit.json)保留全部原字节身份。当前只有Color Fringes通过应用检查，
  其余仍按实际未知物理、对象或资产阻断；没有将菜单收录等同于完整导入支持。

## 精度边界

结果来自共享C# Core。原文件XYZ定义不唯一决定光谱，本实现采用记录在工程中的非负拟合，
而非声称复现私有拟合权重。本轮没有新的原软件逐像素捕获，不宣称彩色像素数值认证。
本次支持波片模式共同普通光线路径与Jones延迟；空间分离晶体模式、各向异性吸收及完整
各向异性界面振幅仍不在认证范围。CIE原始数据及许可见[署名](../../../../third_party/colorimetry/CIE-NOTICE.txt)。
