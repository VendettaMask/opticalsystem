# 高NA镜头离焦点列缺点修复

用户报告同一镜头文件的离焦点列图存在缺点，并提供原文件路径：`C:\Users\19851\Desktop\[MS-L7](10X大NA大视场).ZMX`。原文件只读，未改写或复制为产品镜头资产；内容身份记录在[结果清单](results.json)和原始计算JSON中。

## 根因与实现

原文件的光线瞄准设置已正确导入为开启。标准点列和普通点列指标均使用该设置，`FocusSweepEvaluator` 调用点列引擎时却漏传了开关，使用默认的未瞄准发射。在这个高NA处方中，轴上最外圈36条光线因此于第5面被截掉；另两个视场也在第1、5、6面出现错误发射导致的截光。原始[诊断日志](diagnostics.log)保留逐面分类；其中取消口径的独立诊断副本不是物理验收结果。

共享离焦扫描现传递当前镜头的 `RayAimingEnabled`；离焦点列数据同时记录实际使用的开关。系统关闭瞄准时保持关闭，原处方、口径、波长、采样密度、离焦量、自动图幅规则与显示控件保持原行为。瞄准本身使用已有共享追迹与光阑目标求解；未引入按文件名或数值调参的专用分支。瞄准的光阑采样含义可参见[厂商说明](https://optics.ansys.com/hc/en-us/articles/42661778056083-How-to-use-Ray-Aiming)。
