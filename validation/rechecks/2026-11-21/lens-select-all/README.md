# 镜头表左上角三角全选

用户要求将编号列表头从排序入口改成全选，并以参考图中的右下角实心直角小三角替代 `#` 文本。

## 实现

复用原生 Button 覆盖左上角整个格子，用12 DIP矢量直角三角形和当前主题的 `TextMuted` 色表示全选，保留原44 DIP列宽、表头高度和边框。支持鼠标点击、Enter激活及本地化“全选”提示/可访问名称。编号列禁用排序和拖动换列，列宽调整仍可用。

全选调用原生 DataGrid 多行选择，覆盖未滚动到的行。先完成有效的单元格和整行编辑，再等待其已排队的数据刷新后选择，避免刷新将全选退回单行；验证失败时不取消编辑。

## 验证范围

[定向工程](focused/SelectAll.csproj)直接链接已有 `LensHeaderTypographyTests.cs` 和公共离屏会话辅助类，引用当前默认输出路径的主程序，不复制产品代码。沿用现有五主题、中文/英文/日文、13/18 DIP字号的10组检查，补充实际鼠标和Enter全选、窄高度下未显示行的选择、显示顺序不变、零排序事件及原有字号/字重/对齐/列宽回归。

所有操作在独立的后台离屏窗口中执行，未控制用户桌面、重启用户程序或执行光学数值矩阵。项目还原的NU1900源不可达告警、共享代码更新期间的一次缺失类型和一次编译器文件锁记录为中途失败，不计为通过；未修改产品安全设置或终止其他进程。

默认输出路径的Release主程序及定向工程构建通过，7个NU1900源不可达警告、0个编译错误，见[构建日志](build-release.log)。10组测试全部通过，原始测试结果见[TRX](select-all.trx)，当前结果摘要见[results.json](results.json)。截图保留在 `captures/`，包括全选后的真实五主题窗口与较窄表面类型列；[普通主题实际效果](captures/lens-headers-Light-zh-CN-13.png)。
