# 非序列模式示例入口

用户指定本机 `Documents/Zemax/Samples/Non-sequential`。本轮完整收录16类106个ZMX，
保持原路径、文件名和字节，来源与SHA-256记录在[资源索引](../../../../src/OpticalSystemDesign.App/Assets/NonSequentialExamples/index.json)。
构建/发布复制到`Examples/NonSequential`，打开不依赖原安装目录。

非序列模式的“文件 → 示例”按分类选择，选中后直接显示该文件的现有导入检查，
保留原记录、阻断原因和完整记录导出。检查、取消及读文件失败不改变当前工程；
不能应用时保持禁用。顺序模式原14类95个示例、动作身份和打开流程保持。

## 实际导入边界

[逐文件检查](import-audit.json)覆盖全部106个原文件：**106个均有阻断，当前不能应用为可计算场景**。
每个文件至少包含未完整映射的全局记录、物理/设计定义与报告的外部资产引用；
42个还被当前读取器报告为混合模式端口。这里记录的是当前严格读取器的检查结果，
不是对源文件有效性或其原生软件可执行性的判断。`PROFILE.GRD`等被报告的引用也保留原样。
本轮未扩展商业NSC完整导入、提取二进制归档、复制外部数据库或执行数值认证。
