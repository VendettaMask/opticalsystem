# 圆锥及非球面变量导入

本页保留第二阶段实现和236项验证的历史范围。后续扩展数据、GRIN、多配置及95文件核对见[全面核对记录](variable-audit.md)。

## 实现

按用户补充要求，导入范围覆盖 `VCON` 圆锥系数和 `VPAR` 非球面系数标记。稳定的参数身份随表面转换、克隆、文件打开和镜头库转换进入优化绑定与处方 DTO。偶次/奇次的 Param 1..8 分别映射各自系数，扩展面系数从 Param 15 起映射，不把项数或归一化半径错当系数。已有 Fringe/Grid Sag、环曲面和 Forbes 基面的系数沿各自面型映射。

变量列表区分圆锥与非球面系数及其真实参数身份。实际优化和并行快照评价均写入现有不可变几何，计算仍使用共享 Core。圆锥使用已有 conic 配置链接，各非球面系数分别维护链接，保留其它配置已独立的系数；切换面型移除已不存在的系数变量。清除全部变量与撤销覆盖所有配置的这些标记。

极小的高阶系数使用非零搜索尺度。修复 `UnitRangeScaler` 将小于 1e-12 的有效区间统一变为零，以及 DLS 有限差分将此区间抬高为 1e-12 的问题；真实零宽区间仍是固定参数。没有改动矢高、法线或追迹公式。

快照 schema 7 存储形状变量，含新变量或系数配置链接的工程使用 STAROPT 23，防止旧版静默丢失元数据；旧版工程可由当前程序读取。原生 JSON 和 ZMX 导出重导入保留已映射变量。ZMX 导出也补齐半径/厚度标记。原始文件已丢失标记的旧导入结果须从原始 ZMX 重导入。
