# 扩展光源面积采样修复

## 根因

用户对比图中的两个差异需要分别处理：

- 原均匀方形源把完整源宽上的 5×5 个固定点当作发光源，并重复追迹这些点的瞳孔光线。因此累计能量出现由少数发光点位置决定的大台阶，增加每个点上的瞳孔光线并不能消除这种错误的离散源定义。
- 双高斯原生捕获的 CFG 使用 `LETTERF.IMA`，完整源宽 **19.79898987322333°**；软件旧默认使用均匀方形源，自动源宽 **1.4°**。两个源的形状与尺寸不同，旧图的横轴尺度不能直接作数值比较。两边横轴均为 µm，这一差异不是遗漏毫米/微米换算。

CFG 来源保留在[原始捕获](../all-output-visual-comparison/double-gauss/zemax/extended-source-encircled-energy.CFG)。完整源宽、场坐标单位、发光像素面积及最大显示距离的定义依据[官方扩展源文档](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v251/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Extended_Source.html)。源宽、源图和采样是独立设置，不把机器上保存的某个原生默认值当作产品默认值。

## 实现

均匀方形源和 IMA 像素统一分成面积积分区域；在每个区域内分布确定性的低差异源坐标，与共享瞳孔采样使用独立的序列维度。调用共享物理场光线生成器、实际顺序追迹器和像面/角度投影，不复制求交、折射、瞄准或光线传播公式。图中显示追迹样本的累计能量，未用拟合平滑替代采样。

实际源宽直接用物理场坐标传递，因此只有轴上视场时不会被最大视场 0 压成点源；源边缘超出视场表时也不必修改工程。保留源像素亮度、光谱权重、工程瞄准开关、孔径裁切与已到达像面的归一化。每批追迹至多4096条光线，并限制面积细分和总射线工作量。无焦样本保留 mrad，不再额外乘1000并错误标注为µm；最大距离设置和结果轴同时更新单位。

## 验证

[新增面积回归](../../../../tests/OpticalSystemDesign.Tests/ExtendedSourceAreaTests.cs)使用独立解析控制：-1倍理想中继把均匀2mm方形源成像，半径不超过1mm时的圈入能量应为 `πr² / 4mm²`。覆盖1/5/11区域密度、瞄准开/关、单像素与均匀源等价、只有轴上视场的物理缩放、超出已定义视场、非均匀像素的质心、真实孔径裁切、无焦单位、零亮度及取消。

[直接调用结果](checks.json)中的16组检查通过（13组新面积案例及3组既有能量检查），另完成真实应用结果映射和离屏PNG，见[断言及抓图日志](checks-direct.log)。[默认Release构建](../afocal-lateral-color/app-build.log)零警告、零错误。随后独立VSTest工程因90秒内无法连接testhost而中止，见[原日志](tests-vstest.log)和[TRX](extended-source-area.trx)；不能据此声称完整VSTest运行通过。不把重复执行累计成新案例数量。本轮只针对扩展源及相关能量路径，没有运行完整95镜头矩阵或四种报告格式导出。
