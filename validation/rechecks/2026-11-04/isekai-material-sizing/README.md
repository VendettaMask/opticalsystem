# 异世界页签与场景花饰：高DPI适配修复

用户先指出顶部“二维视图／瞳孔像差”页签出现浅纸条遮字，再指出二维图纸中的右上、下角花饰没有跟随纸面尺寸。两者在150%/200%显示缩放下可以离屏复现；单独96 DPI源图与普通窗口缩放不能覆盖此故障。

## 原因与修复

- 原生文档页签的DrawingBrush由多块带偏移SourceRect的ImageBrush构成，高DPI组合裁切错位后显示了错误的皮革/纸张区域。现将四个原皮肤一次性绘制为固定660×108、288 DPI的完整纹理，再交给原生页签底层伸缩；每UI线程仅四个缓存，不按窗口/DPI无限积累。未替换标题、原生关闭控件或命中区域。
- 空闲/悬停页签使用象牙白字，浅纸选中页使用深褐字，禁用色独立。检查真实文字在实际材质中心区域的对比度，以及标题和关闭区不重叠、状态切换不移动标题。
- 二维/三维/实体场景的四角改用DrawImage源矩形直接绘制，避开同类画刷裁切路径；沿实际画布边界定位，原花叶、天文/炼金组合和比例保持。没有修改素材PNG、镜片/光线几何、物理色或计算。
