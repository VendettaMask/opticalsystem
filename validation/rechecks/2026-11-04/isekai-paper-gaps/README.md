# 分析图纸上下露白：现有羊皮材质补齐

用户指出的两条浅色带来自`AnalysisResultTabs`结果容器的`#F4EBDD`纯色底板。图纸居中适应窗口后，上下空隙露出这层底板；不是图纸PNG缺失，也不需要改动图形尺寸或间距。

修复只将Isekai结果容器背景改为已有的`IsekaiDrawingMaterial.PaperBrush`，复用当前羊皮纹理，也能覆盖调整窗口后出现的左右留白。布局、图纸居中/100%滚动方式、原生页签、文字、科学内容、源PNG/报告和其他主题背景分支保持。
