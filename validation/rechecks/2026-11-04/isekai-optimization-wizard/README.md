# Isekai Optimization Wizard localization

2026-11-04 用户截图显示：窗口标题已为Optimization Wizard，但正文标题、表单标签、选项和摘要仍有中文。

## 修复

- 新增共享的优化向导本地化条目，覆盖标题/说明、卡片、表单/复选项、质量/参考/采样选项、操作数说明和全部禁用原因。选项仍使用原中文源字符串及原索引作为规范身份，原生显示模板只翻译标签。
- 动态摘要改为本地化格式模板与已翻译的标签；数字、RMS及操作数代码保持。已打开的向导随语言事件刷新摘要，关闭时取消订阅。普通主题的中文/英文/日文切换保留；异世界继续服从固定English策略。
- 窗口显式调用`DisplayTypography`并接入本地化树，正文及数字继承现有主题字体；Isekai实际标题字形为Almendra。
- 未修改默认值、采样统计、可用条件、设置DTO和实际生成算法。没有批量改动其他窗口或独立报告/工程制图字体。

## 验证

默认Release App及Tests增量构建成功，零警告/错误，复用已有Core/内置模块产物。见[App日志](build-app.log)、[Tests日志](build-tests.log)。

单次 **9/9通过，零失败/跳过，19秒**，见[TRX](wizard-localization.trx)：新增3项实际窗口检查（13/18 DIP及150%/200%；四种质量、两种采样及三种参考、动态禁用原因；已打开窗口三语切换和实际生成对比）；既有1项向导无效输入/恢复检查、3项多配置变量/向导回归，以及2项采样/向导参数存取检查。

英文窗口可见标签均无中文；真实标题字形为Almendra。只查看/选择模式不改变工程恢复状态。相同设置在普通中文主题与Isekai英文主题生成的完整`MeritOperandRowDto`数组逐项完全一致，包含类型、权重、采样/参数等原始字段。
