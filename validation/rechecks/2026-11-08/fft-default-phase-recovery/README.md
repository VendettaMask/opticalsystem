# 默认 FFT 按需加密复验

原菜单矩阵的 20 条固定 FFT 求值错误由相邻受光节点的未包裹相位差超过 0.5 波引起。默认 Workbench 入口现先执行请求档位，测得有限的欠采样相位差时再使用现有自适应精度路径。在原物理坐标上取得两档相位已解析并达到收敛目标的结果后，才返回较细档。显式固定采样仍报告原相位诊断，已有的固定设置也保留。 [逐请求台账](by-request.csv) [正式默认与固定回执](formal-evidence.zip)

二维 FFT PSF、FFT MTF 和 FFT PSF 截线的参数面板默认选中「按需加密」。该策略的采样上限分别为 2048、2048 和 4096，用户可设更低预算。显式「自适应精度」仍可使用其原有的较高上限。0.5 波相位保护、默认 0.001 内部相对 RMS 收敛目标及原逐分析外部容差保持。产品回执同时记录原档欠采样诊断及实际返回的采样。 [运行时](../../../../src/OpticalSystemDesign.Application/Runtime/WorkbenchRuntime.Analysis.cs) [参数面板](../../../../src/OpticalSystemDesign.App/Panels/Analysis/AnalysisPanel.Parameters.cs)
