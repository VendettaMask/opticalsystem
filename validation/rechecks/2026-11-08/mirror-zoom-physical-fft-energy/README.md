# Mirror Zoom 的环形瞳孔 FFT 包围能量

四条原请求 #2772、#2794、#2816、#2838 对应 Mirror Zoom 的配置 1–4。保留原处方、轴上视场、0.55 µm、原像面、标量 FFT 和质心参考。衍射极限与实际两条曲线各比较 0–5 µm 的全部 401 个节点。原生 32 档均返回低采样诊断，冻结总判定仍为 Incomparable。 [逐项结果与请求身份](results.json)

由原处方的配置表恢复各镜间距和前置遮挡，最终求解的像面位置采用同配置原生处方回读。入口瞳外半径为 75 mm，四个配置的内半径分别为 50、44.5、39 和 32 mm。逐配置独立求交并追迹四次反射，使用出射边缘光线方向计算像方工作 F 数，分别为 8.8110304、7.7351097、6.6547110 和 5.5083408。四份冻结原生单光线验证了归一化瞳坐标 0.8 的像面方向，方向余弦最大差小于 4.6×10⁻¹¹。

原生出瞳波前 #2764、#2786、#2808、#2830 与处方重建的完整 64×64 环形掩码逐点一致。相位拟合覆盖各自 1,648、1,932、2,196、2,448 个有效节点，最大误差小于 2×10⁻⁹ 波。用零阶贝塞尔核积分实际及理想环形瞳孔，按 Parseval 关系使用全像面总能量归一化。理想环瞳另以一阶贝塞尔函数的解析振幅核对。32→64 点积分与第二组相位拟合均通过原门槛。有限网格参考另外从完整 FFT 周期求质心，以全周期功率归一化。 [独立计算](reference.py)
