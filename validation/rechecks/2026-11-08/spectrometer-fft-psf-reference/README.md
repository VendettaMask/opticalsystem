# Sample Spectrometer #443 的独立 FFT PSF 参考

复算使用原处方、配置 1、轴上视场 1、原主波长 0.55 µm、原像面及标量线性辐照度。像面保留原 128×128、0.25 µm 网格，X、Y 坐标各为 −15.75 至 +16.00 µm。冻结原生 FFT 缺有效网格，历史 Incomparable 判定保留。

从有限共轭的 0.08 NA 物方光锥出发，按原坐标断点计算两块球面镜和一块反射光栅。光栅位置相位使用原线密度与衍射级次。对存档 83 条有符号原生光线，五面的截点、方向余弦和含光栅相位的 OPTH 最大差分别为 2.32×10⁻¹⁵ mm、1.34×10⁻¹⁵ 和 7.11×10⁻¹⁵ mm。采用存档原生出瞳位置 0.092752357417 mm，冻结 #442 波前全部 1,153 个有效节点的掩码相同，绝对 OPD 最大差为 2.59×10⁻¹¹ 波。 [有符号原生光线和出瞳](../../2026-11-07/spectrometer-opd-reference-plane/README.md)

物理光瞳为被狭缝裁切的单位圆，归一化半宽为 0.31149839。区间计算验证整个通光域均落在镜面与光栅口径内，三面的保守余量分别为 0.11978、0.06286 和 0.12151 mm，并验证实际光线均与参考球相交。以同一理想瞳孔的轴上峰值归一化，计算完整物理光瞳的带相位 Fourier 积分。横纵工作 F 数 5.42251944 和 5.35681803 分别由原处方边缘方向独立求得。192×768→256×1024 的积分变化为 2.15×10⁻¹¹ NRMS。用算术平均边缘方向、实际非线性出射方向和 Workbench 名义参考球分别作为对照，变化为 3.62×10⁻⁸、0.00119 和 8.06×10⁻⁵ NRMS。 [数值与输入哈希](verification.json)

Workbench 从原 64 档启用 Adaptive，流式物理窗口在 2560 和 4096 档通过相位检查。档间 NRMS 为 0.00240623。声明相对精度 0.003 时，正式入口返回全部 16,384 个像元。4096 档对独立参考的 NRMS 为 **0.000720024**，最大绝对差为 1.21×10⁻⁷，原 NRMS 0.01 和逐点门槛均通过。默认自适应精度 0.001 下仍报告不可用。 [比较指标](verification.json) [正式入口原始数据](../streamed-physical-fourier-windows/README.md)
