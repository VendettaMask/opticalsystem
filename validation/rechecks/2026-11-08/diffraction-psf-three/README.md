# 三条二维 FFT PSF 的原窗口加密

OpticStudio 2026 R1 对三条请求补采 1024 档，再对 #3001 追加 2048 档。沿用原处方、配置、视场、波长、标量设置和 128×128、0.25 µm 的像面网格。核对光瞳采样、选择器和处方回读。当前 Core 通过正式 Workbench 入口重算 1024 与 2048 档，均经过相位保护。每项比较覆盖全部 16,384 个像面像素，采用原容差。 [设置和程序集回执](receipts.json)

| 请求 | 原生相邻档与 NRMSE | Core 1024→2048 NRMSE | 细档交叉 NRMSE | 独立结论 |
| --- | --- | ---: | ---: | --- |
| #2565 Lens pivoted about a point | 512→1024，0.00368654 | 0.00129634 | 0.00132751 | 通过 |
| #2831 Mirror zoom | 512→1024，0.00883814 | 0.00430887 | 0.00426987 | 通过 |
| #3001 Zoom lens | 1024→2048，0.00317799 | 0.00317799 | 2.08871×10⁻⁷ | 通过 |

#3001 的原生 512→1024 仍为 Close，追加 2048 档后通过档间和同档对照。追加批次在完整保存结果后报告 FRU 关闭错误，逐请求保存和诊断回执完整。三条冻结记录保留原分类。 [逐项台账](by-request.csv) [逐档指标](comparisons.json) [数值载荷清单](manifest.json) [新增原始数值](numeric-evidence.zip)
