# 过程预览图清理

用户在旧任务清理中指出过程预览图的保留价值有限。本轮检查了工作区图片的实际用途、Markdown链接、维护中的源码/脚本引用、冻结清单和原始字节身份，删除 **221 张图片，约 26.60 MiB**：

- 214 张逐字节相同的本地副本：每组保留一份原件，原用途路径、SHA256及现存原件位置写入[清理收据](receipt.json)。这些删除项均为本地忽略文件，不改动现有统一证据映射。
- 5 张过时的字体/圆角界面试稿：原渲染源码与说明仍在；另有1张相同的圆角预览已计入上述副本，不重复计数。
- 2 张已撤回、从未接入产品的灰色花纹候选：删除其受跟踪PNG，保留原提示词、哈希及撤回决定。见[候选退役说明](../../../../artifacts/design-candidates/2026-11-04/isekai-gray-not-applied/README.md)。

正式材质、用户参考图、已确认方案、数值参考和独有验证截图均保留。`previews` 只是目录名：其中实际记录DPI、字体、图例、透明边缘或失败状态的独有截图不能当作无用草稿。旧Python分析图被已有历史参考盘点记录识别，本轮也未因所在目录名而删除。

删除前再次检查进程占用，逐文件复核身份、修改时间和副本原件。删除后 **32,729 个其余原受跟踪文件哈希不变**，其他保留文件没有意外缺失或变更，214份副本的现存原件再次匹配。上轮尚未提交的清理改动保持。随后只补充本轮存储说明和收据。

没有停止或重启程序，没有生成新图片、运行光学计算或重做界面验收。本轮文档链接检查单列于收据，不冒充产品数值/界面测试。已提交图片的历史Git对象仍保留，不通过改写历史回收空间。
