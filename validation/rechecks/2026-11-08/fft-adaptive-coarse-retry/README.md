# 二维 FFT PSF 的粗档恢复

显式二维 FFT PSF 的固定像元间距可能让粗档在瞳内不足两个独立节点。自适应入口记录这个物理采样失败并继续加密。需要密瞳路径时，沿用请求明确指定的输出尺寸。返回结果仍需两档相位通过，并在完整物理网格内满足原自适应收敛判据。原固定采样及原采样验证继续使用其请求档位。

Unobscured Gregorian #2499 的原图像窗是 128×128、像元间距 0.25 µm。粗档 64、128、256 均不足以产生二维瞳孔。密瞳 1024→2048 达到相对 RMS 变化 0.000827883，通过默认 0.001 收敛要求，正式入口返回全部 16,384 个物理像元。原生 1024 和 2048 同窗均返回无效空网格，独立跨软件验收保留开放。 [Core 诊断及逐点值](verification.json) [原生同窗重采](../diffraction-2499-native-high/README.md)

Singlet eyepiece #555 也能越过不足的 64、128、256 粗档。常规与密瞳路径仍未在 2048 档预算内建立收敛，正式入口继续报告不可用。 [两条输出与请求](core-numeric-evidence.zip)

Twyman Green Interferometer #2157 在原 0.25 µm 像元间距下，2 倍变换窗的 2048 档最大相邻相位步长仍为 1.47966 波。4 倍和 8 倍窗在 1024、2048 两档均无法覆盖完整物理光瞳。保留该项的产品相位收敛问题。 [档间及物理光瞳诊断](twyman-window-diagnostic.json)

该自适应增量在完成同日原矩阵程序集构建后加入。所有 2,904 条可执行原请求均未指定自适应模式。以增量程序集定向验证了 205 项产品回归和 82 项比较回归。同步既有的分析参数断言后，完整参数约定测试另行通过。 [产品回执](focused-product-final.trx) [比较回执](focused-comparison.trx) [参数约定回执](gui-descriptor-complete.trx)
