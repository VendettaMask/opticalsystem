# Diode Source Simulation #1097 的独立 FFT 截线参考

复算沿用原处方、配置 1、轴上视场 1、0.55 µm、原像面、标量 X 中央截线和自动范围。原 32 档请求的物理横轴由原处方独立得到的 X/Y 工作 F 数 2.87356322 和 0.99849748 确定，范围为 ±8.23760423935 µm，共 201 个原坐标。冻结原生截线保留 Incomparable。

原近轴 XY 面仅在 Y 方向有 7.971 mm⁻¹ 光焦度。径向光束上，近轴面前后的斜率均随归一化半径线性变化，因此可闭式积分相位差，再把光程校正到原出瞳参考球。独立截点和方向与冻结原生实光线分别相差最多 1.61×10⁻¹² mm 和 4.30×10⁻¹¹。冻结 #1092 的 1,043 个原生波前有效点掩码一致，OPD 最大差为 5.06×10⁻⁸ 波。 [原生载荷身份及比较](verification.json)

按原高斯振幅因子计算完整圆瞳，以同一高斯瞳孔的零相位峰值归一化。在全部 201 个原坐标直接求 Fourier 积分，径向与角向采样从 512×1024 增至 768×1536 后，截线 NRMS 变化为 9.17×10⁻¹³。既有 #1093 二维 PSF 的原生 2048 档中央行与独立参考最大差为 5.77×10⁻⁷，该对照验证两条分析共享的中央像面辐照度。 [既有二维 PSF 回执](../diffraction-psf-late-window/README.md)

另按物理圆瞳离散网格直接计算 3072 和 4096 档，两档原相邻点相位差最大为 0.04016 和 0.03012 波，截线档间 NRMS 为 0.00040608。较早的正式入口在密瞳覆盖与分配阶段返回不可用。采用中心首站的闭式相位后，正式自适应入口以原请求和 0.001 精化设置完成。3072、4096 两档产品截线的收敛差为 0.000406083，与独立离散结果一致。

4096 档产品覆盖全部 201 个原横轴点，轴坐标最大残差为 5.33×10⁻¹⁵ µm。与独立连续参考相比，NRMS 为 0.000431038，最大绝对差为 4.11×10⁻⁸，满足原 0.003 门槛及逐点门槛。补充验收通过。 [逐档对照与验收](verification.json) [新旧正式入口原始回执](formal-evidence.zip)

复算使用 Python 3.11、NumPy 和 SciPy，运行 `python DiodeAxisReference.py <仓库目录> <输出路径>`。附加 `--finite-control` 可复算离散控制。为每次正式入口数据附加 `--replay <data.json> <request.json>`，报告会核对原设置并记录完整曲线的比较结果。 [复算脚本](DiodeAxisReference.py)
