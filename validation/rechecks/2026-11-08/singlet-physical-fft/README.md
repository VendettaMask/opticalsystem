光阑到虚像面的距离为 1,000 mm，光阑直径为 5 mm。原生处方与瞳孔读出给出工作 F 数 200。使用同处方、视场、波长和瞄准设置的原生出瞳波前 #554，核对其完整二维通光掩码。以归一化瞳半径平方拟合旋转对称的相位，3,001 个原生相位点的最大残差为 4.59×10⁻⁸ 波。单一子午线独立拟合后验证整个二维掩码，最大残差为 4.83×10⁻⁸ 波。用贝塞尔核计算完整圆瞳的傅里叶强度，以同瞳孔理想峰值归一化。64→128 点求积和两种独立的波前拟合均通过原像面比较门槛。 [原生出瞳 OPD 定义](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Exit_Pupil.html) [独立重建脚本](reference.py)

原窄像面窗将粗档的有效受光点压缩到中心。自适应模式可在既有路径无法建立收敛时，以标准化完整瞳孔追迹，按原物理坐标计算精确离散傅里叶频点。各波长和方向沿用原工作尺度，输出保留原相位保护和理想峰值。使用原起始档 64，显式选择 Adaptive、采样上限 2048 和相对精度 0.001，正式入口从 512→1024 两档得到收敛。相邻相位最大步长分别为 0.04003 和 0.02011 波，双档 NRMSE 为 0.0001228。正式结果对独立参考的 NRMSE 为 **0.0001813**，最大绝对差为 2.04×10⁻⁵，满足原逐点门槛。 [正式证书与完整网格](reference-results.json)
