# FFT 衍射自适应窗口修复与独立复验

FFT PSF 截面在显式物理范围超出粗档 Fourier 区间时，自适应入口会记录该档无法覆盖并继续加密。计算仍需相邻两个覆盖完整范围、相位通过的档位达到既有收敛条件。固定采样及验证原采样仍以请求档位为准。原档无有效输出时，报告留空原档偏差。各档仍按既有光瞳工作量预算计费。

Scanning mirror #2879 的 X 截面固定在 ±250 µm。自适应从 32 开始，保留默认 0.001 相对 RMS 条件并声明 4096 上限。原路径的 32 至 512 档不足以覆盖窗口。修复后完成加密，密瞳 1024→2048 的相对 RMS 变化为 0.000461578，最大绝对变化为 8.44261×10⁻⁶。返回的 2048 档与原生 1024 档在完整物理窗口内通过，NRMSE 为 0.000594717。下表同时保留两侧固定档的独立复验。 [计算证书及曲线度量](fixed-curve-results.json)

同一处方再使用原自动窗口与自适应加密，保留原 201 个坐标和 ±58.566 µm 的范围。原生细档 ±250 µm 曲线覆盖全部坐标，插值到原坐标后 NRMSE 为 0.00114440，满足原容差。 [自动窗口收敛及共同节点比较](fixed-curve-results.json)

二维 PSF 保持原 128×128、0.25 µm 的物理像素网格。#967 和 #2787 的定采样产品档均经过正式相位保护，以原分析比较门槛验证相邻完整网格。其历史自适应 0.001 证书结果单独保留。#2157 在 2048 档的相邻受光节点最大相位差为 1.47966 波，超过 0.5 波保护界限。截面比较使用完整的 ±250 µm 明示物理范围，原自动窗口仍按冻结请求记账。表中有结果的比较均达到 100% 共同物理域。 [逐项台账](by-request.csv) [二维 PSF 逐档数据](fixed-psf-results.json) [曲线逐档数据](fixed-curve-results.json)
