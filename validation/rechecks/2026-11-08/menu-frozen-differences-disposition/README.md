## 按原阈值逐组复核

- **Grid GRIN**。11 条直接对收敛的原生细步长结果通过。四条单光线的全部原生已报告量通过，原生逐面报告缺报的第 2 面网格体弧长由 130 个归档深度站点独立重建，与当前 Workbench 的最大差为 4.37157×10⁻⁹ mm。原生两档重建弧长相差约 9.19×10⁻¹⁴ mm。 [15 条逐项数值与原生档位](grid-grin-verification.json)
- **高采样衍射**。9 条使用正式 Workbench 入口重跑原物理窗口，两边各自的加密比较和跨软件对照均通过各自原阈值。光谱仪 #451 的 1024→2048 档，Workbench 和 Zemax 的最坏 NRMSE 分别为 0.00159288 和 0.00169364。2048 同档跨软件 NRMSE 为 0.0000687206，覆盖完整原离焦范围。 [9 条逐项档位、覆盖和度量](dense-diffraction-verification.json)
- **独立等效参考**。#125 的普通折射率近轴对照返回 100 mm 和 F/5。#847 的独立近轴探针核验了焦距和 F 数。#608 和 #698 的原光扇坐标通过两个独立原生模式。Etalon #2216 与 #2220 的稳定光程参考从原生实光线及绝对光程重建。轴锥 #950 采用显式「校验轴对称瞳孔积分」的正式入口，对独立收敛原生光线重建通过。每条的参考定义、原模式和实际回执分别记录。 [7 条逐项参考合同与度量](equivalent-definitions-verification.json)

Huygens 截线 #448、#500 和 #2162 在原 Workbench 的 32 个物理像素中心上全部逐点通过。原生报告另外打印 +4 µm，区间覆盖率为 96.875%，满足原门槛。#2162 通过的是原逐点判据。#950 的旧原生截线也有额外坐标，独立连续瞳孔参考逐点覆盖原 Workbench 的 32 点。 [截线完整原产品坐标和额外原生端点](profile-physical-coverage.json)
