# 分批 FFT MTF 复验

两项均使用原配置 1、视场 1、有焦标量调制度及 0–50 cycles/mm 轴。子午和弧矢各有 300 个坐标。Workbench 从原 64 档开始，仅显式选择「自适应精度」、相对 RMS 0.001 和对应上限。原生复采只提高瞳孔采样。原比较门槛为绝对 0.001、相对 0.001、NRMSE 0.01 和覆盖至少 95%。下表各项的坐标覆盖均为 100%。

## #445 Sample Spectrometer

原选波长 2，瞳孔入射权重均匀。已有 256 档原生结果带欠采样诊断，512 档首次得到完整曲线。继续采集的 1024 和 2048 档均通过原生诊断。产品 4096 上限的正式入口选出 2560 和 4096 两个全瞳档位，最大相邻相位差分别为 0.46962660 和 0.29424614 波。两条曲线合计档间相对 RMS 为 0.000744244，满足 0.001 精度，累计追迹 18,302,734 个分批节点，耗时约 64 秒。

| 对照 | 子午 NRMSE | 弧矢 NRMSE | 原门槛 |
| --- | ---: | ---: | --- |
| OpticStudio 512→1024 | 0.00994312 | 0.00198595 | 通过 |
| OpticStudio 1024→2048 | 0.00264785 | 0.000711280 | 通过 |
| Workbench 4096 对 OpticStudio 2048 | 0.0000863800 | 0.0000533613 | 逐点和 NRMSE 均通过 |

最后一组对照的最大调制度差为 0.000931844 和 0.000164055。 [正式回执](445-receipt.json)

## #1095 Diode source simulation

原选波长 1，Gaussian 瞳孔照明因子为 1。已有 256→512 两个原生档均提供曲线，但收敛超原门槛。本轮提高至 1024、2048 后，两轴原生结果独立收敛。

| OpticStudio 档位 | 子午 NRMSE | 弧矢 NRMSE | 原门槛 |
| --- | ---: | ---: | --- |
| 256→512 | 0.0448230 | 0.0126417 | 超限 |
| 512→1024 | 0.00529816 | 0.00163026 | 通过 |
| 1024→2048 | 0.000846592 | 0.000281524 | 通过 |

产品设置上限为 6144，现有自适应路径在相位已解析的 1024→2048 两档建立收敛，未进入分批路径。两轴曲线合计档间相对 RMS 为 0.000846535，满足 0.001 精度。后台耗时约 27.3 分钟。返回 2048 档与独立收敛的 OpticStudio 2048 比较，子午和弧矢 NRMSE 分别为 0.00000293357 和 0.00000100677，最大调制度差分别为 0.0000476970 和 0.0000106821。600 个频率点全部覆盖，逐点容差和 NRMSE 均通过。 [正式回执](1095-receipt.json)
