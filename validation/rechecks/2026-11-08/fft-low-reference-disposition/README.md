# 16 条 FFT 旧低档参考差异复核

本轮重算前一次比较中列为差异的全部 16 条原请求。默认 Workbench 输出在原物理坐标和原容差下分别通过两档已收敛的 Zemax 参考，当前验收为 **16 通过、0 差异**。范围包含 8 条 FFT PSF 截线、7 条 MTF 和 1 张二维 PSF。 [逐项验收台账](by-request.csv) [正式重放原始载荷](formal-replay.zip)

| 在同一物理域上的比较 | 通过 | 差异 |

| 冻结低档原生数据与每一档高采样原生数据分别比较 | 0 | 16 |

| 本次 Workbench 与每一档高采样原生数据分别比较 | 16 | 0 |

旧原生数据与两档高采样数据的差异在旧报告自己的全部坐标上复现，在旧报告覆盖的原 Workbench 坐标上也复现。后一种对照中，16 条对最细档各自的最坏 NRMSE 范围为 0.0162902–0.440965。两档高采样原生数据相互比较的最坏 NRMSE 为 0.00225839，本次 Workbench 对最细档为 0.00240125。三个比较使用原政策和原物理量单位。这使 16 条差异可归因于旧采样档的参考值未收敛。 [三方逐项指标和原生载荷哈希](three-way-comparison.json)

32 份高档回读与旧档的全部分析选择器及采样以外的属性一致。#559 的归档原生保存副本通过模式回读绑定原文件的 `PupilSizePosition`，两档均使用该副本。#1989 和 #2679 的旧高档回读通过冻结源路径和原生文本绑定源文件、轴上视场、波长、像面与 cycles/mm。#2813 和 #2835 的旧高档资料以原生文本和光学像面尺度交叉核对，记录了用原波长、网格与坐标间距反算的工作 F 数。 [原生保存副本控制](../../2026-11-07/fnumber-etalon-mirror-zoom/README.md) [原生像面尺度对照](../../2026-11-07/focal-trace-fft/native-scale-controls.json)

七条旧截线各有两个旧报告端点超出原 Workbench 自动窗口。#2835 的两个原 Workbench 端点超出旧报告范围。旧档比较只用共有坐标。两档收敛参考均覆盖完整原 Workbench 窗口，且覆盖旧报告的全部坐标，所有比较均无外推。 [端点覆盖和物理坐标](three-way-comparison.json)
