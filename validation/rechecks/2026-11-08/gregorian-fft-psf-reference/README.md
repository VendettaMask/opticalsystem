# Unobscured Gregorian #2499 的独立 FFT PSF 参考

原处方、配置 1、轴上视场 1、10 µm 波长、原像面、标量线性相对辐照度。完整原网格为 128×128，像元间距 0.25 µm，两轴范围均为 −15.75 至 +16.00 µm。原生 FFT 在 1024 和 2048 档返回空网格，冻结结论为 Incomparable。 [原生同窗重采](../diffraction-2499-native-high/README.md)

独立计算按原处方求两次锥面反射。两面镜共享母轴，入射光线在各自的子午面中传播。对母轴半径 50 至 150 mm 的整个区间证明次镜反射根在原 28 mm 通光口径内。该根的最大逐面截点差为 1.55×10⁻¹² mm，方向余弦最大差为 8.33×10⁻¹⁵。三面共核对 3,001 条存档原生光线，全部通光。 [原生逐面光线与处方](../../2026-11-07/menu-remaining-eight/README.md)

由光阑处近轴方向探针的像方交会计算参考球半径 185.363979762 mm。用原生边缘方向对应的方向 F 数处理原 Wavefront 投影坐标，独立重建的相位与冻结存档中全部 2,999 个有效点最大差为 1.29×10⁻¹⁰ 波。圆瞳内以 Gauss–Legendre 径向节点和等间隔方位角积分，使用原 FFT 的 X、Y 线性尺度，并按同一理想瞳孔的轴上峰值归一化。径向与方位档从 24×96 增至 48×192，像面 NRMS 变化为 2.57×10⁻¹²。以实际出射方向替换 FFT 线性映射的对照变化为 7.33×10⁻⁵ NRMS。 [独立求交、相位和积分](GregorianReference.py)

正式 Workbench 密瞳 1024→2048 的相邻档 NRMS 为 0.000827883。最终 2048 档对独立参考的 NRMS 为 **0.000439097**，最大绝对差为 0.000613946。按原 NRMS 门槛 0.01 和最低覆盖率 0.95 计算，全部 16,384 个像元覆盖，独立结果为 **Pass**。 [数值和输入哈希](verification.json) [Workbench 完整数据与自收敛记录](../fft-adaptive-coarse-retry/README.md)

使用 Python 3.11、NumPy、SciPy 和 mpmath，运行 `python GregorianReference.py <仓库目录> <输出路径>` 复算。脚本直接读取既有原生光线、冻结原生 Wavefront 和 Workbench 数值存档。
