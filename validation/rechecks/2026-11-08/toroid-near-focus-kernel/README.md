# Toroid 原像面 FFT 近焦适用性

两条主轴的边缘光线在原像面分别距主光线 19.999314 mm 和 0.561890 mm，相当于 39,998.6 和 1,123.8 个波长。原生 #1364 约束的同一参考球在相同圆瞳、相位和振幅下提供传播核对照。由真实出射光线反推参考球交点 `s`，使用相对于球心距离的精确传播差 `|s−q|−R`，另算其切向核 `−s·q/R`。该对照保留单位振幅入瞳权重，隔离传播相位与方向映射。 [几何和核误差](results.json)

参考球在两条主轴边缘的横向方向系数为 0.12009692 和 0.11861876。FFT PSF、截线和圈入能量的系数均为 0.08234304，FFT MTF 的像方系数为 0.05822499。在原圈入能量的 5 µm 半径上，两条主轴的边缘线性相位误差为 0.378 和 0.363 波。在 16 µm 位移上为 1.208 和 1.161 波，在原截线末端为 3.294 波。这些是算子方向映射的误差。 [原波前约束和采样](../toroid-fft-phase-domain/README.md)

MTF 逆方向映射直接迭代至残差小于 5×10⁻¹³，两档有符号 OTF 最大差 9.89×10⁻¹²。圈入能量以真实球面投影 Jacobian 计算全切向场 Parseval 功率，精确距离只在原窗评估并共用该分母。理想曲线两档最大差 1.65×10⁻¹⁰，切向与精确距离最大差 1.43×10⁻¹⁰。 [MTF 见证](mtf-kernel-control.json) [圈入能量全曲线](energy-kernel-control.json)

四项都显示原像面的 FFT 线性方向映射偏离同一原生相位约束的球面传播。#1372 的理想分量在完整原窗超过原门槛。这里的结论针对共享圆瞳和振幅的独立标量核对照，商业软件 Huygens 的振幅传输、归一化和正式同合同验收仍需对应证据。保留四项冻结原判定。

用 Python 3、NumPy 和 SciPy 依次运行 `Probe-ToroidKernel.py`、`MtfKernelControl.py` 与 `EnergyKernelControl.py`，各传入 `<仓库目录> <输出目录>`。设置 `OPENBLAS_NUM_THREADS=2` 和 `OMP_NUM_THREADS=2` 可复算。PSF 和截线的同窗复场保存在 [同窗复场](same-window-fields.npz)。
