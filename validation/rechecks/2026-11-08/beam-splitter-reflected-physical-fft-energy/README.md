# Beam splitter 反射支路 #996 的 FFT 包围能量

保持配置 2、轴上视场、0.55 µm、原像面、标量 FFT 和质心参考。衍射极限和实际两条能量曲线各有 401 个节点，覆盖原 0–5 µm。原生 32、256、512 档均返回低采样诊断，未提供可比较曲线。冻结总判定保留 Incomparable，补充通过来自独立物理参考。 [原请求、诊断及逐点结果](results.json)

按原处方的 45° 反射斜面与 90° 坐标断点展开反射轴，逐项核对原生配置回读的镜间距、曲率与介质。独立折射与反射给出边缘出射尺度 F 数 3.37610283180705。将展开的结果转回原生坐标，归一化瞳坐标 0.8 的像面交点和出射方向与冻结单光线 #984 一致。129 个径向采样和斜面任意方位的口径上界给出最小间隙 1.63859 mm。原生 #988 出瞳波前在圆瞳内部完整，单位圆边界有两个离散轴点缺失。

沿实际光线积分光程，使用冻结 #983 报告的 246.9485 mm 出瞳位置计算参考球交点。光程相位与 #988 原生波前拟合的最大差为 1.582×10⁻⁸ 波。两套相位各自积分完整圆瞳并按 Parseval 全功率归一化，实际包围能量互比最大 NRMSE 为 2.33×10⁻⁹。理想曲线通过艾里解析式核对。64→96 点积分和两套相位的实际曲线均通过原门槛。 [独立光程和傅里叶求积](reference.py)
