# Twyman Green #2164 衍射包围能量的独立参考

复算采用冻结的配置 1、轴上视场 1、0.55 µm、原像面、标量 FFT、原质心参考和余弦三次方入射功率。实际与衍射极限各覆盖 0–5 µm 的 401 个原半径节点。独立追迹保留折叠路径的带符号传播、两次反射与 BK7 吸收。虚参考球由 #2156 原生波前约束，折叠追迹也与 #2152 原生实光线一致。 [几何与原生约束](../twyman-streamed-fourier/README.md)

用整个圆形通光瞳直接积分复振幅，再以全像面 Parseval 总功率归一化。单位峰值辐照度的全功率为 0.4821060234 µm²。独立追迹在全部求积节点和有限瞳面网格上核对物理孔径，最大的相对孔径半径为 0.83882。实际质心沿 X 由对称性确定为零，沿 Y 由全瞳功率加权的相位梯度计算，为 −0.4138684 µm。衍射极限瞳孔的振幅为实数，强度在中心反演下对称，两轴质心均为零。

完整有限傅里叶周期的 Y 质心从全谱的边缘功率求和得到，Parseval 相对误差小于 9×10⁻¹⁶。X 谱只剩正 Nyquist 端点产生有限格偏差。将有限格质心分别代入独立积分后，5120 和 5888 两档实际曲线的差为 0.003184 NRMS。
