# Irregular Surface #1205 的独立 FFT MTF 参考

保留原处方、配置 1、轴上视场 1、0.55 µm、原像面以及子午和弧矢方向的标量调制。两条曲线各有 300 个原坐标，频率范围均为 0–50 cycles/mm。冻结原生 MTF 欠采样，历史 Incomparable 判定保留。

独立追迹沿用原生逐面光线和 #1202 波前约束的实际处方。按像面切向的有符号边缘方向余弦差求得横纵 Fourier F 数 2.66942537、2.54302007。每个频率直接积分两片平移圆瞳交叠域内的复振幅相关，以全瞳零频功率归一化。对子午曲线由 192×224 增至 224×256，对弧矢曲线由 112×160 增至 192×224，所有频率上的独立复相关结果分别达到 2.44×10⁻¹² 和 3.22×10⁻¹² NRMS。 [处方、实际通光域与原生波前](../irregular-fft-psf-reference/README.md)

两条完整曲线均通过原 NRMS 0.01 门槛。子午最大差位于 50/299 cycles/mm，该点超出原逐点门槛。Workbench 流式 2816→4096 的两档都通过相位检查，档间 NRMS 为 0.00281986。显式相对精度 0.003 返回原 600 个点。默认相对精度 0.001 的自收敛仍报告不可用。 [逐频点与比较指标](verification.json) [正式入口原始数据](../streamed-physical-fourier-windows/README.md)

在该低频点，连续积分的子午调制为 0.829138235。将独立相关函数取样于相同的 4096 档相关节点，并重放自然三次样条，得到 0.827315460，接近 Workbench 的 0.827230965。用名义参考球直接积分仍得到 0.829148837。 [低频重采样对照](verification.json)
