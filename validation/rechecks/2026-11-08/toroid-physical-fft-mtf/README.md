# Toroid #1367 原频率标量 FFT MTF

原请求为 Toroid 配置 1、轴上视场 1、波长 0.5 µm 的调制 MTF。复算保留原生子午和弧矢各 300 个频点，范围为 0–50 cycles/mm，覆盖率为 100%。原像方方向分别为 +Y 和 +X。把两个方向各自旋转到环曲面主轴，按实际边缘方向余弦计算像方傅里叶 F 数 8.587378332，两轴的截止频率约为 232.9 cycles/mm。光线锥的工作 F 数 6.072158 另行记录。 [频点、曲线与请求身份](results.json)

## 完整重叠瞳孔

由两面环曲面的解析面形、折射和光程重建波前，用原生 #1364 的参考球约束相位。参考球半径为 166.526463578 mm。完整原生波前的 3,001 个受光点与重建相位的最大差为 3.98×10⁻¹⁰ 波。 [原生相位与处方复核](../toroid-fft-phase-domain/triage.json)

每个像方频率对应归一化瞳位移 `h = 2 λ F ν`，方向沿原像方子午或弧矢。将两份圆瞳分别平移 ±h/2，在两圆的整个交集上计算 `exp(2πi[φ(p+h/2)−φ(p−h/2)])` 的面积积分。此处采用原请求无入瞳加权的单位振幅标量约定，目录玻璃吸收属于独立的振幅模型。以未位移单位圆瞳的全功率 π 归一化，MTF 取有符号 OTF 的模。利用中心反演积分互为共轭的两半重叠区域，并用两圆交点分割边界。保存逐频点重叠面积，与理想圆瞳重叠面积公式核对。零频 MTF 为 1。

独立主轴的符号对称性在 5,000 个分布式瞳孔点上复核。原像方方向经过 45° 旋转后，两条位移的分量绝对值相同。两条曲线分别计算并保留原顺序。强轴二次相位在各角度小段中分离为线性载波，解析计算其 Legendre 矩，弱轴和余相由 Gauss 节点积分。复算保存两档全频积分、两种剩余相位多项式阶次的交叉控制，以及 15 个分布式原频率的普通 Gauss 积分。该组直接从处方追迹得到两侧相位并独立绕开分段载波和相位拟合。 [复算脚本](Reference-ToroidMtf.py)

| 验证 | 最大绝对差 |
| --- | ---: |
| 两档全域积分的有符号 OTF | 9.66×10⁻¹⁶ |
| 直接光线相位与普通 Gauss 对最高分段档的有符号 OTF | 9.49×10⁻¹³ |
| 八阶与十阶剩余相位的有符号 OTF | 3.69×10⁻¹³ |
| 数值与解析圆瞳重叠面积 | 1.33×10⁻¹⁵ |

两档 MTF 在原比较的绝对 0.001、相对 0.001、NRMSE 0.01 阈值内。原比较的峰值归一化 NRMSE 为 2.54×10⁻¹⁶，两档非零频点的相对 L2 残差为 4.68×10⁻¹³。两条方向曲线相同，50 cycles/mm 的调制度为 2.9053×10⁻⁷。结果中的积分 `nrmse` 字段是相对 L2 残差。

## 近焦适用性

主轴边缘光线在原像面距主光线约 19.999314 mm 和 0.561890 mm，分别相当于 39,998.6 和 1,123.8 个波长。现有流式 FFT MTF 的 6144 档仍存在 1.10033 波的相邻受光节点相位差。原生 64、256 和 512 档均发出取样过低诊断，原生 MTF 仅提供频点和方向身份。封包状态为 `ConditionalNearFocusFftOperatorOnly`，对应原设置下标量傅里叶算子的数学参考。商业软件同合同精度与实际像面传播仍需各自有效证据。 [相位采样与近焦依据](../toroid-fft-phase-domain/README.md) [原生复采诊断与原比较阈值](../../2026-11-07/residual-reference-followup/fft-mtf-results.json)

用 Python 3、NumPy 和 SciPy 运行 `python Reference-ToroidMtf.py <仓库目录> <输出目录>`。设置 `OPENBLAS_NUM_THREADS=1` 和 `OMP_NUM_THREADS=1` 可复算单线程结果。
