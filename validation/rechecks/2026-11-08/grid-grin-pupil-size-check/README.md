# Grid GRIN 包围能量的瞳孔密度对照

#502 保持同一 GRIN 步长 0.001 mm、配置、视场、波长、像面、标量线性 FFT 及无拉伸完整周期读出。新原生采集使用 256 档瞳孔和 512×512 完整像面，已有对照为 512 档瞳孔和 1024×1024 完整像面。对两次完整周期分别计算质心和总能量，再以原 5 µm 半径积分。角向和径向加密的最大绝对差均小于 8.35×10⁻¹¹。 [原始采集与读出核对](results.json) [既有完整周期参考](../../2026-11-06/grid-grin-bounded-fft-reference/README.md)

256 档在原 0–5 µm 的实际曲线对 512 档的 NRMSE 为 **0.158778**，最大绝对差为 **0.000138936**。各自完整周期内的 5 µm 实际能量为 0.000536936 和 0.000398000。周期边界四行、四列的功率和占比分别为 4.059% 和 0.01364%，质心亦有明显差异。现有独立复验仍需在至少 512 档的完整周期内检验更细 GRIN 积分步长。 [两档完整半径曲线](curves.csv)
