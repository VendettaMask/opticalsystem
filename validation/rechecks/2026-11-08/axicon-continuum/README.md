## 产品入口

惠更斯 PSF、PSF 截线和通焦 MTF 设置新增可选的「校验轴对称瞳孔积分」，默认关闭。开启后，轴上同轴圆瞳的单波长标量平面传播保持原像面网格，逐次细化径向分段，用不同分段数及 8/12 阶 Gauss 规则复核。相邻相位超过半个周期时先继续加密。两档都检查参考振幅和以实际峰值计的像面强度差。该结果标记为已测得采样稳定。偏轴、偏心、散射、偏振、复色、裁光、球面传播及超出积分预算时返回不可用。

直接导入产品菜单中的 Axicon 处方，以原 32 档作为细化起点。在 32×32 像面、0.25 µm 像素间距下，正式入口用 65,536 和 98,316 个径向节点通过校验。截线最大绝对差为 **1.35×10⁻¹⁶**，约为原生连续峰值的 **2.78×10⁻⁷**。通焦 MTF 两个方向的最大差均为 **7.15×10⁻⁸**。固定模式下，同样的三项 32 档结果与上轮程序集逐字节相同。 [正式入口结果与采样诊断](product-results.json) [原阈值对照](verification.json) [固定模式回执](fixed-replay.json)

### #945 标量 FFT 连续模型诊断

用同一批原生光线重建以轴上主光线为中心的实参考球相位。令 \(s\) 为已记录的平面程函，\(b=|x_\mathrm{img}|\,n_z\) 为光线到参考球中心的垂距，\(R\) 为球半径。传播回球面时带符号的像点方向投影抵消，按原生波前符号约定得到 \(-[s+b^2/(R+\sqrt{R^2-b^2})]/\lambda\) 加一个共同活塞。#939 原生一阶报告的出瞳位置为 −463.1391 mm。用 #944 波前的 106 个不同入瞳半径拟合，得到 463.139067 mm 的参考球。留出的 211 个半径、1,980 个网格点最大波前残差为 1.19×10⁻⁷ 波。

#939 给出的工作 F 数为 2.01463，原生边缘光线方向正弦独立给出 2.01462993。按当前标量 FFT 的像面尺度，以 \(\pi \rho r/(\lambda F_\mathrm{working})\) 为零阶 Bessel 核的参数，按均匀单位圆入瞳权重对复参考球场积分。此处 \(r\) 为归一化入瞳半径，\(\rho\) 为像面半径。两档共 229,364 条实追迹光线分别提供独立的 98,292 与 131,072 节点求积，覆盖 128×128 的原 0.25 µm 网格。Bessel 核用 128 个角向节点另行核对，最大差小于 10⁻¹⁵。

两档的全图强度最大绝对差约 2.44×10⁻¹⁷，按参考峰值归一化的 RMS 约 2.62×10⁻⁹，全图相对 L2 约 1.00×10⁻⁷。窗口中心和峰值约为理想峰值的 6.91×10⁻¹⁰。实测相位沿入瞳半径单调变化，斜率约 11,695–12,110 波。固定 0.25 µm 像面采样时，现有笛卡尔 FFT 还需约 107,000 的名义档位才能满足局部 0.5 波保护估计。

上述重建给出标量近焦 FFT 算子的连续极限。原生 #945 文本报告欠采样，API 网格带相同诊断。实际横向像差与出瞳映射仍超出近焦 FFT 的通常可靠条件，当前产品也没有输出该条件模型的正式入口。此项继续开放。 [原轴数值及身份](fft-945-radial-model.json) [重建程序](Probe-Fft945.py)

### 四项原 FFT 的适用性核对

OpticStudio 文档把横向像差达数百波长视为可能失准的范围，具体界限依光路而定。FFT MTF 另要求出瞳在方向余弦空间大致均匀。FFT 截线直接取 FFT PSF，关闭 Huygens 的衍射包围能量沿用相同 PSF 条件。原轴锥透射光线距主光线的像面交点为 76,904–87,431 个波长，远超这个近焦量级。 [FFT PSF](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/FFT_PSF.html) [FFT MTF](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/FFT_MTF.html) [FFT 截线](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v252/en/OpticStudio_User_Guide/OpticStudio_Help/topics/FFT_Cross_Section.html) [衍射包围能量](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Diffraction_enclosed_energy.html)

同批光线的出瞳球面相位与像面平面相位扣除共同活塞后，面积加权 RMS 差为 234.95 波，峰谷差为 785.61 波。实测横向方向余弦相对线性归一化入瞳映射的加权 RMS 差为 0.03611，最大差为 0.09095。半瞳位置的实际值为 0.16800，线性值为 0.12409。16 µm 像高处，这个映射差最高相当于 2.646 波的傅里叶核相位差。

各算子均用相同原生光线的 98,292 与 131,072 节点独立求积。原 128² 网格上的档间相对 L2 差为 FFT 1.00×10⁻⁷、Huygens 2.26×10⁻⁷。Huygens 直接积分重现既有 #950 中央截线，最大绝对差为 2.06×10⁻²³。两种算子均以同一个理想强度归一化，原中心值分别为 6.90922×10⁻¹⁰ 和 4.83093×10⁻¹⁰。在原 128²、共同 32² 和共同中央 32 点 X 截线上，两算子相对 L2 差分别为 0.43017、0.43018 和 0.43021。用同一理想强度标度，5 µm 圆内辐照度积分分别为 2.52408×10⁻⁹ 和 1.76490×10⁻⁹ µm²。这一组是像面信号积分，和各自的全像面能量占比属于不同量。

原 #945 API 返回带欠采样诊断的空网格描述，`nx=ny=0` 且没有数值。#947 返回带同一诊断的 300 点双列曲线，#949 返回空数据缓冲，#952 报告欠采样且无数值数组。算子之间的相对差异在各自独立加密后仍存在。四项原冻结状态按原比较合同保留。 [原设置、诊断与算子差异](fft-huygens-applicability.json) [共同像面网格](fft-huygens-operator-grids.npz) [复算程序](Compare-FftHuygens.py) [精确原生返回与近焦诊断设计](FFT-NEAR-FOCUS-DESIGN.md)

### #949 与 #952 的条件 FFT 数值

保持 #949 的原 32 档请求、中央 X 线性截线与自动范围。按实测工作 F 数 2.01462992668 重建 ±16.620696895 µm 的 201 个坐标，并在这些坐标直接计算零阶 Hankel 变换。辐照度按相同圆瞳的理想峰值归一化，两档原生光线求积的 NRMSE 为 5.92×10⁻⁹、最大绝对差为 2.47×10⁻¹⁷。中心辐照度为 6.90922×10⁻¹⁰，与 #945 独立图的中心吻合。

保持 #952 的原 401 个半径，范围 0–5 µm、步长 0.0125 µm。旋转对称使每个居中有限圆内的质心严格为零。以 `k = π/(λF)` 记 Fourier 尺度。辐照度以理想峰值归一化后，Hankel Parseval 给出实际与理想的共同全像面积分 `4π/k² = 1.563241441117 µm²`。逐环 Gauss 积分采用两档原生瞳孔及各环 6、10 节点。实际完整曲线档间 NRMSE 为 3.54×10⁻⁸，最大绝对差 1.31×10⁻¹⁶。理想曲线与解析式 `1 − J₀(kR)² − J₁(kR)²` 的最大差为 5.55×10⁻¹⁶。5 µm 处实际与理想能量占比分别为 1.61464485×10⁻⁹ 和 0.9534856714。 [完整坐标与曲线](fft-949-952-axes.npz) [数值回执](fft-949-952-continuum.json) [复算脚本](Probe-FftProfiles.py)

### #947 的条件 FFT 调制度

从带诊断的原生报告读取 0–50 cycles/mm 的 300 个频率坐标，在同一坐标计算归一化瞳孔自相关。两个方向由旋转对称性严格重合。把两单位圆重叠区写成椭圆坐标，半位移为 `a`，两瞳孔径向位置为 `r± = a(cosh h ± cos θ)`。原波前中占主导的径向线性相位在相减后成为仅依赖角度的载波。用分段解析 Legendre 矩计算其积分，余相和重叠区 Jacobian 直接在原坐标计算。用两套不同的原生光线拟合小余相，每套留出超过 22.3 万节点，最大留出误差分别为 9.85×10⁻¹⁰ 和 6.24×10⁻¹⁰ 波。

两套全频分段规则的调制度最大绝对差为 4.57×10⁻¹²，相对 L2 差为 1.38×10⁻¹¹。另用两套直接积分检验 19 个原频点，最高档在 18 个非零点的有符号 OTF 与分段积分最大差为 5.75×10⁻¹⁵。全轴理想几何归一化与解析圆重叠面积的最大差为 1.61×10⁻¹³。50 cycles/mm 处实际调制度为 0.000495233817，理想圆重叠对照为 0.9294956745。 [原频率坐标与 OTF](fft-947-mtf.npz) [数值回执](fft-947-mtf-continuum.json) [分段与直接积分程序](Probe-FftMtf.py)

## 重放

在临时运行目录执行 `dotnet run --project <RadialProbe.csproj> -- <原 029-axicon-model-c1.json> 2048x8 4096x8 8192x8 8191x12 16384x8`。项目引用已编译的 Core，可用 `-p:CoreAssembly=<绝对路径>` 选择同一程序集。执行相同程序的 `--nodes native-nodes.csv` 模式生成两档原生输入。

需要原生重采时，用系统 .NET Framework x64 C# 编译器将 `NativeAxiconMeridian.cs` 编为独立程序，引用安装目录的 `ZOSAPI.dll`、`ZOSAPI_Interfaces.dll` 和 `ZOSAPI_NetHelper.dll`。启用 Framework 4.8 的旧运行时绑定策略，使用隔离的进程临时目录。依次传入安装目录、原 ZMX 的隔离副本、节点 CSV 和输出 GZip 路径。采集器校验源文件哈希和版本，遇到失败或渐晕会中止。原生数据已保留在本机，重放可直接使用原文件，无须再次调用 OpticStudio。 [身份与本机载荷路径](identity.json)

使用 `<原 snapshot> --native <native-ray-phase.bin.gz>` 生成原生重建。随后将两份结果和仓库比较设置传给 [Compare-Results.ps1](Compare-Results.ps1)，脚本按 101 个通焦坐标计算原门槛。证据中的原生载荷是 little-endian GZip，依次保存 Int32 条数和每节点六个 Float64 值，分别为归一化半径、面积权重、中心光程、横向折射率方向余弦的模、轴向折射率方向余弦和像面交点半径。

使用 `python Compare-FftHuygens.py <native-ray-phase.bin.gz> fft-945-radial-model.json <full-v1> <输出目录>` 复算适用性证据。`<full-v1>` 指原冻结原生语料根目录，`native-results.json` 与 `fft-945-radial-model.json` 同目录。脚本校验原生光线哈希、原轴、既有 Huygens 截线和原生返回诊断。设置 `OPENBLAS_NUM_THREADS=1` 与 `OMP_NUM_THREADS=1` 后已重放，原始网格的 SHA-256 一致。

使用 `python Probe-FftProfiles.py <native-ray-phase.bin.gz> <full-v1> <输出目录>` 复算 #949 和 #952，使用相同参数执行 `Probe-FftMtf.py` 复算 #947。两程序使用 NumPy 和 SciPy，单线程设置与适用性重放相同。
