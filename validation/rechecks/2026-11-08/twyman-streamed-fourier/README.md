# Twyman Green Interferometer 的分批傅里叶复验

## #2157 FFT PSF

原配置、轴上视场、0.55 µm 波长、标量照明及 128×128、0.25 µm 的物理像面窗口保持一致。现有原生 256→512 比较的 NRMSE 为 0.00421656，通过本项 0.01 门槛。原生 512 参考覆盖全部 16,384 个坐标。 [原生设置和载荷哈希](../diffraction-refinement/manifest.json)

分批计算以相同网格完整追迹物理瞳孔。连续三行供原四邻点插值和相位保护使用，后续只保存要求的横向 DFT 列。混合基分解计算原逻辑 DFT 的指定频点，保留同瞳孔的无像差峰值归一化。单批最多 32,768 个候选瞳孔节点，Ray 工作量、Fourier 蝶形次数和数组都受预算约束。普通 256 档的共同图在稠密与分批实现间最大绝对差为 1.46×10⁻¹³。 [诊断程序](StreamedProbe.cs)

| 比较档位 | 实际透射节点 | 最大相邻相位差（波） | 对原生 512 的 NRMSE |
| --- | ---: | ---: | ---: |
| 6144 | 19,620,955 | 0.50289009 | 0.000913639 |
| 6656 | 23,027,401 | 0.46473075 | 0.000913745 |
| 8192 | 34,881,683 | 0.37784327 | 0.000914755 |

6656 和 8192 的完整窗口最大差为 4.76×10⁻⁷，NRMSE 为 4.03×10⁻⁶。两档均通过 0.5 波相位保护。6144 档虽然跨软件误差已低于原结果容差，仍记录为欠采样。8192 档的横向中间数组为 8192×128 个复数，占 16 MiB。光线追迹占该诊断的主要耗时。 [原比较门槛和逐档结果](window-comparisons.json) [度量脚本](Compare-Window.ps1) [原始图网格及哈希](window-numeric.zip) [清单](manifest.json)

产品的 FFT PSF 设置可选「自适应精度」并将「验证/自适应采样上限」设为 8192。仅适用于单波长、非偏振、线性强度、固定有限像元间距且窗口每边不超过 128 的有焦 FFT PSF，要求无需瞄准且完整边缘光锥可求。候选由实际相位步长规划，两档都需通过相位保护及同一物理窗口的收敛校验。固定采样及验证原采样沿用原路由。 [正式入口诊断程序](FormalProbe.cs)

正式 WorkbenchRuntime 以原 64 档开始，选出 6656 和 8192 两档通过相位保护，累计追迹 57,909,084 个分批瞳孔节点。完整图的档间相对 RMS 为 **0.000272721**，满足显式 0.001 精度。返回图与收敛原生 512 档相比，最大绝对差为 0.000375495，NRMSE 为 **0.000914755**，16,384 个共同坐标全部覆盖并通过原门槛。返回图与同档分批诊断的最大绝对差为 8.15×10⁻¹⁵。此次正式后台计算耗时约 14.8 分钟。 [正式回执](formal-receipt.json) [逐项度量](window-comparisons.json)

20 项定向回归通过，覆盖同档稠密与分批等价、射线预算、无界面设置控件及既有自适应 Fourier 校验。 [测试回执](focused-tests.trx)

## #2159 FFT MTF

补采 1024 和 2048 档，保持原配置、视场、波长、瞳孔余弦三次方权重、标量调制度和 0–50 cycles/mm。子午、弧矢各 300 个频率坐标全部一致。最大调制度差分别为 0.00539452 和 0.00344591，NRMSE 分别为 0.000711487 和 0.000515819，均通过原 0.01 门槛。数据、设置和批次回执按 SHA-256 保存，模型及诊断引用已保留的相同载荷。 [归档及去重索引](native-mtf-payloads.json) [原生身份和阈值](native-mtf-receipt.json) [复算脚本](Compare-NativeMtf.ps1)

以 MTF 的原单位圆瞳格逐行检查相位，512、1024、2048 档的全瞳最大相邻步长分别为 4.52130、2.36486、1.21030 波。4096 档在 1,383 个节点后已测得至少 0.61204 波，提前判定欠采样。5120 档完成 20,572,545 个节点，最大 0.490905 波，通过局部相位保护。 [相位测量](mtf-phase-results.json) [逐行相位诊断](MtfPhaseProbe.cs)

MTF 面板可选「自适应精度」和 6144 上限。分批路径适用于无需瞄准、单视场、单波长、有完整边缘光锥的有焦标量调制度计算，最大频率须明确且位于两轴瞳孔截止内。固定采样和验证原采样继续走原路由。 [正式入口诊断程序](MtfFormalProbe.cs)

分批计算保留 MTF 的实际透射振幅和整个二维瞳孔的轴向自相关。横向逐行累加一维 Fourier 功率。纵向保留 256 行主体和前方 L 行重叠，每列计算主体加重叠的线性自相关，再减去重叠部分的自相关。这样每对节点只计入包含其较晚节点的块。两个方向各自用零位移归一化，并沿用原方向 F 数、物理频率轴及复 OTF 插值。L 在所需最大位移之外保留 32 个样条节点，或延伸至真实末端节点。均匀节点的自然三次样条边界扰动每跨一个节点按 \(2-\sqrt{3}\) 衰减。归一化 OTF 分量的绝对值至多为 1，在节点单位下，完整样条的二阶导数绝对值至多为 12。32 个保护节点使尾端边界影响低于双精度舍入。

对同一 128×128 Twyman Green 瞳孔，以 L=31 和 B=13、24、47 检查纵向前 32 个复 OTF 位移，与现有稠密自相关的最大差为 4.17×10⁻¹⁶。实际 512 档定向测试涵盖两个方向和跨块节点，复 OTF 差均在 10⁻¹² 内。其余定向测试覆盖射线预算、截止频率、PSF 同档等价和两个面板的显式自适应设置，4 项全部通过。 [同档控制程序](MtfHaloControl.cs) [同档控制结果](mtf-halo-control.json) [测试回执](mtf-focused-tests.trx)

正式 WorkbenchRuntime 从原 64 档开始，对选出的 5376 与 6144 两档实施全瞳检查。最大相邻相位差分别为 0.46777895 和 0.40987614 波，两档共追迹 52,310,178 个实际节点。两条完整曲线的档间相对 RMS 为 **0.0000683507**，通过显式 0.001 门槛，最大调制度差为 0.000828311。6144 档占 3,281,920 个预算数组单元，约 22.15 亿个 FFT 蝶形。此次正式后台复验耗时约 6.7 分钟。

返回曲线与已独立收敛的 OpticStudio 2048 比较，0–50 cycles/mm 上子午、弧矢各 300 个原频率坐标全部覆盖。NRMSE 分别为 **0.000238653** 和 **0.000722876**，均通过原 0.01 门槛。两个方向的最大调制度差分别为 0.00270907 和 0.00839873，逐点门槛未通过。 [正式回执](mtf-formal-receipt.json) [原始曲线](window-numeric.zip) [复算脚本](Compare-NativeMtf.ps1)

## #2161 中央 FFT X 截线

用独立几何追迹求原 16 面折叠光路，逐面处理有限物点发射、圆锥与偶次非球面、斜平板的带符号传播和两次实际反射。与 #2154 原生两条光线扇的 82 个点比较，最大差为 6.26×10⁻¹¹ µm。拟合得到 1.16904205 mm 的虚参考球和 1.00012946 的子午瞳孔投影。#2156 原生波前 1,998 个留出点的最大残差为 2.97×10⁻¹⁰ 波。实际边缘方向给出子午、弧矢工作 F 数 1.11754476 和 1.11743379，符合 #2151 一阶报告的合并工作 F 数 1.117489。

以原 32 档瞳孔和自动绘图范围直接计算 ±9.21882878944 µm 的 201 个中央 X 坐标。按原余弦三次方入射权重，用 768² 和 1024² 两套交叉方向的 Gauss 圆瞳求积，整条曲线按峰值归一化的 RMS 差为 4.36×10⁻¹¹。中心和峰值约为理想峰值的 0.000637252 和 0.000753807。相同独立模型与 #2157 已收敛原生 512 的完整 128×128 图比较，NRMSE 为 0.000915704。 [独立截线与对照](2161-independent-receipt.json) [折叠追迹及求积程序](Probe-TwymanAxis.py)

首轮正式自适应 4096 上限在紧凑 3072 档测得最大相邻差 0.813127 波，超出 0.5 波保护。正式 WorkbenchRuntime 采用原 32 档、中心 X 线性截线和自动范围，显式选择 6144 上限和 0.001 精度。4608 档预检测得 0.544796 波，随后 5376 和 6144 档分别降至 0.467779 和 0.409876 波。两档截线相对 RMS 变化为 0.000107812，最大绝对变化为 3.48949×10⁻⁷。累计 22,366,208 个名义瞳孔单元和 68,972,367 个流式瞳孔节点，低于 1 亿总预算。
