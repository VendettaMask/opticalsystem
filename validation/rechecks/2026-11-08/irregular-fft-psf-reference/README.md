# Irregular Surface #1203 的独立 FFT PSF 参考

原处方、配置 1、轴上视场 1、0.55 µm 波长、原像面和标量线性辐照度。按原分析读出 128×128 个像元，间距 0.25 µm，X、Y 轴各为 −15.75 至 +16.00 µm。冻结原生 FFT 没有有效网格，历史 Incomparable 判定保留。 [原生采样复查](../../2026-11-07/incomparable-coverage/by-request.csv)

独立求解圆锥前表面和带倾斜、偏心及不规则矢高的后表面，按 BK7 的 Sellmeier 折射率计算逐段光程。整个入瞳的半径为 20 mm，玻璃内光线在两面间向轴收缩，完整覆盖于两面的 24 mm 口径内。玻璃内入射角上界 30.67°，低于 41.19° 的全反射临界角。冻结的原生 #1198 实光线在三面上的截点最大差为 4.56×10⁻¹¹ mm，方向余弦最大差为 3.99×10⁻¹¹。 [存档成员和哈希](verification.json)

由原生 #1202 波前中心和负 Y 边缘的相对 OPD 反解参考球半径 112.493821220 mm。正 Y 边缘独立给出 112.493821222 mm。按方向 F 数将原投影网格还原为实际入瞳坐标后，2,869 个原生有效节点逐点重建，OPD 最大差为 2.41×10⁻¹⁰ 波。作为对照，名义近轴球半径 112.443649400 mm 会产生 0.00958 波最大差，在这块 FFT 窗口中只造成 5.05×10⁻⁵ 的 NRMS 变化。 [独立折射、参考球与积分脚本](IrregularReference.py)

对完整入瞳进行带相位的 Fourier 积分，使用原 FFT 的线性像方尺度，以同一理想瞳孔的轴上峰值归一化。径向及方位采样由 768×1536 增至 1024×2048，完整窗口 NRMS 变化为 7.89×10⁻¹¹。Workbench 的 8192 档对独立参考的 NRMS 为 **0.000667464**，最大绝对差为 1.02×10⁻⁷，覆盖全部 16,384 个像元。原 NRMS ≤0.01 和逐点误差门槛均通过。 [逐项数值](verification.json)

Workbench 正式入口从原 64 档启用 Adaptive，保留物理设置并声明 8192 的上限。7168 和 8192 均通过局部相位检查，档间 NRMS 为 0.00207909。声明相对精度 0.003 时返回完整图像。默认相对精度 0.001 和绝对精度 10⁻⁷ 下的自收敛仍报告不可用。两次产品回放和原比较门槛分别记录。 [Workbench 原始请求、逐点输出和默认对照](workbench-evidence.zip)

使用 Python 3.11、NumPy 与 SciPy 运行 `python IrregularReference.py <仓库目录> <输出路径>`。脚本直接验证并读取冻结原生数据与 Workbench 存档。
