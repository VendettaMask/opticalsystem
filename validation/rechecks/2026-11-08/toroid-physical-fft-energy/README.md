# Toroid #1372 原半径标量 FFT 圈入能量

保留配置 1、轴上视场 1、波长 0.5 µm、质心参考和衍射极限。冻结原生 32 档报告取样过低，两个原半径序列来自冻结 Workbench 载荷，两条曲线的 401 个横坐标逐值相同，范围 0–5 µm。该载荷仅用于还原原横坐标。 [原请求、原半径和结果](results.json)

通过实际边缘光线与主光线的锥角确定原圈入能量的两个像方尺度，F 数均为 6.072158259，衍射尺度 λF 为 3.036079130 µm。两轴尺度相等，原像面的 45° 坐标旋转保持积分圆不变。圆瞳相位在两条环曲面主轴各自的反射下对称，故实际与理想的强度质心均在原点，以对称扩张的全像面极限定义。相位由处方追迹，并以原生 #1364 的 3,001 个受光节点约束。复算使用单位振幅标量瞳孔。 [原生相位和坐标](../toroid-fft-phase-domain/triage.json)

实际复场按瞳面积 π 归一化。归一化瞳坐标横跨直径 2，像面核为 `exp(iπ p·q/(λF))`，对应 Parseval 全像面功率 `(2λF)²/π = 11.73643753 µm²`。此尺度由 FFT 物理周期 `λF(N−2)` 和归一化瞳步距 `2/(N−2)` 共同确定。在每个原半径上积分该复场的模方，再除以这一全像面功率。理想圆瞳用相同分母，并与解析 Airy 圈入公式 `1−J₀(q)²−J₁(q)²` 逐点核对。两档分段载波积分与独立加密的普通 Gauss 积分都包含完整瞳孔，分别使用 16、24 和 30 阶的像面插值，以及逐档加密的圆域节点。 [复算脚本](Reference-ToroidEnergy.py)
