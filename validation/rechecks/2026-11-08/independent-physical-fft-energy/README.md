# 两条 FFT 衍射包围能量的独立物理参考

#1122 Doubly telecentric system 与 #2438 Schmidt-Cassegrain spider obscuration 均保留原处方、配置 1、轴上视场、原波长、原像面、标量 FFT、质心参考和 0–5 µm 半径。衍射极限与实际能量两条曲线各比较 401 个原半径节点，覆盖率为 100%。原始 32 档返回低采样诊断，两条冻结记录仍为 Incomparable。 [原请求、物理参考和逐项误差](results.json)

从两份原处方独立追迹轴上边缘光线，按出射方向余弦计算 F 数，#1122 为 5.12404583585，#2438 为 6.03928787137。各处方另用既有原生光线 #1110 与 #2426 验证归一化瞳坐标 0.8 的像面交点和方向余弦。交点差小于 10⁻⁸ mm，方向余弦差小于 10⁻¹⁰。使用同配置、视场、波长和瞄准设置的原生出瞳波前 #1114、#2430，分别复现完整 64×64 节点的圆瞳掩码与带三臂遮挡的环形掩码。径向相位在 3,001 和 2,282 个有效瞳点上的最大残差分别为 4.34×10⁻¹⁰ 和 4.55×10⁻⁹ 波。 [独立计算](reference.py)

以贝塞尔核积分完整透射瞳孔，按 Parseval 关系使用全像面总能量归一化。#1122 的理想圆瞳能量用解析式核对。#2438 根据修正镜后的实际径向映射计算 4.5 英寸中心遮挡及旋转 30° 的三根 2 英寸蜘蛛臂。对其瞳孔透射的角傅里叶系数逐阶积分，再按角向正交性累加圆内能量。求积加密和另一套相位拟合所得曲线均通过既有门槛。
