# Toroid 三条 FFT 原请求的相位采样

按原处方计算两面环曲面折射及 ±45° 坐标断点。配置 1、轴上视场 1 和波长 0.5 µm 下，四条原边缘光线都给出正有限数值孔径，工作 F 数为 6.072158。环曲面旋转方向的曲率较低，该方向在原像面明显离焦，在全瞳中产生强烈相位变化。

从冻结原生 #1364 波前的主光线和负 Y 边缘反解参考球半径 166.526463578 mm。负 X 边缘独立给出同一半径。重建相位与 3,001 个原生有效波前节点的最大差为 3.98×10⁻¹⁰ 波。 [原始请求、坐标、原生载荷身份与相位差](triage.json)

使用 Python 3 和 NumPy 运行 `python ToroidTriage.py <仓库目录> <输出路径>` 复算。脚本直接读取原处方和冻结的 OpticStudio 证据。 [复算脚本](ToroidTriage.py)

## 原像面网格的分段求积

在环曲面主轴坐标中，波前关于两个轴分别为偶函数，400 个非轴向点的符号对称差不超过 1.15×10⁻¹⁰ 波。沿强相位变化方向的边缘相位为 −2,410.58 波。把单位圆瞳的第一象限写为 `u = sin θ`、`v = t cos θ`，面积权重为 `cos² θ`。将 `−2410.58 sin² θ` 在每段中心展开至线性项。线性载波的 Legendre 矩用球贝塞尔函数解析积分，余相与精确像面傅里叶核用 Gauss 节点计算。288 段时，每段载波的二阶余项上界为 0.01793 波。此上界仅约束解析分离的载波，实际总误差另由独立加密和全网格直接积分测量。

将原像面频率旋转 45° 到主轴后直接取值。#1365 取原 128×128、0.25 µm 像元的 −15.75 至 16 µm 网格。#1369 取中央 X 截线的 201 个自动坐标，按原 32 档、0.5 µm 波长和实测工作 F 数计算为约 ±45.54118694 µm。所有值相对同一理想圆瞳峰值归一化。两种积分都直接在这些坐标求值。 [坐标、复场与独立档](toroid-original-windows.npz)

| 同坐标检验 | #1365 全 16,384 点 | #1369 全 201 点 |
| --- | ---: | ---: |
| 最后两档分段积分辐照度 NRMSE | 3.73×10⁻¹⁰ | 4.44×10⁻¹⁰ |
| 最高档分段与直接积分辐照度 NRMSE | 3.07×10⁻¹⁰ | 3.36×10⁻¹⁰ |
| 最高档分段与直接积分最大绝对辐照度差 | 5.50×10⁻¹⁶ | 4.06×10⁻¹⁶ |

最高分段档为 288 段、外层每段 18 点、内层 288 点，计算 1,492,992 个瞳孔相位。全网格直接积分采用 1,024 段、每段 26 点、内层 288 点，完整保留原相位，独立绕开载波变换。另用第二个直接积分档交叉检查所有 201 个截线坐标与 15 个分布式像面频率组合。两个原窗口共同的中心辐照度为 1.75433417×10⁻⁷。 [误差、档位和原生载荷身份](toroid-segmented-window.json)

## 近焦适用性

两条主轴的边缘光线在原像面分别偏离主光线 19.999314 mm 和 0.561890 mm，相当于 39,998.6 和 1,123.8 个波长。OpticStudio 将横向像差达数百波长视为可能失准的量级，并说明截线继承 FFT PSF 的近焦条件。原生 #1365 报告欠采样且网格没有数值，#1369 返回空曲线缓冲。上面的数值是原坐标上标量 FFT 算子的条件参考。两项原冻结状态保留。 [FFT PSF](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/FFT_PSF.html) [FFT 截线](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v252/en/OpticStudio_User_Guide/OpticStudio_Help/topics/FFT_Cross_Section.html)

用 Python 3、NumPy 与 SciPy 执行 `python Probe-ToroidWindow.py <仓库目录> <输出目录>` 重放。设置 `OPENBLAS_NUM_THREADS=1` 与 `OMP_NUM_THREADS=1` 可复现单线程运行。 [分段与直接积分程序](Probe-ToroidWindow.py)
