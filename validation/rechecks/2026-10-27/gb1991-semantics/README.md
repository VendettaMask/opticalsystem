# 光学零件图标注核对与修正（2026-10-27）

已逐项核对学校公开教材中光学零件图的相关章节，并修正现有老国标透镜出图路径中的半径、粗糙度、材料等级表达、孔径及非球面说明。统一入口、共用编辑器和参数保持，ISO图纸布局保持。

[完整逐项清单](../../../../docs/LEGACY_GB1991_OPTICAL_PARTS_REVIEW.md)列出每项依据、实现及边界，覆盖教材纸本第41–59页（PDF49–67页）中光学零件图的定义、技术要求、对照和示例；配合1991原标准第3章、4.2/4.3条、表2/表3及附录A2–A4查阅。没有把全书的加工岗位和实物检验全部变成软件功能。

## 实际修改

- 老国标半径引线只标名义R，平面R∞；名义半径保留12位有效数字。共用mm半径公差的控件和值保留供ISO使用，老国标改由ΔR样板等级及N/ΔN要求表达精度。ΔR检查A/B及分面面号，不接受mm公差冒充等级。
- 新增光学工作面、其余面的Ra（μm）及各自取样长度l（mm），输出基本矢量符号、数值和范围；Rq（nm）作为独立补充要求保留，不改单位后替代Ra。空项未规定，非法数值及缺Ra的取样长度拒绝生成。
- 材料等级与共用绝对数值允差分开；不从ISO代码、Vd绝对允差、nm值或玻璃牌号自动换算旧版等级。增加材料依据、检验波长、定心基准及补充技术要求，明确χ面倾角及参考边厚。隐藏的ISO专用无效值不再阻挡老国标，切回ISO仍执行原校验。
- 机械外径轮廓使用共享Core实际面型，D0单独表达共同有效区域。新增非本地化孔径尺寸快照，真实居中圆形物理孔径参与D0；特殊形状、缺少尺寸、机械范围超域或相交时拒绝错误简化或裁切标注。
- 圆锥/偶次/奇次非球面列出表达式、各面顶点原点、基底R、k及完整系数，遵循共享Core的实际幂次；Forbes Q保留完整参数并要求受控面型定义引用。没有新增产品光学计算公式。

原表右上布局、40/25/15 mm列宽、8/6 mm表头/行高继续保留。当前支持共轴旋转对称透镜及胶合透镜；未增加棱镜、自由曲面、特殊孔径零件或完整机械CAD。小倒角及膜层保留文字说明；大倒角等结构需另行受控细节图。旧版样板/材料实际等级、供应商检测及完整企业图签条款没有被宣称自动认证。

- [老国标PDF独立检查](pdf-semantic-inspection.json)：11份实际PDF均核对原表尺寸、每行线、列分隔、几何区没有半径±符号、Ra矢量符号及单位/范围；核对机械φ12/有效φ8、物理圆孔φ6等独立输入及四种非球面的定义文字。全部11页已渲染目视检查，无裁切、重叠或默认Logo栅格图像。
- 三语各捕获镜头库、ISO及老国标，共9张；六张指南图片同步，四张PNG变化、两张逐字节保持。全部54张指南资源大小及哈希已核对，最终嵌入后9/9读取检查通过。

PDF提取核验明确使用NFKC及记录中的少量既有CJK/连字符字形别名。pdfminer会对部分既有CFF字体子集报告缺FontBBox；线框尺寸检查不依赖字体包围盒，字形另行渲染审阅。Skia的MediaBox会按整数点舍入，表格几何按名义物理页面坐标核对。本轮没有修改共享PDF字体/文字代码，也不声称修复全文搜索映射。

数值均为显式测试输入：部分材料/光圈/焦距值参考原示例，Ra、波长及合成面型用于分离标注语义；它们不代表演示处方实际计算出的焦距、制造等级或实物合格结果。Q-001为明确标注的测试引用，未伪称存在外部受控图纸。
