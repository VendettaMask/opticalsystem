# F/3.34、21°失光、最大光斑与畸变门槛修复（2026-10-27）

本轮三项门槛已同时通过，仍是四片。原起点的两种子×直接/渐进四次联合修正均得到合格四片；保留10条失光终点的新鲜接续用2次更新、3次梯度消除失光，RMS47.414336µm、最大半径149.893620µm、畸变2.999853937%，STAROPT回读原完整门槛再次通过。没有得到合格三片，不把四片修复当成减片成功。

## 原因诊断

诊断对原始seed42和上一轮trial0保持同一处方/口径/光阑/像面/光谱，实际206,878追迹，未作优化；[逐光线及切向](diagnosis/diagnosis.json)保存全部99条边界/中心和训练数据。

这些都是21°外圈真实物理遮挡；积分951/960=99.0625%虽通过98%门槛，仍不能抵消99条检查中10条失败。原起点24条失光在第三/第四片，旧补偿改善总量时又在第一片引入遮挡，单纯降低平均余量损失不足以保护每条光线。

最大光斑存在明确训练定义缺口。21°旧训练4×16只取积分瞳最大半径144.172902µm，低于150µm；正式验收还包含独立外圈检查，为157.107565µm。对同一未裁剪光线、沿用积分质心合并检查后是160.207679µm。训练最大应纳入检查，而检查不能参与RMS积分或改用自己的质心。训练未裁剪与物理裁剪的质心/有效光线仍有差别，因此训练不能替代正式通光验收。

畸变不是视场或公式漏项：21°已在五个训练视场中，训练3.017791900072698%、正式3.017791900072606%一致，只有约9e-14百分点差。v3前两步接受后，后六提议均增加其他约束损失而被拒，停在当前终点。原模型只按比例放松失光，仍要求其他超限在同一信赖域一次线性恢复；有限投影未得到可用点就退回最小二乘方向，回溯也未能产生接受步。这不能解释成处方物理无解。

另有可重复的数值缺口：400轮投影会在近耦合约束上尚未收敛便返回无点，退回方向可能增大失光。新增合成约束回归给出同一盒内的明确可行联合下降步；v4有限4096轮找回该步，没有增加光学探测次数。未把投影未收敛当作不可行证明。

## 实质性修复和身份

共享Core新增可微`MaximumRadiusWithChecks`：积分和检查沿用积分质心取最大，RMS/光谱权重保持，复用已经计算的光线。自主训练显式可空`Sampling.IncludeBoundaryMaximum`切换，零新增追迹，原null布局/行为保持，指纹随新设置变化。补齐的是训练统计，独立TopologyValidator、35视场/10×32/33检查/64面型及所有正式门槛不改；AutoLens UpstreamE58/MOBILE_CONFIG不改。

显式版本4把所有正的约束缺口联合按比例恢复，保护每个原已满足或尚未满足约束不恶化，避免总损失降低掩盖个别新遮挡/新超限。线性投影仍有界，v4用4096轮并在模型中响应取消；v3的400轮、旧数学和续跑身份保持。新例默认开启v4与共质心检查最大；已载入的v3计划不自动升级，v3/v4不能混用续跑状态。

当前仍同一16个曲率/镜面位置参数、原曲率范围和原轴向±0.25mm界限，不扩大口径、缩视场、移动光阑/像面、换材料或放宽制造/光学门槛。固定接续直接使用原变量边界，没有围绕10条失光终点重新居中。
