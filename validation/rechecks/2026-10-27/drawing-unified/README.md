# 统一光学制图入口与标准选择

日期：2026-10-27。Ribbon、命令搜索和帮助只提供“光学制图”，页面内选择 ISO 10110 或老国标 GB/T 13323—1991；不恢复 2009 版。

## 已实现

- 默认 ISO；同一页面及参数控件供两种标准使用。切换保留选中的单片/胶合组件、图幅、图签、尺寸、公差和工艺参数，并自动更新预览；PDF 继续由所选标准模板输出。
- 专用纹理 Rq / 激光损伤阈值行按标准显示，隐藏不清空输入。测试将完整图纸对象除标准外作深度比较，并比较实际预览位图，确认切换回来恢复相同图纸。
- 重复打开复用当前编辑页。工作区快照及标准变化事件记录所选标准；显式恢复旧分开页面时合并，保留原活动页的标准和停靠身份。主区、隐藏、浮动布局均有保存、恢复和再次保存检查。
- 旧隐藏页点击统一入口后回到可见文档区，复用原面板。旧 2009 字符串及数值设置仍转 ISO。
- 更新三语工程图和镜头库六张指南图片；另保留三张同页切换老国标的离屏图，仅用于证据。

布局保存记录所选标准，不据此宣称新增了全部制图参数的跨会话保存；本次参数共用及保持指同一编辑页内的标准切换。
