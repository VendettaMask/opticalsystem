# 自主设计：恢复与补偿控制

2026-10-27。在已有12.14恢复修复和12.15界面账目基础上，补齐操作入口。本轮只改自主窗口、工作流、本地化及相关界面测试，继续使用纯 C# 和共享 Core；未新增光学计算、优化策略或持久化字段。

## 可操作配置

- 拆片、并片各有独立开关。仅改预算不升级旧空扩展配置，修改一项不改变另一项或未展示的插入/删除权限。
- 将后端已有的矩阵自动求导、固定光阑瞳倍率、恢复阶段轴向微调、独立锥常数、阶段验收及两种补偿预算保护映射到已有字段。只在用户主动勾选瞳恢复时联动开启自动求导，主动关闭自动求导会关闭瞳恢复；载入时保持原配置。依赖轴向微调或阶段验收的选项保留未生效偏好并解释禁用原因。独立锥常数不创建偶次面型分支。
- Local/Full 更新上限分别可设0–400。改变时仅将该阶段不足的函数/梯度尝试上限提高到更新数+1，已有更高上限保留；未编辑阶段完整保留。总函数/梯度/追迹/时间配额、学习率、采样及验收规则不变，大更新数仍可能受总配额截断。
- 保留 nullable 字段的 null 与显式 false，不自动升级旧计划或给新示例启用新的恢复/锥常数模式。
