## 先解决训练采样低估

问题来自这份短程协议的1环×8臂积分分辨率不足，不需要修改Core光学公式或放宽50µm门槛。采用已有Core Gaussian积分，对合格四片、恢复后三片、仅边界失败三片、训练低估三片共四份冻结处方，在相同五个训练视场比较六档精度。

以下误差均为**相同未裁剪训练定义**下，与10×32参考的最大RMS差，单位µm。实际物理失光和被裁剪后的RMS另存，不能与未裁剪训练值混为一谈。

| 环数×臂数 | 最大RMS差 µm | 单次目标/梯度实际追迹最大值 |
| --- | ---: | ---: |
| 1×8 | 5.312628 | 7,874 |
| 2×8 | 0.080838 | 9,278 |
| 3×12 | 0.0004023 | 12,606 |
| **4×16** | **0.000000357** | **17,246** |
| 6×24 | 约1.22e-10 | 30,614 |
| 10×32 | 参考 | 60,158 |

因此选择4×16，约2.2倍原训练追迹成本，避免每步都用约7.6倍成本的10×32。正式独立验收仍用原10×32。结果见[主校准24项](calibration/calibration.json)。

额外预先指定两份失败三片各42/101/2026的小曲率扰动。五个配对完成，4×16对10×32的最大误差约1.88e-7µm；第六个配对的密集物理诊断达到90万硬配额而截断，未作为完成通过。工具当时未捕获并记录该诊断退出，现已补充配额退出记录；没有增加额度或覆盖原部分结果。[11项部分记录](holdout/calibration.json)、[未完成说明](holdout/INCOMPLETE.json)保留。主校准实测1,091,300，补充诊断保守按90万上限计，两项合计不超过1,991,300追迹。第六个邻域的未裁剪RMS收敛另由定向回归覆盖，不能因此改写其物理诊断为完成。

方法上参考了[Ansys的Gaussian Quadrature说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v25101/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Gaussian_Quadrature.html)中逐步增加环/臂、检查结果收敛的做法，以及[NIST的Gaussian求积说明](https://dlmf.nist.gov/3.5)。Ansys也提醒实际口径裁光会改变有效瞳孔，故这里始终把训练未裁剪统计与原物理通光验收分开。没有复制外部光学实现或将商业软件默认当作本项目定义。

随后单独预先冻结原9条处方的**高精度曲率控制 vs 高精度加第二片位置补偿**两次对照，均4×16与同样总预算。新增的两个变量只是 `element-002` 前后轴向坐标，各在原值±0.25mm内，归一化尺度0.1mm；其他面轴向、光阑/像面/材料/口径/视场不动，原中心厚、边厚、气隙及所有正式门槛保持。既有Core位置参数先通过差分核对，再启动实验。厚度/间距作为补偿自由度的思路与[Ansys的厚度变量说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v25202/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Set_All_Thickness_Variable.html)一致；本案例的有限范围与结果由实际Core计算验证。
