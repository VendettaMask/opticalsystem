# 老国标原表格布局核验（2026-10-27）

本次修正 GB/T 13323—1991 单片和胶合透镜的原表格布局与字段。统一“光学制图”入口、内部标准选择及共用参数继续保留。ISO XML 未改；四张 ISO 预览与修改前逐字节一致，四份 ISO PDF 在96 dpi下渲染后逐像素一致。PDF 元数据不用于字节比较。

## 原始依据

- [原标准扫描件](https://ncstatic.clewm.net/rsrc/2022/0928/18/a8e91b473f322a6f24ebec07b5068cc5.pdf)：由[学校公开教材](https://www.zstp.edu.cn/__local/A/9D/24/BF8073E52E207CD6BDF69B01710_DEEC166A_124C5DB.pdf)第52页二维码链接获得。原文件仅本地查阅，不复制入本证据包；SHA-256见 verification.json。
- 标准印刷第5页（PDF第7页）第4.2.2条、表2：胶合件要求表在右上角。
- 印刷第5–6页（PDF第7–8页）第4.3.1条、表3：材料和零件要求表在右上角，外框粗线、其他细线。总宽40 mm，材料项目列25 mm，零件/胶合件项目列15 mm，表头8 mm、数据行6 mm。
- 附录A2–A4（PDF第11–13页）复核实际位置、栏目及末行 D₀。原表文字与尺寸已经直接目视核对。

## 实现范围

单片按表3显示7项材料、14项零件要求，胶合件按表2显示11项要求，全部原栏目按原顺序保留。A4/A3使用物理坐标，表格不随页面同比缩放。视图在左侧，材料名义值、补充nm面形/Rq、镀膜及边缘要求放下方技术要求区；保留共用矢量Logo和标题栏。

共用厚度及公差、有效口径、角分公差和数值材料公差继续使用原编辑器。旧版等级、光圈数、样板等级、疵病和焦距要求单独填写并随标准切换保留；未规定项目显示“未规定”。不从ISO代码或nm限值推定旧等级/光圈数。焦距要求是输入文本：测试中340/300等数据仅用于检验原表呈现，不是所用演示镜头的计算焦距。棱镜平行差、倒二/三面角在当前旋转对称透镜图中显示“不适用”。

单元格最多两行，过长要求明确拒绝生成；技术说明也检查区域容量。ISO专有输入在老国标中隐藏而保留，切换回ISO后共用图纸参数和预览保持。

不同通过用例合计49个，重复用例不累加。均使用默认Release输出、两个CPU、BelowNormal、单节点且关闭构建服务器。未运行全仓测试，不操作原生桌面或输入，不发布安装包。新实现位于C#/SkiaSharp/XML；外部PDF提取与图像工具仅用于本次验证。

四份实际导出的老国标PDF（A4/A3×单片/胶合）已用独立PDF工具检查实际线框、25/15 mm列分隔、每一行8/6 mm高度和标题文字，四份PDF全部渲染并目视检查。图纸及默认Logo没有栅格图像。实际MediaBox由Skia按整数点舍入，核验以名义页面尺寸定位，表格mm尺寸不受影响。PDF文字提取保留原字体行为：比较时明确使用NFKC以及“㬵→胶、⻆→角”的既有字形映射；显示已目视核对，本次未修改共享字体/PDF文字代码，不声称修复全文搜索映射。

三语各捕获镜头库、ISO图、老国标图，共9张；其中6张镜头库/ISO图已更新嵌入指南。全部54张指南图片的文件大小及哈希已核对。工作台截图状态可因标准选择控件而变化；ISO图纸本体保持的证据来自独立前后基线比较。
