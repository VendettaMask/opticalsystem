# 自主设计：执行资格与补偿续跑

2026-10-27。继续12.16后的实际执行入口核对。发现旧通光原型在引擎中已被禁止执行，界面却仍启用开始/继续。现将既有条件提取为引擎公共查询，供引擎、桌面会话和按钮共用；不改变通光/活动参数策略只支持v3/v4的规则，未使用这些策略的旧计划仍按原行为运行。旧计划/记录保持可读、可保存和复制，不自动升级；后台会话在创建运行目录/文件前拒绝不支持的任务。

本轮保持纯 C#、共享 Core。只增加执行资格查询及其应用，不修改光学计算、优化数学、预算、持久化格式或 AutoLens 损失定义。工作区另有并行任务修改 Core 分析，完整保留并在机器汇总单列。
