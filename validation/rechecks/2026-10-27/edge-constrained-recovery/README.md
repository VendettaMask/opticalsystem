# 原边厚约束下的删片恢复

2026-10-27。按用户明确要求继续12.18的真实边厚阻断，保持纯C#、共享Core，不放宽验收。原输入是前置光阑三片删到两片的轴上流程夹具，宽松像质目标不代表产品标准。本轮修复一阶恢复的约束求步，并另存严格产品验收的失败。

## 变化与冻结条件

原恢复只对A/C/瞳误差求步，正式几何只用于事后拒绝；在 `lens-3:edge:8` 边界不断缩步。新显式 `Recovery.UseGeometryConstraintTangents` 读取共享Core的同一几何行及其导数，将光学误差下降条件、制造切线、原变量界和信赖域联合求步，仍由原Core非线性几何及实测光学目标决定接受。提议的内侧余量最多1e-6，随小半径收紧，仅更保守，不加入验收容差。最终恢复容差仍1e-4，独立验收仍64点几何及正式光线。

起点、8个曲率/轴向变量、±0.25mm窗口、归一化尺度、口径、材料、机械参考、光阑、像面、恢复80函数/30接受步和原目标均冻结。未放开恢复锥常数/高阶面型。新策略必须启用自动矩阵求导；界面“沿制造约束恢复”显式开启依赖，关闭自动求导会关闭该项。旧null/false及默认示例不自动升级，旧null序列化身份保持。新增一个可空选项，检查点schema仍1；独立恢复协议为 `autonomous-paraxial-recovery-geometry-v1`。

通用投影器增加可选偏好起点，受限最小二乘增加可选试探点投影；省略时原路径保持。几何值、边厚/间隙/斜率与导数均来自Core，没有复制光学公式。工作区其他任务的Core分析改动完整保留，不归于本轮。
