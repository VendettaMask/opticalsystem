剩余数值差异以单光线报告（18 项）、光程差（12 项）、点列（10 项）和场曲与畸变（9 项）居多。较集中的镜头为 Grid GRIN（15 项）、Grid Sag（12 项）、示例光谱仪（11 项）和反射变焦（8 项）。78 项错误包括 15 项瞄准未收敛、11 项 FFT 瞳面采样不足，以及 7 项一阶参数字段类型错误。不可比的请求保留捕获无效、覆盖与有效掩码差异等原因。

Core SHA-256 为 `ef619509d9af578999561f1b65f7ffa938e89b5d9b10cd939df0fdc5697528a3`，与该批默认 Release App 一致。固定设置和显式自适应是两类独立请求。六个 FFT 截面与一个二维 FFT PSF 的[自适应复验](../fourier-physical-pupil/README.md)均通过其冻结收敛参考。全量固定设置统计使用 2026 R1 冻结数据，另 108 组固定光线缺有效参考或表面映射。见[运行身份](identity.json)和[集成验证](../tolerance-precision-integration/README.md)。
