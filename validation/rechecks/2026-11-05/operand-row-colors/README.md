# 亮模式优化行色与公差整行分类

亮模式评价函数表增大分类底色与表面的差异，使用原主题文字。公差操作数表沿用相同的整行着色、悬停与选中样式。公差类型以物理用途分组，各代码保留稳定色阶。

| 类别 | 公差代码 | 色系 |
| --- | --- | --- |
| 曲率与面形 | TRAD、TCON、TPAR | 紫 |
| 厚度 | TTHI | 赭金 |
| 偏心 | TSDX、TSDY、TEDX、TEDY | 蓝 |
| 倾斜 | TSTX、TSTY、TETX、TETY | 青 |
| 材料 | TIND、TABB | 绿 |
| 补偿 | COMP | 灰蓝 |

两表通过 `OperandRowAppearance` 绑定真实 DataGrid 模板底板，共用虚拟行的主题和编辑观察。优化红色错误优先，公差验证结果沿用既有提示。操作数启用勾选与类别色分别显示。

[原优化映射与历史预览](../../2026-11-04/operand-row-colors/README.md)记录上版色阶。

## 验证

[优化表亮模式](merit-rows-Light.png)与[公差表亮模式](tolerance-rows-Light.png)由真实 Avalonia 面板离屏渲染。优化表分类色的基础混合从 15–22.5% 提高到 34–41.5%，保留注释行的中性色。公差表 15 种操作数在亮模式下均有各自的底色。测试覆盖五种主题的实际行像素、主题往返、选中与悬停、类型编辑、滚动复用与卸载。全部启用类型和所测交互态的文字对比度至少为 4.5:1。
