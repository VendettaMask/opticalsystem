# 示例镜头 FFT 物理瞳孔加密复核

95 支菜单示例的精度矩阵中，七项 FFT 分析原先无法在声明的采样预算内确认结果收敛。这七项在实际 Workbench 自适应入口重算后均通过原有 OpticStudio 2026 R1 比较。范围是以下七项分析和对应配置，各项仍独立核算原请求的固定采样结果。

自动伸展按采样阶数的平方根增长，因而轴向截面的实际受光直径增长慢于名义瞳孔网格。自适应流程先执行原采样序列。原序列耗尽且用户请求为适用的线性标量焦面分析时，第二段采用独立的物理瞳孔网格，使用两段共用的名义瞳孔额度。每段单独比较相邻档位，并要求两档的真实瞳面相位已解析、原坐标上的全部结果与报告标量一起达标。

截面使用既有轴向傅里叶累加，采用固定的积分像面间距并在完整原物理区间上读回。二维 PSF 使用既有分离 chirp 卷积计算中心窗口，逻辑变换周期增加，保留原像元坐标和像元间距。已有源瞳、聚合分配和蝶形运算额度同时生效。证书中的 `usesDensePhysicalPupil` 标识各档位所属阶段，启用第二段时使用 `FourierPhysicalDomainConvergence/v2`。原 7 个固定请求的结果均为 `Unavailable`。

原先已通过的 835、791 两个截面重新运行后，继续由第一段相邻档位确认收敛，分别返回 1024、4096。835 重新与已收敛原生曲线比较并通过。新增回归覆盖瞳孔加密时的固定像面采样间距、完整原坐标、中心点，以及同一逻辑变换下分离窗口与全 FFT 的逐像元一致性。
