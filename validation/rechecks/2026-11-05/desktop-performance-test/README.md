# 桌面性能检验

顺序模式通过「设置 → 诊断 → 性能检验」运行。测量使用当前配置的独立副本，采用公共进度和取消控件、五主题仪表图标和中英日词库。按随机斜光线追迹和系统更新两段计时，显示三轮中位数。[测量口径](../../../../docs/RAY_TRACING_PERFORMANCE.md#桌面性能检验)

## 28° 双高斯实测

在 Intel Core i7-14650HX、24 个逻辑处理器的 Windows 本机环境中，以 .NET SDK 10.0.300 的 Release 构建测试内置 `Double Gauss 28 degree field.zmx`。样例 SHA-256 为 `f994005d633d4af742402469c9e4e2e0c289a57aed3ae876fb3231d1d3f95460`。每轮发出 32,768 条光线，均到达末面。相同光线的逐面预跑计数为 393,216 面次。

| 轮次 | 追迹用时（秒） | 光线/秒 | 面次/秒 | 系统更新次数 | 更新用时（秒） | 更新/秒 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 0.124575 | 263,038 | 3,156,460 | 9 | 0.210218 | 42.81 |
| 2 | 0.108258 | 302,685 | 3,632,222 | 14 | 0.208127 | 67.27 |
| 3 | 0.114651 | 285,806 | 3,429,672 | 13 | 0.211897 | 61.35 |
| 中位数 | — | 285,806 | 3,429,672 | — | — | 61.35 |

这些读数是同一台机器上的开发构建基线。Ansys 的公开文档描述了 OpticStudio 的指标和测试镜头。双方数值对比需要对齐追迹条件、表面计数与更新范围。[OpticStudio 指标说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v25202/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Performance.html)

## 验证记录

- 默认 Release 整方案构建 0 警告、0 错误。词库检查为 3064 个词条、2845 处引用、0 漏译。[构建日志](build-delivery.log) · [词库日志](catalog.log)
- 最终批次 22 项，15 项通过、7 项失败。三项新检验通过，覆盖正式样例的计数和工程修订、取消入口以及离屏对话框结果。五主题真实工作台在 13 和 18 DIP 的两项回归通过。[最终 TRX](performance-delivery.trx)
- 最终七项架构检查仍报告已有文件中的 Core 类型泄漏、UI 引用、阴影、主题、字号、进度与配色问题。初轮还列出本窗口自建的进度条，现已改用 `OperationStatusBar`。初轮以逐面历史为计时路径，初轮读数与最终末面追迹分开留存。[初轮 TRX](performance-test.trx)
