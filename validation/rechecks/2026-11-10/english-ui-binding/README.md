# 英文界面统一绑定复验

2026-11-09～10，按用户要求修复[前轮跨功能审计](../../2026-11-09/english-ui-audit/README.md)中的系统呈现文字。验证使用独立 Release/headless 进程及 Cooke Triplet；未控制或重启用户运行实例。

## 已处理的呈现边界

| 用户清单 | 实现与验证 |
| --- | --- |
| 总览、镜头数据、主题切换 | Dock 模型标题绑定规范描述；系统选项按显示模板翻译，保留选择值和处方 |
| 点列及其他分析 | 表头、指标、采样参数、坐标/色标、图注、操作提示、只读计算记录绑定共享语言；实际运行点列、场曲畸变、波前、干涉图、PSF、MTF、RMS、包围能量、相对照度 |
| 非序列 | 角色、类型参数、全局参考及属性摘要按显示字段翻译，保留对象 ID 和可编辑名称 |
| 优化 | 通用表头、参数表头、错误显示绑定；全部操作数参数标签检查，原向导回归继续通过 |
| 镜头库、可加工性 | 分类和系统生成的数量、视场、工作距离及历史条目说明翻译；表头绑定，原可加工性语言刷新保持 |
| 光学制图 | 默认输入、选中单片/胶合镜片、ISO/GB 设置、原生工程图表头/轴标/技术要求；已编辑文字保持原文，缓存图纸不借用另一镜片的默认文字 |
| 报告设置和 PDF | 所有已注册分析的参数及选项检查；PDF、HTML、Word、Markdown 原生导出使用开始时的语言快照，界面切回中文不混排 |
| 镀膜、相机、装调 | 选择项、边界说明、动态按钮、阶段名称和长说明补齐；装调原共轭/返回像绑定及三主题回归保持 |

系统文字和数据使用不同边界：`BindChoices` 不替换 ItemsSource/SelectedItem；`TranslateBinding` 只用于指定的单向呈现字段；`BindLanguage` 以弱引用追踪所有者。原始镜头/材料名称、厂商注释、文件路径、公式和用户备注不自动改写。非序列对象表中历史保存的“点光源／矩形探测器”等 **Name 数据**也保持原样，其角色和类型界面已翻译。

绘图仅重绘文字，计算 DTO、曲线、坐标范围与相机处理没有改变；工程图重绘已接受的图纸快照。文本状态按语言缓存，避免每次布局重新匹配同一句。报告输出语言与已有窗口的显示语言隔离。

- 4,096 条本地译文、3,782 处静态界面出现位置，生成目录检查零缺失、零错误。运行时还检查了全部注册分析默认参数/选项，静态提取零缺失不等同于穷举所有外部错误状态。
- [生成管线](pipeline-results.json)的八项正反例通过，包括缺词、陈旧目录、单位变更、术语冲突与失败时不覆盖目录。当前环境没有 PowerShell，使用保留的[等价命令驱动](verify_pipeline.py)调用同一真实 .NET 工具。
