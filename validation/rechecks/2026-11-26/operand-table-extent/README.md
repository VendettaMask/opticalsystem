# 多结构表格按实际列收边（2026-11-26）

用户要求最后一个结构列之后留白。原生 DataGrid 在拉伸至整个工作区时会把填充表头、选中行和水平网格线延伸到右侧，本次让表格左对齐、限制为实际可见列总宽度（包含边框和确有需要的纵向滚动条），并在控件边界裁切。未增加虚构结构列或覆盖真实内容。

初次建立、结构变化和原生列宽变化后更新边界。窄窗口仍由 DataGrid 自身滚动，保留冻结列、调整列宽和双击结构标题的功能；布局事件在面板释放时解除。操作数按类型固定颜色的规则保持。

复用五主题检查，验证真实列数、右侧表头/选中行/不同类型行的像素均为空白背景，以及调整列宽后边界扩展。继续运行已有多配置矩阵/编辑器检查，覆盖选择、重排、切换、变量、草稿与撤销。全部后台离屏，不控制用户窗口；临时测试运行目录完成后移除。
