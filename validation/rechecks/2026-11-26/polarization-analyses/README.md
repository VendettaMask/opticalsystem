# 系统偏振分析接入

本轮将五项偏振分析接入正式顺序分析目录、菜单、命令检索、窗口参数、结果页及报告选择，保留同组的 Jones 瞳。使用共享 Core 追迹，不以矩阵图或通用透过率页面替代这些结果。

计算约定与入口见[系统偏振分析](../../../../docs/POLARIZATION_ANALYSES.md)。均匀介质使用实折射率界面和 Beer–Lambert 体吸收；相干膜层使用复振幅响应。旧指标调用保留严格默认。这一分析窗口模型与任意复折射率介质的完整矢量边界传播分开。

## 功能检查

不同用例的合并结果见 [results.json](results.json)，原始 TRX 与日志以 gzip 保留。三组检查共 147 项不同用例；最后的镀膜组合组包含新增分析的 13 项复验，同名用例取最后结果，不累加重复执行。

- 五项实际计算与处方不变、全部视场／波长选择、取消、零电场相位。
- 解析平板 Fresnel 功率、单次体吸收、截光分母、渐晕面积因子、相干膜层及独立 Jones 输入。
- 五主题实际菜单点击、五项结果和设置、系统／独立输入切换、圆偏振光瞳；三语计算章节与全部分析目录映射。
- 原偏振操作数、照度和目录结构的回归。

初次窗口夹具使用常用镜头时暴露体吸收被严格电场接口拦截，现由显式的共享实界面／体吸收选项接通，保留原默认及其拒绝断言。夹具另修正了双主波长、隐藏设置控件检索和初期设置目录隔离问题；原始失败记录保留。构建期间共享源码的临时编译错误不作为功能通过记录。
