# 本例计算方式核对

用户明确本轮按计算方式与设置含义核对，不要求从另一台电脑取得严格逐像素原生对照。这里只核对当前蓝色陷波示例的无像差路径，不宣称所有图像模式与参考实现完全相同。

| 项目 | 官方公开定义 | 当前示例的实际执行 |
| --- | --- | --- |
| 源位图 | 显示经过源图预处理的输入图 | 第一窗口读取 RGB_CIRCLES.BMP，仅执行方向／尺寸处理，不追迹光学成像 |
| 仿真图，无像差 | PSF 为冲激响应，保留畸变和横向色差 | 第二窗口绕过恒等卷积，继续真实几何映射、照度和偏振权重 |
| RGB | 红／绿／蓝分别取 606／535／465 nm | 三个通道使用相同定义；仅按各自实际功率给像素加权 |
| 相对照度 | 选中使用视场相关瞳面积分；取消使用主光线强度 | 当前选中，保留既有积分和光线采样 |
| 使用偏振 | 计入系统偏振和界面响应 | 当前选中，保留实际 Jones 链功率及引用膜系 |
| 需要相位的分析 | 衍射模式使用 Huygens PSF | 相位／波前／衍射调用仍走原完整追迹；新功率路径不供 OPD 使用 |

官方来源：[图像模拟帮助](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v252/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Image_Simulation.html)、[高分辨率图像仿真教程](https://optics.ansys.com/hc/en-us/articles/42661994652819-How-to-simulate-high-resolution-images)，访问日期 2026-11-26。教程明确以 None 和 1×1 网格构造单个冲激响应；与本例设置一致。

相位省略的物理理由是单条独立光线的公共相位不改变功率：||exp(iφ)E||² = ||E||²。这不适用于不同光线的相干叠加，因此保留默认追迹与波前／衍射的完整近轴面相位。

这份方式核对不等同于独立原生像素验收。一般像差模式仍有 EigenPSF 降维近似，默认像元尺寸等细节也不能由本例性能修复认定为全部等价。未新增原生采集、改写历史基准、调整容差或运行全量光学矩阵。
