# 悬停提示完整文字

用户截图显示「复制文本」末字未完整出现。本次将 ToolTip 内部文字从父级的省略规则中隔离：不省略、不限制单行，空间不足时自动换行，并预留 2 DIP 右侧字形边距。保持原文字、主题字体、颜色和真实按钮操作。

正常 Release 主程序构建成功，0 警告、0 错误。实际调用分析工具栏的按钮工厂，在表头这个会施加省略样式的父容器内打开原生控件的离屏提示，核对五主题、中英日三语、100%／175% 缩放及自动／66-DIP 受限宽度，共 60 个布局采样。异世界按既有规则固定英文，语言请求与实际语言分别记录；采样数不是新增的测试套件通过数。

检查文字未折叠、字符全部参与排版、行宽和行高完整包含。Avalonia 文本行长度包含一个额外的段落结束符，诊断已明确计入。[组合与尺寸](after-layouts.json)、[构建／边界与身份](verification.json)。
