# 实体模型默认不透明与可选透明模式

日期：2026-11-26。本轮只修改绘制，不修改镜头、材料透过率、光线追迹或数值验收范围。

## 行为

实体模型原有“实体／透明／线框”三项选择保持。新建查看器默认“实体”：玻璃、棱镜及该显示方式下的非序列实体使用不透明面；玻璃侧壁、选中面及剖切封口使用同一规则。面按深度遮挡后方几何，取消覆盖在不透明实体上的背面整机线条。需要检查内部光路时选“透明”；线框保持原方式。

单独设置的表面绘制透明度仍有效，100% 表示使用当前模式的完整强度；“实体”完整强度为不透明。材质识别色和真实像面的半透明参考保留，独立三维布局仍沿用原外观。模式切换只改变显示，不重新生成场景或修改工程。
