# 二维布局的子窗口适配

用户要求解决二维光路只占子窗口约一半宽度的问题。本次仅调整二维布局的屏幕适配和独立导出排版；光学处方、追迹数据和三维／实体模型的版式策略保持。

## 实现

- “适应窗口”使用实际子窗口宽高展开绘图页，装饰主题把外侧边框计入尺寸。光路在扣除底部图签后的区域等比显示，保留完整场景和标注。
- 窗口变化和显示模式切换不重建场景，不修改工程，不清除用户平移或缩放。
- 100% 查看保留所选 4:3／16:9 图纸。PNG 使用同一个场景和当前视图状态重新投影到打印画幅，不依赖屏幕子窗口尺寸；图签保留生成时间、实际主题、配置图例状态和字体。既有报告走原来的打印页生成器。
- 保留隐藏图签、超出图框拒绝导出、边框、配置颜色、图像分辨率及比例选择。

## 验证范围

使用实际蓝色陷波滤光片示例、Cooke 示例和多结构 Zoom 示例，后台离屏检查窄窗、宽窗、纵向窗口、五主题、100%／适应窗口往返、键盘缩放平移、手动图纸比例、自动比例回归、125% 导出、三语图签／大字体溢出保护，以及相机导出排除工具栏和焦点框。蓝色陷波示例的宽窗彩色光路横向占用约 72%～73%；完整图纸边框随窗口展开，光路按完整几何留出等比取景边距。

最终 **29/29 检查通过，0 失败、0 跳过**，结果以 `accepted.trx.gz` 和 `results.json` 为准。保留迭代失败回执，不能把中间失败计入最终通过数。`iteration-results.json` 汇总历史失败：最初的测试使用从输出目录向上查找项目的路径，在隔离输出下找不到项目；修正后发现导出图签未继承主题，随后核对真实 100% 图签像素并统一布局取整。最后补齐独立导出图签的即时语言转换，三语测试先切换主题再显式选择并确认语言，避免继承装饰主题的固定语言。装饰纸张具有不规则透明边，不使用普通主题的矩形纯色边框断言。

正常 Release 主程序和项目依赖参与构建，保留 NU1900 依赖审计联网警告；没有关闭 NuGet Audit。测试输出隔离到工作区临时目录，未控制／重启用户应用，未终止其他任务或测试进程。未运行全量光学精度矩阵，本记录不扩大光学数值验收范围。报告格式本轮未逐一重新验收。
