# 按名称及功能语义重绘实际图标

2026-11-03，用户明确要求依规范重新画，并结合名称重新设计；仅调整现有通用图标线宽和颜色不足以满足本轮要求。

实际 332 处入口和状态已绑定 221 款语义图形：196 款新绘，25 款保留已确认原稿。九项 MTF 分别区分傅里叶/惠更斯/几何和频率/离焦/视场，不再共用扫描框或折线。报告、像差、波前、PSF、圈入能量、材料、膜层和对象操作使用对应结构；七个视角按钮由同规范 SVG 绘制。帮助、干涉图及几何图像分析的旧缺失名称改为实际专用资源。

`semantic-manifest.json` 保存每处功能及设计意图，`source-inventory.json` 保存重绘前的语法树清点，`current-source-uses.json` 核对接入后所有实际图标参数。316 处精确字面量绑定计划保留于 manifest，`applied-bindings.json` 记录文件前后哈希；不采用全局字符串替换。72 个实际分析命令的 ID、名称、文字、分组及动作保留。分类原稿及主题调度保持，用户窗口没有被重启或操控。

正常默认 Release App、内置依赖和测试项目构建完成，最终构建零警告、零错误。最终 **57/57 个不同定向用例通过，零失败/跳过**：

初次混合批次 `semantic-icons.trx` 的48通过、6失败、6跳过保留为过程证据：两项失败涉及混用Headless/Skia字体缓存，三项为较早的Light不透明背景断言，一项把Dark与Lumen图标像素误设为相同。按当前已接受的主题契约修正断言，并在后端一致的独立进程完成上述最终检查；PNG检查实际启用，没有把跳过计为通过。另一次构建遇到其他后台测试进程的输出锁，待其自然结束后完成正常默认输出构建，没有关闭该进程或用户应用。

本轮范围为功能图标、绑定、界面和导出验证。数值引擎未修改，不扩展成全光学精度矩阵的通过结论。规范见[语义设计](../../../../docs/ICON_SEMANTIC_DESIGN.md)和[本地图标](../../../../docs/LOCAL_ICONS.md)。
