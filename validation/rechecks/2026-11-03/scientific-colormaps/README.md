# 数值分析图统一配色验证 · 2026-11-03

按用户最后限定，仅改变二维数值伪彩色、彩色等高线和三维分析曲面。默认采用第二张参考图的 Viridis 紫—绿—黄色系，设置入口为 **设置 → 格式与字体 → 分析图配色**；另有红蓝、Rainbow（现有 Jet 色图）、Inferno、Gray，提供本地色带预览、保存和恢复默认。

## 行为与边界

- `ScientificColorMaps` 只参与 App 显示映射，不修改结果 DTO、Core、计算采样或数据。二维块、三维三角面及各自色标共享同一映射；Foucault 伪彩色和全视场像差的颜色模式同步。红蓝以原归一化区间中点为白色，不改变范围或强制零中心。
- 曲线、散点、ColoredLine 曲线、波长/材料/光线/状态色、RGB 栅格和实际相机图像不改色。明确的灰度/反灰度模式继续按原模式显示。探测器热图默认跟随全局，本地原有五种色表仍可显式覆盖。
- 设置预览不改变已打开的分析，保存失败恢复原值；旧设置缺失/无效字段回到 Viridis。仅配色改变时直接重绘已有控件，保留源样本、图例筛选、坐标、归一化和三维交互相机，不重新运行分析。
- PNG 及报告使用现有共享源图。原图仍为 1200×900 逻辑画布，完整输出为 2404×1804；此任务未改画布、像素规格、单位或光学验收标准。

## 当前证据

最终定向范围为 **29 个不同用例**：18 个新增配色用例及 11 个既有干涉图、波前表面、线宽用例。范围包括五种设置往返/旧设置回退、端点与插值、中英日文/Light 和 Dark 的真实下拉选择、保存失败回滚、默认重置、已有二维/三维同时刷新、相机与筛选保留、非目标图像逐像素不变，以及实际 Double Gauss 波前在三维和二维下的实时 PNG / 报告全像素一致性。实际主工作台也验证了保存配色后原分析控件、数据引用、三维视角和镜头恢复状态保持。

默认 Release App、必需内置模块依赖与测试项目构建零警告/错误。最终结果和程序集/编译源码身份见 [receipt.json](receipt.json)；可用 [Summarize.ps1](../../../../tools/diagnostics/ScientificColorMaps20261103/Summarize.ps1) 重新核对。Core 和 Application Runtime 没有工作区差异；其他任务已有的主题、图标、目录和界面修改均保留，不能把此记录解释成整个共享工作区的全量验收。

保留中间失败记录：初次编译修正了测试调用参数；首次 16 项检查中，设置测试使用了不存在的名字作用域、报告比较误用了 PNG 容器字节，改为真实视觉树查找和解码后像素比较。后续 28 项中，四项既有干涉图测试仍用旧的 1200×900 无边框截图比较现有 2404×1804 报告；仅修正测试的捕获前提，继续要求完整像素一致。一次默认测试输出被并行任务占用，未关闭进程，稍后正常构建成功。以上记录不计为当前通过数。

验证全部在后台离屏进行，没有启动、控制或重启用户的前台软件；没有安装、发布、远端同步、全仓测试或新的外部光学精度认证。
