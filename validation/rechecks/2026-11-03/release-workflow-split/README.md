# 云发布与普通 CI 分工

日期：2026-11-03。基线：`80f5f778`。用户明确要求精简云端打包，仅保留必要发布检查，界面回归和文档检查归普通 CI。

## 实施范围

- 发布保留完整解决方案锁定还原/Release 构建、版本与架构、Windows 安装/更新保护、OTA 身份、模块交付/依赖，以及实际 EXE/DMG 与更新载荷检查。将原先已无同名测试类的 `InitialStructureLabLauncherTests` 过滤项改为实际存在的 `BuiltInModuleDeliveryTests`，验证两个内置模块、许可和同进程边界。
- 页面、字体、图例、视图、工作区及更新面板的所有用例仍由普通 CI 完整主测试覆盖；初始结构预设/搜索仍归 CI 原有模块分组。发布不再重复这些集合。
- 导航隔离进程、三语言更新反馈、真实 Skia 分析绘图及 PNG 导出迁入 CI 主测试任务，分别运行并留存 `desktop-ui-*` 产物 30 天。构建成功后，即使其他测试失败，仍执行这些独立检查；取消任务则不继续。原生崩溃报告的范围、数量/大小上限和无内存转储保护保持，专项 LLDB 脚本保留为手动云端诊断工具。
- 文档/冻结证据沿用 CI 的独立任务，未删除对应检查或测试。更新既有工作流契约测试，约束 CI 完整用例与隔离绘图保留，同时继续保护发布凭据、签名顺序、安装包校验和失败备份。
- `validation_only=true` 只执行必要发布测试与构建，跳过打包、成品包检查及发布；它不代表实际安装包已通过。
