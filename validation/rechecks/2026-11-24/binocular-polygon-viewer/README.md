# 双筒示例棱镜组可视化修复

日期：2026-11-24。范围：95 支菜单示例中的 `Afocal/Binocular_System.ZMX`，两个原配置；后台共享 Core 与实际 Avalonia 离屏绘制。

## 原因

第 6 面为混合顺序多边形棱镜组。原读入和真实内部追迹已实现，但只保留出口端口样本；2D/3D 场景缺少内部反射节点和实际棱镜面片。可视化预检因此抛错，查看器清空场景。实体模型与 3D 布局使用同一场景入口，均受影响。源文件原始 SHA-256 为 `cee5760013d36157ff2d1fd825a03dfce63e5b7c5e1db91308732fe78eac6540`，与冻结目录一致。

## 实现

在原共享追迹请求中添加按需保留复合交互路径。节点从原多边形求交与交互结果产生，保留全局位置、出射方向、真实交互类型和面片索引。正常分析不申请这组节点；复合路径使用相同物理算法，独立执行而不读写普通分析缓存，并受原样本预算和每组 128 次交互边界约束。布局沿原光线表面身份筛选路径，不再把增加的棱镜内部节点误当成后续表面序号。

二维数据为独立闭合的真实面片投影，避免跨棱镜拼出连接线。三维发布原面片与真实体材料，沿用现有实体、透明、线框、切面、材质图例及导出绘制。保留源配置、表面和面片身份，所有结构在原全局坐标合并；普通圆形曲面继续使用原采样。GRIN 等其他未接入路径的能力边界继续保留。

## 验证边界

两个配置各 16 个三角面；所选原光线穿过 8 个物理交互，其中 4 次全反射。按需节点开关前后，所有保留的表面数值状态逐项相等；内部段长度之和与原组光程中的几何段长度相符，方向沿实际传播方向。两个配置及保存快照后重新打开均覆盖。源码、原处方和两个原 POB 资源均未替换为简化模型。

验证同时覆盖真实场景服务的单／多结构、取消与工程版本不变，以及实际 2D 轮廓和隐藏光线时的实体／透明／线框／切面像素。当前测试记录会标明默认构建、并行测试隔离和独立输出的区别。没有重跑全套 95 支镜头精度矩阵，没有新的外部原生数值捕获，没有启动或重启用户桌面程序，也没有据此修改光学精度通过率。
