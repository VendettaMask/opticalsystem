# 非序列场景工作区接入 — 2026-11-24

本轮将已确认的交互接入主程序：结构／光学／仿真导航，保留祖先的搜索，模型／对象表选择联动，定位、隔离与恢复，公共／混合属性编辑、单步撤销，以及随工程保存的分组和选择集。默认非序列布局直接显示工作区，窄窗将属性区移至下方。主程序使用已有几何、三维控件和计算服务。

相关功能回归 175 项：173 通过，0 失败，2 项沿用原有三维截图测试的跳过声明。范围包含既有 NSC 导入、资源、光谱、文档、工程归档及共用三维绘制。最终导航三语文字修正后，13 项界面／组织／布局复验全部通过；它们属于相关范围的子集，不与 173 相加。Release 主程序与测试依赖图构建零警告、零错误；本地化 4413 条词条、4038 处出现，零缺失、零错误。

实际主窗口使用原有 32 通道、432 对象 STAROPT 输入。五主题与 100／150／200% 离屏检查覆盖搜索、选择、对象表、隔离、模型点选和文件切换；另检查 2000 个平铺对象的按需分页、批量属性的实际应用／无效输入保持、分组／选择集往返与撤销。布局模型测试统一接入原生离屏会话；初次缺少图形环境的记录保留在 `initial-layout-test-harness.log.gz`。
