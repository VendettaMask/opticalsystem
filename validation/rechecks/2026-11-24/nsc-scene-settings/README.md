# 非序列场景设置面板

用户指出恢复旧布局后的模式说明侧栏过于空置。本轮把原 `NonSequentialModePanel` 替换为真实场景编辑器，并让紧凑工作区的“场景设置”命令打开同一个面板。

## 实际行为

- 名称、环境介质、对象／光源／探测器数量。
- 可滚动的独立波长表，含稳定编号、主波长、nm、权重。短列表自动收缩，浏览显示紧凑数值，编辑与保存保留原精度。只在末尾增删，沿用场景对光源波长引用的校验。
- 偏振、相干、Fresnel 分裂及五项实际追迹限值；追迹窗口使用当前场景默认值。
- 整组应用对应一次撤销；无效输入和外部编辑期间的草稿保留，文件切换载入新场景。版本与物理身份共同防止旧草稿覆盖新工程。
- 复用原生系统分区、五主题资源、产品字体与三语目录。新默认布局从命令栏进入，旧停靠标识解析到同一个编辑器。
