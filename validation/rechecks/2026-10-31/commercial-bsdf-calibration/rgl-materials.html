Material Database

About

This page provides an interactive interface to materials measured using the technique described in the paper

An Adaptive Parameterization for Efficient Material Acquisition and Rendering
Jonathan Dupuy (Unity Technologies) and Wenzel Jakob (EPFL)
In ACM Transactions on Graphics (Proceedings of SIGGRAPH Asia 2018)
Click on any entry to expand it. The Interactive viewer button opens a 3D visualization tool built using WebGL and WebAssembly (this requires a fairly recent browser).
The database is a work in progress and is expected to grow significantly over time. Additional information on its contents, code for parsing the files, and on submitting materials to RGL to have them scanned by us can be found in the Frequently Asked Questions.
