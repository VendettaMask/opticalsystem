# 多结构合并显示与实体模型视口扩展

范围：二维图、三维布局和实体模型的本地实现及后台离屏验证。没有操作或重启用户运行中的程序，没有运行95镜头完整数值验收，也未推送远端。

## 行为

- 结构选择包含各单独结构与“所有结构”，打开跟随活动结构，手动选择仅固定当前视图；重置和换文件恢复跟随。
- 所有结构在同一工程版本冻结，逐结构使用共享Core布局构建器追迹与生成模型，在共同全局坐标叠加；不改活动结构、不修改工程、不做图形平移排列。
- 图元保留结构编号与原面/光线编号。材质关联、实体端面去重及厚度查找使用结构+面号，避免同号表面交叉关联；几何和射线路径逐项与单结构结果比对。
- 全部模式默认按结构着色，显示结构图例；底部指标是各结构的真实范围，图例提示保留逐项值。视场/波长/面范围单项只列共有索引；全部视场、全部波长仍使用各自集合。
- 实体模型的真实视口和紧凑参数/图例使用整页宽度。Auto匹配实际可用宽高，900 DIP高、宽取整并限制320–7200 DIP。手动16:9/4:3仍可用，模型投影等比，镜片/光线数据与相机姿态、平移及缩放状态保留。
- 控件维持原生字号，按新视口边缘定位。PNG保留当前模型、完整结构/材质图例和参数，不含工具及焦点。异世界保留已有羊皮材质，其他主题保留既有背景。

## 参考与验证边界

参考官方[3D Viewer说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v251/en/OpticStudio_User_Guide/OpticStudio_Help/topics/3D_Viewer.html)中的All配置与共同全局参考系叠加方式。本次实现全部和单个结构，未增加任意子集或结构偏移参数；没有新做原生商业软件数值采集。

使用File → Samples中的Zoom lens三结构检查几何/光线与逐结构指标、取消、非法请求、不同视场/波长数量、活动结构/版本不变、单独选择/全部/重置/换文件及控件。既有Cooke界面夹具仅检查五主题布局/着色/截面/光线显隐与PNG，不作为额外数值精度验收。

默认Release主程序及测试构建零警告、零错误。相关135项回归全部通过；最后补充图例/筛选边界后38项复验全部通过（37项与前一轮重叠，不重复累计）。完整结果及源文件/产物散列见[results.json](results.json)。截图均为真实Avalonia/Skia后台离屏渲染。
