# 实体模型深色背景延伸

用户截图中，宽图幅的两侧出现了大面积浅色留边。实体模型现在将原有不可变深色渐变同时用于外层图纸和视口空隙，PNG使用同一外层背景。图纸背景可显式指定，普通图纸继续按主题资源绘制。

模型保留固定内部布局，镜片、光线、材料图例和相机使用已有对象。既有回归逐项核对相机方向、平移、缩放、场景数据和内部模型像素，同时覆盖自动、16:9、4:3及100%滚动。新增回归从实际图纸和外框位置计算取样点，分别检查深色侧边和视口外部空隙。

默认Release主程序构建零警告、零错误。最终一次定向检查 **16/16通过，0失败/跳过**，含五主题背景检查、8项既有实体模型版式/导出检查及3项普通图纸视口回归。[结果摘要](results.json) · [完整TRX](backdrop-delivery.trx) · [默认主程序构建](app-default-build.log) · [独立测试构建](test-build-delivery.log)

初始白边复现为5项失败。修改背景后的批次为15过/1失败，最后一项取样点落入异世界装饰边框；固定坐标调整后的4过/1失败也保留。最终检查根据实测图纸和外框坐标确定取样点，16项全部通过。[初始复现](backdrop-before.trx) · [首轮修改](backdrop-after.trx) · [取样诊断](backdrop-final.trx)
