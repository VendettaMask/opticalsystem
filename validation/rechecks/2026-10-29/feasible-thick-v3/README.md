# C# 厚透镜多布局构造 v3

本批改动在 `opticalsystem` 的 InitialStructure C# 引擎及 Avalonia 自主设计入口，使用原共享 Core；没有将 Python、HappyLens GUI 或外部服务接入产品。原 null/v2 算法继续保留，不改原物理验收。

## 变化与预算

显式配置 `MaterializationVersion = 3` 和 `FeasibleLayouts`。每起点默认尝试最多 3 套布局（范围 1–8），重新采样描述范围内的厚度、间隔和玻璃，用 Core `FixedStopDelano` 构造原焦距、固定光阑和像面要求。每次通过正式一阶量与 64 径向制造几何复核；只有通过者可进入后续原补偿。合格布局之间按最小玻璃/空气净空余量选优，不将近轴评分当作像质评分。

可显式轮换光阑前镜片数；界面候选包含当前分配及前/中/后分配，去重后按布局数量上限尝试。参考面、光阑和像面坐标不变。固定光阑位于参考面时，前方无法容纳正厚度镜片，相关分配被拒绝。有限预算内没有合格布局会返回失败，不放宽几何、不裁切曲率后冒称符合焦距。

退火提议总数在布局之间分配，不乘以布局数。每套布局另计一次调度、初次构造和最终复核，全部受原准备函数总额、每起点上限及时间限制约束。矩阵与几何查询沿用实际计数；取消、额度中断不作为合格结果。新报告逐起点保存布局尝试数、可行数、完成几何检查的失败提议数、选中分配与间隙余量。新选项可保存回读，中英日界面可切换，旧 null 字段省略以保留历史身份。

## 已执行检查

[18 项 C# 测试结果](tests/feasible-thick-v3.trx)全部通过，覆盖直接构造后、补偿前的几何与一阶复核，固定光阑空间边界，预算与取消，不可能厚度要求的拒绝，六规格实际生成，旧 v2 和冻结指纹重放，以及 Avalonia 离屏事件/保存测试。产品与测试程序集已成功编译。未进行本机界面点击验收；用户以 Esc 停止了窗口操作。

六组均使用焦距 50 mm、最大机械/光学长度 65 mm、最小后焦 15 mm，玻璃边厚 0.1 mm、空气边隙 0.05 mm；焦距/F 数沿用 C# 任务默认 2% 容差。每组最多 3 起点、每起点 3 布局、24 次共享退火提议，准备最多 180 函数、每起点最多 60。孔径、厚度范围等完整设置保存在各结果的 `SourcePlan` 与 `Options` 中。

## 独立物理复核的限制

另对八片、50 mm、F/8、全视场 25°、种子 42 的第一个保留起点作原 CPU 独立物理验收：[原始结果](user-spec-independent-physical-inspection.json)。该检查单独计算 44,520 条光线，执行完成，但 `MeetsTargets = false`，有边缘视场通光和检查光线失败，最差有效比例为 0。不能将仅存有效光线上的 RMS 数字当作像质改善证据。

本批完成的是 C# 初始布局构造与几何可行性筛选；孔径下的全视场通光恢复、像质优化及最终完整验收仍需后续处理。固定口径没有被程序自动放宽，原有效光线比例、RMS、最大斑点及畸变验收要求保持。

源码与构建前提交标识见 `source-sha256.json`，规格详细记录为本目录 `feasible-*.json`。旧 v2 相关证据由原回归测试在本目录单独输出，不覆盖先前冻结目录。
