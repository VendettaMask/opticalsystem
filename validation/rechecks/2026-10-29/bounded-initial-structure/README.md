# 有界候选探索后台证据

实现、比较和局限见[报告](../../../../docs/BOUNDED_INITIAL_STRUCTURE_2026-10-29.md)。本目录是独立后续批次，保留此前HappyLens广角记录。

- `protocol.json`：冻结三臂、原任务SHA、原600/100/200万/60秒总额、相同验收及有限停止规则。
- `runs/`：每臂初验、准备、事件/预算、失败后代和最佳合格STAROPT。三臂各执行一次，完整汇总为 `runs/summary.json`。
- `regressions/scoped-final.trx`：主批28个定向用例通过；`stopping-branches.trx` 另2个不重复停止分支通过。三语界面为离屏范围，未验证原生桌面交互。
- `regressions/fixed-stop-dense-recovery.json`：原广角曲率扰动的独立60评价恢复，0追迹，只证明一阶和制造可行。
- `audits/`：三臂结束后的27次共享Core一阶只读请求，0追迹，不属于预算内优化。
- `development-*`、各早期TRX/日志：恢复开发中的失败/诊断，保留反例，不计入冻结比较成绩。它们包含带区、Dogleg、投影深度及预算分配试验，不能说本次开发只运行过一次准备。
- `verification.json`：原任务不变、相同验收/采样/权限、工作额度和事件计数、归档达标、筛检零追迹、层次数、30个不同通过用例与文件SHA核验。

结果：新流程的重生通过841项几何检查，12次补偿接受更新后仍因原焦距/RMS失败；保留原合格三片。新Delano准备仍0/4且F数恢复更差，起点和最佳最终像质未改善。停止原因是完整试验最低额度不足；没有继续强行减片、增加预算或降低原标准。

全程CPU、2处理器、BelowNormal、后台/离屏。没有全套测试、前台窗口/输入、原生GUI/GPU验收、提交推送或发布。
