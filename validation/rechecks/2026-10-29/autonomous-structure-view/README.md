# 自主结构显示：后台/离屏证据

实现和使用见[结构显示说明](../../../../docs/AUTONOMOUS_STRUCTURE_VIEW_2026-10-29.md)。

- `structure-first.trx`：首轮3项通过，覆盖共享Core布局、候选查看/导航/记录隔离及无效输入。
- `structure-layout-final.trx`：宽窄画布空间调整后，真实候选/导航用例单独复验；不重复累计。
- `structure-final.trx`、`structure-final.log`：最终4个相关用例全部通过，包含原载入/身份/三语守卫；不与前置重复用例累计。
- `structure-wide.png`、`structure-narrow.png`：真实后台渲染截图；宽屏显示原合格候选，窄屏显示未达标生成起点。窄屏截图通过页面滚动显示画布，未缩小界面字号。
- `format.log`：仅相关文件格式整理。最初构建的同名成员警告已修正，早期构建日志保留于上级 `structure-preview-build-first.log`。

显示调用同一Core布局/DTO，数据匹配实际处方与光线路径；每场7条主波长光线，颜色为视场。导航和语言切换不追迹；初始文件载入不追迹。单次显示独立硬限50,000，实际计数另列，不写搜索账目。取消/来源变更后的旧结果丢弃，仍使用原合格/未达标状态。

本批不运行新优化或改变原验收。所有验证为后台、2处理器、BelowNormal及离屏，未打开或控制用户桌面，未验证原生交互/GPU、全套回归或发布。
