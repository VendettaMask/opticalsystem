## 共性原因与修复边界

1. **标题、表头和选择项绑定绕过普通控件翻译。** [WorkspaceDockFactory](../../../../src/OpticalSystemDesign.App/Services/WorkspaceDockFactory.cs)直接设置 Dock 模型 Title；DataGrid表头和下拉选中项由绑定模板生成。[数据保护策略](../../../../src/OpticalSystemDesign.App/Services/UiLocalization.Data.cs)有意保留绑定文字，需要在明确的界面字段上选择翻译，不能取消用户数据保护。
2. **词库提取与运行时生成不是同一范围。** 当前工具只提取可识别的App文字；分析服务返回的标签、元组标签、动态拼接和特殊属性不能全部覆盖。“均匀”还涉及未纳入全局处理的 ComboBox.PlaceholderText。当前 `check` 仍是3,416词条、3,261处提取、零缺失/错误，但离屏审计已证明存在残留。
3. **分析绘图直接绘制字符串。** [点列指标呈现](../../../../src/OpticalSystemDesign.App/Panels/Analysis/AnalysisPanel.Plots.cs)、[结果图注](../../../../src/OpticalSystemDesign.App/Panels/Analysis/AnalysisPanel.Results.cs)与 [波前绘图](../../../../src/OpticalSystemDesign.App/Controls/WavefrontSurfaceControl.cs)需要明确的呈现层本地化。保留Core结果、类型身份、单位、数值、坐标、相机和图像，不通过修改计算输出键来修复显示。
4. **工程图与报告有独立文字输出。** [工程图](../../../../src/OpticalSystemDesign.App/Manufacturing/Rendering/OpticalDrawingRenderer.TitleBlock.cs)和 [共享报告版式](../../../../src/OpticalSystemDesign.App/Services/DesignReportPresentation.cs)直接使用中文。修复时需在输出开始时固定语言，翻译固定标签/模板后填入原始数据，并复核原生图像和PDF；只检查TextBlock不足以覆盖。

建议顺序：共享标题/表头/选项边界 → 分析呈现与工程图/报告 → 实验室和动态状态。每一层以真实运行和输出复核，不能仅以词库零缺失作为完成标准。

## 验证资料与限制

- [审计探针](BroadEnglishAudit.cs)通过临时小工程引用正式App、链接仓库的SafeHeadlessUnitTestSession运行，程序集名使用既有测试友元；未改生产工程或引入另一套算法。使用独立临时设置目录，原处方状态比较保持不变，没有控制或重启用户程序。
- 最终 [TRX](audit.trx)的 **1通过** 只表示探针完成和其结构/计算/处方保护断言通过，**不是“漏译为零”的通过数**。九类分析均为Success，PDF导出1项目成功、0失败。
- 早期探针选择了“总体布局”导致无法获取单片sheet、绘图回调未调度至UI线程，两处均已纠正；一次无界Dispatcher排空尝试已取消并改用有界加载等待。上述为验证脚本调整，不记为产品缺陷或修复。
- 字符串候选含自动名称、源资料和未实际落入可见裁剪区域的控件，不作为缺陷精确总数。画布文字由实际PNG/PDF另行人工检查。没有穷举所有数据、弹层、状态、DPI和主题，也没有执行全套数值测试。
- 只保留探针、结构化观察、TRX及一份必要PDF证据；不提交批量过程截图或完整数值DTO。提交/推送不在本次检查范围内。
