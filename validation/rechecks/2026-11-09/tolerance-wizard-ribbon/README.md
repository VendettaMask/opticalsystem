# 公差向导功能区入口验收

在 Light 主题下用 MS-L7 镜头打开真实主窗口，核对「公差」功能区中的独立按钮。编辑器关闭时从功能区启动并取消向导，确认编辑器保持关闭。再次启动并确认，核对生成的操作数和编辑器分类色。原有编辑器入口另行运行，并核对实际渲染像素。

[功能区入口](tolerance-wizard-ribbon-light.png) · [确认后打开公差编辑器](tolerance-wizard-from-ribbon-light.png)

定向回归 36 项通过。初次运行时，功能区路径的一个像素样点与行背景相差一个 RGB 色阶。复验对该路径检查实际行底板颜色并保留截图，编辑器路径继续执行原逐像素断言。[初次记录](wizard-ribbon.trx) · [最终记录](wizard-ribbon-final.trx)

新增入口使用中、英、日三个本地标签。全库词表检查的六处赛德尔报告缺译和词表未同步提示，在修改前的 HEAD 与当前工作区中相同。
