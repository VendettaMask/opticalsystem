# 英文窗口中文残留复验

2026-11-09，依据用户提供的[英文装调窗口截图](reported-mixed-language.png)，修复真实控件中的中文残留。保留一张[最终离屏实图](alignment-english.png)，不新增成套过程预览。

## 原因与修复

- 原语法提取按单文件推导标签辅助函数，漏掉同一 partial 类型另一文件中的调用。扩大检查后发现110项遗漏：107项普通文字补译，CMCO、TMCO和F / d / C按真实技术标识声明原样保留。相机实验室、镀膜工具栏、公差设置等同类词条一起补齐。
- 装调表格绑定的数据默认不由全局控件翻译器改写。现在只在行呈现属性中翻译像类型和固定诊断，保留原始DTO、表面名称和数值。测量模式使用显式本地化的选项模板，枚举身份不变。
- 叉丝详情中的倍率名称、位置、模式和诊断先分别翻译，再填入原始数据。语言切换只原位更新显示，不重算、不取消当前计算，不替换选中行或像素。镜头名称即使与“保存”等界面词相同也保留原文。
- 像类型列按实际内容定宽，完整显示Vertex image和Center-of-curvature image。物理探测面尺度、叉丝像素、工作区结构及光学计算保持。
- 英文词库校验不再把任意花括号内容都视为格式占位符；修复膜系语法帮助中的说明性材料ID标签。最终词库3,416项，比本轮开始新增154项、修正1项。
