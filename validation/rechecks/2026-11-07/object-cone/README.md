# 320° 椭球反射镜的顺序导入与精度复验

ZMX 的 `OBNA 160 1` 表示 160° 物方锥半角。均匀与高斯模式按角度采样，余弦立方模式按立体角采样，并单独计算光线强度。有限物点在闭合旋转二次曲面内部时，追迹使用沿传播方向的交点，允许光线在椭球的另一侧反射。移除 `VCON` 的原生对照得到相同结果。STAROPT 快照和 ZMX 往返保留孔径类型及其角度。 [OpticStudio 孔径定义](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Aperture_Type.html) [原生和本软件数据](numeric-controls.zip)
