# 折叠像面 Huygens 与 Schmidt 包围能量复验

Huygens 球面传播在像方局部坐标中重建出瞳面。此前沿全局 Z 定位出瞳，折叠像面的发射位置和传播距离会偏离同一局部出瞳。自动参考按像面两个方向中较大的半宽判断四分之一波长门槛。两个旋转像方局部坐标的解析测试，以及 12 项既有球面参考和位移测试通过。原生补采读回自动、强制平面和强制球面三个设置，单独记录实际采用的相位分支。 [OpticStudio Huygens 参考定义](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v25101/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Huygens_PSF.html)

| 原生对照 | 自动走平面传播 | 自动走球面传播 |
| --- | --- | --- |
| Sample Spectrometer，像面 32×32 | 像素间距 0.25、0.28、0.30、0.31 µm | 0.32、0.34、0.40 µm |
| Twyman–Green，像面 32×32 | 0.90、1.05 µm | 1.20 µm |

Sample Spectrometer 的原始 0.25 µm 请求与强制平面逐值一致。0.40 µm 请求与强制球面逐值一致。0.28～0.34 µm 中间档用相同平面相位和有限单元包络核对分支。Twyman–Green 的三个自动档与对应的强制分支逐值一致。 [原生对照和设置读回](native-controls.json)

## 加密验收

保留各项原处方、视场、波长和比较阈值。Huygens 保留像面步长和 32×32 像面网格，Schmidt 保留 0～5 µm 能量半径范围。通过项使用正常分析入口计算。

| 请求 | Core 对 Zemax | 最差 NRMSE | 最大绝对差 | 共同覆盖 |
| --- | --- | ---: | ---: | ---: |
| #444 Sample Spectrometer Huygens PSF | 512 对 1024 | 0.005977 | 0.00006952 | 100% |
| #446 Sample Spectrometer Huygens MTF | 512 对 1024 | 0.0002858 | 0.0005902 | 100% |
| #448 Sample Spectrometer Huygens PSF 截线 | 512 对 1024 | 0.0008979 | 0.000007468 | 96.875% |
| #451 Sample Spectrometer Huygens 离焦 MTF | 1024 对 2048 | 0.001548 | 0.001687 | 100% |
| #2278 Flat-field Schmidt FFT 衍射包围能量 | 512 对 1024 | 0.001423 | 0.002704 | 100% |

前三项的 Core 和 Zemax 各自 512→1024 均通过。#451 的原生 512→1024 为接近，1024→2048 通过。Core 1024 同档与对原生 2048 均通过，Core 2048 触及一百万条顺序光线的上限，因此未验证 Core 的 1024→2048 收敛。#2278 的原生 256→512、512→1024 和 Core 256→512 通过。 [加密逐项结果](native-controls.json)

Schmidt 原处方的中心光线确实在第一面被遮挡。32 档原生能量对照中，同尺寸遮挡移到偶格节点时与移除遮挡逐值相同，移到奇格时两条曲线均变化。中心遮挡半径 6.5 mm 时原生曲线未变，扩大到 6.7 mm 后两条曲线均改变。这个结果把冻结能量曲线的差异定位到低采样瞳孔遮挡的离散读出。实际光线遮挡及冻结判定分别保留。 [遮挡逐光线和格点控制](native-controls.json)
