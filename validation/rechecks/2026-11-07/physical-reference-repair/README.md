# 有限像面 Huygens、相对照度与非共轴 OPD 复验

## 非共轴 OPD

Spectrometer 的原生逐面光程控制确认了光栅相位。非共轴的旁基方向笔现在用像面两个横向分量求最窄截面，供波前参考球定位。#458、#466 原超限点的光程差分别由 4.378、4.413 nm 降至 0.0206、0.0208 nm。22 条原请求的 1,593 个物理节点复验通过，28 个补点全部满足原单点门槛。另以两场三波长核对 2,514 个原生单色图表节点，均通过逐点门槛。 [参考球、光栅相位与重放](../spectrometer-opd-reference-plane/README.md)

## 倾斜像面的相对照度

原生有限余弦模式对 TILTSURF 的相对像点采用原生局部坐标约定，并沿实际切面投影。#2752 在原 20 档的 21 个坐标上全部通过，最大照度分数差由 0.00828509 降至 8.51×10⁻¹²。原处方、单轴、混合倾角、反倾和陡倾等共 12 组原生控制通过。物理余弦积分和自适应积分在等价坐标表达中各自保持一致，最大差分别为 2.08×10⁻¹⁷ 和 7.63×10⁻¹⁷。 [原生控制及物理等价验证](../tilted-illumination/README.md)

Axicon #954 只有一个实际定义的轴上视场。Zemax 的 RELI 与 Workbench 在四种密度下均为 1，原生有效 F 数有限且为正，两边的有效 F 数最大相对差为 4.89×10⁻⁵。独立的轴上对照通过。冻结图仍把附加到 10⁻⁶° 的范围用于归一化，因此原判定为 Close。 [四档操作数、透射与积分](../residual-reference-followup/axicon-axis/verification.json)

## Axicon 高采样截线

有限像面的标量 Huygens 分析在符合资源预算时分批追迹光瞳，把相干贡献累积到同一组傅里叶矩中。随后在原二维像面一次求和，保留实际中心和峰值 Strehl、质心、有限单元因子及原归一化。Huygens PSF 和截线的有焦参数可选至 4096。分批路径适用于单一有效波长、主光线中心、有限非零出瞳及平面传播。偏振、球面传播、质心参考和无焦仍由各自的既有入口求值。

#950 以原 32×32 像面、0.25 µm 间距、0.55 µm 波长重放。原 32 瞳采样的发布坐标和值逐点一致。补充的 2048 和 4096 档通过正式入口，实际求和源分别为 3,284,573 和 13,157,549 个，每批最多 32,768 个瞳孔节点。4096 档的完整像面峰值为 1.27944×10⁻⁶。在 32 个共同物理坐标上，与原生六位小数文本的最大差为 3.14×10⁻⁷，满足原逐点绝对容差。原生 1024、2048、4096 档的对数显示仍导出与线性显示相同的 33 个六位小数值。文本分辨率与细档峰值同量级，相对强度随采样的收敛仍开放。 [设置、回读、误差与计算诊断](axicon-verification.json) [分批计算与显示控制证据](axicon-batched-evidence.zip) [Ansys Huygens PSF 定义](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Huygens_PSF.html)

另取同一窗口内的原生实部、虚部和相位，根据报告的实际输出和相位一致性确认三个分量。组合 (I=\operatorname{Re}^2+\operatorname{Im}^2) 后，2048、4096 档与 Workbench 的最大差分别为 1.87×10⁻⁹ 和 9.47×10⁻¹⁰。原生峰值在两档间下降 73.57%，Workbench 下降 73.58%。高精度参考因此确认，两套计算同档吻合，两档的相对强度仍未收敛。 [逐点复振幅与舍入界限](axicon-complex-reference.json) [原生六份分量报告](axicon-complex-reference.zip)
