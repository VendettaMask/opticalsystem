# 95 支菜单镜头精度补采与复验

保留冻结处方、配置、请求、物理范围及比较阈值。独立补采分别验证原生读回、物理覆盖、相邻档收敛及跨软件误差。冻结判定与加密判定分开记录。显式 OPD 的 22 条属于 427 项不可比的子集。

## 衍射包围能量

原 32 档的七条接近项在衍射极限曲线上出现约 0.013 的最大分数差，实际曲线的最大差在 0.0097–0.0138。两边报告的物理半径相同。由衍射极限曲线独立重建，97 与 101 个有效瞳孔节点的两种候选可分别复现两侧曲线，误差低于 4×10⁻⁹。两种候选只差离散圆瞳的四个对角边界节点，原生相对 Workbench 的取舍方向在不同处方与配置中均有出现。

在相同 5 µm 半径、质心参考、波长和视场下，分别补采 64、128、256、512 档，共 28 份原生结果。原生选择器和已记录的处方字段逐项相同。两边各自的 256→512 收敛以及两个档位的跨软件比较均通过原阈值。512 档跨软件最大分数差为 0.000847681，最大 NRMSE 为 0.00048747。七条原 32 档保留 Close。 [逐请求结果和回读](energy-refinement.json) [原生数组、诊断与哈希清单](energy-evidence.zip)
