# 倾斜物面、相对照度与 FFT 加密复验

## 原请求修复

- **#564 单片目镜相对照度。** 有限方向余弦网格沿实际透射口径裁剪后检查折叠和重叠。逆映射的雅可比检查仍适用于实际透射的采样点。原曲线共同覆盖 100%，最大照度比差 0.007597，归一化均方根误差 0.001612，按原阈值通过。最外场仍有可测的照度比误差。 [逐曲线结果](focused-results.json)
- **#746 倾斜像面场曲与畸变。** 倾斜物面求交将表面坐标原点纳入浮点舍入估计。此前 101 个原生扫描场点中有 12 个在物面提前终止。修复后两个配置均通过，第二配置场曲最大差约 7.63×10⁻¹¹ mm，畸变最大差约 1.03×10⁻⁴ 个百分点。 [逐曲线结果](focused-results.json)

## FFT 补充采样

对 18 项相位采样不足的冻结请求，OpticStudio 2026 R1 在原视场和波长下生成 83 份有效报告。MTF 保留原频率范围，二维 PSF 保留 128×128 输出和 0.25 µm 像素间距。截线加密扩大原生报告的像面范围，因此在原报告的物理区间内独立比较，两端只在已有样点之间插值。完整报告的覆盖率和原区间的收敛判定分别记录。 [逐项采样结论](fft-cases.csv) · [收敛梯度和覆盖率](fft-refinement.json) · [原生报告、设置回读和校验清单](native-fft-controls.zip)

17 项的最高两档原生参考按原阈值收敛，Core 对最高档原生参考也通过。#313 需要原生 2048 档，#2569、#2813、#2835 需要原生 4096 档与 Core 2048 档。原低采样的相位检查仍保留，补充结果单列。

**#559 单片目镜 FFT 截线仍有像面坐标差异。** 同档采样的中心强度吻合。Core 用实际边缘光线得到工作 F 数约 7507.09。原生轴尺度反推为约 200，与原处方像面至出瞳距离 1000 mm 除以出瞳直径 5 mm 一致。将该距离改为 500 或 2000 mm 时反推值约为 100 或 400。七个独立近轴模型保持各自的 F 数尺度，最大约 F/7500。依据原处方的出瞳几何进行诊断性投影后，128 到 1024 的四个同档强度对照全部通过，最大绝对差约 5.17×10⁻⁷。原始物理坐标的比较仍有差异，当前正式实现继续保留原坐标定义。 [原生坐标控件](native-scale-controls.json) · [Ansys FFT PSF 的采样与适用条件](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/FFT_PSF.html)
