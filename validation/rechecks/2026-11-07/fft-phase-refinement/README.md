# 20 项 FFT 相位保护的独立补充复验

固定请求在各自的 32 或 64 档触发了同一个局部检查。相邻受光节点的未包裹光程差为 0.508199 至 1.79509 波，超过 0.5 波界限。原请求、固定模式、保护阈值和 20 项原判定均保留。

通过正式 Workbench 入口重算。只增加自适应精度、名义采样上限和 0.001 相对 RMS 目标三个补充设置。截面上限为 4096，其余为 2048。每项均达到两档相邻、局部相位通过的 Core 自收敛，实际返回 512 至 4096 档。现有 PSF、FFT PSF 截面和 MTF 分析的采样策略已经提供这些选项。默认上限 1024 下有 7 项需要再选更高上限。二维 PSF 使用原请求的固定 0.25 µm 像素间距。 [逐项原档与实际返回档](by-request.csv)

20 项各自选用两档独立的 Zemax 2026 R1 数据，两档之间均通过原比较门槛。40 份原生结果和 40 份回读设置均与现有证据包逐件核对 SHA-256。Core 对较细原生参考的 20 项补充比较也全部通过，最大 NRMSE 约为 0.00240125。MTF 保留原频率节点，二维 PSF 保留原物理像素网格。 [逐档收敛、原门槛度量及原生载荷身份](results.json)

FFT 截线的原生高档报告覆盖更宽的物理范围。补充比较将高档原生曲线插值到完整的原 Core 201 个坐标，共同覆盖率为 100%。另有 8 项在冻结原生报告的 201 个坐标中只覆盖 199 个，两个端点在 Core 原窗口之外。记录原范围和端点覆盖，保留整个高档原生报告直接比较时的不可比判定。全流程没有外推或调整物理坐标。 [OpticStudio FFT PSF 采样与物理坐标定义](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/FFT_PSF.html)
