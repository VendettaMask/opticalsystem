## 相对照度

#954 Axicon 只定义轴上视场。Core 在 80 档的物理域只有轴上场，归一化照度为 1。Zemax 的 80 档依然报告 0 到 10⁻⁶° 的区间并按区间最大值归一，轴上读数为 0.9932076604702115。两者的归一化物理域不同。

独立原生 `RELI` 以唯一物理视场相对轴上照度求值，5、10、20、40 四档均为 1，与 Core 的实际轴上点一致。原生 `EFNO` 有限且为正，Core 的每档投影余弦面积为正，实际受光积分节点为 69、305、1229 和 4925。四档有效 F 数最大相对差为 4.887×10⁻⁵。该对照通过，原冻结图仍记为 Close。 [轴上操作数、通光和来源](axicon-axis/verification.json) · [Ansys RELI 操作数定义](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Relative_Illumination_Operand.html)

#2752 Tilted object 在共同的 0–10 mm 物高域比较。Core 和 Zemax 40→80 的最大变化分别为 3.25×10⁻⁵ 和 1.39×10⁻⁵，双边各自通过原阈值。80 同档最大差为 0.00834670，NRMSE 为 0.00642621，覆盖 100%。截点轴距、像面顶点、取消像方基准校正、直接物理锥和均匀像方余弦等控制未解释偏差。原生报告的相对照度等于边缘与该视场有效 F 数比值的平方。 [分场像方基准控制](tilt-probe.txt) · [Ansys 相对照度定义](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Relative_Illumination.html)

后续补采把偏差定位到原生有限配置对 `TILTSURF` 的切面坐标约定。实现后原 20 档 21 点按原门槛通过，最大差为 8.512×10⁻¹²。 [倾斜像面修复和复验](../tilted-illumination/README.md)

## Axicon PSF 截线

#950 追加 Zemax 4096 档原生 X 截线，保持 32×32 像面、0.25 µm 间距、主光线为中心和无峰值归一化。原生截线峰值从 2048 的 5×10⁻⁶ 降至 4096 的 1×10⁻⁶，六位小数导出的分辨率达到峰值量级。2048→4096 的绝对最大差为 4×10⁻⁶，满足原绝对阈值 10⁻⁵，相对曲线收敛仍未证实。Core 2048 的正常入口需要完整二维 PSF，触发有界傅里叶求和的操作量或内存上限。 [4096 档原始文本](native/950-4096/data.txt) · [旧档参考](../dense-huygens-conic/supplemental-results.json)

分批诊断使用相同的出瞳光线、波前和像方切面，保留有限单元孔径因子和衍射极限归一化，只在 X 截线上的像素求和。诊断与正常入口在 32 和 1024 档的最大差分别为 1.73×10⁻¹⁷ 和 8.00×10⁻¹⁵。1024、2048 和 4096 档同档对比均按原绝对门槛通过，三档各有 32 个共同坐标，所有点与原生六位小数的差均小于半个末位。4096 档最大差为 3.14×10⁻⁷。Core 诊断峰值从 4.84208×10⁻⁶ 降至 1.27944×10⁻⁶，与原生加密方向一致，仍不足以确认截线相对强度收敛。正式分析还需保留全像面窗口和 Strehl，以及复色和偏振语义。 [逐点比较](axicon-line-comparisons.json) · [诊断代码](AxiconProbe.cs) · [4096 档诊断数据](axicon-line-4096.json)
