# 原物理窗口内的高档原生参考补采

从上一轮 129 条开放记录中选取 12 条，优先有一档有效原生参考，或已有较高档跨软件通过但档间收敛尚未建立的请求。95 支菜单镜头、3,024 条冻结记录及原比较阈值仍为同一基线。所有结果均为独立补采范围。 [上一轮开放清单](../parallel-refinement/independent-open.csv) · [本轮逐项结果](by-request.csv) · [范围和构建身份](summary.json)

二维 FFT PSF 保持 128×128、0.25 µm、原中心与归一化。衍射包围能量保持 5 µm 半径、质心参考、原波长及视场。补采回读除瞳采样外的分析设置和处方字段与既有参考逐项相同。源处方 SHA-256 保持一致。米制处方仅在原生内存里通过 `OpenScale.ScaleByUnits` 换算为毫米，读回原单位、目标单位及未保存状态，并保留既有换算凭据。 [原生设置与单位回读](native-receipts.json) · [原米制证据](../incomparable-meter/README.md)
