## 保留独立判定的请求

- **#2208 Etalon FFT 衍射包围能量。** 原处方为零光焦度、接触瞳平面且出射光束准直，有限像高上的 FFT 衍射能量缺少物理比例。冻结有焦结果改列不可比。无焦角域的 64、128、256、512 同档结果均通过。原生 128→256 未通过，256→512 和 512→1024 均通过原角域阈值。Core 512 对 Zemax 1024 也通过，NRMSE 0.001030、最大能量占比差 0.002945，共同覆盖 100%。原生补采单独记录。
- **#608、#698 Double Gauss 光程差。** 原处方中的 PARAXIAL OPD Mode 1 在 20、37、80 点档保留约 0.02863 波的弧矢边缘差。独立副本的 Mode 0、Mode 3 等效准直对照均通过，最大差 5.54×10⁻⁶ 波，原请求仍记为差异。 [离轴 OPD 分析](../../../../docs/OFFAXIS_OPD_SAMPLING_REPAIR_2026-11-04.md)
- **#2216、#2220 Etalon 光程差。** 无焦平面参考逐点一致，绝对光程差最大差小于 8.67×10⁻¹³ 波。每个波长的 82 条原生显式光线，在 10¹⁰ mm 的工作尺度下按浮点间隔 1.9073486328125×10⁻⁶ mm 量化后，可重现有焦参考的锯齿残差，最大拟合误差小于 1.4×10⁻¹⁴ 波。保留冻结有焦差异。
- **#125 Birefringent cube 一阶报告。** 独立原生对照在不改动实光线模式的情况下，显式采用中心顶点普通折射率约定，获得 100 mm、F/5，与本软件一致。原参考使用原生默认近轴模式，EFFL 为 −0.036662647 mm，冻结判定仍为差异。
- **#2770 Mirror zoom Huygens PSF 截线。** 该原请求已在上一轮通过。本轮原生 2048→4096 通过收敛比较，NRMSE 为 0.002949、最大差 0.000218，共同覆盖 100%。高档验证为两次原生结果之间的比较。
