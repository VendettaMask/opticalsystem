# 高采样 Huygens、Axicon 和 FFT 参考有效性

## 2048 档离焦 MTF

几何质心使用已有的分批顺序追迹，并直接累计投影坐标。标量 Huygens 根据实际透射节点选择有限傅里叶求和方案。原严格泰勒方案优先，超过预算时允许使用余项上界为 10⁻¹⁰ 的方案。单批仍限制在 100 万条光线，求和仍受 1 亿次估算操作与 256 MiB 工作区上限约束。另行测量同一处方的 2048 档单色 PSF，实际参与求和的发射点为 1,281,281 个，估算工作量 99,362,615 次，工作区约 149 MiB。工作区估算仅计求和阶段。

Sample Spectrometer #451 的 2048 档离焦 MTF 从正常入口完成，Core 与 Zemax 同档的最大调制度差为 **5.01×10⁻⁵**，最差 NRMSE 为 6.87×10⁻⁵，覆盖 100%。Core 和 Zemax 各自从 1024 加密到 2048 均通过原阈值。 [逐档比较和求和记录](supplemental-results.json)

## Axicon 极小半径圆锥面

轴上光线从约 20 mm 外入射到顶点半径 10 nm 的圆锥面时，原批量二次方程的判别式发生消减。CPU 标量批次与 SIMD 批次改按半径、圆锥系数和轴向距离选择稳定的顶点坐标求交。顺序追迹对这一数值范围使用可保留局部交点的路径，避免用距离回算极小矢高时再次丢失有效位。原处方和曲面几何参数逐字节保持。

冻结请求 **#942、#943、#951、#959、#960** 转为通过，分别涵盖两条光线扇、两条光程差和几何包围能量。#951 最大能量占比差为 2.17×10⁻¹⁹。11 条显式轴上与近轴原生光线全部到像面，此前漏掉的六条已恢复，像面横坐标最大差为 2.85×10⁻¹⁴ mm。#950 的 Huygens 截线仍有差异，原生 1024→2048 也未通过收敛阈值。 [原请求指标](focused-results.json) [逐光线和加密结果](supplemental-results.json)
