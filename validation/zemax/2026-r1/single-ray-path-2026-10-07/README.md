# Six-source Single Ray Trace reference

This fixture retains 12 original OpticStudio 26.1.0 build 260127 licensed captures: primary/on-axis and short-wavelength/edge selections for Doublet, Cooke, Double Gauss, Even Asphere, finite-conjugate Relay and Tessar. The 120 source, snapshot, native report/array/environment/CFG/readback, canonical-request and normalized files are SHA-256 inventoried in `manifest.json`. These are original captured settings, not universal defaults. No array, tolerance or native request was refitted.

`SingleRayPathParityTests` checks all eleven report columns at every physical surface. For a positive-infinite Object thickness, the first geometric segment starts on the first surface's vertex plane, perpendicular to its local Z axis, and can be signed. Finite and zero Object distances keep their physical object-to-surface segments. This report convention does not modify physical launch history, cumulative geometric distance or refractive-index-weighted optical path. Reference: installed OpticStudio 2026 R1 user manual, PDF page 745; original source is retained locally.
