# Axial scalar Huygens planar controls

Captured locally on 2026-10-11 using OpticStudio 26.1.0 build 260127 with a valid Enterprise API license. Each case preserves its source bytes, request, applied settings, environment and original native 32x32 intensity grid.

The six cases are MS-L7 uniform, MS-L7 Gaussian factors 4/32/512, Cooke uniform and Tessar uniform. Field 1 and wavelength 1, pupil/image sampling 32, .25 micrometer image delta and polarization off are captured settings. Gaussian overrides are recorded in the request and applied system settings; source prescriptions are never saved back or overwritten.

Tests compare all 1024 pixels with maximum absolute error < 1e-5 and relative L2 < 5e-5. These tests certify the axial scalar planar cases only. They do not certify spherical, off-axis, polarized, afocal or arbitrary polychromatic propagation.

`capture-file-hashes.json` covers capture files; this explanatory README is not native capture data. See [repair and remaining limits](../../../../docs/HUYGENS_FFT_ENERGY_REPAIR_2026-10-11.md).
