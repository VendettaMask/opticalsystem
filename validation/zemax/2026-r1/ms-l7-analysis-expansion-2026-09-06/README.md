# Frozen MS-L7 native captures, OpticStudio 2026 R1

Source: `source.ZMX`, SHA-256 `8bcc937c2c2e02ba175f38875fd0def40db547f7eedab509cbfd1fed4353e0e8`.
Native: 26.1 SP0 / API 260127 / EnterpriseEdition. Lengths mm, wavelengths µm;
each scalar/curve/grid uses the quantity and unit specified by its contract.
This extends the primary committed `123456.ZMX` baseline; it does not replace it.

The 42 top-level analysis directories contain the new numerical contracts:
original data, native text (when available), CFG, canonical request, captured
selectors/properties, model and environment. Earlier captures are retained
byte-for-byte; the manifest lists their separate originating runs and hashes.
`comparison-settings.json` records per-quantity precision policy. These are
captured experiment settings, never universal Zemax defaults.

`capability-inspection/` contains 12 separate captures: four spot layouts and
eight definition/image audits. `inspectionOnly`, support and result-channel
audits prohibit treating these as numeric agreement. Image Simulation exports
a bitmap; Geometric Image GreyScale, Partially Coherent and Extended Diffraction
expose grids. A returned channel does not establish aligned input settings.

Extended Source Encircled Energy uses the owned uniform 3×3 IMA, copied as
`source-image.IMA` and hashed in its canonical request. It represents area
pixels, not nine isolated point sources. Workbench uses deterministic subpixel
sampling; the native Monte Carlo sample is frozen, not regenerated by tests.

RMS: radial GQ order 6, explicit Workbench angular count 12 for this experiment.
Native angular sampling is not exposed. General Core defaults remain 6, and the
primary baseline uses its own explicit settings. No benchmark values are read
by product code to choose an algorithm or parameter.

Offline tests recalculate current Workbench results from `source.ZMX`. Passing
precision contracts must remain Pass under the unchanged public tolerances.
For open Close/Difference cases, regression tests separately limit previously
measured error; a green non-regression test is **not a precision pass**. The
two original Huygens discrepancies are explicitly named in ExtendedAnalysisTests;
the remaining appended contracts use `additional-regression-expectations.json`.
Current conclusions and physical limitations are in
[the expansion report](../../../../docs/ZEMAX_ANALYSIS_EXPANSION_2026-09-06.md).

Historical absolute paths inside native reports/requests record provenance.
Tests resolve the local fixture/source image instead of depending on those paths.
No production project references this directory. Do not silently overwrite or
regenerate these captures; add a separately dated capture for changed settings.
