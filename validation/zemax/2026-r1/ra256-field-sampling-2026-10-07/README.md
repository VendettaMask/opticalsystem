# Independent RA256 field-scan controls

Six licensed OpticStudio 26.1.0 build 260127 RMS-vs-field captures cover five original official sources: Tessar with vignetting factors removed and retained, Cooke, Double Gauss, finite/aimed Relay and Even Asphere. Each curve has 16 captured field positions. The 54 source/snapshot/request/native array/report/CFG/readback/environment files are frozen by `manifest.json`; these controls are counted separately from the original 132 comparisons and 17 earlier RMS controls.

Tests compare both unchanged captured snapshots and fresh imports of the same source bytes. Old snapshots deliberately retain the historical automatic-stop clipping mask. Correcting the importer never rewrites that evidence or silently removes explicit apertures from saved snapshots. A fresh Tessar import with factors removed additionally checks a 1e-6 micrometer residual bound to detect the former 46-ray rejection; the original comparison policy stays unchanged. Passing a whole curve does not certify pupil convergence, every clipping decision, wavefront sampling, polarization or other lens settings.
