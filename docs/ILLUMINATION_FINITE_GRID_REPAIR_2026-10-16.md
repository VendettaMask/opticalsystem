## 实现与独立控制

本机已授权 OpticStudio 2026 R1 build 260127 Enterprise API 实测。原四文件 256 项新捕获与冻结值完全一致，来源及原件保留在[此前本机复核](ZEMAX_NATIVE_DIFFRACTION_ADAPTER_REPAIR_2026-10-16.md)。本轮另建有限网格控制，使用已有理想薄透镜、矩形孔径和逐节点小遮挡，逐项隔离节点位置、边界权重及像面距离；没有修改原镜头。

通过控制观察到并显式实现的配置为：

- 有效密度 `d=min(Samp,100)`；原生 MFE 对 101/128 的单元格读回均为 100，直接求值和保存新副本再载入后也一致。
- 粗瞳网格整数半径为 `r=max(8,floor(d/2))-1`，仅使用圆内且通过实际孔径的光线确定像方范围。这解释低采样矩形孔径的边缘漏采和奇偶档位跳变。
- 像方范围相对中心扩展 1%，每轴使用 `-d..d` 的 `2d+1` 个节点。共享正式追迹逆解节点，不把瞳网格直接当作像方网格。
- 边缘积分权重为 `sin²(π×clamp(d×(1-ρ),0,1)/2)`，`ρ` 是该节点逆解后的归一瞳半径。这是离散积分权重，不能改写实际光线的变迹或传输功率。
- 以实际主光线像点为中心作一阶像点参考修正。若入射单位方向为 `v`、像点偏移为 `Δp`、有符号近轴参考瞳距为 `D`，使用 `v-(Δp-v*dot(v,Δp))/D` 后投影到像面切向轴，不再次归一化。

这是一组由控制推断的有限配置及一阶像差修正，不是已公开的完整原生私有算法，也不是任意三维出瞳模型。`D` 来自共享 Core 同波长近轴出瞳估计；有限非零参考距离是当前边界。折叠、重叠、无法追迹、逆解失败或超预算均明确拒绝，不回退近似。

EFNO/RELI 和主程序“相对照度”预设均接入 `FiniteImageCosine`，遵从镜头既有 `RayAimingEnabled`。控制发现强制统一开/关瞄准会引入额外差异，因此没有为各镜头另选最有利设置。通用 Core 构造器仍为原自适应物理积分；原均匀单元中心积分可显式调用，原物理功率策略保留。主程序发布实际积分模式及有效密度元数据。

偏振策略沿用[传输修复](ILLUMINATION_TRANSMISSION_REPAIR_2026-10-16.md)：Pol=0 忽略玻璃吸收/镀膜透射，保留折射、孔径和变迹；Pol=1 使用标量及 Jones 功率链。本轮原生矩阵是 Pol=0，不把软件偏振回归称作新原生偏振认证。
