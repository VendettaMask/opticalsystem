## 首版使用

1. 在主程序打开镜头，从实验室进入光学装调。首次打开自动计算。
2. 选择前端/后端观察及测量波长，点击“计算全部表面”。默认波长取当前镜头主波长。
3. 表格为每个实体表面列出顶点像、球心像；不包含物面和设计像面。“按找像位置排序”按数值位置从小到大排列。
4. 选择测量模式及表格行，点击“更新叉丝图像”。默认“附加测量物镜”支持有限共轭；“无穷远（平行光）”支持 ∞ 共轭，也能查看有限共轭表面在平行光下的实际返回状态。
5. 修改处方、打开其他文件或切换工作模式时，旧表格和旧图像立即清除。计算运行在后台，可以取消；过期计算不能覆盖新文档结果。

所有位置单位为 mm，零点为原设计的第一实体表面顶点，正向为设计 +Z；从后端观察时也不改变这个基准。表格给出测量光束的共轭位置，不是未经标定的仪器刻度。附加物镜模式给出该物镜位置，“找像位置偏移”的正向沿所选观察方向；无穷远模式给出自准直仪自身物镜位置，不虚构附加物镜位置。

## 无穷远与附加物镜模式

自准直仪的 **焦距** 和它对外观察的 **共轭距离** 是不同参数。无穷远模式下，自准直仪物镜仍有有限焦距（默认 200 mm），叉丝位于其焦面，每个叉丝点经共享 Core 薄透镜模型形成相应方向的平行光束；无需也不允许把物镜焦距填为 ∞。出射光经当前镜组到目标面反射，再经过前置镜片回到同一自准直仪物镜，成像到有限距离的探测面。

无穷远模式使用独立的 **仪器通光直径**（默认 4 mm）和 **物镜到入口顶点距离**（默认 100 mm）。后者从当前观察侧的入口实体面顶点量起，仪器放在镜组外侧；从后端观察也维持表格原 +Z 基准。移动仪器会改变光束覆盖和遮挡，不会把平行光改成有限焦点，不能代替有限共轭找像。

模式切换保留位置表，立即取消旧图像计算并清除旧图；非当前模式的参数隐藏且不参与计算。附加物镜模式选择 ∞ 行时，按钮禁用并提示切换模式；无穷远模式可以对该行模拟。无穷远模式选择有限共轭行时仍追迹真实返回状态，但明确提示 **未对焦到所选共轭**，不自动加入附加物镜或移动到虚构焦点。同一表面的顶点像/球心像行在无穷远模式下使用相同物理出射配置，区别在于所选找像条件是否匹配。

直接观察平面时可以形成清晰的返回叉丝像；其理想倍率不因轴向距离改变，但通光量可以变化。对于前置镜片后的内部表面，是否满足无穷远共轭由整条前置光路决定，不凭面型或表面名称判断。

## 计算依据和内核复用

计算实现位于正式共享 Core 的 `Analysis/Assembly/AssemblyConjugates.cs`，实验室窗口只消费 Application DTO。所有曲面求交、光线传播、反射、折射、材料折射率均调用原有 `OpticalSurface.TraceRayValue`、交互模型和材料模型；没有复制 Snell 定律或建立实验室专用追迹器，没有 Python 产品依赖。

找像位置用共享真实光线内核的高度/角度小扰动求一阶共轭：顶点条件为目标面交点高度为零；球心条件为光线在目标球面法向入射。采用原步长、半步长、四分之一步长，两次 Richardson 外推去除探测光线的二阶步长误差，并检查两次结果收敛；先外推残差导数、再求位置，避免真实无穷远共轭被探测光线的球差误判为有限大数或失败。这是共享内核结果的数值求导，不是另一套光学近似追迹器。这个结果明确是近轴找像位置，不宣称是有限孔径下经过最佳焦面优化的位置。有限孔径、指定离焦的实际几何返回像由完整往返路径另行采样。

回程访问前置表面的顺序反转，入射/出射介质互换；仅在分析副本上选择目标面的反射分支。既有追迹缓存和当前处方均不修改。

首版计算范围：共轴、球面/平面、轴向非负厚度的顺序处方，最多 256 个实体表面。前置镜面、未解析材料、偏心/倾斜、非球面和特殊面型显示具体不支持原因。相邻折射率相同且非镜面的界面显示“无界面反射像”。有限位置、无穷远、追迹失败和不支持分别报告，不用零或经验值代替。

**平面的球心在无穷远，但经过前置有光焦度的镜片后，其平行光条件在外部可能对应有限共轭。** 代码按实际前置光路计算，不把所有平面一律标为外部无穷远。∞ 共轭现可在无穷远模式下生成图像，附加物镜模式仍明确阻止不匹配的设置。

## 叉丝像和尺寸

初版焦距和叉丝参数经用户确认；无穷远模式新增的通光直径与距离为模拟初值，均可在窗口修改：

| 参数 | 默认值 |
| --- | --- |
| 理想测量物镜焦距/工作距离 | 100 mm |
| 理想自准直仪准直/成像透镜焦距 | 200 mm |
| 测量 NA（近轴，瞳半径 / 测量物镜焦距） | 0.02 |
| 明亮十字叉丝总长 / 线宽 | 1 mm / 0.02 mm |
| 找像位置偏移 | 0 mm |
| 方形探测面宽度 | 4 mm |
| 无穷远模式仪器通光直径 | 4 mm |
| 无穷远模式物镜到入口顶点距离 | 100 mm |

附加物镜模式是共用发射/接收光路的两片理想薄透镜，间隔固定 10 mm；无穷远模式只保留自准直仪自身的准直/成像透镜，不经过附加物镜。两种模式的叉丝和探测面均位于自准直仪物镜焦平面。薄透镜仍使用 Core 已有的 `ThinLensInteractionModel`；回程镜头坐标系朝向实际传播方向。真实仪器物镜、分光镜、机械零点尚未建模，因此这组默认参数不能解释成某台实际设备的标定值。

叉丝两个有限宽度臂分别采样，经测量头、前置镜片、目标面反射、前置镜片回程、测量头成像，累计到固定 320×320 探测网格。源叉丝采样随像素尺度调整，每臂沿长度 81–1025 点、沿宽度 3–33 点，各配 29 个圆瞳样本；是有界离散几何预览，极端倍率或极小探测范围可能欠采样。检查物理孔径、处方半口径及测量头瞳径，显示返回和入框光线数；测头将进入镜组时拒绝图像并说明工作距离不足。

图像坐标始终是探测面 mm，不会把每张叉丝自动拉伸到相同大小。显示的“近轴倍率”来自小离轴叉丝点的返回像，“名义像长”为该倍率下的总长；设置不匹配所选共轭时改标“主光线比例”，不把它解释为清晰像倍率。名义像长不代表离焦模糊范围，几何模糊直接体现在采样图像中。自共轭条件下名义倍率的绝对值接近 1 是正常现象，不人为放大不同表面的差异。

亮度仅作归一化几何可视化：不计算衍射、真实镀膜反射率、偏振、多重鬼像或相机响应。设计材料仍决定光线折射。这里的“真实几何光线”不代表已完成实际自准直仪的成像标定。
