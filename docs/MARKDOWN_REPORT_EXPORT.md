# 光学设计报告导出

更新日期：2026-11-04。

## 使用

顺序工作台打开 **数据库 → 设计报告 → 导出报告**，先进入设置窗口，沿用默认或已保存的选择和参数。**导出格式**提供 Word（`.docx`）、PDF（`.pdf`）、Markdown（`.md`）和 HTML（`.html`）四个选项；首次使用或旧设置未指定格式时默认 Markdown，之后保留用户保存或成功导出时选择的格式。可勾选当前模式的分析目录、逐项编辑参数，使用“常用分析 / 全选 / 清空”，选择二维、三维布局和“逐一导出所有配置”，并确认输出目录。“保存导出设置”只保存格式、分析选择、布局和参数；点击窗口内的 **开始导出** 才捕获当前工程、执行计算并写入所选格式。打开窗口、修改格式或设置、重复点击顶部入口都不会启动导出；重复点击仅显示已有窗口，保留当前设置和任务进度。

Word 的正文和表格可编辑，具有页眉、页码和内部目录链接；PDF 自动分页，嵌入中文字形和原字符映射，正文可选择，表格跨页重复表头。HTML 是带内嵌样式和图片的单文件，可离线打开，提供桌面侧边目录、窄屏重排和打印样式。这三种格式均无损内嵌报告 PNG，可以单独分享文件，不需要安装 Word 或调用外部转换程序来生成。Markdown 使用配套图片目录，便于继续编辑文本或纳入版本管理。四种格式基于同一份冻结结果与报告模型；正文覆盖工程概要、配置、分析结果、图片和失败说明，完整设置与原始记录按下文的显示方式及附录选项保留。

## 报告版式

四种格式共用已确认的工程报告结构：“独立封面 → 目录 → 系统概要 → 编号图页与原生数值表 → 计算记录”。HTML、PDF 和 Word 使用统一的石墨文字、钢蓝辅助色、浅灰表头与淡灰交替行，保留正式矢量 Logo、计算时间和页码。封面可重复展示选中的二维布局，正文图页保持统一比例；不把图表内容拼接成新的图。多配置在各自系统概要与分析条件中明确标识。无分析项目时只生成系统概要封面，不额外创建空目录或空附录。

四格式均保留焦距、F 数、总长和入瞳等概要，不导出逐面完整处方表，也不附带完整工程/处方 JSON（含曲面参数、求解定义及非序列对象原始定义）。旧设置中的表面数据报告和已退役的通用 Zernike 入口也会过滤；不改变独立工作台分析或工程保存功能。

HTML 提供完整目录、页码导航、原图预览与原始尺寸查看、独立计算记录窗口和 A4 打印样式，页面中全部资源内嵌，可离线使用。内置阅读脚本的 CSP 使用其规范化文本的 SHA-256，只允许这一固定脚本；用户文本始终编码，不参与脚本或模板解释。PDF 使用内嵌字体与无损 PNG，不依赖浏览器；目录预排得到真实页码和内部跳转。Word 使用原生可编辑表格、内部书签和 PAGEREF 页码、带 SVG 及兼容 PNG 的正式 Logo 页眉、页码字段，并显式禁止压缩原图。

PDF、Word与两种HTML正文/代码/公式的字体统一由`ProductFonts`、`DisplayTypography`和一次捕获的`DocumentTypography`管理；不再分别声明Arial、微软雅黑、Consolas或Cambria。普通主题正文默认Noto、代码JetBrains，异世界正文/代码固定Almendra；数学公式统一使用开源STIX Two Math，中文用户内容保留补字。Word采用OOXML字体表/odttf，HTML内嵌字体data资源和许可，完整中文字体会增加文件体积。字号、页框、原图比例和表格数值沿用各自排版规则，文字家族更换后的宽度由实际选中字形测量。自选系统字体的便携回退和固定图形边界见[字体方案](TYPOGRAPHY.md)。

Markdown 使用同样的内容结构、向量 Logo 资源、章节链接、表格、编号图注和可折叠计算记录。正文数值表完整保留，不截取前 12 行，也不把系数表改成文字截图；字体、颜色和实际分页由阅读器控制。HTML 在固定纸页中分页显示原生数值表，PDF/Word 重复表头；这些排版只作用于文档文字与表格。

所有图页使用纵向 A4，整图统一为约 **184.60×138.53 mm**（含边框），保持原始长宽比与无损像素。图面不拆分子图、不替换图例或改字号；完整 Logo 图签、波长颜色与整图边框保留。文档空间不足时移动整张图，正文指标和长表另行分页。原始设置、完整结果、执行器、请求指纹和原始文本保存在 HTML/Markdown 的计算记录中；Word 与 PDF 默认采用相同的正文范围，需要时勾选“附加详细计算记录（增加页数）”。数千行原始采样不会自动扩充纸面报告，完整系数表仍始终列于正文。

### Zernike 公式

Fringe、Standard 和 Annular 正文表格均包含“序号、n、m、公式、系数 / 波”五列，完整保留所请求的项数。公式与拟合来自同一共享 Core 基底：Fringe 使用非单位 RMS 基底，Standard 包含对应的归一化因子；Annular 依据本次实际遮拦比 ε，从拟合使用的径向递推展开，并注明 **u = (2ρ² − 1 − ε²)/(1 − ε²)** 与 **ε ≤ ρ ≤ 1**。仅整理公式显示精度，不改变基底求值、系数拟合、OPD 或波前统计。

Word 的公式列使用可编辑的原生 OMML，包含真正的上标和根式；HTML 使用上标，PDF/Markdown 使用可读数学符号。没有新增 Zernike 重建图或系数柱形图。定义核对参考 [Ansys Fringe](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26103/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Zernike_Fringe_Coefficients.html)、[Standard](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26103/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Zernike_Standard_Coefficients.html) 和 [Annular](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26103/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Zernike_Annular_Coefficients.html)；这不代表新取得全部商业软件数值认证。

分析图和二维/三维布局统一采用所选4:3（1200×900 DIP）或16:9（1600×900 DIP）源图；默认自动按各绘图区可用宽高选择，保留手动固定比例。独立报告没有实时绘图区时，自动模式按所设导出画布比例选择稳定版式；等比例坐标图使用相同的原始内部布局，宽版只增加两侧留白，不改变坐标范围，绘图区高 740 DIP、图签高 160 DIP；屏幕及导出均显示四周 1 DIP 外框。报告内原图默认高1080像素，宽度按所选源图含外框的比例取整（4:3为1440、16:9为1919像素），保持所选比例与既定纸面图框；宽版在相同纸面宽度下的文字相应较小。“格式与字体”中的像素高度及独立打印 DPI（默认150）控制报告图像质量。普通PNG导出的可调整画布草案默认1920×1080，将同一完整图框居中留白；报告不嵌入这层画布留白，以免缩小纸面绘图和文字。工作台默认将同一源图完整等比适应窗口，也可选100%原生滚动；导出不随显示倍率、窗口或屏幕缩放改变源图规格。报告按选定设置计算后使用同一绘图构造器；保存时不缩字、裁切或二次排版。子图或文字超过固定图框时明确提示该项失败，可减少同时显示的视场/子图或减小用户设置字号后重试。纯文字报告的分页截图及实体模型不采用该固定规格。

PDF 直接内嵌完整源 PNG，以固定纸面尺寸等比放置，不进行像素降采样或有损 JPEG 重编码。源图规格和共享文字样式一致，因此纸面上的图签、Logo 和同类文字大小也一致。高斯 28° 的七张图已核对实际物理尺寸与内嵌像素；见[PDF 尺寸验证及桌面样例](../validation/rechecks/2026-10-30/pdf-uniform-figures/README.md)和[源图验证](../validation/rechecks/2026-10-30/uniform-source-diagrams/README.md)。内部子图仍按各分析语义排布，不强行把单图、矩阵及成对扇形的坐标区变成相同尺寸。

选择 PDF 时可勾选“附加详细计算记录（增加页数）”，默认关闭，旧设置未指定时也关闭。勾选后附加完整分析参数、执行器/请求指纹、原始分析文本和分析数值记录，不加入完整处方。该选项随导出设置保存与回读；切到其他格式时隐藏，并保留原有 Word/Markdown/HTML 内容行为。

Word/PDF/HTML 的数值表使用浅灰绿色表头（#EAF1EF）、深灰绿文字、白色与极浅灰绿隔行（#F7FAF8）和细灰绿边线，HTML 打印沿用同一配色。Markdown 的表格颜色由阅读器主题决定。Word 目录可跳转到章节，主配置与附录从新页开始。Word/Markdown/HTML 的纯文本分析分页截图仍进入附录；PDF 的此类分析使用原生文字和表格，避免将长文本缩成图片。

离焦点列图按图例实际测量宽度检查源图边界，不再始终为短波长标签预留最大图例宽度；默认 5 列 × 3 视场完整保留，仍拒绝真实超框。非相干照度优先采用探测器实际物理孔径；桌面默认启用“无物理孔径时按表面半口径采样”，仅在孔径为空时以实际表面半口径建立方形分箱窗口，报告注明窗口来源与范围。该窗口不添加物理遮挡，不改镜头处方；已有物理孔径、上游透过损耗和入射功率定义保持。窗口外的入射光线不计入该窗口的照度。严格 Core API 默认仍要求物理孔径，未知物理孔径不能被窗口替代。

以上离焦图边界和照度窗口修复位于共享绘图/应用分析入口，覆盖**界面显示、普通 PNG 保存、Word、PDF、Markdown 和 HTML 报告**。报告格式不选择另一套绘图排版或孔径算法；四种格式复用同一完整源图，Word 内嵌 PNG、HTML 内嵌图片及 Markdown 资源图均保留源像素，PDF 同样无损内嵌。PDF 纸张分页和目录页码属于文档本身；Markdown 表格配色仍取决于阅读器主题。

赛德尔系数与 Zernike Fringe、Standard、Annular 系数均按数值报告处理。即使计算结果含有辅助系列数据，也不把它们误判为绘图或转换成文字图片；四种格式均直接输出原生系数表；三类 Zernike 系数表均包含对应公式。

默认分析为 **点列图、光线扇形图、傅里叶 MTF、场曲/畸变**。选择依据是[亚利桑那大学 OPTI 517 设计过程课程](https://wp.optics.arizona.edu/jsasian/wp-content/uploads/sites/33/2019/10/Opti-517-Design-Process-Example-2019.pdf)中联合使用的几何与衍射评估图；这是本产品的报告预设，不是所有设计的统一验收标准。其余报告支持的分析可从目录勾选，表面数据报告不在导出范围内。

未设置报告专用参数时复用工作台已保存的分析设置；配置窗口可重新指定视场、波长、采样等选项。切换分析结构会刷新对应的参数选项。报告采用共享操作状态组件，按已完成项目数显示确定进度，长任务可取消。

有源文件时，默认输出目录为当前打开文件所在目录；未保存工程默认使用系统文档目录，可手动选择目录，无须先保存工程。文件名称示例：`镜头_report_20261029_203040_123.docx`，扩展名随所选格式自动确定。Markdown 的配套图片保存在同名 `_assets` 目录，复制或分享时同时携带该目录；Word/PDF/HTML 内嵌图片，完成后清理本次临时图片。重复时间戳会增加后缀，不覆盖旧报告。输出目录需要有写入权限。

## 内容与边界

- 四格式保留 EFL/F/#/TTL/入瞳直径概览，均不含逐面处方表或完整工程/处方 JSON。Word/Markdown/HTML 继续记录源路径、UTC 偏移、修订号与未保存状态；PDF 首页使用简洁身份和日期，内部计算来源仅在显式详细附录中提供。
- 二维、三维布局来自共享可视化服务；分析截图使用工作台相同的绘图构造器。导出完整绘图与页脚，文本分析分页截图，不捕获工具栏或整个桌面。
- 二维、三维布局图片与工作台复用完整图签：图名、同一快照的生成时间与结构/光学参数，以及正式公司标志、软件版本、工程文件名和名称；Word、PDF、Markdown、HTML 均保留这些内容。实体模型的紧凑参数栏和材质图例保持原状。
- 四种格式的全部报告图片（布局和分析图）统一带整图外边框，完整包住图面与图签。边框为主题适配的 1 DIP 细线，原图外侧各增加 1 DIP，不裁切内容；与相机 PNG 使用同一套导出绘制逻辑。
- 每个分析使用实际合并后的设置并保留实际配置范围。Word 和 PDF 默认正文只显示必要条件、概要指标和完整分析图/原生表格；完整参数、执行器、请求指纹和原始文本需显式启用详细附录，HTML/Markdown 保留可展开的完整记录。
- “逐一导出所有配置”逐配置生成独立系统概览、布局与分析；此时分析配置设为当前迭代配置。配置窗口其余选项仍沿用相同分析设置，不自动替换不存在的视场/波长。
- 导出开始捕获独立的完整工程工作区，后续编辑不会混入正在导出的报告。导出不保存或切换源工作区，不清除未保存标记。布局使用报告标准视角，分析按选定设置重新计算，不复制可能过期的已打开页面。
- 支持从当前模式的分析目录选择报告支持的项目，过滤表面数据报告与已退役分析；已有分析不适用、输入文件缺失或计算/截图失败时，报告明确记录该项失败并继续其他项目，不声明全部成功。图像模拟等外部输入仍需提供有效文件；其输出图像自动写到报告附件，避免覆盖既有分析输出。
- 进度条按实际完成项目数更新，并显示当前项目。导出期间格式和内容设置锁定，取消仍可用。取消会停止后续计算或文档生成并清理本次未发布内容；已有报告保留。四种格式均先在目标目录暂存，再发布成品；Markdown 在附件就位后最后发布 `.md`。图片、文本和文档写入均有大小上限，PDF 最多 1000 页。
- 这是设计报告，不是完整工程备份或版本库；原生工程仍用 `.staropt` 保存。报告入口位于顺序工作台的“数据库”，不增加启动页签；普通分析与二维/三维相机 PNG 采用上述统一源图规格。

## 实现

`IWorkbenchApplication.CaptureReportSnapshot` 在工作区锁下捕获所有配置、活动配置、非序列文档与多配置行表，然后构造独立工作区。App 保留 `MarkdownReportSettings` 设置存储；格式与纸面详细记录选项均可回读；为兼容旧设置，保存字段仍使用 `PdfIncludeDetails`，现在同时控制 Word/PDF 的详细附录。`MarkdownReportExporter` 编排计算和原子发布，`DesignReportContent` 保存共享内容，`DesignReportPdfModel` 保存共享的报告语义，`DesignReportPresentation` 将同一计算结果整理为四格式共用的封面、目录、分析图页与完整数值表，不重新计算物理量，也不把用户文本重新解释为 Markdown。Word 使用 .NET ZIP/XML 写出 OOXML，PDF 使用现有 SkiaSharp 与公共字体注册表；`ReportImageRenderer` 与工作台共用 `UniformDiagramPage` 和绘图构造器，PDF图像在隔离的浅色作用域绘制，不改变源图几何、字号或工作区主题，文档正文使用输出开始时捕获的字体策略。没有增加产品运行时依赖、Python、Office 进程、外部光学软件或第二套光学公式。

测试和截图证据见 `validation/rechecks/2026-10-24/markdown-report/`。当前验证范围与最终结果以[当前状态](CURRENT_STATUS.md)为准。
