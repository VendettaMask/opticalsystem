# 光学设计报告导出

更新日期：2026-10-30。

## 使用

顺序工作台打开 **数据库 → 设计报告 → 导出设计报告…**，先进入设置窗口，沿用默认或已保存的选择和参数。**导出格式**提供 Word（`.docx`）、PDF（`.pdf`）、Markdown（`.md`）和 HTML（`.html`）四个选项；首次使用或旧设置未指定格式时默认 Markdown，之后保留用户保存或成功导出时选择的格式。可勾选当前模式的分析目录、逐项编辑参数，使用“常用分析 / 全选 / 清空”，选择二维、三维布局和“逐一导出所有配置”，并确认输出目录。“保存导出设置”只保存格式、分析选择、布局和参数；点击窗口内的 **开始导出** 才捕获当前工程、执行计算并写入所选格式。打开窗口、修改格式或设置、重复点击顶部入口都不会启动导出；重复点击仅显示已有窗口，保留当前设置和任务进度。

Word 的正文和表格可编辑，具有页眉、页码和内部目录链接；PDF 自动分页，嵌入中文字形和原字符映射，正文可选择，表格跨页重复表头。HTML 是带内嵌样式和图片的单文件，可离线打开，提供桌面侧边目录、窄屏重排和打印样式。这三种格式均无损内嵌报告 PNG，可以单独分享文件，不需要安装 Word 或调用外部转换程序来生成。Markdown 使用配套图片目录，便于继续编辑文本或纳入版本管理。四种格式共用同一份报告内容和计算结果，覆盖相同的工程元数据、系统概览、分析参数、配置、分析结果、图片和失败说明。

## 报告版式

Word/Markdown/HTML 按“标题与工程名称 → 报告概览 → 目录 → 各配置的系统概览与图表 → 执行结果 → 分析参数与计算记录附录”组织。PDF 使用专门的纸面模型：紧凑系统概览和项目执行状态置于首页，随后按分析主题独立分页。四格式均保留焦距、F 数、总长和入瞳等概要，不导出逐面处方表，也不附带完整工程/处方 JSON（含曲面参数、求解定义及非序列对象原始定义）。导出分析列表不提供“表面数据报告”，旧设置中的该项及别名也会过滤；工作台独立的表面数据分析和工程保存功能保留。

Word/Markdown/HTML 正文优先呈现图表与可读数据表；超过 80 行的表格明确显示前 12 行节选，完整分析数值保留在附录。指标超过 8 项时同样明确标注正文范围，并保留完整指标。分析原始文本、运行参数、执行器与请求指纹保留在这些格式的附录；没有分析记录时不生成空附录。

PDF 首页显示工程文件名、日期、系统概要和视场/波长，不列完整路径、工程修订或请求指纹。原“报告内容”状态表改为目录：逐项列出标题、实际起始页码并支持点击跳转，多配置注明配置，长目录自动续页；勾选详细记录时附录也进入目录。分页预排只计算页码，不重复光学分析或重新排版源图。所有图页使用纵向 A4，整图统一为约 **184.60×138.53 mm**（含边框），按同一比例直接放置完整源图，不随页面剩余空间或概要指标数缩小。空间不足时将整图移至下一页，指标和长文字另行分页；纯数值宽表仍可使用横向 A4。图面不拆分扇形图、替换图例或改字号，完整 Logo 图签、波长颜色与整图边框保留。每项最多显示五个概要指标，数值仅作显示精度整理，纯数值分析使用可选择的原生表格。

分析图和二维/三维布局统一采用 1200×900 DIP 的源图，绘图区高 740 DIP、图签高 160 DIP；默认以 2 倍像素密度生成 2404×1804 PNG（含四周 1 DIP 边框）。工作台显示与普通相机导出使用同一张源图，窄窗口滚动查看，不随窗口或屏幕缩放改变图面规格。报告按选定设置计算后使用同一绘图构造器；保存时不缩字、裁切或二次排版。子图或文字超过固定图框时明确提示该项失败，可减少同时显示的视场/子图或减小用户设置字号后重试。纯文字报告的分页截图及实体模型不采用该固定规格。

PDF 直接内嵌完整源 PNG，以固定纸面尺寸等比放置，不进行像素降采样或有损 JPEG 重编码。源图规格和共享文字样式一致，因此纸面上的图签、Logo 和同类文字大小也一致。高斯 28° 的七张图已核对实际物理尺寸与内嵌像素；见[PDF 尺寸验证及桌面样例](../validation/rechecks/2026-10-30/pdf-uniform-figures/README.md)和[源图验证](../validation/rechecks/2026-10-30/uniform-source-diagrams/README.md)。内部子图仍按各分析语义排布，不强行把单图、矩阵及成对扇形的坐标区变成相同尺寸。

选择 PDF 时可勾选“附加详细计算记录（增加页数）”，默认关闭，旧设置未指定时也关闭。勾选后附加完整分析参数、执行器/请求指纹、原始分析文本和分析数值记录，不加入完整处方。该选项随导出设置保存与回读；切到其他格式时隐藏，并保留原有 Word/Markdown/HTML 内容行为。

Word/PDF/HTML 的数值表使用浅灰绿色表头（#EAF1EF）、深灰绿文字、白色与极浅灰绿隔行（#F7FAF8）和细灰绿边线，HTML 打印沿用同一配色。Markdown 的表格颜色由阅读器主题决定。Word 目录可跳转到章节，主配置与附录从新页开始。Word/Markdown/HTML 的纯文本分析分页截图仍进入附录；PDF 的此类分析使用原生文字和表格，避免将长文本缩成图片。

离焦点列图按图例实际测量宽度检查源图边界，不再始终为短波长标签预留最大图例宽度；默认 5 列 × 3 视场完整保留，仍拒绝真实超框。非相干照度优先采用探测器实际物理孔径；桌面默认启用“无物理孔径时按表面半口径采样”，仅在孔径为空时以实际表面半口径建立方形分箱窗口，报告注明窗口来源与范围。该窗口不添加物理遮挡，不改镜头处方；已有物理孔径、上游透过损耗和入射功率定义保持。窗口外的入射光线不计入该窗口的照度。严格 Core API 默认仍要求物理孔径，未知物理孔径不能被窗口替代。

以上离焦图边界和照度窗口修复位于共享绘图/应用分析入口，覆盖**界面显示、普通 PNG 保存、Word、PDF、Markdown 和 HTML 报告**。报告格式不选择另一套绘图排版或孔径算法；四种格式复用同一完整源图，Word 内嵌 PNG、HTML 内嵌图片及 Markdown 资源图均保留源像素，PDF 同样无损内嵌。PDF 纸张分页和目录页码属于文档本身；Markdown 表格配色仍取决于阅读器主题。

赛德尔系数与 Zernike Fringe、Standard、Annular 系数均按数值报告处理。即使计算结果含有辅助系列数据，也不把它们误判为绘图或转换成文字图片；PDF 直接输出可选择的原生系数表，其他格式继续保留对应数值内容。

HTML 同时适配宽屏和窄屏，宽表在自身区域横向滚动；打印使用 A4、浅色表头和黑色文字。附录可手动折叠，默认展开以保留完整打印内容。文件只使用内嵌资源，用户文本经过 HTML 编码，并配置禁止外部资源和脚本的内容安全策略。Markdown 使用标题层级、章节链接、表格、编号图注和可折叠附录；支持 HTML `details` 的阅读器可折叠原始记录，字体和颜色由阅读器主题决定。

默认分析为 **点列图、光线扇形图、傅里叶 MTF、场曲/畸变**。选择依据是[亚利桑那大学 OPTI 517 设计过程课程](https://wp.optics.arizona.edu/jsasian/wp-content/uploads/sites/33/2019/10/Opti-517-Design-Process-Example-2019.pdf)中联合使用的几何与衍射评估图；这是本产品的报告预设，不是所有设计的统一验收标准。其余报告支持的分析可从目录勾选，表面数据报告不在导出范围内。

未设置报告专用参数时复用工作台已保存的分析设置；配置窗口可重新指定视场、波长、采样等选项。切换分析结构会刷新对应的参数选项。报告采用共享操作状态组件，按已完成项目数显示确定进度，长任务可取消。

有源文件时，默认输出目录为当前打开文件所在目录；未保存工程默认使用系统文档目录，可手动选择目录，无须先保存工程。文件名称示例：`镜头_report_20261029_203040_123.docx`，扩展名随所选格式自动确定。Markdown 的配套图片保存在同名 `_assets` 目录，复制或分享时同时携带该目录；Word/PDF/HTML 内嵌图片，完成后清理本次临时图片。重复时间戳会增加后缀，不覆盖旧报告。输出目录需要有写入权限。

## 内容与边界

- 四格式保留 EFL/F/#/TTL/入瞳直径概览，均不含逐面处方表或完整工程/处方 JSON。Word/Markdown/HTML 继续记录源路径、UTC 偏移、修订号与未保存状态；PDF 首页使用简洁身份和日期，内部计算来源仅在显式详细附录中提供。
- 二维、三维布局来自共享可视化服务；分析截图使用工作台相同的绘图构造器。导出完整绘图与页脚，文本分析分页截图，不捕获工具栏或整个桌面。
- 二维、三维布局图片与工作台复用完整图签：图名、同一快照的生成时间与结构/光学参数，以及正式公司标志、软件版本、工程文件名和名称；Word、PDF、Markdown、HTML 均保留这些内容。实体模型的紧凑参数栏和材质图例保持原状。
- 四种格式的全部报告图片（布局、分析图和分页文字截图）统一带整图外边框，完整包住图面与图签。边框为主题适配的 1 DIP 细线，原图外侧各增加 1 DIP，不裁切内容；与相机 PNG 使用同一套导出绘制逻辑。
- 每个分析使用实际合并后的设置并保留实际配置范围。PDF 默认正文只显示必要条件、概要指标和分析图/原生表格；完整参数、执行器、请求指纹和原始文本需显式启用详细附录，其他三格式继续保留完整分析记录。
- “逐一导出所有配置”逐配置生成独立系统概览、布局与分析；此时分析配置设为当前迭代配置。配置窗口其余选项仍沿用相同分析设置，不自动替换不存在的视场/波长。
- 导出开始捕获独立的完整工程工作区，后续编辑不会混入正在导出的报告。导出不保存或切换源工作区，不清除未保存标记。布局使用报告标准视角，分析按选定设置重新计算，不复制可能过期的已打开页面。
- 支持从当前模式的分析目录选择报告支持的项目，过滤表面数据报告与已退役分析；已有分析不适用、输入文件缺失或计算/截图失败时，报告明确记录该项失败并继续其他项目，不声明全部成功。图像模拟等外部输入仍需提供有效文件；其输出图像自动写到报告附件，避免覆盖既有分析输出。
- 进度条按实际完成项目数更新，并显示当前项目。导出期间格式和内容设置锁定，取消仍可用。取消会停止后续计算或文档生成并清理本次未发布内容；已有报告保留。四种格式均先在目标目录暂存，再发布成品；Markdown 在附件就位后最后发布 `.md`。图片、文本和文档写入均有大小上限，PDF 最多 1000 页。
- 这是设计报告，不是完整工程备份或版本库；原生工程仍用 `.staropt` 保存。报告入口位于顺序工作台的“数据库”，不增加启动页签；普通分析与二维/三维相机 PNG 采用上述统一源图规格。

## 实现

`IWorkbenchApplication.CaptureReportSnapshot` 在工作区锁下捕获所有配置、活动配置、非序列文档与多配置行表，然后构造独立工作区。App 保留 `MarkdownReportSettings` 设置存储；格式与 PDF 详细记录选项均可回读。`MarkdownReportExporter` 编排计算和原子发布，`DesignReportContent` 保存共享内容，`DesignReportPdfModel` 将同一计算结果整理为纸面概览、分析页和关键指标，不重新计算物理量，也不把用户文本重新解释为 Markdown。Word 使用 .NET ZIP/XML 写出 OOXML，PDF 使用现有 SkiaSharp 与内嵌 Noto 中文字体；`ReportImageRenderer` 与工作台共用 `UniformDiagramPage` 和绘图构造器，PDF 仅在隔离的浅色作用域绘制，不改变源图几何、字号或工作区主题。没有增加产品依赖、Python、Office 进程、外部光学软件或第二套光学公式。

测试和截图证据见 `validation/rechecks/2026-10-24/markdown-report/`。当前验证范围与最终结果以[当前状态](CURRENT_STATUS.md)为准。
