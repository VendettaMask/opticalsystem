# Markdown 光学设计报告导出

更新日期：2026-10-24。

## 使用

顺序工作台打开 **数据库 → 设计报告 → 一键导出 Markdown**，按默认或已保存的设置立即导出。**报告导出设置**打开配置窗口，可勾选当前模式的分析目录、逐项编辑参数，使用“常用分析 / 全选 / 清空”，选择二维、三维布局和“逐一导出所有配置”。“保存导出设置”保存分析选择、布局和参数；配置窗口中的“一键导出 Markdown”也可直接执行。

默认分析为 **点列图、光线扇形图、傅里叶 MTF、场曲/畸变**。选择依据是[亚利桑那大学 OPTI 517 设计过程课程](https://wp.optics.arizona.edu/jsasian/wp-content/uploads/sites/33/2019/10/Opti-517-Design-Process-Example-2019.pdf)中联合使用的几何与衍射评估图；这是本产品的报告预设，不是所有设计的统一验收标准。其他分析均可从目录勾选。

未设置报告专用参数时复用工作台已保存的分析设置；配置窗口可重新指定视场、波长、采样等选项。切换分析结构会刷新对应的参数选项。报告采用共享操作状态组件，按已完成项目数显示确定进度，长任务可取消。

有源文件时，默认输出目录为当前打开文件所在目录；未保存工程默认使用系统文档目录，可手动选择目录，无须先保存工程。文件名称示例：`镜头_report_20261024_203040_123.md`，配套图片保存在同名 `_assets` 目录。Markdown 使用相对链接，复制或分享时同时携带该目录。重复时间戳会增加后缀，不覆盖旧报告。输出目录需要有写入权限。

## 内容与边界

- 报告包含源路径、时间及 UTC 偏移、软件版本、源修订号、未保存修改状态、EFL/F/#/TTL/入瞳直径、逐面处方和结构化系统/环境/视场/波长/面型设置。
- 二维、三维布局来自共享可视化服务；分析截图使用工作台相同的绘图构造器。导出完整绘图与页脚，文本分析分页截图，不捕获工具栏或整个桌面。
- 每个分析记录实际合并后的设置、计算执行器和请求指纹，并包含实际报告文本或数据表。指定不同分析配置时，报告列出实际配置范围。
- “逐一导出所有配置”逐配置生成独立处方、布局与分析；此时分析配置设为当前迭代配置。配置窗口其余选项仍沿用相同分析设置，不自动替换不存在的视场/波长。
- 导出开始捕获独立的完整工程工作区，后续编辑不会混入正在导出的报告。导出不保存或切换源工作区，不清除未保存标记。布局使用报告标准视角，分析按选定设置重新计算，不复制可能过期的已打开页面。
- 支持从当前模式的分析目录选择全部项目；已有分析不适用、输入文件缺失或计算/截图失败时，报告明确记录该项失败并继续其他项目，不声明全部成功。图像模拟等外部输入仍需提供有效文件；其输出图像自动写到报告附件，避免覆盖既有分析输出。
- 进度条按实际完成项目数更新，并显示当前项目。取消会停止后续计算并清理本次未发布内容；已有报告保留。报告暂存于目标目录，附件就位后最后发布 `.md`。图片和文本写入沿用有界原子文件工具。
- 这是设计报告，不是完整工程备份或版本库；原生工程仍用 `.staropt` 保存。报告首版界面入口位于顺序工作台的“数据库”，不增加启动页签，不改变原有 PNG 导出。

## 实现

`IWorkbenchApplication.CaptureReportSnapshot` 在工作区锁下捕获所有配置、活动配置、非序列文档与多配置行表，然后构造独立工作区。App 中 `MarkdownReportExporter` 编排计算、目录发布、失败记录和 Markdown；`ReportImageRenderer` 在 UI 线程使用现有场景控件和 `AnalysisPanel` 共享绘图构造器渲染 PNG。未增加 Python、外部光学软件或第二套光学公式。

测试和截图证据见 `validation/rechecks/2026-10-24/markdown-report/`。当前验证范围与最终结果以[当前状态](CURRENT_STATUS.md)为准。
