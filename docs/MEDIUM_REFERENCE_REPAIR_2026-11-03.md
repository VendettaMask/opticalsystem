## 修复的共性根因

1. **晶体穿越参考面时丢失所在介质**。保留的坐标断点之前使用普通折射模型，批量路径会把已经定位的晶体状态替换成无坐标的声明材料；标量路径则拒绝没有显式晶体界面的材料。现在使用明确的坐标参考面交互，延续实际入射介质、全局晶轴、相位折射率及连续介质体坐标，不产生新的折射界面。真正晶体边界仍要求入口坐标和显式双折射模型，偏振与各向异性镀膜的既有拒绝保持。
2. **零厚度坐标断点上的 STOP 被折叠**。导入器现在保留实际光阑参考面，包含配置选择的光阑；Toroid 的入瞳不再被错误地从整个系统传输矩阵估计。真实孔径、光线发射和能量积分未通过取消裁光来制造通过。
3. **零半径遮挡错误地遮住一个中心点**。`OBSC 0 0` 现在是空遮挡，含偏心时也不会产生幽灵遮点；有限半径遮挡及其边界保持。
4. **环曲面旋转半径参数槽位错误**。按原生定义，旋转半径属于 PARM 1，PARM 2 起是非球面系数；导入、单位换算、表面光焦度识别和 ZMX 导出已统一。矢高改用避免大半径相减的稳定式，法向使用解析导数，超出实数矢高域返回无效。非零锥常数、非球面系数和活动 Zernike 项仍明确不支持，未作为半径吞掉。参数依据见 [OpticStudio 2026 R1 Toroidal 官方定义](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Toroidal.html)。

能量绘图同时为零个/一个累计节点增加边界处理，避免负计数或不适用的样条调用；空曲线没有伪造为有效能量。

新的参考面类型也纳入原有同顶点曲面回溯规则。第一次跨系统复验暴露了遗漏该规则造成的 Yolo 失败；补齐后，最终 426 项按原分类逐项保持。没有保留这项中间退化作为最终状态。
