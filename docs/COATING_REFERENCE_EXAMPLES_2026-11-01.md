# 截图中的五套镀膜示例

来源为已保存的 TFStudio `8b942b3f956728a23cea2b35023c8b5d8de17428` 的 `web/demo-examples.js`，与用户截图中的五个名称、15层高反和58.5/94.2 nm厚度一致。没有使用另一个 `sampleDesigns.js` 的11层名义高反，也没有用本地Ta₂O₅/SiO₂生成器代替原TiO₂膜系。

## 菜单与原处方

“示例”菜单首先提供五个参考示例，随后以分隔线保留原有三个设计目标模板。选择参考示例直接装入完整原膜层并调用共享 Core 计算，不生成新结构、不先优化或修改膜厚。原有模板及其真实吸收、协议和验收不变。

| 参考示例 | 入射侧 → 基板侧的物理膜厚（nm） |
| --- | --- |
| 宽带减反膜，4层 | MgF₂ 86.19 → Ta₂O₅ 118.07 → SiO₂ 387.70 → Ta₂O₅ 134.23 |
| 边缘滤光片 | (Ta₂O₅ 64.0 → SiO₂ 94.2) × 10，共20层 |
| 高反膜，TiO₂/SiO₂ | (TiO₂ 58.5 → SiO₂ 94.2) × 7 → TiO₂ 58.5，共15层 |
| 金属反射镜 | Ag 120.0 → SiO₂ 80.0，共2层 |
| 单层减反膜 | MgF₂ 99.6 |

原材料为 Air、BK7 (Schott)、SiO₂ (Fused Silica)、MgF₂、TiO₂ (anatase，Jolivet)、Ta₂O₅ (Bright-amorphous)、Ag。保留原色点、Sellmeier系数、原始n/k节点、PCHIP规则、BK7由内透射率导出的微小k，以及源文件中原本为零的k；不以旧Rodríguez-de Marcos实测表或新的拟合常数替换。

基板为BK7、厚1 mm，出射介质Air，参考波长550 nm，`front_only`/`mfEvalMode=side`。这些来源字段及原始英文名称/注记保存于实验的可选 `ReferenceExample` 字段。当前曲线与参考的“忽略另一面”一致，计算前面膜系进入半无限基板的R/T/A；没有将1 mm基板传播和背面反射加入侧面评价，也不宣称支持完整双面系统。Ag原始序列按源文件保存，未依据注记中的“protective overcoat”文字交换两层。

参考示例没有给出优化验收目标。桌面继续提供原产品的减反/高反默认比较目标，保留原门槛；状态栏和指标说明明确其为本地比较目标，不能把它们说成参考软件规定的达标要求。

## 材料域与持久化

共享 Core 新增显式版本化色散标识 `tabulated nk pchip-clamped/1` 与 `formula 2 pchip-k-clamped/1`。PCHIP在原节点精确取值，内部采用形状保持分段三次，表外延用端点。现有 `tabulated nk` 的线性插值及波段拒绝行为保持。

参考Ta₂O₅原始表为500–2475 nm，所以400–500 nm曲线是参考自身的端点延用，不是该波段的测量结果。新材料快照显式保存 `HoldTabulatedEndpoints`，仍记录真实原始有效范围；评估跨域时在图下提示“域外按参考模型延用端点（非实测）”。未声明该规则的旧材料仍由Engine和Core拒绝越界。没有伪造参考材料的有效波段，也没有以该行为修改原吸收材料的验收。

新规则随材料formula和原系数/表格保存，重开使用相同模型复算，不依赖全局目录或Node。旧文件中可选字段缺失时不写默认空值，保留原指纹兼容。材料表编辑器保存/复制参考表时保留PCHIP与显式端点规则；新建或导入普通CSV仍采用原线性、严格域规则。CSV仅携带原始节点，完整色散规则须以实验快照保存。旧运行时不支持新formula时会拒绝计算，不作为兼容重算环境。

## 验证入口

62/62项桌面及邻接回归通过；最后收紧解析n模型的有效域守卫后完整依赖重新构建零警告/错误，38/38项定向复验通过，包含全部五套处方及菜单、光谱设置/导出、原物理与旧文件检查。共63个不同用例身份，重跑不累计。七种材料的图下域外规则仅允许完整表格模型；BK7解析n仍限定原有效域，k表在其自身边界延用。实际离屏图像已核对，400 nm高反例子T=92.2373%、R=7.7627%，与用户截图相符。本批使用独立构建，未替换默认输出、重启用户窗口或完成系统原生桌面验收。

离线脚本实际执行未修改归档的 `demo-examples.js`、`materialDatabase.js`、`pchip.js` 与固定`tmmcore 0.4.2`，生成产品静态源数据及测试参考，记录三份源文件SHA-256。生产程序只加载静态JSON和C#共享Core，不加载上游JavaScript或Node。
