# Python 分析与绘图兼容

## 参考

参考环境固定为 Python Optiland 0.5.8 和仓库中的 Cooke/Tessar 夹具。Python 参考生成脚本位于 `tools/python-reference`，生成结果提交到测试夹具。只有有意更新固定依赖或契约时才重新生成。

## 数值契约

已建立来源契约的分析包括点列图、光线像差、单光线报告、离焦点列/MTF、场曲/畸变、RMS 扫描、主光线和质心/最佳拟合参考波前、Zernike、FFT/Huygens/几何/采样 MTF、FFT/MMDFT/Huygens PSF、辐射度、入射角、Jones 光瞳和图像模拟。

每项比较必须固定：

- 处方、视场、波长和孔径；
- 光瞳采样、参考方式和密度；
- 焦点/视场/波长扫描点；
- 输出单位和归一化；
- 可接受的绝对/相对误差。

不允许把产品预设或 Zemax 捕获设置写入 Core 通用构造函数。

## 绘图契约

`AnalysisSeriesDto` 和 `AnalysisPlotPaneDto` 描述曲线、散点、热图、光栅和多窗格。`AnalysisPresentationKind` 决定专用控件；`AnalysisAxisQuantity` 与 `AnalysisAxisUnit` 决定缩放、悬停和 CSV。标题和轴标签只用于显示。

图形回归关注：

- 面板数量和排列；
- 系列顺序、图例和颜色语义；
- 波长颜色按真实纳米值使用稳定的光学工程约定，不按系列序号轮换；Fraunhofer F/d/C 线 `486.1 nm`、`587.6 nm`、`656.3 nm` 分别使用蓝、绿、红。d 线绿色是工程辨识色，不代表其真实单色光外观；紫外/红外使用中性灰。视场、结构等分类色仍使用主题调色板，显式分类键优先于名称文本；
- 固定范围、零线和网格；
- 热图色标和方向；
- 光线像差图和瞳孔像差图由各自的展示契约按视场分组：每个视场的 `P_y` 与 `P_x` 紧邻显示，多个视场按数量自动形成平衡网格，末行居中；组合卡片内自动使用方形子图。瞳孔像差对所有视场、波长和 X/Y pane 使用共同的对称纵轴范围 `±scale`，`scale` 由全局最大绝对值向上取整到十进数量级，近零范围最低为 `1e-5%`；这只统一显示范围，不修改曲线数据。其它多子图使用各自的自动布局，结果区不提供手动方形切换。
- 全视场点列图、光迹图和干涉图使用方形外层视口并保持二维数据等比例；色焦移保留普通曲线图的自适应布局。独立“畸变”入口已退出，Python/Zemax 畸变数值契约由“场曲/畸变”组合页继续承载。
