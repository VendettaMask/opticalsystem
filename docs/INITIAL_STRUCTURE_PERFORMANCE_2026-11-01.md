# 自动初始结构固定口径性能对照

本轮推进搜索计划 M3.4。M3.5 准备续跑已交付，M3.3 自动口径继续保留计划状态。优化在共享 C# Core 和现有引擎内完成，不改变原 F/8 的口径、像质、制造规则、采样、阶段分配或总计算额度。原 F/4 仍因固定光阑与镜面口径冲突停止。

## 已实现的复用

按冻结基线的实际耗时定位热点：积分/边界光线及导数占主要计算，受约束求步和 QR 秩计算也有明显费用。正式实现只复用同一评价快照中的确定值：

- Core 几何工作区持有私有处方和参数快照，复用逐面位置、弧矢和斜率及其前向导数。每条原制造检查仍执行、计数；独立终验仍走原标量/Core 追迹路径。
- 光线微分上下文有界复用相同参数槽/值和面/波长的不可变前向标量。反向 tape 生命周期不读写这些缓存，不跨处方、参数、评价或工作线程共享。
- Core 前向切线采用双精度 CPU SIMD，乘法、加法顺序保持，短向量、尾部及无硬件加速时使用原标量路径。未使用低精度或 FMA 捷径。
- 同一个已接受评价对象的拒绝重试复用原 QR 秩；新评价立即重新计算。未采用近似秩或改变线性求解器、变量尺度、阻尼和接受规则。

可选测量器分别记录绑定、积分、边界、几何、求步和秩的包含式耗时。默认关闭，不写入计划/结果协议；仅诊断观察实际模型时复制矩阵。没有新增用户配置或切换原冷启动默认开关。

## 原任务五种子对照

输入沿用原 `competition-8-F8-full25.input.json`：八片、50 mm、F/8、全视场 25°、逐面通光/机械半径 5 mm、前置光阑半径 3.125 mm、像面 z=65 mm。原 21 视场、10×32 积分和边界检查，焦距/F 数 ±2%、RMS 50 µm、最大半径 150 µm、畸变 3%、有效率至少 98%、中心/边界零丢失及原制造/材料/轴向/面型权限均保留。

预先冻结两臂各自运行时和源代码；每臂五个独立冷启动，种子 42–46，单工作进程，顺序 46、42、43、44、45。每次原额度为 600 函数、600 梯度、1,000 万实际 CPU 光线、600 秒活动时间，原阶段上限不变。未导入开发终点或检查点，持久化/停止等待与活动计算分开。

种子 46 的几何累计耗时由 10.331 秒降至 1.864 秒；实际 QR 秩计算由 177 次降至 142 次。积分和边界合计耗时基本相近，不能把整体收益全部归因于 SIMD，求步计时也受系统/GC 状态影响。

## 尺度、阻尼与有界并行

辅助探针只导入冻结种子 46 的六阶阶段点，重新由当前 Core 建立实际线性模型，明确不计为独立冷启动或新增收益。原尺度/列范数尺度分别配合阻尼 0.001、0.01、0.1，共六组；每组均求解原不等式并执行真实评价和原完整终验。六组均不合格，仍存在原几何、RMS 或边界失光违例，没有据此更改正式尺度和阻尼。

相同实际点四次评价的有界吞吐对照：一工作线程 9.299 秒、CPU 9.672 秒；两线程 4.998 秒、CPU 9.484 秒。两组各 25,464 条实测光线，数值逐值一致，累计分配各约 19.2 GB。这只是局部评价的吞吐证据；尚未启用全局候选并行、并行预算调度或改变随机派发顺序。全部辅助探针另计 362,610 条实测光线，不回填冷启动预算。

上述正式冷启动和辅助探针均为 `cpu-forward-v1`，GPU 批次/光线为零，无 CPU 回退冒充 GPU。设备枚举可见 RTX 4060；另行模块回归的既有 CUDA 短程用例实际执行225条导数光线、9批次，并通过原 CPU 对照。它不证明本轮 F/8 GPU 性能或任意 GPU 范围；Core 专项另有4项受环境开关限制而跳过。既有 GPU 选项、适用域和回退行为保持，CPU 向量化不等于 GPU 或新光学批量后端。

## 验证与复现边界

Core定向70项通过，另4项CUDA环境开关跳过；模块/桌面逻辑去重184项通过，分别为首轮153项和恢复原夹具目录后31项重试，原失败保留。首轮Core的一项失败为测试将非球面改成球面却保留非球面参数，修正为合法非球面变更后通过，未改物理门槛。基线、候选和实际产品三个独立运行时各完成76次原完整验收和工程口径回读，均零错误。

原种子45在球面安全更新停止，使用同一候选内核的新进程恢复，与连续运行的RNG、候选池、阶段、处方、完整QA和全部离散预算精确一致。前后段实测光线141,606加289,194恰为430,800；累计活动时间61.756秒，原阶段与总配额均未重置。另1项实际产品会话通过停止、零追迹重开、续跑、单次自动交接、重复交接零新增追迹和原生文件原验收/逐面口径回读。该额外会话仅将后续自主主搜索限制为一次试验，准备仍使用原600/600/千万/600秒额度，不计入五种子冷启动比较。F/4原任务再次返回`OriginalExternalStopApertureConflict`，零函数、零实测光线。

默认Release主程序及两内置模块构建零警告/错误；Core、模块、产品和三套审计驱动的构建日志分别保存。候选模块回归6个、实际产品会话7个相关二进制前后哈希均无漂移，具体运行时各自封存。默认输出构建与临时目录驱动验证分开，不将辅助输出冒充产品默认构建。
