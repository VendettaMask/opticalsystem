# 镀膜联动编辑、历史与双面设计

本轮按[实施计划](COATING_EDITOR_DUPLEX_PLAN_2026-11-02.md)扩展C#镀膜工作区。单面实验继续使用原物理模型、优化协议与验收门槛；双面实验显式记录优化和评价对象，仍调用共享Core。实现后的定向验证范围将在[本轮记录](../validation/rechecks/2026-11-02/coating-editor-duplex/README.md)登记。

## 厚度编辑

每层仅保存物理厚度d（nm），四种列编辑同一物理值：

| 列 | 显示与换算 |
|---|---|
| 物理厚度 | d |
| 光学厚度OT | n(λ₀)d，单位nm |
| QW | 4n(λ₀)d/λ₀，无量纲 |
| FW | n(λ₀)d/λ₀，无量纲 |

转换使用当前材料快照在参考波长处的实折射率；不使用复折射率的模，也不混入斜入射余弦。输入OT/QW/FW会反算物理厚度，其余列更新。显示舍入不覆盖内部完整精度；单纯选中或原样提交显示值不改变原处方。

参考波长现已独立于设计中心保存，旧文件缺项以中心初始化；修改λ₀或材料保持物理厚度并重新派生显示。没有采用参考软件“改λ₀时保持QW并缩放所有物理厚度”的行为。无有效折射率或数值不合法时保留错误输入，阻止保存/计算或批量换算；不会使用上次的折射率继续转换。材料原有效域、显式端点延用和非实测提示保持。新增公式、跨实验剪贴板及草稿恢复见[工程操作](COATING_WORKFLOW_ANALYTIC_2026-11-02.md)。

## 多选和撤销重做

表格支持Ctrl/Cmd加选、Shift连续选择和“全选”。复制、删除、替换材料、上移/下移、反转层序、固定/释放、厚度设定与倍率调整作用于所选行。多选移动保留相对顺序；设定OT/QW/FW时每层按自己的折射率转换。全部候选厚度先校验，任何一层不合法则整批不提交。固定是优化变量开关，不阻止用户显式手动编辑。

窄窗口和小浮窗中，上方模式/工具/介质区可独立纵向滚动，膜层表保留编辑空间，新增工具不覆盖或挤出表格。大字号及四个厚度列沿用原横向滚动和数字字体，不缩小文字。

工具栏撤销/重做与Ctrl/Cmd+Z、Ctrl/Cmd+Y（或Shift+Z）使用镀膜设计历史，在浮窗中同样生效；批量操作为一步，连续输入按同一编辑字段合并，结束单元格编辑后形成边界。历史最多保留50个编辑状态，包含原数值、材料、两面层表和模式，并可恢复错误文本；不保存到实验文件。新编辑清除未来历史，打开文件清空历史，布局移动不成为处方编辑。

撤销/重做会立即撤销旧计算的写回资格并清除过期结果，恢复后的设计仍按正常计算/复验流程求值。历史不调用镜头文档事务，也不修改主镜头。

## 两面与评价对象

“启用双面设计”显式进入新文件语义。正面和背面层表各自从该面外侧向基板编号；完整光路从入射介质依次经过正面层表、有限基板、反向排列的背面层表和出射介质。切换编辑标签不交换物理入射方向，不改变处方，也不自动开始优化。

| 优化表面 | 可选评价对象 | 优化变量 |
|---|---|---|
| 正面 | 正面或整片 | 仅正面标记为变量的厚度 |
| 背面 | 背面或整片 | 仅背面标记为变量的厚度 |
| 两面 | 整片 | 两面的独立变量 |
| 对称双面 | 整片 | 正面一组变量，背面与正面链接 |

正面单独评价使用入射介质→正面膜系→半无限基板；背面单独评价使用出射介质→背面膜系→半无限基板，各自角度相对该面的外侧介质。整片评价的角度相对正面入射介质，内部所有界面共用守恒横向波矢，包含有限基板真实吸收和非相干无限次内部反射。膜层保持相干、各向同性；不产生厚基板的相干条纹。

无损体系的内部往返分母采用能量守恒等价式`Tr + Tb − Tr·Tb`并在对数域组合，避免两面极高反射时`1 − Rr·Rb`被舍入成零。该规则依据实际无损性质，对任意材料/层序通用，不清零k、不设置透射下限；有吸收体系继续使用真实反射与基板衰减求和。

对称表示两面从各自外侧看具有相同材料/层序/厚度和变量开关，背面标签只读，优化不重复创建变量。解除链接得到当前正面的独立副本；之前的独立背面可用撤销恢复。固定层、未选择优化的一面不被厚度优化改动；生成/结构搜索遇到固定层时保持对应面的结构。

显示光谱、正式评价、目标线、优化、公差与导出均读取同一评价对象。独立绘图波段/角度仍是显示设置，不能代替密集验收。整片T为进入出射介质的功率，A包含两面膜层和基板吸收；单面T为进入半无限基板的功率。旧schema1的“计入基板与背面”仍只改变显示，保留原正面验收；它不会被隐式升级。

## 优化与公差

原双面路径以`duplex-target-constraints/1`记录身份，使用现有DLS、Nelder-Mead或Coordinate Pattern Search执行有界厚度优化，指导值来自所选评价对象的真实R/T/A和原目标违反量。双面组合先作光谱筛选及短程优化，少数候选再作完整精化/密集验收；正式保留遵守原目标逐项超限保护。后续增加显式`Duplex.OptimizationVersion=2`的共享Core解析导数与目标恢复/质量阶段，旧文件缺项继续走v1；详见[新路径与实际成本](COATING_WORKFLOW_ANALYTIC_2026-11-02.md#双面解析与分阶段优化)。v2不宣称移植单面协议4的全部追加日程。

每面层数和物理厚度仍按原上限与原制造约束判断；波段最大/最低R、峰值T、峰位、实际FWHM、每侧最差OD及独立加密收敛条件保持。没有放宽门槛或清零材料k。候选完整保存两面，采用候选后清除旧结果再复验。

公差使用原分布、种子和厚度/角度误差定义，同时保存两面的实际采样膜厚。对称设计不等于两次镀制的误差完全相关；独立、同材料同步、全部同步由原相关性设置控制，试验可暂时解除设计链接以评价实际误差。固定层仍参与制造公差，无效样本计失败。

## 保存与导出

旧schema1输入指纹与缺省字段规则保持。双面文件使用schema2、`Duplex` v1、`BackLayers`和`StackGeometry`；两面及评价模式、出射介质和基板厚度进入完整指纹。对称文件由正面处方派生背面，不额外存储可产生矛盾的背面副本。旧读取器拒绝schema2，不能静默丢弃背面。

正式导出增加`back-layers.csv`和`evaluation.json`，实验快照、候选及公差保留两面。显示光谱的列标识用`front_`、`back_`、`system_`区分评价对象，保留原偏振、角度、单位及完整数值精度。见[文件契约](FILE_FORMATS_AND_PLUGINS.md#镀膜实验文件)。
