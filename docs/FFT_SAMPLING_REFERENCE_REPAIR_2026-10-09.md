# FFT 采样和包围能量参考点修复

2026年10月9日，正式共享 Core 修复 FFT 包围能量顶点参考点、显式间隔有效性检查及复色共同网格三个问题。最终完整 Release 4539/4539、Debug 定向 187/187 通过，均零跳过；默认两配置构建零警告、零错误。新增 13 项回归的修复前结果为 3 通过、10 失败，修复后全部通过。冻结原生参考、历史镜头输入、比较设置及容差保持不变；完整原生比较工具仍有 2 个旧残差，不表示整体 Zemax 数值认证已通过。

## 行为定义与实现

| 问题 | 原实现 | 修复后的实现 |
| --- | --- | --- |
| 顶点参考点 | 曲线只区分质心与其他选项，顶点和主光线共用零点。 | 追迹所选参考波长的主光线，使用其像面局部坐标，将像面顶点转换到主光线相对网格。使用 PSF 实际瞄准元数据，刚体平移不改变结果。 |
| 显式 FFT 间隔 | 只要有一个非零瞳孔样本就能返回成功；不检查网格是否覆盖完整瞳孔。 | 正间隔重新生成瞳网格前，拒绝覆盖不足、非有限网格或退化的一维节点集合，明确说明间隔过大或过小。不返回一条光线形成的恒定 PSF。 |
| 复色默认采样 | 各波长先用相同伸展系数计算，再将不同间隔的 PSF 插值到共同网格。 | 共享 `ComputeFftPsfSpectrum` 先确定最短选定波长的默认间隔，再按该间隔伸展其他波长的瞳网格并追迹。PSF 图和衍射能量操作数共用此入口。 |

[官方包围能量说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26102/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Diffraction_enclosed_energy.html)将顶点定义为像面局部坐标零点，并提醒离轴顶点分析必须覆盖所需范围。[官方 FFT PSF 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/FFT_PSF.html)规定较长波长使用更小的有效瞳网格，显式间隔改变追迹前的瞳孔采样，覆盖不足或节点不足应报错。

当前检查针对可证明的退化和覆盖不足，不宣称重现 Zemax 未公开的全部采样误差阈值。一般用途的 32 以下网格保留，但默认不再用小于 1 的伸展系数压缩覆盖；这不是 Zemax 的原生采样档位。负间隔保留各波长完整、不伸展的瞳网格；一般非兼容 FFT 路径不改为原生共同网格。

## 认证边界与后续检查

顶点修复遵循现有标量 FFT 坐标契约，已验证对齐系统及平移，不外推任意旋转、偏心出瞳或斜入射像面的完整三维投影。倾斜像面或明显斜入射应优先使用 Huygens，FFT 本身仍有官方说明的适用限制。

原 N02 捕获为轴上、单波长、质心、FFT 自动间隔，因此本轮三个问题不能被当成其完整根因。有限窗口、像素面积积分和总能量定义没有为匹配曲线而调整。原 N01 的 Huygens 平面与球面自动选择仍未实现；[官方 Huygens 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26102/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Huygens_PSF.html)给出距离差 λ/4 的自动判断，原捕获的高级传播覆盖设置仍待核实。后续应对照同设置的理想和实际二维 PSF、总能量及积分，不以增加采样或放宽容差替代原档位认证。

已有原生二维 FFT PSF 的 64/128 档、显式 0.25 µm 控制本轮逐像素重算：16384 个像素，坐标最大差为零，强度相对 L2 为 0.0028567503339345444，最大绝对差 0.0009863041087567748，满足原有 0.01 门禁，未平移、拟合或额外归一化。它与 N02 的 32/64 自动间隔不是同一采样设置，不能替代其理想及实际二维对照。当前已核对捕获中的 D 盘 API 目录及两个常见 C 盘目录，均不存在；尚未定位可用本机 API，本轮只有既有原生数据的重算，没有新捕获。

| 比较项 | Zemax 公开行为 | 当前代码与结论 |
| --- | --- | --- |

阶段一完成条件是同源身份和各实际设置可追溯，至少实际二维 PSF 可与 DEE 路径建立对应；理想或总量缺口必须明确，不能以另一组 64/128、显式 0.25 µm 控制替代。

### 阶段二 分层定位 FFT 包围能量误差

实际与理想分开记录。理想曲线忽略 OPD 后仍存在差异，因此不能仅归因于像差；原 N02 是轴上单色质心控制，也不能预设 C11-C13 或 N01 已解释它。每层保留输入、输出、单位和上一层来源，区别原生输出与 Core 诊断值。

| 检查层 | 必须比较的内容 | 判断与后续方向 |
| --- | --- | --- |
| 瞳孔与光线 | 网格节点、伸展、有效掩码、首次截断、振幅与 OPD；原生接口未公开的数据标为缺失。 | 节点或掩码不符时先查发射、瞄准、孔径和渐晕，不用下游归一化补偿。 |
| 二维 PSF | 物理坐标、间距、完整尺寸、逐像素强度、中心截面、总和与坐标加权质心。 | 在相同原生归一化下 PSF 已不符时，检查瞳采样、相位、振幅、FFT 构造和尺度。 |
| 中心与窗口 | 完整网格、当前中心 32×32 窗口、两者质心、保留能量与截断尾部。 | PSF 一致但此层不符时，检查参考中心和窗口范围；保留既有全窗候选变差的反证。 |
| 总能量与积分 | 归一化分母、圈内未归一化能量、圆与边缘像素重叠、401 点的最终曲线。 | PSF 和中心已一致但曲线仍不符时，优先检查分母、面积积分及曲线插值。 |

先验证坐标和网格一致再比较像素；不额外平移、峰值重标或拟合到原生曲线。逐像素相对 L2、最大绝对差、曲线 NRMSE、能量总和及单位分别报告，NRMSE 不解释为每点相对误差。原生未公开内部数值时只能限定剩余候选，不能宣称已经唯一定位。

阶段二交付物是原设置的逐层差异表、实际与理想的独立结果、能复现问题的控制，以及“最早出现差异的已观测层”和仍缺少的原生输入。64/128、128/256 等密度序列用于解释收敛，不改写原 32/64 档的状态。

### 阶段三 按证据修复并关闭原档位残差

每个确认问题先建立修复前失败测试，再对正式共享 C# Core 做最小修改；一次只改变一个可解释因素。图像、截面和能量操作数必须使用相同快照及相关设置，快照的追迹相关变更先脱离共享缓存。不得新增替代引擎、运行时 Airy 补偿、曲线拟合或外部 Python 计算路径。

N02 关闭须在原捕获设置下，实际与理想能量曲线满足原数值分类判据及非回归门禁，并解释其二维 PSF 与积分的一致性。仅低于旧误差预算、加密后接近或一条内部路径一致，均不自动等于原生 Pass。冻结参考、原镜头、设置和容差不改；此前增大误差的候选记录继续保留。

修复验收按默认输出执行 Debug/Release 构建、相关专项、正式完整 Release 和完整比较工具；完整 Debug、实验室及发布范围按 E03 补齐或明确记录未执行。保留原测试身份，不合并重叠集合，不把中止运行计作完整通过。报告同时记录修复前后证据、加载 Core 身份、未通过项和适用边界。

### 阶段四 独立定位 Huygens 传播差异

以[原 N01 设置](../validation/zemax/2026-r1/ms-l7-analysis-expansion-2026-09-06/huygens-psf-cross-section-c1/captured-settings.json)为控制：MS-L7、配置 1、轴上视场 1、单色波长 1，瞳孔与像面各 32×32，间距 0.25 µm，线性 X 截面，关闭峰值归一化、质心与偏振，保留瞄准。先取得系统高级传播选择的实际值，区分自动、强制平面和强制球面；未记录该值时不能断言原生样本使用平面传播。

逐项核对完整光线方向、坐标、OPD、振幅、像面切平面和原生中心，然后分别验证平面相位、球面相位、λ/4 自动选择、倾斜权重及理想峰值归一化。球面传播本身不是错误；固定球面与方向输入不完整是实现差距，是否造成 N01 的具体残差仍需证据。N02 使用 FFT，与这条传播路径独立。

补齐实际需要的共享输入后，一项模型改变对应一组独立控制与原生比较。此前使残差增大的平面和球面法向候选不得直接恢复。N01 关闭须满足原设置的原生数值判据和非回归要求；几何质心、刚体平移和复色一致性通过不能替代该传播认证。
