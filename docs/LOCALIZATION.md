# 界面语言

Optical System Design 的界面语言默认为简体中文，并内置 English 与日本語。顺序模式和非序列模式都可以在功能区的“设置 / Settings / 設定”页选择语言；选择后当前主窗口、已打开页面、弹窗、工具提示和辅助功能文字立即更新，无需重启。选择结果写入当前产品的 `settings.json`，下次启动继续使用。

语言切换只处理程序提供的界面文字。用户输入、工程名称、文件名、材料牌号和导入数据保持原文，避免修改工程语义。数字编辑继续沿用既有显示与解析设置；语言选择不会暗中改写光学数据。

## 实现约定

- `AppSettings.Language` 保存 `zh-CN`、`en-US` 或 `ja-JP`；缺失或无效值归一化为默认的 `zh-CN`。
- `UiLocalization` 保存三语界面词条，并在 Avalonia 控件进入窗口时挂接 `Text`、`Content`、`Header`、窗口标题、占位文字、工具提示及辅助功能名称/说明。
- 已打开控件保留其中文规范源文字。切换语言时从规范源重新生成显示值，因此可以在中、英、日之间反复切换，不会把译文当成新的源文字。
- 分析文档标题以共享目录中的中文显示名为规范源；显式恢复旧布局时修正内置英文报告标题及副本，不改分析键、实例或自定义标题。图片导出使用纯图标按钮，工具提示、辅助功能名称和保存对话框文案均提供中英日词条。
- 分析结构选择器将 `Current` / `All` / 编号与“当前的 / 所有 / X / N”标签分开保存。下拉项标签在原控件尚未载入弹出层时也登记规范源，已选择项和后续弹出项均可随语言切换；编号、图格标识及 CSV 结构列保持不变。
- 状态栏中工作模式、运行状态和表面/视场/波长计数由当前语言直接格式化；用户工程名保持不变。
- 孔径类型等规范枚举仅翻译控件中的显示文字，选中值仍保留中文规范值；波长、视场、权重及表面属性等带编号的动态标题和摘要按固定界面片段翻译，数值与单位不变。
- 帮助页的用户指南使用同一语言设置重建目录、章节和完整命令/分析参考；搜索条件与命令标识不翻译，工程数据不受影响。
- 后续新增固定界面文字时，必须同时添加英文和日文词条，并为切换前、切换后动态更新以及稍后创建的控件补充回归覆盖。

## 验证

`UiLocalizationTests` 覆盖默认中文、无效设置回退、日文设置保留，以及已加载控件、孔径枚举、波长摘要、表面编辑文字、后续创建控件和用户输入的切换边界。`UserGuidePanelTests` 进一步覆盖指南搜索和三语重建；`AnalysisConfigurationSelectionGuiTests` 检查结构选择标签、运行时语言切换、编号保持和三语图面。最新定向测试、构建和截图范围见[当前状态](CURRENT_STATUS.md)及[结构选择说明](ANALYSIS_CONFIGURATION_SELECTION_2026-10-22.md)，不将这些集合的重复执行累计为全仓库通过数。
