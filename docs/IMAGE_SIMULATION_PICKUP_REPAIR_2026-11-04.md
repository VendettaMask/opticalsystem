# 图像模拟跨列参数拾取修复，2026-11-04

已修复图像模拟示例2、5共用的导入错误。原处方中焦距100 mm的准直薄透镜，曾被错误导入为零光焦度；修正后，两份镜头原60项请求新增 **52 Pass**，六项FFT采样拒绝全部恢复通过。原源文件、分析采样、参考、容差及0.5波局部保护均保持。

## 根因及通用修复

两份原始ZMX均包含：

```text
PARM 1 100
PARM 2 1
PPAR 1 0 1 0 2
```

最后一行将本面参数1拾取为物面厚度。导入器却把末尾的2当成“参数2编号”，读取物面不存在的参数，结果为零；随后把焦距零解释为零光焦度。原处方本身没有问题，错误从第一片准直面传播到一阶量、光线、OPD、波前和衍射分析。

依据[官方Parameter Solves定义](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Parameter_Solves.html)和[列编号规则](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v252/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Integer_Codes_for_Column_Numbers.html)，拾取来源是列，而非任意参数序号：0为同列，1–4分别为半径、厚度、圆锥系数、半口径，5–17为参数0–12。导入现在按这些身份读取，先恢复源数据的文件单位，再应用比例/偏移及目标参数的单位规则；源曲率、厚度拾取先完成求值。无法支持的来源列明确拒绝，不再默默读取零。

修复位于共享Core的ZMX导入器，没有镜头名或参考数组分支，不修改追迹/FFT算法，也不通过增加采样解除拒绝。两份镜头重新导入后的快照仅有准直面的 `PowerX/PowerY` 从0恢复为0.01 mm⁻¹；全部95份源文件哈希保持，114个已导入配置中其他 **112个逐字段结构相同**。320°物方锥角的原导入限制保持。
