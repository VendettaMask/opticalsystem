# 文档生命周期与检查

现行索引是 [docs/README](README.md)。使用说明描述当前可操作行为；日期报告保留该阶段的输入、结果和失败，当前问题和最新运行分别由[问题清单](OPEN_ISSUES_2026-10-08.md)及[状态页](CURRENT_STATUS.md)串联。原始材料、实际用户文件和第三方通知不作普通产品指南改写。

## 更新与退役

1. 从当前源码、参数契约和已有验证记录核对指南正文。更新已实现项、默认值、格式/算法身份、操作入口和明确边界；不能只在过时内容前追加一条“历史”提示而继续给出错误的当前指令。
2. 计划按实际状态分类：未完成的任务保留在现行区；已交付的阶段记录进入历史索引，当前操作由稳定指南维护。带日期不自动表示历史；日期较早也不自动表示无效。
3. 删除前检查代码、脚本、其他文档和回归输入的消费者。若没有独有证据、已被完整替代且无需继续消费，可删除旧文件并修复来链；记录替代项与原因。仍有独有失败、用户原始要求或当前测试输入的材料按实际关系保留。
4. 冻结、baseline 或 before/after 标签不是永久豁免。若要退役重复的资料或容器，先按完整文件/归档条目哈希核对替代物，保留一份权威载荷。收据只保存身份、差异和关系，不重复复制整套数据或运行时。
5. 不因文档整理重新认证光学结果、合并不同阶段通过数、扩大商业软件等价结论或修改原参考/容差。

[生命周期清单](documentation-lifecycle.json)列出日期规则的显式例外和已删除文档的替代关系。新增活动计划、历史化或删除后同步该清单。检查器拒绝失踪的活动计划、冲突身份、重新出现的废弃文件和丢失的替代文档。

## 本地检查

```powershell
pwsh -NoProfile -File scripts/verify-documentation.ps1 -Strict -OutputPath artifacts/documentation.json
pwsh -NoProfile -File scripts/tests/verify-documentation.tests.ps1 -OutputPath artifacts/documentation-tests.json
```

检查包含版本化和未忽略文档清单/哈希、现行及历史指南的 Markdown 链接/锚点、HTML href/src/srcset、代码围栏、现行正文重复及生命周期。生成报告归为证据；PDF/Word/ODT 只登记指纹，不将二进制当 Markdown。远端网址不在此脚本中联网核验；原生参考、证据及第三方内容需要另按其消费者和归档关系评估，不能把静态检查等同于全部内容正确。

自动脚本不能判定一句功能说明是否已过时。本轮编辑复核另见 [2026-11-02 维护记录](../validation/rechecks/2026-11-02/documentation-maintenance/README.md)，包含逐份去向、修改/删除原因、覆盖范围和仍需人工判断的边界。
