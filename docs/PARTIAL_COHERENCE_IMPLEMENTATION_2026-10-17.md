# 部分相干成像实现：2026-10-17

共享 Core 已实现复光瞳传递及均匀空间互相干成像，`Partially Coherent Image Analysis` 的 γ=0、中间值及 γ=1 均接入该路径。结果保留真实复相位和干涉项，不再混合原图，也不再将所有非零相干度作为未实现拒绝。

本轮实现的范围是**标量、单参考视场等晕、均匀空间互相干度、带限采样物体**。不是任意互相干函数、场变复响应或完整矢量传播；未新增同设置 Zemax 原生图像认证，不声称界面 γ 与 Zemax 的 Alpha/Gamma/Fraction 参数等价。

## 源模型与传播

第 i 个采样源的平均强度为 I_i，复振幅 a_i=√I_i exp(iφ_i)。采用半正定的离散源互强度：

```text
W_ij = (1-γ) I_i δ_ij + γ a_i conjugate(a_j),  0 <= γ <= 1
A = h * a
B = |h|² * I
I_image = (1-γ) B + γ |A|²
```

γ 是不同采样源之间的空间互相干度幅值，不是直接复用某商业分析的光源半径或 coherent fraction。γ=0 时采样源模态独立，传播强度相加；γ=1 时复振幅相加后取模平方。中间值保留按 γ 缩放的交叉干涉项。上式是源互强度经同一个线性光学算子传播的解析展开，不是将原图混入衍射图。

物理依据见 TU Delft 的[干涉与互相干](https://interactivetextbooks.tudelft.nl/tn2421/content/Chap5_Interference/InterferenceCoherence_2022_01Clean.html)及[相干光学成像](https://qiweb.tudelft.nl/aoi/coherentimaging/coherentimaging/)。上述均匀离散源族是本产品明确选择的模型，不把该选择归为商业软件默认。一般模态传播的理论背景见 [IUCr 原始研究](https://journals.iucr.org/s/issues/2022/06/00/ay5600/index.html)；本实现直接利用所选源矩阵的解析形式，不声称完成任意源矩阵的本征模分解。

## 共享光学、采样与数值标尺

`DiffractionEngine` 的既有 FFT 路径与新相干图像路径共用复光瞳构造，保留追迹 OPD 相位和功率振幅，包括已有体吸收衰减。旧公开 FFT 接口和计算顺序保留。没有从强度 PSF 开平方猜测丢失的相位，也没有新增模块内光学引擎。

复光瞳插值至输入像素可表示的空间频率格点，圆形光瞳外频率置零，再用共享逆傅里叶变换生成复响应。物体定义在像方缩放后的参考平面；高于采样 Nyquist 的物体频率不在该离散模型内。保留既有 OPD/FFT 的轴向约定，图像行向下、光瞳 Y 向上；独立倾斜相位控制验证响应移动方向。

传递光瞳按其最大振幅设定统一的相对标尺，所有 γ 使用同一光学算子。不按 γ、核总量或最终窗口重新增益归一化；输入/输出是相对线性强度，不是绝对 W。γ=0 的离散带限源模型不应冒充既有单位总量强度 PSF 分析的绝对亮度口径。

有限复响应核直接截取，保留其原始样本，报告 `MinimumKernelCapturedFraction`。该比例相对于同一傅里叶格点的完整离散响应，不是连续光场的无穷积分认证；最终图像窗口还可继续损失能量。原主镜头控制的 33×33 核保留约 **98.21617372555461%**，该有限误差没有被隐藏或补偿。界面增加复响应核尺寸及物理像素间距；可在预算内增大核并检查保留量，不能把当前小核结果当作无限窗口收敛值。

旋转、翻转和过采样同时作用于源强度和可选的 `SourcePhaseRadians` 数组；相位单位为弧度，按原源图尺寸提供，一通道或源图同通道数。界面内置靶默认零参考平面相位，额外相位输入目前通过 Core API 提供。保护带只延伸同一格点，不改变有效源图采样。各波长分别传播强度，不把不同波长电场作相干叠加。翻转/输出缩放后的最终统计仍使用同一显示数据数组。

源矩阵中的 δ_ij 定义在准备后的源采样格点上；改变过采样也会细化该离散源族，不能将其当作固定连续相干长度或固定源模态的收敛序列。固定物理相干面积、原像素相关块或一般连续源的采样保持传播仍属扩展模型。本轮只验证所声明离散模型的传播和变换一致性。

## 实际支持与拒绝边界

- 每个波长一个参考复光瞳；可使用场中心、物场高度、照度权重、保护带、过采样、核尺寸和物理像素间距。结果明确报告等晕模型，不追加场变几何畸变或横向色差变形。
- 使用共享标量 OPD 与追迹功率模型，不声称已补齐吸收界面的完整复 Fresnel/矢量相位。反射、携带未建模复相位的镀膜、偏振、无焦成像、非 chief 参考或请求多个复光瞳均明确拒绝。允许具有明确实振幅口径的无膜/简单功率涂层。
- 直接 Core 的 `Partially Coherent` 模式调用互强度路径；仅能表示强度的 EigenPSF 基函数入口拒绝该模式。没有几何 PSF 回退、PCA 强度修正或原图混合。
- 非有限/负强度、非有限相位、无效 γ 或物理像素间距、空复响应拒绝；复卷积和整个复色傅里叶工作量在追迹/分配前受资源预算约束，计算可取消。

## 独立控制与原主镜头

两单位点源共享响应 .5 的观察点中，γ=0 的强度为 .5；γ=.5 时同相为 .75、反相为 .25；γ=1 时同相为 1、反相约 3.75e-33。十组 γ/相位控制与解析干涉公式最大差约 **3.75e-33**。任意复核的小网格另与显式完整互强度双重求和比较，验证相位、边界及核锚点。

独立通带控制采用 λ=.5 μm、F/8、像素 1 μm：50 cycles/mm 的相干对象频率通过，250 cycles/mm 被滤除；相干截止为 125 cycles/mm。全局源相位不改变强度，局部相位改变干涉，有限窗口及核振幅缩放不被归一化抵消。还验证复相位轴向、核窗口增大、光谱独立、源相位旋转/过采样和界面参数转发。

原 `123456.ZMX`、550 nm、16 级瞳采样、33×33 核、1 μm 像素及 24×24 双点源控制：γ=0 与 γ=1 图像最大差 **0.004773267233830059**；将一个源点改为 π 相位后，相干图像最大差 **0.00954653446766012**，非相干图像保持相同。γ=.5 的结果与旧“原图/强度图各半”最大差 **0.4960637952925678**。这是当前 Core 计算与独立数学控制，不是新 Zemax 图像对照。

原主镜头 24 组既有 FFT 数组在本轮前后逐位指纹相同，涵盖三个波长、两个视场、两种瞳密度和两种瞳格点约定。此前冻结源文件、参考、设置及容差均保持，独立 Cooke/Tessar 未重新列为原生调查或认证目标。
