# 2026-10-20 更新后多配置计算输入一致性修复

基于同步后的 `59bb1de5` 检查。此次更新新增多配置矩阵的跨结构厚度编辑，暴露了原厚度接口中已有的同步与依赖解析缺陷。本轮修复 Application 层的编辑事务，保留共享 Core 光学算法、原生参考、原容差及所有已有测试断言。

## 复现与修复

1. **活动处方过期并可能回写旧值。** 在结构 2 或 3 激活时，编辑基础结构的关联厚度，只更新了配置存储，没有替换当前活动处方。后续计算使用旧厚度，捕获工程又将旧活动处方写回存储。独立双透镜反例把间隔从 `3` 改成 `3.123456789012345` mm；六组活动结构/行登记组合中，修复前四组仍返回 `3`。现在先在配置副本中完成修改和依赖解析，再统一更新存储、活动处方与事件。
2. **表面厚度拾取未传播。** 未登记为操作数行的厚度编辑此前绕过表面拾取刷新，其他结构的派生间隔可滞后。现在通过共享 Core 的既有拾取、求解及属性关联接口处理；基础源值、直接和跨配置拾取、当前处方和保存结果保持一致，独立覆写的结构不被覆盖。
3. **受控目标接受直接写入。** 矩阵厚度入口此前允许写入由表面拾取决定的目标，随后重新求解时又恢复派生值，造成“已应用”的输入与实际计算不符。现在与操作数行编辑的既有契约一致，明确拒绝直接覆盖，要求编辑源表面或先移除拾取。

11 项新增守卫使用双精度精确相等检查处方、关联值、独立覆写、近轴焦距、撤销/重做及 STAROPT 保存重开。合成双透镜仅用于独立输入一致性控制，不作为新增 Zemax 镜头认证。失败控制及修复过程保留；中间扩展控制补全了调用共享拾取解析的初始化，不改已有回归断言或误差限。
