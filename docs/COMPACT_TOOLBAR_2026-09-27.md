# 紧凑顶部菜单与工具栏（2026-09-27）

本文记录该阶段的实现和验证。后续主动作与紧凑侧栏已完成，跨阶段测试数不相加；当前整合行为及验证范围见 [状态页](CURRENT_STATUS.md)。


## 已实现

顶部分类页签保留原有功能分区，默认选择“文件”。命令改为左图标、右文字的单行布局，下拉指示位于文字右侧，取消原大图标上下排列和分组标题栏。默认字号下四套主题实测高度均为 77px；布局资源的最小高度为 72px，较大的字号允许自然扩展，超宽工具栏横向滚动。

顺序模式文件工具栏依次提供新建、打开、保存、导入、导出、示例、撤销、重做。导入菜单使用原 Zemax ZMX 命令，导出菜单使用原 CAD（STEP）命令；Cooke/Tessar 只出现在示例菜单中，仍经原文档切换和未保存保护流程。非序列模式保留新建、打开、保存及撤销/重做，不暴露顺序交换与示例入口。

撤销/重做的启用状态读取应用层文档历史，在文档事件后刷新；初版禁用状态为透明底面；当前普通亮模式使用统一的雾蓝灰禁用底色与文字。四套主题共用至少 56×36 的自动宽度按钮及 20px 图标，像素和异世界继续使用现有图标包、字体与颜色。分析菜单、动作 ID、模式隔离和计算链路保持原语义。

## 历史阶段：纯白亮模式与三位小数

此节记录早先实现与验证；当前色值、禁用底色、侧栏和标题样式已由[深蓝 × 雾蓝主题](BLUE_THEME_2026-09-27.md)替代，三位小数规则保留。

普通亮模式的主窗口、侧栏、页签、表格及空白工作区改为纯白背景；浅蓝只用于按钮、悬停、选中和禁用输入状态，正文使用深墨蓝。边框淡化为 `#D9E8F7`，普通亮模式关闭卡片与顶部投影，滚动条及下拉占位文字也改用蓝色资源。`LightTheme` 集中提供 Fluent 与 Dock 资源，切换主题会恢复旧主题覆盖前的根资源，避免其他主题残留配色。

`NumericDisplayOptions` 与 `AppSettings` 共用默认 **3 位小数**，正常显示及科学计数法尾数最多保留三位，不强制补零；已有显式精度设置仍保留。本机原有 6 位偏好已按本次要求更新为 3，原设置备份保存在本地验证目录。Core 计算与 STAROPT 序列化不依赖该显示精度。

本阶段验证记录见本地 `artifacts/validation/light-theme-20260927/`：使用实际系统属性、镜头表、停靠工作区和顶部控件进行 Headless 渲染，检查默认/重置/科学计数格式及暗夜、异世界、像素到亮模式的往返切换。禁用按钮使用白底和低对比蓝色文字，与可点击的浅蓝按钮区分。
