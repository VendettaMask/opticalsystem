# 非序列模式 Zemax 工作流对齐路线图

更新：2026-11-01。本页只维护差距、里程碑和验收门槛，不作为已实现功能的第二份操作手册。

## 与成像传感器共享的产品主线

2026-11-01 已补齐[同轴胶合/浸没镜组的事务转换](CEMENTED_IMMERSION_NSC_2026-11-01.md)：实际介质边界、逐面口径/镀膜、共享体吸收、多次 Fresnel 分支及探测器 RAW/ISP 使用同一 Core。转换范围以平面/球面/圆锥、透明/弱吸收均匀体为限；相对偏心/倾斜、非球面、强吸收体、偏振传输和逐面散射仍待扩展。该进展解决原先整组跳过的问题，不代表完成精确镜筒 CAD、实拍 RAW 标定、非序列优化/公差或 GPU 大规模追迹。

2026-10-30 用户将产品方向明确为 ImSym 与 Speos 能力融合：同一主程序和共享 Core 提供三维光传播、照明/杂散光分析，以及光学—传感器—RAW—ISP 成像链。既有 Zemax 风格工作流是当前入口组织方式，后续目标同时包含与相机共享的物理结果和工程状态。统一单位、路径去重、阶段里程碑及已知相机阻断集中维护于[相机产品目标](CAMERA_IMAGING_LAB.md#产品目标imsym-与-speos-能力融合)。

共享 `SpectralDetectorPower` 和 `NonSequentialCameraSensor.Capture` 把匹配矩形探测器的原始 `PowerByWavelength` 及波长快照冻结为 W/物理像元的带积分功率。2026-10-31 已通过应用层核对当前场景/会话/数据库身份，并接入相机的“非序列探测器”输入、路径筛选、QE/曝光、RAW/ISP、A/B 和完整实验。只读取完整分析会话，不发起隐式追迹、不读取归一化显示图、不再叠加顺序主像；按冻结功率复算不等于重跑 NSC。操作与边界见[相机说明](CAMERA_IMAGING_LAB.md#非序列分析到-raw--isp)。Lambertian 与实测网格 BSDF/BTDF 已接入，商业数值认证仍未完成。

最新[White实际追迹功率检查](WHITE_SPECULAR_RUNTIME_2026-10-31.md)已修复约0.01835 W差异，协议6/v14的23组功率及正常入射方向矩通过；White关闭603点的有限范围不变。当前[全入射角对数重建和绝对XYZ校准](XYZ_LOG_RECONSTRUCTION_2026-11-01.md)新增10/v18、11/v19：40个Cornell原入射节点切片在550 nm和3份法向BTDF完整链路通过，保留旧9/v17线性结果。Mystic/Cayman新增通过原开发留出门槛，另4组合成角形状链路通过；此前Garnet/Krylon校准保持，Blue Acrylic仍失败。下一步重点为Blue Acrylic、新盲测、原发布观察者证据、更多波长/入射/材料轴、真实背面，以及White开启完整二维和等价介质的商业逐值控制；不以局部统计替代完整商业验收。

用户已选择三维相机成像作为首个场景。另有有界直射路径：复用 NSC 的不可变几何/BVH 查询，结合共享顺序表面反向追迹、点光源与 Lambertian 直接反射，输出实际感光面积内的带积分功率，再进入原传感器/ISP。其桌面设置、独立三维文件和完整实验冻结见[操作说明](CAMERA_IMAGING_LAB.md#三维场景与照明到相机)。这条直射路径与读取完整 NSC 分析结果的路径分开；后者已接入 Lambertian 和实测 BSDF/BTDF，见[接口与验收](MEASURED_BSDF_BTDF_2026-10-31.md)。

V8 又在相同入口接入有限单元标量 Huygens 表面求积：共享 NSC 逐对象/遮挡查询和实际镜头光程，输出绝对功率并复用传感器/ISP。它属于直接照明下的非相干三维成像，未实现 NSC 多次散射波场、矢量高 NA 或遮挡边缘的多次衍射。几何、场景、瞳面及窗口控制和冻结版本边界见[三维衍射](CAMERA_IMAGING_LAB.md#三维衍射)。

现有 `MainRayScatterLossApproximation` 与 `MeanMeasuredScatterLoss` 仍只扣减主光线能量，旧 Lambertian/BSDF 别名不执行方向采样或 Evaluate/Sample/Pdf。新 `IBsdf / LambertianReflectionBsdf` 单独实现并接入 NSC 的功率账本、路径事件、采样统计和相机；自有 CSV 实测网格和 BTDF 已实现，[固定材料轴与 Speos v8 文本两类格式](COMMERCIAL_BSDF_AXES_2026-10-31.md)已实现，[已核验 Speos 二进制与 Zemax 单色辐射度格式](BINARY_ZEMAX_BSDF_2026-10-31.md)已接通；[v11、原生镜面增强/White Specular 和校准 XYZ](SPEOS_V11_XYZ_2026-10-31.md)已实现，其他格式与商业数值对标仍未完成。

## 目标与兼容边界

STAROPT 非序列模式按熟悉的照明与杂散光工作流组织：

`对象建模 → 追迹控制 → 探测器查看器 → 光线数据库查看器 → 路径分析 → 3D 布局联动`

这里的“对齐”指常用窗口层级、术语和操作语义相近。实现仍使用独立的 STAROPT 工程、STARRDB 数据库、对象模型和界面，不复制第三方私有界面，也不声明兼容 Zemax NSC、ZRD 或完整 Filter String。

## 当前与 Zemax 的主要差距

| 领域 | STAROPT 当前状态 | 后续差距 |
| --- | --- | --- |
| 结果生命周期 | 完整分析会话驱动探测器/数据库/路径；3D 使用独立有界布局会话，支持过期检查 | 暂停、实时进度、会话历史和跨窗口选择总线 |
| 分裂 | 无分裂、完整 Fresnel、Simple Stochastic；转换光学组件的逐面常量/相干膜；不透明 Lambertian 单方向延续 | 普通实体逐面镀膜编辑、一般散射混合瓣、衍射、荧光等分支事件 |
| 探测器 | 矩形位置/角空间、功率/辐照度/强度/命中；显示变换、任意剖面、CSV/PNG | Color、Polar、Surface、Volume、对象探测，相干/偏振/光度结果及完整报告 |
| 数据库 | STARRDB 流式写入、校验、分页分支与分段 | 真正的随机索引树浏览、大结果后台查询；ZRD兼容不在目标内 |
| 路径筛选 | `Q/H/R/S/B/T/D/M/W/A/E/X`、布尔和 `SEQ`，S 为方向散射、B 为 BTDF | 衍射、偏振、波长变化等事件语义 |
| 3D | 自动布局会话、对象与抽样光线、逃逸尾线 | 按源/波长/层级/功率着色、即时筛选和选中路径高亮 |
| 光学物理 | 反射、折射、吸收、全反射、非偏振 Fresnel；转换组件逐面镀膜与共享弱体吸收；对象级 Lambertian、实测光谱/角度及固定轴 BSDF/BTDF 多次散射 | 其他商业 BSDF 格式、普通实体逐面覆盖、体散射、偏振、相干探测、衍射和强吸收体传播 |
| 对象 | 10类原生光源；矩形/椭圆面源支持 VirtualPoint、Cosine、Gaussian和兼容圆锥；体源支持全空间均匀球面和兼容圆锥；原生基础实体、标准镜片、同轴胶合/浸没复合组件、STL、矩形探测器 | IES/LDT及厂商射线文件、对象型光源、更多探测器、相对偏心/非球面组件、自由几何和精确CAD |
| 设计工具 | 无非序列专用优化和公差 | 探测器/路径操作数、向导、固定种子策略和蒙特卡洛 |

1. 增加可暂停的进度事件、速度/预计时间、几何错误策略和错误能量分类。

3. 建立窗口间选择总线：数据库选中分支后，3D高亮完整父子路径，探测器和路径统计使用相同不可变筛选 AST。
4. 增加带追迹设置、筛选、统计和单位元数据的探测器完整数值报告导出。
5. 增加主路径、鬼像、机械杂散光和异常逃逸分类，以及从统计行生成筛选表达式。

### 里程碑 B：探测器扩展

实现 Detector Color、Detector Polar、Detector Surface、Detector Volume 和普通对象探测；加入真彩色、光度单位、空间/角度数据及体吸收切片。STAROPT负载升级时继续迁移旧矩形探测器。

### 里程碑 C：面属性、镀膜与散射

已实现对象级 Lambertian、实测 CSV BSDF/BTDF、IBsdf、STARRDB 反射/透射散射事件及 S/B 筛选，并接到统一传感器。已增加 Speos v8 TEXT 两类、已核验二进制、Zemax 单色/校准 XYZ、Speos v11/原生镜面增强与 White Specular 及固定轴各向异性。顺序转换组件已保留逐面常量/相干多层膜，支持真实膜料n/k与反向膜序；普通实体逐面覆盖、独立桌面膜层编辑、Gaussian、ABg和其他商业文件导入仍待扩展；不把旧主光线损耗别名当成方向模型。

### 里程碑 D：偏振、相干与衍射

传播 Jones/Stokes 状态和一致相位/光程，加入偏振光源、偏振镀膜、相干及偏振探测器、光栅和衍射级次。STARRDB升级并继续读取v1。

### 里程碑 E：对象、CAD、优化和性能

增加椭圆、抛物面、棱镜、光管、自由曲面、测量光源、IES/EULUMDAT；之后引入 STEP/IGES/SAT 精确CAD和面映射。建立探测器总功率、像素、均匀度、质心、RMS和路径功率操作数，以及非序列优化向导、公差与蒙特卡洛。最后推进SIMD/GPU、BVH缓存、多线程分块和超大数据库索引。

## 验收规则

- 打开或刷新探测器、数据库和路径分析不得启动追迹；3D窗口只允许自动准备或刷新独立布局会话，不能替换完整分析会话。
- 固定场景、设置和随机种子时，数据库、3D抽样、路径统计和探测器像素必须一致。
- `TraceOnly`只能累积兼容会话；不兼容请求必须明确要求清空并追迹。
- Simple Stochastic 必须可重复，并在足够样本下以规定统计误差接近完整 Fresnel 分裂。
- 取消、异常和文件发布失败不得破坏上一有效会话及旧数据库。
- 所有新增结果坐标必须携带类型化量纲和单位，不能从显示字符串推断。
- 百万射线验证使用独立性能基准；普通CI使用小规模确定性场景验证行为。

历史增量测试与性能记录见 [基础链路验证](NONSEQUENTIAL_PHASE2_STRAY_LIGHT.md#验证与边界)，当前工程测试以 [状态页](CURRENT_STATUS.md) 为准；本路线图不是新一轮数值或桌面验收。

## 明确不承诺

不进行 Zemax 界面像素级复刻，不导入 Zemax NSC，不读写 ZRD，也不承诺完整 Zemax Filter String 兼容。验收目标是常用非序列工作流和公开物理语义对齐，而不是私有格式或内部实现兼容。

## 镀膜共享计算与当前 NSC 接入

共享 Core 的各向同性相干薄膜求解器支持真实 n/k、斜入射、S/P和R/T/A。2026-11-01顺序转换组件已调用同一求解器，计算逐面非偏振平均功率并接入NSC分裂、STARRDB和相机，反向穿越时反转膜序。普通实体的逐面覆盖、Jones/Stokes传播、相干探测和膜散射等仍待完成；不另建膜系计算引擎。见[转换支持域](CEMENTED_IMMERSION_NSC_2026-11-01.md)及[共享镀膜能力](COATING_DESIGN_LAB.md)。
