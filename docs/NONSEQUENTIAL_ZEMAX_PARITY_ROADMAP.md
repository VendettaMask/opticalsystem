# 非序列模式 Zemax 工作流对齐路线图

## 目标与兼容边界

STAROPT 非序列模式按熟悉的照明与杂散光工作流组织：

`对象建模 → 追迹控制 → 探测器查看器 → 光线数据库查看器 → 路径分析 → 3D 布局联动`

这里的“对齐”指常用窗口层级、术语和操作语义相近。实现仍使用独立的 STAROPT 工程、STARRDB 数据库、对象模型和界面，不复制第三方私有界面，也不声明兼容 Zemax NSC、ZRD 或完整 Filter String。

## 当前已完成的分析闭环

### 功能区与窗口

非序列功能区按工作流提供独立一级入口：

- 光线追迹：`追迹控制`、`单光线追迹`；
- 探测器：`探测器查看器`、`清空探测器`；
- 光线数据库：`光线数据库查看器`、`路径分析`；
- 布局：`非序列 3D 布局`。

对象编辑器只负责场景和对象，不再重复放置追迹与数据库入口。单光线追迹保留为几何调试工具；完整源对象追迹统一从追迹控制启动。

### 统一追迹结果会话

`INonSequentialAnalysisService` 独立于文档编辑服务，管理当前结果会话、数据库、探测器重建和分页读取。一次分析追迹默认写入应用管理的临时 STARRDB；探测器、数据库、路径分析和3D布局读取同一份结果，不在打开窗口或改变显示选项时重新生成随机光线。

会话记录场景哈希、工程修订、追迹设置、源对象集合、随机种子、分支和分段数量、能量平衡、数据库位置、警告与追迹次数。工程内容改变后旧结果仍可只读查看，但会显示过期；切换、打开或新建工程时会话和应用临时数据库被清理。

追迹命令语义为：

- `清空并追迹`：成功后原子替换当前会话；取消或失败保留旧会话和旧目标文件；
- `仅追迹`：只在场景哈希及关键设置兼容时向当前结果累积，并使用后续确定性随机序列；
- `仅清空`：清理当前探测器结果和应用管理的临时数据库，不修改非序列文档。

用户指定保存路径时，数据库仍先写同目录临时文件，完成后再发布。应用管理的临时结果被替换、打开外部数据库或关闭时都会回收。

### 追迹控制和分裂

追迹控制可选择全部启用光源或单一光源，使用对象布局/分析射线数或临时覆盖数量，并设置随机种子、最大段数、最大活动分支、最小相对能量、结果保留量、保存筛选和数据库路径。

当前分裂模式为：

- `None`：界面折射只保留透射路径，全反射仍遵循物理反射；
- `FullFresnel`：按非偏振 Fresnel 能量生成反射与透射子分支；
- `SimpleStochastic`：按 Fresnel 概率确定性抽样一个子路径并保留该射线全部统计权重，固定随机种子可重复。

达到能量、段数或分支限制会进入截断能量和警告，不伪装成无警告完成。当前取消由计算令牌即时终止；实时速度、预计剩余时间、暂停和逐类几何错误能量仍在后续范围。

### 探测器查看器

当前矩形探测器查看器只读取当前会话或指定 STARRDB，并支持：

- 作为主工作区中的稳定可停靠分析页打开；重复点击入口聚焦同一页面，不创建模态独立窗口；

- 探测器、系统波长和统一路径筛选；
- 位置空间的像素功率、非相干辐照度和命中数；
- 角空间的功率、辐射强度和命中数；
- 线性或对数热图；
- 总功率、有效命中、峰值、质心、X/Y RMS 和均匀度；
- X/Y 积分曲线和 CSV 数值导出。

位置与角空间分别维护功率和命中像素；单波长显示的总功率与命中统计也使用同一波长口径。刷新、切换数据类型、波长或筛选不会启动新追迹。

尚缺颜色表选择、自动/手动范围、归一化、平滑、像素光标、任意行列剖面、PNG和完整数值报告导出。

### 数据库、路径与3D

光线数据库查看器通过流式读取和分页显示分支父子关系及分段链。分段包含对象、面、交互、位置、出射方向、功率、波长、几何光程和光学光程。路径分析继续按对象—面—交互—终止原因分组，并报告数量、功率、占比、光程范围、波长、最终探测器和可复用筛选表达式。

3D布局只从独立布局会话读取有界确定性样本，不复用或替换完整分析会话。打开布局只显示对象；用户点击“准备布局光线”后才以固定种子追迹。刷新、旋转、缩放和显示设置不会追迹。场景哈希变化时默认不加载旧光线；用户可显式“查看过期光线”，页面同时显示红色横幅及结果/当前哈希状态。对象使用光源、探测器和普通实体角色着色，多面对象按真实闭合面片绘制，光轴以浅色虚线显示。

当前分页仍以顺序扫描分块实现，尚未完成百万分支按射线ID直接跳转、可展开树、选中路径高亮和多维着色。路径分类也尚未自动标记主路径、鬼像、机械杂散光和异常逃逸。

## 当前与 Zemax 的主要差距

| 领域 | STAROPT 当前状态 | 后续差距 |
| --- | --- | --- |
| 结果生命周期 | 同一 STARRDB 驱动探测器、路径和3D；支持清空/累积/替换 | 暂停、实时进度、会话历史和跨窗口选择总线 |
| 分裂 | 无分裂、完整 Fresnel、Simple Stochastic | 镀膜、散射、衍射、荧光等分支事件 |
| 探测器 | 矩形位置/角空间、功率/辐照度/强度/命中 | Color、Polar、Surface、Volume、对象探测，相干/偏振/光度结果 |
| 数据库 | STARRDB 流式写入、校验、分页分支与分段 | 真正的随机索引树浏览、大结果后台查询；ZRD兼容不在目标内 |
| 路径筛选 | `Q/H/R/T/D/M/W/A/E/X`、布尔和 `SEQ` | 散射、衍射、偏振、波长变化等事件语义 |
| 3D | 对象与会话抽样光线 | 按源/波长/层级/功率着色、即时筛选和选中路径高亮 |
| 光学物理 | 反射、折射、吸收、全反射、非偏振 Fresnel | 镀膜、表面/体散射、BSDF、偏振、相干、衍射和体吸收 |
| 对象 | 10类原生光源、原生基础实体、标准镜片、STL、矩形探测器 | IES/LDT及厂商射线文件、对象型光源、更多探测器、自由几何和精确CAD |
| 设计工具 | 无非序列专用优化和公差 | 探测器/路径操作数、向导、固定种子策略和蒙特卡洛 |

## 后续里程碑

### 里程碑 A：完成查看与联动细节

1. 增加可暂停的进度事件、速度/预计时间、几何错误策略和错误能量分类。
2. 为 STARRDB 增加按射线ID和分块的直接索引，数据库树、分段表和筛选结果全部后台分页。
3. 建立窗口间选择总线：数据库选中分支后，3D高亮完整父子路径，探测器和路径统计使用相同不可变筛选 AST。
4. 完成探测器颜色表、范围、归一化、平滑、光标、任意剖面、PNG/CSV/报告导出。
5. 增加主路径、鬼像、机械杂散光和异常逃逸分类，以及从统计行生成筛选表达式。

### 里程碑 B：探测器扩展

实现 Detector Color、Detector Polar、Detector Surface、Detector Volume 和普通对象探测；加入真彩色、光度单位、空间/角度数据及体吸收切片。STAROPT负载升级时继续迁移旧矩形探测器。

### 里程碑 C：面属性、镀膜与散射

增加对象级和面级属性覆盖，支持理想、金属及多层膜，以及 Lambertian、Gaussian、ABg 和文件型 BSDF。STARRDB和筛选AST增加散射与吸收细分类。

### 里程碑 D：偏振、相干与衍射

传播 Jones/Stokes 状态和一致相位/光程，加入偏振光源、偏振镀膜、相干及偏振探测器、光栅和衍射级次。STARRDB升级并继续读取v1。

### 里程碑 E：对象、CAD、优化和性能

增加椭圆、抛物面、棱镜、光管、自由曲面、测量光源、IES/EULUMDAT；之后引入 STEP/IGES/SAT 精确CAD和面映射。建立探测器总功率、像素、均匀度、质心、RMS和路径功率操作数，以及非序列优化向导、公差与蒙特卡洛。最后推进SIMD/GPU、BVH缓存、多线程分块和超大数据库索引。

## 验收规则

- 打开或刷新探测器、数据库、路径分析及3D窗口不得启动追迹。
- 固定场景、设置和随机种子时，数据库、3D抽样、路径统计和探测器像素必须一致。
- `TraceOnly`只能累积兼容会话；不兼容请求必须明确要求清空并追迹。
- Simple Stochastic 必须可重复，并在足够样本下以规定统计误差接近完整 Fresnel 分裂。
- 取消、异常和文件发布失败不得破坏上一有效会话及旧数据库。
- 所有新增结果坐标必须携带类型化量纲和单位，不能从显示字符串推断。
- 百万射线验证使用独立性能基准；普通CI使用小规模确定性场景验证行为。

## 明确不承诺

不进行 Zemax 界面像素级复刻，不导入 Zemax NSC，不读写 ZRD，也不承诺完整 Zemax Filter String 兼容。验收目标是常用非序列工作流和公开物理语义对齐，而不是私有格式或内部实现兼容。
