# PARM 0 与评价函数面号导入修复

日期：2026-10-19。范围是此前 Sequential 全目录中受两类导入缺陷影响的 14 个名称，原文件、原比较请求和容差保持。原 95 镜头[逐镜头报告](../validation/zemax/2026-r1/sequential-corpus-2026-10-19/BY_LENS.md)保存修复前状态；本次另存复验，不能用导入成功覆盖其数值失败。

## 修复行为

- `PARM 0` 单独存入第 0 原生参数位置，不挤占原 `PARM 1..N` 的几何系数。特殊面型的非零值随只读几何和快照保留；负编号仍拒绝，受支持几何未实现的非零第 0 参数也明确拒绝，避免静默改变物理含义。
- 评价函数根据现有类型化参数表转换 Surface/EndSurface 槽位，统一转换原始整数参数与编辑别名。采样数、波长、视场、操作数行号、原始只读行及各操作数的零值约定保留；没有把所有整数都当成面号。
- Yolo 的 REAX/REAY 直接引用原坐标断点 9，不能改指相邻曲面 10。对有真实光线位置操作数引用的坐标断点，导入时保留其独立透明平面：先应用该断点的偏心和旋转，在其厚度平移之前建立平面，不引入孔径、折射或反射；相邻曲面保持原几何。支持范围限定于 REAX/REAY/REAR/REAZ 所需参考平面，其他原不支持的坐标断点引用继续明确拒绝。
- 复验确认 REAX/REAY/REAR 原来返回全局坐标，现通过共享 Core 的目标面坐标变换返回局部坐标。保持各操作数原有零面含义，特别是这些操作数的 0 仍指物面；没有改成像面，也没有改变追迹缓存键或其它操作数的坐标契约。

第一候选恢复了 13 个镜头，但 Yolo 的断点引用仍被拒绝；其 `matrix-v1` 捕获及 1268 项候选回归保留，最终结果使用 `matrix-v2`。最终 14 个镜头、21 个配置均完成导入及正式快照准备，原 PARM 0 和评价函数面号造成的准备错误清零。

## 认证边界

恢复导入不代表双折射、衍射、网格矢高、非序列组件、用户 DLL 或 Zernike/Chebyshev 几何已获得可计算支持。未支持能力仍由原门禁拒绝。Yolo 新增的 20 组本机原生操作数控制仍为 Difference，包含坐标断点及像面；没有为使其通过加入参考常量或放宽限值。其完整倾斜折返追迹差异需另行定位，本轮只关闭导入/引用表示的缺陷。
