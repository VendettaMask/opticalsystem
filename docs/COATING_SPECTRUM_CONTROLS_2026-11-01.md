# 镀膜光学评价：偏振、评估设置与结果导出

## 已实现

- T 蓝、R 红、A 绿，分别独立选择平均 / s / p；平均使用共享 Core 的非偏振功率，等于同波长、同角度 S/P 功率等权平均。OD 使用该功率的稳定 log(T)，不平均两个 OD。s 为虚线、p 为点线，平均为实线。
- 目标线切换、原设计目标编辑、网格、重置视图、刷新；PNG 捕获当前图像，去掉悬停辅助线，2 倍像素密度并在打开保存对话框前冻结。中性线宽菜单紧邻相机，细/标准/粗对应 1/1.5/2 倍原 1.5-DIP 线宽。
- 独立评估默认 **0°，400–800 nm，步长 0.5 nm，Y=0–100%，关闭自动范围**，801 个采样点。支持 nm/µm、百分比/比例/OD、自动 Y、最多 16 个不同角度；非整除步长保留原步长并额外包含上限端点。总波长点数乘角度数不超过 200001。
- “另存为默认”与“恢复默认”使用当前产品用户目录的独立、有界原子 JSON 文件；支持既有 `OPTICAL_SYSTEM_DESIGN_SETTINGS_DIRECTORY`。仅明确点击这两个命令写默认值，普通显示操作不覆盖原实验。
- 图下结果表按已选量/偏振/角度与当前单位生成，完整点数不随滚动、视图裁切或可见行减少。CSV/TSV/复制使用全精度 G17、不变区域格式，字段包含角度、偏振与单位；表格显示舍入不改数据。CSV 首列为 `wavelength_nm` 或 `wavelength_um`，例如 `T_average_45deg_percent` 明确表示 45° 非偏振透射百分比。
- 关闭、修改输入、切换实验和取消可终止后台显示采样，代次检查禁止旧结果覆盖；显示开关、线宽、单位、网格与纵轴变化不重新计算光学功率。

## 物理与验收

新增 Engine 只读评估入口从冻结的膜层/材料快照调用共享 Core，按声明波段/步长/角度取样。材料覆盖检查针对实际膜层、入射介质和基板，禁止外推。原 `Materials` 调用未提供评估波段时保持原检查。

独立评估不修改原目标、原偏振、结构、预算、采样协议、正式结果或达标门槛。状态栏同时注明评估角度与验收角度/偏振。评估曲线不替代原密集复验，原指标与公差区继续报告原结果。顶部完整实验导出与图下评估数据导出含义不同，实验文件没有悄悄升级或更改设计参数。

波段超出真实材料范围会清空显示并报错，不能据此认定原设计不达标。OD 图形最多显示到 12，表格/导出保留原始 OD。多角度的“平均”仍是各角度的 S/P 等权平均，不是角度平均。

## 验证范围

31/31 项定向检查通过，包含原协议保持、保存重开、未保存保护、五种主题、三种窗口尺寸，以及真实吸收材料 0°/35°/57° 的 S/P/平均逐点核对；检查独立角度/步长、默认值持久化/恢复、CSV/TSV 与当前数据逐值一致、nm/µm 与比例换算、PNG 尺寸、无重算显示切换和取消旧任务。随后根据离屏预览修正“恢复默认”的延后文本事件状态，最终完整依赖重新构建零警告/错误，对应 1 项交互/导出检查复跑通过；同一测试身份不累计为 32 项。实际离屏预览检查了设置及展开的结果表。截图中的三层膜系是交互夹具，光谱来自真实材料共享 Core 计算，不代表优化达标处方。

默认输出曾完整构建成功，后续默认文件被运行程序锁定；没有关闭用户窗口，最终使用独立输出构建并验证，不将其表述为最终默认输出替换成功。中途非序列边界接口的并行编译错误及中止试跑不计完成。日志和实际离屏图像见[证据](../validation/rechecks/2026-11-01/coating-spectrum-controls/README.md)。
