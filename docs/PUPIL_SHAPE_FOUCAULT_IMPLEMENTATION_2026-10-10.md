# 出瞳形状投影与物理 Foucault 刀口实现

2026-10-10 接通波前图的出瞳形状显示，并将 Foucault 从波前梯度着色替换为复振幅衍射刀口计算。两项均使用正式共享 C# Core，桌面只负责显示。它们不关闭既有 N01 Huygens、N02 DEE 数值残差，也不代表已经取得新的 Zemax 原生认证。

## 出瞳投影：改变显示，不改变计算

`WavefrontAnalysis` 调用共享 `DiffractionEngine.WorkingFNumbers`，X 使用 sagittal，Y 使用 tangential。定义 `sX=min(FX,FY)/FX`、`sY=min(FX,FY)/FY`；最大的显示半轴为 1，宽高比为 `FY/FX`。同一系统瞄准设置用于波前与 F 数追迹。

比例由 `AnalysisPlotOptions.SpatialDisplayScaleX/Y` 经应用契约传到 `WavefrontSurfaceControl`。伪彩色、等高线及三维表面坐标均应用该比例；原始点仍是入瞳归一化坐标，数据导出不偷偷换成出瞳毫米。关闭开关时比例恢复 1。结果明确列出显示模型、比例与所用方向 F 数。

无焦系统没有焦面 F 数定义，本轮保持归一化光瞳显示，明确报告不适用和 F 数未求值；没有虚构一个“实际出瞳”形状。任意三维出瞳的原生图形认证仍待完成。

## Foucault：复场传播与功率记账

实现入口为 `FoucaultEngine.Compute`；`FoucaultAnalysis` 不再包含经验梯度、拟合亮度或假环纹。

1. 以 N×N 单元中心采样正式主光线参考波前，遵循系统瞄准；输入圆瞳外和真实截断光线没有入射场。标量幅度为光线功率的平方根，OPD 提供相位。
2. 采用与正式 FFT 一致的共轭场约定：`exp(−i 2π OPD)` 配合负指数前向 FFT；偏振传输场也取相应共轭，保留界面相位，不重复添加光程或镀膜损耗。
3. 零填充到 `M=nextPowerOfTwo(4N)`。焦面间距分别为 `λµm FX N/M`、`λµm FY N/M`。增加填充只加密焦面网格，不增加实际追迹密度；N 支持 8～512，M 最大 2048。
4. 在带符号频率坐标施加物理半平面刀口。跨越刀口的频率单元采用面积平均的振幅透射率，恰好居中的边界单元为 1/2。这是明确的离散积分选择，不声称复现 Zemax 私有的边界像素规则。
5. 调用共享 FFT 的归一化逆变换，逐通道取复场模平方。保留输入圆瞳外的刀口衍射，不再将观察强度强行截回圆形或限制在 0～1。

输出显示中央 N×N 正方形；`InputPupilPowerSum`、完整填充观察面的 `OutputNearFieldPowerSum`、裁切显示区的 `DisplayedNearFieldPowerSum` 分开记录。`KnifeThroughput` 以完整观察面功率除以输入功率；裁切图的像素和不能代替总通光率。这些是等面积离散功率和，不是未经面积/功率标定的瓦特值。图形调色与最大刻度不改物理数据。

偏振通过正式 `TracePolarized` 获取 XYZ 复场：相干系统输入用三个场分量，非偏振用两个正交输入、各乘 1/√2 后分别求强度，总计六个通道。支持共享追迹已实现的透明各向同性均匀介质及受支持的镀膜；GRIN 和吸收接口的复折射率 Jones 传输仍明确拒绝，不静默退回标量。不支持参考位图配准/差值，也不接受旧“二次”显示选项。无焦系统须先定义聚焦/再成像光学系统，不能直接放一个 µm 焦面刀口。

线性/对数显示由类型化 `LogarithmicIntensity` 标记接线，结果行改名或本地化不会使对数失效。对数显示的 0 dB 对应 `max(1, 原始最大强度)`，低于 −60 dB 的颜色饱和为黑；这只是调色范围，不是功率归一化或刀口通光率。灰度零强度为黑、亮区为白；数据页保留未经显示变换的物理强度。
