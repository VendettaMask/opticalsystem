# 本机 Zemax 复核与衍射图像适配修复

日期：2026-10-16。已修复衍射核的偶数原点和上下方向两项图像接入错误，并恢复本机原生采集。**有效 F 数和扩展相对照度差异仍未关闭。** 本报告分别记录软件反例与原生数值比较。

## 两项已修复错误

Huygens 的物理网格零点在整数 `N/2`，行随物理 Y 递增；图像卷积核以 `a = floor((N-1)/2)` 为锚点，行向下递增。此前直接拷贝数组造成偶数核共同偏移一像素，以及离轴 PSF 上下翻转。

现在在图像适配边界按 `X=(column-a)×pitch`、`Y=(a-row)×pitch` 选择物理样本。偶数 N 使用 N+1 的奇数物理网格，取得原先缺少的边缘后截取所需 N×N 窗口；奇数 N 只转换行方向。没有循环移位、复制边缘或丢弃后补零，也没有改变 Huygens 的物理原点、有限单元 footprint、传播公式或通用 same 卷积。chief/centroid、偏振及既有几何回退报告继续有效。

新增边缘的真实直接传播工作量计入单 PSF、全部视场及全部波长的既有资源预算；几何模式保留原预算。资源超限在追迹前拒绝，不能由资源异常触发静默几何回退。

## 原十组反例复算

使用[修复前审计归档](../validation/repairs/2026-10-16/diffraction-kernel-open-audit-evidence.zip)中的原 `Program.cs`，源码字节不变，仅将诊断项目指向当前默认 Core 输出。六个 7/8/9/15/16/17 核控制与四个 ±0.5/±0.8 视场控制均保留原参数，全部仍为 Diffraction，零几何回退。

- 8/16 核卷积质心由 `(17,17)` 恢复到 `(16,16)`，浮点差低于 1e-13 像素；最终图像质心由约 `(16.999994975,16.999994975)` 恢复到 `(15.999998428,15.999998428)`。末端插值的原有微小偏差单独保留。
- +0.5 视场的预期向下偏移为 `0.794801937722125` 像素，实际为 `0.794801937722120`；负视场及 ±0.8 同样匹配。四组物理到像素偏移最大差低于 3e-14 像素。
- 奇数对称控制的质心保留原位；偶数窗口按实际物理边缘取样。有限窗口截掉非零尾部时允许真实窗口质心偏置，不能把每个有限窗口都要求成理想点，或强行移动 PSF 峰值。

这些是同一产品计算链的坐标/卷积反例，不能替代新的 Zemax 图像数值认证。
