# Tessar RMS 积分与连续渐晕修复 · 2026-10-07

本页保留 GQ 积分与连续渐晕阶段的历史结果（原矩阵 85 Pass、独立控制 17 Pass）。后续已完成 RA256 与单光线路径修复，并定位自动光阑导入误截光；当前结果及旧快照/重新导入两条路径见[最新报告](ZEMAX_RA256_SINGLE_RAY_REPAIR_2026-10-07.md)。下文误差与测试计数仅描述本历史阶段。

共享 Core 已修复两个可重复的问题：非偏振 RMS 光斑 GQ 积分错误地执行物理孔径截断，并把曲面边缘交叠产生的负距离交点当作追迹失败；连续视场的渐晕因子此前取最近定义行，未按原生的视场半径平方插值。

六份官方镜头原设置 **132 项**复算为 **85 Pass / 12 Close / 26 Difference / 8 Incomparable / 1 Error**，比上阶段增加一项 Pass：Tessar 的原 GQ6 RMS vs Field。已有 84 项 Pass 无回退。五份镜头的 **17 项独立 RMS 控制全部 Pass**，上阶段为 14 Pass / 3 Difference。本批没有改写任何原生数组、原设置、请求指纹或原逐量容差；原 132 项成功结果中 126 份原始 JSON 逐字节不变，5 份 RMS JSON 改变，只有 Tessar 改变分类。

## 原生逐光线证据

从本机实际 **OpticStudio 26.1.0 build 260127 / EnterpriseEdition / 有效 API 许可**采集五份镜头的同批 GQ6 入瞳点，包括有限共轭并启用瞄准的 Relay。Tessar 另采保留渐晕的完整 16 点扫描，以及负 Y、X、斜向视场控制。七份冻结控制共 **3384 条输入光线、28656 个逐面结果**，保留原生 error 与 vignette 两个独立标志、交点、方向、发射坐标、字段、版本和源文件 SHA-256。最终构建另补 Tessar GQ12 的轴上与边缘控制，576 条输入产生 5184 个逐面结果，零传播错误，XY 最大误差 **1.3501e-13 mm**；这是独立复验，不增加已比较镜头数。

Tessar 25° / GQ6 的 72 条光线，原生全部到达像面，其中 23 条带孔径渐晕标志。此前 Core 忽略孔径的诊断仍有 9 条停止：1 条在第 2 面、8 条在第 8 面。这些交点位于传播方向的负距离处；其他光线各面的 XY 误差低于 1.2e-13 mm。用全部原生像面点与正式 GQ 权重独立检查得到约 99.488303 µm，与原生 GQ6 RMS 的 99.488201 µm 相近；仅关闭孔径无法解释此前的 86.194326 µm，更不能解释正式物理截断后的 50.696297 µm。

官方本机手册第 843、1242 页限制了 GQ 在被表面孔径截断、非椭圆光瞳中的适用性；第 1851 页说明 Y 轴字段可插值、一般 X 字段表使用最近字段。**按半径平方分段插值的具体规则来自本批原生坐标实验，手册文字本身没有给出该公式。**原生负 Y 与 X 方向控制沿用相同压缩、偏心因子，证据没有支持额外翻转偏心或自动旋转。

## 实现范围

`SequentialRayTracer.TraceGaussianPupil` 使用正式共享表面交点、传播、材料、相互作用与坐标变换。只有显式 GQ 光瞳积分忽略物理孔径；通常交点不存在时，反向求同一几何的有效交点并以带符号距离传播。反向也无交点、传播失败或 TIR 均保持失败。负距离只支持均匀介质；正向 GRIN 仍走正式连续积分，新增回归验证它没有变为直线近似。

该积分不写正常追迹缓存或表面显示数据，不提供物理通过率。正常物理追迹、RA 孔径检查和通用几何的前向求交约定保持原流程。非偏振 RMS 光斑的视场、波长、离焦和场图通过共用 `RmsScanSupport.SpotRadius` 使用此积分；本批外部认证范围为捕获的 RMS vs Field，不能据此认证偏振 GQ、RMS 波前或所有扫描设置。

`RayGenerator` 对 **X 全为零、Y 非负且互不重复**的定义字段表，在相邻行间按实际字段半径平方分段插值五个渐晕因子；因此当前实验也覆盖负 Y、X 和斜向的查询。端点取端点值。一般 X 字段表、含负 Y 定义行或重复 Y 行保留最近字段选择，尚未对这些边界建立完整原生认证。采样、瞄准与相位均使用同一个解析后的变换。

比较工具新增独立 `--ray-audit <job.json>`：严格校验源哈希、方法和字段范围，从正式 Core 生成输入点，只允许新目录，持有独占运行锁，通过已安装原生 API 捕获逐面数据。字段、采样点和表面数共同受共享 200 万保留结果上限约束，原生端再次检查同一预算。它输出诊断证据，不产生 Pass 分类，也不改变已有分析请求模式。
