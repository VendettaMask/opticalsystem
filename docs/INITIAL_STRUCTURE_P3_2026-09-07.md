# P3 多家族搜索：实施与验证记录

日期：2026-09-07。状态：P3 引擎、检查点与确定性恢复已实现并验证；P4 新界面及 P5 发布验收尚未完成。

## 本阶段规则

- 根家族按允许片数轮流获得预算；首个家族保留 P2 的初始玻璃、前光阑和最小厚度，其余家族采用明确的真实玻璃分配、表面光阑位置以及可重复的合法厚度变化。全部根曲率严格为零。
- 默认允许材料集合为 P0 协议中的 N-BK7、N-F2、N-SF6，调用方可显式指定；逐项核对正式 Core 的目录材料及波长覆盖。不扩展允许集合，不使用临时或近似玻璃。无效项单独报告，剩余可用项继续运行。
- 初步探索后，对有希望的候选执行连续细化、单片／成对换玻璃、表面光阑变体及有界曲率／厚度扰动。每个分支保存父候选与原始平板来源；不把已有曲率的分支冒充平板根。
- P3 复用 P1/P2 求解器及正式 Core 光学分析，不新增追迹或像质算法。每个可展示的达标候选必须通过完整规格的加密正式分析。
- 根探索可有界并行，但按预定顺序汇总；后续自适应分支按确定顺序运行。片数／光阑／玻璃分组、精确指纹及结构距离控制展示多样性，全部试验记录仍保留。
- 检查点先记录并预扣即将派发的预算，完成后换成实际消耗。恢复时未结算的预留工作按完整额度计费并明确标为中断，不能返还可能已经消耗的预算。正常取消在有界批次完成、记录保存后结束；可精确恢复已完成批次，尚不恢复求解器内部雅可比状态。
- 新搜索采用独立契约和算法身份，不修改 P0 冻结规格及容差，不替换旧实验室桌面 v3 的运行服务。P4 再接入界面。

本阶段首先实现离散的有效表面光阑位置；空气间隔内额外独立光阑面的连续移动仍需后续单独扩展，不能声称已实现。

## 实现入口与计算边界

`FlatStartSearchService.RunAsync(specification, options, cancellationToken, checkpoint, checkpointSink)` 是新入口，算法身份为 `strict-flat-family-search/v1`。默认材料集合采用冻结协议的三个目录玻璃。可复用的 `FlatStartFamily` 显式指定每片玻璃、根中心厚度／空气隙和实际顺序面编号的光阑位置；未提供该参数时，既有 P1/P2 单家族入口保持原行为和身份。提供家族参数的子求解分别记录 `strict-flat-family-bootstrap/v1`、`strict-flat-family-design/v1`。

搜索器只提出材料、光阑及变量变化，组合正式返回值进行排序和约束判断。所有系统功率、焦距、F/#、色散、表面几何、追迹、点列及最终分视场数据继续来自正式 Core。没有在实验室增加第二套光学分析。此阶段不修改正式 Core 的实现及数值基线。

初始家族按片数轮转，第一轮采用初始玻璃、前光阑和最小厚度；后续轮次采用可重复的厚度变化、交替真实材料以及中间／末端表面光阑。约 55% 总评价预算均分给预定根，每个根另受单次上限限制；未用余额进入细化阶段。余额很小时仍保留完整验收的真实状态，不伪造达标候选。种子数或预算不足以覆盖片数范围时发布 `search.incomplete-coverage`。

细化按固定顺序循环连续细化、单片换玻璃、成对换玻璃、表面光阑变化、有界参数扰动，并轮换结构不同的父候选。没有可继续的正焦距候选时，另建零曲率根继续探索。参数扰动和结构距离仅处理已有变量，不计算任何新的光学量。每个子候选保留父候选 ID、原始根指纹及起始快照；根保留启动记录和首次曲率更新，最终结果保留阶段入口、首次连续更新及完整目标的加密验证。压缩的阶段日志省略搜索残差向量，不能当作逐步雅可比重放日志。

候选先按正式验收状态、目标差距排序，然后按片数／实际光阑面／实际玻璃组合分组，优先展示不同家族，组内使用变量距离排除近乎相同的结果。精确光学快照指纹进一步去重。展示上限默认为 8；全部试验及其失败原因仍在检查点中。`CandidateLineage.StopVariant` 在新搜索中记录实际顺序面编号，旧算法的 0/1/2 变体含义不变，按算法身份区分。

## 预算、取消和恢复

- P3 限制最多 128 个初始家族、256 个试验、64 个允许玻璃名称和 64 个展示候选；总评价仍受规格的 100,000 次上限约束。根阶段实际并行数不超过 4，后续自适应分支顺序执行。
- 每批先保存 `Reserved` 记录并预扣额度，完成后换成实际评价数。实际追迹光线数单列，连续细化不会重复计算父候选的历史消耗。失败分支不终止其他分支；无法确认消耗的失败保留完整预扣额度，并通过诊断说明。
- 每次子求解使用总运行剩余时间及按分配额度估算的时间上限，P1/P2 在原有请求／迭代边界检查。普通取消等待当前有界批次完成再保存退出；不是即时停止一条光线。已完成批次的恢复保留运行 ID、试验顺序及已用预算，确定性测试要求未触发时间截止。
- 进程意外中断留下的 `Reserved` 记录恢复为 `Interrupted`；完整预留评价额度与该批预留墙钟上限都继续计费，实际完成次数为 null。未知光线工作不能混入已确认的光线计数。中断的内部求解状态尚不恢复，也不返还可能已经使用的预算。
- `FlatStartSearchCheckpointStore` 独立于旧检查点，使用 SHA-256 包装、64 MiB 有界 JSON 及正式 Core 原子文件写入；内容超限明确失败并保留原检查点。加载校验结构、光学快照、状态、谱系和预算；继续运行额外核对规格、选项、根计划、实际目录材料和候选快照指纹。校验和是损坏检测，不是数字签名。

## 最终验证与实际结果

完整实验室回归 **91/91**，0 失败、0 跳过，约 11 分 21 秒；包括既有 63 项和本阶段 28 项。随后完善不同状态之间的同家族近似去重，并在最终代码上重跑 P3 功能子集 **16/16**；该子集已包含在 91 项中，不能相加为 107 项。独立实验室默认 Debug/Release 构建均为 0 警告、0 错误，格式与差异检查通过。本阶段没有修改正式 Core，没有重跑正式全量或定向测试；P2 的正式 46/46 仍是此前记录，不算本次新验证。

12 个冻结规格均保留原目标、容差、预算和种子 101，每个规格实际使用 **10,000 次评价**；全部预定根完成，未出现失败或未知中断试验。4 个规格找到达标候选，8 个仍未达标，成功覆盖率没有比 P2 的 4/12 增加。前四个规格分别找到 20、32、49、47 个不同玻璃／表面光阑组合的达标家族。这里的家族数不代表不同片数，因为冻结规格每项片数固定。
