# 初始结构 SPC：真正鞍点与双分支优化

后续自动准备、数值续跑和产品入口已完成后台验证，默认输出更新待解除占用，见[后续交付](INITIAL_STRUCTURE_SPC_AUTOMATIC_RESUME_2026-11-01.md)。下文保留算法层首轮交付的原范围与结果。

2026-11-01。本轮交付显式、单层、空气分隔的 SPC 研究 API：先优化父结构，在声明的曲率子空间内检查父极小点，构造零元件并确认一个负曲率方向，沿两个符号优化，再恢复真实厚度、间隔和目录玻璃，使用原完整验收。它扩展了 [M3.1 过渡基础](INITIAL_STRUCTURE_M3_1_2026-10-30.md)，没有把零厚度编译或正负扰动本身当成 SPC 完成。

**已实现算法和便携研究记录；尚未接入桌面自动准备流程、SPC 断点续跑、自主胶合调度或递归增长。** 原有准备检查点和 M3.6 报告的支持范围不自动扩大。自动口径仍暂缓，F/4 继续保留规格冲突。

## 计算与验收

1. `SpcBranchSearch.Run` 读取原 `AutonomousSearchPlan`，先检查外置光阑矛盾、插片权限、原片数上限、保护片和球面支持域。不能通过修改许可、口径或片数上限让任务进入 SPC。
2. 在原曲率边界内用 BFGS 优化未保护的非平面曲率，保留参考面、光阑、像面、原厚度、材料、净/机械口径及面型。父结构需通过原制造检查，并在声明的曲率变量内达到内部驻点和正曲率检查；这不是对所有轴向、面型、玻璃变量的全局极小证明。
3. 旧玻璃后表面之后加入同材质、同曲率、零厚度及零轴向空气间隔的两个独立面。共享 Core 提供显式 `EvaluateNullElementContinuation`：只对声明的两个重合面允许有符号交点，强制 CPU，执行身份为 `cpu-null-element-continuation/1`。普通追迹、GPU 路径和正式制造验收不启用此研究续延。
4. 对真实 AD 梯度作中心差分，分别使用 h=0.001 和 h/2 的无量纲坐标步长，求对称 Hessian 的谱；记录非对称误差和两步长差异，要求所有特征值与保守数值不确定度分离，且恰好一个负方向。没有用半正定 Gauss–Newton 矩阵证明鞍点。
5. 沿规范化负特征向量的两个符号出发，以绝对曲率尺度作预条件后分别下降，记录驻点及同样的 h/h2 正曲率检查。未确认的分支不进入实体化。
6. 依次恢复原最小中心厚度的 1、2、4 倍及原最小真实空气间隔，使用既有固定拓扑补偿和原目录材料权限。仅将实体坐标向可行侧取相邻浮点数以满足原最小间隔，不修改门槛或引入放宽容差。每阶段均留原 21 视场、10×32 高斯采样、独立中心/边缘、逐波长及制造验收；失败材料阶段也保存。

光学值、材料、交点、折射和导数全部由共享 Core 提供；模块只组合搜索残差、数值搜索和预算。零厚度状态不能成为普通合格镜头。`InitialStructureSpcTransitionV1` 和历史检查点身份未重写。

研究步骤参考 [Maurey 等，SPC 自动双片搜索](https://doi.org/10.1051/jeos/2026024) 的零元件、双符号和逐步实体化方法。本轮实现空气分隔研究路线及声明变量内的数值检查，不复现论文的胶合调度或其性能结果，也不使用论文的规格替换本产品原任务。

## 固定预算对照

正式输入先冻结，再运行种子 42–46。两臂使用同一既有 M3.1 作者样例中的单片几何、原默认目标和制造门槛：f=50 mm、F/12.5、边视场3°、光阑半径2 mm、逐面净半径5 mm，RMS≤50 µm、最大半径≤150 µm、畸变≤3%、有效光线≥98%，中心/边界独立检查保持。该样例不是原广角 F/8 或 F/4 任务。

各臂每次总上限均为 **600 函数、600 梯度、2,000,000 条实际 CPU 光线、120秒**。这些是总上限，不强制耗尽；每轮包括父结构优化、研究评价、数值曲率探测、实体补偿和搜索内密集验收。直接插片对照保留相同父优化、材料和厚度阶段，使用两个小共弯曲起点，省去鞍点及零厚度优化，因而不是将同一条物理路线重复计数。外部独立复验与工程回读单列，不回馈搜索。

| 固定源码副本的一次代表运行 | 直接插片 | SPC |
| --- | ---: | ---: |
| 合格正厚度分支 | 2 | 2 |
| 函数 / 梯度 | 32 / 22 | 161 / 151 |
| 实际 CPU 光线 | 456,468 | 503,394 |
| 负支最差视场 RMS | 15.109 µm | 12.324 µm |
| 正支最差视场 RMS | 14.996 µm | 10.799 µm |

五种子两臂各10个分支验收通过，但各臂只产生 **2 个不同物理终点**；一个父结构、一个可选位置和确定性优化使种子结果重复，不计为五种独立设计的统计成功率证据。SPC 相比此直接插片对照改善了两个分支的 RMS，但增加了成本，不能据此宣称普适提速。

原初始父结构不合格，经过两臂共同的父优化后已合格，最差 RMS **10.025 µm**，仍优于这两个实体 SPC 子结构，且少一片。因此本轮没有得到相对合格父结构的复杂度/像质支配收益，不自动将增长分支推入原合格方案集；零态目标下降也不能替代实体像质比较。负支的 N-F2 替换未通过原完整验收，保留失败并选择原许可 N-BK7 阶段。

SPC 零元件的细步长 Hessian 特征值为约 `[-1.887067e-4, 5.637887e-4, 8.823647e-2, 2.991709e3]`，数值不确定度约 `1.338223e-6`，稳定负方向为1；两个下降端的全部特征值通过正曲率检查。结论仅适用于记录的变量尺度、目标、采样及支持域。

## API、记录及验证范围

- [Engine](../labs/InitialStructure/src/OpticalSystemDesign.InitialStructure.Engine/SpcBranchSearch.cs)：显式一层运行及协议指纹；`ParaxialSeedSearchOptions` 在此仅提供函数、实际光线和时间三项总上限，梯度等策略由 `SpcBranchOptions` 提供，其他准备子策略不在此执行。默认搜索不自动调用本 API。
- [Contracts](../labs/InitialStructure/src/OpticalSystemDesign.InitialStructure.Contracts/SpcBranchModels.cs)：父驻点、Hessian 双步长、两支驻点、实体阶段、原验收及费用。
- [便携研究文件](../labs/InitialStructure/src/OpticalSystemDesign.InitialStructure.Persistence/SpcBranchStudyFiles.cs)：64 MiB 有界原子写入，算法/协议/内容校验，独立于自主搜索检查点。新进程加载10份记录为零追迹，不升级验收，不构成可恢复优化器状态。

共享工作目录的75项相关回归通过；固定源码副本重跑其中48项SPC专项，并额外通过23项原Core导数、制造几何和独立边界像斑检查。重复用例不相加为独立覆盖；总计98个不同的通过用例身份。默认含两个内置模块的Release主程序构建零警告、零错误。没有全仓、GPU、前台GUI或跨平台认证，也没有提交、推送或发布。

首批共享构建对照和后续固定源码对照分别保留，两批均为十次、各965函数/865梯度、4,799,310条搜索内实际光线；固定源码批累计活动时间81.097秒。每批另有40次分支独立验收/STAROPT回读、15个原任务零工作守卫及5份原F/8精确复验。早期零态普通追迹失败、最小间隔浮点下溢、编译和取消测试失败、源码冻结发现的其他模块并行变化均保留；没有用新的成功覆盖旧失败。最终固定运行时577条PDB文档校验匹配，598份执行源码/资源封存，正式运行前后文件哈希不变。具体时长、开发试探成本、失败材料、原始处方和完整证据见[验证目录](../validation/rechecks/2026-11-01/spc-branches/README.md)。
