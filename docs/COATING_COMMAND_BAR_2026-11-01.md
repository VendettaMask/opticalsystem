# 镀膜窗口顶部工具栏

后续工作区已调整为左右双窗格，并将常驻参数移到“设计 / 优化”菜单，当前状态见[桌面工作区](COATING_DESKTOP_WORKSPACE_2026-11-01.md)。本页保留先前工具栏阶段的范围。

## 已实现

去掉窗口内容中的重复大标题与流程标语，将原来的三层头部收为单行桌面工具栏。正常字号 13 的离屏工具栏高 43 DIP；字号 18 时随文字增长，不压缩字体。

- 左侧按文件操作、示例、材料分组，使用共享本地图标和文字。空闲按钮不再逐个画边框，保留原生悬停、按下、键盘焦点和下拉状态。
- 减反、高反、窄带收入原生“示例”菜单，只显示一处下拉箭头。选择仍走原来的未保存修改保护、实验载入和任务跟踪。
- 宽窗口右侧显示当前实验名，随名称编辑/打开同步；过长时省略并提供完整提示。窄窗口将空间优先留给命令，名称仍可在左侧编辑。
- 命令不换成多排按钮；极窄空间保留横向滚动与焦点访问，滚动条轨道隐藏。
- 标题栏使用“光学镀膜设计”。工具栏不重复宣传式标题；正文获得更多高度。
- Ctrl/Cmd+O、Ctrl/Cmd+S、F5 和 Esc 保持原操作。示例菜单文字支持当前中文、英文和日文设置，在打开时更新。

膜层色点、名称/来源层级和数字对齐保留；没有更改真实材料、优化器、采样或验收。

## 验证边界

独立目录的 Release Win-x64 App 及完整项目依赖已经构建成功，零警告/错误。上一轮非序列转换器的工作区编译错误本次未再出现；本次未修改该模块。测试程序集在上述依赖上构建成功。

用户正在使用的默认输出未替换，未关闭窗口、启动前台软件或注入原生输入。离屏验证不等同于默认输出或原生桌面验收。截图中的 32 层处方是布局夹具，不是优化结果。

实现位于 `MainWindow.Commands.cs`，布局接入位于 `MainWindow.cs`。示例菜单回归通过点击真实离屏下拉按钮确认打开，再派发菜单项 Click 事件；不宣称原生弹出窗口指针验收。
