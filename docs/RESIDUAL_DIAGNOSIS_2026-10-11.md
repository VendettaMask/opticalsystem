## N02：已分离显示插值与积分节点

对最大距离 2.5、5、10 µm 的六条原生曲线检查分段三次多项式。节点间距为各自最大距离除以 31，即 32 个均匀节点。仅为识别显示算法，诊断从同一段的四个原生输出点还原节点，再调用正式自然三次样条；这些原生节点不会送入产品或用来补偿 Core 曲线。

最大距离 2.5 µm 时，理想/实际 401 点的还原相对 L2 分别为 `1.5518410293081862e-14` 和 `1.6636105960932746e-14`，确认这些捕获的显示插值为自然三次样条。5/10 µm 存在平台及限幅区，局部多项式还原的值只是显示节点，不能认定全部等于未限幅积分节点；10 µm 理想曲线的还原差异尤其不能忽略。

[Zemax 官方社区的开发团队确认](https://community.zemax.com/got-a-question-7/zpl-macro-or-api-for-diffraction-encircle-energy-caculation-in-multi-configuration-2054?postid=6879)说明 API 曲线会插值输出，并采用三次样条。32 个节点的数量来自本轮冻结捕获测量，不外推所有版本或档位。

三组范围的第一个显示节点均满足 `E(r1)=E(r2)/4` 至舍入误差；同一物理半径位于第一节点时，会与其他范围内的后续节点不同。例如实际曲线在 `r=0.16129032258064516 µm`，最大距离 2.5 µm 的第二节点为 `0.08490006415226437`，最大距离 5 µm 的第一节点为 `0.05880156139599424`。这是已观测的范围相关显示行为，尚不能据此推断通用物理积分规则。

即使使用正确的显示插值，正式积分节点仍不一致。例如 `r=0.3225806451612903 µm`：

| 曲线 | 原生显示节点 | 当前 Core 像素面积积分节点 |
| --- | ---: | ---: |
| 理想 | 0.49997463879224613 | 0.46080107416223665 |
| 实际 | 0.2352062455839754 | 0.1991959190730238 |

因此不能只补样条就宣布 N02 修复。本轮另检查双线性范围重采样、保持瞳孔不变的积分加密、完整/中央窗口、相位插值开关、其他瞳孔网格及标准二维三次插值。所有候选都未成为原设置下的精度通过结果；加密是分层诊断，不能改变原档位验收。
