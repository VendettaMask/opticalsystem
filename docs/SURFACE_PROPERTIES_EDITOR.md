## 界面结构

镜头数据表上方使用紧凑横条：“展开/收起圆形按钮 + 表面 N 属性 + 上一面/下一面圆形按钮”，不再使用 240 DIP 宽的“表面类型与属性”标题按钮。三个按钮为 28 DIP，标题随选中行更新；首尾面禁用对应方向，前后切换同步表格选中行和属性内容，不改变展开状态。默认收起，展开后保留原有分类和功能。

展开后的左侧导航依次为：类型、绘图、孔径、散射、倾斜/偏心、物理光学、膜层、导入、复合、偏振。右侧显示所选分类，底部共用“应用”和“还原”。标题条使用现有主题资源，圆形按钮沿用普通主题的淡蓝背景及交互状态。

面板高度限定为 300 DIP，导航宽度 124 DIP，属性页内部滚动；类型页的两组设置在宽度不足时换行，不无限增加整块面板高度。标签和控件横向并列；下拉控件复用已有的局部设置背景规则，不修改全局主题。切换分类不提交草稿，“还原”恢复当前表面的已提交值；切换表面会丢弃旧表面的未应用草稿，避免写到另一个表面。

## 当前支持边界

标准球面/圆锥与平面在界面上统一为“标准面”。表面类型下拉框不再提供独立“平面”选项，镜头表、属性摘要及导入页使用同一名称；曲率半径为“无限”/∞ 时是标准面的平面情形（曲率为零），输入有限半径即恢复相应曲面。此规则不把带有非零高阶项的非球面按基底半径自动改成标准面；平面光栅等有独立物理语义的类型保持独立。

底层 `PlaneGeometry`、旧 DTO 几何名称与序列化继续兼容已有文件。应用“标准面”时保留已有平面组件；从其他面型切回标准面保留当前半径及圆锥系数，不再将零曲率的无穷半径默认改为 40 mm。未修改 Core 追迹公式或处方文件格式。

## 编辑安全

- 组件、光阑和膜层在同一工作区事务中应用，仅产生一个修订和一个撤销步骤；净口径状态由表格中的统一求解入口单独提交并使用既有原生保存链路持久化。
- 物面和像面不能设为光阑。已有光阑不能直接取消，应在另一个物理表面上“设为光阑”；新光阑替换旧光阑，保持唯一。
- 已有几何、孔径或膜层名称/类型未改时保留原组件及其导入参数。更换孔径类型时使用当前净半径初始化，净半径本身不覆盖原有物理孔径尺寸。
- 不支持的导入几何由服务/运行时拒绝编辑，不仅是 UI 禁用；非法净半径在修改前拒绝，事务失败不留下部分更改。
- 坐标/散射只读信息由 `SurfaceInspectionDto` 传递，不通过文字解析或默认值猜测。
- 上一面/下一面切换前完成表格待提交数值编辑，等待已排队的行刷新后再选择新行；工作区修订变化后取消旧导航请求。属性草稿仍按原规则在切换面时丢弃，不自动应用。

2026-09-05 移除上方“添加 / 删除”按钮，改为右键行菜单的“下插入、上插入、删除”。仅这三项；物面和像面不能删除，禁止在物面前和像面后插入。插入后选中新行，删除后选中邻近行；支持撤销/重做与原生文件保存重载。插入保留已有组件，并重排拾取关系和多配置覆盖的面序号。菜单出现前完成待提交数值编辑，修订变化后禁止执行旧菜单命令。详细默认值与验证记录见 [UI 设计检查](UI_DESIGN_REVIEW.md#2026-09-05-镜头数据右键插入与删除)。

## 延伸区（2026-10-02）

镜头表原“延伸区”列现可编辑有限非负 mm 值；通过 `ChipZone` 保存、撤销与恢复。原列宽、顺序及材料行蓝色不变，非法输入使用现有校验反馈。默认机械半径包含延伸区，显式机械半径保持独立。TSAG、体积、毛坯和 CAD 使用该边界；详细支持范围、外部文件限制及验证见[指定方向矢高与延伸区](DIRECTIONAL_SAG_OPERAND_2026-10-02.md)。
