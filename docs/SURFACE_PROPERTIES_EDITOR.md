## 界面结构

镜头数据表上方使用紧凑横条：“展开/收起圆形按钮 + 表面 N 属性 + 上一面/下一面圆形按钮”，不再使用 240 DIP 宽的“表面类型与属性”标题按钮。三个按钮为 28 DIP，标题随选中行更新；首尾面禁用对应方向，前后切换同步表格选中行和属性内容，不改变展开状态。默认收起，展开后保留原有分类和功能。

展开后的左侧导航依次为：类型、绘图、孔径、散射、倾斜/偏心、物理光学、膜层、导入、复合、偏振。右侧显示所选分类，底部共用“应用”和“还原”。标题条使用现有主题资源，圆形按钮沿用普通主题的淡蓝背景及交互状态。

面板高度限定为 300 DIP，导航宽度 124 DIP，属性页内部滚动；类型页的两组设置在宽度不足时换行，不无限增加整块面板高度。标签和控件横向并列；下拉控件复用已有的局部设置背景规则，不修改全局主题。切换分类不提交草稿，“还原”恢复当前表面的已提交值；切换表面会丢弃旧表面的未应用草稿，避免写到另一个表面。

## 当前支持边界

| 分类 | 可用内容 | 尚未实现或只读部分 |
| --- | --- | --- |
| 类型 | 现有几何类型、设为光阑；光栅类型显示级次/周期/槽角，已有薄透镜交互显示焦距 | 表面颜色、透明度、行颜色、全局坐标参考面、超半球面限制、忽略表面均禁用并注明未实现 |
| 绘图 | 只读显示实际表面角色、净半径和机械半直径 | 独立颜色/透明度/隐藏控制未实现 |
| 孔径 | 现有物理孔径类型、固定净半径开关及数值 | 物理孔径具体参数没有新增编辑器；类型不变时保留原有参数 |
| 散射 | 只读显示实际模型标识，无模型时显示“无” | 不提供参数编辑，不把主光线损耗近似描述成完整 BSDF |
| 倾斜/偏心 | 只读显示实际全局 X/Y/Z 及三个旋转角，不填假零值 | Zemax 的前后变换顺序、返回/参考面编辑未接入 |
| 物理光学 | 只读显示当前交互模型 | 无逐表面 POP 传播设置；不能用系统级 PSF 分析冒充 |
| 膜层 | 名称编辑，留空/None 取消膜层 | 沿用现有非 None 名称的透过率起伏近似，非完整多层薄膜求解 |
| 导入 | 当前面型与计算/编辑支持状态 | 无逐表面导入/DLL 配置；不支持的面型保留原始数据并只读 |
| 复合 | 明确显示未实现说明 | 无可应用的复合参数 |
| 偏振 | 说明现有 Jones/Fresnel 分析边界 | 无逐表面覆盖参数 |

禁用的外观默认值不构成导入文件原始属性的读取结果；未实现的追迹开关不会参与计算。本次不新增 Zemax 面型或 POP/散射算法。

## 编辑安全

- 组件、光阑、膜层和固定净半径在同一工作区事务中应用，仅产生一个修订和一个撤销步骤；使用既有原生保存链路持久化。
- 物面和像面不能设为光阑。已有光阑不能直接取消，应在另一个物理表面上“设为光阑”；新光阑替换旧光阑，保持唯一。
- 已有几何、孔径或膜层名称/类型未改时保留原组件及其导入参数。更换孔径类型时用本次提交的固定净半径初始化，净半径本身不覆盖原有物理孔径尺寸。
- 不支持的导入几何由服务/运行时拒绝编辑，不仅是 UI 禁用；非法净半径在修改前拒绝，事务失败不留下部分更改。
- 坐标/散射只读信息由 `SurfaceInspectionDto` 传递，不通过文字解析或默认值猜测。
- 上一面/下一面切换前完成表格待提交数值编辑，等待已排队的行刷新后再选择新行；工作区修订变化后取消旧导航请求。属性草稿仍按原规则在切换面时丢弃，不自动应用。
