## 确认存在的问题

### 非主波长完整 OPD 曲线

20 个完整 OPD 扇形请求中，10 Pass、10 Difference；差异请求都选择了非主波长。Riflescope 边缘视场短波最大绝对差 **1.004463856 波**，双筒两配置约 **0.1880858585 波**，棱镜最差约 **0.06426401065 波**。主波长曲线通过。

另外重采的 13 组、169 个显式瞳点，使用原生 `CurrentAndChief` 定义，全部通过，最大绝对差 **8.4963611×10⁻⁶ 波**。逐点控制和完整分析的参考定义不同，不能相互代替。下一步须核对完整曲线的主波长参考方向、参考平面与波数归一化；当前没有认定所有差异的唯一根因。

### 扩束镜 RMS 光斑统计

20 个光斑请求中，18 Pass，Beam 的两个重复范围请求 Difference。Core RMS 为 **0.0003262103276 mrad**，Zemax 约 **0.0007584519350 mrad**，绝对差 **0.0004322416073 mrad**；GEO 半径差仅 **8.32×10⁻¹⁴ mrad**。几何外包络一致，RMS 统计仍不同。原文件含高斯输入设置；权重、瞳采样和参考定义需继续核对，当前不把高斯权重作为已证明的唯一原因。

原生光斑图坐标单位和 RMS/GEO 报表单位各自读取。Riflescope/Beam 原生指标为角秒，双筒/棱镜为微弧度；诊断按各自明确读回转换为 mrad，没有套用系统单位或通过修改产品轴标签凑齐结果。

### 无焦能量、截面和 RMS 输出定义

下列 **25 项**无法建立相同量纲的比较：几何包围能量、衍射包围能量、FFT PSF 截面、Huygens PSF 截面和 RMS vs Field，各五项。Core 的类型化轴仍给出毫米/微米，原生无焦结果使用角度。需要修正实际计算及共享结果契约，不能只替换显示单位。

### 惠更斯手动间距缩小 1000 倍

在原 150 项之外，预先声明同样的物理角间距，补采五配置各四种分析，共 20 个独立控制。瞳采样 64、像方网格 128；Riflescope/双筒为 0.05 mrad，Beam 为 0.005 mrad，棱镜为 0.02 mrad。原生输入转换到文件声明的角单位，不拟合尺度、平移、重采样或峰值。

**FFT PSF 五项全部通过。Huygens PSF 五项输出的实际角间距却都只有请求值的 1/1000**，例如请求 0.05 mrad，输出 `PixelPitchMilliradians=0.00005`。Application 的历史 `ImageDeltaMicrometers` 设置无条件除以 1000，而无焦 Huygens 入口与输出按 mrad 解释这一间距，形成链路契约错误。Huygens MTF 同样读回该错误间距。

这 20 个控制为 **6 Pass / 9 Difference / 5 Incomparable**：FFT PSF 5 Pass，Huygens MTF 1 Pass / 4 Difference，Huygens through-focus 5 Difference，Huygens PSF 5 网格不可比。原范围自动间距的 Huygens MTF 为 1 Pass / 4 Close，through-focus 五项 Difference。这些差异需要先修正角间距和网格，再判断传播算法残差；不能把它们宣称为相同实际网格下的数值认证。through-focus 仍保留各实现原采样数及既有有界曲线插值，未修改显示曲线来匹配。

原范围 FFT PSF 为 1 Pass / 4 自动坐标网格不一致，Huygens PSF 五项自动网格均不一致。固定手动网格关闭了本轮 FFT PSF 的直接网格阻断，没有认证所有采样、波长和视场。

### 一阶报表与单光线报告

一阶参数五项为 2 Pass / 3 Difference。双筒两配置的 EFL 报表差约 5.42×10⁴ mm；棱镜 Core 报 0、原生使用 10¹⁰ mm EFL 和 10⁹ F 数。这是近零光焦度、无穷量与原生有限哨兵值的报告语义问题，不能把这些数直接解释为真实焦距误差。

20 个单光线报告为 6 Pass / 14 Incomparable。双筒八项在生成附带 2D 布局时被 POB 组内路径能力检查阻断；数值报告不应因此无法交付。棱镜六项的 Core 折叠后八个面与原生十六个源面，尚未在此报表适配器建立物理面对应。独立逐面审计已按物理面映射通过，不能把报告适配问题称为物理光线错误。

## 尚无有效原生参考的范围

相对照度五项均未获得有效原生数值。额外五次保留原设置的诊断复采，原生文本和消息明确给出“无法计算相对照度...”；其数值序列缓冲区为空。比较工具现在先保存原生文本与诊断，再读取数值，防止空缓冲区异常隐藏说明。这五项仍不可比，不归为已确认的 Core 精度超差。
