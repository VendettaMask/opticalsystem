## 计算范围

- `CoherentThinFilmSolver` 版本为 `coherent-scattering/2`。既有 R/T/A 与对数透射接口保留，新增 `EvaluateAmplitude` 返回 S 或 P 的复反射振幅、透射相位及功率归一化透射振幅；非偏振光没有单一相干振幅，不能传给该接口。
- 反射振幅统一到 `p = s × 传播方向` 的正交光线基底；透明出射介质的透射振幅模平方等于 T。半无限吸收基底仍可计算复反射与进入基底的功率，但 `PowerTransmission` 为空，不能用实光线 Jones 向量代替其中的非均匀波。有限吸收膜层两侧均为透明介质时可传输完整复振幅。
- 稳定散射递推继续只使用衰减传播因子，透射模在对数域累计，并保留复相位。强吸收造成透射振幅下溢为零时，有限的 `LogTransmittance` 仍保留。物理约定为 n+ik、exp(-iωt)、nm、入射角度数、入射侧到基底的层序；背景说明见 [Byrnes 的多层膜计算论文](https://arxiv.org/abs/1603.02720)。产品计算没有引入外部 Python 或其它薄膜运行时。
- 新 `CoherentMultilayerCoating` 使用明确的 `coherent_multilayer` kind；材料被深拷贝，公开层表也返回拷贝，修改需替换模型。层数上限 4096、厚度必须非负有限、材料传播模型必须均匀。没有把旧经验起伏模型或旧 `thin_film_stack` 名称改解释为真实膜系。
- 正式表面引擎向镀膜提供实际入射方向、法线和两侧 n/k。角度来自入射光线，不能用折射后的方向代替。普通标量追迹使用单界面的非偏振平均功率；偏振照度绕过这一步标量乘法，按追迹发布的作用类型传播完整 S/P 复振幅，避免重复衰减。像面终点仍在其自身镀膜和折射之前。

上述连接复用正式相交、材料传播和光线坐标，不在实验室或照度服务中复制光学追迹。每次物理镀膜求值目前会构造求解器和材料拷贝；大膜系、大光瞳网格的性能尚未专门验收。

## 保存和兼容

JSON 与 STAROPT 完整保存每层材料快照及 nm 厚度，保持 schema 6；新增 kind 属于组件类型扩展，旧读取器应拒绝不认识的类型。层数必须为 0–4096 的整数，材料子节点数量匹配，缺失层厚、材料或内部必要系数均拒绝。重建材料后再次核对规范快照，不能以旧材料读取器的缺省折射率补齐缺失数据。详见 [STAROPT 格式](STAROPT_FILE_FORMAT.md)。

这不包含膜层编辑 UI、镀膜实验室向当前镜头的应用按钮或 ZMX `COAT` 名称到真实膜层的自动解析。`.coating.json` 仍是独立实验文件；实验室不会隐式修改当前镜头。
