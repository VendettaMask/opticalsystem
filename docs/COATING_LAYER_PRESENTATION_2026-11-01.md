# 镀膜膜层表视觉与材料色标

## 已实现

- 缩短表头为“材料”，把入射方向和编辑提示移到卡片标题区，减轻表头背景。
- 将材料名称末尾的括号注记分为次要文字，悬停保留完整名称，剪贴板也保留完整名称。没有改写材料 ID、来源或 n/k。
- 材料名前增加小圆点。同一窗口按材料 ID 维护颜色映射，初次按实验膜料 ID 排序分配，层序调整、重复膜层、材料替换和主题切换保持对应关系。颜色仅用于识别，未作为实验物理参数保存；不承诺跨不同材料集合或不同窗口的全局配色一致。
- 膜厚使用共享数字字体并右对齐；层序、变量控件居中。变量可直接勾选，仍通过原行属性使结果失效。
- 表格随用户字号调整行高、表头高度和数值列宽。修正数字内容与单元格双重内边距导致普通字号层序被挤掉的问题；保留原生编辑、焦点、选中和错误状态。
- 新提示提供中文、英文和日文翻译。未增加新的优化、验收或材料模型分支。
