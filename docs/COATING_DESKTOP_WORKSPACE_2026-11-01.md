# 镀膜桌面工作区与设置入口

## 当前界面

主界面采用“膜系编辑器 / 光学评价”左右双窗格，中间分隔线可拖动，两侧至少保留 300 DIP。原有常驻参数侧栏已移除。膜层表使用剩余高度，光谱及逐项指标留在右侧；窄窗口或大字号允许表格横向滚动，不压小字体。

顶部为一行图标文字工具栏，不重复大标题或流程标语：

| 入口 | 内容 |
| --- | --- |
| 打开 / 保存 / 导出 | 原实验文件与结果操作，快捷键保留 |
| 示例 | 减反膜、高反膜、窄带滤光片 |
| 设计 | 设计目标设置；介质与膜料设置 |
| 优化 | 优化设置；公差设置 |
| 材料 | 原实验材料管理与 n/k 表编辑 |

设计与优化菜单打开同一个设置窗口的对应页：设计目标、介质与膜料、优化与采样、公差。标签与输入不再挤在 256-DIP 侧栏内。关闭设置后保留修改，值的变化仍立即使旧结果失效；“完成”用于关闭，没有新增取消回滚语义。主窗口准备关闭时先关闭设置窗口，再走原未保存修改保护。

膜层编辑保留真实材料色点、完整名称提示和来源注记，膜厚数字右对齐；复制、删除和移动使用带提示的紧凑图标按钮。窄单元格优先保留材料名，并正确显示省略号。光谱图例根据实际文字高度留出独立空间，避免窄窗/大字号时与能量单位重叠。

本轮没有改变实验格式、真实 n/k、原设计协议、算法或验收门槛。参考图用于操作布局，不代表已完成参考软件的全部功能。

## 验证与范围

最终版本 **25/25 桌面回归 + 3/3 三语布局检查通过**，共 28 个不同用例身份；前序试跑不累计。浅色/深色/大字号主窗口及四个设置页已检查实际离屏图像。

独立输出的 Release Win-x64 主程序及完整项目依赖构建成功，零警告/错误。桌面回归范围包括生成/编辑/复验、三种窗口尺寸、颜色及回收行、菜单设置入口、全部五种主题、原设计协议保持、未保存保护、材料管理、保存重开与导出。三语布局检查覆盖中文浅色、英文深色、日文大字号窄窗口下的四个设置页，检查输入可达、语言/主题切换不改值和实验指纹。

主测试项目曾因工作区 `SequentialExampleTests.cs:60–61` 引用缺失的 `SequentialExampleGroup.DisplayName` 构建失败，本次未修改该范围。三语检查使用仅链接原 `LaboratoryPresentationTests.cs` 和安全离屏宿主的临时测试程序集；不能据此宣称整个主测试项目通过。复现项目、日志、预览见[证据](../validation/rechecks/2026-11-01/coating-desktop-workspace/README.md)。

验证全程后台离屏，未关闭或控制用户窗口。默认输出目录未替换，不计默认输出构建或原生桌面验收。示例菜单测试点击离屏下拉按钮确认打开，再派发菜单项 Click 事件；未宣称原生弹出窗口指针验收。
