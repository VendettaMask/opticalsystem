# 干涉条纹显示与设置

2026-10-26 起，`Interferogram` 使用独立的共享 Core 干涉分析，不再把 OPD 热图作为干涉图。界面显示两束光在重合归一化瞳面上的干涉强度；OPD 差和条纹相位仍单独保留在数据表中。

## 计算定义

设共享 Core 返回的波前差为 `W1 − W2`，单位为所选波长的波数；参考光束的波前差为零。在归一化瞳坐标 `(x, y)` 上计算：

```text
q = ScaleFactor × (W1 − W2 + ChiefPathPhase) + (XTilt × x + YTilt × y) / 2
I = (1 + cos(2πq)) / 2
```

`q` 是条纹相位，`I` 是 0～1 的归一化强度。X/Y 倾斜表示穿过完整瞳直径增加的条纹数，在波前倍率之后加入；倍率为 2 可表示双程波前灵敏度。零相位数值为 1，与已冻结的 Zemax 原生数据一致；灰度显示将 1 映射为黑色、0 映射为白色，因此零相位对应暗中心。不要为了改变灰度外观而反转物理数据。

默认消除两光束各自的主光线常量光程。勾选“考虑光程差”后加入到实际像面的主光线总光程差。Core 的 OPD 定义为参考光程减实际光程，所以 `ChiefPathPhase = (OPL2 − OPL1) / λ`，λ 在此换算为毫米。分析面选为中间面时，波前分析使用中间面的副本，主光线总光程仍来自原系统的实际像面。

两光束假定等强、归一化瞳面完全重合，不模拟横向错位、放大率差或透过率差。只显示共同有效的真实追迹样本；没有插值补洞、虚构边缘数据或按截图调整条纹。

## 可用设置

| 设置 | 当前含义 |
| --- | --- |
| 瞳面采样 | 桌面提供 32、64、128、256、512 的方形网格，默认 64；Core 接受 8～512。圆瞳和真实遮挡决定有效样本。 |
| 分析面 | 实际像面或指定物理面。中间面在分析副本上截断后续表面，并设置旁轴焦面；不会改写镜头。 |
| 条纹数/波长 | 正的波前倍率，默认 1。 |
| 显示为 | 灰度、伪彩色、等高线；共用相同的 0～1 强度数据。 |
| 波长 | 选择一个实际波长，桌面初始选择主波长；两束真实光必须使用相同波长。 |
| 视场 | 选择一个已定义视场，初始为第 1 视场；摘要显示真实角度/高度及单位。 |
| X 倾斜、Y 倾斜 | 沿完整瞳直径的条纹数，正负值均可；不随波前倍率再次缩放。 |
| 光束 1、光束 2 | 当前结构、指定的 1 起始结构编号，或零 OPD 参考光束。默认“当前结构”和“参考光束”。两个当前结构相互抵消，而不会被解析为参考光束。 |
| 参考光束到顶点 | 在倍率为 1 时，按像面顶点与主光线参考球心的位移加入小倾角修正；适用于主光线偏离光轴很小的情况。 |
| 使用出瞳形状 | 由子午/弧矢工作 F 数估计显示椭圆比例；优先取真实光束 1，否则取光束 2。只改变显示比例。 |
| 考虑光程差 | 加入两束光到实际像面的主光线总光程差。未勾选时不求值这一常量项。 |
| 等高线格式 | 留空使用默认强度级别 0.1～0.9；单个正数表示间隔；多个空格分隔数表示具体强度级别，如 `0.2 0.5 0.8`。过密请求回退到默认级别，限制为 100 条。 |
| 子孔径 Sx、Sy、Sr | 归一化瞳面上的中心与半径，默认 `(0, 0, 1)`。在实际偏移位置追迹，并与原圆瞳取交集。 |

页面仍为软件分析页，保留绘图、数据和文本三个标签以及完整图片导出，不增加报告式分页。绘图页脚显示实际波长、视场、OPD PV、分析面、出瞳直径、倍率和 X/Y 倾斜。

## 明确边界

- 中间面位于光阑之前且开启 Ray Aiming 时，当前明确拒绝并说明缺少相应的物理中间瞳模型；不悄悄关闭瞄准或输出近似条纹。光阑之前、未开启瞄准时，采用入口瞳位置的虚拟光阑副本；非 NA 孔径转为入瞳直径。
- 顶点参考采用官方适用范围内的小倾角修正；不声称大角度顶点参考等价。无有限旁轴焦点的中间面、缺少共同有效光线或不一致的双光束波长有明确错误/不可用结果。
- 外部数值核对仅认证本仓库已冻结 `123456.ZMX`、OpticStudio 2026 R1 的轴上 64×64、λ=0.4400 µm、倍率 1、零倾斜设置。其他设置使用解析关系、共享 Core 一致性和界面/导出回归验证，尚无逐项新增原生 Zemax 捕获。
- 本次后台验证没有操作桌面或安装应用。默认 Release 输出已编译更新，不能据此声称用户已安装版本已经更新，也不代表完整原生 GUI 验收。
