## 2 产品和计算边界

1. 初始结构继续作为 Optical System Design 主程序内置模块，运行保持纯 C#/.NET；产品运行不依赖 Python、CODE V、Zemax 服务或另一套追迹引擎。
2. 光学值及导数统一来自共享 Core。低阶评价是显式搜索阶段，具有自己的支持域、单位和结果身份；不能在实光线失败时充当替代结果。
3. 第一批沿用当前支持的无限远物方、同轴顺序透射、圆形口径、独立单片及已有球面和偶次非球面。有限共轭、胶合共享界面和 SPC 过渡状态各自扩展后再开放。
4. 新调度接入自主拓扑准备和搜索。主 AI 入口继续遵循托管 AutoLens 的现有执行资格，不重新开放旧 TrustRegion、CPU 启发式或 target-polish 选项。
5. 目标、机械平面、光阑、像面、材料和逐面口径按任务权限执行。临时课程阶段使用任务副本，最终回到原规格；轴向权限始终锚定原候选，不能逐阶段漂移。
6. 原光学和制造终验协议不随快筛改变。只有完整原规格终验通过的候选有合格归档权限；原合格方案不会被失败后代覆盖。
7. 历史空配置保持行为和序列化身份。改变结构、材料、面型、变量、采样或目标后，重建求解器状态与指纹；不套用旧雅可比或优化器数组。
8. 验证在后台或离屏运行，不控制用户桌面。沿用仓库明确排除的独立 Cooke/Tessar 残差与原生认证范围；搜索夹具不升级为新的外部精度认证。

## 3 完整搜索流程

```text
规格和结构权限
  → 可行性预检查
  → 多路线构造
  → 几何和一阶筛检
  → 低成本像差优化
  → 多轮候选竞争
  → 原规格精修
  → 独立完整终验
  → 合格方案归档

候选池 → 结构或材料变化 → 几何检查和一阶恢复 → 重新竞争
```

### 任务规格和口径权限

任务保存焦距、实际 F 数、物距、半视场及对应全视场、正权重波长、成像映射、畸变和像质目标，以及总长、后部净空、玻璃厚度、空气间隔和制造限制。结构权限另外保存片数区间、光阑区间、面型、目录材料和受保护元件。

口径模式分为固定净口径和允许自动分配。固定模式逐面保持输入；自动模式必须有净口径和机械尺寸上限，修改后重新检查真实通光和制造几何。M0/M1 不自动改变现有任务的口径。自动口径在 M3 独立实现并验证后提供。

对可证明矛盾的条件尽早返回具体原因，例如指定区间放不下最低玻璃厚度与空气间隙。预算内搜索失败、计算接口不支持和已证明的约束矛盾使用不同停止原因，不能统一解释为系统无解。

### 多源起点构造

| 路线 | 方法 | 接入顺序 |
| --- | --- | --- |
| 厚系统 Delano | 复用实际顶点、固定光阑和像面的现有构造 | M1 保留为基线来源 |
| 光焦度符号组合 | 用各片正负光焦度规定初始方向，小片数枚举，较大片数有界覆盖 | M1 |
| 光焦度分配与目标闭合 | 在明确自由度下随机前部光焦度和间距，用 Core 求解剩余目标，再实体化 | M2 对照实验 |
| 已有镜头检索 | 从已有合法来源镜头选择相近规格，按允许尺寸缩放并重新评价 | M3 |
| 简单系统增长 | 使用现有结构操作，再逐步加入胶合和 SPC 方法 | M2 后进入 M3 |

符号只描述起始方向，用户未约束时允许优化后变号。现有 Balanced、FrontBending 等是边缘光线路径提议，不能直接改名当作已实现的正负组合。

归一化光焦度、间隔、光阑相对位置、材料和面型共同描述结构差异。比较最终处方，避免仅靠初始标签去重。各结构族获得最低探索机会；多样性保留以可用几何和接近的质量为前提。

### 分层评价和候选竞争

| 阶段 | 计算和用途 | 输出权限 |
| --- | --- | --- |
| 构造筛检 | 有限参数、定义域、厚度间隙、固定平面、焦距和实际瞳 | 几何与一阶工作起点 |
| 低成本像差优化 | 已验证的 Core 低阶量、稀疏实光线和有限连续更新 | 快筛分数和失败原因 |
| 多轮竞争 | 逐步增加采样，或按显式课程恢复原视场和孔径；同轮同额优化 | 保留、淘汰或待重评 |
| 原规格精修 | 原规格下为少量终选候选分配连续优化额度 | 待终验处方 |
| 独立终验 | 原密集视场、瞳积分、独立边缘、制造和全部原目标 | 合格或明确未合格 |

M1 首先核对 `SeidelMetrics` 的适用系统和单位，复用已验证的球面三阶能力；非球面等不支持请求明确路由到对应实光线阶段，不返回零像差。五阶能力单列后续研究，不能因为参考 DSEARCH 就宣布已具备。

候选先获得短程优化机会，再比较其终点，避免把未经补偿的初始 RMS 当作潜力结论。排序优先考虑几何和通光，再考虑归一化的最差视场像质、进展与结构差异；失光视场不能从分母中删除。不完整计算保留状态，不能用已有少数视场的好成绩替代完整筛选。

初始实验规模为 24 → 8 → 3 → 最多 2 套终验，作为有界对照配置而非保证执行规模。根据完整轮次和终验的可支付额度缩减候选数。同一轮使用同一协议；阶段目标或采样变化后重新评价，不能混排不同阶段的原始分数。

在总额内预留少量挑战候选和淘汰样本复核，估计低阶快筛漏掉潜力方案的风险。其比例由 M0 成本实测和 M1 预试确定，冻结正式对照前写入协议。

### 结构变化和补偿

结构分支统一采用“提议 → 几何检查 → 一阶恢复 → 短程实光线补偿 → 竞争”的顺序。优先复用已有增删拆并、目录材料和允许面型变化；连续变量仍受原权限约束，复杂度改善必须由完整终验确认。

SPC 零厚度零元件需要独立的过渡模型及执行身份，不能送入普通制造验收或保存为合格镜头。增加厚度、恢复实际间隔和材料后才能进入普通竞争。胶合组必须采用真实共享界面与介质关系，不能用空气分隔单片冒充。

非球面分支比较不同位置引入面型后的补偿收益，达到原目标后停止增加复杂度。面型数量、最高阶和制造约束必须显式声明，不以无限加高阶项换取通过。

### 预算和性能

先按原终验协议、波长、视场、瞄准和恢复工作估计终验成本，再预留有限名额。名义采样光线数不能当作实际追迹成本；若预留不足，减少终验名额或提前停止，不能挪用其他阶段预算冒称完成验收。

构造、筛检、梯度、瞄准、失败追迹、恢复、终验和中断前工作均计费。每个候选受累计额度约束；每轮受统一函数、梯度、追迹和时间上限约束。准备和自主搜索分别记账，端到端对照必须把两者实际耗用相加，并从统一总额扣除。

记录首个合格方案用时、各阶段调用和耗时、接受更新数、失效原因及终止原因。优化停滞时转向其他候选或结构；不足完整试验额度时停止派发。

性能优化按实测热点进行：先复用同快照同设置的 Core 结果，再进行有界候选并行，之后评估受支持的批量计算。缓存键包含处方修订、后端、输入光线和影响结果的设置；共享预算采用原子预约和结算，取消后保守结算未知执行程度。固定种子、候选顺序和派发规则需要可重放。

逐变量尺度和阻尼实验放在 M3，与原连续优化策略同预算比较。不宣称复现闭源 PSD III；先解决阶段成本和调度，再依据账目决定是否更换内层方法。

## 5 验证协议和指标

正式比较前冻结任务和原验收，先进行开发预试，再冻结候选数、分配规则、随机种子和停止条件。每项先用至少 5 个固定种子进行工程对照，并报告全部种子和失败；扩大样本后再讨论通用成功率。

| 任务组 | 使用目的 |
| --- | --- |
| 现有三片 50 mm F/8 全视场 10° | 基本闭环与首个合格用时 |
| 原 21°半视场冻结任务 | 困难任务同预算连续性；沿用原计划和原验收 |
| 八片 F/8 和 F/4 全视场 25°固定口径夹具 | 诊断与受限任务对照，不预设应该通过 |
| 单独冻结的允许口径广角任务 | 在明确机械权限下评价新结构潜力，与固定口径任务分别报告 |
| 多波长目录玻璃及允许面型任务 | 色差、材料与非球面分支 |
| 明确约束矛盾及极小预算任务 | 正确拒绝、停止、取消和保存 |

各臂使用同一任务、硬门槛、最终采样、设备与精度，并给出相同预算上限及实际耗用。路线变化属于被比较因素；不能增加新臂的隐含准备、训练或外部验收额度。已有镜头库的离线建设成本与在线检索成本分别披露。

主要指标为首个原规格合格方案用时、固定预算内合格数量、最佳及中位像质、复杂度取舍、结构多样性和各原因失败率。没有合格者的运行报告为未在预算内找到，不能从用时统计中删除。中间 RMS、总损失和通过测试数不能替代最终设计效果。

每批保留协议、输入、源码哈希、处方、阶段摘要、预算账目和未合格终点。新的证据放在相应日期的 `validation/rechecks` 子目录；新任务看板完成时填入实际链接，不预建不存在的成绩链接。
