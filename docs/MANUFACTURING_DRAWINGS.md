# 可制造性审查与光学制图

“加工与图纸”Ribbon 提供两个文档工具：

- 可制造性评估：把连续折射面及其玻璃区间组合为物理元件，输出通过、需复核或无效结论；
- 光学制图：为单片、胶合组件或整个系统生成 A4/A3 中文预览，并导出相同矢量内容的 PDF。

## 可制造性评估

可编辑筛查阈值包括：

- 最小中心厚度；
- 最小采样边缘厚度；
- 最大有效口径/中心厚度比；
- 最小绝对半径/口径比；
- 最大表面边缘斜率。

系统还检查实际面型是否超出实数弧矢域、前后表面相交以及需要特殊加工和检测的非标准曲面。这些是确定性的早期工程提示，不能替代供应商对刀具、材料、公差、镀膜、装调、环境和良率的审查。

评估页分为“几何加工指标”和“规则评估结论”两张表。几何加工指标对每个玻璃元件输出机械直径、中心厚度、有光焦度面半径绝对值、按共同净半口径计算的全口径弧高、全口径边厚、表面边缘倾角和表面类型。机械直径取前后表面较大机械半口径的两倍；规则中的口径/厚度比也使用同一机械直径。指标表是制造沟通用事实数据，不直接替代下方红黄绿规则结论。

### 实际面型与共享计算（2026-10-13）

处方行携带复制、只读的 `SurfaceGeometryDefinitionDto` 参数；`ManufacturingGeometryService` 从该快照恢复 Core 几何，`ManufacturingProfileGeometry` 统一计算实际矢高、法线斜率和径向采样厚度。App 不再复制圆锥矢高公式，也不把非球面只按基底半径绘制；无产品调用者的旧 `Sag(radius, conic, height)` 入口及其转发方法已删除，制造端统一传递完整表面。偶次/奇次非球面和现有 Forbes Q 模型保留全部系数；基础半径为零不再跳过非球面的斜率检查。标准面的实数域容差与追迹几何一致。

本接口限定于共轴、无倾斜的旋转对称面。缺少完整参数的特殊面、未知面、非旋转对称面以及偏心倾斜元件明确拒绝径向评估/单片和胶合图，不回退为标准面或零矢高；总体布局图仍可用。最小厚度仍是从顶点到共同净半口径的 65 点采样估计，不保证连续全局最小值。现有轮廓防相交裁切与共同外径扩展是绘图策略，不等于制造合格认证。

玻璃元件不再因中心厚度为零或负数而被筛掉：可加工性评估保留该元件，并给出中心厚度错误。单片/胶合图的元件选择及直接制造轮廓入口要求中心厚度为有限正数；无效时明确拒绝，不能通过漏掉元件或裁切成伪轮廓生成图纸。空气间隔不作为玻璃元件，正常元件的识别及总体布局入口保留。

定义核对依据：[Ansys Sag Table](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v25101/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Sag_Table_1.html) 明确计算实际表面的矢高/斜率，并限制径向表的旋转对称适用范围。已有 `123456.ZMX` 表面 1 矢高捕获用于球面数值对照；非球面本批仅做解析及共享 Core 一致性回归，不扩大为 Zemax 原生非球面认证。最新结果见 [当前状态](CURRENT_STATUS.md)。

## 光学制图

Ribbon 和命令搜索统一为一个“光学制图”入口，页面顶部的“制图标准”选择 `ISO 10110` 或老国标 `GB/T 13323—1991`，默认 ISO。元件、图幅、图签、尺寸及公差共用同一组编辑控件；切换标准自动更新预览，不重建编辑区或重置已填参数，PDF 按当前标准输出。专用字段按标准显示，隐藏时仍保留输入。共用半径公差在 ISO 中标注，老国标按样板/光圈要求表达精度并只标名义半径；Ra、Rq定义不同，分别填写。

重复打开入口复用同一编辑页；新页使用 `document:optical-drawing`，标题统一为“光学制图”。工作区布局记录当前所选标准。显式加载旧布局时，原分开的 ISO/老国标页合并为一页，优先保留原活动制图页及其标准、停靠 ID 和位置；无活动制图页时优先已有统一页，否则保留已有制图页。原隐藏页从入口重新打开时移回可见文档区，复用原编辑控件。GB/T 13323—2009 的命令、内置模板和专用绘图逻辑仍已移除，旧 2009 设置转为 ISO。

预览和 PDF 共用同一渲染器。图纸页面区域、规格表类型、字段顺序和字段绑定由两套内置 XML 模板驱动；SkiaSharp 负责执行布局并输出 PNG/PDF。

选择器保留每块玻璃的单片图；连续玻璃区间还增加胶合组件图，不删除组成单片。单片和胶合组件图的剖面轮廓采用与 2D 布局视图一致的表面矢高、共同外径扩展和防相交裁切语义：前后表面半口径不一致时，小口径面先在自身边缘处垂直补到共同外径，再闭合成实体，不会把曲面外推到不存在的口径。系统布局页绘制完整镜头列、材料分组、光阑/参考面和按波长着色的追迹光线。

两套制图布局共同包含：

- 按优选比例绘制的 2D 布局一致剖面、光轴、外径、中心厚度、S1/S2 半径及尺寸箭头；小口径或薄胶合件可自动选用 `20:1`、`50:1`、`100:1` 放大比例，避免几何图在 A4/A3 页面中过小；
- ISO 的 S1/材料/S2 规格区，或老国标的材料要求/零件要求表；
- 已知玻璃的目录折射率和 Abbe 数；
- 镀膜、倒边、图号、零件名、版本、设计和审核；
- 应力双折射、气泡/杂质、均匀性/条纹、面形、偏心/倾斜、表面疵病和纹理；
- 中文技术要求和标题栏。

单片使用局部制造面编号 `S1`、`S2`，与处方全局面号独立；胶合组件沿共享界面继续为 `S1`、`S2`、`S3`，同时保留全局面范围。

### 材料数值与公差（2026-09-28）

制图通过共享材料服务解析处方中的玻璃：`SCHOTT:F2` 等带厂商前缀的名称按指定目录解析，未限定名称遵循当前工程的玻璃目录优先级，不再遍历全部目录取首个同名项。nd、Vd 复用材料库 DTO 的数值来源：有目录参考值时使用参考值，否则使用现有共享材料色散计算结果；制图不另建计算公式。

材料栏显示名义值及“材料公差”设置，例如当前内置 `SCHOTT:F2` 为 `nd 1.620040 ±0.000500`、`Vd 36.366 ±0.5`。修改公差后点击“更新预览”，或直接导出 PDF，会使用当前设置；公差不改变名义材料数值。预览和 PDF 由同一图纸对象及渲染器输出。两套模板均支持此标注；胶合组件逐片读取材料。老国标现将 L1、L2 等牌号和 nd/Vd 列入下方技术要求，共用本张图纸的材料公差；填写老国标材料等级时按下文规则显示，右上表格不再沿用旧横向兼容表。

找不到目录玻璃时明确标注“未解析”（胶合分栏为 `UNRESOLVED`），不会再显示暗示已有值的“由玻璃库解析”，也不会借用另一片材料。当前此接口返回目录玻璃；非目录模型材料不据此宣称已支持制图材料参数。

本阶段默认 Debug/Release 编译及相关回归各 **55/55** 通过，新增 8 个用例覆盖限定名称、目录优先级、未知材料以及三套模板的单片/胶合公差传递。12 份 PDF 的名义数值与修改前后公差已逐项提取核对，并检查实际渲染；范围与产物见 [构建记录](MANUFACTURING_DRAWINGS.md#材料数值与公差2026-09-28)。这是材料读取与制图输出验证，不是外部数值精度或标准条款认证。

### 模板与兼容边界

ISO 10110 布局把尺寸几何和表格式光学标注分开；有效孔径属于光学检验区，在表面规格中标注而不是绘制第二个机械直径。ISO XML 模板按 Zemax 风格把镀膜指示放在有效孔径下面、`3/` 之前，并按 `3/`、`4/`、`5/`、`6/` 顺序输出表面相关指示；当前 ISO 模板不生成 `7/` 行。`6/` 为激光照射损伤阈值：默认 `6/-` 表示未规定；用户填写的阈值、测试条件或合同引用文本会原样保留，软件不解析或校验其中字段。

GB/T 13323—1991 与 ISO 共用编辑页、元件及物理尺寸/公差。老国标单片图按第4.3.1条、表3将“对材料的要求”和“对零件的要求”纵向叠放在右上角；胶合件按第4.2.2条、表2使用右上角“对胶合件的要求”。图形位于其左侧，材料名义数据、补充物理限值、镀膜和边缘要求写在下方技术要求区。标题栏及默认矢量公司 Logo 保留；系统布局图原绘法不变。

原表格的物理尺寸由 XML 指定：总宽40 mm，材料项目列宽25 mm，零件/胶合件项目列宽15 mm，表头高8 mm、数据行高6 mm。老国标 A3 直接使用页面物理坐标，保持这些尺寸，不沿用 ISO 的整页缩放；ISO 模板和绘图路径保持原样。

表3的七项材料要求依次为 `Δnd`、`Δνd`、光学均匀性、光吸收系数、应力双折射、条纹度、气泡度；十四项零件要求为 `N`、`ΔN`、`ΔR`、`χ`、`B`、`θI`、`θII`、`d`、`f′`、`Lf`、`L′f`、倒二面角、倒三面角、`D0`。表2使用其原十一项胶合件要求。当前制造图针对旋转对称透镜/胶合透镜，棱镜平行差及倒二/三面角显示“不适用”，不据此增加棱镜制图能力。

`d`、`D0` 和角分制 `χ` 使用共用的中心厚度/公差、有效口径及角度公差。材料等级、`N`/`ΔN`、样板等级 `ΔR`、旧版疵病 `B` 及焦距/顶焦距要求有老国标输入项：留空显示“未规定”，不把 ISO 代码、nm 面形限值或目录玻璃参数推定为旧版等级或光圈数。焦距/顶焦距栏是用户要求文本，不是本功能新增的计算结果。材料等级留空时，右上表保持“未规定”，共用绝对数值公差在技术说明中显示；填写等级时保留名义折射率和阿贝数，避免重复另一套允差。特别是Vd的绝对数值公差，不直接替代材料标准中的百分比/类别及批差等级。等级依据默认标为`GB 903—1987`，可按合同修改，软件不自动跨版本转换等级。

老国标半径引线只标`R`及名义值，平面标`R∞`，非球面标明基底半径并在技术要求中列出面型定义。共用半径公差输入在老国标中隐藏并保留；`ΔR`接受样板等级A/B，也可明确写`S1:A；S2:B`，不接受把`0.1`当成mm公差。`N`、`ΔN`是光圈检验要求，支持注明S面号及独立检验波长；nm补充限值不自动换算。`χ`按光学表面面倾角解释，定心基准默认机械外圆轴，可修改，不换算成偏心长度或边厚差。ISO专用缺陷代码的空值不再阻挡老国标出图，切回ISO仍按原规则验证。

粗糙度分别设置光学工作面及其余表面的`Ra`（μm）和取样长度`l`（mm），输出基本粗糙度矢量符号、参数、数值及适用表面；未规定时留空，不自动指定加工方法或抛光等级。原有`Rq`（nm）作为独立补充要求保留，不视为Ra，也不改单位后直接替代。零、负数、非有限数及只填取样长度未填Ra的组合会拒绝生成。

老国标轮廓按共享Core的实际面型计算机械外径范围，`D0`独立表达有效检验孔径；存在居中圆形物理孔径时，从非本地化的尺寸快照读取实际半径，取共同有效区域。机械范围超出有效面型或导致相交时明确拒绝，不再裁小轮廓后标原外径。当前老国标透镜图不把矩形、椭圆、环形、偏心或其他特殊孔径简化成圆形D0；缺少必要尺寸快照也明确拒绝。图示边缘厚度`t`由实际轮廓提供，带参考标识；胶合组件内部`d1/d2`亦带参考括号，总厚度的共用允差仍用于总厚尺寸。

圆锥、偶次和奇次非球面列出表达式、基底R、k及全部已捕获系数，遵循共享Core的实际幂次约定：偶次首项为r²，奇次首项为r，而非另行假定A4起始。Forbes Q保留全部参数，另要求受控面型定义或图纸引用，不以基底R冒充完整面型。镀膜按具体S面号或共用膜层说明输出；小倒角可用文字表达。补充技术要求可写胶合、特殊工艺或分面合同条件，受整页文字容量约束。

单元格最多容纳两行、技术说明区具有固定可用高度；超长内容在生成前明确报告，不把文字挤出表框或截断后输出。依据为教材二维码公开提供的[原标准文件](https://ncstatic.clewm.net/rsrc/2022/0928/18/a8e91b473f322a6f24ebec07b5068cc5.pdf)及教材光学零件图章节。最新逐项依据、实现和范围见[光学零件图核对表](LEGACY_GB1991_OPTICAL_PARTS_REVIEW.md)；此前[表格布局证据](../validation/rechecks/2026-10-27/gb1991-layout/README.md)保留原阶段范围。此功能不自动完成旧材料等级评定、供应商检测或所有企业图签/棱镜图样的条款认证。

标题栏默认使用打包的 `CompanyLogo.svg` 标准矢量字标，与其他品牌界面共用真实路径；元件图与总体布局图的默认 Logo 在 PDF 中保持矢量，不先转换成 PNG。工程图设置区显示同一矢量预览；当前图纸仍可临时替换自定义 PNG，并可恢复默认矢量资源。Logo 已转为轮廓，不依赖本机 Nasalization；中文与数学文字使用打包的 Noto Sans CJK SC，预览和 PDF 不依赖工作站字体。

实现完全位于 C#/SkiaSharp 和内置 XML 模板，不调用 Python 或外部 CAD。模板结构参考 Zemax 的模板化思路，但不是 Zemax 私有 XML 模板的直接兼容格式；后续如需读取 Zemax 模板，应通过单独转换器映射到本项目的强类型字段绑定。OtoCAD Community 只作为公开行为参考，不包含其源码或运行时组件。

## 制图参数的显示与裁剪

两套制图保留原设置/预览分区、340 DIP 宽屏设置面板和 900 DIP 响应式断点。标签采用短名称及完整提示，mm、deg 等单位保留在可见标签中；必要时单位放在第二行。顶部和参数区在有限容器内测量并纵向滚动，滚动条实际占位，避免遮住编辑器右边框；Logo 操作仅在原字段内部换行。

此调整只影响屏幕测量与文本适配，不修改预览几何、图纸标准、制图数值或 PDF 输出。真实控件验证与截图见 [容器修复](PANEL_CONTENT_LAYOUT_2026-09-27.md)。

## 标准边界

UI、XML 模板和渲染器参考 ISO 10110 系列、ISO 10110-17 激光照射损伤阈值、ISO 129-1、ISO 5455 以及旧版 GB/T 13323—1991 的公开版式说明。软件执行结构、字段绑定和单元格溢出检查，并提供 ISO/老国标两套中文图样；最终生产图仍需依据授权标准文本、合同要求和制造商能力进行条款级工程审核。
