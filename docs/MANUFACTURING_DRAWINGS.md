# 可制造性审查与光学制图

“加工与图纸”Ribbon 提供两个文档工具：

- 可制造性评估：把连续折射面及其玻璃区间组合为物理元件，输出通过、需复核或无效结论；
- 光学制图：为单片、胶合组件或整个系统生成 A4/A3 中文预览，并导出相同矢量内容的 PDF。

## 可制造性评估

可编辑筛查阈值包括：

- 最小中心厚度；
- 最小采样边缘厚度；
- 最大有效口径/中心厚度比；
- 最小绝对半径/口径比；
- 最大表面边缘斜率。

系统还检查二次曲面是否超出实数弧矢域、前后表面相交以及需要特殊加工和检测的非标准曲面。这些是确定性的早期工程提示，不能替代供应商对刀具、材料、公差、镀膜、装调、环境和良率的审查。

评估页分为“几何加工指标”和“规则评估结论”两张表。几何加工指标对每个玻璃元件输出机械直径、中心厚度、有光焦度面半径绝对值、按共同净半口径计算的全口径弧高、全口径边厚、球面边缘倾角和表面类型。机械直径取前后表面较大半口径的两倍；规则中的口径/厚度比也使用同一机械直径。指标表是制造沟通用事实数据，不直接替代下方红黄绿规则结论。

## 光学制图

预览和 PDF 共用同一渲染器。Ribbon 分别提供 `ISO 10110`、`GB/T 13323—2009` 和 `GB/T 13323—1991` 命令，每种标准拥有稳定文档和独立持久化设置。

选择器保留每块玻璃的单片图；连续玻璃区间还增加胶合组件图，不删除组成单片。单片和胶合组件图的剖面轮廓采用与 2D 布局视图一致的表面矢高、共同外径扩展和防相交裁切语义：前后表面半口径不一致时，小口径面先在自身边缘处垂直补到共同外径，再闭合成实体，不会把曲面外推到不存在的口径。系统布局页绘制完整镜头列、材料分组、光阑/参考面和按波长着色的追迹光线。

两套生产布局共同包含：

- 按优选比例绘制的 2D 布局一致剖面、光轴、外径、中心厚度、S1/S2 半径及尺寸箭头；小口径或薄胶合件可自动选用 `20:1`、`50:1`、`100:1` 放大比例，避免几何图在 A4/A3 页面中过小；
- S1、材料、S2 规格区；
- 已知玻璃的目录折射率和 Abbe 数；
- 镀膜、倒边、图号、零件名、版本、设计和审核；
- 应力双折射、气泡/杂质、均匀性/条纹、面形、偏心/倾斜、表面疵病和纹理；
- 中文技术要求和标题栏。

单片使用局部制造面编号 `S1`、`S2`，与处方全局面号独立；胶合组件沿共享界面继续为 `S1`、`S2`、`S3`，同时保留全局面范围。

ISO 10110 布局把尺寸几何和表格式光学标注分开；有效孔径属于光学检验区，在表面规格中标注而不是绘制第二个机械直径。GB/T 13323—2009 布局分别提供材料要求和零件要求表，并采用现行标准配置的短—长—短光学玻璃剖面符号。

GB/T 13323—1991 作为独立旧版兼容图样实现，不复用 2009 的图框或表格。它使用自己的稳定文档 `document:optical-drawing-gb-1991`，标题栏明确标注 `GB/T 13323—1991 光学制图`，规格区按旧版习惯组织为“对材料的要求”和“对零件的要求”，并在零件要求中使用旧版常见的 `B` 表面疵病字段；光轴和光学玻璃剖面符号也与 2009 分开配置。旧版表格当前覆盖单片、胶合组件和系统布局标题栏；如果合同要求逐条复刻 1991 原文的编号、等级或示例图，应以授权标准文本为准复核。

标题栏默认使用打包的 S.T.A.R. Labs 标识，当前图纸可临时替换 PNG，并可恢复默认资源。中文与数学文字使用打包的 Noto Sans CJK SC，预览和 PDF 不依赖工作站字体。

实现完全位于 C#/SkiaSharp，不调用 Python 或外部 CAD。OtoCAD Community 只作为公开行为参考，不包含其源码或运行时组件。

## 标准边界

UI 和渲染器参考 ISO 10110 系列、ISO 129-1、ISO 5455、GB/T 13323—2009 以及旧版 GB/T 13323—1991 的公开版式差异说明。软件执行结构和数值合法性检查，并提供 1991/2009 两套独立中文图样；最终生产图仍需依据授权标准文本、合同要求和制造商能力进行条款级工程审核。
