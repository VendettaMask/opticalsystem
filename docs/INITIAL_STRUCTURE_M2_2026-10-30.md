# 初始结构 M2：结构分支、恢复和统一竞争

对应[实施计划](INITIAL_STRUCTURE_SEARCH_IMPLEMENTATION_PLAN_2026-10-30.md) M2.1–M2.5，沿用[M0/M1](INITIAL_STRUCTURE_M0_M1_2026-10-30.md) 的共享 Core、阶段协议与原规格独立验收。实现和真实对照范围见[验证记录](../validation/rechecks/2026-10-30/initial-structure-m2/README.md)。没有实现 M3 的胶合、SPC、检索、自动口径、并行或准备检查点。

## 使用

在 **实验室 → AI 初始结构 → 自主拓扑设计 → 一阶起点准备** 勾选“实验：对当前处方做结构演化”。M2 从当前载入的实际处方出发，不按结构描述重新生成一批父方案。需要八片输入时，先载入实际八片处方或已准备的起点；描述面板的“生成镜片数”不改变已经载入的 M2 父方案。

“结构变化后先恢复一阶目标”和“恢复补偿后进入多轮竞争”选择三种有明确身份的流程：直接实光线补偿、先恢复再补偿、恢复补偿后竞争。可限制父方案数、分支数、每分支恢复评价和补偿更新；“实验：光焦度分配与目标闭合起点”另给新构造路线名额。关闭恢复会同时关闭后续竞争；开启竞争会开启恢复。关闭主竞争会关闭 M2。新选项默认关闭，载入和保存只回读配置，不执行追迹。

配置为可空、独立版本 1 的 `ParaxialSeedSearchOptions.Evolution`；空值不写入 JSON，继续 M0/M1/旧路径及内容身份。新身份为 `initial-structure-evolution-v1`。M2 最多允许 10,000,000 rays、10 分钟；未开启 M2 的旧准备仍保留 1,000,000 rays、2 分钟限制。提高了可设置范围，不自动提高既有额度。终验昂贵的原 21°输入需要足够额度同时完成父方案重验和新方案终验；不足会明确停止。

## 结构、权限与状态

处理顺序为：独立原规格父方案验收 → 有限结构提议 → Core 制造几何检查 → 新建一阶恢复绑定 → 原规格短程实光线补偿 → 公用多轮竞争或直接终选 → 原规格密集终验。每个候选保留父 ID、结构操作、编辑处方、原始变量边界、各阶段绑定指纹、恢复和补偿摘要、实际费用及最终验收。

复用已有增片、删片、拆片、并片、目录材料和偶次面型操作。原扩展开关、片数上下限、保护片、允许材料和面型阶数始终有效；被权限或空间拒绝的提议单列原因，不消耗光学评价额度。拆片采用真实空气隙，共享界面胶合和零厚度 SPC 不在此阶段支持。新增内侧面/插入片使用明确且不超过父方案最小净口径的尺寸，不扩大现有逐面口径。

一阶恢复通过共享 Core 自动矩阵导数恢复父方案参考面到像面的 A/C、固定光阑瞳与制造约束。改变片数、玻璃、面型后重新编译并绑定，补偿和各竞争阶段重建自己的优化器；不复用父雅可比、动量或旧变量数组。物面参考、光阑、像面、环境、波长和视场保持；轴向范围锚定编辑时的处方并与原机械区间求交，恢复后不重新扩大窗口。保护片不进入变量集。

返回的“工作起点”必须已完成原终验，并通过原几何、一阶焦距/F 数及无过渡片门槛；像质未达标仍明确是工作起点。未完成或一阶/制造失败只留在候选证据中，不能列为可继续使用的准备结果。完整合格名单还要求全部原成像目标通过。

## 光焦度分配路线

这条路线从允许的实际父布局出发，对可移动片进行原窗口内的刚性位置扰动；在实际 Core 厚片光焦度附近做有界随机分配，固定前部可编辑镜片，只释放最后两片闭合原目标。它不是从任意空白布局保证构造，也不声明某个失败符号/布局无解。

Core `ElementPowerAssignment` 在原快照上用实际厚片传递矩阵求前表面曲率：保持后表面、厚度、材料及其他界面不变，执行两个响应探针和一次实际功率验证，超出曲率界限明确失败。随后由已有 Core-backed 目标求解器闭合原 A、焦距和入瞳；分配镜片临时冻结，输出恢复原保护状态，并独立复核固定功率、焦距/F 数和焦点。制造几何及最终像质继续走普通流程。所有探针、闭合、失败和中断都计入同一额度。

## 合格归档、预算与对照

既有合格父方案作为原始处方保留，失败后代不能覆盖。新合格处方只有在实际变化且原密集验收完成后进入新名单；重复的原处方不当作新设计成果。原归档之外另算片数、实际非球面数、显式多项式项数、最差视场 RMS 和最大半径的 Pareto 集，保留复杂度与像质之间的取舍，不因减片而覆盖原合格高质量方案。

函数/梯度/矩阵/差分/Jacobian/制造查询/追迹/时间有总额与候选累计账目。终验按原视场、波长、积分/边缘采样及 M0 实测的瞄准恢复成本预约；多轮竞争沿用 M1 的阶段重评和挑战机制。准备和后续搜索分别记账，端到端指标必须相加；复用已有起点的正式对照也计入冻结准备费用。

本阶段重点比较八片 F/8、F/4 全视场 25°和原 21°半视场：固定拓扑、直接变化、变化加恢复、再加竞争、仅功率路线、组合六臂，各 5 个固定种子。原 21°保留原 SK4/SK4/LAK09、逐面口径及只允许删片等权限；八片仍受最多八片和固定 5 mm 净半径限制，不以开放九片或扩径制造改善。原已有合格输入与新增合格、真正的减片收益分别报告。CPU double 后台计算和离屏回读不代替原生桌面或外部光学精度认证。
