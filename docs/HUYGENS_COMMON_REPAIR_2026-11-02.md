## 高采样 Huygens

原有限单元实现对每个像元重复遍历全部瞳孔，512 档在完整 32×32 像面上超过一亿次直接求和守卫。新增共用有限傅里叶和：把线性像面相位分解为过采样 FFT 格点和补偿累加的 Taylor 矩，保留原瞳孔节点、复振幅、有限单元包络、像面位置/间距、折射率、离焦、谱权重和绝对峰值参考。没有图像插值、瞳孔重采样或峰值拟合。

计划同时检查 Taylor 尾项、浮点误差余量、内存和所选算法的工作量。原一亿上限没有提高；新工作量计数为矩更新、FFT 蝶形与重建项数，不等于直接路径的每次复指数成本或实测 CPU 指令数。新增求和工作区估算上限为 256 MiB，追迹历史及既有瞳孔数据另占内存。低工作量仍走原直接路径；非可分的球面传播、相干 XYZ 和原 Gaussian/Checked 路径仍保留直接工作量守卫。`SummationChecks` 描述有限和计算误差，明确不认证瞳孔或像面窗口的连续采样收敛。

## 实际为同一物理视场的相对照度

零最大视场时，扫描请求的所有点实际属于同一个物理域。若绝对方向余弦映射折叠，仅归一化的同域比值可以约去共同正照度。新增受限处理先用共享物理追迹、口径、透射及偏振规则确认存在正透射且非共线的角瞳孔，再给出单位归一化曲线。正常可积域仍保留原绝对积分。

结果显式发布 `Normalization=IdenticalPhysicalFieldDomain`、`RawIntegralAvailable=false`、失败原因与实际有效光线数，不伪造原始面积或有效 F 数。原始绝对积分、非零物理视场折叠、全遮挡和无透射情形仍不升级。严格轴上相对比值入口使用相同受限条件。

原例及快照、20/40 密度控制通过。补采原生仍返回“无法计算相对照度...”且没有有效数值缓冲；因此 2166 从 Core Error 转为参考 Incomparable，不能计为原生数值通过。保留第一次失败，不重复申请相同失败参考。
