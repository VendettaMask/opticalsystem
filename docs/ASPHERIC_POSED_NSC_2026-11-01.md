# 非球面及偏心/倾斜镜组顺序转 NSC

2026-11-01。本阶段继续使用主产品共享 C# Core 和现有探测器/RAW/ISP，不另建光学引擎。

## 实现

新复合组件使用 `OpticalAssembly/2`，每个物理界面保存完整的旋转曲面定义和表面到组件的右手正交坐标架。支持平面、Standard球面/圆锥面，以及偶次/奇次旋转非球面，最多32个原始系数。系数按既有Core定义保存，偶次表从r²开始、奇次表从r开始；不能把其他软件的高阶项顺序直接套入。奇次面的非零r一次尖点明确拒绝。

坐标架保存原点和三个基向量，直接从原顺序表面的实际坐标变换得到，不分解回Euler角。求交前把射线变到该面的局部坐标，求交后把交点和法线变回组件；口径直接在真实局部坐标判断，不能把绕轴旋转再应用一次。组件及探测器继续支持现有对象参考链的刚体变换。实际介质沿用顺序追迹的上一面出射介质，胶合边界只保存一次，材料、口径和逐面镀膜按值保留。

曲面追迹复用原有Core几何。新增有限旋转曲面域以机械口径、完整高度和导数界隔离最近物理解；普通入射复用原求交并进一步精化，掠入射检查首根和切线，工作预算用尽或根无法验证时明确失败。连续分支从实际曲面点出发，避免顺序求交残差造成同一界面重撞；没有靠扩大固定射线偏移跳过相邻介质。

每个旋转曲面的真实机械边是位于其自身平面上的圆。相邻圆边使用解析直纹面封闭，完整圆周由两个有界半角图覆盖，通过四次多项式隔离求交；追迹不使用显示三角网。圆边的接缝方向按法向平行输运，口径绕轴旋转不会制造假的机械扭腰。显示网格也从相同曲面和圆边计算点。空气间隙没有虚构的可追迹侧壁。

转换使用完整机械口径上的保守高度/导数界，并在统一参数域上检查整个逐段组件的Jacobian对称部分。只有存在共同正定度量、保证全组件映射无折叠/交叠时才接受；这是充分条件，部分物理有效但无法通过该保守检查的处方也会明确拒绝。不会通过缩口径、删面或网格近似使其通过。

None/被动常量R/T/物理相干多层膜继续调用共享功率计算；反向穿越反转膜序。完整Fresnel、随机分裂、实际介质光程和共享弱体吸收沿用上一阶段账本。新几何进入同一STARRDB、路径筛选、探测器与传感器一次光子换算。

## 支持域和失败语义

- 完整逐面介质、物理/机械口径、光阑、标签、坐标架、膜系及原始系数保留；成功后才整体发布新场景。
- 2–512个物理界面，参考顶点沿组件参考Z严格正序，相隔大于1e−9 mm；所有曲面在参考轴上保持正则单值，且通过全组件证书。
- 允许独立偏心、X/Y/Z倾斜及参考链变换，但不包含折返、相交实体或任意弯折路径。准入由实际几何界和证书决定，不按材料名或示例身份选分支。
- 各向同性均匀透明/弱吸收体，仍限定k/n≤1e−6；强吸收膜料由原膜系求解器处理。没有新增偏振态、相干多路径或体散射。
- Biconic、自由曲面、Grid Sag、Forbes Q、非旋转多项式等本阶段不转换；不会退回球面。没有把所有“非球面”类型都宣称支持。
- 实际像面须为出射侧物理平面，无独立镀膜/散射/介质转换；新组件的有限探测范围不能与镜组交叠。非平面像面明确拒绝。
- 任何几何、材料、膜层、预算、求解或转换检查失败，应用事务保留原NSC场景、原顺序处方及修改状态。

解析封边只描述原始机械圆边之间的声明连接，不是精确镜筒CAD。尚未完成整机实拍RAW标定、非序列优化/公差或GPU大规模追迹。

## 文件与兼容性

新增可选的 `SurfaceGeometry` 与 `Frame` 字段要求STAROPT v21，包括禁用对象；降写为v20会明确拒绝。容器2与顺序快照6保持，原来共轴球面组件继续使用`OpticalAssembly/1`和v20，缺省新字段不写入JSON，旧场景摘要保持。旧BSDF Grid/1–11及相机冻结功率版本不因此升级。

## 验证与复查

结果集中在[本轮证据](../validation/rechecks/2026-11-01/aspheric-posed-assembly/README.md)。控制包括八组空气/浸没、偶次/奇次及有无独立倾斜的逐面位置/方向/光程比较，内部源介质定位、精确圆边首尾图求交、旋转矩形口径、刚体参考链、非球面内部交叠拒绝、掠入射双根/切线、v21禁用对象与降版本拒绝，以及已有v20工程/STARRDB摘要的只读回归。

独立倾斜平板参考计入有限口径对高次反射的裁光，再与完整分裂及8192条固定种子随机光线比较；不把无限平板功率当成有限镜片的参考。四组三波段链路分别覆盖空气/浸没和直射/Lambertian多次散射，核对R/!R路径功率分区、逐像元光子换算、工程重开后的NSC精确重追迹及电子/RAW/ISP精确冻结重放。所有控制是声明的解析场景，不是商业软件或实拍认证。

证据仅保存本轮变更源码、新案例和必要失败记录；不复制整棵源码、测试运行时或旧数据集。其余源码/输入以版本与校验收据绑定。后台和离屏验证不操作用户桌面；默认构建锁定与后续重试分别保留原记录。

最终521/521项定向回归通过，新增33项，零失败/跳过。最终默认Release App含两个内置模块及测试驱动零警告/错误。四个执行程序集的105份相关源码校验一致，133个源码/输入收据与90个执行文件运行前后无漂移；22份实际执行夹具与源文件一致。旧v20两工程/两数据库的摘要回归及原封存字节保持。
