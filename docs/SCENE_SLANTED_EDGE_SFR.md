# 物方棋盘与线性场景斜边

2026-11-03：已接入 M1 单 ROI、M2 预算内全幅逐源谱，以及 M3 的原始线性图多 ROI 测量与两类边缘方向，遵循[Ansys 工作流计划](ANSYS_SCENE_SFR_IMPLEMENTATION_PLAN_2026-11-02.md)。原文 5000×3000、ROM、独立工具、正式 MTF 和收敛验收继续开放。[M1](../validation/rechecks/2026-11-02/ansys-scene-sfr/README.md)、[M2](../validation/rechecks/2026-11-02/scene-linear-batch/README.md)与[多 ROI 记录](../validation/rechecks/2026-11-03/scene-multi-roi-sfr/README.md)各保留自身范围。

## 使用入口

打开“实验室 > 成像系统 > 相机成像仿真 > 场景斜边”，选择“单 ROI 诊断”“全幅逐波段”或“多 ROI SFR”。第一项设置靶标、单波段、完整图像与 ROI 后点击“生成物方棋盘像”；主波长从计算时冻结的当前镜头取得。第二项将全部源谱任务作为一个完整实验生成，第三项直接测量这些图像。亮暗格的值均是波段已积分的 W/(m²·sr)，权重角色各自声明。

初始设置是 100 m 远靶控制、14×14 格、2 m 格边、Z 旋转 5°、96×96 个 3 µm 像元、2×2 感光区积分与 8×24 瞳面节点。靶标平移按几何关系将一条竖边中段放在光轴上，避开棋盘交点。这组设置不是 Ansys 原例，也不自动匹配有限共轭镜头；请填写真实物距。粗采样生成图像不代表测量质量或收敛已通过。

两张预览分别表示靶面局部坐标中的发光分区与完整相机取景，各自使用显示峰值。实际计算保留原始功率；预览未进入 SFR。选择“测量 ROI”后，输入图像内的一条近竖直边区域。邻边、交点、离焦过宽、通光区域欠采样或非均匀背景可能使测量失败；此时仍保留整幅线性图、失败原因和冻结输入。当前页不显示正式参考 MTF 或“已收敛”的通过标识。

## 物理与数据约定

`EmissiveCheckerboard` 通过共享 NSC 矩形交点和局部坐标划分实际发光区域，一张共面表面表达全部格子，不受 64 个场景对象的限制。每格可声明发光与反射谱；本页控制靶采用发光、不反射、单面朝向相机。默认中心原点的旧反射棋盘保持其原来的均匀发光行为。新发光分区具有独立模型标识。

镜头、靶标、像元和波段均在任务开始时冻结。实际共享 Core 逆向几何追迹保留镜片、介质、像面、界面损耗和像元面积积分，没有局部 PSF 或替代模糊核。原处方不回写、不自动聚焦。严格单位强度的 Uniform / Zemax Uniform 切趾仅在计算副本中等价规范为无额外权重；非均匀切趾、偏振或现有追迹器不支持的几何明确报错。

帧的真值为每波段 W/pixel，已经包含真实感光面积和镜头传输。`LinearDetectorImage` 只除以感光面积一次得到 W/m²。没有 QE、曝光、电子转换、ADC、噪声、Gamma、白平衡或锐化。列从像面局部 −X 到 +X，首行为 +Y；CSV 使用真实像元中心，首尾中心位于半像元内侧。物体姿态相对第一实体镜面，几何单位 mm；传感器位于保存的实际像面。

`LinearImageEdge/1` 仅接线性图像与用户 ROI，从浮点数据裁切，支持近竖直/近水平的明确方向。它为数值条件使用一个公共比例，返回的 ESF、LSF 和对比度恢复到原输入单位；不同发光强度不改变 SFR。不会使用靶标角度或光学参考来拟合图像。该适配器保留既有近竖直估计器的质量门限与测量边界，没有升级为完整 ISO 12233 实现。

## 保存、重放与接口

“保存线性实验”写入 `.scene-sfr.zip`：冻结处方与摘要、源波段/辐亮度、靶标姿态、像元和计算量、原始功率、ROI 测量或失败，以及逐带 CSV 的功率/辐照度和像面毫米坐标。打开时验证归档摘要、物理尺寸、波段、完整光线数与保存像面，并从原始像元重算测量，拒绝与保存 SFR 不一致的记录。

“按冻结镜头复算”独立于之后打开的工程。当前镜头生成的结果在文档变化后清除；明确打开的冻结实验保持来源身份。导出为有界原子写入，取消或失败不会替换目标文件。曲线 PNG 使用原始 2404×1804 绘图与共享线宽选项。

单 ROI 应用接口仍为 `SimulateSceneSlantedEdgeAsync`、`RecomputeSceneSlantedEdgeAsync`、`ExportSceneSlantedEdgeAsync` 和 `OpenSceneSlantedEdgeAsync`。旧 `.scene-sfr.zip` 身份和结果保持；全幅任务使用下面的独立归档，不能把两者当成同一种输入交换。

## 全幅逐波段

此页有独立、显式的靶标和完整传感器参数。默认 128×128、3 µm、每像元 1 点、2×4 瞳面节点，用于流程检查。宽、高和像元尺寸直接定义完整物理传感器，不代表原文相机。所有任务冻结同一个镜头、像面、棋盘和像元；分块按完整行输出，横纵坐标和瞳面包络始终按整幅传感器计算。没有中央 ROI 拼图或每块重新居中。

“当前镜头各波长分别生成”保留每条波长行，包括零权重行。选中“将镜头权重作为物方源辐亮度倍率”时，节点辐亮度为输入带宽辐亮度乘原权重；不把权重归一化，也不沿用局部 PSF 的像面相对能量语义。取消该选项时，各任务使用相同声明辐亮度。零倍率任务保留黑色全幅数据及原始行身份。

“原文三种源谱形状”使用已核对文件中的 486/588/656 nm 有限窄带折点，保留 0% 支持节点、平顶与两侧斜坡。源形状先按其带宽面积归一到用户输入的总带宽辐亮度，再逐段作 2 阶或 3 阶 Gauss 积分，各任务分别为 8 或 12 个非零节点。节点带宽权重在发光源处只施加一次；图像不再作波长权重或光子权重转换。该选项是**原文源谱形状经过当前原生镜头**，不代表原 Speos 发光单位、ROM、相机谱域或原例场景已经复现。

开始前显示完整像元数、全部任务和光谱节点的总光线数、表面传播上界与浮点数据量。现有 8388608 光线、100000000 次表面传播、262144 像元及每边 1024 的计算上限不变；全部原始浮点数据也受既有 8388608 数值预算约束。任务、光谱节点和分块共用一次总预算。超过预算会保留请求的尺寸并停止，不暗中缩图、降低采样或拆成多个预算。任务执行区分追迹、交换图、归档与完成，支持取消；仅完整成功后原子替换目标文件。

## 全幅线性文件

“生成全幅线性实验”保存 `.scene-linear.zip`。其 `manifest.json` 和摘要给出输入镜头、物距/姿态、源谱折点与积分节点、波长行/原权重、完整尺寸、感光面积、坐标、逐任务/总计算量、数据文件摘要和 PNG 编码。

每个光谱节点保存 `float64 little-endian` 的 W/pixel 全幅文件。有限带宽任务另有节点求和功率；单节点任务直接引用节点文件，避免重复保存。各任务均保存 W/m² 浮点图，等于已含面积的功率除以真实感光面积一次。行优先、X 递增、首行为像面局部 +Y，像元中心由 `x=(列+0.5-宽/2)×pitch_mm`、`y=(高/2-行-0.5)×pitch_mm` 恢复。未接入曝光、QE、电子、噪声、ADC 或 ISP。

所有任务的 16 位无符号灰度 PNG 共用一个零偏移标尺，默认取**全部任务的共同峰值**。恢复辐照度为 `DN/65535×CommonMaximumWattsPerSquareMeter`，量化误差不超过半个灰阶；浮点文件仍是真值。没有 Gamma、sRGB、ICC、色彩变换、滤波或逐带峰值归一化，也不允许静默裁切。归档明确标注编码与物理比例，编码格式遵循 [W3C PNG 规范](https://www.w3.org/TR/png-3/)。原始 PNG 尺寸由传感器决定，与窗口截图无关。

打开归档时检查文件摘要、任务/节点完整性、全幅尺寸、全局计算量、节点求和、面积换算及 PNG 物理量化一致性。任务下拉框可查看各图，屏幕 8 位预览也使用同一标尺；多 ROI SFR 读取归档中的 float64 辐照度。明确打开的冻结实验在工程切换后保持来源，按冻结条件另存复算沿用原输入。

对应接口为 `PrepareSceneLinearBatch`、`RunSceneLinearBatchAsync`、`OpenSceneLinearBatchAsync` 和 `ReadSceneLinearTaskAsync`。自定义离散或有限源谱的批次可由接口声明，界面提供当前镜头与原文形状两种预设及自定义文件回放。逐任务的正式 MTF、独立工具与收敛不是本阶段的通过项。

## 全幅图上的多 ROI SFR

完成或打开 `.scene-linear.zip` 后，切换“多 ROI SFR”。在完整预览上拖框，或填写从 0 起的左列、顶行、宽、高；反向拖动和窗口适配均换算回原始像素，不重采样图像。填写唯一名称、选择“近竖直边”或“近水平边”，再添加或更新 ROI。列表可选择、删除，修改定义会清除旧测量。每个 ROI 宽高各 32–256 px、法线半窗口 8–48 px；最多 32 个定义、128 个任务/ROI 组合。可测全部波段，也可只测当前任务，共用同一组原幅面坐标。

测量器只接原始 W/m² 像元与像元尺寸，不读取靶标角度、镜头参考或显示图。水平边通过无插值转置复用同一估计器；截距映回原幅面，像面毫米坐标与法线按首行方向转换。位置是实际拟合边缘在 ROI 中段的像素中心，法线为探测器局部 X/Y 下的规范无符号方向，尚未赋予 T/S 或自动匹配视场。两种方向保留既有 `0.02 ≤ |slope| ≤ 0.25`、残差 `≤0.25 px`、窗口支持和非空投影箱门限；没有放宽原质量标准，也未宣称完整 ISO 12233 实现。

每项独立返回曲线或明确失败：无光、非法区域、无对比度、交点/邻边导致的不一致、角度/拟合或采样支持不足。失败项没有替代曲线，其他 ROI 继续测量；可以取得拟合时保留失败前的斜率、残差和扫描线数。有效结果还保留每箱最少样本和投影样本总数、线性对比差、ESF、加窗 LSF、SFR、Nyquist 内的首次 MTF50/MTF10 交叉，以及 cycles/pixel、cycles/mm 两套频率。没有交叉时显示“Nyquist 内未交叉”。

界面可切换 SFR、ESF、LSF，选择 ROI 查看质量和实测方向；图上的黄线来自图像拟合。ESF 单位 W/m²，LSF 为 W/m²/pixel，SFR 为无量纲；PNG 及线宽菜单使用共享绘图路径。某波段或 ROI 失败后不会沿用上一项的曲线。

“保存 ROI 与结果”只写 `.scene-sfr-rois.json`，拒绝其他后缀以保护原图归档；内容包括定义、逐任务结果/失败、算法、像元/行序、源文档、镜头摘要、完整批次清单摘要和辐照度文件摘要。它是原归档的伴随记录，不复制镜头与像元；保留对应 `.scene-linear.zip`。打开记录会核对源身份，并从同一浮点图逐项重算验证，不重新追迹镜头，也不使用当前工程。源批次不符或结果被修改会拒绝。由当前工程实时生成的源在工程变化时清除图与结果；明确打开的冻结源及其 ROI 记录继续保留身份。

对应接口为 `MeasureSceneLinearRoisAsync`、`SaveSceneLinearRoisAsync`、`OpenSceneLinearRoisAsync`，共享 Core 为 `LinearImageRoiSfr`。本阶段没有自动寻找所有边、曲边拟合、任意 PNG 的线性标定导入、MTF Mapper 读回或正式光学 MTF 对照。取得曲线表示 ROI 通过测量质量检查，不能据此判定场景采样已收敛。

## 原例与后续边界

资源包的 17 个文件及原件摘要已记入[资源清单](../validation/rechecks/2026-11-02/ansys-scene-sfr/original-reference-inventory.json)。其 Lens 710 处方确实存在，三条有效波长是 486.1327、587.5618、656.2725 nm；源光谱文件是有限宽度的窄带，不能直接替换为理想单线后宣称相同条件。项目保存的 Speos 版本为 2025.1.0.24542。

保存相机为 5000×3000、2.5×1.5 mm，即 0.5 µm 像元；完整 1500 万像元即使每像元一条光线也超过既有 8388608 光线和 262144 像元上限。`.OPTDistortion` 为未解码的二进制；原处方也未通过当前场景追迹器的几何适用性检查。因此原例全流程仍未复现，不用缩小传感器或其他镜头代替其验收。

预算内的全幅分块、逐源谱编排、线性交换与多 ROI 已接入；仍需原例完整幅面的专用资源方案、原场景几何/源单位和验收参数、独立工具逐 ROI 比较、匹配共轭/方向的正式 MTF、各级收敛、原生 ROM 及声明版本的 Ansys 文件接口。既有局部单色/多波长 SFR 的通过记录保持其原范围。
