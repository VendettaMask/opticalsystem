# 四个无焦项目：修复与原生复比

日期：2026-10-24。范围为既有 Sequential 95 文件中的四个无焦文件、五个结构。本轮确认的导入、光程、衍射、畸变及场曲问题均已在专项范围关闭。以下结果限于所列文件、请求、采样和 OpticStudio 2026 R1；其余分析没有由此取得通用认证。

## 实现

几何求交、折反射、玻璃色散、通光和光程继续使用同一个纯 C# Core。无焦评价单独使用角坐标、平面波前参考、屈光度和角空间频率；有焦评价保留既有焦面、参考球和长度单位。

- 导入 `ROPD`，在快照和 ZMX 导出中保留参考模式。ExitPupil 默认值不新增旧快照字段。无焦出瞳平面垂直于参考主光线，锚定该主光线在出瞳位置的交点；入射相位使用实际瞄准后的发射点。显式支持的另外两个平面模式有契约测试，Infinity 在无焦模式中明确拒绝；本轮外部认证只覆盖原文件的 ExitPupil。
- 无焦场曲输出 Diopter；对完整横向位置响应求逆，保留单方向零光焦度，并尊重显式对称/单侧傍基光线设置。Core 默认、桌面预设、复合分析和 FCGS/FCGT 的无焦取样统一为对称 ±0.0001；有焦既有取样和算法保持。百分比畸变使用输出方向正切；无焦参考放大率改用四阶中心差分，减小极小间隔对追迹误差的放大。绝对畸变图输出无量纲 `Δtan θ`，不再误标为 mrad；此定义不外推到其他畸变操作数。
- FFT 无焦路径不再调用有焦 working F/# 探针。包含多边形组时通过现有真实光阑像计算出瞳尺度，避免把忽略棱镜的一阶结果用于衍射坐标。
- 实现反序坐标断点，保留被 REAA/REAB/REAC 引用的透明参考面；接通逐结构 AFOC 和 NCOM。双筒通过原始左右手 POB 几何逐面调用现有 Core 折反射及 TIR，不使用拟合平移或另一套追迹器。
- POB 支持范围限定为毫米单位、一个闭合体对象、无面膜层/散射覆盖的有界三角面/四边形。四边形展开成三角面，保留十进制顶点的非共面细节；材料、面片随原生快照保存。缺失资源保留不可计算状态，未解析玻璃、开放壳、多对象、非毫米等不冒充可计算模型。组内偏振运输、ZMX 无损重导出及组内场景路径不在支持范围，相关入口明确拒绝。两个原始 POB 资源随镜头示例一起交付，运行产品不需要 Zemax。

逐面合计 **15/15 组、3240 条输入、44496 个有效物理面比较**。接受掩码、首次裁光、坐标和方向失败均为零；最大位置差约 7.51223e-8 mm，最大方向余弦差约 2.66015e-9。使用既有点对点 1e-6 mm / 1e-8 绝对限及原 1e-6 相对限。非序列组在原生目标行返回入口，Core 组样本表示出口；专项账目显式核对入口线、下一物理面出口以及折叠坐标断点对应，未跳过整组或把内部每个面片都称作已原生逐面认证。

OPD 的 **13 组、169 点**使用原波前误差门槛逐点通过，最大差约 **8.49637e-6 波**。Riflescope 轴外发射相位错误修正前同点最大差约 59.47 波；接入实际发射点后约 0.00783 波，修正参考平面锚点后达到上述结果。原生参考、输入瞳坐标和有效性标志没有被改写。

原低频矩阵保留 64 瞳采样、全视场/全波长 MTF 的原请求。另以原生读回出瞳直径与最短波长的截止频率乘 1.05 设置五个补充全带宽请求，上限分别约 **8.69957、56.44788、8.10168、8.10168、23.57959 cycles/mrad**；五请求、30 条 T/S 曲线均按原调制度门槛通过。这些读回只选择验证频率范围，没有给产品计算注入原生瞳尺寸或参考数组。

统一设置 55 cycles/mrad 的探索控制中，双筒两项为 Close，保留原结果。此范围明显超过双筒物理截止频率，改变上限也改变了原生输出的低频曲线；不能用后续按物理带宽设置的 Pass 改写该试验，也没有为了匹配它修改 Core 的 OTF 或容差。

分析目录展开为 **150 项：30 Pass / 120 Incomparable，无 Difference/Error**。其中 30 项具备本轮选定的比较契约，120 项保留各自缺少无焦契约的原因，并不计为通过或计算错误。此前单侧场曲契约的 **28 Pass / 2 Difference** 阶段账目完整保留；新的对称取样请求单独生成，不改写旧请求或原生数组。有焦原请求没有随之变化。

## 弧矢场曲差异的关闭

此前请求沿用了单侧 1e-5 归一化瞳间隔：双筒结构 1 最大弧矢差约 **0.00431921 D**、结构 2 约 **0.08224252 D**；切向轴上也有约 0.00118750 D 差异。该取样与本轮原生无焦场曲的评价契约不同。对比预先列出的单侧/对称、1e-5/1e-4/2e-4/1e-3 控制，**对称 ±1e-4** 同时复现左右手两结构的 FCGS/FCGT 和完整场曲图，并在全部五个无焦结构成立。

修正后双筒两结构弧矢最大差均约 **4.65795e-9 D**，切向最大差约 **4.90461e-9 / 4.12849e-9 D**；Riflescope 场曲最大差约 3.55294e-9 D。五个复合场曲/畸变请求全量通过原先声明的独立屈光度门槛；另有原生 FCGS/FCGT 的 20 个读回值按 1e-6 D 逐值验证。没有加入镜头专用补偿、改变面片来拟合曲线、放宽门槛或替换参考。

±1e-4 是本轮对 **2026 R1 和所列模型**实测确认的兼容契约；公开说明没有给出所有版本通用的这个私有取样常量，不能把观察推广为通用规范。显式指定其他间隔/单侧光线仍按请求执行，旧失败记录继续说明定义不一致会产生什么差异。原生会话复采、同点真实光线、POB 剖分枚举、显式三角面及波前二阶差分试验均保留，最终只采用共享 Core 已有追迹和对称响应评价。
