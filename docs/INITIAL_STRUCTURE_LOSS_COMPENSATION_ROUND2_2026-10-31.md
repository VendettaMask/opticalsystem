本轮已完成原两任务的五种子新旧对照和全部完成验收的冷复算；减片有稳定重复结果。F/8 原固定布局两臂仍为 0/5，随后另开的新后焦布局探针已得到一份通过原全部验收的设计。该新路线尚未完成端到端多种子对照，不能把单例与原 0/5 统计合并。证据保存在 `validation/rechecks/2026-10-31/initial-loss-round2/`；第一轮及中止批次的失败不覆盖。

正式对照中，原 21°新策略 5/5 得到合格二片，旧策略 0/5；五份新记录按精确光学指纹去重为一份处方。RMS 49.996622 µm、最大半径 149.987024 µm，原 35 个视场通光/边界及其余验收项均通过。共同冻结 Core 和当前产品 Core 均独立复算并经官方 STAROPT 保存/读回通过，见[可打开工程](../validation/rechecks/2026-10-31/initial-loss-round2/comparison-current-core/current-product-export-seed42/evolution-003.staropt)。F/8 两臂仍均为 0/5。

## 改进方向

显式 `GateCompensationVersion=2` 保留旧空配置和 v1 的执行/检查点身份。新策略复用共享 Core 已有的 `InequalityLeastSquaresStep`：在同一次受约束最小二乘求步中处理原焦距/F 数、制造、固定变量界及通光/像差条件，替代先求步再欧氏投影。所有光学值和导数仍来自 Core；模块只组装残差与约束。

试跑发现，所有视场平均光斑与最差视场验收目标竞争，可使补偿停在仍有失败像质项的位置。v2 优先减少原 RMS、最大半径、畸变及失光的实际超差量，不把平均光斑作为失败项修复的竞争目标。末轮训练使用 Gaussian 10×32；独立终验的字段、光谱、通光、边界、几何及容差均保持。原 21°任务在 `FieldsPerDirection=21` 下实际合并得到 35 个视场点，F/8 得到 21 点，不能把“每方向 21”误写成所有任务只有 21 点。

新增显式机械坐标绑定，避免 Core 厚度累加的一 ULP 往返把合法边界点错误拒绝；默认绑定及旧端点逐位身份保持。求步中去除在整个信赖域内只有机器舍入量级的线性约束，避免把固定光阑边缘的导数噪声归一化后锁住镜片。每个真实试探点仍检查原 Core 值；焦距和制造超差采用小量二次修正后重新追迹，不直接放行。

失光恢复采用与求步一致的原尺度联合超差目标，通光恢复后转入保通光的像质补偿。训练目标在原像质阈值内侧留 `1e-4` 的相对数值余量（50 µm RMS 对应 0.005 µm），完整验收仍用原 50/150 µm 与原畸变上限。训练结束判断只忽略光阑瞄准舍入噪声，不能给予合格归档权限。

F/8 的辅助一阶包络在共享 Core 内实现：固定真实光阑、各界面的原净口径、正权重波长和原字段范围，给出高度/亏量及其导数，用于重新分配初始光焦度。名义值与 Core 一阶追迹、所选导数与中央差分核对；它不替代最终真实光线。该阶段的矩阵、雅可比、函数和制造探测均计费，不能把“零物理追迹”称作零计算成本。

包络恢复只通过显式 `TransmissionEnvelopeVersion=1` 启用，默认关闭。开发记录中，包络亏量下降仍可产生不存在可传播真实光线的处方；这些 `DomainFailure` 均保留为失败。最终对照未启用它。更早开发版少计了每次包络调用的一次名义矩阵请求，最终 Core 已同时计入名义和微分光阑矩阵；旧证据不改写，也不据此声称预算收益。固定布局 Delano 多起点和从平板出发的包络探针同样未找到合格 F/8，不计为冷启动成功，更不据此证明物理不可行。

F/8 最终候选显式开启 `TransmissionProfileVersion=1`，只在原 `EnableProfile=true`、允许 Profile 操作且非“固定拓扑/仅减片”任务中，对可编辑标准面释放四阶偶次项。逐面净口径、机械口径、玻璃、位置、曲率初值和锥面权限不变；系数界仍由原 0.02 mm 坐标边缘 sag 权限计算。保护/过渡面不释放，关闭配置不增加历史 JSON 字段；本轮没有切换桌面默认模型或优化路线。

## F/8 新后焦布局与边缘修正

原固定布局、平板起点与一阶包络没有通过验收，记录全部保留。随后检查到厚片构造只用最小后焦分配布局，会把本可留作后焦的空间消耗在组内。独立探针在原生成机械包络内提高采样用的后焦下限，保留原验收下限、固定参考/光阑/像面、八片材料许可和逐面口径；这是更紧的采样条件，没有放宽目标。它选择合法新布局，再以原曲率界、以该生成布局锚定的原 ±0.1 mm 轴向范围补偿。

球面阶段最差视场通光达到 99.2708%，仍丢 9 条边缘，RMS 72.535908 µm；四阶续算达到 RMS 50.465525 µm、最大半径 117.213210 µm，仍丢 1 条边缘，因此都未放行。原权限本已允许偶次最高八阶，随后只加入六阶项，旧四阶、曲率和轴向界保持。RMS 达到 49.995000 µm，但仍有约 `1e-17` 平方残差量级的一条边缘亏量，旧阶段判断把它当作已恢复，导致求步停滞。

通用 v2 修复在原像质已通过、仍有微小且确有移动导数的边缘亏量时，组装 Core 受约束的向内参数修正，同时保留原焦距/F 数、制造、像质和变量界。忽略固定光阑瞄准导数的机器噪声，不扩大光阑，不给实际通光增加 epsilon。修复后的正式 `FixedTopologyOptimizer` 从该失败点 **1 次接受更新、3 次函数**收敛，原 21 视场终验通过，并完成两次额外冷复算及官方保存/读回。
