## 参考与实现边界

- [OSD 官方软件概览](https://osdoptics.com/synopsys-software/software-overview/)将 DSEARCH 定义为定焦系统的二进制形式搜索，局部优化使用其 PSD 算法。
- [官方自动设计工具说明，第 7 页](https://osdoptics.net/files/Automatic%20Design%20Tools%20in%20SYNOPSYS%28TM%29.pdf)说明 N 片对应 2^N 个正负初始方向。本项目据此展开形式，再交给自身的正式 Core 和既有有界信赖域求解器计算。
- [官方 Lesson 16](https://osdoptics.com/wp-content/uploads/2020/05/16_a_practical_camera_lens.pdf)展示系统/目标输入、QUICK 筛选、候选比较与后续优化。本项目实现相应工作流程，不解析或输出 SYNOPSYS 宏，也不宣称复现 PSD、退火、AEI 或达到其性能。

## 已实现

`DesignFormSearch` 为每个片数枚举正负方向，无重复完成一轮后才开始另一个玻璃/光阑组合。片数范围按轮交错，防止小预算只访问最少片数。第一种是筛选允许的最正方向，其余由保存的随机种子确定顺序。`+/-/*` 筛选仅限定初始化，不固定优化后的符号；非空筛选要求固定片数。

每个试验先保留零曲率处方，再记录正负曲率初始化。默认起始半径是目标焦距的 10 倍，这是本项目的参数选择，不是 SYNOPSYS 默认值或光学推导。正方向的前后面分别为 +R/-R，负方向反之；适配器仍应用既有球面参数界限，实际半径保存在初始化快照。默认中心厚度、空气隙取规格最小值，可在搜索设置中显式指定；超过总长的输入在工作前拒绝。

QUICK 使用有界粗采样局部优化筛选各根，FULL 给每个根完整的单试验预算并允许密采样修复。两者都在发布候选之前重新进行原视场、原孔径、全部有效波长的正式 Core 密采样验收；完整物理门槛没有修改。它们的名称表示本项目流程，不表示与 SYNOPSYS 同名参数逐值兼容。

筛选完已计划的根后，`DesignFormScheduler` 对保留分支按已用轮数分配工作，每轮依次安排细化、参数扰动、可用的单/双片玻璃替换和允许的光阑调整。历史以原根的谱系累计，改善子候选不会清零。排名仅用已完成独立密采样的候选。排名池可能随结果变化；预算可能在一轮结束前耗尽，因此完成初始形式覆盖不保证已尝试全部玻璃/光阑操作，也不保证全局最优。

桌面左侧分为“系统／目标／搜索”页签。搜索页提供 QUICK/FULL、起始半径/厚度/空气隙、形式筛选、起始光阑及是否探索其他位置、起始试验上限和保留方案数。右侧候选表显示起始形式，“搜索计划与过程”页显示形式覆盖、逐试验操作与预算。参数变化清空旧结果。搜索设置与形式谱系随检查点保存；历史 v1–v4、v6、v7 仍可读取、导出和建立独立 v8 细化，不能原地换算法续跑。

## 输入对照

| DSEARCH 中的概念 | 本项目的对应输入/结果 |
| --- | --- |
| SYSTEM | 系统页的焦距、孔径、半视场、波长与权重 |
| ELEMENTS / FNUM / BACK / TOTL | 系统/目标页的片数、F/#、后焦和总长约束 |
| RSTART / THSTART / ASTART | 搜索页的起始半径、中心厚度与空气隙 |
| FILTER | 固定片数下的 + / - / * 起始形式筛选 |
| STOP | 起始物理表面及是否探索其他物理表面 |
| QUICK 与后续优化 | 快速筛选或逐形式完整优化，之后选择候选追加预算 |
| 候选检查 | 结构/光线、目标、处方、视场明细、来源、搜索过程 |

这些是工作流程对照，输入不具有 SYNOPSYS 宏语法兼容性。所有设置作为本项目类型化配置与检查点保存。

## 桌面操作

1. 在“系统”输入焦距、孔径、最大半视场和波长；在“目标”设置片数、总长、后焦、玻璃及成像质量要求。
2. 在“搜索”选择 QUICK 或 FULL。形式筛选留空会遍历允许的正负方向；固定三片时填 `+*-`，只搜索 `++-` 和 `+--` 两种初始方向。起始试验上限包括后续材料/光阑组合，不等于不同正负形式的数量。
3. 点击“预检查”，在“搜索计划与过程”核对可能形式、计划形式和每根预算，再点击“开始形式搜索”。运行结束后同时检查完成覆盖率与候选是否达标。
4. 选中候选，在“目标对照”和“视场明细”查看差距，用“设为 A/B”比较实际光线。需要继续优化时填写追加评价次数并点击“细化选中方案”；“导出结构”保存所选处方并自动回读验证。

“继续运行”只使用同一实验尚未消耗的预算；追加细化会建立独立实验。修改输入表示新设计任务，会清空当前显示的旧结果；已保存记录可重新打开。

## 有界搜索及尚未实现

起始试验上限仍为 128，总试验上限仍为 256，检查点文件仍受原 64 MiB 上限约束；没有为了形式枚举取消资源限制。8 片有 256 个无筛选形式，一次运行无法穷举，必须使用形式筛选分区。预算不足、试验失败、中断或只写入平板根时，不计作已完成形式；界面明确显示覆盖不足。保留候选优先覆盖不同初始化/材料/光阑家族，不等于证明最终镜型互不等价。

PSD、高阶导数优化、SYNOPSYS 宏兼容、自动增删片、连续玻璃模型、OPD/MTF 搜索目标、连续自由光阑、变焦 ZSEARCH 均未在本次实现。旧的 `FlatStartScheduler` 决策方法仅保留历史策略机制测试与旧配额计算；v8 搜索使用新的分支调度。

### 剩余问题与下一步

分支检查统一采用各规格的种子 101。100 mm 固定后焦已经覆盖细化、扰动、单片/双片换玻璃及移动光阑。24 mm 可见光虽完成 16 种初始形式，但剩余预算只执行了细化和扰动；六片规格只覆盖 24/64 种形式，起始筛选消耗 4704 次、细化消耗 5296 次，没有进入其他邻域操作。新调度修复了改善后谱系历史被重置的问题，但有限预算仍会限制后续操作覆盖。

下一步应先在独立机制用例中验证两个问题：有界局部优化能否在多波长条件下同时收敛焦距与光斑，以及固定总预算如何在初始覆盖、分支细化与玻璃/光阑探索间分配。之后冻结新版本，再完整重跑原协议和留出集，保留原冻结规格和质量门槛。
