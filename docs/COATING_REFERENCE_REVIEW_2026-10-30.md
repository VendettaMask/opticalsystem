# 镀膜设计优化与固定参考复核

本次修改 C# 镀膜的候选选择和目标评价，不替换共享 Core 薄膜求解器。参考固定 TFStudio `8b942b3f956728a23cea2b35023c8b5d8de17428` 与 tmmcore 0.4.2；归档、许可证和原 120 组参考保持。结果与失败范围见[本轮证据](../validation/rechecks/2026-10-30/coating-reference-review/README.md)。

后续对高反/窄带未达标的材料前提、耦合结构、宽度定义和实际参考优化器复跑见[原因复核](COATING_FAILURE_ANALYSIS_2026-10-30.md)。后续仅增加诊断，没有改变本页交付行为或把理想无吸收控制算作真实材料达标。

当前新建窄带已由后续的协议 3 接替，见[材料诊断与窄带竞争](COATING_NARROWBAND_COMPETITION_2026-10-30.md)。本页以下保留此前交付时的算法、结果和成本范围。

## 当时使用方式

新建减反、高反示例启用 `Settings.DesignProtocolVersion = 2`，记录为 `target-balanced-coating/2`。点击“1 生成膜系”时，先比较模板，对最多 16 套候选各做最多 2 次正式 Core 优化器迭代，按优化后的表现选择起点，再对选中者做原密集复验。“2 优化”继续优化当前处方。

“结构搜索”复用已有短程结果，合计最多 32 个短程候选，再按用户起点数做完整优化和密集复验。短程上限为 `min(2, MaximumIterations)`；完整阶段仍使用原每起点迭代上限。固定层和厚度界不变；存在固定层时禁止结构变化。粗候选不声明达标。

新增阶段消耗额外计算。`Run.Evaluations` 是正式局部优化器报告的评价数，`TemplateEvaluations` 单列模板及排序的目标评价次数，都不是所有单波长求解次数。生成对选中者密集复验一次，结构搜索另对各完整起点复验。界面提示新评价方式和候选数，新旧 merit 不直接比较。

旧文件缺少设计版本时保留原目标/生成/搜索行为，打开编辑不自动升级。新建窄带也保留旧默认：本次新窄带评价和扩展结构没有稳定收益。

## 与参考对照

| 内容 | 固定源码与本地处理 |
|---|---|
| 薄膜计算 | 对照 tmmcore 实际 JavaScript TMM；本地稳定散射递推保持，复验原 120 组及新输出膜系 R/T/A |
| 起点排序 | `seedGenerator/rank.js` 先 `refineFn` 再排序；新协议借鉴此流程，调用现有 Core 优化器 |
| 目标权重 | 上游 `filterTarget.js` / `meritFunction.js` 使用单侧残差和各点 sigma；本地按目标分组，平均与最差违反量各占一半，避免采样点数改变权重 |
| 窄带 | 保留本地峰位/FWHM/峰值 T/OD 定义；试验加入 Core 实际峰位和半高宽指导，不称为上游同一评价函数 |
| 多腔构造 | 扩展提议的 8 个常折射率案例与实际 `prototypeLayers.js` 一致；没有完整解析匹配、离散下降或全局综合 |
| 斜入射 | 本地保留绝对目标波长和实际角度，不照搬上游部分嵌入式评分移除通带漂移的处理 |

没有移植上游优化器或引入 JavaScript/WASM/Python 产品计算；Node 仅用于离线参考。仍使用现有 Damped Least Squares、Nelder-Mead 或 Coordinate Pattern Search。优化只组装 Core 结果的残差；材料 n/k、目标门槛、独立密集采样及收敛要求不变，最终仍按原逐项检查判定。

## 四组实际结果

同一材料、目标和层数上限，每次完整优化最多 24 次迭代：

| 规格 | 原策略 | 本轮默认 |
|---|---|---|
| 500–600 nm 减反，最多 8 层 | 2 层，最大 R 1.098132% | 4 层，最大 R 0.084967%，达标 |
| 520–580 nm 高反，最多 32 层 | 最低 R 95.677295% | 最低 R 95.984480%，未达 98% |
| 单腔窄带 | 峰值 T 72.603178%，FWHM 27.228174 nm | 默认保持相同，未达标 |
| 双腔窄带 | 峰值 T 68.946148%，FWHM 20.297745 nm | 默认保持相同，未达标 |

减反新增 123 次短程优化器评价，完整阶段由 26 次变为 73 次；高反新增 674 次，完整阶段由 809 次变为 811 次。不是固定总计算预算或整个 TFStudio 优化器的成功率对照，不能由未达标推断物理无解。

## 显式窄带试验与保存

设置 `Settings.DesignProtocolVersion = 2` 可试用新窄带评价；扩展镜层/腔阶还需 `Target.Structure.PrototypeFamilyVersion = 2`。后者只在设计协议 2 下接受，默认关闭，打开、参数编辑和保存保留。未增加界面按钮，属于可读取的试验配置。

扩展包含有限奇/偶镜层、内镜层提议及一/二阶腔，最多 256 套提议再有限筛选，物理厚度仍由 Core 根据实际入射条件生成。构造一致不等于设计收益；本轮部分扩展双腔更慢、指标更差，所以不默认推广。窄带试验使用 Core 测得的峰位/FWHM；缺失 FWHM 只施加不可用惩罚，不补造带宽，最终仍会失败。
