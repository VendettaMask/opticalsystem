# C# 初始结构候选竞争与分阶段优化 v1

这项改动位于内置的“AI 初始结构 → 自主拓扑设计”，复用原 C# 构造、连续优化和共享 Core 物理评价。新流程由独立的“生成一阶起点”命令执行。主 AI 入口的托管 AutoLens、历史记录执行资格、自主拓扑检查点与续跑协议保持原行为。

## 使用

在“一阶起点准备”勾选“多结构候选竞争与分阶段优化”，会同时选择多布局厚透镜构造并关闭另一套独立像差排序，避免重复筛选。设置原始焦距、F 数、视场、片数、固定光阑、口径和厚度等权限后，设置准备总函数/每起点上限、总追迹和时限，点击“生成一阶起点”。视场沿用现有界面的半视场定义：全视场 25° 对应半视场 12.5°。

新模式的追迹默认上限为 500,000，阶段更新上限为 4；其他原准备上限不会自动提高。广角或多片建议显式设置 60–120 秒、每起点 40–80 次评价，并查看实际停止原因；上限不能保证全部候选完成。读取或保存计划不会执行优化。自定义阶段、候选路线和预算可在版本化计划中保存回读。

## 流程

1. 按允许片数、玻璃、逐面口径及固定参考/光阑/像面构造多套厚透镜。候选初始边缘光线路径采用均衡、前段变化、后段变化、交替变化四种提议，且分别采样厚度、间隔和允许材料。路线名描述提议方向，不保证某种正负光焦度形式。允许的光阑前后分配也参与；最小厚度都放不下的分配直接拒绝。每套候选先通过原一阶和 64 径向制造检查，再进入竞争。
2. 默认三阶段为视场/孔径 **50%/70% → 75%/85% → 100%/100%**。临时复制视场及光阑净半口径，目标 F 数随孔径相应变化；其他目标和制造约束不放宽。各阶段复用原固定拓扑优化策略，使用 CPU 和显式稀疏训练采样。每个阶段重新建立优化状态，轴向变量范围始终锚定该候选刚生成时的位置，不能逐阶段累积移动权限。
3. 同一轮候选获得同等函数、梯度、追迹和优化时间配额；完成后按原几何、实际通光、边缘检查及原生光斑统计排序，在相近表现中保留路线和结构差异。默认每轮存活比例 0.67，仍高于终验名额时至少淘汰一个，保留最多两套终验候选。例如四套候选依次为 4 → 3 → 2 → 2。没有完整统计的候选不优先于同等几何和通光下的完整结果。
4. 最终恢复原视场和光阑，调用未修改的独立完整终验：21 视场密度、10×32 高斯瞳采样、中心及 32 臂边缘检查、64 径向制造检查，以及原焦距、F 数、RMS、最大半径、畸变和通光门槛。只有完整且 `MeetsTargets` 的结果进入 `QualifiedIds`。

## 预算与记录

准备独立计费，不从随后的自主设计借用额度。全流程遵守原总函数、单候选累计函数、时限和 CPU 追迹硬限。构造、被拒提议、梯度、稀疏筛选、终验与中断前的实际工作均保存；CPU 追迹包括瞄准和失败光线。

默认总梯度上限 200，每候选阶段追迹最多 15,000，其中筛选预留 2,500；总追迹中留 100,000 给有限名额的终验。单候选阶段优化时间最多 8 秒，并按剩余轮次/候选数公平缩减，整体时间预留 20% 给终验。构造退火提议在原提议上限内缩减，为后续最小阶段额度留空间。没有足够完整一轮额度时停止阶段优化，尝试用剩余终验额度检验已保留候选；终验不足、取消或超时不能产生合格声明。

报告保存每套候选的来源路线、光阑分配、初始处方、每阶段临时规格、优化终点/工作量、筛选统计、淘汰选择和原规格终验。界面区分“候选 / 工作起点 / 原规格合格”，并显示每轮进入及存活数量。工作起点可以未通过像质门槛，但必须完成原规格终验且通过原几何、焦距和 F 数门槛；它们不会自动写进自主设计的合格归档，后续自主设计仍重新验收。

## 范围与限制

当前是固定片数、多个起点的分阶段竞争。未加入新的拆片/合片或鞍点插入路线，也未自动扩大逐面口径、改玻璃目录或改变允许的面型。既有后续结构演化继续独立使用。初始路径仍是边缘光线提议；全视场像差通过后续原生评价与优化介入，不能保证任意广角/大孔径规格成功。

准备报告可保留取消前的安全终点与账目，v1 不提供阶段优化断点续跑；再次准备是新的一次有界执行。原自主设计记录的续跑能力保持。历史空 `Competition` 不序列化该字段，旧算法身份和历史采样不升级。
