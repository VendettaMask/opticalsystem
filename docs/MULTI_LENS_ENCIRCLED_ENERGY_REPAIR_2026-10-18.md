# 多镜头包围能量分阶段修正

日期：2026-10-18。原七款镜头的原设置残差已关闭；扩展矩阵尚未全部关闭。原容差、冻结参考和已有通过项保留，不能据此宣称全部镜头或全部采样档位达到商业软件精度。

## 修正范围

共享 Core 修正 FFT 包围能量的共轭采样间距、系统主波长的像方尺度与参考球面，以及复色峰值归一化 PSF 合成时的波长平方因子。32/64 档直接从毫米单位的归一化频率生成光瞳坐标，避免通过圆整后的伸缩量重建坐标。128 档及以上保留此前的间距约定；系统参考球面和复色修正仍生效。本轮高档原生控制为 128，256/512 没有因保留公式而获得认证。这是有明确范围的兼容保留，不能称为高采样边界残差已解决。

ZMX 导入区分用于定义系统入瞳的固定平面 STOP 半口径，与实际浮动表面孔径。原逆远摄镜头第 9 面在本机 API 中的孔径类型为 `None`，六条独立光线均未遮挡，Core 原先错误地在该面截光。显式浮动孔径经原生导出确认使用 `FLAP`，现在导入、追迹及导出往返均保留。带光焦度表面，以及发生折射或反射的 STOP，保留其既有固定物理孔径行为。

验证器另外修正 X/Y 狭缝和方形能量的曲线配对：原生保留的衍射极限不再被误配为产品的实际视场曲线。原始两条曲线和严格数量检查仍保留；径向能量仍分别比较理想与实际两条曲线。官方表面孔径语义参见 [Ansys 孔径说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v251/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Aperture_surface_properties.html)，本报告的具体文件行为以本机原生回读和逐面光线为证据。
