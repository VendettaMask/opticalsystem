## 已交付的本机链路

追迹控制可打开偏振与相干探测；对象属性可设置非偏振或 Jones 幅值/相位、局部参考轴、相干组、初相位及探测器归一约定。光源波长编号 0 按当前波长权重抽样，正整数保持原单色语义。不同波长和不同相干组独立平方后相加。字段沿原始共享追迹、分裂、光程和体吸收传播，透明界面用真实 S/P 振幅，转换组件调用共享多层膜求解器并在反向遍历时反转膜序。镜面使用理想 PEC 约定。

每次入射保存归一双 Jones 模态、当时真实功率和折射率；不能用分裂后的标量强度代替入射强度。探测器按本地 XY 输出 Stokes I/Q/U/V，并单独保存纵向功率；斜入射时 I 是 XY 投影，不能当成完整三维功率。查看器支持相干功率、未归一幅平方、Stokes，以及复场实部、虚部、模和包裹相位。复场必须选择单波长、单相干组、单模态与探测器局部 X/Y/Z 分量，不能把互不相干的模式合为一个相位。幅值是射线幅和 √W，随采样变化，不是 V/m 电场。

相位使用 −180°…180°；零幅值或落入浮点求和误差尺度的像素以 NaN/有效掩码保留为空白，不伪造为零度。该筛查不是总光程/相位误差认证，不改变原场或能量账本。禁止相位求和归一、取对数和跨越 ±180° 的线性平滑；有符号分量禁止求和归一/取对数。实际热图和逐行/列剖面共享类型化角度/幅值量纲；复场不提供有歧义的像素相位加和剖面。CSV 保留波长、组、模态、分量、单位与有效列，空相位值不写成零。源/波长/组/模态选择改变会清除旧图并取消旧请求，不用新标题解释旧数据。新物理数据的质心/RMS/均匀度始终按实际非相干功率统计，避免用带符号 Stokes 或角度作光强权重。

对象编辑器的“优化与公差”打开同一桌面页：可添加最多 64 个对象位置、角度、可写浮点参数或光源相位变量；设置上下限、物理步长、补偿量和制造分布。目标包括总/像素功率、辐照度、相对 RMS 均匀度、实际光线落点质心/RMS、相干功率和 Stokes Q/U/V，可按源、波长和路径筛选。位置矩使用加权在线方差，不将落点量化到像素中心。

优化复用既有优化器，固定训练种子，保留实际评估的最好候选，再以不同种子验证全部目标。未达目标、场景或材料已变时拒绝应用；应用事务可撤销。每次任务捕获场景、材料和请求副本，计算不修改工作区。公差复用共享高斯/均匀采样，输出中心差分灵敏度、原始制造抽样、逐样本指标/失败原因、补偿结果和良率；不裁剪高斯尾部，物理无效样本仍进入良率分母。全部评价和补偿预先计入统一上限，实际发射与预留源光线分别记账，异常中已有计算也计入成本。

轻量方案 JSON 仍绑定原场景/材料摘要，读取时要求对应项目；结果 JSON 绑定运行时冻结方案，不随之后的界面修改漂移。另提供“保存完整实验”/“重放实验”：自有 `OpticalSystemDesign.NscExperiment` v1 ZIP 保存一份 `source.staropt`、全部实际引用材料模型及别名、方案、数值结果和逐条 SHA-256 清单。结果不重复保存候选场景；它可由原场景和变量值重建。重放读取包内几何/材料/设置，在后台重新优化或执行制造抽样，并对原记录作规范 JSON 逐值比较；当前工作区即使为空或已经改变，也不会被重放覆盖。界面重放结果不能隐式应用到另一场景。

## 相干结果的适用边界

相位采用共享薄膜的负时间约定、实际光程和像素中心参考。RawCoherentPower 是双复矢量模平方之和，依赖射线采样；CoherentPower 使用显式射线探测器归一约定：单像素/关闭总归一时，按每组的幅和平方缩放至该像素非相干功率；多像素打开总归一时，在每个波长/组内归一到该组总非相干功率。物理能量账本始终来自真实射线功率，不用相干显示值补账。

此方法借鉴 Ansys 的射线探测器约定，额外保持波长和相干组分离。它不等于任意矢量波场的严格功率预测，不能用于声明完整干涉能量重分配、空间相干度/相干长度、Huygens PSF 或衍射认证。功率型经验膜和标量 BSDF 缺少 Jones/Mueller/相位数据时明确拒绝偏振/相干追迹；相干模式拒绝未实现振幅重要性权重的 Simple Stochastic；强吸收非均匀波也保持不支持。普通实体逐面物理膜编辑、一般偏振器/延迟器及退偏散射仍有缺口。
