## 范围

本文记录桌面 GUI 的当前工作流，以及已经落地的应用边界。它不是第三方界面的逐像素复刻说明。

## 当前结构

```text
MainWindow
  ActionManager
  PanelManager
    WorkspaceDockFactory
      ToolDock
      DocumentDock
  IWorkbenchApplication
    文档、处方、分析、可视化、优化、公差和多配置服务
```

Core 与 Application 不依赖 Avalonia。App 只消费应用服务和不可变 DTO。分析专用控件由 `AnalysisPresentationKind` 选择；坐标范围、悬停、单位转换和 CSV 导出由 `AnalysisAxisQuantity` 与 `AnalysisAxisUnit` 驱动。

## 顶部菜单与工具栏

顶部使用紧凑分类页签，下方为图标与文字并排的单行工具栏，默认选择“文件”。分组只保留竖向分隔线；分析和材料等已有下拉菜单沿用原命令，箭头移到文字右侧。四套主题共用布局，工具栏在窄窗口可横向滚动，字号增大时按内容扩展。

顺序模式“文件”工具栏依次为新建、打开、保存、导入、导出、示例、撤销、重做。“导入”包含 Zemax ZMX，“导出”包含 CAD（STEP）；撤销和重做随当前文档历史启用。非序列模式提供新建、打开、保存、撤销、重做，保留模式隔离。

## 亮模式与默认数字格式

macOS 主窗口普通亮模式的标题栏与菜单栏现连成正蓝整体，标题居中并随文件名更新；保留原生交通灯。普通亮模式使用白色主区与工具栏、雾蓝侧栏和表头。普通按钮白底，悬停与按下使用不同浅蓝色阶；选中、焦点、禁用和错误各自独立，失焦不恢复系统高亮。侧栏外沿雾蓝、分组内部连续白底，以内收细线组织，标题悬停底色两侧留白并使用小圆角，普通模式无投影。精确色值集中在 `BlueThemeTokens`，详见[状态与验证矩阵](BLUE_THEME_2026-09-27.md)。

数字显示默认最多 3 位小数，科学计数法尾数同样最多 3 位，不补无意义的尾零。“设置 > 格式与字体”仍可调整或恢复默认；已有明确保存的自定义精度会保留。显示舍入不修改光学模型与 STAROPT 保存值。

“机械半直径”列和表面属性“绘图”摘要现已接入同一位数设置；修改精度后同步更新，数值排序、只读状态和原始精度保持不变。见 [机械半直径显示精度修复](MECHANICAL_PRECISION_2026-09-27.md)。

库存镜头匹配的结果说明、“厂商页面”按钮与表头已按实际可用高度测量，重开及平铺时不再相互覆盖；高度不足时只在原设置区内滚动。公共表头不再为隐藏的排序图标预留 32 DIP，长表头和标准文本单元格提供完整提示。库存目录/匹配的单位独立显示；三套制图参数采用短标签、完整提示与单位行，滚动条预留宽度，保留原分栏和数值语义。见 [容器测量和文本适配修复](PANEL_CONTENT_LAYOUT_2026-09-27.md)。

## 编辑与更新

镜头编辑器通过 `IPrescriptionService` 提交命令。应用层负责验证、撤销/重做、拾取和求解、修订号及事件发布。轻量查看器防抖更新；重型分析只标记为过期，等待用户点击同步。

## 分析结果

本节是当前分析 UI 的简要操作说明；完整布局与颜色契约见 [UI 设计走查记录](UI_DESIGN_REVIEW.md#当前分析结果-ui-契约)，各分析的 Zemax 定义边界见 [Zemax 分析参考](ZEMAX_ANALYSIS_REFERENCE.md)。

分析结果统一提供“绘图 / 数据 / 文本”页。绘图支持指针中心缩放、拖动平移、双击重置和最近采样悬停。图内标题、刻度、坐标轴、图例、色标、矩阵标签和 fan 卡片标题使用统一分析图字号，标题仅用字重区分。光线像差图和瞳孔像差图先把同一视场的 `P_y` 与 `P_x` 组合在一起，再根据视场数量自动规划组合卡片的行列，末行自动居中；两个 fan 面板尽量接近正方形。瞳孔像差的全部子图共用按全局数据确定的对称纵轴缩放，说明区只保留日期、共同最大缩放、波长和像面。其它分析使用各自的自动铺满或固定矩阵布局，结果区不显示方形切换开关。

离焦点列图使用专用紧凑矩阵：每个小图隐藏重复的 X/Y 轴标题和刻度文字，只保留视场行标签、离焦列值及统一的离焦轴说明；小图外框保持方形并扩大有效散点区域。点坐标仍是像面 X/Y 截距，不能把两个方向都显示为“像高”。

全视场点列图、光迹图和干涉图属于单图二维空间分布，除 X/Y 数据等比例外，外层绘图容器也默认保持方形；右侧图例只占用独立列，不再把绘图外框拉成长方形。

色焦移保持普通曲线图的自适应宽屏布局；横轴为焦移、纵轴为波长，不套用二维空间图的方形视口规则。

矩阵点列图使用 140×140 的方形小图和更紧凑的行列标题。每格不再重复生成“像高”轴标题及其大块边距，有效散点框使用最小 4 像素绘图边距；视场、波长和共同缩放文字缩小，矩阵空间优先分配给点列形态。

普通矩阵点列图按“视场行 × 波长列”拆分；结构矩阵点列图则按“视场行 × 结构列”组织，每个单元叠加该视场和结构下的全部波长。结构矩阵的蓝、绿、红波长图例可独立开关，但不会再把三个波长拆成三个格子。

颜色分为两类语义：波长不是普通分类，凡按波长着色的曲线、图例以及二维/三维光线，都根据真实纳米值使用稳定的光学工程配色，例如 Fraunhofer F/d/C 线 `486.1 nm`、`587.6 nm`、`656.3 nm` 分别使用蓝、绿、红。这里的绿色是为了工程曲线辨识而采用的约定色；`587.6 nm` 的真实单色光外观偏黄，文档不得把约定色描述为肉眼光谱颜色。可见范围外的紫外/红外使用中性灰。按视场、结构或其它离散类别着色时仍使用主题分类调色板，并以显式系列语义为准，不会因为名称中带有波长而被误判。全视场点列图的“按视场”模式现已真正按视场拆分系列。

分析目录保留 FFT、PSF、MTF、RMS、Huygens、Zernike、Jones、Y-Ybar 和 `vs.` 等既有专业术语。显示名称是文案，不能参与实现分派或缓存身份。

分析 Ribbon 的报告入口统一显示为“报告”下拉菜单。菜单依次提供“表面数据报告、系统数据报告、分类数据报告”，分隔后提供“系统数据摘要、基面数据”；基面数据不再混入“光线迹点”。表面数据报告逐面列出类型、曲率、厚度、材料、半口径、圆锥系数、光阑和镀膜；系统数据报告按系统、孔径、视场、波长和近轴量组织；分类数据报告按表面角色、材料和几何类型汇总。旧名称“一阶量、一级像差/一阶量、处方报告”只作为项目和会话兼容别名保留，不再出现在 Ribbon。

## 图像分析

图像模拟支持内置目标或 BMP/PNG/JPG/JPEG 输入、几何/衍射/无卷积模式、过采样、保护带、翻转、旋转、RGB 或单波长、视场中心、参考光线、相对照度、探测器像素和输出尺寸。当前路径是标量实现；部分兼容设置保留但尚未选择独立计算分支时，界面必须明确说明。

分析请求在后台执行前按公开参数描述符严格验证，非法选项、非有限浮点和范围外数值不会绕过界面进入 Core。FFT、图像与直接 PSF 分配具有统一资源预算；外部位图先检查元数据再解码。紧凑矩阵只隐藏重复轴文字，类型化轴量和单位继续保留。具体上限见[可靠性与资源边界加固](RELIABILITY_HARDENING_2026-08-29.md)。

IMA/BIM 与普通位图查看器属于 App 文件工具，不是数值分析本体。

## 优化与公差

优化 Ribbon 提供快速聚焦、快速调整、滑块、评价函数编辑器/向导、阻尼最小二乘优化和贪心随机扰动搜索。随机扰动不是差分进化、双重退火或盆地跳跃；这些名称在真实算法完成前不出现在界面中。“玻璃替换模板”当前只是打开玻璃目录和默认评价工作流，不是自动 Glass Expert。

“帮助 > 操作数帮助”打开可停靠、可恢复的操作数参考页。左侧可按代码、中文名称、定义、计算说明和参数搜索，并可筛选“可计算”或“兼容保留”；右侧显示分类、支持状态、定义、当前 Workbench 实际计算路径、通用贡献公式和 Zemax 原始参数槽位。页面内容由优化服务发布的同一操作数目录生成，不复制编辑器之外的代码清单，标题与正文使用全局显示字号令牌。标记为“兼容保留”的条目只说明 ZMX 导入与无损保存边界，不提供伪计算公式，也不会显示为当前可计算。

公差工作流包括向导、可编辑操作数表、正态/均匀分布、RMS 点列或 RMS 波前准则、双侧灵敏度、可选像距补偿、确定性 Monte Carlo、P50/P90/P95 和良率统计。定义保存为 `*.startol.json`，结果可导出文本。服务入口与公开 Core API 统一限制最多 `10000` 次试验和 `500` 次补偿迭代；操作数表最多 `1000` 行，未知类型/分布在计算前失败。

## Dock 窗口行为

顺序模式启动、新建、打开工程和“重置为系统初始布局”均只打开“镜头数据”和“二维视图”两个文档页签，默认激活镜头数据，左侧系统选项保留。启动不会实例化旧会话中的分析、三维或其他页面；需要时从菜单手动打开。用户显式执行“载入默认”或载入布局槽位时，仍恢复该布局的完整页面集合。非序列模式沿用自己的对象工作区与会话恢复规则。实现与验证见 [默认双页工作区](TWO_PAGE_STARTUP_2026-09-27.md)。

主窗口最小尺寸为 `640 x 480`。优化向导在窄宽度下自动由双列改为纵向，公差相关向导降低固定最小尺寸并通过内部滚动区保持操作可达；显示设置窗口允许缩放，并在短窗口内滚动。分析图、波前表面、光学场景和图纸预览向自动化客户端发布数据摘要及复位动作。这属于当前已实现行为，不表示所有平台的端到端辅助技术走查已经完成。

- 标签可拖动分栏、合并、浮动和重新停靠；
- “保留分栏停靠”不会强制合并已有文档区；
- “合并单窗格”自动回收所有原生浮动页，把全部页面集中到主文档区并恢复标签模式；
- “全部独立浮动”为每个页面创建独立原生宿主；
- “平铺全部”和“层叠全部”自动回收所有原生浮动页，在中央文档区切换为内部 MDI 窗口；
- 平铺调用 MDI 平铺布局，层叠调用 MDI 层叠布局；二者都不会把页面移到软件外；

## 光学镀膜设计实验室

从“实验室 → 光学镀膜设计”启动独立窗口，或使用根目录 `Run-CoatingDesign.command` / `.cmd`。先选择三种示例之一，再按“输入指标和材料 → 生成膜系 → 优化 → 检查逐项指标 → 保存/导出”操作。材料支持名称搜索；膜层支持增删、上下移动、复制、厚度和固定/变量编辑。
