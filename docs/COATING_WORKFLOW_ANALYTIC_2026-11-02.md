# 镀膜工程操作与双面解析优化

本轮落实独立参考波长、堆栈公式、膜层剪贴板、异常退出恢复及双面优化强化。产品仍为C#内置模块，计算使用共享Core与原材料n/k；原单面、双面v1及正式验收保持。计划见[阶段表](COATING_WORKFLOW_ANALYTIC_PLAN_2026-11-02.md)，验证入口见[记录](../validation/rechecks/2026-11-02/coating-workflow-analytic/README.md)。

## 独立参考波长

编辑器“介质与基板设置”的参考波长λ₀与“设计目标”的中心波长分别保存。OT=n(λ₀)d，QW=4n(λ₀)d/λ₀，FW=n(λ₀)d/λ₀；参考波长变化只更新这些换算及堆栈标注，不缩放物理膜厚、不改变设计目标或已有物理光谱。换算使用实折射率与原材料有效域/显式端点延用规则，不包含斜入射余弦。

实验新增可选`ReferenceWavelengthNm`，旧文件缺项时以其设计中心初始化。原样打开/保存不增加字段；当用户改动设计中心而参考输入保持原值时，参考值会明确保存，之后不再跟随中心。参考值作为单位元数据不进入物理输入指纹，旧指纹保持；直接改λ₀可保留原结果，撤销/重做仍沿用原设计历史的结果失效规则。非法/域外λ₀不使用上次有效n继续换算。

## 堆栈公式

在可编辑的正面或独立背面点击“堆栈公式”，输入并“预览展开”，确认材料、层序及物理厚度后“应用到当前面”。应用替换该面全部膜层，为一步撤销；另一面、目标与介质不被公式隐式修改。预览后再修改输入会使应用按钮失效，须重新预览；对称背面不可直接写入。

| 输入 | 含义 |
|---|---|
| `(HL)^4 H` | H/L取当前高/低折射率材料，4组后加H |
| `0.5H L 2H` | 系数为λ₀处QW；默认系数1 |
| `0.5(HL)^2` | 整组乘0.5，重复2次 |
| `Hi Lo`及`Hi=材料ID;Lo=材料ID` | 显式自定义材料符号，材料名称必须唯一 |
| `{材料ID}` | 引用完整ID，避免相邻符号歧义 |
| `Inc | (HL)^4 | Sub` | 明确外侧→基板；命名边界必须与当前面匹配 |

支持正有限十进制/科学计数系数、分组和整数重复；不执行脚本，不猜测未知材料。上限为8192字符、64个自定义符号、16级嵌套、每次重复1–200、展开每面≤200层，物理厚度须在(0,100000]nm。展开超过当前设计层数上限会提示，正式优化仍按原制造/层数约束拒绝，不能以导入绕过。公式预览是结构/膜厚预览，光谱由应用后的正常计算给出。

## 膜层剪贴板

“复制到剪贴板”“剪切膜层”“粘贴膜层”支持不连续多选和跨面、跨实验。未选择行时复制当前面全部层；粘贴插在最后一个所选行之后，无选择则追加。剪切须先成功写入剪贴板，期间输入改变则只复制，不删除；粘贴失败不提交任何材料或膜层。每次剪切/粘贴为一步撤销。

Ctrl/Cmd+C、X、V在膜层表与其浮窗可用；单元格文本编辑时保留普通文本剪贴板。完整数据格式`OpticalSystemDesign.CoatingLayers.v1`保存源λ₀、完整材料快照、物理厚度双精度和变量开关；同时提供`MaterialId / Thickness_nm / Variable`制表符文本，供外部表格交换。文本回贴使用物理nm，仅接受已知材料ID或唯一名称，不按名称虚构n/k。

接收方保留自己的λ₀、目标与介质。同ID材料内容不同则用完整材料内容SHA-256派生新ID并重映射粘贴层，不覆盖接收方n/k；重复粘贴复用该身份。富数据≤4MiB、膜层≤200、材料快照完整并校验原有效域，接收实验合并后材料≤500。它是本软件交换格式，不声称兼容TFStudio文件或其私有剪贴板。

## 异常退出恢复

编辑停止1.5秒后，在设置目录的`coating-recovery/`中原子写入本窗口独立草稿。保存原始字段、错误文本、物理膜厚及OT/QW/FW未完成输入、两面层表、材料快照、选择与设计/优化模式；不保存计算结果或整个撤销栈。最多32MiB，失败保留上次完整草稿并显示错误；突然退出前最后1.5秒的尚未落盘输入可能丢失。

每份草稿用GUID会话名及独占文件锁。仍由其他窗口/进程持有的草稿不会被恢复或删除；不凭PID判断。新窗口发现可用草稿时提供恢复、删除这份、稍后处理，也可用顶部“恢复草稿”再次检查。恢复先校验版本、SHA-256及编辑字段，再载入编辑器，不覆盖原实验；新会话草稿写成功后才删除旧草稿。损坏/未知版本保留并提示。稍后处理或关闭恢复对话框均保留文件。

正常保存后清理自己的旧草稿；正常关闭经保存/放弃确认后清理本窗口草稿，取消或保存失败则保留。原子替换和锁文件与实验文件、停靠布局分离；释放锁后保留零字节`.lock`以避免跨进程删除竞争。没有承诺对断电、磁盘损坏或用户手动删除草稿作完整恢复。

## 双面解析与分阶段优化

schema2的`Duplex.Version=1`仍表示两面数据与评价合同。新增可选`Duplex.OptimizationVersion=2`表示`duplex-analytic-restoration-quality/2`；缺项保持`duplex-target-constraints/1`，旧文件不隐式切换。新启用双面默认选择v2，编辑器可显式切回v1。单面原协议1–4不变。

Core的`duplex-incoherent-thickness-adjoint/1`复用相同散射递推对正向正面、反向正面和背面求物理膜厚解析导数，组合非相干有限基板的内部反射及真实吸收，含无损极高反射时的对数分母。单面评价按其同一Core导数映射，独立两面分别映射，对称变量求两面贡献之和，固定层不创建优化变量。平均偏振的log(T)导数按真实s/p透射权重组合，不作透射下限。

v2共享通用目标约束构造：AR/HR的采样反射率，窄带真实峰值、实际采样FWHM/半高点、局部峰位导向及每个截止带最差OD。窄带网格必须含目标边缘锚点和通带细分；缺失半高点时保留形状引导。局部峰位估计只是优化方向，正式峰位仍按原采样定义。

输入主迭代额度N≤2时全用于目标恢复；其余以ceil(2N/3)给恢复阶段，剩余给质量阶段，不额外复制N。恢复使用超限残差；质量从已保留的最好点出发，保留相同约束并增加反射/透射质量方向。DLS实际调用解析Jacobian；Nelder-Mead、坐标搜索继续使用所选无导数算法，不把它们的调用计为解析。候选保留及最后原密集复验继续逐项保护起点超限、已通过门槛及采样收敛，必要时退回输入。固定另一面时可能物理上无法通过整片目标，状态仍为未通过。

`Run.Duplex.Analytic`分别记录灵敏度点、实际Jacobian、恢复/质量迭代、完整密集复验次数、最终保留网格点数`DenseSpectrumPoints`、包含各级扫描及极值细化的实际密集功率调用`DensePowerEvaluations`、被逐项保护拒绝的试探和主额度；`PowerEvaluations`保留普通指导功率点语义。灵敏度一次包含多次共享散射求解，不能和单次功率点混加成等价成本。AR/HR/窄带v1/v2比较使用同起点、同主迭代上限并公开实际调用量；v2细分网格不同，不称为同总计算量或普遍更快。该版本没有宣称移植单面协议4的全部自适应续算、非线性修正及预算追加日程。

## 验证范围

所有验证后台进行，包括共享Core独立数值差分、162组原双面物理输入、原参考/格式/验收回归、离屏窗口和内存剪贴板，以及测试自己启动的后台进程被终止后由新进程恢复。桌面用户的窗口、剪贴板与进程不参与测试。构建、通过数量、同预算实际结果及未通过规格以[本轮记录](../validation/rechecks/2026-11-02/coating-workflow-analytic/README.md)为准；历史批次不累计成当前通过率。
