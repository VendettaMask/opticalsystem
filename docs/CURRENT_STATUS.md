## 实现、兼容与未完成边界

- 正式计算为共享纯 .NET Core；独立实验室独立的是流程、进程和数据，不是另一套光学引擎。初始结构实验室 v19 不等于通用自动设计能力已验收。
- 已加入共享相干薄膜求解及独立镀膜实验室；不能据此宣称真实薄膜响应已经接入正式逐光线追迹。正式表面膜层、散射、偏振标量 PSF 等边界见各专业文档。
- 库存目录结果不是自动换片；没有合法本地模型时不能载入处方。公差向导兼容入口、未实现操作数/表面类型保持各自明确禁用或拒绝，蓝色外观不表示新增业务能力。
- 顺序按文件会话仍可保存作兼容数据，但自动打开不恢复其额外页面。显式自定义布局载入与非序列恢复不能混为同一条默认流程。
- 外部精度权威仍为提交的 `123456.ZMX / Zemax OpticStudio 2026 R1` 捕获文件及设置，仅限该范围。`validation/history` 是冻结辅助证据；不新增 Optiland 比较或改写历史数字。
