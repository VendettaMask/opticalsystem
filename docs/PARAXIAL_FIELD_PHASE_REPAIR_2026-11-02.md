# 近轴像高视场的入射相位修复，2026-11-02

本轮从95支菜单镜头的跨分析根因入手，快速重放变焦、扫描和双目镜的94项基础分析。扫描与双目镜的主要传播差异已由此前共享修复消除；当前最明确的遗漏是变焦镜头三配置、三波长的9项离轴OPD，而其点列、光扇和逐面控制保持通过。

## 根因与修复

无限远的近轴像高视场会由共享RayGenerator转换为主波长近轴焦面的入射斜率。WavefrontEngine的入射相位方向原来只处理角度与真实像高，近轴像高落入零倾角分支，漏掉瞳孔上的入射平面波相位。仅像面OPL正确不足以得到正确OPD；本例一条子午扇最大误差约967.935 waves。

现在该视场直接使用共享生成器的实际入射方向，包括主波长、所选共轭及介质条件。修改为共享Core中的11行通用分支，作用于同一定义的OPD、波前、衍射及参考球入口；有限物体仍保持原共同物点光程规则。没有镜头名、配置号、参考数组或拟合常数分支，没有修改处方、采样、容差或归一化。

三配置、三波长的9项旧离轴OPD全部从Difference变为Pass；最差NRMSE为`2.990418161382848E-05`。第一配置主波长示例的最大差由967.9347209降至0.00000456918 waves，NRMSE由2172.672565降至0.000003480414。变焦原12项OPD，包括原先通过的3项轴上控制，全部Pass。
