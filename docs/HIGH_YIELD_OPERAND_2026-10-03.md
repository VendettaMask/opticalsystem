## 定义与支持范围

官方[真实光线约束目录](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26102/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Constraints_on_Real_Ray_Data.html)确认 HYLD 的 Surf/Wave/归一化光线定义。[Ansys 高良率优化文章](https://optics.ansys.com/hc/en-us/articles/43071054749459-Designing-for-as-built-performance-with-High-Yield-Optimization)的公式为 `τ = |n−n′| (1−R·N)`，进入较高折射率介质时选入射方向，否则选出射方向。该量是降低角度敏感性的惩罚，不是成品率百分比，也不能替代公差 Monte Carlo。

[共享 Core 服务](../src/OptilandWorkbench.Core/Services/RayManufacturingMetrics.cs)读取同一次正式追迹的交点、入射/出射方向和界面局部折射率，并使用该交点的几何法线。普通透射面取锐角；法线朝所选方向，`1−cosθ` 通过单位向量差平方的一半计算，保留极小角度贡献。

| 模式 | 当前行为 |
| --- | --- |
| 均匀玻璃/目录色散 | 使用指定波长的真实界面折射率；n′>n 用入射角，其余用出射角 |
| GRIN 入口/出口 | 使用正式空间场在交点处的 n；出口入射方向来自连续曲线传播，不使用入口顶点 n 代替 |
| 整体位姿与反向传播 | 在一致坐标系中计算局部界面角度；不依赖全局 Z 顺序 |
| 曲面 | 使用真实交点处的法线，不使用顶点法线 |
| 目标面的反射、TIR、衍射、理想薄透镜或散射 | 明确未支持；不返回成功零值 |
| 无穷远物面、无交点、渐晕、缺失/非有限元数据 | 明确失败，评价贡献为无穷 |

GRIN 光线生成仍受正式 RayGenerator/近轴/瞄准现有能力限制；共享指标能计算已有非旋转 GRIN 追迹，不代表所有此类材料均已能通过归一化瞳孔生成光线。先前反射段可以保留正确介质状态，但反射界面本身的 HYLD 尚未开放。原生镜面符号、超半球法线、原生列和数值均缺少实机捕获，不能据公式测试声称 Zemax 全模式等价。

## 共享数据、编辑和文件

`RayTraceSampleValue` 和公开 `RayTraceSample` 增加可空 `RefractiveIndexBefore/After`；标量、批量和 GRIN 路径在有限交点处写入，公开/值类型互转及共享追迹缓存保留它们。`After` 指界面另一侧的材料，不是反射后仍保留的入射介质；真正未命中时两者为空，不能据一个旧位置臆造折射率。照度分析在像面交互前停止时只保留 Before，After 为空，保证改变像面后的材料不影响入射结果。孔径挡住的有限交点可以保留这两个数，但不能作为有效操作数结果。没有额外追迹缓存、材料查表替代或第二套光学引擎。

本地操作数为 Surf/Wave/Hx/Hy/Px/Py 六槽，原始槽位优先，Wave=0 取主波长。归一化视场须在 [-1,1]，瞳孔须在单位圆内。Application/桌面编辑与 STAROPT 往返保留原始参数、目标和权重；正式 DLS 已用于 GRIN 厚度优化。帮助仍为“功能大类 → 操作数族 → 具体操作数”，HYLD 留在“光线与坐标 → 光线条件与良率”，显示真实支持范围。

**ZMX 导入的 HYLD 保持禁用只读，旧兼容工程行也不自动升级**，直至原生列和数值捕获完成。本地新建行可以执行。没有增加工程 schema 版本：新增字段属于运行时追迹结果，不属于工程模型负载。
