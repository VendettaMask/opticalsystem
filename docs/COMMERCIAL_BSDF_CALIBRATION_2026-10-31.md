## 原生参考的取得与范围

从本机安装介质提取官方 Speos RPC 到工作区隔离目录，未运行附带的其他安装辅助程序，未改注册表或全局安装。原生 EXE 和主要数值 DLL 均核验有效 ANSYS 数字签名、版本及 SHA-256。RPC、Viewer 均为 **2026.1.0.37094**；相同版本的两个组件具有不同的数值 DLL 字节，保留各自完整身份，不能将其当成同一二进制。

RPC 仅监听动态本机回环端口，不启用弹窗；用官方 protobuf 语法经 C# HTTP/2 调用。Viewer COM 在独立、不切换显示的 Windows desktop 中启动，调用前核对服务器 PID，只清理本次创建的进程。已存在的查看器不连接或修改。没有前台窗口操作、原生桌面验收或产品外部引擎依赖。安装负载不随代码或测试分发。

该原生保存变体按当前读取器解释为“增强标志0、White标志1”，自动导入会拒绝；上述Core对照明确用了手工锥覆盖，不冒充该变体已自动兼容。还保留65536光线的无权重Interactive控制、早期交互上限/场景选择拒绝，未将它们等同于带权重辐射度验收。

观察到的方向差异涉及连续锥边界、投影量、峰高与运行时功率的解释；本程序仍使用有明确身份的节点分解和 SlopePowerTransport/1。White模型、该原生归档变体及输入节点之间的行为仍需修正/验证，没有将原生组件差异分类成已修复或已知厂商缺陷，也没有用单个控制拟合补偿常数。

## 新计算与兼容

新导入的 v11 使用 **MeasuredBsdfGrid/5**：出射表格及输入极角沿 θ 线性插值，材料方位沿原角度插值；积分与方向采样使用同一非负双线性密度。投影量以 `q sinθ dθ dφ` 积分，BSDF 量以 `f sinθ cosθ dθ dφ` 积分；以解析基函数质量、CDF 和有界反演采样，无拒绝抽样。小区间采用稳定求积，避免三角函数消差。

v11 二进制保留并应用归档中的正归一化标量；不再把它当成可以丢弃的采样缓存。文本按 θ 线性表格的参考角积分转换。存储的光谱与该标量只应用一次。v11 输入极角超出测量端点时取最近端点，与已采集原生系数行为一致；波长仍不外推。旧协议保持其原边界规则。

对每个已测输入/每瓣，令存储背景、峰积分为 D、P，谱因子为 S，White 基准为 Sb。新分配为固定峰 `P·Sb`，背景 `max(0,(D+P)·S−P·Sb)`；有背景时按其原形状分配。没有背景时只保留固定峰。**先在节点分配，再插值输入**，避免非线性截零被移到插值之后。背景固定于材料轴，峰仍按声明的斜率功率映射移动并包含雅可比。逐节点/光谱端点检查 R+T≤1，吸收为剩余；不叠加 Fresnel、第二次介质权重或第二次光子换算。

表格缺片、非法/非有限角、极点、方位接缝、法向入射旋转不一致、非被动数据及无效透射峰介质均拒绝；保留原预算、取消及不可变载荷。新协议写 STAROPT **v13**，容器2、顺序快照6不变；STARRDB、应用 DTO、相机快照和显示接受协议5。旧 1–4 协议、v12 XYZ 及原 Speos 冻结实验不升级，已增加旧 grid4 Speos 的精确 RAW/ISP 重放控制。

## XYZ 校准实施与实测失败

新增共享 Core `XyzRadiometricCalibrator`：每波长以非负最小二乘拟合三个归一化 XYZ 通道到辐射度 BSDF 的系数，用实际方向 SampleId 划分训练与独立验证。要求全波段相同样本/角色和完整网格，拒绝重复、负值及角色泄漏；不修补实测值。通过共享 JacobiSvd 判秩/条件数，报告独立留出 NRMSE、最大绝对/相对误差。策略由调用方显式给出，未引入“通用合格”默认值。

结果冻结来源种类、两个源 SHA-256、已核实的观察者/照明条件、验证策略、每波段统计和系数摘要。未通过、秩不足、条件未知或系数被改写均不能导出带拟合证据的正式校准。证据随原校准 JSON、BSDF 与相机冻结载荷保存；旧手工声明 JSON 仍兼容。拟合目前是 **Core/API 与诊断工具能力**，桌面继续使用已有校准 JSON 导入入口，没有新增拟合向导。它不把任意 XYZ 唯一恢复为光谱。

自行取得 Cornell 原始 **Mystic lacquer / Ford Mystic** 的配对 ASTM 光谱 BRDF 与 CIE XYZ：**1,439** 个相同方向、31 波段（400–700 nm、10 nm），959 方向训练、480 独立留出，44,609 观测。原件描述观察者/照明条件未明确，未自行填入 D65 或其他假设。保留原件与源字节摘要，只用于校准诊断，不作为产品材质或测试夹具分发。

在事先显式的内部探索策略 NRMSE≤0.01、最大绝对误差≤0.01 sr⁻¹、相对信号底1e−6下，**0/31** 波段通过；最差留出 NRMSE **0.6083908**、最大绝对误差 **0.1043304 sr⁻¹**，正式导出被拒绝。没有放宽策略、用训练残差替代验证或将该文件包装成已标定 Zemax 材料。这是一份材料/数据对在当前三非负通道模型下的失败，不是所有 XYZ 测量的普遍结论。真实 Zemax XYZ 逐值校准仍缺少通过等价测量条件与独立验证的案例。

又自行取得Cornell **Krylon Blue** 实测光谱，以校验过官方SHA-256的CIE 1931 2°数据，在明确的400–700 nm受限等能测试光源下，以1 nm线性光谱插值/梯形积分推导XYZ；这不是独立的XYZ实测，也未假定原文件使用D65。预先选择相机主绿 **550 nm**、仍用959/480方向及同一策略，留出NRMSE **0.1298540**、最大绝对差 **0.1909097 sr⁻¹**，秩3、条件数443.244，仍失败并拒绝正式导出。该结果表明，明确条件后当前三非负通道映射在这份数据上依然不足；未挑选通过波段或放宽策略。推导数据及CIE许可/身份保存在 `derived-xyz-candidates/`，未接入产品材质库或宣称Zemax材质全链路通过。
