# C# 材料诊断、窄带结构竞争与入射侧匹配

新建窄带已采用 `coupled-narrowband-competition/3`。材料诊断先说明当前数据是否满足参考无吸收原型的前提；随后以真实 n/k 比较镜段、腔阶和入射侧匹配，最后调用原独立密集验收。旧实验不会自动升级。原高反最低 R、窄带峰位/FWHM/峰值 T/截止 OD、膜厚/层数和采样收敛标准保持，**材料适用性提示不参与 Passed 判定**。

实现位于 `DesignService.NarrowBand.cs`、`MaterialSuitability.cs`，物理计算、复反射振幅、相位厚度、光谱测量及优化均复用共享 Core。没有引入另一套薄膜算法、外部运行时或清零真实材料 k。

## 操作与版本

新建“示例：窄带”或主动切换到窄带类型时默认勾选“镜段/腔阶竞争与入射侧匹配”。旧文件打开时按自己的协议恢复；勾选该项是显式采用新流程，取消可继续旧窄带流程。减反/高反仍采用已有协议 2。

- “1 生成膜系”：进行材料诊断、有限整数竞争、匹配和短程优化；只对最终选中的结构做密集验收。其余候选标记为未认证，采用后需复验。
- “2 优化”：继续调整当前可变膜厚，使用新窄带目标指导，并保留可追溯的起点原型元数据。
- “结构搜索”：对候选按用户完整起点预算逐个正式优化及密集复验，先选真正通过者，再按该协议的评价值比较。当前用户结构另做完整复验作为保留项。起点不足时沿用种子、厚度扰动与随机种子设置；固定层不被扰动。
- 只要当前存在固定层，就不再生成替代拓扑或增加匹配层；保留固定层的材料、厚度、位置，仅优化其余变量。

协议 3 仅用于窄带，旧空版本和协议 2 的算法路径保留。原显式 `PrototypeFamilyVersion=2` 试验继续属于协议 2；在界面采用协议 3 时清除该旧试验标记，不混写两个结构生成身份。

## 材料适用性诊断

`AssessMaterials` 返回所选 H/L 和实际膜层材料的来源、中心 n/k，以及 64 区间加中心锚点内的最大采样 k；不是全波段连续最大值证明。诊断点的无效 n/k 明确报错。对窄带标明 H/L 中心 k 是否满足固定参考向导的 `1e-5` 前提，但有吸收材料仍可通过真实数值流程设计，不由该阈值宣告无解。

有当前膜系时保存中心 R/T/A；高反结果另取**原密集复验光谱的最差 R 点**说明相应的 T 和有限膜吸收。尚未正式计算时的高反诊断点明确标为采样诊断。界面结果与 `material-suitability.json` 导出均可查看；打开实验时随物理结果重新计算，不能相信文件中人为修改的缓存诊断。

## 有界镜段与腔阶竞争

原型保存 `MirrorLayers`、`CavityOrders`、`SubstrateStartsHigh` 和候选族名。向量从基板侧计数，实际 `FilmLayer[]` 始终按入射侧→基板排列；原型描述的是连续优化之前的起点，不能把最终非四分之一波处方反写为该整数原型。

初始池同时保留均匀镜段与参考启发的耦合镜段，包含奇偶镜层、两种交替材料起始顺序、厚度界允许的腔阶。耦合阶来自实际材料中心折射率的整数提议，所有好坏仍由真实 Core 光谱决定，不依赖参考表格的拟合宽度常数。镜段各为 1–41 层，腔阶 1–400；同时必须满足用户总层数和每层物理厚度界。

最多比较 512 个有效初始结构，再对有潜力且不同的起点进行两轮逐段镜层/逐腔阶数 ±1 和联合移动，累计最多 1024 个不同离散结构评价。保留全部已评价种子，不因一次整数移动或后续匹配失败删除更好的原始结构；有输入处方时保留该原始起点。该预算不是枚举全部允许组合，也没有声称复现参考的所有重启/离散优化策略。

优化指导采用实际峰值位置、Core 测得的峰值半高宽和峰值 T，加中心及半高点的连续指导，以及各截止带的平均/最差违反量。没有把参考 T=89.13% 处的通带宽度当作本地 FWHM。不同协议的 merit 数值不直接比较。

## 入射侧匹配与连续精化

对最多 8 个有潜力的起点分别试一层 L、一层 H、L/H、H/L，原不加匹配的结构继续参与竞争。匹配使用用户实际入射介质、实际角度/偏振、真实色散及吸收；没有先改成无吸收或透明基板嵌入问题。

共享 Core 的 S/P 复反射振幅实部/虚部作为残差，使最小二乘目标对应中心 R；非偏振时两种偏振等权。匹配期间只调整新增层，原滤光结构保持。每个一层提议取三个相位起点，两层提议取九种独立组合；每个匹配层限于用户膜厚界与两倍四分之一波厚度的交集，每起点最多 `min(32, MaximumIterations)` 次用户所选 Core 优化器迭代。最后只在满足单层厚度界时合并相邻可变同材质层。

中心匹配好不代表整谱好。每个匹配结果再按真实通带与截止目标竞争，保留裸膜候选。最多 12 个不同候选各做 `min(4, MaximumIterations)` 次短程膜厚优化，再进入选中者或用户完整起点预算的精化/密集验收。最终全谱复验仍使用原算法和原阈值。

`Run.Evaluations` 累计本次匹配、短程与完整阶段的 Core 优化器评价数；`TemplateEvaluations` 单列离散结构和匹配结果的目标比较数。它们不是所有单波长求解次数：中心匹配一次评价远便宜于整谱评价。`NarrowBandCompetition` 保存离散上限、实际结构数、轮次、匹配前后能量/处方及实际优化记录；`Screening` 保存短程初末处方和来源原型。用户分别点击生成再优化时，两次命令各有自己的记录，不能只拿最后一次局部优化次数代表全部成本。

## 实际对照结果

以下四组新旧对照的目标、材料、层数/膜厚界与完整阶段最多 24 次迭代均相同，只有设计协议不同；新流程额外消耗结构筛选、匹配与短程预算，不能声称同总算力。低损耗控制使用明确标注的常折射率合成材料，不是把真实膜数据清零后冒称达标。

| 规格 | 原流程：T峰 / FWHM | 新生成＋优化：T峰 / FWHM | 新流程原验收 |
|---|---|---|---|
| 真实材料单腔 | 72.603178% / 27.228174 nm | 70.563563% / 15.591383 nm | 带宽通过；峰值与两侧截止仍失败 |
| 真实材料双腔 | 68.946148% / 20.297745 nm | 62.817031% / 15.995719 nm | 带宽和两侧截止通过；峰值仍失败 |
| 常折射率低损耗单腔控制 | 87.122497% / 14.982295 nm，原流程已通过 | 97.352516% / 14.993399 nm | 通过全部原指标 |
| 常折射率低损耗双腔控制 | 74.617834% / 16.256067 nm，失败 | 99.884979% / 14.998578 nm | 通过全部原指标 |

高反算法本轮保持协议 2，重新运行仍为最低 R 95.984479929%，未达 98%，诊断明确显示该最差点的吸收。真实单/双腔另完成 4 起点×24 次完整结构搜索，T峰约70.845954%/63.334901%，FWHM约15.813103/15.792581 nm；仍未通过原验收，双腔搜索终点另有一侧截止失败。不能只报告带宽改善而省略峰值下降和剩余截止问题，也不能用有限试验断言真实材料全局无解。

实际固定参考生成 10 个跨 1–5 腔、奇偶/非均匀镜段及不同腔阶的原型，逐层核对本地构造；另生成 6 组无吸收解析匹配控制。新输出膜系共 546 个 R/T/A 点与固定 tmmcore 实际 JavaScript 对照，最大绝对差约 `1.03e-14`。这是构造/匹配和数值对照，不是整个 TFStudio 优化器或任意规格成功率认证。完整处方、输入一致性、计算量、测试及保留失败见[本轮证据](../validation/rechecks/2026-10-30/coating-competition/README.md)。

本轮没有移植解析膜厚 Jacobian、任意腔数解析综合、针插入或沉积设备控制；底层物理与完整验收继续共用 Core。参考适用前提和此前未达标原因保留在[诊断阶段报告](COATING_FAILURE_ANALYSIS_2026-10-30.md)。
