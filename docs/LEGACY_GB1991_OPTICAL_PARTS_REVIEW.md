# 老国标光学零件图逐项核对

日期：2026-10-27。范围为《光学零件加工与检测岗位任务解析（第二版）》“正确识读与绘制光学图纸”中与光学零件图有关的说明、对照及示例，纸本第41–59页（PDF第49–67页）。完整查阅这部分不等于把全书加工岗位、全部配套检验标准或所有零件类型实现为自动功能。

产品保留单一“光学制图”入口和共用编辑器，内部选择ISO或老国标；本轮只修正老国标标注及必要输入校验，ISO模板和有效输入下的图纸布局保持。当前单片/胶合制图能力是共轴旋转对称透镜，棱镜和特殊形状没有被扩展为新的出图能力。

## 依据与版本

- [学校公开教材](https://www.zstp.edu.cn/__local/A/9D/24/BF8073E52E207CD6BDF69B01710_DEEC166A_124C5DB.pdf)：纸本第42、46–51页用于定义及新旧标注的区分；第52–59页为老国标说明、图1-16至图1-18、粗糙度、样板等级及零件图应有内容。加工工艺卡不纳入本次产品功能。
- [GB 13323—1991原扫描件](https://ncstatic.clewm.net/rsrc/2022/0928/18/a8e91b473f322a6f24ebec07b5068cc5.pdf)：教材二维码所链文件；核对第3章、4.2/4.3条、表2/表3及附录A图A2–A4。原文件与教材只本地查阅，不复制进验证归档。
- 原标准3.1引用机械制图和GB 131的粗糙度表示规则。另查阅[GB/T 131—1993原文摘录](https://www.bzxz.net/bzxz/32028.html)的基本符号、Ra单位及取样长度说明作交叉核对；本实现使用各旧版本共有的基本符号，不混入ISO抛光P等级或2006版完整表面结构符号。
- 教材表1-36与正文说明旧版面形、定心、疵病的引用分别为GB 2831—1981、GB 7242—1987、GB 1185—1989；材料质量默认按GB 903—1987解释。图纸可通过补充要求和材料依据明确合同版本，软件不跨版本重算等级。

## 验证与解释范围

对应回归包括A4/A3单片及胶合、修改半径允差不会改变老国标预览但会改变ISO标注、Ra/Rq及单位/范围独立、分面样板、机械外径与有效口径、真实物理孔径快照、非球面表达式与共享Core幂次一致、缺省及非法输入、原子输出保护和标准往返保持。ISO另用修改前后的实际PNG/PDF作不变性比较；默认Logo检查矢量输出。

测试可以证明这些输入、布局和输出行为，不能代替材料批次合格证、样板溯源、实物面形/粗糙度检验或所有引用标准的条款认证。未重新引入2009模板，未修改Core光学公式。运行记录、原文哈希和输出核验见[本轮证据](../validation/rechecks/2026-10-27/gb1991-semantics/README.md)。
