# Cornell 全入射角对数重建与绝对 XYZ 校准

2026-11-01。本阶段解决了显式新插值模型下五种 Cornell 材料在 550 nm 的全部八入射角功率积分超限，并让 Mystic、Cayman 的已知条件派生 XYZ 校准通过原开发留出门槛。**Blue Acrylic 仍未达到 1% NRMSE，整项校准目标尚未完成。** 新模型进入共享 C# Core、现有 NSC、统一探测器和 RAW/ISP；没有引入 Python 产品后端。[证据及复验入口](../validation/rechecks/2026-11-01/xyz-reconstruction/README.md)。

## 角表功率超限的处理

[上一阶段](XYZ_MEASURED_ANGULAR_2026-11-01.md)的线性 Grid/9 对稀疏、高动态范围角表存在峰宽扩张：部分积分达到 1.99、24.55 等。原结果、拒绝行为及其失败记录全部保留。MAT 的入射/出射方向 Z 与 `cos(theta)` 最大差分别约 4.48e−7、4.04e−7，符合角度舍入；没有把原极角误改成仰角，也没有缩放测量值来通过能量检查。

新可选模型 `MeasuredBsdfLogInterpolation` 声明 `Log1pBilinearCosine/1`：

`g=log(1+f/s)`；在出射 `mu=cos(theta)` 和周期方位上分段双线性插值 `g`，再取 `f=s*expm1(g)`。

本次统一固定 `s=1e−6 sr⁻¹`，对应原文本的数值分辨率，**这是插值尺度，不是测量不确定度**。每个原环的方位节点并集同样在变换域插值；保留所有原始测量节点和幅值，不拟合或抹掉尖峰。实测极角范围外仍为明确的零计算支持，不能据此认证真实材料在缺测区域散射为零。新方法改变节点之间的曲线，因此通过被动性不能证明未测中间方向已经获得真实测量认证。

方位积分使用稳定的解析指数表达式，余弦积分按 Gauss 8/16 自适应核对、限定细分深度/数量，未收敛拒绝。功率 CDF 使用补偿求和，方向采样反演同一密度的边缘与条件 CDF；不裁剪积分、不把 R+T 自动归一化到 1。入射和波长的原凸组合逻辑不变。独立 Python 原环积分及独立 C# 二维 Gauss 16→24 细化分别核对功率、方向矩和二维概率。[原始独立积分](../validation/rechecks/2026-11-01/xyz-reconstruction/diagnosis.json)、[C# 全表导入](../validation/rechecks/2026-11-01/xyz-reconstruction/final-log-import/summary.json)。

## 绝对 XYZ 的新正值模型

新增显式 `PositiveAbsoluteLocalRbf/1`，以归一化 BSDF 单位的绝对 XYZ 为输入，而非把它误当任意亮度的颜色。两个通用配置对剩余三种材料全部执行：

- 色度 `X/S,Y/S` 加 `log(S+1e−12)`，96 邻点、平滑 0.01。
- `log(X+1e−12),log(Y+1e−12),log(Z+1e−12)`，192 邻点、平滑 0.0001。

坐标尺度由训练集标准差决定；薄板径向基加实际独立的局部仿射列，以带缩放主元和残差检查的共享数值求解器求系数。响应为 `exp(interpolated log(f+1e−6))`，显式保留正值偏置；原始测量目标和验收误差没有加偏置。秩不足的局部仿射方向不伪造为满秩，溢出/病态求解拒绝；每次导入在角节点映射，不在每条追迹光线中拟合。最大邻点 256、训练节点 4096、训练值总数和文件大小均有原预算约束，并支持取消。

原 CIE1931 2°/D65、400–700 nm、范围外为零、白 Y=1，原 959 训练/480 验证划分、550 nm、NRMSE≤0.01、最大绝对误差≤0.01 sr⁻¹、相对信号底 1e−6 全部保持。正式配对和原测量 SHA 绑定，训练模型不存留出目标；校准证据还绑定模型、条件表、颜色域和非零强度上下界。黑色映射零，强度域或色度域外拒绝，不对绝对 XYZ 任意按源功率缩放。

独立尝试还包括不同核、响应变换、训练协方差白化、训练信号加权和旧正值模型对照；除上述两个明确配置外，其他新探索候选未纳入产品。Blue Acrylic 探索最佳候选仍约 1.72%，训练信号加权最佳仍约 2.10%，没有降低 1% 门槛或给失败模型可计算身份。全精度 MAT 用相同两个配置独立复核，Blue Acrylic 仍为约 2.733%/86.3%，排除仅靠六位文本舍入即可解决的解释。[严格有限 JSON 探索记录](../validation/rechecks/2026-11-01/xyz-reconstruction/exploration-finite.json)、[MAT 复核](../validation/rechecks/2026-11-01/xyz-reconstruction/rbf-full-precision.json)。这只是已尝试方法未达标，不证明所有未来模型不可能成功。原发布 XYZ 的观察者仍缺直接证据；此处是已声明条件下从实测光谱重新派生的 XYZ，不是新的独立 XYZ 仪器测量。

## 接入、版本与使用

对象编辑器的 Cornell 导入提供显式“Cornell 对数角插值（新模型）”和尺度字段，默认不启用。选择 550 nm、入射角留空可请求全部八个原入射角；Core/Application 选项为 `AstmLogInterpolationScalePerSteradian`。旧线性选项保持原拒绝行为；不能把一个按新插值通过的模型标为旧线性计算。

新对数角模型使用 **MeasuredBsdfGrid/10 / STAROPT v18**，新绝对 XYZ 校准使用 **MeasuredBsdfGrid/11 / STAROPT v19**。源、尺度、方法、校准模型和证据进入对应摘要、项目、STARRDB 和相机冻结。低版本夹带新模型拒绝，包括禁用对象；旧 Grid/1–9 不升级，容器 2 / 顺序快照 6 不变。Zemax XYZ 导入仍需要显式校准文件；新非线性转换先映射绝对 XYZ 角节点，再积分实际辐射度表，不能先把 XYZ 通道 TIS 当作输入映射。校准拟合通过 Core API/诊断器执行，本轮没有新增桌面拟合向导；桌面已有的校准 JSON 导入入口可以使用新模型。

## 完整链路和证据身份

实测链路共 43 组：五种 Cornell 材料全部八入射角在 550 nm 加三份 VIAVI 原法向 BTDF。每组 32,768 次独立方向采样及 8,192 条 NSC 光线，4×8 直方图共 1,376 个分箱，按原六西格玛加一个计数检查；方向矩、`f|cos|/pdf`、吸收/探测/逃逸/截断账本均独立核对。Cornell 场景都内嵌全部八入射角数据，没有为每组仅保留一条合成分布。

源功率统一 5e−12 W、10 ms、解析 QE 0.2/0.5/0.8、无噪声、增益 2 DN/e⁻，用于暗材料的非零 ADC 验证，不改任何测量值或校准目标；QE 不是实测传感器。43 组使用 3.2 mm 方形/32×32、100 µm 像元及相同物理几何；光电子按真实波段功率只换算一次。项目保存重开、删除临时导入源并清空场景后，冻结实验的光电子/RAW/ISP 均逐值重算。[43 组结果](../validation/rechecks/2026-11-01/xyz-reconstruction/final-angular-chain/summary.json)。

两个新批准校准另有反射/透射共 4 组均匀角形状控制，使用**原留出方向的未缩放 XYZ**，功率对独立 SciPy TPS 结果核对并验证 v19 保存及冻结重算。这是实测校准加合成角形状，不能冒称完整实测 XYZ 角分布或真实材料 BTDF 测量。[独立未缩放输入](../validation/rechecks/2026-11-01/xyz-reconstruction/final-rbf-witnesses.json)、[四组链路](../validation/rechecks/2026-11-01/xyz-reconstruction/final-calibrated-chain/summary.json)。

VIAVI 的 31,046 原角节点、原示范 ZMX 的 550/550/632 nm 声明及声明相同的背面沿用上一阶段：仅前面法向切片实测，不认证背面、谱宽或全部入射角。原材料来源为 [Cornell 官方数据页](https://bowers.cornell.edu/computer-graphics/data)和 [VIAVI 官方数据页](https://www.viavisolutions.com/en-us/osp/resources/bsdf-data)。

新增回归包括解析指数密度积分/方向矩、尖峰节点保留、采样端点、校准偏置与未见输入、留出目标隔离、域外/篡改拒绝、主元求解、BRDF/BTDF 光电子链路及版本降级。另由上一阶段冻结 Core/Application 生成纯解析 Grid/9 夹具，当前精确重算旧光电子/RAW/ISP；没有把第三方实测数据放入该 CI 夹具。

最终 **332/332** 定向测试通过，零失败/跳过，默认含两个内置模块的 Release 主程序及测试/诊断构建零警告错误。43 组实测链路最大能量差 2.21670e−13、账本闭合差 2.23821e−13，最大光电子差 3.63798e−12 e⁻；独立全表功率最大差 4.55191e−15，原节点最大缩放差 1.69273e−14。23 组旧 White 控制最大功率差仍为 1.45344 µW，范围不扩大。[机器汇总](../validation/rechecks/2026-11-01/xyz-reconstruction/final-verification-summary.json)。使用从默认构建复制的专属执行目录，9 个执行程序集和 164 份相关源/输入快照绑定；94 份编译文档校验与快照匹配。[身份核对](../validation/rechecks/2026-11-01/xyz-reconstruction/final-run-integrity.json)。旧五阶段 1,694 份冻结文件逐一复核。早期测试宿主、精确原入射角匹配和沙箱文件发布问题保留，不计为通过。后台/离屏执行，没有全仓、前台原生 GUI、新商业全范围认证、提交或发布。

开放项：Blue Acrylic 原 XYZ 门槛、新独立盲测、原发布观察者证据、更多波长/入射/材料轴、真实背面 BTDF 和节点之间角分布的外部验证。本阶段不能宣布用户要求全部完成。
