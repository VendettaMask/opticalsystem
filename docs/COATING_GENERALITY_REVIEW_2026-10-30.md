# 与固定参考相比的通用能力差距

用户本轮要求：不允许针对某个膜层作特殊修改，必须通用修正。该约束已记入仓库协作规则。本次是源码审查和改进顺序记录，没有修改产品算法、真实材料或验收，也没有新增或重跑测试。已实现的协议3与当时测试保持[原阶段身份](COATING_NARROWBAND_COMPETITION_2026-10-30.md)。

审查对象是当前 C# `DesignService.NarrowBand.cs`、`DesignService.cs`、共享 Core 优化器/光谱测量，以及固定 TFStudio `8b942b3f956728a23cea2b35023c8b5d8de17428` 源码。下列修正都是待实现方案，不能算作已完成能力。

## 主要判断

前一轮546点R/T/A一致说明给定处方的前向计算与固定参考接近，不说明搜索质量、优化效率或跨规格能力已经追平。当前生成、竞争和匹配逻辑没有按 SiO₂/Ta₂O₅ 名称、550 nm 或指定膜层编号触发专用优化分支；但仍有固定经验尺度、浅搜索和候选过早丢弃等不足。不能把真实材料尚未达标全部归因于吸收，也不应靠添加一个样例模板解决一个失败案例。

## P0：先修目标一致性和候选保留

**固定加权折中仍会牺牲其他验收指标。** `CompetitiveNarrowBandObjective` 用0.05/0.1等绝对透射尺度，以及0.02的半高点尺度下限。它们是全局启发式参数，并非按某层写的补丁，但没有充分由用户目标/容差及统一约束策略推导。当前真实材料结果里，带宽收窄同时峰值下降，说明仍需认真检查目标之间的权衡；该现象本身不能证明某一个权重是唯一原因。

通用方向：用明确的目标/容差尺度组织约束违反量，采用可行性优先和自适应约束处理，并保留峰值、带宽、截止之间不同取舍的非支配候选。没有用户容差的目标必须有明确的尺度定义，不能从某个失败示例倒推数字。正式通过仍由原逐项检查与密集收敛决定，不靠更换标量分数宣称达标。

**匹配阶段过早按中心最低R选唯一解。** 当前每个L/H层序提议在多个相位起点中只保留 `r < bestR` 的结果，然后才做整谱比较。不同匹配根即使中心R接近，其透过、吸收、通带形状和总厚度也可能不同；被丢弃的根不能在后续竞争中恢复。固定参考 `adjustToIncidentMedium.js::pickCoat` 对已匹配根优先选较薄者；其向导另有低损耗材料前提。本地允许真实吸收材料，因此仅以中心R选根尤其需要谨慎。

通用方向：按实际设计目标保留多个根，比较已有T/R约束、整段通带、截止及总厚度，在统一竞争阶段再淘汰。A用于解释损失，除非用户显式声明吸收目标，不偷偷增加新的硬验收门槛。按物理界面角色处理匹配，而不是给第几层指定经验厚度。

另一个通用边界问题：当前先按“原层数＋新增层数”裁剪，再合并相邻同材质层，可能漏掉合并后仍在总层数界内的有效结构。应统一做候选规范化、变量/固定层映射和约束检查，避免临时表示决定候选是否存在；不能为某个具体层数单独开例外。

## P1：加强连续优化与谱域指导

**解析导数和物理步幅尚未接通。** 固定参考 `lsqEngine.js` 对支持的操作数使用膜厚解析Jacobian、缓存线性化和半波步幅，`newton.js` 有真实Hessian与回退。当前膜厚精化调用共享Core的通用差分DLS，并固定 `stepHint: 0.01` nm。共享DLS已有阻尼/缩放和稳定线性求解，不能把它描述成没有这些能力；缺口在薄膜导数接口、光学尺度和相应复用。

通用方向：在共享Core中增加稳定薄膜响应的可验证膜厚导数，再通过可选导数接口接入通用优化器。所有变量按实际相位/光学厚度尺度处理，保留原通用回退与协议身份；不在模块中复制另一套薄膜引擎或优化器。先用独立数值导数/解析控制验证，再验证真实材料、角度、偏振和强吸收支持域。

**把粗网格峰位/FWHM直接放进差分目标存在非光滑问题。** `ThinFilmSpectrum.Measure` 选择最高采样点，再找相邻半高交点；峰索引切换会使峰位目标跳变，同一网格单元内又可能没有峰位导数信号。当前优化网格和正式密集网格还可能给出不同排序。

通用方向：优化阶段使用与目标对应的可微光谱约束、连续边缘定位或经过误差控制的代理；自适应加密真正影响峰、边缘、截止的波长。实测FWHM和原密集采样继续用于原标准验收，不把参考指定透射水平的通带宽度当作本地FWHM。

## P1：搜索覆盖与预算仍需自适应

当前初始池按腔阶、镜段数的固定顺序枚举，到512个有效结构截断；随后只做两轮±1及部分联合移动。预算触顶时有枚举顺序偏好，并不代表均匀覆盖设计空间。固定参考 `globalSearch.js` / `localDescent.js` 有±1/±2、镜段与腔阶的组合/联合移动、多次重启和迭代停滞判断；当前尚未实现同等逃离局部结构的机制。

通用方向：保留安全预算，在其内部按收益、停滞、结构距离和光谱差异分配竞争额度；用分层采样/重启降低枚举顺序偏差。候选多样性目前仅依赖层数和 `Family` 字符串分组，应改用稳定的结构身份和物理差异，显示族名退出算法决策。改进目标不是把512和两轮改成另两个拍脑袋数字。

当前评价计数也混有成本不同的中心匹配和整谱评价。应补充真实波长求解量、导数/回退工作和阶段时间，以可比预算评估算法；不能只比较完整局部迭代数。

## P2：比当前原型族更一般的综合

当前从零生成主要是两种选定材料的交替镜段/腔结构及一两层匹配。固定参考另有 `structuralOptimizer.js` 的通用增/删/分裂/合并及退火接受机制，针插入/渐进演化也属于其更广范围。当前不能称作任意膜系综合。

后续可用实际灵敏度指导结构变化，并与局部精化竞争；对所有可变膜层采用同一规则，仍尊重固定层与制造限制。该项是后续能力扩展，不能用来掩盖前述目标、匹配和优化基础问题。

## 通用修正的验证要求

- 跨中心波长、相对带宽、折射率对比、吸收、腔数、入射角和S/P/非偏振建立预先固定的测试集合，保留不参与参数选择的规格。
- 固定材料和原验收，用相同总预算统计成功率、最差约束违反量、求解量与时间，保留失败和取消；546点物理一致、75项当时用例通过不替代该设计质量矩阵。
- 相同光学材料仅改名称/ID时，算法行为不应改变；对无色散解析控制，同时缩放波长、膜厚、范围和容差，验证相应尺度一致性。真实色散材料不能冒称具有严格缩放不变性。
- 改模板显示名或不相关元数据不应改变物理排名；所有候选在冻结的同一输入下由共享Core重评。
- 不以降低峰值要求、放宽FWHM/OD、清零真实k、替换失败材料或针对第N层写特例取得“通过”。基于用户声明的固定层、材料/界面角色、实际光学量和灵敏度的通用分支允许。

实施顺序：**目标/匹配一致性与根保留 → 共享Core导数及谱域指导 → 自适应结构竞争 → 更广结构综合**。跨规格验证从第一项开始同步进行，不留到最后补几个示例。
