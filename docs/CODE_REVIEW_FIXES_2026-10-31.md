# 2026-10-31 三项审查问题修复

修复[同日审查](CODE_REVIEW_2026-10-31.md)发现的快速聚焦、相机输入校验和三语遗漏。未扩展审查中另列的未完成功能。

## 快速聚焦

像方间隔保持原有符号，直接应用共享 Core 给出的焦移，拒绝非有限结果；不再把反射系统的合法负距离强制改成 `+0.001 mm`。完成表面求解及自动口径刷新后，以实际处方和零额外焦移调用共享 Core 重算 RMS，再生成返回值。最终厚度、实际应用焦移和 RMS 对应同一处方；取消或重算失败沿用事务边界，不提交半成品。

新增合成凹面镜负间隔、不同离焦方向和理想薄透镜正间隔回归，检查保存后处方的独立重算及有实际修改时的撤销。原输入、标准计算定义、射线采样和物理模型保持。

## 相机输入校验

运行和保存参数时，按 NumericUpDown 自己的数字格式与解析规则检查当前文本、范围及 Value 一致性；ADC 位深、黑电平、种子和采样数量必须为整数。保留已导入高精度数值的正常格式化显示，不把格式化舍入误判为用户输入错误。

非法编辑立即取消旧计算、清除 B 和旧采样报告，保留固定 A；运行和完整实验保存保持不可用，直接调用运行也不能绕过校验。失焦不会把非法文本悄悄改回旧值，修正后才恢复运行。局部采样区域独立校验，不把它当作 B 的物理参数；二维模式不读取未启用的三维字段。检查数值后才执行需要读取数值的三维就绪检查，避免错误输入从 UI 事件中抛出异常。

新增非法/空/越界文本、整数参数、失焦、修正恢复、德语逗号小数、高精度 QE，以及三维错误保护带与返回二维模式的离屏回归。

## 三语覆盖

补齐完整实验保存/打开、A/B 复算、快照输入选择、标定入口和说明、禁用原因、完成/取消/失败状态的中英日文案。受控失败前缀可以随语言切换，保留异常细节、来源名称及数字。新增实际控件和提示的中→英→日→中往返回归，不仅检查字典里是否存在键。

默认构建、测试数量、同一合成输入修复前后结果及全部阶段账目见[本批验证](../validation/rechecks/2026-10-31/review-fixes/README.md)。本次只使用后台计算和离屏界面，未操作用户桌面或发布。
