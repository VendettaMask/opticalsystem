# 非序列光源

## 已实现类型

| 光源 | 空间分布 | 角分布 |
| --- | --- | --- |
| 单射线 | 用户给定局部XYZ | 用户给定局部LMN |
| 点光源 | 局部原点 | 圆锥内均匀立体角 |
| 矩形光源 | 矩形面内均匀面积，可设置最小X/Y半宽形成中心遮挡 | 新建默认 `VirtualPoint`；支持 `Cosine`、方向余弦 `Gaussian`、旧文件兼容均匀圆锥 |
| Gaussian光源 | X/Y独立Gaussian位置 | X/Y独立Gaussian斜率 |
| 椭圆面光源 | 椭圆面内均匀面积，可设置最小X/Y半宽形成椭圆环 | 新建默认 `VirtualPoint`；支持 `Cosine`、方向余弦 `Gaussian`、旧文件兼容均匀圆锥 |
| 双角度面光源 | 矩形或椭圆面内均匀面积 | 局部切线空间中的椭圆分布，X/Y半角独立 |
| 径向分布光源 | 局部原点 | 对“角度—相对强度”表线性插值后按立体角采样 |
| 矩形体光源 | 长方体内均匀体积 | 新建默认全空间均匀球面；旧文件兼容前向均匀圆锥 |
| 椭球体光源 | 椭球体内均匀体积 | 新建默认全空间均匀球面；旧文件兼容前向均匀圆锥 |
| 圆柱体光源 | 椭圆截面圆柱体内均匀体积 | 新建默认全空间均匀球面；旧文件兼容前向均匀圆锥 |

每种光源保存独立总功率、系统波长编号、布局射线数和分析射线数。单条射线功率等于源总功率除以本次实际生成数量；临时覆盖射线数不会改变总功率。所有局部起点和方向最后通过对象参考链与 `Z * Y * X` 坐标规则转换到全局坐标。

## Zemax风格面源与体源

矩形光源和椭圆面光源的3D外形只表示真实发光口径；椭圆源显示为椭圆面是正确几何，不代表光线只是一块椭圆。发射方向由 `Zemax 方向分布` 参数决定：

- `VirtualPoint`：`Source Distance=0` 时，`Source X/Y` 表示局部方向余弦，默认值为平行 +Z；距离非零时，每个面内采样点从虚拟点 `(Source X, Source Y, -Source Distance)` 指向采样点。
- `Cosine`：按 `cos(theta)^N` 采样局部 +Z 半球，`Cosine 指数` 为 `N`。
- `Gaussian`：按 X/Y 方向余弦的独立 Gaussian 系数采样局部 +Z 半球。
- `LegacyUniformCone`：保留旧STAROPT文件和教学样例使用的均匀圆锥分布，半角由“兼容圆锥半角”给定。

三类体光源的新建默认方向为全空间均匀球面，符合常见 Source Volume 对象的随机方向语义；`LegacyForwardCone` 只用于旧工程和需要前向投影的教学样例。

## 径向分布表

对象编辑器使用：

```text
0:1; 10:0.9; 30:0.25; 60:0
```

冒号前是相对局部+Z轴的角度（度），冒号后是非负相对辐射强度。规则为：

- 2到4096个样本；
- 第一项必须为0°；
- 角度严格递增且不超过180°；
- 强度有限、非负且不能全部为零。

追迹器对曲线线性插值，将强度乘以球面面积因子后建立2048格CDF。CDF每个光源、每次追迹只建立一次，随后用二分查找采样；固定种子时结果逐条重复。

## 编辑、保存与显示

- 添加对象后，属性区只显示该源的类型化字段；非法尺寸、角度、射线数、波长或径向表不会部分提交。
- 对象类型切换从Core唯一默认值来源创建新参数，网格对象仍只能通过STL导入。
- 3D布局显示面源发光面和体源外形；点、径向和单射线源显示小型源标记。
- STAROPT容器保持v2，工程负载为v4；加载器继续读取负载v1–v3。
- STARRDB继续保存实际生成的射线路径和逃逸分支最终状态，不依赖光源参数类型重建结果。

## 教学工程与效果基线

[`samples/non-sequential`](../samples/non-sequential/README.md)中的07—12号工程分别演示椭圆面、双角度、径向分布、长方体体、椭球体和椭圆柱体光源。每个工程串联一个非吸收近场探测器和一个吸收远场探测器，使用固定随机种子和10,000条分析光线，并附带3D布局、近场热图、远场热图以及功率、质心和RMS基准。生成器和自动测试会重新追迹这些工程，避免效果图与实际追迹实现脱节。

## 与 Zemax 的边界

这些光源参考 OpticStudio 非序列模式中点、面、双角度、径向和体源的公开工作方式。矩形/椭圆面源的 VirtualPoint、Cosine、Gaussian 方向分布和体源全空间随机方向已经按公开语义实现；其余参数名、采样细节及文件格式仍是STAROPT独立实现，不声明逐参数数值兼容。

下一批光源为 IESNA、EULUMDAT、自有测量射线文件、二极管阵列、管状/灯丝和对象型光源。文件型源需要先建立带哈希、大小限制和原子保存的STAROPT内嵌源资产；不会依赖用户机器上的原始绝对路径。
