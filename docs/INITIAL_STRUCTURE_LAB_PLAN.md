# 初始结构内置模块：范围与后续计划

更新：2026-10-24。本页取代旧的“独立软件开发计划”；旧版本中的独立解决方案、外部启动器、默认不打包和可选产品入口均已撤销。历史原文可从 Git 查询，不再作为开发约束。

## 当前实现

2026-10-24 起，新桌面实验采用 `AutoLensManagedV1` 入口下的显式 `UpstreamE58` 策略，名称后缀 `autolens-upstream-e58-v2`、优化状态 schema 2。基准为已下载并完整跑通的原版默认 MOBILE_CONFIG；逐项改动、源代码身份、规则夹具和保留差异见 [原版对齐报告](AUTOLENS_UPSTREAM_ALIGNMENT_2026-10-24.md)。不比较最终效果，也不把工程测试通过数当作设计成功率。

内置窗口仍在主程序进程内运行，采用 Contracts、Engine、Persistence 与共享 Core 的边界。新建默认预设为 5 mm、F/1.8、90° 全视场、六片、独立前置光阑、20000 mm 物距、r⁴–r¹⁸、种子 42；另保留原 README 五项明确标注的本地适配。产品没有 Python 或外部优化器依赖。

新流程不经过原生 bootstrap、二元形式、QUICK 或邻域变异。采用三条原版启动随机流、弱曲率/厚度/玻璃初始化、绝对轴向坐标、固定输入光线求导、绿色 detach 参考/权重、原版线性正则、直接 Adam、余弦重启课程和 warmup 精修。默认 2001 + 3001 次更新，预算不足保存完整计划、坐标、矩及光线缓存，不压缩课程。材料默认按原 61 项 CDGM 常用表投影并使用固定源色散；显式允许材料子集仍构成本地约束。阶段交接规则位于实验室，首面归零后由舍入面间距累计重建所有面和像面；相同的几何参数读取共用 Core。Core 执行周期修形和真实传感器边缘视场选择。

不以实测下降筛选 Adam，不接原生 target polish，也不以更优 incumbent 替换训练终点。只有完成终点进入原有独立密采样物理验收；光焦度、焦距、F 数、光斑、制造与通光硬门槛和训练目标分开。旧存储中的严格平板祖先仅作谱系证明，实际随机起点单独留存。

新参考路径的 GPU 仍执行共享 Core 正式传播、法线、折射及六输出双精度反传。有限物距方向瞄准必须保持物方点不动，因此由 Core CPU 执行并单独计为 CpuAimingRays；不能借用无限远的 CUDA 起点平移瞄准。记录实际设备、批次、传播、回退和旧延拓恢复。训练随机流未逐位模拟 PyTorch CUDA Philox，正式 Core 精度/容差和 PyTorch float32 也不同；未复现另一套 CAMERA_CONFIG 的内部光阑及混合拓扑。

旧 v1、原生和混合记录保留身份、源码与冻结证据，可查看和导出，不能从当前桌面恢复或细化。新参考状态可在同训练规格、种子、允许玻璃及根身份下恢复，资源上限变化不重排计划。保存仍在批次边界：恢复工作先预约配额；未知的在途工作保持计费，尚未派发的取消则撤销已知零工作预约。可选胶合继续保留绑定的同位置零光焦度参考行，其处方和硬验收均明确记录。操作见 [模块 README](../labs/InitialStructure/README.md)。
## 不变的计算与数据边界

- 相同的光线追迹、近轴量、色散、正式点列、波前、MTF 和二维布局共用 Core。AutoLens 特有的绿色参考、detach、epsilon RMS 损失汇总及 JSON 交接约定留在实验室，不替换普通 Core 分析定义。
- App 通过 Application/Modules 的规范 DTO 消费结果，不直接引用 Core；内部引擎复用共享计算。源工程状态不交给搜索过程原地修改。
- 每个候选保留规格、不可变快照、随机种子、算法版本、父来源及预算；计算、展示、最终验收与导出必须使用同一快照和设置。
- 平板祖先的折射面曲率必须精确为零，作用仅为兼容谱系证明；新策略的实际随机起点另存，所有材料、厚度、空气隙和光阑仍为实际模型。
- 模块自己的运行记录和编辑状态与当前镜头分离，但不是独立产品。只有用户明确导出/打开后才把候选作为普通工程载入。
- 取消、关闭、保存失败与过期回调不得破坏用户工程；主程序关闭必须协调模块运行和未保存状态。

## 支持范围与结果表达

主要研究无限远、固定焦距、中心旋转对称折射成像的初始结构；默认路径生成球面，原生 AutoLens 可生成偶次非球面和显式胶合组。多片数、材料和光阑家族搜索不等于任意规格都可达标。预算结束仍未满足目标时，展示有效候选和具体差距，不宣称“物理无解”或全局最优。

完整目标验收、通光、像质和资源预算分别记录。一次搜索成功、固定候选回归通过、控制对照和独立多种子成功率是不同证据；中断的原协议不能冒充完成，自动变径改变的问题不能与固定口径成功率直接合并。

## 已知问题和优先级

1. 保持案例 9 完整目标和 `trial-0078` 原回归阈值，并验证微小起点扰动下的有界求解行为；继续改善尚未满足完整像质/焦距规格的宽角候选，不把定向回归通过称为完整设计达标或跨平台认证。
2. 固定算法、规格、种子与预算，完成可复现的困难规格和留出协议；v19 曾恢复失追迹起点，但宽角像质差距并未因此关闭。
3. 完成统一主程序中的人工桌面与目标平台验收。集成后界面/契约定向通过不替代完整搜索与实机验收。
4. 检索、排序模型、条件生成和设计智能体仍是研究方向，尚未实现；先有可信数据与真实光学验证，再决定是否建设。SQLite 索引、CMA-ES、Pareto 聚类也不作为既有能力宣称。

有限共轭、无焦、变焦、反射、折叠和偏心倾斜系统不在该生成器支持范围；不能因主工作台能处理而宣称生成器已经支持。非球面与胶合当前支持上述受限形式，尚无外部原生等效认证。
