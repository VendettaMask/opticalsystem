# 初始结构内置模块：范围与后续计划

更新：2026-10-22。本页取代旧的“独立软件开发计划”；旧版本中的独立解决方案、外部启动器、默认不打包和可选产品入口均已撤销。历史原文可从 Git 查询，不再作为开发约束。

## 当前实现

桌面设置已整理为系统、目标、搜索三页卡片；高级约束与 AutoLens 参数按功能折叠，候选、预览和操作层级重新划分。中英日、主题与窄窗口使用同一组输入控件和搜索调用，不改变算法或验收标准。操作说明及本轮界面验证见[界面整理记录](INITIAL_STRUCTURE_UI_2026-10-22.md)。

2026-10-22 新增五个 AutoLens 官方目标的原生预设，按固定上游提交区分明确指标和本地补充参数；载入不自动执行。配套固定 CPU 协议覆盖四个单种子目标及一个 20 种子系列，独立物理复核与 STAROPT 重载复核不与流程测试通过数混淆。详见 [预设与验收边界](AUTOLENS_OFFICIAL_EXAMPLES.md)；它不改变本页已有的上游非等价声明。

模块通过主程序“实验室 → AI 初始结构”打开，在主程序进程和 UI 程序集中运行。标准构建、安装、升级、修复和卸载必须包含它，不允许单独交付。现有 `labs/InitialStructure` 只保存 Contracts、Engine、Persistence、测试和基准；界面在 `src/OpticalSystemDesign.App/Laboratories/InitialStructure`，显示适配在 `src/OpticalSystemDesign.Modules`。

当前工作流是输入规格、真实材料预检查、从精确零曲率平板根生成、候选比较、停止/恢复、追加细化及 STAROPT 导出。搜索入口为 `FlatStartSearchService`；v21 保持原投影搜索，仅在首个非驻点模型无法产生可用步时，用实际固定偏移的耦合残差和剩余信赖半径尝试后备步，仍消耗原预算，不重启或追加评价。这是算法版本，不是独立软件版本。v20 等受支持旧记录可读取、导出和另建细化，不允许静默续跑为 v21。操作与数据目录见 [模块 README](../labs/InitialStructure/README.md)，当前工程验收见 [当前状态](CURRENT_STATUS.md)。

局部优化保留默认信赖域和旧 AutoLens 启发式试验，另新增 `autolens-managed-v1` 原生 C# 自动求导路径。共享 Core 沿正式交点/折射路径传播导数，并隐式求导实体光阑瞄准；实验室只组装目标与调度 Adam。流程包含余弦口径课程、全部光谱和双向视场、固定种子的面积分层瞳重采样、连续 n/V 材料优化、允许目录玻璃投影、固定真实玻璃精修及独立完整目标验收。偶次非球面支持 r⁴ 至 r¹⁰，r² 系数保持零；可显式指定相邻片胶合，绑定公共面型和介质，普通空气隙下限不变。

胶合按现有固定行处方表示：玻璃/玻璃界面后保留一个共位置、同面型、同出射介质的零光焦度参考行。它不是一层隐形空气，也不能独立优化；编辑破坏绑定后完整目标验收会拒绝。优化记录保存参数、Adam 动量、阶段、实际工作及已用时间；`ResumeAutoLens` 只接受同规格、同允许玻璃和同平板根，逐项核对坐标与快照。搜索文件仍以既有批次边界原子保存，不承诺进程崩溃后恢复未保存的步内状态。

每个接受的 Adam 步骤都需在同一口径/瞳样本上实测下降；非下降动量只重置偏差校正年龄，不重置课程进度或计费。真实光线包络的镜片体口径投影发生在求导阶段之外，阶段内体口径固定，最终重新定径验收。默认另预留一部分预算交给既有原生完整目标求解器，固定真实玻璃和非球面系数、联合细化曲率/厚度；该阶段使用原有数值雅可比，单独记录，不冒充自动求导步骤。高级设置可把“完整目标原生精修评价上限”设为 0。全过程保留经过独立完整目标验证的更优候选，训练末态不能覆盖更好原候选。

这是融入本产品的 CPU 流程重构，不是 Python 包装，也不是逐位复刻上游：归一化、目标权重、初始化、采样、物理域处理和原生目标精修遵循产品约束。未实现 CUDA/GPU 训练，未载入预训练网络，未完成原版数值等效或任意规格成功率认证；不能仅凭流程/测试通过宣称所有设计达标。原 [启发式试验评估](INITIAL_STRUCTURE_AUTOLENS_CSHARP_2026-10-19.md)保留旧范围，后续实现与验证见[原生重构账目](validation/AUTOLENS_MANAGED_2026-10-19.json)。

## 不变的计算与数据边界

- 所有光线追迹、近轴量、色散、点列、波前、MTF 和二维布局调用唯一共享 Core；模块不复制光学公式或用近似回退冒充真实结果。
- App 通过 Application/Modules 的规范 DTO 消费结果，不直接引用 Core；内部引擎复用共享计算。源工程状态不交给搜索过程原地修改。
- 每个候选保留规格、不可变快照、随机种子、算法版本、父来源及预算；计算、展示、最终验收与导出必须使用同一快照和设置。
- “从平板开始”要求谱系根的折射面曲率精确为零，不以预制镜头起跑；材料、厚度、空气间隔和光阑是实际物理模型。
- 模块自己的运行记录和编辑状态与当前镜头分离，但不是独立产品。只有用户明确导出/打开后才把候选作为普通工程载入。
- 取消、关闭、保存失败与过期回调不得破坏用户工程；主程序关闭必须协调模块运行和未保存状态。

## 支持范围与结果表达

主要研究无限远、固定焦距、中心旋转对称折射成像的初始结构；默认路径生成球面，原生 AutoLens 可生成偶次非球面和显式胶合组。多片数、材料和光阑家族搜索不等于任意规格都可达标。预算结束仍未满足目标时，展示有效候选和具体差距，不宣称“物理无解”或全局最优。

完整目标验收、通光、像质和资源预算分别记录。一次搜索成功、固定候选回归通过、控制对照和独立多种子成功率是不同证据；中断的原协议不能冒充完成，自动变径改变的问题不能与固定口径成功率直接合并。

## 已知问题和优先级

1. 保持案例 9 完整目标和 `trial-0078` 原回归阈值，并验证微小起点扰动下的有界求解行为；继续改善尚未满足完整像质/焦距规格的宽角候选，不把定向回归通过称为完整设计达标或跨平台认证。
2. 固定算法、规格、种子与预算，完成可复现的困难规格和留出协议；v19 曾恢复失追迹起点，但宽角像质差距并未因此关闭。
3. 完成统一主程序中的人工桌面与目标平台验收。集成后界面/契约定向通过不替代完整搜索与实机验收。
4. 检索、排序模型、条件生成和设计智能体仍是研究方向，尚未实现；先有可信数据与真实光学验证，再决定是否建设。SQLite 索引、CMA-ES、Pareto 聚类也不作为既有能力宣称。

有限共轭、无焦、变焦、反射、折叠和偏心倾斜系统不在该生成器支持范围；不能因主工作台能处理而宣称生成器已经支持。非球面与胶合当前支持上述受限形式，尚无外部原生等效认证。
