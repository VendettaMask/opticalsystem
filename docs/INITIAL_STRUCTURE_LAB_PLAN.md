# 初始结构内置模块：范围与后续计划

核对：2026-11-02。本页描述当前产品边界；具体操作见[模块指南](../labs/InitialStructure/README.md)，阶段工作见[搜索实施计划](INITIAL_STRUCTURE_SEARCH_IMPLEMENTATION_PLAN_2026-10-30.md)。早期平板生成和上游对齐报告保留原身份，不能作为现在尚未实现的功能清单。

## 当前入口与能力

初始结构是主程序同进程、必装的内置模块。App 的交互通过 Application / Modules DTO 调用内部 Contracts、Engine、Persistence 和共享 Core，没有独立优化进程或 Python 光学依赖。

| 入口或阶段 | 已实现范围 | 仍保留的边界 |
| --- | --- | --- |
| 托管 AutoLens | `AutoLensManagedV1`、`UpstreamE58`，规格/随机状态、训练、独立验收、保存续跑、受支持的 CUDA/CPU 设备 | 不重启用户已停止的长训练；上游逐位或最终输出复现不是本产品后续目标 |
| 自主拓扑设计 | 起点生成/导入、实际结构变更、近轴恢复、受约束补偿、原规格独立验收、预算与谱系 | 结构变化和局部下降不等于满足完整像质/制造要求 |
| M0/M1、M2 | 失光诊断、快筛、一阶准备、结构恢复、竞争和显式演化 | 快筛不能替代正式验收；原口径和约束不自动放宽 |
| M3.2 已有镜头检索 | 当前起点/文件收录、库保存回读、兼容筛选、Core 缩放迁移和原规格重验 | 当前迁移仍限原支持的空气单片、片数及轴向权限，自动口径未开放 |
| M3.4、M3.5 | 固定口径计算复用/性能改进，独立准备阶段 `.preparation.json`，原状态及预算精确续跑 | 准备检查点与主搜索检查点独立；不静默迁移旧计算版本 |
| M3.6 | 三语过程/淘汰/验收展示、只读方案库、设计报告及数据导出 | 中间候选不作为原规格合格镜头，展示通过不等于原生平台验收 |
| 胶合与 SPC | 真实共享界面、显式单层鞍点/双分支、正厚度补偿；准备、自动交接、自主胶合调度和主检查点续跑 | 递归 SPC 尚未开放；检索迁移不因此自动支持胶合，自动口径仍未开放 |

托管训练的默认预设、更新课程、材料表、GPU 回退和已知上游差别只在[模块指南](../labs/InitialStructure/README.md)及 [GPU 说明](AUTOLENS_GPU.md)维护。自主准备/主搜索与托管训练具有独立算法和检查点身份，不能交换优化器状态或继承别的共轭下的合格成绩。

## 计算、工程与数据边界

- 追迹、折射/色散、近轴量、正式点列、波前、MTF 和布局使用共享 Core。AutoLens 专用绿色参考、detach 与训练损失留在实验室，不替换普通分析定义。
- 源工程不交给搜索原地修改。每个候选绑定规格、不可变处方、算法/数值环境、父来源、实际费用和独立验收；显示、保存和导出使用同一结果身份。
- 平板祖先只证明旧谱系，实际随机起点另存。材料、厚度、物理口径和光阑不能用历史标签或代理分数替代。
- 取消、关闭、保存失败与过期回调保留用户工程及已有记录。只有明确导出/打开后，候选才成为普通工程。
- 有限共轭、无焦、变焦、反射、折叠与偏心支持按具体入口声明；不能从主工作台支持这些模型推定生成器已经支持。

## 当前后续工作

1. 继续按原规格核对宽角/困难任务，区分单例、同预算多种子、固定候选回归和真实产品会话。F/8 后续完成记录不能与早期 1/5 等不同阶段相加；F/4 原约束冲突保持，不自动扩径。
2. M3.3 条件生成仍暂缓，递归 SPC、更多迁移结构和自动口径分别建设与验收。已有检索不再列作“尚未实现”；学习排序、条件生成和设计智能体不作既有能力宣称。
3. 原生桌面及目标平台验证仍须独立进行。按用户要求，本地自动验证只在后台/离屏执行，不占用用户桌面；不把 Headless 结果替代原生交互验收。
