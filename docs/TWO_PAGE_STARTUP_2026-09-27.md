# 默认只打开镜头数据与二维视图

本文记录该阶段的实现和验证。后续主动作与紧凑侧栏已完成，跨阶段测试数不相加；当前整合行为及验证范围见 [状态页](CURRENT_STATUS.md)。


顺序模式的初始文档页签固定为“镜头数据”和“二维视图”，镜头数据初始激活，左侧系统选项保留。该规则适用于启动、新建、打开文件、切回顺序模式及重置系统初始布局。二维视图沿用稳定 ID，再次点击菜单只聚焦已有页，不创建副本。

此前系统初始布局只有镜头数据，但启动和文件切换会自动反序列化完整旧会话，因此保存过的分析页、三维视图等会被再次实例化。本次在 `WorkspaceDockFactory.CreateLayout()` 创建两个初始文档，在 `PanelManager` 中让顺序启动使用已创建的初始工作区、自动文件切换重建该工作区，不加载旧会话中的额外文档。没有采用“先恢复所有页面再关闭”的方式。

完整默认布局和槽位仍可通过用户显式命令载入。会话存储格式、保存路径、已有文件和自动保存机制未改；初始化不会改写磁盘上的默认布局。按文件会话继续保存作兼容数据，顺序模式自动打开不使用它来恢复页面集合。非序列模式保持自己的对象工作区与自动会话恢复流程。未改变光学数据、业务默认参数、计算或未保存工作保护。

固定偏好已同步到根 `AGENTS.md`；当前行为同步到 README、GUI 工作流、架构和 UI 规范。
