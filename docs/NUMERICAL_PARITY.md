# Optiland 0.5.8 数值兼容

## 参考边界

兼容基准固定为 `optiland==0.5.8` 的 Cooke 三片式、Tessar F/4.5 和仓库夹具。它是辅助回归，不是商业软件精度声明，也不能覆盖所有光学模型。

## 处方与视场

基准覆盖：

- 曲率、厚度、材料、孔径和光阑；
- EPD、像方 F 数、物方 NA 和按光阑浮动孔径；
- 角度、物高和近轴像高视场；
- 有限/无限物方共轭；
- 视场渐晕、物方远心发射和主光线；
- 波长、权重及主波长。

只有物面厚度为正无穷才表示无限物距；零厚度是与第一物理面重合的有限物体。该规则有独立回归，不能从坐标或容差推断。

## 追迹结果

Cooke/Tessar 夹具比较：

- EFL、F 数、入瞳/出瞳；
- 逐面位置、方向、强度和光程；
- 主光线、边缘光线和光束点列；
- 标量/SIMD、串行/并行和不同历史保留模式的一致性。

Optiland 金色数据是辅助证据。Zemax 2026 R1 `123456.ZMX` 基准是该文件对应分析的优先精度证据；两类结论必须分开表述。

## 分析结果

Python 来源契约覆盖 30 个数值/显示视图，包括点列、光线像差、波前参考、Zernike、FFT/Huygens/几何/采样 MTF、FFT/MMDFT/Huygens PSF、辐照度、Jones 光瞳和图像模拟。额外桌面分析使用各自的 Zemax 捕获基准、物理约束或有限性回归。

比较必须明确区分：

1. 参考数据完整性；
2. 当前 Workbench 重新计算；
3. 数值误差与容差；
4. 仅截图视觉走查。

## 回归契约

2026-08-28的正式产品历史基线为严格构建 `0` 警告、`0` 错误、全量回归测试 `837/837`；该数字只作为变更前记录，不代表当前测试总数。2026-09-02 当前正式解决方案构建为 `0` 错误，正式主测试 `1000/1000` 通过；构建仅有 NuGet 漏洞数据源 SSL 警告。独立智能初始结构实验室定向测试不参与数值兼容结论。几何 MTF 现按像面光线强度加权并在全无有效光线时明确失败，因此与按计数加权的 Optiland 0.5.8 辅助基线只保持 `2e-5` 近似约束，不再宣称逐点完全相同。该变化不修改已捕获 Zemax 版本、文件和设置的权威边界。独立 `Distortion` 只从公开目录退场，组合“场曲/畸变”仍调用同一底层算法。

基准构造函数必须保持通用默认值。产品预设可以选择产品默认，Zemax 捕获测试必须显式传入捕获设置，并在名称与文档中标明“文件/版本捕获设置”。
