# SPC 自动准备、断点续跑与主搜索交接

2026-11-01。SPC 已从[算法层](INITIAL_STRUCTURE_SPC_BRANCHES_2026-11-01.md)接入自主拓扑的准备流程、三语入口、记录与报告。原批后台验证通过，默认输出当时受运行实例占用。用户随后关闭主程序，已补齐正常默认 Release 完整构建及同组程序集的后台复验，见[默认输出验证](INITIAL_STRUCTURE_SPC_DEFAULT_OUTPUT_2026-11-01.md)。本页保留原批范围，旧封存结论不改写；未启动前台程序。

## 使用与权限

在 **AI 初始结构 → 自主拓扑设计 → 起点准备（独立预算）** 勾选 **实验：SPC分支准备并自动搜索**。它与冷启动、检索和其他准备路线互斥，旧计划默认不开启；原参考面、光阑、像面、视场、波长、净/机械口径、材料和面型权限保持。SPC 准备使用 CPU，函数与时间沿用准备总额度，梯度和实际追迹额度有单独控件。

点击“开始”后先执行 SPC 准备，只有通过原完整验收的普通正厚度起点才能进入主搜索；未完成、超预算、规格冲突或没有合格起点的准备会保存并停止，不借用旧起点绕过失败。“SPC分支准备”按钮仅运行准备，完成后“继续”才交接主搜索。

点击 **停止并保存**，等待安全边界落盘；重开后通过 **打开自主记录** 载入 `.preparation.json`，再点 **继续自主任务**。主搜索交接使用同一运行身份与确定的文件路径，已有匹配记录只加载，不重新创建。报告与方案库只读展示父结构和真实实体阶段，零元件不成为合格镜头、普通工程或主搜索起点。

该路线是一层空气分隔 SPC：每个父结构选择一个原许可的光阑后球面位置，仍要求原片数上限允许插片。保留未保护面曲率、原变量边界与原独立验收；没有开放自动口径、自主胶合或递归增长。

## 保存的计算状态

准备检查点新增可空、带版本的 `Spc` 状态，空值不改变旧记录的 JSON 和协议身份。保存内容包括：

- 父结构排序、已选插片位置、随机流状态、父结构/分支/厚度/材料游标。
- BFGS 坐标、目标与完整梯度、逆曲率矩阵、迭代数及终止状态。
- h/h2 中心梯度差分的已完成列、原始矩阵、粗步长谱、驻点与曲率检查结果。
- 物理阶段的原模板、绑定、冻结额度及既有补偿器的坐标、矩、学习率、接受/拒绝历史和评价结果。
- 原规格合格候选池、完成的父结构/双分支/材料失败证据，以及累计函数、梯度、差分、制造查询、实际光线和计算活动时间。

停止在完整的 BFGS 或实体补偿更新、完整的正负差分列、或原独立验收之后完成。若暂停发生在线搜索中，当前更新先完成，避免恢复时重新追迹已计费的失败试探。恢复直接使用保存的优化器和列状态，没有重跑父优化或重新抽取随机数。

持久化使用原64 MiB有界原子文件、写锁、内容校验和修订检查；已完成的父证据、分支和候选池只能追加，累计预算不能回滚。计算活动时间累计接续，暂停等待和持久化分列；进程启动、读盘、最后一次写盘的墙钟费用不冒充纯计算时间，不据此报告端到端加速。

最终 SPC 数值身份包含 Core/Engine MVID、.NET、操作系统、进程架构和相关 SIMD 能力。不同数值环境只读，不能重写身份继续；历史非 SPC 协议保持原规则。强制结束进程可能留下在途预约，此时保守计费一次、标为中断并停止，不宣传为精确崩溃恢复，也不把原额度重新赠送。

## 原任务与产品会话

原八片F/8已达原8片上限、F/4的固定外置光阑半径6.25 mm超过全部面半径5 mm、原21°任务禁止插片：各五种子共15个SPC守卫均为零函数、零追迹，不创建主搜索。原F/8五个既有合格终点另按原完整验收重算，内容指纹全部一致，不算新冷启动或新增SPC广角成功。

真实 `AutonomousDesktopSession` 另外在负支停止，新进程载入后继续准备并自动交接。准备161函数/151梯度/503,394条光线；主搜索162函数/0梯度/89,040条光线，各自保持独立原额度。主搜索上限为400函数/100梯度/600,000条光线/30秒，限定一个结构试验，未将准备额度借给主搜索。两个交接起点都通过独立原验收与STAROPT回读；第三个进程重复交接仍只有一份主记录，重复交接、加载及报告重开全部零追迹。
