# NSC 分析到统一探测器、RAW 与 ISP

本轮先修复相机专项审查的两项问题，再在现有主程序中接通 NSC 分析结果到传感器的完整桌面链路。没有启动前台应用、操作用户桌面或修改其他正在进行的光学/镀膜工作。

## 两项正确性修复

- 3D 参数 readiness 使用与 `V()` 相同的原始文本、范围及整数验证。物深、功率、保护带和窗口半径的非法文本不会再从信息展示/输入事件逃出异常；清 B 留 A，修正后恢复运行。
- 几何与衍射 renderer 共用的预检明确拒绝曲面像面。Plane 和共享 Core 定义的零曲率 Standard 保持支持，不把真实曲面静默替换为顶点平面。没有伪造曲面面积、法向或移动处方。

## 实际交付

入口：相机成像仿真 → 源图像“非序列探测器”。用户先完成非序列分析，随后选矩形探测器、输入路径筛选、读取 NSC 结果、导入绝对 QE 并运行。尺寸由探测器决定；例如 `0.384 × 0.288 mm / 128 × 96` 对应 `3 µm` 方形像元。此阶段不重采样其他物理像元，也不隐式发起追迹。

```text
当前完整 NSC 分析数据库
  → 核对场景、会话和数据库身份
  → 按保存路径/用户筛选重建原始分波长 W/像元
  → SpectralDetectorPower
  → 一次曝光和绝对 QE 积分
  → 原噪声 / 满阱 / ADC / Bayer RAW / 基础 ISP
  → A/B、导出、完整实验及冻结功率复算
```

NSC 的完整分析与独立布局会话继续分离。读取同一个已打开数据库流，检查场景哈希、源修订、实际数据库创建时间/种子/分裂模式和分支数，并在发布前检查会话 ID、更新时间、筛选及路径。选中会话现在保留实际数据库头，不能把会话生命周期时间误当作文件创建时间。场景/会话变化拒绝旧读取，取消/错误保留既有结果。

读取和复算始终使用原始功率，不读取显示热图、平滑图或归一化结果。分波长功率已经包含光学传播、波段和像元面积，不再次乘波长表权重或像元面积。原 NSC 负局部 Y 起始数组只在传感器栅格转换一次方向；Bayer 按最终顶部起始坐标解释。

完整 NSC 路径已包含的主成像不再叠加顺序像或 PSF。用户可以按 R/T/SEQ 等实际路径语义区分贡献；没有把任意反射路径自动命名为杂散光。解析控制中的玻璃板主路径与鬼像分别筛选后，其光电子之和等于全路径结果。空筛选指全部已保存路径，写库筛掉的路径不能恢复。

## 保存和物理边界

`CameraLabV9-NscDetector/1` 冻结分波长功率、波长表及原权重、探测器物理尺寸和世界轴、场景/会话/数据库身份、追迹设置、源 ID、原始写库/本次路径筛选、警告和各自传感器/ISP。删除源数据库或更换工程后仍可开发冻结功率；这是传感器复算，不是重新追迹原始 NSC 场景。

实验容器保持 schema 1、256 MiB 上限。可空 `NscDetector` 不参与旧请求序列化，保留 V5–V8 旧实验和旧采样报告指纹。NSC 对照 ZIP 添加 `nsc-detector.json` 和顶部起始的物理 `detector-power.csv`。光学预览是固定标尺总辐照度灰度图，不是光谱恢复后的真彩色。

该链路使用现有 NSC 镜面反射/折射/Fresnel 分支和机械路径，不新增方向散射/BSDF、角度 QE、偏振相干求和、动态快门或商业软件数值认证。原光线、像素、波段、处方与精度容差保持。光学蒙特卡洛采样误差与真实传感器噪声分别解释。
