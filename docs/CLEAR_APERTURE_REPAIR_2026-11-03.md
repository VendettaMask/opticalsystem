# 通光孔径形状与偏心导入修复，2026-11-03

本轮从95支示例的未关闭结果中，优先定位会同时改变传播、波前、PSF、MTF、能量与照度的上游问题。已确认并修复：圆形/环形通光孔的`OBDC`偏心量被读取后丢弃，矩形通光孔`SQAP`被忽略。修复位于共享纯C# Core，没有镜头名分支、参考数组、残差拟合或比较门槛放宽。

## 根因与物理证据

无挡格里高利的主镜坐标系横移100 mm，文件声明半径55 mm的圆形通光孔，再用`OBDC 0 -100`把孔中心移回实际入射光束处。旧导入仍把孔放在该曲面坐标原点，错位100 mm，造成真实可通行的光线被截断。两片90°抛物镜同样丢失了±160 mm的圆孔偏心。

Chebyshev离轴抛物面声明50×50 mm矩形孔、Y偏心−60 mm。旧导入没有安装矩形孔，使实际应被裁掉的光线进入衍射计算。这与原生定义一致：矩形尺寸是X/Y半宽，表面孔径可独立偏心；它不改变曲面坐标或曲面方程。[表面孔径定义](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Aperture_surface_properties.html)、[原生自由曲面示例说明](https://optics.ansys.com/hc/en-us/articles/42661754261651-Freeform-optics-in-OpticStudio)。本轮另用独立Zemax 2026 R1实际固定光线确认，未只凭文档推定通过。

六支系统、72条独立输入包括格里高利、两片90°抛物镜、Chebyshev离轴面、分光系统、坐标断点棱镜及棱镜复消色差系统。修复前有**25条接受状态和25条首裁光面不一致，修复后均为0**。可生成的69条输入共541组逐面位置/方向对照，沿用位置`1e−6 + 1e−6·|值|` mm、方向`1e−8 + 1e−6·|值|`门槛，零超限。五个系统的完整固定输入组Pass；两片90°抛物镜仍有3条原有瞄准失败，前后相同，该组整体保留Difference，不能把缺失光线计为通过。

## 实现与相邻契约

- 圆形/环形通光孔使用已有`OffsetRadialAperture`，矩形使用已有`RectangularAperture`；零偏心圆孔继续使用原类型。`OBDC`、`APDX/APDY`及`APMN/APMX`配置值按实际长度单位转换，补齐原先未进入配置解析的`APDX/APDY`。
- 形状、偏心及浮动半径经克隆、STAROPT快照与ZMX往返保持；圆环孔的内孔继续裁光。调整拥有浮动半径的表面半口径保留偏心，显式孔径不随外形半口径改变。未激活的APMN/APMX/OBDC不会自行安装孔径。
- 矩形尺寸要求有限且为正，不静默改成微小通光孔。其他未映射孔径/遮挡形状不由本轮取得支持认证。已经保存成错误居中孔径的旧STAROPT缺少原偏心信息，需要重新导入原ZMX，不能从镜头名猜回。
- 实际孔径恢复后，单光线报表在首个裁光面后可显示**明确标注的几何延长**，每行保留渐晕状态，另报物理终止面与诊断使用状态。图中实际光线仍止于物理裁光处；后续数值不计通光功率，正常追迹缓存不接收诊断样本。几何求交失败不会补造后续行。
- 有限曲面域可能让全瞳边缘探针失败。若原设置chief物理通过、自动瞄准的chief反被实际孔径挡住，FFT保留请求的发射约定，并使用既有较小瞳孔区的几何F数估计。高NA的原整体瞄准回退继续保持；没有为匹配参考改变孔径或物理容差。

此前[偏心出瞳专题](BIOCULAR_PUPIL_FREQUENCY_REPAIR_2026-11-02.md)中，格里高利被挡的辅助轴线是在当时错误孔径下观察到的结果，本轮已找到其导入根因。几何相位参考的显式许可仍保留，原回归改为主动安装的合成遮挡；真实格里高利chief现在按原生孔径通过。
