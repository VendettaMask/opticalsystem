## 1.0.1 已实现的保护（历史）

- 每个发布使用独立 `versions/<release-id>` 目录，逐文件 SHA-256 校验通过后才启用新入口。旧载荷保留，不递归清空安装目录。
- 应用持有跨版本存在标记；安装器和卸载器要求应用正常退出，且禁止安装期间启动新应用。不强制结束进程。旧版无标记程序另有 EXE 排他访问检查。
- 相同安装包重复安装先核验现有载荷，并保持原恢复指针。新布局拒绝低版本覆盖；历史平铺布局没有可靠的版本状态，不能宣称已实现其通用降级判定。

- 默认 `SigningMode=Unsigned`；可选 `Required` 模式要求指定有效代码签名证书、签名工具和时间戳服务，对本项目二进制、安装器和卸载器签名并验证。当前无证书，这一成功路径未验收。

## 构建和复验

普通未签名安装包：

```powershell
.\Build-Installer.cmd -AppVersion 1.0.3
```

输出包含 `*-Unsigned-Setup.exe`、对应 `.sha256`、`release.json` 及构建载荷。向用户交付安装 EXE；同时提供可信下载位置上的哈希和版本说明。不得把未签名文件写成“已验证发布者”。构建使用新目录，失败保留 `.partial`，不覆盖旧包。

```powershell
.\scripts\build-installer.ps1 -AppVersion 1.0.3 -UnsignedTestPackage `
  -ProductAppId OpticalSystemDesign-UpgradeValidation-20261012 -EnableValidationHooks
```

只有测试包与非正式产品标识同时具备时才允许故障注入。正式默认包不编译这些入口。`scripts/verify-windows-upgrade.ps1` 接收该包、其 `release.json`、低版本平铺包，以及可选低版本新布局包、不同发布 ID 的恢复测试包 `RecoverySetupPath` 和第三个未安装发布的 `PartialCopySetupPath`，保存逐项检查和日志；不得对正式安装执行该脚本。中断注入只结束新测试包写入 PID 标记所确认的本次安装器进程，不结束正式应用或其他安装任务。

历史 1.0.1 未覆盖持久中断恢复、工程定时副本和同发布载荷修复；这些已由 1.0.2 实现。1.0.3 增加有归属证明的旧载荷自动清理，上一版仍保留；一键版本回退按用户要求不纳入范围。持久日志是本安装拥有状态的应用级事务，不是文件系统、全部 Windows 注册表或硬件的系统级事务；恢复自身遇到磁盘/权限错误时保留日志并阻止继续，不能承诺自动消除底层故障。

当前验收不是安装向导逐页操作或完整桌面 GUI 验收。当前已增加不依赖会话命名空间的目录文件锁，实际第二 Windows 登录会话仍未验收；旧二进制只能保留已有 Local 互斥及 EXE 占用兼容保护。ARM64 仍只有构建脚本支持，未在对应机器安装运行。没有执行真实受信任签名验收、Microsoft Store 上架或新 Zemax 捕获；也没有据此认证资源再分发许可或所有光学路径。

后续实机验收使用独立测试标识与可丢弃环境：第二会话保持同目录应用运行，再在第一会话安装/卸载，确认阻止且工程可保存；可丢弃虚拟机在复制/激活/提交阶段切断虚拟机电源后重启，逐项核对状态、快捷方式、工程原哈希与重试；故障虚拟盘模拟空间不足/只读/备份损坏并验证日志保留和禁止继续；ARM64 机器安装原生包并打开、编辑、保存及恢复工程；桌面逐页操作安装、退出重进、未保存确认、崩溃恢复对话框和卸载数据保留。记录系统/架构、包哈希、实际步骤和原始日志后才能标为通过，不在用户当前磁盘实施断电或损坏测试。

如未来需要不购买证书的受信任分发，可增加 **Microsoft Store 的 MSIX** 路线，由 Store 在提交时签名；需要账户身份核验、格式适配和审核，尚未实现。现有 EXE/MSI 上架通道仍要求受信任签名，不能直接拿当前未签名 Inno 包换取 Store 签名。普通用户安装自签证书不是此项目的分发方案。[微软 MSIX 签名说明](https://learn.microsoft.com/en-us/windows/msix/package/sign-msix-package-guide)、[EXE/MSI 上架要求](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msi/app-package-requirements)。

安装/应用互斥、事件和签名实现参照 [Inno AppMutex](https://jrsoftware.org/ishelp/topic_setup_appmutex.htm)、[SetupMutex](https://jrsoftware.org/ishelp/topic_setup_setupmutex.htm)、[脚本事件](https://jrsoftware.org/ishelp/topic_scriptevents.htm) 与 [SignedUninstaller](https://jrsoftware.org/ishelp/topic_setup_signeduninstaller.htm)。SHA-256 安装校验属于完整性检查，不替代操作系统的发布者认证。
