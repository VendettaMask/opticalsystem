# 多配置联合公差实施计划

2026-11-06，四阶段已实现并完成本地验收。当前环境未安装 OpticStudio，原生逐值对照待执行。[测试、算例与复算文件](../validation/rechecks/2026-11-06/joint-configuration-tolerancing/README.md)

用同一件虚拟样件验收广角端、长焦端或不同物距。每次 Monte Carlo 先生成一份制造误差，再把它应用到所选配置中的同一实体。所有受检配置在同一次试验中均达标，该样件才计入整机良率。

首批交付覆盖两配置联合 Monte Carlo、分步补偿和逐配置验收。首批通过后，再接联合反求、最差样件复算和配置操作数。复用现有的配置选择、公差、分步装调及样件文件工作流。[配置选择](ANALYSIS_CONFIGURATION_SELECTION_2026-10-22.md) · [现有公差](TOLERANCING.md)

## 首批实施边界

- 适用于能明确对应实体表面和镜组的顺序系统。配置可有不同的名义间隔、像距和视场。运行前按处方拓扑、已有配置关联和目标面适用性核对对应关系。表面缺失、实体对应不明确或拾取与补偿写入冲突时，报告配置、表面和操作数。
- 在公差分析的设置页增加「当前配置」「选定配置」「全部配置」。默认使用当前配置。单配置研究沿用现有入口和结果。
- 首批复用现有 RMS 点列、RMS 波前及指定频率 MTF。各配置可设置自己的验收限值。逐视场 MTF 用各配置实际的视场、波长和限值计算，在报告中保留这些设置。

## 第一阶段 同一样件跨配置计算

在一次工作区修订下冻结所选配置、已求解处方、表面关联、公差定义与补偿设置。试验在独立副本运行，配置的切换和计算均在副本中完成。

制造误差按实体绑定。共享曲率、镜组偏心等操作数只抽样一次，将同一个物理扰动应用到对应实体。镜组误差使用已核对的装配坐标。共享面形以实体面为基准固定系数、归一化半径和方位，再用各配置自己的净口径追迹。对于条纹输入，先确定统一的检测波长和基准净口径，再换算为实体面误差。运行顺序和线程数不参与试验的随机身份。

验收时用一支两配置镜头验证同一 `ISOB + ISOC` 扰动在两端的系数、基准和方位一致。另用不同口径验证追迹范围可随配置变化。移除一个目标面或构造冲突的拾取关系，确认运行前能定位具体配置和公差行。

## 第二阶段 联合补偿和整机良率

复用现有补偿阶段。把每个可调量显式指定为共用执行器或配置独立执行器。共用镜组在同一阶段只有一个有界调整量，由所选配置共同评价。独立像距只作用于目标配置。后续阶段沿用前一阶段的调整结果，报告保留每阶段评价和可调量。

优化时汇总各配置现有的评价残差，首批默认配置等权。验收逐配置、逐视场判定。无效评价计入该样件的失败，报告定位失效配置或视场。整机良率等于全部选定配置均通过的试验数除以总试验数。设定验收限值时，按各配置和视场中最小的验收余量选择最差样件。未设置限值时，沿用 RMS 取最大值、MTF 取最小值的规则。失效试验优先。

用同一份试验表核对配置和整机的结果。下列四次试验中，广角端良率为 75%，长焦端为 50%，整机为 25%。

| 试验 | 广角端 | 长焦端 | 整机 |
| --- | --- | --- | --- |
| 1 | 通过 | 通过 | 通过 |
| 2 | 通过 | 未通过 | 未通过 |
| 3 | 未通过 | 通过 | 未通过 |
| 4 | 通过 | 评价失效 | 未通过 |

共用执行器在所有配置施加的相对调整量一致。独立像距可得到不同数值，且仍在各自限位内。串行与并行运行输出同序的试验结果。此阶段通过后完成首批交付。

## 第三阶段 联合反求和最差样件复算

按公差行逐侧反求。每个候选扰动都重新执行同一套联合补偿，所有配置和适用视场均达标后才接受候选范围。将收紧后的端点用实际追迹再算一次，报告限制该范围的配置、视场及余量。

扩展样件文件，冻结参与配置、实体关联、实际执行范围、补偿阶段、试验号、种子、采样规则版本和记录结果。打开样件后只复算所存试验，逐项核对每个配置的评价、验收和阶段调整量。旧单配置研究与样件继续按原语义读取。

验收时构造由不同配置分别限制正、负端点的例子，验证复验后所有配置均通过。在另一份工程打开保存的最差样件，复算结果与原记录一致，当前工程的处方和活动配置保持原值。

## 第四阶段 配置操作数

首批支持可编辑配置厚度或空气间隔。将 `TMCO` 用于指定配置和多配置编辑器行的制造误差，将 `CMCO` 用于指定行的有界补偿。复用现有行与配置关联，明确拾取、只读行和重叠补偿的处理顺序。[Ansys TMCO](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v252/en/OpticStudio_User_Guide/OpticStudio_Help/topics/TMCO_Tolerance_on_Multi_Configuration_Data.html) · [Ansys CMCO](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v25101/en/OpticStudio_User_Guide/OpticStudio_Help/topics/CMCO_Define_Multi_Configuration_Operand_Compensator.html)

验收时对指定配置的空气间隔施加误差或补偿，核对目标配置和明确关联的配置发生对应变化。保存重开后解析到同一行。失效的行引用及重复写入给出具体错误。

## 验证记录

首批保存两配置样例、固定种子、共享面形参数、分阶段调整量和逐试验验收表。复验单配置、源处方与活动配置保护、取消、配置映射失败、串并行一致性及离屏设置界面。后续阶段追加反求端点和样件往返证据。
