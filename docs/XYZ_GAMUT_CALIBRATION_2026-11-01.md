# 有颜色适用域的 XYZ 辐射度校准

后续当前状态：[已知观察条件的正值XYZ校准与协议8/v16](XYZ_KNOWN_CONDITIONS_2026-11-01.md)已让两份实测光谱派生XYZ通过原门槛并导出。本页保存协议7阶段的原结果与失败，不代表后续算法结果；原发布XYZ观察者仍未核实。

2026-11-01。本阶段增加共享 Core 的 **有域约束、有符号线性校准**，接入同一 Zemax BSDF→NSC→统一探测器→RAW/ISP，使用 **MeasuredBsdfGrid/7 / STAROPT v15**。原非负三通道校准、Grid/1–6 和 White 运行时功率模型保持原协议。

Cornell 发布的 Krylon Blue 配对数据在固定550 nm下，从旧模型留出 NRMSE **0.13196594** 改善至 **0.00838003**，最大绝对差 **0.00273240 sr⁻¹**，通过原拟合策略；**观察者条件仍未核实，正式导出实际被拒绝**。独立按已知 CIE 1931/D65 条件从实测光谱推导的 XYZ 仍未通过，因此不能宣称真实材料校准或商业 XYZ 完整认证完成。[完整结果与执行身份](../validation/rechecks/2026-11-01/xyz-radiometry/README.md)

## 校准模型

旧 `Fit` 强制所有光谱映射系数非负，保证整个正XYZ空间的输出非负。当前新增 `FitWithinGamut`：允许系数为负，但要求在调用方声明的全部颜色域内 `aX+bY+cZ≥0`。颜色域是 `X/(X+Y+Z), Y/(X+Y+Z)` 上的严格凸多边形及其对应正锥，黑色映射为零；适用域之外明确拒绝。

```csharp
var gamut = XyzCalibrationGamut.Create(description, xyzSourceSha256, inputColors);
var result = XyzRadiometricCalibrator.FitWithinGamut(
    pairedObservations, provenance, explicitPolicy, gamut, cancellationToken);
// Only passed validation AND verified observer/illuminant can export.
var calibration = result.CreateCalibration(name, observer, illuminant);
```

适用域只用未标注的XYZ输入特征建立并在拟合前固定，可以包含预定应用/验证输入的颜色；不读取留出的辐射度标签。域来源SHA必须与XYZ来源一致，最多64个顶点。拟合仍只用训练辐射度值，保持跨波段样本身份、训练/验证角色、防泄漏、秩3、取消和原观测数量预算；不从文件名、材质名或某个样例触发特殊规则。

约束是齐次三变量凸二次规划。枚举内部、一个约束面、两个约束面的交线和零解，均用共享Jacobi SVD求解；没有复制基础光学引擎。边界解仅向域内移动有明确浮点舍入上界的系数量，不裁剪任何测量或负预测。域、系数与来源一起进入新证据摘要；修改域或系数不能保留旧证据。旧无域证据省略新增字段、继续使用原摘要字节。

## 功率与方向采样

Zemax各XYZ通道有独立TIS归一化。新模型先把原角表节点换成每通道的**绝对BSDF**，检查颜色适用域，再做有符号线性映射。所有辐射度节点和TIS均须有限、非负且被动；越域、负值或TIS超过1均拒绝，不把负值裁成零，不用总功率归一化修正错误校准。

转换后的非负辐射度网格复用普通 Zemax 镜面中心积分、Evaluate/Sample/Pdf 和介质规则。没有将有负权重的XYZ通道混合当成概率分布。波长之间是两个非负辐射度网格的凸混合，按混合功率选择采样；范围外拒绝。派生网格总节点数受原131,072节点预算限制，不降低原输入分辨率。

Grid/7贯穿对象协议、STARRDB反射/透射散射、相机来源冻结及界面标签。工程按最高所需模型选择v15；v14或更早夹带Grid/7明确拒绝，包括禁用对象。容器2、顺序快照schema6、旧Grid/1–6及其存量实验不升级。桌面使用既有校准JSON导入入口，拟合仍为Core/API能力，没有新增桌面拟合向导。

## 实测结果与适用范围

预先固定550 nm及原探索策略 NRMSE≤0.01、最大绝对差≤0.01 sr⁻¹、相对信号底1e−6；每份配对数据均1,439方向，959训练/480验证，完整四角G17键排序、每第三项留出。以下均为**发布配对数据**：

| 材料 | 旧非负模型留出NRMSE | 新域约束模型留出NRMSE | 新最大绝对差 sr⁻¹ | 原拟合门槛 |
| --- | ---: | ---: | ---: | --- |
| Cayman | 0.32920326 | 0.32920326 | 0.01107594 | 失败 |
| Garnet Red | 0.08034165 | 0.05682363 | 0.09950984 | 失败 |
| Krylon Blue | 0.13196594 | 0.00838003 | 0.00273240 | 通过拟合；条件未核实，拒绝导出 |
| Blue Acrylic | 0.61200403 | 0.61200403 | 0.00216511 | 失败 |

Krylon系数约为 `(-3.59659351, 6.38460479, -0.15178324)`，域16顶点；独立小规模法方程诊断与共享SVD约束解一致，产品使用SVD。无约束有符号拟合虽有更小留出误差，但出现约−0.00013 sr⁻¹预测，未采用。新模型在声明域内保持非负，不意味着暗信号具有低相对误差：Krylon最大相对误差仍约1054.97，原门槛未包含该项，完整原值保留。这是开发过程中找到的受限通过案例，不是未参与模型开发的新盲测或跨材料认证。

原训练误差误导性的原因也已量化：Cayman单个镜面高亮样本占训练目标平方和的 **99.89298%**，训练最大BSDF631.320435 sr⁻¹，验证最大0.166210 sr⁻¹。改变权重的独立诊断未通过，未更改产品默认目标或门槛。即使把验证集自身作为训练来求非负三通道最小残差，四材料最低NRMSE仍分别约0.100960、0.015834、0.060035、0.491688；这些仅用于证明旧模型的限制，相关系数不导出、不用于正式拟合或留出评分。

Cornell官方说明发布XYZ由实测光谱在D65下计算；不是独立XYZ仪器测量，观察者角度未明确。前向比较仅作为观察者/积分约定的假设诊断：1 nm线性插值、10 nm求和及梯形等预定方法存在不同归一化和残差，不能据此把观察者标记为已核实。[Cornell说明](https://bowers.cornell.edu/computer-graphics/data)

另用已核对官方SHA的CIE 1931 2°和D65数据，在明确400–700 nm、范围外为零、1 nm线性光谱插值/梯形积分、白色Y归一化下，从Krylon实测光谱独立推导XYZ。原策略保持，新域约束模型留出NRMSE **0.03380156**、最大差 **0.04817358 sr⁻¹**，失败并拒绝正式导出。保留该失败，未改用某个较粗积分约定制造通过。来源：[CIE观察者](https://cie.co.at/datatable/cie-1931-colour-matching-functions-2-degree-observer)、[CIE D65](https://cie.co.at/datatable/cie-standard-illuminant-d65)。

## 验证与剩余工作

最终定向 **280/280通过、0跳过**（1分23秒），其中本阶段新增16项。覆盖精确已知系数、非负约束面、域/来源篡改、未知条件、越域、非法域、非被动功率、非恒定角分布的独立密度/矩/方位统计、波长插值、固定材料轴、反射/透射、STARRDB、工程版本、防静默导入覆盖，以及NSC→电子→RAW/ISP保存重开。反射和透射链路各8,192次抽样，独立光子换算最大差均2.84217e−14 e⁻，冻结RAW/ISP逐值一致；该链路是合成解析控制。新增上一阶段Grid/6自制相机ZIP逐值重放，旧Grid/4/5控制继续保留。
