# 协议 4：真实材料高反、窄带的通用连续优化修正

本页保留上一阶段140项测试及24组配对身份。后续已修正本页记录的峰值T/截止OD交换退步，增加逐项原输入保护及高反停滞重启；最新154项测试和35组对比见[后续报告](COATING_TARGET_PRESERVATION_2026-10-30.md)。本页原数值不改写。

本轮继续处理真实 n/k 下未达标的高反、单腔和双腔窄带。没有材料名称/ID、某个膜层编号或例子签名分支；不清零 k，不改制造界、固定层、默认协议或原验收。全部运行在后台，产品计算继续使用 C#/.NET 共享 Core。实现、完整输入和失败均保存在[证据目录](../validation/rechecks/2026-10-30/coating-infeasible-repair/README.md)。

## 已修正的通用问题

**未达标反射率的目标停滞。** 原 `feasible-worst-reflectance/1` 只在指导网格可行后接入，困难高反会一直停留在单边可行性目标。本轮保留一段原目标的可行性预处理及短筛选，然后把剩余预算用于实际最差损失 `R`（AR）/`1−R`（HR）的上界优化，无须先跨过验收门槛。已可行起点保留上一阶段的零乘子质量优化。未可行起点按活跃最差点的上界一阶条件初始化对偶量，`Σλ/√N=z`；不是针对材料拟合权重。新记录为 `worst-reflectance/2`，可行性和质量工作仍共享一次最大迭代预算。

**窄带指导指标与验收定义不一致。** 原流程以中心点 T 和四个固定目标边缘点引导宽度，没有实际 FWHM/峰位方向。本轮在共享 Core 增加 `sampled-log-half-maximum-adjoint/1`：对既有 log(T) 相对半高交点求分段膜厚导数；缺少交点或 log 导数时返回不可用，不补造零宽度导数。另提供局部三点 log 光谱顶点及其膜厚导数，用于峰位引导；正式峰位仍使用原密集谱最大点，正式 FWHM、绝对 T 与测量版本完全保持。

协议 4 据此约束实际采样 FWHM、估计峰位和实际峰值 T，不再额外要求峰恰在指定中心。带形超限时保留目标边缘引导，实际宽度及峰位进入允许区间后关闭该辅助引导，避免把合格的不对称峰形强制改成对称峰。每个截止带用最差 log(T)/OD 构成约束，避免残差权重随自适应点数变化。通带基础指导加密到每个目标 FWHM 约 64 段，与正式扫描的基础尺度一致；它仍不是连续光谱认证。

约束行按物理角色固定，峰或半高边缘消失时只关闭对应行，防止试探期间残差/Jacobian 维度变化。固定排名网格上的物理更优试探点也会保留，而非只保留每个增广阶段的最后一步。新增 `GeneralWork.PassbandProtocol="measured-passband-constraints/1"`、`BandMetricEvaluations`、`BandSensitivityBatches`；计数单位分别为指标批次和使用共享膜厚导数的指标批次，后者是前者的子集，不能叠加为总光学工作。

## 固定参考的实际对比

离线执行未改动的 TFStudio `8b942b3f956728a23cea2b35023c8b5d8de17428` 的 DLS 与 Newton，共 7 组输入、14 次参考运行。材料 n/k 由共享 Core 在参考查询波长导出并精确查找；未导出的波长拒绝回退，不以无损或嵌入介质代替原材料。使用相同初始膜厚、固定标志、厚度界与最大迭代次数，再把参考生成的膜厚交回最终共享 Core 按原门槛复验。

参考 HR 使用谱点 R=1 的平方目标；窄带使用中心/目标半高边缘和截止 T 点目标。这些是参考引擎可直接运行的指导目标，**与本产品实际 FWHM/OD/最差损失目标不等价**，因此不是同优化问题、同总成本或全局能力排名。原始目标、评价次数和结果全部保存。

参考 DLS/Newton 的真实高反最低 R 分别为 **95.610597% / 95.882407%**，均未达到98%；单腔窄带峰值 T 为 **67.195838% / 67.219052%**，双腔为 **64.348670% / 64.443486%**，同样未通过原规格。参考14份处方中2份通过各自原门槛；它也会改变已经合格的谱形，不能以参考内部 merit 下降替代正式验收。源码同时确认参考还有精确二阶方向、随机结构加/删/分裂/合并等能力，本产品本轮没有迁入这些算法，也不宣称完成一般膜系综合。
