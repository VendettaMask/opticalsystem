## 当前公开算法

2026-10-05 应用服务的快速聚焦、单半径和多变量优化已改为完整文档快照计算：捕获与最终提交使用短锁，求解及自动半口径刷新在锁外执行。计算期间可读取、取消或编辑；源修订/代次变化时丢弃旧结果。成功提交保留全部配置与注册数值后端，作为一次可撤销变更；失败不提交副本。算法名称、版本及数值门槛未改。见[可靠性修复与验证](AUDIT_RELIABILITY_FIXES_2026-10-05.md)。

界面和 `OptimizerCatalog.Names` 只公开代码中真实执行的算法。运行结果保存规范名称和版本，不能使用请求别名冒充实际算法。

| 规范名称 | 版本 | 当前实现 | 诊断信息 |
|---|---|---|---|
| `Damped Least Squares` | `damped-least-squares/2` | 带阻尼的残差雅可比最小二乘步进、精确约束处理、无效试探步拒绝与差分探测恢复 | 停止原因、梯度范数、函数评价次数、无效试探步计数警告 |
| `Nelder-Mead` | `nelder-mead/2` | 有界单纯形反射、扩张、内/外收缩和缩小；固定变量不占单纯形维度 | 停止原因、函数评价次数 |
| `Coordinate Pattern Search` | `coordinate-pattern-search/1` | 有界坐标方向模式试探和步长收缩 | 停止原因、函数评价次数 |
| `Momentum Gradient Descent` | `momentum-gradient-descent/2` | 有限差分梯度、动量方向和回退步长；非有限梯度明确失败 | 停止原因、梯度范数、函数评价次数 |
| `Greedy Random Perturbation` | `greedy-random-perturbation/1` | 固定种子的逐坐标随机扰动，只接受更优候选 | 停止原因、函数评价次数、随机种子 |

`Greedy Random Perturbation` 是启发式局部/区域搜索，不宣称具有全局最优保证。

2026-10-26 起 Nelder–Mead 区分反射点优于最差点时的外收缩和反射更差时的内收缩，并使用对应接受条件。初点与每个顶点均投影到变量边界，保存的单纯形坐标与实际评价坐标一致；上界初点向区间内部生成顶点，等上下界变量保留数值但不占搜索维度。实现版本更新为 `/2`，历史 `/1` 记录不改写；具体回归见[修复记录](PRIORITY_RELIABILITY_REPAIR_2026-10-26.md)。

## 名称兼容与拒绝边界

只有确实指向同一实现的旧称保留为兼容别名，每次运行都会显示并记录兼容警告；返回结果的 `Algorithm` 始终是右侧真实名称。

| 旧名称 | 实际执行 |
|---|---|
| `LM / DLS`、`Least Squares` | `Damped Least Squares` |
| `Orthogonal Descent` | `Coordinate Pattern Search` |

`Powell`、`COBYLA`、`BFGS`、`L-BFGS-B`、`Differential Evolution`、`Dual Annealing` 和 `Basin Hopping` 不再作为兼容别名映射到不同算法；调用这些名称会明确返回 `NotSupportedException`。兼容别名不会出现在算法选择器、Ribbon、能力清单或宣传文案中。

## 状态校验

优化公共 API 会在进入求解前拒绝不完整或非有限状态：变量名称、getter/setter、上下界、步长提示、缩放器正反变换、操作数目标、权重和评价值都必须有效且有限，且变量下界不能大于上界。变量向量和缩放变量向量必须与变量数量完全一致；维度不匹配会立即失败，不会只写入前几个变量并混用旧值。权重为正的操作数进入目标残差，权重为负的操作数进入精确约束残差，权重为零只作为监视项；`NaN` 或无穷权重不会被静默跳过。

## 尚未实现

以下算法在真实、独立实现和数值测试完成前不得出现在产品 UI 或功能宣传中：

1. 带强 Wolfe 线搜索、曲率更新保护和收敛诊断的 BFGS。
2. 具有投影梯度、活动边界和有限内存校正对的 L-BFGS-B。
3. 使用线性近似约束和信赖区域的 COBYLA。
4. 具有种群、变异、交叉和选择过程的差分进化，以及独立的 CMA-ES。
5. 具有接受概率与温度调度的双重退火，以及局部求解器驱动的盆地跳跃。
6. 使用增益比调整信赖域的 Levenberg-Marquardt。

2026-09-27 路线复核后，优先验证参数化、残差表达、真实光学导数和局部收敛，再根据对照结果决定上述算法的实现顺序。每个新算法必须通过标准基准函数、有界问题、约束问题、固定种子复现、停止条件和函数评价计数测试，并在相同光学问题上验证后，才能加入公开目录。参见 [路线复核](OPTIMIZATION_ROUTE_LITERATURE_REVIEW_2026-09-27.md)。

## 正式程序的变量与默认评价

2026-09-27 起，单面半径优化和标记变量优化均使用共享 Core 的 `SurfaceCurvatureParameter`，内部变量为曲率（1/mm），零曲率表示平面。变量创建不再把平面改成 +40 mm，连续变化可以经过平面改变曲率符号。默认曲率范围为 `[-extent, +extent]`，其中 `extent = max(0.025, 2 × |起始曲率|)`；这是当前局部搜索范围，不是制造或光线可达性约束，也不是全局搜索保证。目前尚无该范围的独立编辑界面。既有零厚度或负厚度保留在厚度变量范围内，不在入口强制改为 0.001 mm。

单面动作、以及没有有效评价行的标记变量动作，复用 `CreateDefaultRmsSpot` 生成的逐光线有符号 X/Y 质心像差操作数（3 环、6 臂 Gaussian quadrature，各定义视场和全部波长）。临时默认操作数不会写进评价函数编辑器；已有有效评价行继续按原定义执行。报告的 merit 是 Core 的加权归一化残差平方和，不是一个 RMS 半径读数，也没有自动附加焦距、F 数或制造约束。`BestVariables` 中这些曲率变量的单位为 1/mm；文档、界面和单面动作结果仍显示半径。

`CreateOperand`、`CreateOperands` 和独立批量评价对不可用值抛出带操作数名称与原因的 `OptimizationEvaluationException`，不再用固定大数替代。无效起点直接失败；DLS 对无效试探步提高阻尼，并在差分探测失败时尝试反向和缩短扰动。所有探测都失败时明确中止，不能产生零导数。其它公开求解器目前遇到无效评价会中止；应用层仍完整回滚文档和历史，不宣称已具备可行性恢复。

DLS 和动量梯度下降不再把非有限梯度标记为 `GradientTolerance`；残差平方和溢出也立即报错。2026-10-26 起，`Success` 要求初末 merit 有限、不恶化，并且有严格改善、零残差或梯度收敛依据；固定非零残差且无改善不再报成功。梯度诊断仍非完整的约束投影梯度，有改善的有效运行也不等于已达到局部极小值或满足光学用途。原阶段修复见 [实施记录](OPTIMIZATION_ENTRY_FIX_2026-09-27.md)，本轮语义见[续修说明](FULL_RELIABILITY_REPAIR_2026-10-26.md)。

## 运行记录约定

每次优化至少记录：

- 实际算法规范名称与实现版本；
- 停止原因和迭代次数；
- 函数评价次数；
- 最终梯度范数（算法可计算时）；
- 随机种子（随机算法适用时）；
- 兼容别名警告。

取消或异常仍由应用事务回滚，不生成伪造的“完成”结果。

## 桌面执行入口的状态表达

评价函数编辑器“执行优化”、优化向导“生成评价函数”和变量滑块“应用”使用共享 `accent` 主动作样式。取消、重置和恢复初值为次级；主次样式不改变算法、变量模型、计算或取消逻辑。

对比度向导沿用现有条件：空间频率大于 0，且 X/Y 权重至少一项大于 0；条件不满足时生成按钮禁用，原摘要及悬停提示解释要求，恢复合法设置后正常启用。无可调整内部表面时滑块/应用禁用，原状态区域用正常文字说明可用条件。采样/评价类型造成的禁用字段也提供具体提示。详见 [实现与交互验证](PRIMARY_ACTIONS_AND_COMPACT_SIDEBAR_2026-09-27.md)。

## 镀膜实验室的优化调用

内置镀膜模块直接调用正式 `OptimizerCatalog` 的 Damped Least Squares、Nelder-Mead 和 Coordinate Pattern Search；未复制求解器，也未引入上游 DE。模板生成与优化分别执行，模板排名不代表目标达标。变量仅为勾选的膜层物理厚度（nm），固定层保持不变；厚度上下界由正式变量接口约束。

每次运行使用冻结材料/输入，记录实际算法、版本、停止原因、迭代/评价次数与适用的随机种子；当前三例使用 `damped-least-squares/2`。光谱残差由同一共享薄膜求解器计算，最终独立密集复验检查反射率、峰值、FWHM、截止 OD、层数及厚度。梯度阈值或迭代上限不代表指标达标。高反/窄带例的未达标项和本地搜索限制见[验收记录](../validation/coating/README.md)。

## 镀膜结构搜索 · 2026-09-28

“2 优化”保持局部变量厚度优化；新增独立“结构搜索”在层数/厚度约束内排序模板、反转、尾部增删与 H/L 替换，再按有限起点预算调用已选正式优化器。固定层存在时禁用结构变化。模板用尽后采用有种子的厚度扰动起点；不宣称 DE、全局最优或针插入。每个候选都密集复验，优先选达标者，再按 merit 排序；停止原因与物理达标分别记录。完整边界见[镀膜实现](COATING_DESIGN_LAB.md)。

## 多配置单元格联合变量（2026-10-03）

## 多配置拾取与候选一致性（2026-10-03）

四类数值单元格的 P 拾取在独立候选配置图内求值，顺序覆盖 MCE 拾取、镜头表拾取、基准链接和像面后焦距求解。循环或非法结果明确拒绝；自动半口径来源必须先固定或设为变量。联合变量与单面半径优化采用同一依赖路径，并以最终配置重算核对报告的评价值。优化后及时解除活动配置存储别名，避免后续增删面被执行两次。源行重排、配置复制和保存规则见[本批记录](MCE_PICKUP_SOLVES_2026-10-03.md)。
