# 镀膜工作区停靠与布局实施计划

更新日期：2026-11-02。用户已确认按此计划改进 C# 镀膜界面。目标是让膜系编辑器、光学评价、堆栈几何、设计结果四类面板支持停靠、浮窗和布局保存恢复，同时沿用现有计算逻辑、材料数据和验收标准。

## 对照与范围

交互参考仓库固定的 TFStudio `8b942b3`：标签排序、中央合并、四边分栏、方向指引和落位预览、拖出浮窗及拖回、保存停靠树与浮窗位置。参考文件包括 `TabGroup.js`、`useTabDrag.js`、`dropZones.js`、`FloatFrame.js`、`layoutStorage.js`；归档和许可见[参考源说明](../third_party/coating-reference/README.md)。

C# 复用产品已有的 Dock 组件与内容宿主。镀膜使用独立的布局身份和设置文件，不与镜头工作区相互移动面板。默认显示编辑器和光学评价；堆栈、候选与指标公差从原入口或“窗口”菜单打开，保留专用页面。设计参数窗口继续执行原编辑流程。

本轮不新增优化协议，不改共享 Core 膜层计算、真实 n/k、基板与背面模型、原密集验收或材料有效域。QW/FW 列及更多逐行工具留待停靠工作区稳定后扩展。

后续OT/QW/FW联动、多选历史及独立/联合/对称双面设计已另批完成，见[后续说明](COATING_EDITOR_DUPLEX_2026-11-02.md)及[实施计划](COATING_EDITOR_DUPLEX_PLAN_2026-11-02.md)；不回写本停靠阶段原验收计数。

## 状态与持久化约定

同一实验的面板移动、浮动、关闭重开、重排和恢复布局均复用同一份控件与编辑状态，不触发光谱重算，不序列化计算结果来维持多个副本。堆栈剖面仍通过原快照更新，固定绘图与完整PNG尺寸保持。

“保存布局”显式保存当前工作区到独立的 `coating-workspace-layout.json`。后续打开镀膜工作区恢复最近保存的布局，也提供手动恢复。重置恢复默认左右面板，不修改实验；再次保存前不覆盖原保存的布局。

布局只记录面板身份、结构和窗口几何，不写入膜层处方。恢复前校验版本、允许的节点类型、唯一面板身份和规模，再绑定当前控件；损坏或不适用的文件保留当前布局并反馈原因。浮窗按可用屏幕和缩放率修正，避免恢复到已拔掉的显示器之外。

## 验证与完成条件

使用后台离屏窗口与真实指针事件验证标签和方向指引，使用布局往返与窗口边界用例验证保存恢复。检查明暗主题、大字号、中文/英文/日文、窄窗口、全部面板关闭/浮动后的恢复和未保存关闭的保存/放弃/取消分支。

复跑受影响的镀膜操作与主程序共享停靠检查，保留有用的失败记录和当前预览，不复制整套运行时或源码。原生跨屏交互若未实际验证，在交付记录中列明；构建成功不代替交互验收。
