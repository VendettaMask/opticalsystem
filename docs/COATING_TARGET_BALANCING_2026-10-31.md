## 查明的问题与修正

上一阶段的逐项保护已经挡住相对输入的目标超限退步，但保护残差按起点超限归一化，原目标方向仍按原尺度累积。对不同大小的未完成超限，优化方向与保护的尺度不一致，部分预算改善增广目标，却很少产生可保留的物理改善。

当前 `target-violation-envelope/2` 对未完成项先用起点超限 `s_i` 归一化目标残差 `g_i / s_i`。一阶段没有改善受保护的指导候选时，最多一次回到已保留的最好膜厚，清除该方向的乘子，以 `g_i / sqrt(s_i)` 继续。这对应原无量纲目标中 `sum(g_i² / s_i)` 的方向，在起点给各项相同的一阶边际系数。已完成项使用单位尺度；目标边缘辅助行保持原尺度。两种方向使用同一剩余迭代预算，用户原目标值及逐项候选上界不变。

另查明指导峰位不一致：约束方向采用 Core 的局部三点峰位估计，候选保留却用粗采样最高点。冻结双腔试探中，粗最高点在中心门槛内，密集峰位却为 `550.526756 nm`，越过 `550.5 nm`。现在保护阶段的指导评估和保留排序都用同一个 Core 峰位估计；最终验收、密集逐项保护仍使用原正式采样峰位，没有改门槛。该试探不再升级为指导最好结果；本输入仍未找到可保留改善，不能把内部一致性修正算成它已经优化成功。

新增可选结果字段 `GeneralWork.TargetDirectionRestarts` 记录实际方向恢复次数；单次局部优化为0或1，顶层搜索可累计多个局部工作。它不是新增迭代预算。`BandMetricEvaluations` 也包括这条路径实际执行的候选指导指标批次；导数批次仍是其中子集。旧记录缺字段保持零，输入指纹及 schema 1 不变。

## 中间结果与剩余范围

- `probe-1`的纯起点比例方向改善部分双腔，但单腔续算没有进展；`probe-3`的单一平方根尺度又阻塞了另一个单腔。保留这两种失败，最终没有按样例选权重。
- `probe-2`在构建未成功后误启动了旧二进制，已终止该任务进程，结果不计入有效比较。
- `probe-4`和`probe-5`保留不同通用恢复条件的试算，最终采用一次阶段停滞恢复。
- 初次新增测试错误地将`ir-absorbing-s`的旧输出当成未达标；实际旧输出已达标。失败TRX保留，回归改用冻结真实单/双腔的实际OD收益；红外项不计作新达标。
- 第一轮156项全回归与41组结果保留为初始阶段。此后指导峰位一致性修正重新执行受影响路径、41组新臂及最终完整范围；不把这些重复执行相加为不同用例数。

当前仍未补齐真实高反98%、窄带75%峰值及15±1 nm宽度；保护、方向归一化和指导一致性都不等于这些规格已经达标。结构族受现有模板和局部厚度变量限制，不证明任意规格存在可行解，也没有引入按材料或膜层打补丁的结构。
