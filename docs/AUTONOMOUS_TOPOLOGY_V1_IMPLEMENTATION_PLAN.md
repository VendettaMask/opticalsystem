# 自主镜头拓扑设计实施计划

版本：1.2。建立日期：2026-10-26。状态：M0 至 M2 已完成，M3 至 M6 待实施。

本计划用于在现有 AI 初始结构内置模块中建立可执行的镜片增删设计流程：生成或导入起点，修改镜片数量，恢复一阶光学特性，执行补偿优化，再按原始设计要求独立验收。后续实施以本计划的阶段看板和验收门槛为依据。

用户已授权开始实施。首批交付基线与拓扑基础层，按下方看板继续；用户此前停止的 AutoLens 完整训练继续保持停止。

## 1 目标与首版范围

首版采用独立编排身份 `AutonomousTopologyV1`。它复用 AutoLens 的起点生成和连续优化基础能力，采用结构变更后的近轴恢复、有预算的多候选搜索，以及直接删除失败后的渐进删除。现有 `UpstreamE58` 的算法身份、默认行为、迭代协议、检查点和数值参考保持独立。

| 范围 | 首版约定 |
| --- | --- |
| 产品集成 | 现有主程序内的初始结构模块；纯 C#/.NET，共享 Core，无独立光学进程 |
| 首批光学系统 | 无限远物方、同轴旋转对称、顺序透射、均匀介质、圆形物理口径；球面和支持范围内的偶次非球面 |
| 首批镜片模型 | 空气分隔的双面单片，机械参考平面、独立光阑和像面单独建模 |
| 最早闭环 | 增片、删片、近轴恢复、局部补偿、全目标优化和独立验收 |
| 后续首版能力 | 自动候选搜索、取消恢复、渐进删除、拆片并片、目录材料与面型分支、界面和同预算对照 |
| 有限共轭与胶合组 | 分别列为扩展能力；支持模型、导数和验收明确建立前，返回具体不支持原因 |
| 算法边界 | 首版不同时引入强化学习、光学 Agent 或完整 RESTORE/MCMC 采样器，不称为这些算法的完整复现 |

有限物距的 AutoLens 处方不能直接作为首版无限远任务的接续状态。若采用其几何形状作为新任务种子，必须显式声明新的共轭、重新编译、清空优化状态并重新评价；原有限共轭成绩不能随之继承。

## 3 模块划分与数据流

流程顺序为：起点生成或导入 → 拓扑编译 → 结构变更 → 检查与近轴恢复 → 局部补偿 → 全目标优化 → 筛选与候选归档 → 独立验收。

| 拟新增模块 | 责任 | 所属位置 |
| --- | --- | --- |
| `DesignTopology` 及操作契约 | 稳定 ID、绝对位置、保护标记、过渡状态和操作结果 | InitialStructure.Contracts |
| `TopologyCompiler` | 拓扑与 Core 快照互转、介质和物理口径建立、ID 到面序号映射 | InitialStructure.Engine |
| `TopologyParameterBinder` | 按当前结构、阶段和权限建立参数身份、尺度、上下界与指纹 | InitialStructure.Engine |
| `FixedTopologyOptimizer` | 从当前支持处方优化允许变量，返回工作量、终止原因和评价 | InitialStructure.Engine |
| `ParaxialRestorer` | 采用 Core 一阶量和有界求解，恢复子结构的一阶聚焦行为 | InitialStructure.Engine |
| `TopologyOperators` | 插片、删片、拆片、并片、渐进删除及保护规则 | InitialStructure.Engine |
| `TopologyValidator` | 对实际编译结构执行固定筛选协议和独立最终验收 | InitialStructure.Engine，计算调用 Core |
| `AutonomousSearchService` | 父子分支、调度、候选池、预算、失败记录与检查点 | InitialStructure.Engine |
| 检查点及界面适配 | 新身份保存恢复、谱系显示、取消、候选复验与导出 | 现有 Persistence 和 App 模块 |

Core 负责追迹、交点、法线、折射、色散、近轴矩阵、光斑和净空等通用计算。实验室负责结构操作、参数选择、任务残差、调度和验收组织。需要新增通用光学能力时，先补 Core 并在 Core 中验证，不在实验室复制公式。

## 4 拓扑与参数契约

### 稳定身份和坐标

镜片至少保存 `Id`、`FrontSurfaceId`、`BackSurfaceId`、`FrontZ`、`Thickness`、`ClearSemiDiameter`、`Material`、前后面型及 `Protected`。非球面按显式幂次保存，例如 `{ Power = 4, Coefficient = ... }`，编译时转换为 Core 系数索引，r² 不与 r⁴ 混用。

镜片级 `ClearSemiDiameter` 作为名义口径，前后面还须分别保留物理口径和机械尺寸，避免丢失已有处方两面不同口径的信息。首版优化范围为 r⁴–r¹⁸，r² 固定为零；含非零 r²、偏心倾斜等超出首版契约的输入须明确拒绝。

机械参考平面、光阑和像面拥有独立身份和绝对坐标。插删瞬间保持所有未修改元件、参考平面、光阑和像面的坐标不变；后续优化只调整显式允许的坐标。首版近轴恢复固定参考平面和像面。

必须分别报告机械参考平面到像面的长度，以及第一片真实透镜到像面的光学总长。删除第一片后，不能继续用原固定长度冒充两者。

编译结果至少包含 Core 快照、镜片和表面双向映射、真实元件计数、材料来源、物理口径、参考平面和结构指纹。Core 面序号仅作为本次编译索引，不承担稳定身份。机械参考行若编译成不裁光的零光焦度参考面，不计为真实镜片。

### 编译和导入约束

- 父处方与父拓扑保持不可变，子分支深复制后编辑。
- 每个物理半口径必须建立实际物理口径，不能只填显示或机械半口径。
- 按 Core 接口同步每面前后介质、色散、坐标、编号、光阑和像面；更新后使追迹缓存失效。
- 面序穿越或碰撞不能靠隐式排序修复；按固定参数身份拒绝当前尝试，或使用事先明确的间隙参数化。
- 无限远物方以 Core 的正无穷 Object 厚度语义表达，零厚度不表示无限远。
- 实际 F 数采用真实瞳与光阑计算，不靠把孔径配置设为目标 F 数来伪造达标。
- 支持导入的处方须有无歧义的镜片和表面映射；未知拓扑、共享胶合界面或不支持的共轭须显式拒绝。
- 最终结构使用允许的真实目录材料；连续材料若作为探索变量，必须标记阶段，投影后重建状态并重新验收。

### 参数与优化状态

参数身份由稳定表面 ID、参数种类和非球面幂次组成。变量表同时记录尺度、边界、是否保护、所在阶段及 Core 面序号，读取和应用统一经 `OpticalDesignParameters`。

结构、材料、面型、变量集合、采样或残差定义改变后，重新建立参数映射、自动微分映射和求解器状态。首版不迁移旧 Adam 矩，不用旧数组位置猜新参数，也不复用旧雅可比。阶段内部的取消恢复须校验完整指纹。

## 5 结构操作规范

### 插片

先枚举允许的空气区间；独立光阑或受保护参考面将区间分开。对区间左右坐标 `zL、zR`，厚度 `t` 和最小空气隙 `gMin`，仅在 `G = zR - zL >= t + 2*gMin` 时生成候选。位置由 `eta ∈ [0,1]` 控制：

```text
a = gMin + eta * (G - t - 2*gMin)
b = G - t - a
frontZ = zL + a
backZ = frontZ + t
```

首版插入有实际厚度的弱作用镜片。少量位置、允许材料、弱正负光焦度和弯曲形式构成受预算的分支。`alpha = ±0.03、±0.10` 等只作为待校准的初始化参数，不作为已验证最优值。

初始化曲率通过 Core 或现有共同设计能力生成；近似关系只用于初猜，真实厚透镜光焦度、边厚和相邻曲面间隙均经 Core 计算。空间足够不能替代曲面碰撞检查。

### 删片

为每片非保护镜片生成独立试删分支，删除后保留其他全局坐标。原前间隙、片厚和后间隙自然合成新空气区间。不得删除独立光阑或保护元件，不得低于任务规定的最少片数。

删片后依次重建映射、近轴恢复、邻片补偿、全目标优化和原要求验收。按补偿后的结果判断分支价值，不能仅按刚删除时 RMS 或最低单片光焦度决定删除位置。

### 拆片与并片

M5 前明确并固定操作语义。首版拟将拆片定义为在允许轴向包络内把单片替换为两个有实际厚度的空气分隔单片，并片定义为将相邻且无独立光阑夹入的两片替换为一个允许材料的单片。两者均保持未修改元件的身份和坐标，新增、保留和删除 ID 写入谱系。

胶合与上述并片区分。若后续支持共享胶合界面，需增加相应组模型、单一界面身份和非空气介质连接，不能用两张无关表面或伪参考行冒充。

### 渐进删除

直接删除未能恢复时，才启动渐进删除。保存原始目标片快照，按 `s = 0.7 → 0.4 → 0.2 → 0.1 → 0.02 → 实体删除` 的起始日程推进；厚度、曲率和每项非球面系数均由原值乘以本阶段 s，不能对上一步重复缩放。

目标片标记为 `Transition`，仅该片获得明确的临时厚度例外；其他元件制造约束保持。每阶段固定目标片的规定缩放状态，让允许的其他变量承担补偿。最后实体删除，清除例外，再执行全部原始约束和独立验收。过渡结构可作为探索检查点保存，不得发布为合格设计。

## 6 近轴恢复规范

### Core 矩阵接口

先为现有 Core 近轴实现增加只读接口，返回约定参考平面到像面的 A、B、C、D、输入输出介质信息和参考坐标。明确高度/斜率单位、传播方向、矩阵乘法顺序，以及最后一面到像面的传播是否包含。复用现有矩阵计算，实验室不另写近轴引擎。

首版按 Core 的高度与斜率约定建立契约；如果改用约化角 `n*u`，由 Core 提供明确转换并独立验证，不能混用。首片删除后，矩阵仍从固定机械参考平面计算。

CMU 原文使用不同的光线坐标顺序，并在论文模型中不设置独立光阑。本项目保留独立光阑，借鉴其结构变更后恢复一阶聚焦的思路，不直接复制矩阵下标或声称完整算法等效。[论文第 5 节](https://arxiv.org/html/2509.23572v1#S5)

### 残差和最小改变量

记录父结构的一阶参考量。统一约定后，可采用以下无量纲量恢复无限远轴向聚焦：

```text
G(q) = [ A_img(q), f_target * C_img(q) ]
r(q) = G(q) - G_parent
```

刚完成结构编辑的子结构定义为 `q0`。优化变量已按物理尺度归一化，恢复目标为：

```text
min || r(q) / tau ||² + eta * || q - q0 ||²
subject to bounds and protected-coordinate constraints
```

父子参数维数可以不同，最小改变量项始终围绕子结构 q0，不能相减父子参数数组。tau、eta、变量尺度和容差写入计划与指纹，M0/M3 使用短程数据校准并记录，不能默认为通用常数。

优先释放邻片曲率和允许的间隙，必要时再扩大到全系统允许变量。新插片形状可在第一次恢复中冻结。使用有界信赖域求解；恢复成功只表示一阶量满足恢复容差，后续仍须真实追迹和像质验收。

### 恢复终止信息

至少区分 `Recovered`、`RankDeficient`、`GeometryBlocked`、`NoParaxialRecovery`、`BudgetExhausted`、`Cancelled` 和不支持的输入。记录初末残差、参与变量、接受步、函数/导数探测和工作量。恢复失败不等于该设计规格物理无解。

## 7 任意固定拓扑优化与验收

`FixedTopologyOptimizer` 输入当前编译处方、稳定映射、允许变量、原始目标、阶段和预算。输出新快照、实际工作、终止原因及原目标下的评价。首版连续更新复用 AutoLens 的求导和 Adam 基础；近轴恢复中的通用信赖域属于内部求解组件，不重新暴露旧的桌面搜索算法选项。

一个阶段内，残差维度、行顺序、归一化、字段含义和采样协议固定。至少覆盖焦距或任务要求的一阶量、实际 F 数、各视场多色像质、畸变、通光、中心和边缘厚度、空气间隙、机械长度/光学总长、后工作空间及曲面有效域。

多波长像质使用共同参考以保留横向色差，不能各波长独立居中后称为消色差。正式评价使用 Core 的定义；AutoLens 专用 detach/绿色参考等若用于训练，保持实验室专用身份，不混入普通分析。

对失效光线保持残差布局和有效性记录。有明确净空诊断时采用对应连续惩罚；无有效交点或导数时，拒绝本次尝试、回退或转入恢复，不能删除残差行让目标虚假下降。

边界处理必须满足：

- 正式口径与验收采用 Core 的边界约定，训练层若采用其他约定须单独标识。
- 近临界折射的数值策略须有固定输入回归，不能通过修改共享物理定义来掩盖差异。
- 单条奇异导数可使当前评价不可用，但不能让外层搜索无记录地崩溃；已消耗工作仍计费，分支按规则拒绝或恢复。
- 记录真实 CPU/CUDA 后端和回退原因，不把 CPU 回退计为 GPU 执行。

最终验收由 `TopologyValidator` 对实际结构调用共享 Core，采用明确的原目标、原口径、全视场、波长和独立检查。初始协议沿用现有 21 视场、10×32 面积积分瞳及边界/中心检查的组织方式，并核对支持范围和任务语义。合格、可追迹、未达标和过渡状态分别保存；训练目标、近轴恢复或搜索排名不能代替验收。

## 8 自动搜索的预算和恢复

外层采用有界多候选搜索。每个父结构只派发少量子分支，记录尚未尝试的操作和位置。起始调度可采用每片数最多四个候选、每父结构每轮最多六个子分支；这些是可配置且待标定的上限，不是论文保证。

| 当前状态 | 优先动作 |
| --- | --- |
| 几何或追迹不成立 | 几何和一阶恢复 |
| 同一目标下仍持续改善 | 继续允许的连续优化 |
| 像质停滞且未达标 | 增片、拆片、材料或面型分支 |
| 已达标且有余量 | 删片、并片或降低复杂度 |
| 达到片数上限 | 在允许范围内重分配光焦度、材料和面型 |
| 起点与候选缺乏差异 | 增加不同的合法结构起点 |

已经独立验收达标的结果永久独立归档，探索分支不能覆盖。各操作、恢复失败、拒步、筛选失败及原因都有日志，不能用无记录的跳过隐藏消耗。

预算同时记录函数评价、梯度评价、真实尝试追迹量、可获得的传播/导数工作和墙钟时间。重采样、差分探测、拒步、目录投影后的复核、CPU 回退及最终验收均按实际工作计费，不将不同规模的一步视作等价成本。预留独立最终验收预算。

初始阶段上限暂采用近轴恢复 30 个接受步、局部补偿 80 步、满目标粗优化 160 步、候选深化追加 400 步。它们与原版 2001+3001 协议无关，仍受总预算约束，不承诺这些步数必然达标。

新检查点使用独立版本，保存原始规格、拓扑和谱系、ID 映射、变量与残差指纹、阶段、随机流、操作游标、候选池、合格归档、优化状态、累计工作和已预约工作。结构变化后清空的状态不能借恢复流程重新继承。保存采用有界原子写入；中断的未知工作保守计费，已知零工作按现有规则退还。恢复不能改变历史算法身份。

界面加载配置或计划不自动运行。用户取消后在安全边界保存，不能自动恢复已停止的旧长跑。

### 12.1 M0/M1 已交付契约

代码入口为 Contracts 的 `DesignTopology`，Engine 的 `TopologyValidation`、`TopologyCompiler`、`TopologyParameterBinder` 和 `TopologyOperators`。小型输入保存在 [autonomous-topology-v1](../labs/InitialStructure/benchmarks/autonomous-topology-v1/README.md)，命令、TRX、Core 快照、材料与二进制指纹保存在[本阶段证据](../validation/rechecks/2026-10-26/autonomous-topology-foundation/README.md)。

模型使用不可变记录与集合。每片镜片、前后面及独立参考/光阑/像面具有唯一 ID；前后面分别保存有效及机械半口径。`Compile` 显式建立每个物理口径及空气/真实目录玻璃介质，不依赖显示半径产生裁光。Core 坐标采用机械参考归零，`GlobalToCoreZOffset` 明确记录与模型绝对坐标的关系。

`Import` 首次为无映射的 Core 处方分配确定的新 ID；模型 JSON 往返及已有映射的 `Update` 保留原 ID。导入只接收声明的无限远、同轴、独立空气光阑和空气分隔目录单片；有限共轭、胶合、偏心倾斜、活动后焦求解、拾取、未建模面型/镀膜/散射等明确拒绝。玻璃名称相同但完整数据不同也拒绝，不能悄悄改为本机目录版本。

绑定支持各面绝对轴向位置、曲率、圆锥系数和声明阶数内的 r4–r18；r2 固定为零。边界和尺度由调用方显式给出，材料保持目录离散值。参考及光阑固定，像面默认保护，可显式解除；平面改型、材料或结构分支须重编译并重建绑定。映射指纹拒绝跨结构、材料或坐标系复用。

插删是结构编辑，尚不代表补偿或验收通过。插入只占用光阑分割后的实际空气区间，保护首末端间隙和后工作空间；浮点端点向可行区间内取值，不放宽约束。删首片仅改变光学总长，不改变机械参考、像面及保留镜片坐标。暂未实施表面边缘碰撞/厚度的完整物理验收、任意拓扑优化、近轴恢复、自动搜索、检查点或界面。

此批 M0/M1 没有训练更新；后续 M2 的实际交付见下节。M3 再实现 Core 只读完整矩阵接口和实际增删恢复闭环，旧完整精修保持停止。

### 12.2 M2 已交付契约

新增 `FixedTopologyObjective`、`FixedTopologyOptimizer`、`TopologyValidator` 与独立结果/预算类型。按稳定 ID 绑定输入，不再依赖六片或固定族面号；保持目录材料，复用现有 `DifferentiableAdam`，不接旧 UpstreamE58 检查点。新阶段固定模板、变量、边界、残差行、归一化和采样，变化即使用新身份。固定残差包括光焦度、连续逆 F 数、制造/空气间隙、工作空间、机械/光学总长、面型有效域和斜率、各视场多色共同质心像质、主光线畸变及逐光线口径净空。训练中的逆 F 数在零光焦度处保持有限，不把正式报告中未定义的 F 数判作合格。

Core 已补齐显式二维视场和实际光阑尺寸的隐式瞄准求导，公开实际像面的一阶主光线像高尺度，支持跨参考行的轴向面间距，并由 Core 返回多色质心。新增像高尺度明确排除像面之后的占位厚度；未改变现有 Core 焦距或旧协议规则。M3 所需完整 A/B/C/D 接口仍待实施。

本阶段畸变明确采用主波长主光线相对实际像面近轴映射的偏差，由 Core `DistortionMetrics.ParaxialChiefFractionAtField` 提供。它不是现有 Grid Distortion 的实光线拟合参考，也不把目标焦距误差重复算作畸变；两种定义不互称等价。最终光斑仍为三波长共同质心，不独立居中各波长。

最终验收独立使用 Core CPU、每个有效定义视场从轴上到该点的 21 点扫描并去重、Gaussian 10×32、32 个边界点加中心、64 个轮廓径向点。默认样例为 21 个视场；多方向/多定义点可以更多，超过 101 点在训练前明确拒绝。按总有效光线比例、各波长比例和全部边界检查分别验收，过渡片永不合格。原始目标、结构约束、变量和协议/处方指纹随结果保存。

预算有评价尝试、完整梯度、最终验收和墙钟上限；最后一个评价槽预留终验。实际追迹和几何查询记录包含失败、拒步、回退和取消的已消耗工作；未知 GPU 导数计数用 null 表示，不当作零。取消或超时不补跑昂贵终验，返回当前有效结果并明确未验收。硬光线配额、持久优化状态和断点续跑属于 M4，尚未实施。

验证使用显式小预算，三种片数各 20 次更新。三片在本轮目标和独立验收下合格，两片/四片不合格；四片虽然训练目标下降，RMS 反而变差，完整保留失败。三种基准显式允许移动像面；另有固定像面及保护镜片的真实优化回归，不能把可动像面的达标推广为固定像面达标。27 参数、340 残差的全部 9180 个 Jacobian 项通过中心差分；极端目标缩放下的差分分辨率边界仍有失败日志，不宣称任意尺度都已验证。

冻结协议见 [M2 小预算基准](../labs/InitialStructure/benchmarks/autonomous-topology-v1/fixed-topology-m2.json)，数值、命令、快照、工作量及限制见 [M2 证据](../validation/rechecks/2026-10-26/autonomous-fixed-topology/README.md)。本轮未运行旧完整课程或精修。下一阶段 M3 以这些接口接入近轴恢复和实际 N→N+1/N−1 补偿，不以本轮四片输入测试代替增删恢复闭环。
