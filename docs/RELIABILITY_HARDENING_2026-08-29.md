# 可靠性与资源边界加固（2026-08-29）

## 状态

本文记录已实现的防护，不是未来功能清单；当前验证结果见“验证边界”。

## 已实现

- 分析服务按参数描述符校验整数、有限浮点范围、布尔值和选项；未知旧设置会在合并时删除，已知但非法的值明确失败。
- FFT 网格在 Core 分配前限制为最大 `2048 x 2048`；产品 FFT 采样选项最高为 `1024`，安全的次幂计算使用受检位移。
- 图像模拟限制源图、准备图和输出图为单边最多 `4096`、总计最多 `262144` 像素；直接 PSF、单波长 PSF 基底和多波长图像模拟分别具有工作量预算。外部位图先读取元数据再解码，`1 x 1` PSF 视场网格按视场中心真实计算。
- 光学文档、STAROPT、ZMX、STL、分析/公差预设、应用设置、工作区会话、镜头目录、GUI 捕获清单、位图/IMA/BIM、AGF/玻璃库和 ZMF 入口具有读取或解压上限；同步与异步整文件读取复用同一限额入口，避免“先检查、后无边界读取”的文件变化窗口。原生 JSON、Python Optiland JSON、商业文本格式、CAD、分析/公差文本与预设、GUI 捕获清单、位图、玻璃目录/包和光学图纸使用受限流、同目录临时文件、刷新及原子替换发布；取消、磁盘错误或超限不会截断已有目标。超限设置会隔离并回退默认值，超限会话和镜头目录按既有恢复语义降级。唯一实现位于 Core `BoundedFile`；App 只经 Application 的无 Core 类型薄代理调用，避免安全工具造成反向分层依赖。ZMF 元件数在无符号到有符号转换前验证。
- SMIA-TV 无定义或追迹失败时返回明确的数据不可用异常，不再返回伪 `0%`。紧凑分析矩阵保留类型化坐标量与单位，只隐藏重复文字。
- 优化评价、公差准则、图像回退和 CAD Sag 只捕获预期的参数、数值和不支持异常；取消、内存耗尽及未知运行时故障继续向上传播。
- 启动 Splash 到主窗口的切换由返回 `Task` 的协调器驱动，启动完成、主窗口提前关闭、Splash 关闭取消和 `30 s` 超时都会被观察；失败时停留在 Splash 错误状态、显示退出入口并写入本地启动诊断日志，不再在调用 `Shutdown` 后把异常重新抛回 UI 同步上下文。
- 主窗口最小尺寸为 `640 x 480`；公差和优化向导降低固定最小尺寸，优化向导在窄宽度下由双列改为纵向。显示设置窗口可缩放且在短窗口内滚动。分析图、波前表面、光学场景和图纸预览的自动化节点发布只读数据摘要，并提供可调用的视图复位动作。
- 工作区浮动窗口恢复会先处理非有限坐标和尺寸，损坏会话不会把 `NaN` 或无穷值送入 Avalonia 布局；隔离文件名使用唯一后缀，连续损坏不会覆盖先前证据。macOS Objective-C 字符串入口显式使用 UTF-8 封送和不可映射字符策略。
- 异世界主题 Chrome 装饰渲染器缓存尺寸无关的画刷、画笔和其它绘制资源；Ribbon 剑刃几何只在边界尺寸变化时重建，并有主题切换/窗口缩放渲染分配回归测试约束每帧托管分配。

## 顺序追迹与分析

- 光瞳采样最多 `1000000` 条光线，Hexapolar 最多 `576` 环；未知采样枚举和名称明确失败。采样计划缓存只保留最多 `128` 个小计划，大计划即时生成并响应取消，不再永久占用共享缓存。
- 顺序追迹在租用数组前限制输入光线和“光线数 x 保留面数”工作量；共享缓存只有在结果满足自身预算时才建立缓存键和复制数据，重复计算并发写入不会在锁外制造第二份大型副本。
- 通用分析网格、聚合网格、场/波长/光线乘积、波前图和插值工作量具有 Core 级预算。波前最近邻插值复用固定工作缓冲区，不再为每个像素排序并分配数组；网格、拟合和重建长循环响应取消。
- Zernike 类型、PSF 剖面轴向和后焦求解分别由类型化枚举、显式轴选择和像面角色驱动；显示名称、系列标题和英文标签不再选择算法。现有字符串构造入口只保留兼容显示语义。
- Python/Optiland 对齐的非相干照度和辐射强度分析中，`hexapolar` 的 `NumRays` 与上游语义保持为环数，其它采样仍表示采样点数；资源预算按环展开后的实际光线数计算。Zemax Fringe Zernike 拟合采用固定 37 项表语义，对超过 37 的请求按固定 Fringe 表截断，低于 1 仍明确失败；分析结果同时记录请求项数和实际输出项数，避免 UI/API 调用者误解。Standard 与 Annular 仍保持严格最大项数校验。波前图继续接受 `16 x 16` 兼容采样。

## 公差

- 服务入口和公开 Monte Carlo API 统一限制最多 `10000` 次试验；补偿迭代、并行度、有限数值、评价准则、运行模式、表面和操作数在复制快照及分配结果数组前验证。
- 公差表最多 `1000` 行；未知公差类型和概率分布明确失败，不再把未知分布静默解释为均匀分布。界面验证与服务执行使用同一约束，导入或程序调用不能绕过。

## 非序列

- 单探测器最多 `1048576` 像素，启用探测器总计最多 `4194304` 像素，像素数乘系统波长数最多 `8388608`；重建只为实际命中的波长分配数组，热图超过 `262144` 个显示单元时按功率守恒聚合。探测器重建、数值转换、统计和剖面计算响应同一取消令牌；会话切换或清空立即释放筛选及探测器缓存。
- 矩形挖空面源使用直接面积采样；同心比例椭圆使用直接环带采样，普通椭圆拒绝采样有次数和取消边界；小于外形面积 `1%` 的有效发光区会被拒绝。椭球体使用直接体积采样。
- 路径筛选限制为 `4096` 字符、`256` 节点、`64` 层嵌套和 `128` 个 `SEQ` 事件。
- 数据库“检查”和“选择”分离。桌面窗口取消旧读取任务，只有当前代次可以更新分析会话；路径统计使用数据库头对象表。缓存身份直接来自已打开流的长度、数据库头、创建时间、源修订和分支数，不再用第二次路径查询混合两个文件版本。筛选索引最多缓存 `1000000` 项，超过后回退流式分页。
- STARRDB 写入器和读取器共用文件头、分块、索引项和单分支段数上限。写入器按分段预算提前刷新分块，拒绝无法由读取器重开的输出；读取器使用值类型索引、最多 `1000000` 个索引项，并拒绝无序或重叠分块。Brotli 解压写入精确长度缓冲区，不再通过 `MemoryStream.ToArray()` 复制大型分块。
- STARMESH 在编码前验证顶点/三角形数量、有限坐标、索引、退化面和输入缓冲区上限；STL 路径导入在读取前检查 `256 MiB` 上限并返回与缓冲区导入一致的错误语义；解码拒绝未知标志、溢出计数、越界索引和退化面。STAROPT 压缩段直接解入精确目标缓冲区，并拒绝短数据或额外解压数据。
- 光线数据库重建探测器画面时，跨分裂子分支按原始段分支 ID、探测器、面号和累计路径长度去重共享祖先命中，避免非吸收探测器 hit 被每个子分支重复累计。
- 临时数据库所有权只在路径字节完全一致时继承；仅大小写不同的路径按外部文件处理，避免在区分大小写文件系统上删除用户文件。“仅清空”不再依赖无关追迹输入框可解析。

## 实验室功能

智能初始结构实验室仍与正式产品隔离。当前已实现上限为：`10000` 个初始种子、`100000` 次最大评价、`256` 并发、`64` 个波长、`128` 个玻璃目录、`24 h` 运行时长、最大 `89` 度视场、`64 MiB` 运行清单和 `4 MiB` 单候选文件。规格验证会在分配前拒绝非有限或溢出的总长和口径。运行 ID 包含时间、规格指纹和随机熵。保存先在同根目录完整构建暂存树，再一次性发布不可变运行目录；取消不会留下部分运行，重复 ID 不会覆盖旧记录。加载会重新校验 manifest、快照、评价、谱系、候选文件集合和规范化内容哈希，缺失、多余、篡改及仅大小写不同的候选文件都会失败。

实验室解决方案显式包含共享 Core 项目，Release 构建不会再因 solution 外部 `ProjectReference` 解析而把 Core 落到 Debug 输出。
