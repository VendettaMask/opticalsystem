# 本机 Zemax 部分相干成像对比与修正

日期：2026-10-17。主参考为原 `123456.ZMX`，使用本机 OpticStudio 2026 R1 build 260127 Enterprise API 实际补采。源文件 SHA-256 为 `0cd65a2f823baf5079f20f91d8310765899a182a6be72ddac53ede943f2bf75b`，未重存镜头、修改冻结参考或旧门槛；独立 Cooke/Tessar 不在本轮原生调查范围。

## 修正的三类差异

1. **相干源模型不同。** 先行常数 γ 模型是一个合法的离散源族，却不等同于 Zemax 的空间相干函数。Core 现增加 Gaussian `exp(-(dx²+dy²)/α²)` 和带符号的 `sinc(dx/α)sinc(dy/α)`，其中归一化 sinc 为 `sin(πx)/(πx)`，α 和位移使用像面毫米。保留原 Uniform 模型并明确区分，不能把常数 γ 换名为 Alpha。源相位仍以复振幅参与完整互强度求和，负 Sinc 旁瓣没有取绝对值。
2. **物理图像尺度不同。** 原视场高度/自动间距不能直接当作原生 File Size。新增 `FileSizeMillimeters` 表示有效源图在像面的全宽；像素间距为该全宽除以过采样后的有效宽度，保护带不参与分母。与显式像素间距同时输入时拒绝歧义。新增显式峰值归一化选项，用于对应本轮原生相对强度显示；保留原始相对强度选项，未按误差拟合增益。
3. **复瞳面二次插值改变边缘与相位。** Gaussian/Sinc 直接在所需像面间距的傅里叶共轭瞳面追迹，复用共享 FFT 的 OPD 插值、孔径和标量约定，再保留复相位生成响应核。没有从强度 PSF 开平方重建相位。原主镜头 256 采样、0.5 µm 间距的归一化 PSF 最大差从 **0.0010488033276919717** 降至 **4.20070644935322e-11**。Uniform 的原插值路径及既有普通 FFT 行为保留。

原生函数、像面 File Size、过采样和有限截断的定义见 [Ansys 官方说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Partially_Coherent_Image_Analysis.html)。本轮另用原生 Gamma 网格直接核对公式与单位，包括负 Sinc 样本；官方页面不能代替本机数值捕获。

## 捕获契约与失败记录

本机 `PartiallyCoherentImageAnalysis` 没有类型化分析设置。未知 `ModifySettings` 关键字可能返回成功却不改 CFG，因此诊断使用冻结构建对应的 CFG 布局并逐项回读。最终 18 组均核对分析类型、波长、场号、OTF 采样、过采样、补零、函数、α、Fraction、文件全宽、偏振和像差开关，同时要求原生文本成功、一个完整有限网格且无结果消息。测试 fixture 的每个数与原始 API 数组一致，详见证据包中的 `capture-manifest.json` 和 `audit-captures.ps1`。

原生 API 输出图像行按 Y 递增，比较固定采用 `native[N-1-y,x]`。独立 Raw 不对称图验证输入强度 9:3 保持为 1:1/3，并锁定行方向及每侧补零。原生偶数 PSF 的峰在下中心 `(127,127)`，与 Core 有限核锚点按已确认坐标对应。原生网格的 `MinX/MinY` 等字段不能脱离该分析实际定义当作坐标原点；物理间距由源全宽、有效采样及原生文本交叉核对。

设置探测中，错误数据类型槽、未生效的 Alpha 槽及过高过采样产生的空/旧结果均不记为通过。请求 Fraction 为 0.9999、0.99999999 或 1 时，原生回读都钳至 **0.98**；这些输出不能称作无截断或 Fraction=1 的参考。界面启动授权等待超时，未完成截图核对；最终数值依赖 API、CFG 回读、原生文本与 Raw 控制。没有把界面审阅记为原生数值验证。

新测试最初因 `Optic` 命名空间写错而未编译，修正后原生专项先后通过 26 项与 30 项。首轮完整相关集合为 **369/370**：切换为可选原系统波长后，一个示例先遇到照度映射错误，遮蔽了原有膜层相位能力拒绝。已将复瞳能力检查移至照度计算之前；保留原示例及原拒绝原因断言，失败 TRX 单独留档，不并入最终通过数。离线指标程序也曾自动解析到同目录旧 Core，已明确 HintPath 优先，并在输出中记录实际加载 Core 的 SHA-256；失败构建不记为数值结果。

## 保留的数值边界

完整有限源对求和不采用原生 Fraction 的近似相关截断。附加八组对角双点/三点源中，五组最大差低于 1e-9；α=.001 的三点 Gaussian、三点 Sinc 和对角 Gaussian 仍分别为 **1.1768391923960841e-5**、**1.9998684784826304e-4**、**3.588953252275928e-5**。同一源改为 α=.004 后，对角和三点两种函数均达到约 4e-11。原生两种有限宽度加速方式及 Fraction 的影响是后续归因方向，尚未完成逐项隔离；这些三项保留 Difference，未放宽门槛或通过经验截断 Gamma 消除。

原生 Mostly Incoherent 与完整源对求和也未统一：440 nm 同一双点六组的最大差约 **1.67e-5～5.38e-4**，原生两种方式之间本身有非零差异。普通 Incoherent / Coherent 的 FFT 窗口和传递函数控制单独留作诊断，未纳入本轮部分相干接受结果。**18 组通过不等于全部原生图像模式、任意源图或所有镜头精度闭合。**

当前仍为标量、单参考视场等晕、相对强度模型。Gaussian/Sinc 使用与本轮关闭偏振的原生 PCI 一致的发射渐晕振幅及 OPD，排除标量透射；Uniform 保留原追迹功率口径。未认证绝对瓦特、反射/完整矢量/膜层相位、任意互相干矩阵、场变相干、ZBF 复杂输入或全镜头原生矩阵。大规模稠密源的精确源对算法受全波长聚合工作预算约束，可能要求降低源采样/过采样；没有悄悄改用常数相干或非相干图。
