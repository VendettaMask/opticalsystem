## 原因和修正

原生复 FFT 的实部、虚部反变换得到 405 个光瞳节点，包含四个对角边缘点；复振幅模方与线性 PSF 的最大差为 3.33e-16。冻结旧 Core 的理想 PSF 能量校验对应 401 个节点，最终 Core 对应 405 个节点。通光条件、镜头处方及曲线积分没有改变。

扩展单波长路径先形成归一化频率间隔 `sqrt(1/N)`，再除以光锥截止频率得到像面间距。此前把平方根移入已舍入的分母，使用 `1/(cutoff*sqrt(N))`；在 128 档这会改变对角临界节点。默认 FFT 网格缩放仍保留原顺序，横纵方向平均 NA、四条边缘 NA 的精确 RMS 舍入、系统主波长参考球面均保留。32 档、真正复色共用网格及完整光锥不可用时的路径没有调整。

这是通用采样运算顺序的兼容修正，由本机同设置控制验证；不声称获得了原生程序内部源码或所有临界网格的通用规则。共享 Core 仍为纯 C#/.NET；没有按文件名选择运行时分支、读取参考曲线、加入拟合系数、放宽孔径或容差。离线 Python 脚本只分析 Core 输出的标量及等价算式，不承担产品光线追迹或运行时计算。

原 **48/48** 组与上一轮 **6/6** 份有效独立控制继续通过原门槛。Relay 64/128、Offner 64 的关闭身份与所有既有回归保持。
