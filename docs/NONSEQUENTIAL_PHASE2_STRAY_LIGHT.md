## 实现状态

本阶段已经形成独立的杂散光基础链路：

`STL 机械对象 → 非序列分支追迹 → STARRDB 光线数据库 → 路径筛选/统计 → 3D 布局与探测器重建`

实现参考 Zemax OpticStudio 的工作流，但不复制其专有文件格式。Workbench 的 `.starrdb`、筛选语法和 STAROPT 网格资产均为自有格式，不声明与 ZRD、NSC 或完整 Zemax Filter String 兼容。

## STL 网格对象

对象编辑器提供“导入 STL”，支持 ASCII 和 Binary STL。导入窗口要求明确源文件单位，支持毫米、厘米、米和英寸；数据进入工程前统一转换为毫米。单个输入文件或字节缓冲区上限为 `256 MiB`，路径导入会在整体读取前检查长度。网格对象保存稳定 `MeshAssetId`、吸收/镜面反射/折射行为、材料和双面相交设置。

导入在临时数据中完成以下验证：

- 有限坐标和最多 `2,000,000` 个三角形；
- 按模型尺度容差焊接顶点；
- 删除退化和重复三角形并重新计算几何法线；
- 检查共边流形、闭合、连通、可定向、自相交和有向体积；
- 闭合网格整体朝向反转时统一翻转到正体积；
- 建立三角形级 BVH，用于导入自相交筛选和运行时最近交点。

开放网格可用于双面吸收或反射。折射网格必须闭合、流形、连通、可定向、无自相交且具有正体积，否则对象事务整体失败。精密球面、非球面和标准镜片仍应使用原生参数对象；STL主要用于挡板、镜筒、支架和其他机械杂散光结构。

## STAROPT 内嵌资产

当前 STAROPT 容器版本为2，工程负载版本为6（新增单元格变量，详见 [变量记录](MCE_CELL_VARIABLES_2026-10-03.md)）。加载器继续接受容器v1和负载v1/v2/v3/v4/v5：负载v1迁移为空非序列场景，负载v2按第一阶段规则恢复独立文档，负载v3恢复内嵌网格资产，负载v4增加扩展原生光源。

容器v2保持原有52字节工程清单头，随后保存：

1. Brotli压缩的UTF-8工程清单；
2. 每个网格资产的64字节头；
3. Brotli压缩的规范化 `STARMESH` 顶点/三角形数据。

网格资产使用规范小端二进制格式和 SHA-256 内容寻址。同一内容在一个工程内只保存一次；删除或改变最后一个引用对象时会清理未使用资产。加载时交叉检查清单、资产ID、长度、解压上限和固定时间哈希。最多保存 `4,096` 个资产，总解压大小上限 `512 MiB`。保存仍使用目标目录临时文件和原子替换，失败或取消不会破坏已有工程。

## 分支输出和 STARRDB

追迹请求支持四种输出模式：

- `LayoutSample`：确定性保留最多指定数量的分支供3D布局；
- `InMemory`：保留最多 `MaximumRetainedBranches` 个匹配分支，适合小规模分析和测试；
- `RayDatabase`：通过 `INonSequentialTraceSink` 流式输出，不保留完整光线树；
- `SummaryOnly`：只返回探测器和能量平衡。

`.starrdb` 是独立的版本1二进制数据库。文件头保存场景SHA-256、工程修订、UTC时间、毫米单位、波长、对象表、追迹设置、随机种子和保存筛选。每512个分支形成一个Brotli分块，分块带SHA-256；文件尾保存随机访问索引和完整完成标记。缺少文件尾、截断、长度不一致或分块哈希失败会被明确拒绝。

应用在目标目录写临时数据库，只有追迹、分块索引和刷新全部完成后才原子替换目标。取消和异常会删除临时文件并保留旧数据库。未指定用户路径的分析自动使用应用管理的临时数据库；替换会话、打开外部结果、切换工程或关闭应用时回收旧临时文件。打开数据库时比较当前场景哈希：不一致的结果仍可只读分析，但界面显示“结果已过期”。数据库头继续为v1兼容布局，并可选记录新追迹的分裂模式；旧文件缺少该字段时由原Fresnel设置推断。

## 路径筛选和联动

统一筛选器支持：

- `Qn` 源对象、`Hn` 命中、`Rn` 反射、`Tn` 透射、`Dn` 探测、`Mn` 未命中；
- `Wn` 系统波长；
- `A` 吸收、`E` 逃逸、`X` 阈值/上限/无效终止；
- `!`、`&`、`|` 和括号，优先级依次为 `!`、`&`、`|`；
- `SEQ(...)` 有序子序列，例如 `SEQ(Q1,H3,R3,D8)`。

语法忽略空白且不区分大小写。非法标记、缺失编号和括号错误会报告从1开始显示的字符位置。依赖完整路径的条件在分支结束后求值，再决定是否保留或写入。

解析器当前限制为 `4096` 字符、`256` 个表达式节点、`64` 层嵌套和 `128` 个 `SEQ` 事件，超限会在构造递归树或执行筛选前明确失败。

路径分析按对象、面、交互和终止原因分组，报告射线数、功率、占比、最小/平均/最大光程、波长计数和目标探测器，并生成可再次使用的筛选表达式。每个 Fresnel 终端分支包含完整祖先路径，每次探测器穿越都产生 `D` 事件；共享祖先探测命中通过原始段分支 ID 去重。独立分析服务把数据库和筛选保存为当前非序列分析会话：

- 3D布局从匹配分支中确定性读取最多2,000条路径，没有会话时只显示对象；
- 探测器查看器流式扫描全部匹配分支并重新累计各波长、指定源的位置/角空间功率与命中数；位置辐照度按像素面积、角度辐射强度按每个角像素实际立体角归一化；
- 探测器显示支持颜色表、自动/手动范围、峰值/总和归一化、对数、0至8像素方框平滑、任意行列剖面、像素读取和当前视图PNG；显示变换不修改物理累计数组，CSV始终导出原始物理值；
- 新建或打开另一工程时清除该会话；普通处方修改保留只读数据库并通过场景哈希显示过期状态。

## 桌面入口

非序列功能区提供：

- 光线追迹组：追迹控制和单光线追迹；
- 探测器组：探测器查看器和清空探测器；
- 光线数据库组：数据库查看器和路径分析；
- 布局组：非序列3D布局。

追迹控制支持全部或指定光源、对象分析数量或临时覆盖数、随机种子、段/分支/能量限制，以及无分裂、完整Fresnel和Simple Stochastic。探测器、数据库与路径读取完整分析会话；3D读取独立、有界且固定种子的布局会话，避免打开布局覆盖分析结果。探测器、数据库和路径窗口不会启动追迹；非序列3D窗口会在打开或当前布局过期时自动准备布局光线，用户也可点击“准备布局光线”强制刷新。旋转、缩放和显示选项只重绘已有布局会话。场景变化后过期布局光线默认隐藏，显式查看时显示红色警告。对象数据页继续负责导入STL及单位、行为、材料和双面选项，不再放置重复分析入口。

3D网格显示最多确定性抽样50,000个三角形，不影响追迹使用完整网格。数据库的百万级光线不会整体载入3D页面或探测器内存；3D只取上限样本，探测器只保留像素累计数组。数据库无筛选分页直接使用分块索引读取范围；路径分析建立的筛选结果保存物理分支索引供后续分页复用，数据库读取和探测器重建在桌面端后台执行并丢弃过期 UI 请求。

数据库后台读取现已把“检查”与“选择为当前会话”分开：窗口取消旧代次和关闭后的任务，只有最新结果可以选择会话。路径统计使用文件头对象表解释对象编号；缓存身份取自同一个已打开流的长度、数据库场景哈希、创建时间、源修订和分支数，不再把已读内容与第二次路径元数据查询混合。筛选匹配索引最多缓存 `1000000` 项，超限后分页回退为可取消流式扫描。

矩形探测器单个最多 `1048576` 像素，全部启用探测器总计最多 `4194304` 像素，像素数乘系统波长数最多 `8388608`。重建只为实际命中的波长分配位置/角度数组；分析热图超过 `262144` 个显示单元时执行功率守恒聚合，不改变数据库或探测器原始累计值。显示平滑使用O(N)积分图且半径硬限制为8像素；归一化、对数和剖面只重算当前显示副本。数据库扫描、重建、数值换算和物理统计共用取消令牌；清空或切换会话会释放旧筛选和探测器缓存。

STARRDB 写入和读取共用 `100000` 单分支段数、`256 MiB` 分块以及 `1000000` 索引项上限。写入器按段数预算分块并拒绝不可重开的输出；读取器以值类型保存索引，拒绝无序或重叠分块，解压只保留一个精确长度输出缓冲区。临时结果所有权只在路径字节完全一致时转移，仅大小写不同的外部路径永远不会继承删除权限。
