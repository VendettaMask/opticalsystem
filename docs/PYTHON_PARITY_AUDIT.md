# Python Optiland 兼容性审计

首次审计：2026-07-11

当前状态：2026-08-04

## 审计基线

- 源码结构参考：PyPI `optiland 0.6.0` 源码包，以及 `optiland/optiland` 仓库的 `v0.6.0` 标签（提交 `f854a0bf5145f7931a40a3da77191c2b3e955745`）。
- 文档交叉检查：Optiland ReadTheDocs 开发文档；审计时页面标记为 `0.5.8`。
- 可执行数值基线：固定 `optiland==0.5.8`，使用 Cooke Triplet、Tessar Lens 和专用生成器夹具。
- Zemax 基线是另一套合同，只用于明确记录的 ZMX 导入和分析配置，不得与 Optiland 兼容结论混用。

## 结论

.NET 实现不是 Python Optiland 的完整数值或行为替代品。

当前实现已经覆盖标准顺序追迹路径、Python JSON 的已声明子集，以及一批具有源码派生金标准的分析方法；优化、公差、可视化和中文 Avalonia 工作台也已具备可用流程。兼容性必须按“方法 + 设置 + 固定夹具”声明，不能对整个仓库笼统声称完全一致。

任何新增兼容声明都必须同时具备：固定的 Python 版本、可重建的生成器输出、.NET 点值/像素/参数比较，以及不支持类型的显式失败行为。

## 已对齐的主要能力

- 归一化视场/光瞳追迹 API、微米与纳米单位边界、逐面追迹记录。
- 角度、物高、近轴像高视场，以及 Zemax 实像高的独立求解路径。
- 标准顺序系统中的几何相交、材料传播、孔径裁剪、相互作用、OPL/OPD 累积。
- Cooke/Tessar 固定夹具覆盖的光斑、能量、波前、像差、PSF、MTF、辐射度和部分扫描分析。
- Python JSON 中已声明的系统孔径、视场、波长、若干面型、材料、物理孔径、渐晕、切趾、薄透镜、相位、衍射和简单镀膜字典。
- 分析参数编辑、设置持久化、多分析页面、复制/关闭和结构化图表/数据/文本结果。

这些条目只表示已测试子集，不表示所有默认值、替代算法或对象组合均与上游一致。

## 主要差距

### 光学对象模型

Python `Optic` 通过统一更新器协调孔径、面组、视场、波长、近轴量、像差、偏振、切趾、拾取和求解。Workbench 具有相近入口，但尚无完全等价的 `OpticUpdater`，偏振、拾取、求解以及部分自由曲面和镀膜对象仍不完整。

后续应先建立统一更新路径，再扩展对象种类，避免不同入口各自刷新几何或近轴状态。

### 光线追迹

当前公共追迹合同已验证，但内核仍以托管 `RealRay` 集合为主，不是 Python 的后端数组执行模型。GRIN 曲线传播与曲面求交尚未完全合并，偏振相关镀膜和部分参考球策略也未覆盖全部上游组合。

后续工作包括后端数组执行、完整渐晕/视场行为、GRIN 曲线求交和剩余参考策略；不得破坏已经验证的托管 API。

### 分析框架

已实现方法覆盖多种光斑、波前、PSF 和 MTF 方案，但并非所有 Python 默认参数、参考方式和向量衍射方法都已复现。结构化结果必须保留视场、波长、方向和采样维度，不能用单个摘要值代替上游数据合同。

图像模拟采用已记录的 Zemax 风格流程，包括外部位图、黑色保护边、相对照度、可选 PSF 和畸变/横向色差公共参考；它不是旧 Python 固定 FFT 夹具的直接复刻。

### 可视化

2D/3D 查看器使用 Workbench 自有场景模型和 Avalonia 投影，不等同于 Python 的记录数组绘图与 VTK 交互。仍需统一分析和可视化的数据源，并补足投影视图、孔径叠加、参考光线、弧矢面查看和高性能 3D 交互。

### GUI

中文 Avalonia 工作台已经具有主要编辑器、分析页、工作区布局、主题和持久化能力，但嵌入式 Python 终端、命令注册深度、Toast、VTK 级 3D 和广泛 UI 自动化仍与 Python GUI 不同。连接器中的领域逻辑还应继续拆分到服务层。

### 优化、公差与多配置

Workbench 已有优化变量/操作数、公差编辑器与向导、双侧灵敏度、确定性 Monte Carlo、百分位/良率统计和报告导出；这些是独立验证的产品能力，不构成 Python 全量金标准。

尚缺 Python 的管理器式变量/操作数模型、批量光线求值、材料类别变量、更多自由曲面变量、部分优化器和通用属性关联。

### 文件格式

原生 `.staropt` 是独立、带版本的工程快照；Python `to_dict/from_dict` 是另一条适配路径。当前适配器只承诺已列出的顺序系统子集。

Forbes、NURBS、网格面形、部分 Zernike/多项式基准半径项、非均匀材料传播、Fresnel/偏振/薄膜镀膜、BSDF、偏振、拾取、求解和多配置仍不完整。遇到不支持类型时必须明确报错，不得静默降级为相似对象。

## 后续优先级

1. 扩展 Python JSON 到剩余自由曲面、镀膜、BSDF、求解、拾取和偏振对象。
2. 合并 GRIN 曲线传播与曲面求交，并增加固定外部金标准系统。
3. 让分析和可视化共享规范追迹数组，补足投影、孔径和弧矢检查。
4. 增加向量 PSF/MTF，以及现有 FFT、MMDFT、Huygens、采样和几何方法之外的默认合同。
5. 深化优化变量/操作数管理、批量求值、材料变量和补偿器支持。
6. 在不改变已验证公共合同的前提下增加可选数组/GPU/自动微分后端。
7. 扩大分析参数、布局持久化、文件对话框、主题和命令导航的 GUI 自动化。

## 修复进展摘要

### 2026-07-11：追迹基础

- 增加 `Optic.Trace`、`Optic.TraceGeneric`、归一化输入校验和单位转换。
- 增加 `SurfaceTraceData`、`SurfaceTraceRecord` 与逐面记录。
- 把单面实光线内核移入 `OpticalSurface.TraceRay`，顺序追迹器只负责遍历。

### 2026-07-12 至 2026-07-13：分析与衍射

- 扩展 RMS 波前、焦面扫描、入射角、照度、辐射强度、几何/采样 MTF 和最佳拟合球。
- 增加 MMDFT、Huygens-Fresnel PSF 与 Huygens MTF，并修正奇数尺寸 `fftshift`。
- Cooke/Tessar 金标准比较确定性采样、球参数、热图像素和 MTF 点。

### 2026-07-13 至 2026-07-17：Python JSON

- 扩展双圆锥、可表示环曲面、高阶非球面、材料、物理孔径、复合孔径和七种切趾模型。
- 增加薄透镜、相位和衍射相互作用的字典与数值合同。
- 对未知系统孔径、非均匀传播、拾取、求解和偏振保持显式防护。

### 2026-07-18 至 2026-07-19：视场与 Zemax 路径

- 对齐角度、物高、近轴像高、有限/无限共轭和最大径向视场归一化。
- 增加 Zemax 实像高的阻尼二维主光线求解，并统一查看器、分析和追迹入口。
- 增加五个可手动打开的 ZMX 样例，用于玻璃解析、主光线和场景生成检查。

### 2026-08-04：当前回归口径

截至2026-08-26，正式产品严格构建为 `0` 警告、`0` 错误，全量回归测试为 `786/786`。独立智能初始结构实验室定向测试为 `7/7`，不参与 Python 兼容结论。几何 MTF 改为按像面光线强度加权后，与 Optiland 0.5.8 计数权重辅助数据保持 `2e-5` 近似约束；这项有意差异不扩大为其他 Python 兼容结论。独立 `Distortion` 从公开目录移除不改变 Python 畸变数值契约，组合“场曲/畸变”仍使用同一底层算法。

Optiland 包围能量和旧 Huygens MTF 兼容只通过明确的辅助模式保留。Zemax 专用测试固定的是 `123456.ZMX` 捕获设置，不是所有 Zemax 工程的通用默认值；Core 构造函数继续保留通用默认配置。
