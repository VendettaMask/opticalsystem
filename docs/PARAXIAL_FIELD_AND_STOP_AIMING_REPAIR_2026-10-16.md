# 近轴像高与光阑交点修复：2026-10-16

本轮检查同步后的 `4a63729f`，确认并修复两类可复现的 Core 问题。

## 近轴像高映射

此前无限物距发射器及标量近轴报告使用 `u = -h C`，隐含传递矩阵行列式为 1。空气入射、像方折射率 1.5 的单球面因此把入射斜率少算 1/3；像方折射率 2 时少算 1/2。反射路径还可能丢失像高符号。

现在两条路径调用同一个共享 Core 换算：从物面之后的主波长矩阵得到 `u = -h C / det(M)`。折射路径的行列式为物像方折射率之比，每次反射再改变一次符号；GRIN 路径采用同一端点轴上折射率比。避免从大数相减的 `AD-BC` 计算行列式，也不向无限远物面引入虚构的空气折射界面。实际像面移动、其他波长请求及有限物距不改变已有视场定义。

独立单球面控制使用 `f' = n' R / (n'-n)` 与顶点折射斜率 `n u/n'`，同时检查真实发射方向、标量近轴发射斜率、焦面像高和离焦后像高。另覆盖两侧浸没、负曲率、负视场、单反射符号及色散材料的两个不同主波长。解析公式只存在于测试，不参与运行时求值。

## 光阑瞄准失败记录

`TraceToSurface` 可以返回带失败标记的记录，其位置仍是上一传播位置。此前瞄准器只检查记录非空和 X/Y 有限，在上一位置恰好等于目标时会误报收敛。两个 ±90° 倾斜光阑反例中，轴上光线与光阑平行，没有交点，却被标为强度 1 的有效样本。

求解器现在先拒绝 `Vignetted` 失败记录。已有单光线异常与批量零强度无效样本规则继续生效；没有改变物理孔径、求解残差或外部数值容差。
