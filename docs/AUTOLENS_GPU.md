# AutoLens GPU 计算

AI 初始结构的 **搜索 → 计算设备** 提供自动（优先 GPU）、GPU、CPU。新窗口默认自动并显示显卡。载入预设保留设备选择，打开实验恢复原设备模式；手动切换会清除旧显示结果并新建实验。AutoLens 算法与关闭原生目标精修的规则不变。

2026-10-24 新建流程切换为 `autolens-upstream-e58-v2`，使用有限物距固定输入光线。正式传播支持有限物距；独立验收的方向瞄准使用共享 Core CPU，单独计为 `CpuAimingRays`，CUDA 起点平移瞄准仍只用于无限远物方。原有 `CpuRecoveryRays` 不混入这类工作。原版规则、状态及测试边界见[本轮对齐报告](AUTOLENS_UPSTREAM_ALIGNMENT_2026-10-24.md)。

| 环节 | 执行位置 |
| --- | --- |
| 材料色散、处方与曲面参数准备 | 共享 Core CPU |
| 正式交点、法线、折射、全反射与体吸收 | 共享 Core CUDA，双精度 |
| 有限物距方向瞄准 | 共享 Core CPU，保持物方点固定，单独计数 |
| 自动口径包络与密集物理验收的光线传播、裁光 | 共享 Core CUDA，多视场合批 |
| 记录求导图与发射坐标导数 | CPU，沿 GPU 返回的正式交点与方向 |
| 光线六个输出（含逐面累计弯折）对参数的链式反传 | CUDA GPU，双精度 |
| 质心/RMS 等统计、制造约束、Adam、玻璃选择、规则判断与导出 | 共享 Core / 流程 CPU |

GPU 与正常 CPU 几何调用同一组 Core 交点、法线、Snell 折射和二维瞄准函数。没有另外拟合曲面、复制模块内光学引擎、降低采样或用训练坐标代替物理验收。独立验收仍使用 21 个视场、10×32 积分光瞳、独立边界/中心检查、原波长及原物理门槛。积分和边界检查共享质心，但检查光线不进入面积 RMS 权重。

口径包络与物理验收按波长合并视场，复用有界显存和完全相同的曲面参数，减少分配、传输与提交开销。常规分析和 CPU 模式仍用原默认路径；自动选择只在 AutoLens 操作作用域内生效，不更改文档、常规分析默认后端或历史记录。

目前正式传播支持有限/无限远物方、无倾斜平面/标准面/至多十个系数的偶次非球面、均匀介质、圆孔径和无镀膜/散射的设计。CUDA 瞄准限无限远且方向 |Z|≥0.5；有限物距使用 Core CPU 方向瞄准。保留色散与体吸收。传播批次最多 4096 光线、128 面；CUDA 瞄准网格最多 101 视场、每波长十万光线。梯度每批最多两百万节点、每光线 262144 节点、每批 128 光线。取消在准备、提交与返回边界检查，已提交内核不能中途打断。

自动模式在设备、面型或数值范围不可用时记录原因并使用 CPU；强制 GPU 不会把后端不可用静默当作成功。少数复杂瞄准分支超过有界 GPU 延拓后，使用原 CPU 的扩展主光线延拓恢复，单独计入 `CpuRecoveryRays`，包括最终不可达的光线。运行状态与候选详情分别记录真实 GPU 瞄准/追迹数量、成功梯度批次和 CPU 恢复次数。CPU 模式与省略设备字段的历史记录仍保留原身份。

以下为 2026-10-23 历史 v1 协议在 RTX 5060 Laptop GPU 上的冻结测量，不能用于本轮有限物距参考流程的性能结论。本轮未比较速度或最终效果。

| 同输入工作 | CPU 中位数 | GPU 中位数 | 比值 |
| --- | ---: | ---: | ---: |
| 实际搜索服务：2 个初始根、13 个完成试次、160 次评价、单工作线程 | 14.308 s | 7.315 s | 1.96 倍 |
| 三片短完整求解：渐进口径和真实玻璃精修各一次 | 684.59 ms | 364.45 ms | 1.88 倍 |
| 单次光学梯度：42 参数、5 视场、36 光瞳点 | 89.73 ms | 59.80 ms | 1.50 倍 |

整轮搜索包含计划、筛选/细化、密集物理验收和候选选择，CPU/GPU 的试次操作及各试次完成评价数量一致。每轮 GPU 瞄准和传播各 433628 条光线，CPU 分支恢复为零；RMS 梯度的最大归一化差小于 8.85×10⁻¹²。对照使用本轮同样重构后的 CPU，未把 CPU 自身的改进计为 GPU 收益。窗口渲染、磁盘保存、首次 JIT/内核编译不在这个预热比值内；其他规格、并行度、设备和成功率不能由此推定。

真实优化、胶合结构、CPU 物理对照、保存恢复及 GUI 验证见[当前状态](CURRENT_STATUS.md)和[完整路径账目](validation/AUTOLENS_GPU_FULL_2026-10-23.json)。此前仅梯度阶段见[原账目](validation/AUTOLENS_GPU_2026-10-23.json)，其旧性能和范围保留，不能代表当前实现。

硬件测试需显式设置 `OPTICAL_SYSTEM_DESIGN_GPU_VALIDATION=1`，否则对应硬件用例跳过；不能把 CPU 测试通过说成 GPU 实测。测量目录由 `OPTICAL_SYSTEM_DESIGN_GPU_EVIDENCE` 指定。未进行 AMD/OpenCL、Apple GPU 或上游 AutoLens GPU 等效认证。

实现锁定 [ILGPU 1.5.3](https://www.nuget.org/packages/ILGPU/1.5.3) 与 [ILGPU.Algorithms 1.5.3](https://www.nuget.org/packages/ILGPU.Algorithms/1.5.3)，参考[官方设备](https://ilgpu.net/docs/02-beginner/01-context-and-accelerators/)和[内核说明](https://ilgpu.net/docs/02-beginner/03-kernels-and-simple-programs/)。本轮以共享符号位函数规避该版本的 [CopySign 参数顺序问题](https://github.com/m4rs-mt/ILGPU/issues/1361)，并对 Release 的浮点条件值与近乎平面法线保留真实 CUDA 回归。许可证与打包范围见 [ILGPU 声明](../third_party/ilgpu/ILGPU-NOTICE.txt)。
