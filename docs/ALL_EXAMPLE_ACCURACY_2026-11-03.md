## 本轮暴露的优先问题

1. **晶体坐标框架与界面上下文**：Rochon、Senarmont、Wollaston 三支共有 **142 个 E**，集中报入射晶体缺入口坐标框架或缺显式双折射界面。这是本轮原请求中的共性执行缺口，之前特殊模型的局部关闭不能替代这些请求的数值验证。
2. **9 项旧通过未保持**：Toroid 的 1371/1375/1378/1379 为几何能量、RMS 随视场、点列和光扇；环形瞳孔示例的 1782/1783/1792/1799/1800 为光扇、OPD 和衍射能量。Toroid 出现空射线集合、能量绘图负计数和掩码不一致；环形瞳孔的四份光扇/OPD 掩码不一致、能量 Close。诊断显示部分主光线从旧快照可用变为当前不可用，移除孔径的诊断副本又可到达像面；这仅是归因线索，不能靠删除真实孔径制造通过。见[原始诊断](../validation/rechecks/2026-11-03/all-example-accuracy/regression-probe.json)。
3. **采样与相位/统计余项**：175 D 与 39 C 主要涉及单光线表、OPD、能量、点列、场曲和 Huygens 系列。图像模拟示例 2/5、网格矢高面、光谱仪、GRIN 等仍有多项原设置残差；应先核对有效参考、完整范围、界面和通光定义，再判断算法误差。
4. **参考与适用性覆盖**：原生缺失/无效数组、折叠表面映射、非毫米旧请求、超广角 F-Tan 及 320° 锥角导入仍需分别处理。15 项瞄准失败、11 项既定 FFT 采样拒绝、7 项瞳孔频率尺度不可用、7 项数值结果契约错误等独立列在[原因统计](../validation/rechecks/2026-11-03/all-example-accuracy/failure-taxonomy.json)，不能混成一种精度问题。

第 10 项未保持是平场施密特原 32 档衍射能量 2278，属于已记录的低采样差异；独立 512 档及双方收敛的历史通过保持其原身份。本轮没有重跑所有高采样专题，不因原请求 D 自动推翻已验证的不同采样控制。环形瞳孔 1792 的参考收敛也尚未由本轮建立。
