## 查明的规则

旧实现把入口处的相邻四节点查询和体内全局自然样条混合使用，并在每步把传播状态当单位方向归一化。它们在常数/线性网格上等价，在非线性 GGD 上会产生可见相位差，原产品对收敛原生 2048 档的 S NRMSE 为 0.013350，高于原 Pass 0.01。

直接原生 GRIN Profile 与独立光线控制确认以下分工，不将私有算法匹配本身作为验收目标：

这是对捕获版本数值行为的归纳。[官方 GGD 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v251/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Grid_Gradient.html)只规定网格格式与三次样条，未公开这些窗口、梯度及积分细节；本轮具体结论来自保存的独立控制。

- **折射率查询**在 X/Y 使用四节点自然样条，Z 使用全轴自然样条。横向窗口依赖物理坐标的 floor、网格原点商的整数部分及坐标符号；不能将原点和坐标合并后取整，也不能按数据范围中心平移窗口。正负整数边界的入口 Snell 控制独立核对了符号约定，没有拟合 epsilon、镜头名分支或原生查表。
- **连续体梯度**来自全局张量自然样条。公开 `Evaluate` 和 `RefractiveIndex` 继续给出一致的连续场值和导数，用于高斯运输及一般场查询；GGD 传播查询是明确的内部入口，不把两个不同定义改成同一公开分析结果。
- **传播状态**在 GGD 段保留光学动量 `p`，初值为查询折射率乘单位方向。按弧长积分 `dr/ds=p/|p|`、`dp/ds=n_query*g_volume/|p|`、`dOPL/ds=n_query²/|p|`。对外仍返回单位方向。出口折射使用同一个位置查询值，不能用连续场标量代替。
- **交点精度**另发现原有健壮性问题：包围交点的大步长被接受，不保证二分中的任意部分步也通过 RK 估计。超差部分步现在继续按原估计器细分，保留原最小步长、最大尝试数、取消和表面误差限制，不接受超差试探。

GGD 专用规则位于共享 Core 的材料与传播层；分析和实验室没有加入另一套光学公式。其他解析 GRIN 的单位方向积分路径保持。为降低同一积分的开销，传播仅计算需要的全局梯度，省去未使用的 Hessian；不减少光线或放宽误差要求。

## 独立依据与候选边界

四组 6³/8³ 二次/四次材料、16 条非零瞳孔光线，排除了只修入口/只修光程/出口仍用全局标量等假设。长路径及偏移、不等轴 7×8×9 网格再提供八条留出光线。最终索引规则下，这些小步控制的光程最大差约 3.9e-10 mm，位置约 4.9e-12 mm，退出方向约 8.1e-13；后续定向测试另用更大的 Core 步长核验自适应积分。

13 条完整直接材料曲线、共 1,313 点，涵盖奇偶轴数、非零 Z、非零 X、偏移原点及不等间距，查询最大差约 5.33e-15。两条精确正负边界入口控制还验证了同一坐标下查询值确实不同，不能强制材料镜像或用最近节点替代窗口规则。

旧候选 1024 档对收敛原生 2048 的 T/S NRMSE 为 0.002482/0.002063，按原门槛均 Pass。但它仍是隔离候选身份，不能代替最终共享 Core 的产品核验。旧候选 2048 和发现交点问题后的首轮产品大采样已明确取消，保存了所属进程与取消原因；没有关闭其他应用，也不把未完成输出算通过。

固定参考、失败和被排除的假设均保留。原生能量 8192 采样不足/16384 内存失败、截线固定范围 4096→8192 未收敛的结论保持。

最终验收 Core `115d94afb6a12aa41140a566c0a19a93ab285723a8f24d19f535d73541554afc` 已通过 125 项定向检查，包含 12 项新夹具检查；该版本默认含两模块的 Release App 构建零警告、零错误，构建时默认 Core 与冻结运行时哈希一致。34 份独立 Workbench 计算全部完成：最终 1024/2048 MTF、已关闭 24 项及八项相邻结果均以此身份验收。首轮 11/12、交点试探超差及被取消的大采样保留为中间失败，不叠加测试通过数量。
