## 默认文件与执行身份

完整构建使用正常项目和默认路径：

```powershell
dotnet build src/OpticalSystemDesign.App/OpticalSystemDesign.App.csproj -c Release --no-restore -m:1 -nr:false
```

输出为 `src/OpticalSystemDesign.App/bin/Release/net10.0`。构建后到验证和归档结束期间，对八个产品程序集及其 PDB 持有允许读取的句柄，防止其他构建替换文件。109 项定向测试使用与该目录逐字节一致的产品副本；47 个独立场景进程直接从实际默认目录加载 Core、初始结构契约/引擎/持久化、Application、镀膜引擎、Modules 和 App，逐进程保存路径、MVID 和 SHA256。前后八个程序集指纹一致。

场景代码复用上一批已经保留的测试驱动，仅提供任务与断言。驱动目录中的旧产品程序集不参与本批光学计算。默认输出二进制、测试宿主和编译文档校验另行归档，第三方依赖沿用现有包身份，不反复复制整套平台运行库。

## 验证结果

- 109 项相关测试通过，零失败、零跳过，覆盖 SPC 数值续跑、旧记录、预算、补偿、原权限、自动交接与三语离屏控件。
- 种子 42–46 各做连续运行和六个暂停位置的新进程接续。处方、原完整验收、随机状态、BFGS/Hessian/实体补偿状态、候选池、选择结果和离散费用精确一致；每轮 161 函数、151 梯度、503,394 条实际光线、56 次差分评价、10 次搜索内验收。每个恢复段只产生新增光线，六次暂停不重放已完成工作。
- 各轮保持 600 函数、600 梯度、2,000,000 条光线和 120 秒计算活动时间上限；十轮搜索合计 1,610 函数、1,510 梯度、5,033,940 条光线。暂停等待和持久化时间单列，不冒充端到端加速。
