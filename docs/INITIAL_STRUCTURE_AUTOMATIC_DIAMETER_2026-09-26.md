## 已实现

新建桌面实验默认勾选“镜片直径随光线自动调整”，位于“目标 → 几何、材料与验收”。每次改变曲率、厚度、阶段孔径或视场后，实验室请求正式共享 Core 重新计算各片的光束包络。各片直径可以增大或缩小；同片前后面使用该片两面光束包络的较大值乘半口径裕量，作为共同净半口径和机械半径。系统入瞳、F/# 目标和视场不随这项计算改变。

正式 Core 新增 `AutomaticSemiDiameterSolver.UpdateFromRayEnvelope`。它使用独立光学快照、正式光线生成器及顺序追迹，覆盖调用方给出的视场、光瞳和正权重波长。只有显式指定的镜片圆孔径被移除以测量所需尺寸，其他物理孔径保留；只有全部请求光线完成传播才应用新尺寸。缺交点、全反射或其他固定孔径截光不会触发估算尺寸回退。应用尺寸前会脱离共享追迹缓存；取消或传播不完整时不修改原尺寸。旧 `Update(Optic)` 行为保留，正式产品的既有默认算法不变。

实验室完整验收沿用六个视场、97 个光瞳点和全部正权重波长；轴上或阶段视场为零时只需轴上位置。启动与粗筛使用各自已声明的采样。口径追迹计入光线成本，随后再按实际圆孔径做正式点列/通光评价。放大后的边厚、球面有效范围和空气间隙重新检查；不同直径相邻镜片的边缘间距在共同径向范围内检查。

候选保存的是**评价时实际使用的口径快照**。先前“评价后再从参数重新构造快照”的做法已移除，避免预览或导出回到旧尺寸。处方、正式 Core 布局、候选指纹、检查点和 STAROPT 导出重载使用同一快照。导出处方记录实际物理尺寸；自动更新策略属于实验规格，后续实验室优化仍重新求口径。

## 历史与验证口径

算法身份升为 v11。新增 `FlatStart.AutomaticLensDiameters`，旧文件缺省为 `false`，序列化时仍省略 `false`，保持既有规格指纹和固定口径含义。新建桌面实验显式设为 `true`；导入旧记录按原策略显示，修改勾选状态会清除旧候选和预览并创建新实验。v1–v4、v6–v10 可读取、导出并创建独立 v11 续算，不能静默恢复为新算法。

冻结原协议没有新增此字段，仍表示固定口径。自动口径引入了此前没有的尺寸自由度，其新结果不能冒充“相同固定口径问题”的成功率提升。v10 的完整协议进程已中断，保留的结果为原协议 43/60 次完成，其中 30 次成功，尚未执行留出集；它不是完整验收结果。本轮不改写或丢弃那些记录。

官方资料同样将自动半口径描述为依据光线所需的径向范围，但具体采样、迭代和精度属于各自实现。本项目采用上述有限采样和用户裕量，没有声称复刻 OpticStudio 的迭代精度，也没有新增外部 Zemax 数值认证。[Ansys 半口径说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v251/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Semi_Diameters.html)、[采样说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v252/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Fast_Semi_Diameters.html)。

正式 Core 五项专项测试覆盖增大/缩小、同片尺寸、波长/视场覆盖、无效传播、固定遮拦、取消和源状态保护。实验室搜索/兼容专项 16 项通过；自动口径与桌面控件逻辑专项 5 项通过。专项是完整测试的重叠子集，不能相加。最初一次 Core 专项的测试夹具重复声明主波长，导致 1 项失败；修正夹具后专项及完整回归通过，旧失败 TRX 保留。

本机 macOS 原生窗口实际完成默认 50 mm / F8 / 5°、三片、10000 次评价的 v11 自动口径搜索，界面保留 10 个达标候选，结构预览显示正式 Core 的 21 条布局轨迹。保存记录中的一个达标例子，各片半口径依次为 **4.439785、4.948951、6.420539 mm**（直径约 **8.879570、9.897901、12.841079 mm**），每片两面共享对应净半口径和机械半径。其完整采样通光率为 1，最差视场 RMS 为 0.009097 mm；这些是当前 Core 的结果，没有经过新的外部精度认证。
