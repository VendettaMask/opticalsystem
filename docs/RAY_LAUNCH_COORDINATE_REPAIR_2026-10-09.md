# 光线发射坐标基准修复

本文保留光线发射坐标阶段的 4526 项 Release、443 项 Debug 定向及该阶段源代码和二进制哈希。后续 FFT 采样与参考点修复的当前行为和验收见[最新报告](FFT_SAMPLING_REFERENCE_REPAIR_2026-10-09.md)，不同阶段结果不合并。

2026年10月9日，修复光线发射初值仍依赖世界 X/Y=0 的错误。整体平移镜头时，发射原点和入瞳初值现在随物面坐标原点一起移动，角度视场、有限物高、近轴像高、实际像高、单条和批量采样共用一致的基准。真实遮挡、单片偏心和原瞄准失败规则保留。该修复不等于完成任意三维出瞳或 Zemax 数值认证。

此前轴上参考、校准畸变、几何质心及 Huygens 传播/复色修复继续保留，见[上一阶段报告](HUYGENS_IMPLEMENTATION_REPAIR_2026-10-09.md)。该阶段验收时没有提交或推送；后续同步见[同步记录](PROJECT_SYNC_2026-10-09.md)。没有修改冻结参考、历史镜头输入、比较设置或容差。

## 错误位置与根因

共享 Core 的 `RayGenerator` 原先在三个地方混用了世界坐标原点与镜头坐标：

- 角度与无限物距近轴像高的发射原点使用世界 X/Y=0。
- 单条、批量和预备采样的入瞳目标，以及有限物距瞄准延续和实际像高主光线初值，使用 `(0, 0, entrancePupilZ)`。
- 有限物高与近轴像高的物面发射点只加了物面的 Z 原点，没有将局部物面点转换为全局坐标。

因此同一 Cooke 镜头整体移动到 X=10、Y=10 mm 后，自动发射仍从 `(0, 0, -10)` 开始。错误初值在前组传播中失去有效光线，无法给 Newton 瞄准提供样本；异常发生在衍射之前。内部瞄准控制忽略物理孔径，所以这不是一次已证明的真实孔径遮挡。把原来有效的光线原点按同样向量平移后，正式物理追迹仍到达像面，位置、方向和光程残差均为零，从而确认是发射初值错误。

## 实现与边界

| 入口 | 修复行为 |
| --- | --- |
| 入瞳初值 | 缓存完整三分量中心；横向基准取物面坐标原点，纵向沿用正式近轴模块的全局 Z 约定。 |
| 无限/有限角度视场 | 原有视场角、起始纵向位置和发射净空不变，横向原点随物面基准移动。 |
| 有限物高、近轴像高 | 先算物面局部点与面型矢高，再通过物面的坐标变换获得全局发射点。 |
| 实际像高、有限物距瞄准延续 | 主光线与延续初值使用同一个移动的入瞳中心。 |
| 批量、预备采样 | 与单条发射共享相同中心，未增加备用追迹器或重复光学引擎。 |

横向基准不能取第一片物理表面：只移动一片镜片时，光源不应自动跟着该片移动，否则会掩盖真实偏心。早期候选采用第一物理表面，触发了既有 `BSER` 波长与遮挡回归；已撤回，最终采用物面原点，相关测试通过。没有修改既有数值断言来迎合候选实现。

正式入瞳位置仍是近轴标量，纵向按全局 Z 定义。本轮没有把它解释为任意倾斜面法向距离，也没有求解偏心、折叠系统的真实三维入瞳。整体旋转、任意倾斜与独立偏心系统的全面原生认证仍待补充。

## 修复前后控制

八组 Cooke 轴上平移使用同一正式 Core 追迹诊断，不另建物理模型：

| 平移 (mm) | 修复前自动瞄准 | 最终自动瞄准 |
| --- | --- | --- |
| (0, 0, 0)、(0.1, 0.1, 0)、(10, 0, 0)、(0, 10, 0) | 成功 | 成功 |
| (10, 10, 0)、(10, -10, 0)、(-10, 10, 0)、(20, 0, 0) | 失败，残差为无穷 | 成功 |

最终八组发射初值随平移变化，前组及光阑保持有效传播；独立平移的已知有效物理光线全部到达像面，位置、方向和光程残差仍为零。诊断仅检查现有正式追迹，不写入产品回退逻辑。

新增 8 项正式回归覆盖有限/无限角度、有限物高、近轴/实际像高、单条/批量/预备采样、三波长、轴上/边场、联合横向及纵向平移、波前、FFT/Huygens PSF，以及真实孔径阻断。发射/像面位置和光程界限为 1e-8 mm，方向 1e-9，OPD 1e-8 waves，PSF 归一化强度百分数的最大绝对差为 1e-6 个百分点；这些是新增物理不变性控制，不改变任何冻结原生判据。

最初有限物距测试错误地保留了多个默认主波长，已纠正测试准备。有效模型上的最终修复前运行为 0/8，通过坐标残差或瞄准异常复现；修复后为 8/8。最终新增测试与既有表面差分/偏心/遮挡测试合计 72/72。不同测试集合重叠，不相加。

## 原生残差与未完成范围

本轮针对整体移动的发射初值错误，没有据尚未确定唯一根因的残差替换传播模型。N01 的原捕获处方横向原点为零；N02 使用 FFT，不能由 Huygens 修复自动关闭。两项仍按原容差核对：

- N01：最终比较的 MS-L7 Huygens 截面 NRMSE 0.0037256670590166724，为 Close，仍超过原预算 0.0037256669899999998。需独立核对原生瞳节点、方向振幅和球面/平面相位。
- N02：最终比较的 MS-L7 FFT 包围能量理想/实际曲线 NRMSE 分别为 0.013875784968407625、0.011467280942848471，为 Difference；实际曲线仍超过原预算 0.01146706362185577。需二维理想/实际 PSF、像素尺度、有效窗及总能量定义；单纯加密采样或改积分分母尚未证明能关闭残差。

内部一致性通过、冻结证据完整、原生数值认证与人工桌面验收分别记录。本轮没有新原生捕获，未重跑原 132 项六镜头矩阵、完整 Debug、实验室、安装包或人工桌面烟测。整体发布门禁仍开放，详情见[问题分类清单](OPEN_ISSUES_2026-10-08.md)。
