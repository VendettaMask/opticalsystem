# 双筒 Fourier 高频随视场：原因与收敛基准

后续五频率复核见[2026-10-31 专题](BINOCULAR_FOURIER_REMAINING_FREQUENCIES_2026-10-31.md)，独立记录其参考归一化方式、原生整图提取限制和最终 Core；下文保留本阶段仅 3.2 的验证身份。

**原约 0.132 的差异主要来自 Zemax 32 采样快速积分未收敛。按用户确认的收敛基准，双筒两个配置在 3.2 cycles/mrad 的整条 T/S 曲线均已通过原门槛。**共享 Core 原有 32 采样结果已经满足此次收敛参考，无需修改光学计算去复现低采样高值。

本结论只关闭这两个配置的该高频检查点，不代表其余五个频率、全部 Fourier MTF 或 Huygens 已完成。前一轮固定 32 对 32 的两个弧矢 `Difference`、两个子午 `Close` 均保留原身份。

## 查明原因的证据

同一源文件、配置、+Y 视场、全波长、无偏振，物理频率始终为 3.2 cycles/mrad。以下为边缘视场弧矢调制度，C1/C2 的结果在列示位数内相同。

| 瞳采样 | Zemax 快速 MTF | 共享 Core |
| --- | ---: | ---: |
| 32 | 0.132303149 | 0.000508959 |
| 64 | 0.007220565（C1） | 0.000221988 |
| 128 | 0.000348779 | 0.000196969 |
| 256 | 0.000259674 | 0.000209273 |
| 512 | 0.000226006 | 0.000205507 |

原生直接 `MTFS`/`MTFT`、随视场端点、通过焦移零点控制一致，确认使用的是快速稀疏积分路径；普通 FFT MTF 在 32 采样下弧矢端点约 `0.000884532`，没有该高值。单色控制也存在明显抬升；倒序频率和六槽重复相同频率保持原值，排除了频率槽位读取及仅由多波长合成造成的差异。

Ansys 文档明确区分普通 FFT MTF 与 `Grid=0` 的快速稀疏积分，且要求检查采样变化；本专题关于具体数值及未收敛现象的判断来自实际捕获，并非从文档直接推断。[Ansys MTFA 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26103/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Optimization_Operands_Alphabetically.html)、[FFT Through Focus MTF](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/FFT_Through_Focus_MTF.html)。

另直接捕获 C1 主波长的 704 条移位瞳孔光线：全部原生追迹/口径状态有效，Core 与原生 OPD 最大差 **5.4349515235e-6 波**，小于既有 Wavefront 的 `1e-5` 绝对门槛。该误差量级不足以解释 0.132 的调制度差。没有为本检查点修改三角片择片、边界映射、材料、光阑或相位基准。

## 采用收敛参考后的正式结果

用户在本任务明确选择“以收敛结果为精度基准”。原生完整曲线的 128→256 采样复核均通过；Core 的 32→128 检查也通过。选择原生 256 作为本检查点参考，独立披露 Core 32 与原生 256，保持相同物理处方、频率、视场、波长和归一化。

比较配置及判据保持原样：绝对 `1e-5`、相对 `0.002`、NRMSE `0.003`、Close NRMSE `0.01`、覆盖率至少 `0.95`。仍按“全点满足门槛或整曲线 NRMSE 合格”判 Pass；**不是逐点超限 0**。

| 检查 | C1 T NRMSE | C1 S NRMSE | C2 T NRMSE | C2 S NRMSE |
| --- | ---: | ---: | ---: | ---: |
| 原生 128→256 收敛 | 0.000801 | 0.000752 | 0.000801 | 0.000752 |
| Core 32→128 收敛 | 0.002041 | 0.001794 | 0.002041 | 0.001794 |
| Core 32 对原生 256 | 0.001727 | 0.001565 | 0.001727 | 0.001565 |

四条结果曲线合计 **1,332 次对齐比较**，最大绝对差 **0.000843226**，均 Pass；仍有 **782 个点**超过点门槛，依既有整曲线 NRMSE 判据通过。512 数据仅为边缘点补充控制，未将它冒充整条 512 曲线，也未声称这些边缘值逐点完全收敛。

原生单频率请求只启用一个 3.2 槽位，以减少后台计算；C1 的 128 单频率曲线与原六频率请求的对应曲线逐值一致，且之前的倒序/等频率控制吻合。完整请求、实际设置和原生模型单位回读都保留，不通过改写原 JSON 曲线取得新分类。
