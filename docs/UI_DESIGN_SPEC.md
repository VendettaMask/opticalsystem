## 设计原则

顺序模式默认只打开“镜头数据”和“二维视图”两个文档页签，镜头数据初始激活；左侧系统选项保持可用。启动、新建、打开工程和重置初始布局均遵守此规则；不会自动恢复额外分析或三维页，完整自定义布局可显式载入。

MDI 平铺/层叠子窗口标题按钮使用 20 × 20 DIP 点击区域，图标在 12 × 12 DIP 内按比例绘制，不继承表单按钮的 32 DIP 最小高度。按钮继续沿用主题状态与关闭权限。子窗口激活不能把业务内容转移到隐藏页签；内容只能在所属子窗口边界内绘制与命中，不遮挡相邻页面。此行为已实现，验证范围见 [平铺交互修复](MDI_INTERACTION_FIX_2026-09-27.md)。

1. 光学数据优先。界面应服务镜头参数、图形分析、制造数据和误差判断，避免装饰性大卡片、营销式标题和无意义说明文字。
2. 同一语义只允许一种表现。主题色、文本层级、按钮状态、图表背景、分析页底部信息区和品牌区应来自公共资源或公共组件。
3. 响应式优先，固定尺寸例外化。Dock 文档区会被分栏、浮动和恢复旧会话压缩，普通页面不得依赖写死宽高才能可用。
4. 主题完整。明亮、暗夜、异世界和像素风格主题必须同时可读；除物理波长、工程图标准色和导出文档外，不直接写界面颜色。
5. 可访问性是功能契约。可点击、可编辑、可滚动、可选择的控件必须有键盘路径、焦点反馈、自动化名称和可理解的禁用/错误状态。

## 颜色

所有普通 UI 颜色必须通过 `ThemeResourceBindings` 或由它派生的局部资源绑定。品牌图、主题相关位图和其它非画刷资产使用 `ThemeAssetBindings`，不得放入画刷资源表。

核心色彩语义：

| 语义 | 用途 |
| --- | --- |
| `Surface` | 主界面和普通内容背景 |
| `SubtleSurface` | 次级区域、分隔区、状态栏、轻量容器 |
| `SettingsSurface` | 设置卡片、参数卡片和可编辑面板背景 |
| `SettingsOverlaySurface` | 覆盖在图形区上方的设置浮层背景；普通亮模式为不透明白色 |
| `Workspace` | Dock 工作区底色 |
| `Border` | 普通边框和分隔线 |
| `TextPrimary` | 主文本、标题、坐标轴 |
| `TextSecondary` | 次级文本、表格辅助信息 |
| `TextMuted` | 说明、时间戳、低权重元数据 |
| `TextDisabled` | 禁用文本 |
| `Accent` | 当前选择、主操作、活动标签 |
| `PlotBackground` | 分析图页面和图内绘图区背景 |
| `SceneBackground` | 二维/三维查看器背景 |

约束：

- 明亮主题下分析页外层和绘图区必须一致，不允许出现“页面偏灰、图内纯白”的割裂。
- `Brushes.White`、`Brushes.LightGray`、`Color.FromRgb` 等硬编码只能用于物理/工程语义：波长颜色、光线颜色、制造图纸标准线色、导出图像画布、算法数据可视化的固定色标。其它场景必须抽成主题资源。
- 普通窗口、面板、工具栏、状态栏、分隔线、说明文字和表格行前景色不得直接使用白/灰/RGB 字面量；应绑定 `Surface`、`PlotBackground`、`Border`、`TextSecondary`、`TextMuted`、`TextError` 等主题资源。
- 普通 UI 色彩约束由 `OrdinaryAppUiColorsUseThemeResources` 契约测试保护；新增普通交互界面不得绕过 `ThemeResourceBindings` 写裸 `Brushes.*` 或 `Color.FromRgb/Argb`。确需固定色时必须属于工程/物理/标准语义，并集中到受审计的命名调色板或明确豁免文件。
- 分析结果表格的业务行色使用主题资源，例如 `AnalysisRealRayRowBackground/Foreground` 和 `AnalysisParaxialRayRowBackground/Foreground`，必须同时覆盖明亮、暗夜、异世界和像素风格主题。
- Zemax 评价函数行色属于业务分类色，不直接散落在面板里；统一由 `MeritOperandRowPalette` 输出背景/前景组合，并通过明暗主题对比度测试。该业务色不得复用为状态色、波长色或普通控件色。
- 基点、焦平面、主平面、节平面等分析注释色属于光学分析语义色，应集中在命名语义调色板中；不得在结果页局部直接写匿名 RGB。
- 波长颜色不是普通分类色。Fraunhofer F/d/C 约定为蓝、绿、红；该绿色是工程曲线辨识色，不描述为真实视觉黄光。
- 按视场、结构、状态、类别着色时不得复用波长调色板，避免物理含义冲突。
- 文本与背景对比度：正文至少 4.5:1，大字号和图形关键线至少 3:1。禁用态可以更低，但必须仍可辨认。

## 主题包、图标和 Chrome

- 主题必须通过 `ThemeRegistry` 注册完整 `ThemeDefinition`，不得在 `MainWindow`、设置窗口或业务面板中增加主题名称 switch。
- 运行时切换只能经 `ThemeApplicationService` 完成；不得由面板分别修改 `RequestedThemeVariant`、Fluent 强调色或 Dock 资源。
- 业务界面只使用稳定语义图标名；具体几何由 `ThemeIconResolver` 和当前主题包决定。
- 明亮、暗夜主题继续使用当前 `StandardLucide` 图标；普通亮模式卡片圆角为 6、无投影，侧栏分组使用连续白底与内收底部分隔线，暗夜保留既有 Chrome。修改异世界或新增主题不得改变这两套显示。
- 异世界使用从 Game-icons.net 官方仓库筛选并随应用内嵌的 `GameIconsFantasy` SVG 图标包以及旧金锐角 Chrome。图标必须保留上游作者、文件名、固定提交和 CC BY 3.0 署名，不得以本地自绘或自动生成符文替代；边框和纹理属于界面装饰，不得替代波长、状态或分析业务颜色。
- 像素风格使用 Light 派生的亮色 8-bit 色板、零圆角 Chrome、无模糊硬阴影、Farm-Fresh 彩色 32×32 PNG 图标和 `Fusion Pixel 10px Mono zh_hans` 中文像素字体；图标缩放必须使用最近邻插值，点阵与阶梯角标只出现在空白 Chrome，正文、表格和绘图区不得使用抖动纹理或模糊位图缩放。
- 顶部统一采用紧凑分类页签与单行工具栏：图标在文字左侧，下拉指示位于文字右侧，取消分组标题栏。四套主题共用自适应宽度与至少 56×36 的命令命中区，图标 20px，文字不换行；放大字体时自然增加高度，超宽工具栏横向滚动。像素主题保留连续浅蓝底面、图标与字体，常态命令无独立卡片边框。
- macOS 普通亮模式主窗口标题栏与菜单栏使用同一正蓝背景，标题实时居中显示；采用扩展客户区和原生窗口按钮，标题区域交由平台命中处理。全屏隐藏自绘标题占位，退出恢复。其他主题和未验证的平台继续使用原窗口装饰。
- 默认打开“文件”页，顺序模式依次提供新建、打开、保存、导入、导出、示例、撤销、重做；Cooke/Tessar 仅在“示例”下拉中显示。撤销/重做依照文档历史启用；非序列模式不显示顺序导入、导出或示例。
- Ribbon、工作区、卡片、控件框、状态栏、对话框和视口必须通过 `ThemeChromeRole` 表达边框语义。装饰绘制使用 `ThemeChromeOverlay`，必须不接收输入且不参与布局测量。
- 公共 Chrome 角色保持稳定的布局契约；普通亮模式的侧栏分组通过主题样式采用连续白底和 1 DIP 内收底部分隔线，线段与内容左右边距对齐。标题悬停/按下底色圆角 6 DIP，左右留白并避开覆盖式滚动条；标题保留 35 DIP 高度、整行点击区域和 8 DIP 分组间距；紧凑侧栏内容改为 8 DIP 左右缩进，分隔线同步对齐。双线、纹理和符文只能由覆盖层绘制。
- `System` 是跟随系统的选择代理，不维护复制的独立调色板；控件必须从 `ActualThemeVariant` 解析实际视觉包。
- 新主题的颜色、图标和边框必须作为同一个主题包注册；不得把新主题资产追加到异世界类或普通主题资源中。
- 公司标识、启动页品牌、物理波长/光线色、工程图标准色、算法固定色标和导出版式不跟随界面主题改色。
- 完整扩展流程见 [主题包开发规范](THEME_PACKAGES.md)。

## 亮模式与数字格式

- 普通亮模式采用“正蓝 × 雾蓝”：标题/菜单栏 `#2F6FD1`，菜单悬停 `#2864C3`、按下/展开 `#235AB3`；标题文字 `#FFFFFF`、菜单文字 `#F5F8FF`，当前菜单用已有选中背景区分、不显示下划线，标题分隔线 `#4A82D8`，主区/输入/工具栏白色，工作区 `#F2F5FB`、侧栏外沿 `#F5F7FC`（分组内容连续白底）、表头 `#EBF0F9`。普通文本 `#22334C`，次要文本 `#5C6F8A`，控件边框 `#8297B6`。背景、文字、边框 token 集中在 `BlueThemeTokens`，主要按钮背景与焦点边框使用各自变量。浅色区域强调文字三态为 `#2446F0`、`#1C3ED8`、`#1734BB`，仅用于分组标题、活动页签、选中菜单/视场项及对应箭头；释放恢复悬停，移出恢复默认，禁用色沿用原值。
- 普通按钮常态/悬停/按下为白色 / `#EAF1FF` / `#CDDDFA`，松开恢复悬停、移开恢复默认。主要按钮品牌蓝 `#2F65CC`，悬停 `#2554AF`，按下 `#1D448F`。只有 Toggle/Tab/选择模型保留选中状态。
- 镜头数据中材料列非空的所有行在普通 Light 下持续使用材料蓝底 `#EAF1FF`，悬停 `#D5E3FC`；这是材料语义，不是行选择。沿用 `HasOpticalMaterial` / `MaterialDisplay` 判定，Air 显示为空；材料清空/恢复、取消、撤销、刷新、文件切换与行复用必须正确更新。选中、当前单元格、禁用和错误继续使用下述状态规则。此要求已保存为根 `AGENTS.md` 的长期项目偏好。
- 选中/选中悬停/选中按下为 `#DFEAFE` / `#D5E3FC` / `#B9CFF5`，输入选区为 `#BED3FA` 配深色字；2 DIP 蓝色焦点独立于选中。错误边框 `#AD3F3B` 优先，聚焦时额外保留蓝色外圈。禁用 `#F0F3F8` 配 `#9BA9BF`，不得被悬停或选中覆盖。
- 主题资源覆盖 Fluent/Dock 原生模板，局部状态由 `BlueThemeStyles` 处理；仅精确匹配普通 Light，不影响 Light 派生的 Pixel。系统跟随模式在实际主题变化时同步根资源。完整规则与实测边界见 [蓝色主题记录](BLUE_THEME_2026-09-27.md)。
- 默认数字显示最多保留 **3 位小数**，科学计数法尾数同样遵守此设置；不强制补零。新设置、缺失该字段的旧设置和“恢复默认”均使用 3，已有显式自定义位数仍可保存。显示舍入不改变 Core 数值或 STAROPT 保存精度。
- 镜头数据中的“机械半直径”与表面属性“绘图”中的相应摘要必须通过统一 `NumericDisplayFormatter` 显示，位数变更后同步刷新。机械半直径保持只读及按原始数值排序，不能用格式化字符串替代原始数据。实现与验证见 [机械半直径显示精度修复](MECHANICAL_PRECISION_2026-09-27.md)。

二维光学布局中的镜片曲面、外轮廓和上下连接边统一使用固定 2 DIP 黑色实线，缩放不改变屏幕线宽；该工程轮廓不采用主题蓝色。镜片填充、光线颜色、光阑与参考面以及选中表面的橙色提示保留各自语义。此规则仅适用于二维布局，三维与实体模型继续使用原有线条。

## 字体

默认 UI 字号以用户设置的基础字号为准，默认值为 13。普通控件、面板和分析页不得写死不缩放的视觉字号；应使用公共样式或 `DisplayTypography` 的命名字号 token。自绘图表使用 `DisplayTypography.Scale` 或图表专用字号常量。

建议层级：

| 层级 | Token | 默认字号 | 用途 |
| --- | --- | ---: | --- |
| 启动画面标题 | `DisplayTypography.SplashTitle` | 29 | 启动画面产品名 |
| 空状态符号 | `DisplayTypography.EmptyStateIcon` | 27 | 空状态大号符号文字 |
| 页面标题 | `DisplayTypography.PageTitle` | 22 | 向导页、独立窗口主标题 |
| 大标题 | `DisplayTypography.LargeTitle` | 20 | 数据库页面标题 |
| 窗口标题 | `DisplayTypography.WindowTitle` | 18 | 对话框重点数值、材料标题 |
| 空状态标题 | `DisplayTypography.EmptyStateTitle` | 17 | 错误页、空状态标题 |
| 分区标题 | `DisplayTypography.SectionTitle` | 16 | 面板分区、对话框分组 |
| 卡片标题 | `DisplayTypography.CardTitle` | 14 | 结果页底部标题、工具卡片标题 |
| 正文 | `DisplayTypography.Body` | 13 | 普通标签、输入、表格正文 |
| 小正文 | `DisplayTypography.BodySmall` | 12 | 分组标签、Zemax 风格摘要 |
| 紧凑正文 | `DisplayTypography.CompactBody` | 11.5 | 分析结果元数据、图例、状态摘要 |
| Ribbon 文本 | `DisplayTypography.RibbonText` | 11 | Ribbon 命令、紧凑提示 |
| 标注 | `DisplayTypography.Caption` | 10.5 | 时间戳、低权重说明、图内辅助文字 |
| 微文案 | `DisplayTypography.Micro` | 10 | 折叠摘要等极低权重信息 |

约束：

- 分析结果页底部标签“绘图 / 数据 / 文本”使用紧凑页签样式，不允许出现接近标题字号的巨大页签。
- 图表内坐标轴、图例和标题必须跟随统一图表字号，不得因 `Viewbox` 或局部画布缩放而放大。
- `monospace` 只用于数值报告、Zemax 风格文本输出、代码/日志和固定列数据，不用于普通导航和设置项。
- 中英文混排保留行业通用缩写：FFT、PSF、MTF、RMS、Zernike、Jones、Y-Ybar、vs. 等不得随意汉化。
- 普通 UI 源码不得出现 `FontSize = 12` 这类数字字面量；必须使用命名 token。该规则由 `AppUiFontSizesUseTypographyTokens` 契约测试保护。

## 间距与几何

间距采用 4 点网格：4、8、12、16、24、32。新代码不得随意引入 7、9、13、18、23 等一次性间距，除非是算法图形或标准文档版式。

组件几何：

| 项 | 规范 |
| --- | --- |
| 普通输入/按钮高度 | 32 |
| 表格行 / 表头高度 | 36 / 34 |
| 工具栏图标按钮点击区 | 32 起，优先 36 |
| 控件圆角 | 普通/暗夜为 5；其它主题由 `ControlFrame` Chrome 角色声明 |
| 卡片圆角 | 普通为 6、暗夜为 8；普通侧栏分组为 0；其它主题由卡片 Chrome 角色声明 |
| 普通边框 | 普通/暗夜为 1；其它主题由对应 Chrome 角色声明 |
| 卡片阴影 | 统一使用主题 Chrome 配置，不新增局部阴影参数 |

上述控件与表格尺寸必须从 `UiDensity` 读取；普通 UI 不得为 `DataGrid.RowHeight` 或 `ColumnHeaderHeight` 新增数字字面量。工具内确有不同密度时，应先增加具名语义令牌并说明使用边界。

约束：

- 普通设置卡片、工具卡片、状态卡片、预览卡片和可编辑表面必须通过 `SettingsPanelChrome.ApplySurfaceCardStyle`、`SettingsPanelChrome.ApplyCardStyle` 或等价公共组件获得卡片圆角、边框、主题背景和阴影。
- 覆盖在分析图或查看器上的设置面板必须使用 `SettingsOverlaySurface` 主题背景（普通亮模式为不透明白色，其他主题保留半透明）；不得通过控件整体 `Opacity` 实现半透明，以免输入框和文字一起变灰。
- 列表框、预览框、输入框外壳等控件框架必须使用 `SettingsPanelChrome.ApplyControlFrameStyle` 或全局控件样式；普通/暗夜圆角保持 5，独立主题从 `ControlFrame` Chrome 角色读取。
- 不允许同类卡片在不同面板使用不同圆角、阴影和内边距；普通 UI 源码不得新增局部 `BoxShadows.Parse`。
- 允许例外必须有明确语义：图例色标/采样点属于数据标记，Splash、Dock 文档 pill 属于外壳装饰，导出文档和标准图纸属于独立版式。
- 底部分析信息区高度、分隔线、品牌区和文件区必须统一；同一组分析页面不得出现不同高度。
- 图标按钮必须有 tooltip 和自动化名称；只有图标无法表达的命令才使用图标加文字。

## 布局

普通页面使用 `Auto`、`*`、`DockPanel`、`Grid`、`WrapPanel`、滚动容器和容器相对尺寸。固定尺寸只允许用于：

- 稳定图标、色块、光标、拖拽柄；
- 明确有标准尺寸的导出文档、工程图和截图对标画布；
- 最小可用窗口尺寸；
- 对话框初始尺寸；
- 分析结果底部信息区这类产品级固定 chrome；
- 方形二维空间图的正方形约束。

查看器和分析设置浮层的字段布局必须响应容器宽度。两列设置应使用 `ResponsiveSettingsGrid` 或等价断点容器，在窄于400px时保持原阅读顺序重排为单列，不得靠固定字段宽度后被父容器裁切。

库存匹配与制图页保留原面板划分，在短视口中用 `ScrollableHeaderGrid` 限制顶部区的测量高度并局部滚动，给结果/预览留出空间。表格不得用大 `MinHeight` 反向溢出到说明区；边界裁剪不能替代正确测量。制图参数滚动条须占用实际宽度，不能悬浮遮住输入框右边框。原制图左右分栏宽度、窄屏断点与分栏比例保持不变。

Fluent 表头排序图标按内容占位，未排序不保留空白的 32 DIP 排序列。长表头和标准文本单元格采用省略号及完整提示；匹配/库存表的 EFL、EPD 和相对偏差单位单独测量，列变窄时优先保留单位。制图长参数使用短名称、完整提示及独立单位行，允许标签自然增高，不缩小字号。实现与验证边界见 [容器测量和文本适配修复](PANEL_CONTENT_LAYOUT_2026-09-27.md)。

禁止：

- 用 `Viewbox` 包住含文字的 UI 来适配窗口。
- 给普通分析子画布写死 840x290、固定列数或固定高度。
- 在 Dock 文档区强制大 `MinWidth` 导致窄分栏不可用。
- 图表外层和内层背景不一致。

设置布局：

- 分析页和查看器设置默认使用左上浮层卡片，不随主窗口宽度横向铺满。
- 分析页设置卡片的左边缘必须与工具栏“设置”按钮对齐，并从工具栏下方开始；不得用 `Stretch + MaxWidth` 形成视觉居中。
- 设置项按两列字段阅读，底部保留自动应用、应用、确定/取消或重置等操作区。
- 参数数量较少时，卡片宽度由内容决定；不得用横向 `WrapPanel` 把字段从左到右排到窗口最右侧。
- 双栏文档使用容器断点：材料、目录和详情页在可用宽度不足时改为上下排列，不能用横向滚动代替重排。
- 含长列表或数据表的主从页面必须在有限视口内测量：宽布局的主列表与详情分别滚动，窄布局按可用高度分配上下视口。不得把整个双栏容器放入纵向滚动区，使列表条目数量决定详情画布高度；否则会破坏列表虚拟化并把详情推到数据末尾。
- 主窗口支持 640px 最小宽度；Ribbon 可横向滚动，Dock 文档不得设置 500px 及以上的内容 `MinWidth`。

分析图布局：

- 点列图、全视场点列图、矩阵点列图、结构矩阵点列图、光瞳/光线 fan、干涉图等二维空间图应保持方形绘图区。
- 色焦移是曲线图，不强制方形。
- 光线像差和瞳孔像差按视场分组，X/Y 或 P_x/P_y 成对放在同一视场组内，不按方向拆成两列全局排列。
- 离焦点列图、矩阵点列图和结构矩阵点列图的多个波长应在同一个子图内叠加，图例说明波长，不拆成互相独立的小图。

## 控件与输入

- 每个输入项必须有可见标签；自动化层面应能从标签定位到输入控件。
- 数值输入默认应提供 spinner 或等价微调能力；只有密集表格、只读单元格或明确的紧凑模式可以关闭 spinner。
- 表格数值列右对齐，单位在列标题或旁侧标签中说明，不在每个单元格重复。
- 禁用控件必须说明原因，不能保留“可选但无效”的参数。
- 长耗时操作必须使用 `OperationStatusBar` 或等价公共组件表达运行状态，不得在各页面只写局部状态文本。
- 长耗时操作超过约 500 ms 时应显示进行中状态；可能超过 2 秒的操作应提供取消路径或明确说明不可取消。
- 运行状态语义固定为执行中、可取消、失败、已同步、结果过期；失败和过期必须保留可读原因，不允许只显示空白或单独图标。

## 分析结果页

分析结果页统一由以下区域组成：

1. 顶部工具栏：设置、刷新、复制文本、导出文本、同步状态。
2. 中央图形区：使用 `PlotBackground`，图表标题、轴、图例和提示统一字号与颜色。
3. 底部信息区：左侧摘要，右侧品牌/文件信息，固定产品级高度。
4. 底部页签：绘图、数据、文本，使用紧凑字号和统一活动下划线。

约束：

- 品牌区使用主题处理后的 S.T.A.R.Labs 标识图，不直接绘制灰块或硬编码文字 logo。
- 文件名、来源和版本信息使用同一字号、颜色和行距。
- 同一分析家族的底部区高度、字体颜色、分隔线和内边距必须一致。
- 失败状态必须保留用户能理解的错误原因，并避免显示空白图。

## 可访问性

最低要求：

- 所有按钮、菜单、图表、绘图画布、可滚动区域和可编辑控件必须设置自动化名称。
- 自绘画布如果支持鼠标滚轮缩放、拖拽平移、双击复位，也必须提供键盘等价操作。
- 焦点框必须可见，不能被透明背景或自绘层遮挡。
- 图例不能只靠颜色区分，至少结合形状、文本或序号。
- 错误、警告和成功状态不能只靠颜色表达。

当前公共实现：

- 自绘交互控件使用 `InteractiveCanvasAutomationPeer`，并通过 `AutomationProperties.Name` 和 `HelpText` 发布语义。
- 自绘图表统一保留 `Home` 重置、`+/-` 缩放和方向键导航；3D 内容的 `Shift+方向键` 表示平移。
- Ribbon 命令使用动作 ID 作为 Automation ID；分析参数使用参数键作为 Automation ID，显示文本只用于自动化名称。
- `ResponsiveTwoPaneGrid` 是 Dock 双栏文档的公共断点容器；宽度不足时第二栏移动到第 3 行。

## 主题和回归验证

涉及 UI 的改动至少验证：

- 明亮、暗夜、异世界、像素风格四个具体主题；
- 100%、125%、150%、200% DPI；
- 主窗口最小支持宽度、普通全屏宽度和窄 Dock 分栏；
- 键盘 Tab 顺序、Enter/Escape、图表键盘缩放/复位；
- 关键文字对比度；
- 分析页底部信息区和品牌区高度一致；
- 相关 GUI 契约测试。

- 优化向导、执行优化、公差运行/向导、变量滑块、库存匹配/搜索的主动作使用现有 `accent` 主题角色；取消、重置、导出保留次级。禁用提示说明当前条件，周围标签与说明保持正常可读性。

## 镀膜实验室界面适用范围

独立镀膜 App 首版复用正式 `BlueThemeTokens`、`UiDensity` 和 `NumericDisplayFormatter`，采用 Light 风格；不读取主程序当前窗口、镜头、主题或用户显示设置。不要把正式 App 的四主题回归结论套用于实验室。主窗口最小 820×640 DIP，实际控件测试覆盖 1200/820 DIP 宽、900 DIP 高。

默认主动作是生成膜系和优化；参数、膜层表、光谱、逐项达标摘要同窗组织，高级设置折叠。材料搜索、厚度编辑及固定变量标记必须保留键盘操作；显示舍入不得改变底层厚度。输入变化同步清除旧结果，后台任务须按输入代次提交。验证范围及原生自动化超时见[镀膜验收](../validation/coating/README.md)。主程序菜单无下划线、镜头数据材料行蓝底等既有规范继续适用于正式 App。
