# 非序列场景工作区

非序列模式的主文档包含工程导航、三维模型／对象表、对象属性及任务栏。默认布局直接使用此工作区。界面使用当前主题、产品字体和语言。

命令栏左侧通过“添加对象”选择类型并添加；导入及轻量编辑操作紧邻其后，右侧放置探测器和追迹主操作。“更多”保留 STL、优化与公差、顺序调整及转换。视图方向、着色和显示光线集中在“视图设置”，底部“任务”可准备布局光线或打开追迹设置和路径分析。

## 场景设置

命令栏的“场景设置”打开当前工程的全局参数。恢复旧停靠布局时，原“非序列设置”侧栏直接显示同一编辑面板：

- 场景名称、环境介质及实际对象／光源／探测器计数。
- 独立波长表：编号、波长 nm、权重和主波长选择。长列表在表内滚动，窄侧栏可横向查看；悬停和编辑显示完整数值。
- 偏振追迹、相干探测与 Fresnel 分裂。
- 每条光线最大段数、最大活动分支、最小相对能量、最大源光线总数及随机种子。

“应用设置”将整组修改作为一次操作保存，可一次撤销；“重载”取回当前场景设置。未通过校验时保留输入。波长只在末尾添加或删除，保持已有光源的波长编号；仍被光源引用的末行由场景校验处理。对象修改期间保留未应用草稿并提示重载，切换文件后载入新工程的设置。追迹窗口打开时读取当前场景的追迹限值，仍可为单次追迹调整参数。

## 导航和选择

- **结构**：展开对象的参考坐标层级及用户分组。标准透镜可展开前、后表面。
- **光学**：按光源、材料、探测器和坐标参考查找同一批对象。
- **仿真**：打开追迹设置、布局光线、分析追迹、探测器、光线路径以及优化与公差。
- 搜索名称、材料或对象编号时保留匹配项的祖先路径。清空搜索恢复完整导航。
- 树、三维模型和对象表共用对象选择。Ctrl／Shift 配合原生树或表格进行多选；三维模型支持单击选择及 Ctrl 增减选择。拖动仍用于旋转，Shift 拖动平移，滚轮缩放。

树分支按展开状态创建；单层超过 128 项时按范围分页，展开后才创建这一页的原生控件。材料导航和结构导航通过稳定对象 ID 引用同一个对象；重排对象表不改变分组与选择集的成员身份。

## 查看与编辑

三维模型使用主程序已有的场景几何和绘制控件，并按真实几何的投影范围等比适应视口。旋转期间保持已拟合的相机比例，切换方向或显式适应时重新拟合。定位将所选对象移至视图中央；隔离只显示所选对象及相关光线路径，显示整机恢复完整视图。光线显示最多 800 条已有布局分支；准备布局光线和分析追迹分别从现有计算入口运行。

对象表保留逐项编辑、排序、滚动和原参数列。单选属性可编辑名称、参与追迹、显示、局部位置／倾斜、参考坐标、介质包含及原有类型参数和 BSDF。多选属性显示公共值，混合值显示“多个值”；只应用修改过的字段，局部位置仍相对于各对象原来的参考坐标。一次批量应用或批量删除对应一次撤销。外部仍引用所选对象时，删除保留原场景并给出原因。

单选属性先显示名称和参考关系，再按轴并排显示位置与倾斜，几何／光源／探测器参数分别分组。输入框限制在属性视口宽度内，应用按钮固定在下方。导入散射等异步更新后，按稳定对象身份恢复选择和最新资料。

显示开关与参与追迹分别设置。隔离、搜索和模型／表格切换保留物理处方。任务栏显示当前分析会话的实际状态；源文件切换清除旧选择、隔离及过期模型，异步返回的旧场景不会覆盖新工程。

## 分组与选择集

“整理”提供新建分组及保存选择集。树的右键菜单可将对象移到已有分组或工程根目录，并可新建子分组、重命名及删除分组／选择集。选择分组或选择集可选中其成员。删除分组保留对象，子分组回到上一级；删除对象同时清理其组织成员身份，撤销会一起恢复。

组织文件夹独立于物理参考坐标和介质包含。分组、选择集以 `Organization` 随 STAROPT 工程保存，采用按需工程载荷 v29；没有组织数据的工程继续使用其原有按需版本。组织调整不改变场景的光学身份。历史交互原型保存在 [2026-11-23 预览目录](assets/ui-proposals/2026-11-23/non-sequential-scene-tree/README.md)。
