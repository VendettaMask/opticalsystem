# 双程零位检验与两种干涉仪修复（2026-11-01）

本轮按用户优先级处理双程零位检验、马赫–曾德尔、泰曼–格林三个菜单示例、五个配置。产品修改位于共享纯 C# Core；没有镜头名称分支、参考值拟合、口径放宽或原比较门槛修改。源 ZMX 保持原字节，旧请求、旧失败与所有中间诊断保留。

## 修复内容

1. 有限物体的虚入瞳决定发射直线，不应使光线逆着物方坐标轴发射；反向无限远视场的原规则保持。
2. 倾斜平面沿用顺序平面的唯一有符号交点，照度和口径诊断使用相同规则。交点可以为虚传播段，实际口径、材料、反射和光程仍参与计算。
3. GLSS 改变配置时重新确定反射面；补齐 PPAR 参数拾取、CURV 同列曲率拾取、PZUP 厚度拾取、GLAS 玻璃拾取及 EDVA 扩展数据配置。先应用源配置，再按依赖求解；缺源、循环、无效值显式失败。厚度、曲率的本地拾取关系随 STAROPT 保存。
4. 坐标断点的主光线 X/Y 偏心求解按当前配置重新计算。共面掠入射使用入射点，避免除以接近零的方向余弦。非零厚度坐标断点保留为透明参考平面，防止一阶矩阵丢失传播；折叠系统的标量近轴坐标按有符号处方距离展开。断点表格入射角使用其入射参考框架，不能误用变换后的平面框架；该元数据经快照保持，实际交点法线不变。
5. 非同轴出瞳使用已有共享旁基光线求解。虚出瞳参考球选择向前交点，修正 OPD 校正项的符号。

该出瞳选择与官方定义一致：顺序系统优先追迹真实旁基光线计算出瞳；OPD 包含像面到参考球的校正项。[出瞳位置定义](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26103/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Exit_Pupil_Position.html)、[OPD 参考球定义](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26103/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Exit_Pupil.html)。不据此声明任意坐标断点倾角求解、跨列拾取及所有外部求解类型均已支持。

## 仍未关闭

双程零位检验仍有旧衍射包围能量参考的低采样警告。马赫–曾德尔仍有一个场曲 Close 和第二配置旧衍射能量参考缺口。泰曼–格林第一配置仍有两份点列 Close、Huygens PSF/截线/离焦 MTF 差异、Huygens MTF Close、旧 FFT/衍射能量参考缺口；相对照度因像方方向余弦映射折叠显式不可用。不能用主光线走通、固定光线通过或高采样同档一致将这些项改写为已验收。

下一步优先解决泰曼–格林第一配置的 Huygens 工作量/完整窗口收敛和照度折叠映射，再处理旧低采样参考与场曲/点列统计定义。望远镜余项继续按独立记录处理。
