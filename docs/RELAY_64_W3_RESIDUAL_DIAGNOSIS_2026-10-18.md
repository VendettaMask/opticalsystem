# Relay 64 档第 3 波长残差诊断（2026-10-18，未关闭）

原冻结请求 `0472-n64-w3` 的实际曲线 NRMSE 仍为 **1.0480732682054777e-8**，最大绝对差 **3.6879603884654166e-10**；理想曲线 NRMSE 为 **6.371803674200336e-13**。本轮没有找到能可靠消除该差值的产品修复，因此没有把它记为精度关闭，也没有修改产品代码、原容差、旧参考或测试断言。

## 同设置重采与隔离

本机 Zemax OpticStudio 2026 R1（26.1，build 260127，许可证有效）完成 39 份原生捕获：六份原设置 DEE、六份 Huygens、十二份线性/实部/虚部 FFT PSF、三份完整网格射线审计，以及十二份缓存/收敛选项诊断。原始源文件 SHA-256 为 `b7d9b8641d60a6898b54d7533a09b67108ed7085c5e0e28f6ac4fffb4a729ea2`。

原目标保持轴上、656.2725 nm、第 3 波长、64×64 瞳采样、128×128 像面、质心参考、5 µm、401 点、Paraxial 瞄准及开启缓存。新重采与旧 `data.json` 的 SHA-256 均为 `884e1dd8b5020fdcbe1d01c82eabf8c2b45d2982f7f7ad0f13cd645264b5db25`。同设置的结果可重复；后述缓存实验不是同设置重复波动。

- 目标复振幅反变换得到 193 个有效瞳节点，与 Core 完全相同，没有支持节点差异；`|Real+i·Imaginary|²` 与原生线性强度最大差 **2.78e-17**。
- 使用原生 FFT 强度经现有累计能量积分重建 DEE，401 点跨度归一化 NRMSE 为 **1.11e-11**。这支持继续保留当前积分和输出规则。
- 回放原生发射方向后，第 3 波长像面坐标最大差 **2.56e-14 mm**；三个波长均不超过 **5.09e-14 mm**。自行瞄准的发射方向与原生缓存方向最大差约 **3.81e-10**；这区分了传输内核与发射输入，不能直接等同于 FFT 内部瞄准。
- Core 与原生目标瞳相位最大差 **1.74e-8 rad**。直接将原生射线审计发射方向代入 Core 反而使能量差异增大，说明该 API 的缓存发射输入不能当作 FFT 内部相位的替代真值。

## 原生瞄准敏感性

仅在独立诊断宿主的内存系统中关闭缓存，原生实际曲线相对原设置变化：最大绝对差 **8.314083865812449e-10**，401 点跨度归一化 NRMSE 约 **2.83e-8**。该变化大于原目标产品比较的绝对差，但它是不同算法选项间的敏感性，不能据此直接把所有差异归咎于 Zemax。

开启 Enhanced Ray Aiming 和 Advanced Convergence 后，原生曲线相对原设置变化约 **3.49e-9**，当前 Core 对该诊断曲线约 **6.92e-9**。宿主曾请求关闭缓存，原生模型读回却为 `UseRayAimingCache=true`；记录以模型读回为准，没有称该设置为“增强瞄准且无缓存”。单独关闭缓存并打开 Advanced、但不启用 Enhanced 的实验也保留其真实身份，不能当作稳定的高精度真值。

原生文档说明[缓存复用先前瞄准迭代](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v252/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Ray_Aiming.html)，[增强瞄准的选项](https://optics.ansys.com/hc/en-us/articles/42661958377491-Introduction-to-Enhanced-Ray-Aiming-and-Ray-Aiming-Wizard)会改变算法行为。本次“原生近似参与差异”的判断来自上述捕获和隔离，是限定设置的推断，不是官方公开的误差规格。

## 高精度辅助核对与未采用的候选

诊断程序另以 C# `decimal` 计算该同轴球面中继的子午折射和相对光程，停面瞄准残差检查为不超过 1e-21 mm。输入仍沿用导入处方及双精度折射率，只用于隔离运算舍入；它不是第二套产品引擎，也不替代 Zemax 精度权威。

该辅助计算对原冻结实际曲线的 401 点跨度归一化 NRMSE 仍为 **1.0151725652421689e-8**。当前 Core 对辅助结果约 **2.7730614749889757e-10**，最大原始 OPD 差约 **3.72e-10 waves**。这表明简单增加光程运算位数不足以消除当前原生差异；仍不能宣称所有物理误差均已排除。
