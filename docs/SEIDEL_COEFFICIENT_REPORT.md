## 数值定义与修正

换算依据为 [Ansys OpticStudio 官方 Seidel Coefficients 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Seidel_Coefficients.html)。Core 长度为 mm；以下 λ 使用 mm，n′ 和 u′ 分别为所选波长下最终像空间折射率和近轴边缘光线斜率。

- 逐面和累计值以未舍入的 `double` 换算，最后统一显示六位小数，不能先从显示表读回六位数再换算。
- 波前系数依次为 S1/(8λ)、S2/(2λ)、S3/(2λ)、S4/(4λ)、S5/(2λ)、CL/(2λ)、CT/λ。
- 横向单色换算公因子为 −1/(2n′u′)，轴向单色换算公因子为 1/(2n′u′²)；十列对应的组合依次是 S1、S2、3S2、2S3、S4、S3+S4、3S3+S4、S5 和两个色差项。
- 横向色差为 CL/(n′u′)、CT/(n′u′)，轴向色差为 CL/(n′u′²)、CT/(n′u′²)，不能机械地对全部轴向列套用单色符号规则。
- W220S/M/T 分别为 (S3+S4)/(4λ)、(2S3+S4)/(4λ)、(3S3+S4)/(4λ)。
- S5 移除原有多余负号，使用与 `(Ā/A)(S3+S4)` 等价的无除法表达式，避免 A=0 时错误置零。
- CL/CT 使用最短、最长已定义波长相对于所选波长折射率的相对色散变化；移除原有多余曲率因子。平面折射界面不应因此丢失色差贡献。
- 佩兹伐半径为 `−1 / (n′ × Σ[c(n_after−n_before)/(n_before n_after)])`，求和仅含内部物理面。
- 像方边缘光线斜率为零或无效时，横向/轴向换算显示 `—` 并注明未定义；不伪造零值。
