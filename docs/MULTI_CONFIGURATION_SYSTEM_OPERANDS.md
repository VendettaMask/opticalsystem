# 多重结构的视场与波长操作数

2026-11-27。第一批接通五类已有真实系统模型的数值行，扩展原有表面行，不另设计算引擎。

| 代码 | 目标编号 | 数值及单位 |
| --- | --- | --- |
| XFIE | 从 1 开始的视场号 | X 坐标；角度视场为 °，物高／像高为内部 mm |
| YFIE | 从 1 开始的视场号 | Y 坐标，单位同上 |
| FLWT | 从 1 开始的视场号 | 非负视场权重 |
| WAVE | 从 1 开始的波长号 | µm；当前模型下限为 0.001 µm，不把非法输入悄悄夹到下限 |

名称及目标类别按 [Ansys 多重结构操作数定义](https://ansyshelp.ansys.com/public/views/secured/zemax/v26103/en/opticstudio_user_guide/OpticStudio_Help/topics/Multi_Configuration_Operands.html)核对；ZMX 波长单位及非毫米视场转换沿用正式导入器。定义核对和本地验证不等于新增原生数值认证。

## 已接通的链路

- ZMX 固定值及变量行保留原有顺序，FLWT 也写入每个结构的实际视场权重。非法数值、缺失编号明确拒绝。
- 桌面可新增、编辑、重排和删除五类行。编号列用 `F1` 或 `λ1` 区分视场和波长，编辑区显示实际单位。APER 继续保留系统孔径只读摘要。
- 各结构的系统行独立，不使用表面参数的隐式基准链接。显式仿射拾取与表面行共用依赖图，比例／偏移以编辑器单位计算；支持混合行依赖、原子失败回滚、变量／拾取互斥。
- 正式 DLS 和独立评价副本消费相同类型绑定，可联合优化多个结构；MCOV／MCOG／MCOL 读取同一实际行值。候选和主工程隔离，提交可整体撤销／重做。
- 系统选项中的普通视场／波长编辑同步拾取，拒绝直接改写拾取目标。删除会使已有行改变编号时明确拒绝；先移除相关多配置行再删除，不把引用静默移到另一项。
- 插入／删除光学表面不改变视场及波长编号；工程克隆、增加结构和保存重开保留类型、变量及拾取。
- 更新实际波长会使共享光学计算及缓存失效。完整镜头缩放时，长度型视场按长度缩放；波长、角度和权重不随机械缩放改变。

## 保存及验证边界

带五类系统行的工程按需使用 STAROPT 载荷 v32，容器仍为 2、顺序快照仍为 11。沿用 `Kind`／`SurfaceNumber` 绑定字段，后者在这些类型中解释为一基目标编号，不是表面号。值保存在各结构的真实视场／波长快照里；不重复存一份表格数值。旧版本夹带新行类型会拒绝，其他工程继续按自身功能选择较低版本。

本地变量的初始搜索范围沿用产品的局部范围策略：视场坐标至少覆盖初值 ±10，波长／权重至少覆盖初值附近 1；波长及权重有物理下限。这是优化搜索范围，不是外部软件默认值或数值容差。

ZMX 中尚未核实的求解代码仍保留原诊断，不自动当作仿射拾取执行。此次未实现 TEMP／PRES 的完整热光学链路、所有孔径／光阑／系统状态行，也没有增加评价函数注册表中 341／383 的可执行数量。后续见[接通计划](OPERAND_COMPATIBILITY_PLAN.md)。运行结果及实际画面集中记录在[当前状态](CURRENT_STATUS.md)。
