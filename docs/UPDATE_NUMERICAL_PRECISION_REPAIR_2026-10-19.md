# 更新后自动导数精度与分层回归修复

日期：2026-10-19。审计基线为 `38fddb1dcc4e77ea162c2388b325b560b94a930e`。本轮检查更新新增的共享 Core 自动导数、优化参数绑定和 AutoLens 调用，并重算既有衍射矩阵；原容差、原生参考、设计规格和旧断言均未修改。

## 确认问题与实现

| 问题 | 修复前影响 | 当前行为 |
| --- | --- | --- |
| 自动除法的量级与相消 | `b²`、导数系数或分别舍入的贡献上下溢，把有限梯度变成 0、Infinity 或 NaN。例：`1e308/x`，`x=1e308, x'=1e308`，正确导数为 -1，旧值为 0。 | 普通量级保留原次序；危险量级以二进制规格化组合乘积和舍入余项，再恢复指数。真正不可表示的梯度及零分母仍不可用。 |
| 优化坐标与处方不一致 | 有限坐标乘 Scale 溢出，`1/Infinity` 把要求的曲率静默变成平面；读写下溢、无关系数编号绕过重复检测，以及绑定面初值不一致，也使参数与求导系统不一致。 | 读写均检查表示范围；非零量不能静默变零，无法由现有几何表示的曲率明确拒绝。除非球面系数外的参数只允许默认系数编号，绑定参数要求相同当前物理值，原输入快照不被部分修改。 |
| A2 能力门禁遗漏 | 设计光斑/近轴接口固定二次非球面项 A2 为零，却允许将它设为优化坐标，返回遗漏该项的近轴切线。 | 在设计近轴求导入口明确拒绝优化 A2；几何单项的 A2 矢高导数仍支持。这没有实现 A2 光学设计优化。 |
| App 直接引用 Core | 候选详情直接访问 Core 处方快照，触发原 `AppAssemblyDoesNotReferenceCore` 失败。 | 改读现有模块展示 DTO，材料显示含义和顺序保持，原分层断言通过。 |

首批 18 项在旧代码上为 **17 失败、1 通过**；扩展 24 项为 **23 失败、1 通过**。首个候选通过这些测试后，独立探针仍发现最小正数遗漏：`a=1, a'=ε, b=2, b'=-ε` 的真导数为 `3ε/4`，binary64 应舍入为 `ε=5e-324`，候选返回 0。最终增加贡献下溢检测，再组合、舍入。完整新增 **25 项**在冻结旧 Core 上为 **24 失败、1 通过**，最终全部通过；探针恢复正确的 `5e-324`。App 架构反例修复前 **1/1 失败**，最终通过。

新增有限梯度检查采用固定 **2e-12 相对限值**，最小正数采用精确值断言。既有中心差分步长及 `5e-7 / 2e-5 / 8e-4` 限值保持。独立核对使用解析恒等式和正式 Core 参数扰动，没有在产品中加入第二套光学引擎、外部参考或曲线修正。

## 边界

本轮认证为自动除法、列明参数边界和分层回归，不保证任意病态设计、全部自动微分算子或任意量级 Adam 二阶矩都可表示。设计求导仍限既有共轴、无限共轭、角度视场、EPD、均匀折射介质和受支持球面/偶次非球面，A2 继续固定为零。
