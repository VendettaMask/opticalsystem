## 已确定的计算架构边界

正式产品只使用 C#/.NET 计算，不包含 Python Optiland 后端或文件互操作，也不再规划恢复这些功能。通用 CPU/SIMD 数值抽象及未来 GPU 后端继续保留。Optiland 0.5.8 现有资料只保留为 validation/history 的冻结辅助历史回归，禁止新增对照；后续外部验证以已提交的 Zemax OpticStudio 2026 R1 基准为主，并明确镜头、设置、版本、单位、采样和容差。程序集及命名空间重命名单独立项。
