# 远心度分析

入口：**分析 → 光线迹点 → 远心度**，也可搜索“远心度”或 `Telecentricity`。

## 操作与结果

使用当前镜头中已经定义的全部视场，横轴为实际视场编号，包含轴上视场；不使用 `On axis` 标签。离散点之间的连线只连接这些编号，不表示额外的连续视场扫描。设置中的波长 **0 表示全部定义波长**，也可选择一个波长编号。

- 每个波长分别显示物方和像方远心角：同波长同色，物方虚线、像方实线，分别勾选显示。
- 图签显示本次有效主光线中的物方、像方最大远心角。
- 数据页列出视场编号、原始 X/Y 视场坐标及其单位、波长编号和 µm 值、两侧带符号 X/Y 投影角、总远心角与有效状态。
- 文本页包含最大角、有效/无效主光线数及测量范围说明。图例显隐只影响绘图，摘要仍对应本次计算请求。
- 沿用现有的细/标准/粗线宽、适应窗口、PNG、文本导出和报告绘图路径。改变线宽或图例不重新计算光学结果。配置选择沿用普通曲线的独立计算与叠加机制。

各波长独立测量，包括用户显式选择的零权重波长。不对远心角做谱加权平均，也不平均正负投影角来判断远心。最大值仅覆盖当前定义视场和所选波长中的有效主光线，不代表视场间的连续极值或制造容差。

## 计算定义

调用共享 Core 的实际光线生成与顺序追迹，归一化瞳坐标为 `(0, 0)`，瞄准光阑中心。使用去除渐晕因子的独立计算副本，避免渐晕偏移把主光线移离光阑中心；不修改原镜头、视场、孔径或配置。

物方使用发射方向在物面坐标系中的分量。像方追迹在像面传播和物理孔径检查后、像面交互前停止，使用到达方向在像面坐标系中的分量。因此像面的折射、膜层交互和曲面法线不替代像方光轴，也不改变已经到达的主光线角。

对相应局部方向 `(dx, dy, dz)`：

```text
总远心角 = atan2(sqrt(dx² + dy²), |dz|) × 180 / π
X 投影角 = atan2(dx, |dz|) × 180 / π
Y 投影角 = atan2(dy, |dz|) × 180 / π
```

总角为 0–90°，0° 表示平行于该空间的局部 Z 轴。正反传播方向均以轴线的平行程度表示，适用于折叠坐标；投影角保留局部横向符号。度为正式输出单位。此定义与[主光线平行于光轴的远心定义（Ansys Optics）](https://optics.ansys.com/hc/en-us/articles/42661811743251-Modeling-a-lens-that-is-telecentric-in-image-space)一致；[Edmund Optics 的说明](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/distortion-and-the-telecentricity-specification/)也将远心度作为以度表示的剩余角度。

有物方远心发射设置的系统沿用共享生成器的物方 NA 契约。分析本身不以开关值、近轴出瞳位置或镜头名称代替真实光线测量。

## 无效结果与验证范围

瞄准失败、被物理孔径遮挡或未有效到达像面的主光线保留无效状态、表中 `—` 与曲线缺口，不填 0°。部分有效时最大值仅取有效结果；全部无效时分析不可用。

新增 `TelecentricityAnalysis`、应用目录/设置/菜单、类型化的视场编号轴和最大角摘要。类型化整数刻度、物方/像方独立图例与大字号两行摘要共用实时和导出源图。

验证采用独立自由传播几何、理想薄透镜的物方/像方远心布局、局部倾斜像面、物理遮挡、波长选择及取消，并运行菜单示例中的 Double Gauss 实际分析页与 PNG 导出。专项结果及范围见[证据目录](../validation/rechecks/2026-11-26/telecentricity/README.md)；不将这些检查称为全部 95 示例的新数值认证。
