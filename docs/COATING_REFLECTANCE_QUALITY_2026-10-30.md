## 通用目标与求解

对实算指导谱点定义损失 `ℓ=R`（减反）或 `ℓ=1−R`（高反）。指导网格达到原目标后，以起点最差损失 `L0>0` 归一化，引入一个辅助上界变量 `z∈[0,1]`：

`min z，约束 ℓ(λ_i)/L0 ≤ z`

这让全部谱点共同限制最差损失，避免可行区内失去优化方向。原有增广拉格朗日分阶段方式处理不等式，质量残差为 z，N 条约束按 `1/√N` 归一化；加密后相应缩放乘子和罚项，保留既有约束的系数。物理下界为零时直接保留；没有可变膜层时不运行优化。没有新增固定的可行侧经验权重。

所有膜厚变量仍使用共享 Core 按实际材料 n/k、波长及角度计算的相位/衰减尺度。DLS 使用共享膜厚灵敏度组装 Jacobian；Nelder-Mead 和 Coordinate Pattern Search 仍由原正式优化器计算。只把声明可变的膜层设为优化变量，质量上界是独立辅助变量。没有材料名/ID、特定膜层编号或某个规格签名分支。

可行性与质量阶段共用用户的一次 `MaximumIterations` 上限；进入可行区时不重新领取一份完整预算。保持原分阶段自适应指导采样及有界点数，期间保留已实算的最好候选。这是局部、有采样和工作预算的最差损失优化，不证明连续波段全局最优或任意材料必然改善。

## 原验收与保护

只有原 `Checks` 与原 `Converged` 决定达标，两个函数源码与本轮基线一致。完整优化对原输入和质量结果作原密集复验；若质量阶段之前已获得新的膜厚结构，也独立复验该起点。按实际达标状态优先、随后最差反射质量选优，保留更好的合格结果。原输入不合格时，也不因为质量指导满足就跳过正式验收。

`GeneralWork` 增加可空/缺省兼容的阶段记录：

- `QualityProtocol: "feasible-worst-reflectance/1"` 只在实际执行质量优化步骤时出现。
- `QualityPasses` 是 `ConstraintPasses` 的子集，`QualityIterations` 是总 `Run.Iterations` 的子集，不能再相加算总工作。
- 质量阶段的实际谱点、灵敏度点、解析批次和加密工作已经进入原相应计数。
- `Run.QualityStartLayers` 保存质量阶段起点，用于复验及追溯；完整复验计数可能由 2 次增加到 3 次。它是结果元数据，不进入输入指纹。

保持 `general-constraint-coating/4` 家族身份，新增阶段由上述单独版本标识。旧文件不补造历史质量工作；已有原子保存、64 MiB 限制和材料快照规则保持。膜厚改变后 R/T/A 均由同一 Core 重算，不增加新的吸收或透射目标。
