## 共性修复

几何能量的原生兼容绘图现在统一从开放的零半径边界开始，包括完全聚焦的有焦光束。此前只在无焦参考模式处理该边界，有限光束因浮点舍入会在零半径出现非零累积能量，并进入样条插值。物理几何能量 CDF 仍保留闭边界，未丢弃中心光线或更改功率。

广义场曲现在对每个入瞳 X/Y 扰动保留两个横向输出分量，由差分光线 `p + z a` 的横向距离极小值求焦点：`z = -(p·a)/(a·a)`。旧公式混合两束光线的行/列，旋转与耦合系统会出现错误焦点。四组 0°/30°/45°/60° 独立后台原生控制提供 24 项 FCGS/FCGT 依据，形成活动夹具；最终 Core 还验证像面滚转 90° 的不变性。

跨系统复验又发现世界 X/Y 向已在像面局部坐标中的结果重复投影，会在折叠像面退化。现在直接使用像面自身的正交横向坐标。中间六项退化完整保留；修正后，跨 95 支来源中被选中的 **156 项原通过几何能量/场曲请求全部保持**，含分光器、棱镜、泰曼–格林与三配置扫描镜。倾斜像面 FCGS/FCGT 操作数的既有拒绝仍保持，验证其绘图不等于新增操作数能力。

一阶量控制读取晶体出口的固定走离约 -5.457143 mm，以及后续理想透镜的真实差分方向。原生近轴读回带有该固定偏移，其 EFFL 标量与实光线差分光焦度不等价；从这些控制判断，存在全局轴/偏置的定义冲突。原生实光线微分、声明的理想透镜与当前 Core 光焦度相符。官方 [EFFL 定义及非近轴适用性说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Optimization_Operands_Alphabetically.html)明确提示非近轴系统的局限。该观察不作为将 125 升级为 Pass 的理由，后续仍须明确相同一阶量定义及适用性。场曲的原生说明见[官方定义](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Field_Curvature_and_Distortion.html)。
