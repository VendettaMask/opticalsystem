## 已实现的启动路径

独立 `FlatStartBootstrap.Solve` 使用 `strict-flat-bootstrap/v1` 身份，要求规格带 `FlatStart` 设置。旧种子生成器和运行服务显式拒绝新规格，避免无提示地套用旧预弯曲算法。JSON 中空的 `FlatStart` 字段不序列化，因此旧规格指纹保持原样。

每个根全部曲率精确为零。入瞳直接取目标焦距/F/# 的 30%，不依赖 Core 平板焦距接口返回的 0。用单位高度、零斜率的近轴光线得到矩阵 C 项，建立有限光焦度残差；同时以实际像面截距建立多项残差向量。中心差分雅可比与阻尼步更新无量纲曲率和有界像面间距，记录根、首次更新、后续改善及独立加密重算。

P1 固定中心厚度、空气隙和材料，使用第一片前表面光阑，只评价轴上主波长。材料必须是具有声明有效波段的目录项，超范围波长不会作谱外延拓。检查固定后焦、边厚、空气边缘间距、表面可构造域、总长和实际通光。所有雅可比扰动、试步和最终验证均计入评价预算，总光线数包含近轴和真实光线。取消会抛出取消信号；时间截止、预算耗尽与停滞具有不同状态。这条引擎路径尚未接入检查点恢复与桌面按钮。

每个结构有两次被接受的曲率更新。最后从快照建立新对象，以 49 条真实光线重新计算；搜索每次使用 17 条真实光线，另各有一条单位近轴光线。验证光线全部到达像面，没有几何约束违反。

以上通过的是**启动门槛**：光焦度相对误差 ≤2%，截距 RMS/实际入瞳半径 ≤2%，通光率 100%。它不等于完整 F/8、多色、离轴像质达标；新路径不会发布 `LabAccepted` 候选。
