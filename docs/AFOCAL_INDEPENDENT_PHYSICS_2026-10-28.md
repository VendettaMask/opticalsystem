# 无焦独立物理与探针稳定性验证（2026-10-28）

基于 `9ee9cd547688a8876287d8420635b1ddd20e2873`、分支 `fix/afocal-precision-20261028`。只新增测试、离线结果汇总和文档，本阶段未修改共享 Core/AutoLens。原生参考、原始门槛与150项历史结果不变；没有运行Zemax、GPU或用户电脑，没有推送发布。

## 假设与独立期望

测试处方是空气中的直径2 mm圆形光阑、平面传播、无限远物体，波长0.55 µm、均匀照明、无偏振和零像差。仅验证标量近轴无焦衍射，不扩展到大角度矢量传播。测试直接导入此简单处方，运行共享 Core FFT；不依赖任何新原生数据，也不使用Cooke/Tessar。

独立解析期望：`I/I(0)=[2 J1(v)/v]^2`，`v=π D θ/λ`；圆瞳非相干MTF为 `2/π[acos(ν)-ν sqrt(1-ν²)]`。角坐标用mrad，故λ以µm、D以mm可直接代入。J0/J1用测试内幂级数求值；MTF从完整输出PSF直接求离散傅里叶和，对比圆盘重叠面积公式。没有调用被测实现构造期望。

离散Parseval检查使用独立枚举的圆内节点数M与输出边长G：在产品峰值100的约定下，`sum(I/100)=G²/M`。这不是绝对光功率认证。90°旋转采用明确非对称相位 `0.21x+0.13x²+0.09xy`，同时旋转输入相位坐标并检查完整PSF的预定索引映射；不是为匹配原生结果尝试旋转，也不是折叠系统整体坐标系认证。

有限圆瞳栅格的解析比较采用事先写入的保守O(h)预算 `8/(N−1)`，不会改变原生门槛。该预算是粗离散一致性检查，不应称为原生高精度通过；实际误差单独记录。浮点离散守恒相对门槛为2e−12，旋转/零填充强度绝对门槛1e−10（峰值100）。

## 结果

[测试源码](../tests/OpticalSystemDesign.ZemaxComparison.Tests/AfocalIndependentPhysicsTests.cs)包含8个测试身份，首轮及补充输出后的最终轮均8通过、0失败/跳过。第二轮只增加证据字段与有限窗口诊断，没有放宽门槛。每轮测试报告约1秒，最终TRX运行窗口2.76秒；包含构建的命令各设180秒上限。没有重跑150项或全库。8项中3项探针测试只断言数据有限且光线有效，**不代表稳定性通过**。

| 瞳孔N / 输出G | Airy最大绝对差（峰值1） | MTF最大绝对差 | Parseval相对差绝对值 |
| --- | --- | --- | --- |
| 32 / 128 | 0.00685834 | 0.00574685 | 5.66e−15 |
| 64 / 256 | 0.00235254 | 0.00258841 | 2.10e−14 |
| 128 / 512 | 0.000623668 | 0.000465401 | 6.00e−15 |

此三档误差下降，属于本次采样范围内的收敛证据，不推断所有采样单调收敛。固定N=64、G从128增至256时，同角坐标样本最大差2.13e−13；`sum(I)×角步长²`相对差2.26e−14。**零填充缩小步长但保留同一傅里叶周期，不是扩大物理窗口**。非对称相位90°旋转后的最大差1.28e−13。

另分开记录有限半径截取，不能强令截窗能量为1：N128/G512时，半径0.2/0.4/0.8 mrad内的离散周期能量比例为0.677136/0.846042/0.934000；无限平面解析包围能量为0.701567/0.845635/0.933378。0.2 mrad小窗有明显像素边界积分误差，未作为高精度通过；这些是诊断数据，没有调窗口或归一化来匹配。

## 真正值得继续定位的敏感性

5档归一瞳孔探针 `h=1e−2,3e−3,1e−3,3e−4,1e−4`，单次只改变h；另外双筒复合出瞳采用三档独立方向探针 `3e−4,1e−4,3e−5`。共15组四光线笔形束，30次三点复合出瞳计算，保留全部50条记录及坐标。

- Apochromat_prism控制：X/Y尺度比跨h范围变化仅约5.29e−13，切向直径约9.88096974533 mm，表现稳定。
- 双筒配置1/2：X/Y尺度比分别从h=1e−2的0.999999502069，变成h=1e−3的0.999995020650，再到h=1e−4的0.999950203999；总跨度49.2981 ppm。缩小探针并未带来稳定平台。不能用“更小h更准确”直接改参数。
- 双筒固定h=1e−3时，方向探针三档得到直径3.75096353293、3.75094691051、3.75094504328 mm，跨度4.92933 ppm。h与方向角的敏感性已分开；小拟合残差不能保证直径稳定。

相关共享Core位置：`ImageSpaceAnalysisSupport.AfocalFftPupilAspectStretch`（固定h）、`CompoundExitPupil`（固定h并使用默认方向探针），以及 `ExitPupilGeometryEngine.Compute`（方向探针与交会拟合）。这已证明数值结果对探针敏感，但尚未区分追迹/瞄准误差、数值消减与估计器截断误差，不能断言已找到六项原生网格差的根因。

**没有改上述Core函数。** 后续若协调修改共享Core，应先用已保留的正负端点坐标检查导数误差量级与追迹精度，再确定有误差估计的尺度算法；不能选一个恰好贴近原生的h。该潜在改动会影响FFT纵横比例、自动角步长及依赖出瞳尺度的结果，需要与AutoLens共享代码工作协调。

## 生产链覆盖复核与补充（2026-10-28）

原8项并非只验证参考：3项圆瞳、零填充和旋转均直接调用ComputeFftPsf；其中旋转使用准备好的非对称相位瞳孔，3项探针只检查有限值。实际缺口是MTF由测试内直接傅里叶和得到，没有检验生产MTF轴/幅值；也未覆盖ComputeHuygensPsf的无焦远场分支。已有其他原生比较不能替代这个独立解析检查。

现对原3项圆瞳测试增加ComputeFftMtf及ComputePsfMtf两条生产路径，分别检验T/S幅值和cycles/mrad频率轴，期望仍来自D/λ与解析圆盘重叠面积，不从被测元数据推回。新增2项Huygens测试直接导入相同2 mm圆瞳、0.55 µm波长并生成真实波前，不使用preparedWavefront；固定32×32输出和0.02 mrad步长，仅改变瞳孔N=32/64。逐像素用解析Airy作为独立期望。Huygens有限单元求和不是周期DFT，不套用FFT Parseval或把截窗能量归一为1。仍仅适用标量近轴、均匀圆瞳。

5项定点验证全部通过（原3项扩展+新增2项，不是新增5项）；测试报告约1秒，命令硬上限180秒。生产MTF最大绝对差N32/64/128分别为0.00574685、0.00258841、0.000465401；轴与独立D/λ标尺误差在1e−12内。Huygens全窗口Airy最大绝对差为0.0237125与0.0114679（峰值1），随两档采样加密下降，仍是百分比量级，不能称为原生精度认证。保留事先既有的宽松8/(N−1)离散预算，没有调整原比较门槛。未证明新的计算缺陷，不修改Core。未重跑其他旋转/探针/150项；原3项Difference和6项自动网格Incomparable不关闭。
