# 瞄准镜 Fourier / Huygens MTF 随视场，2026-10-31

本轮 Fourier 六频率的 T/S 共 12 条曲线已按收敛后的 Zemax 通过。Huygens 已修复两处共享 Core 的实际计算差异，同采样多色曲线全部通过，但原生与 Core 的窗口、瞳孔积分尚未全部收敛，**Huygens 最终精度检查点保持开放**。不能把同采样一致、未收敛的高采样值或 `Close` 当作最终验收通过。

## 输入、单位与原门槛

物理频率为 0.1、0.2、0.4、0.8、1.6、3.2 cycles/mrad。该原生文件使用 ArcMinutes；原生频率按 `f_native = f_mrad × π × 1000 / 10800` 转换，不能直接抄入 cycles/mrad 数值。Huygens 原生积分方法读回为 Planar，排除了自动切换球面方法的猜测。

`comparison-settings.json` SHA-256 保持 `30c27e7976710867d0edc6dd4099edac54ca9e070245dea679b3afdd88fd28f5`。Modulation：绝对 1e-5、相对 0.002、NRMSE 0.003、CloseNRMSE 0.01、覆盖率至少 0.95。沿用“全部点符合，或整曲线 NRMSE 符合”的原 Pass 规则；逐点超限另行统计，`Close` 不算通过。

## Huygens：两处实际计算修正

无焦 Huygens 在像面局部方向余弦网格上计算。原来只取出瞳发射位置的图像 X/Y 分量，漏掉斜主光线的 Z 耦合。由单位方向约束，`d(sz)=−(sx*d(sx)+sy*d(sy))/sz`，传播坐标应取 `x−sx*z/sz`、`y−sy*z/sz`。共享 `ImageSpaceAnalysisSupport` 现在从实际参考主光线和像面坐标系取得该投影，同时供有限单元和 Gaussian/checked Huygens 使用。

另一处是有限采样单元的 sinc 包络和截断：包络中心应跟随图像窗口的像素偏移；几何质心偏移用于传播相位，原来错误地也移入包络。修正保持 OPD、实际光线、材料、质心定义和验收策略，不包含镜片名、配置或频率特判。

单色诊断排除了主光线法向投影、角度雅可比、反号 OPD、取消包络和取消质心等候选。原生 PSF 文本中的无焦绝对中心使用方向余弦，不能拿它减去 atan 角度来改质心。实际质心相对主光线偏移 Core 为 0.5436215 mrad，原生约 0.543622 mrad，两者一致。

| 多色、64 对 64，全部六频率 | 通过曲线 | 最大 NRMSE | 最大绝对差 | 逐点超限 |
|---|---:|---:|---:|---:|
| 修正前 | 4/12 | 0.013741646 | 0.021672081 | 2,567 |
| 修正后共享 Core | 12/12 | 0.000069650 | 0.000141704 | 0 |

另以原生 Field 2、0.587 µm、32×32 的主光线/质心两幅 PSF 交叉核验。诊断使用 DC 归一化比较形状，修正后 NRMSE 分别约 3.89e-5、4.24e-5；这两个数只是形状诊断。正式回归直接核对公开 `HuygensPsfAnalysis` 的绝对相对强度、物理轴和原 PSF 门槛，不拟合峰值或能量尺度。

正式绝对强度结果两幅均 Pass：主光线 PSF NRMSE **3.83153e-5**、最大绝对差 **3.33058e-5**；质心 PSF NRMSE **4.22326e-5**、最大绝对差 **3.72975e-5**。2,048 个像元逐点超限为 **0**。

## Huygens：尚未关闭的收敛问题

直接原生整图的 256 双采样先后遇到 120 秒及 600 秒超时。改为每次请求一个频率，六个 256 参考全部取得；128 单频与原完整曲线一致。没有把超时解释成数值结果，也没有删除失败记录。

直接 128→256 六频率 **仅 1/12 Pass、2 Close、9 Difference**，最大 NRMSE **0.035951824**、最大绝对差 **0.055747336**。自动图像间距随采样改变，瞳孔和窗口同时变化，不能视 256 为已收敛权威。

为区分两者，新后台诊断在独立、未保存的原生系统中替换一个非最大视场，保持原 2.5° 最大视场不变，依次计算原十个物理场点的 Huygens MTF 频谱。使用原生频率网格的精确节点选取六频率，再独立作自然三次视场显示重建；这是**派生诊断曲线，不是直接 vs-field 原生缓冲区**。与原生 64 完整曲线的 3,600 值对照，最大差 **4.89e-8**，小于原绝对门槛，证明该分离控制的转换精度。

固定 0.04 mrad 图像间距后：

| 独立控制 | 通过曲线 | 最大 NRMSE | 结论 |
|---|---:|---:|---|
| 原生瞳孔 128→256，图像 64 | 4/12 | 0.007346882 | 未收敛 |
| 原生瞳孔 256→512，图像 64 | 9/12 | 0.003564322 | 3 条 S 仍为 Close |
| 原生图像窗口 64→128，瞳孔 512 | 0/12 | 0.073026369 | 窗口仍显著影响结果 |
| Core 瞳孔 64→128，图像 64 | 2/12 | 0.019930119 | Core 同样未收敛 |

这里的窗口跨度由 2.56 增到 5.12 mrad；仍有结果变化，不能仅提高瞳孔采样或把窄窗口 Core 与宽窗口原生的差叫作传播公式误差。下一检查点是独立验证足够的图像窗口和瞳孔积分，再用两侧收敛后的数据判定最终差异。现有 Core 单次直接 PSF 运算预算保持不变，没有通过放宽资源/数值门槛制造通过。
