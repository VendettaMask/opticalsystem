# 无焦 MTF 随视场：原生核对与第一轮修复

本专题扩展原四份无焦文件、五个配置的结果验收。**几何 MTF 随视场五个配置已按原曲线门槛通过；Fourier 和 Huygens 尚未全部一致。**原 170 项是前一阶段的固定请求，不能外推为本专题已通过，也不将本专题的失败改写进历史结果。

后续用户确认以收敛后的 Zemax 为精度基准。[双筒高频专题](BINOCULAR_FOURIER_CONVERGENCE_2026-10-31.md)已查明约 0.132 的低采样差异，两个配置在 3.2 cycles/mrad 的 T/S 曲线对收敛参考通过；本报告原 32 对 32 的分类、数据及身份保持，不外推其余频率。

## 同输入核对

通过独立 ZOS-API `CreateNewApplication` 后台捕获 OpticStudio 2026 R1，全部请求禁止截图；没有附着用户实例、打开产品窗口或操作桌面。15 个正式请求覆盖 Fourier/Huygens/Geometric，每个使用 32 采样、Field Density 10、+Y、全部波长、移除渐晕因子、无偏振；几何关闭衍射极限缩放。共同物理频率为 **0.1、0.2、0.4、0.8、1.6、3.2 cycles/mrad**。

瞄准镜原生角单位为角分，扩束镜为角秒，双筒和棱镜复消色差系统为毫弧度。请求显式换算输入频率，并保留原生设置、单位及模型回读；没有拟合或缩放比较后的调制度。

原 `comparison-settings.json` 保持不变：Modulation 绝对门槛 `1e-5`、相对门槛 `0.002`、NRMSE `0.003`、Close NRMSE `0.01`、覆盖率至少 `0.95`。既有比较器按“全部点在绝对/相对门槛内，或整条曲线 NRMSE 合格”判 Pass。**Close 仍未通过；曲线通过不等于每个点均通过。**

## 实际修复

共享 Core 修正兼容模式的视场密度计数：三种 MTF 随视场均按包含两端的计算位置数解释，而非把 Fourier/几何多算一个位置。几何均匀采样按区间数构造网格；捕获的 32 采样对应 33 个轴向节点。采用此规则后，五个配置的几何轴上、边缘视场值与原生达到约 `1e-9`；完整曲线按原门槛通过。节点规则只因它影响实际输出才核对，不作为额外验收目标。

几何多频率计算复用同一视场、同一波长的实际追迹样本，仍先合成复 OTF 再求模。Fourier 稀疏瞳孔自相关的功率平均保留被遮挡的零能量样本，避免把整个名义瞳孔误当成通光区域。新增半瞳遮挡的 DC 归一化不变性检查通过。该修复将瞄准镜 Fourier 最大差从约 `0.05593` 降至 `0.05240`，**仍未通过**。

所有产品计算继续使用纯 C# 和共享 Core；没有增加实验室内的另一套 MTF 算法。

## 尚未关闭的问题与排除结果

- **Fourier 的原生分析定义差异**：同一瞄准镜的普通 FFT MTF 与 FFT MTF 随视场，在轴上、同采样/波长/实际频率时就有不同结果。3.2 cycles/mrad 分别约为 `0.2618353` 和 `0.2927880`。直接复用普通 FFT 路径的候选改法扩大了部分差异，已撤回。双筒边缘视场高频弧矢差异仍最大，尚未证明根因。
- **Huygens 离轴差异**：单视场原生 Huygens MTF 与随视场端点吻合，差异不是随视场数据读取独有的问题。单色及固定像元间隔控制仍超限，不能只归因于谱权重或自动间隔。新增原生瞄准镜边缘视场 PSF 回读的间隔为 `0.1771830876394204 arcmin`，对应 Core 的 `0.05154047096933756 mrad`。主光线法向坐标轴的候选改法虽改善双筒，却恶化瞄准镜最大差，已撤回，继续保留离轴传播/有限窗口问题。
- **扩束镜零最大视场**：原生 Fourier 没有曲线；原生 Huygens 却随相对视场变化，且首点与后续点不同。Field Density 5/20 控制仍存在该现象。Core 对同一物理视场给出相同结果；目前不能认定已一致，也没有把该项改为 N/A 或通过。
- 三类瞄准镜原生曲线在移除渐晕因子开/关时逐值相同，排除了这些请求的该开关差异。此结论仅限本批文件设置。

共新增 28 次原生捕获：正式 15、单色/固定间隔/密度控制 5、渐晕和单视场控制 7、离轴 PSF 控制 1。源文件 SHA256 前后均一致。没有修改原参考、采样或验收门槛来消除差异。
