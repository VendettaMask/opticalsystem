# 互强度消减与动态范围修复：2026-10-18

本轮修复共享 Core 的两类浮点计算缺陷：近完全相干双源的弱暗纹被相减消掉，以及先平方复响应导致本可表示的最终强度被提前判为溢出或下溢。没有替换原生参考、放宽既有门槛、读取参考值补偿运行时结果或增加 Zemax 运行依赖。

## 已修改的计算

完整源对及 FourierModes 中，两个活动源的实相关系数为 `g`。当 `g >= 0`，强度改以两个非负项组计算：`(1-g)(|a|²+|b|²) + g|a+b|²`；负相关使用反对称场 `a-b`。权重先进入振幅，再平方。Gaussian/Sinc 的 ExactSourcePairs 另直接计算退相干振幅的小量展开，避免先得到四舍五入为 1 的相关系数再相减；即使退相干功率本身下溢，其对亮源的贡献仍可表示。

Uniform 的非相干与相干分量也先在场域组合源幅度、相关权重及复响应。非相干分量使用源幅度模，保持源相位不变量。复响应的合法性按有限分量与至少一个非零分量检查，不再要求未参与归一化的响应平方和必须落在浮点范围内。真正无法表示的最终强度仍明确拒绝。

独立解析控制包含：Gaussian 暗纹原本应为约 `2e-18`、`2e-24` 的结果被算成零；退相干平方下溢但亮源贡献为 `2e-100` 的控制；源强度/响应分别为 `1e-300/1e200`、`1e300/1e-200` 时应得到 `1e100`、`1e-100` 的控制。Sinc 的负相关及真正溢出的反向控制分别保留。

双源稳定分解不扩大为任意规模协方差的稳定因子分解认证。三个及以上活动源仍使用既有源对求和及负值/范围门禁；FiniteCorrelationWindow 的非厄米有序兼容累计不改为上述 PSD 模型。FourierModes 的相关性仍由有限频谱决定，不能恢复被模态截断删去的信息。

## 多镜头 DEE 调查及撤回的候选

本机 OpticStudio 2026 R1 build 260127 / Enterprise API 重新捕获七款原矩阵镜头：Apochromat、Doublet、Gaussian Quadrature over Annular Pupils、Inverse telephoto、Relay、Offner 和主基准；独立 Cooke/Tessar 继续排除。另补三项狭缝、十八项高采样/全波长留出、三项原 MS-L7 及一项 WFNO 诊断，共 32 项成功分析捕获。三项最初使用错误 `X` 枚举的狭缝请求、首次任务键名失败均单列失败，不能计为认证。

平方根尺度及开边界候选曾使六款镜头的 32 档控制通过原数值预算，但扩展到 64/128、全波长和 MS-L7 后暴露边界节点差异。候选下原能量相关 21 项仅 11 项通过、10 项失败，其中旧 MS-L7 实际曲线 NRMSE 为 `0.007039767841231948`，超过原 `0.003`。因此候选已完整撤回，未改变产品 DEE 路径；不能将其中的六款局部改善报告成最终修复。原始候选源码、两侧数组、原生设置、失败 TRX 与后续控制均保留。

平方根尺度与边界节点规则来自输出曲线的诊断推断；公开 API 未提供这一路径的完整私有积分光瞳，本轮控制尚不足以建立适用于全部采样与镜头的统一原生公式。

七款原设置的理想/实际曲线共 5614 个强度值，重新捕获与原参考的最大差为零。这证明这些参考可复现，不表示当前 Core 在扩展 DEE 上已经全部通过。

MIL 六位玻璃号也仍未关闭。官方说明明确它由专用的内部色散模型计算，不能等同于同 MIL 号目录玻璃；本轮没有用 BK7 或线性 Abbe 近似代替来绕过导入错误。[Ansys 的 MIL 玻璃说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26103/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Using_MIL_Number_Glasses.html)是该边界的依据。
