# 斜边图像到 SFR：单色与镜头多波长

入口为 **实验室 → 成像系统 → 相机成像仿真 → 斜边 SFR**，点击“生成斜边并计算”。波长模式默认“当前镜头波长与权重”，也可选择“单色”手动输入。这一页使用当前未保存的顺序镜头快照，在线性强度域生成无噪声、一个 ROI 的测试图。计算不改变处方、权重或像距，也不自动聚焦。

本页描述局部 PSF 校验流程，与[物方棋盘场景入口](SCENE_SLANTED_EDGE_SFR.md)区分。后者支持单 ROI 以及预算内完整传感器的逐源谱成像、浮点/16 位线性交换和冻结复算；Ansys 原文全分辨率、多 ROI、独立工具、正式 MTF 与 ROM/黑盒继续按[独立计划](ANSYS_SCENE_SFR_IMPLEMENTATION_PLAN_2026-11-02.md)另行验收。

## 已实现流程

1. 选择波长模式、Field 编号与像元边长。多波长直接读取当前镜头的完整波长表和权重，禁用手动波长输入；单色使用手动波长。桌面生成 96×96 像元的解析斜边，默认倾角 5°、亚像元偏移 0.2 px，暗/亮相对线性强度 0.2/0.8。可设置一个矩形 ROI 和 ESF 半窗。
2. 共享 Core 使用真实追迹 OPD/通光瞳孔与两个方向的工作 F 数，以可分离 Fourier 积分生成选定视场的局部非相干强度 PSF。V3 将每个瞳孔样本代表的矩形单元积分为 Fourier sinc 因子，强度包含其平方。大窗口使用与直接求和数学等价的 chirp 卷积/FFT，支持任意物理步距，没有插值或隐式重采样。像面步距为像元边长除以每边采样数。检查未包裹 OPD 的相邻步长，超过 0.5 波时明确拒绝；同时拒绝强度欠采样和接触采样瞳孔周期副本的窗口。该必要相位检查不替代加密验证。
3. 将实际二维 PSF 节点投影到边缘法线，按位移排序并累积权重及一、二阶矩，精确求和解析半平面与满填充方形像元的交叠面积。这与逐节点二维非相干卷积加方形像元积分等价，支持非对称 PSF，没有用一维理想模型替代镜头。图像保留浮点相对线性强度，未经 Gamma、CFA、量化、噪声、锐化或 ISP。理想图和生成图的 8 位预览仅供观察。
4. 估计器只接收像元数组、ROI 和物理像元尺寸：行梯度质心 → 直线边缘拟合 → 按拟合法线投影至 8 倍 ESF 分箱 → 中心差分 LSF → Tukey 0.6 窗 → Fourier 幅值/DC，并校正差分与分箱响应。拟合不使用输入目标角度，也不读取参考 MTF；保留高于 1 的测量值，不人为压低曲线。空分箱、边缘窗不完整、平坦 ROI、非法数据或拟合失败会明确报错。
5. 同图绘制五条可独立开关的曲线：测得 SFR、有限 PSF 光学 MTF 及其含像元曲线、完整瞳孔光学 MTF 及其含像元曲线。有限 PSF 参考作二维 Fourier 截线；完整瞳孔参考独立积分复瞳孔的线性自相关，不依赖 PSF 截取窗口。分数单元位移按单元交叠精确求和，大采样使用零填充 FFT 线性相关，避免循环相关。两种参考都沿**实际拟合的边缘法线**，像元项为 `sinc(f nx) sinc(f ny)`，没有重复施加像元积分。横轴 0–0.5 cycles/pixel，CSV 同时提供 cycles/mm。MTF50/MTF10 取 Nyquist 内第一次下降穿越，没有穿越时显示“Nyquist 内未交叉”。

这里的斜边是选定像面视场附近的局部解析目标。使用局部恒定 PSF，不宣称完成整个物方靶标经全视场空间变化、畸变、照明和杂散光传播；当前不支持无焦系统、反射镜头或带复相位薄膜的矢量传播。图像为相对线性辐照度，不是绝对电子计数或实拍传感器标定。近竖直单直边版本不是完整 ISO 12233 合规实现。完整瞳孔参考与局部图像使用同一物理输入及瞳孔单元模型，不改变通用 FFT/Huygens 的历史采样约定，也不代表新增 Zemax/Speos 精度认证。

## 当前镜头多波长

支持 1–16 个镜头波长，保留原编号、原始权重和主波长标记。正权重归一化为 `α = w / Σw`；零权重行保留在记录中但不追迹，全部为零时明确报错，不改成等权。有限大权重先缩放再求和，避免溢出。参与计算的波长范围为 200–20000 nm，材料的实际可用范围仍由共享 Core 检查。

每个波长使用同一保存像面、同一物理像元网格和**当前镜头主波长的主光线参考点**，保留纵向色差和各波长的横向像移；不逐波长重新聚焦或移到各自中心。无主波长标记时，以原第一行作为公共参考，包括其权重为零的情况。

权重在这个相对强度流程中按**相对像面能量权重**使用。各单色 PSF 相对于其完整采样瞳孔功率归一化，先在线性强度域累加 `Σ αλ PSFλ`，再对合成有限窗口统一归一化并积分方形像元。不会逐波长先把截取窗口归一化；也没有附加 QE、CFA、光子能量换算或绝对通光量权重。完整瞳孔参考为 `|Σ αλ OTFλ|`，保留复数相位后再取幅值，不能平均单色 MTF 的幅值。复瞳孔在一次计算内共享，独立 OTF 算法不读取有限 PSF。

页面与实验记录列出实际波长、原始/归一化权重和公共参考，修改当前镜头波长表会使实时结果失效。明确打开的冻结实验仍显示其原始光谱，复算不读取当前工程的波长表。现有镜头表是离散波长定义；本功能没有插入新谱点，也不把三项空间采样检查当作连续光谱积分收敛。

当前多波长实现、两份原始镜头的八视场收敛、冻结权重及实际离屏导出见[多波长验证记录](../validation/rechecks/2026-11-02/polychrome-sfr/README.md)。页面和图签遵循统一数字显示精度，实验数据保留原始浮点值。

## 有限窗口与收敛

有限 PSF 的原始面积积分相对于完整采样瞳孔功率保存，页面显示“PSF 截取能量”。生成归一化相对斜边时明确除以该窗口功率；有限 PSF 参考使用同一个条件归一化。因此两者曲线一致不等于 PSF 窗口足够大。V3 另列“完整瞳孔对照”：SFR 与完整瞳孔含像元 MTF 的最大差、有限窗口与完整瞳孔光学 MTF 的最大差均不超过所选门限时通过。这个对照与采样加密状态分别显示，不能用一个通过代替另一个。

瞳面默认 **256**、像元每边 **8**。多波长页面初始 PSF 半径为 **24** 个物理像元，分别只加到瞳面 512、像元每边 16、半径 48；这组显式设置为短波长保留周期边界余量。单色 API 原默认半径仍为 32、扩窗到 64；切换页面模式保留当前可见采样输入，不暗中调整用户设置。多波长 API 推荐 `CameraSfrRequest.FromLensSpectrum()`。任一参与波长欠采样或窗口触及其周期副本，都将明确失败，不能跳过该波长。两种模式都比较基准图像最大差（除以目标对比度）、SFR 最大差、窗口含像元 MTF 最大差、完整瞳孔含像元 MTF 最大差；窗口还比较合成原始能量积分相对差。全部完成且逐项通过才显示采样检查通过，原门限仍为 **0.01**，不替代既有光学精度公差。

Core/API 支持 32–256 像元图像、2–10° 正负倾角、1/2/4/8/16 倍像面采样和有界瞳面/PSF 窗口。直接 Fourier/MTF 运算保持共享一亿运算预算；精确 chirp 变换按实际 FFT 蝶形工作量限制在同一预算内，每个变换长度仍不超过 2048。多波长逐带计算，保留的瞳孔、合成网格和参考变换同时受共享累计网格预算限制。超出直接预算的大幅 PSF 截线须为等间隔频率，其他大幅非均匀请求明确拒绝。不自动修改用户设置或放宽公差；加密超限或精度不足保留具体原因并记为未完成/未收敛。单次翻倍并非无限采样极限证明；高度离焦或大像差镜头可能需要当前资源范围外的窗口/瞳孔，不能把其局部截取曲线当作已收敛。

需区分内置“物镜 → Double Gauss 28 degree field.zmx”（无穷远物距）和库中的 `Double Gauss 28 degree field_2.zmx`（物距 500 mm）。后者保留了不匹配的当前像距，光斑达毫米量级；128/512 档相位仍欠采样，不能把它当作标准样例的精度失败，也不会替用户改物距或自动聚焦。另一个 `double-gauss-50mm.zmx` 同样在其保存像面严重离焦。文件、未变处方、光斑和相位证据见[Double Gauss 排查记录](../validation/rechecks/2026-11-02/double-gauss-sfr/README.md)。

## 保存、复算与导出

“保存实验”生成 `.sfr-experiment.zip`，内嵌镜头快照、波长/视场/像元/ROI/全部采样设置、浮点图像、ESF/LSF、五条曲线、加密结果、判定、算法身份及 SHA-256；CSV 用 17 位有效数字。“打开实验”和“按快照复算”不依赖原镜头文件或当前工程。当前镜头/工作模式变化会清除实时结果；明确打开的冻结实验保持来源，修改参数后重新运行使用当前镜头。

PNG 按统一 1200×900 图源加边框导出为 2404×1804，包含图签与显示的图例状态；旁边“线宽 ▾”为细/标准/粗，默认标准。PNG 预览不参与 SFR 计算。

容器保留 `OpticalSystemDesign.MonochromeSlantedEdge` schema 1 标识；单色当前模型仍为 `MonochromeLocalFourierEdge/3`，多波长使用独立身份 `PolychromeLocalFourierEdge/1`，估计器保持 `LinearEdgeSfr/1`。请求的 `UseLensWavelengths` 必须与算法身份对应。多波长每帧新增 `Spectrum` 和 `ReferenceWavelengthNanometers`，打开/保存时与内嵌镜头逐行核对权重和主波长，不接受伪造或缺失光谱。旧单色记录缺失新字段按原单色解释；V1/V2 保留原身份供查看/另存，不能跨版本复算。单色 V3 和多波长当前版均可按各自冻结快照复算，不自动升级。旧记录缺少完整瞳孔曲线时显示原三条曲线，不补造数据；曲线 CSV 的两列完整瞳孔数据在旧记录中为空。容器上限 64 MiB，校验后打开，原子保存；不是旧 `.camera-experiment.zip` 的隐式升级。工程、NSC 与旧相机模型版本保持原协议。
