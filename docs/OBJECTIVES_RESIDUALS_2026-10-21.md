## PSF 显示修复

发现两处显示路径问题，均在共享 Core 修正：

- 标量 FFT 的底层兼容开关已能排除表面和材料衰减，但 `PsfAnalysis` 未传入该开关。现由原生兼容显示路径传入；发射加权、实际通光、偏振、prepared 输入及通用构造器原有行为分别保持。
- 二维热图使用 `(-N/2+1)..N/2` 的坐标；原生截面使用 `-N/2..(N/2-1)` 的 N 个独立结点，在正端显示边界保持最后一个结点值。原代码把正 Nyquist 点一同加入样条，导致右端回绕，并改变靠近右边界的插值。现在转换为原生截面结点，再对超出最后结点的显示坐标保持末值。X/Y 截面与共享该表示路径的线/边缘扩散一起修正，二维 FFT 和光学相位不变。

## 原 32 档差异的调查依据

本轮取得以下独立证据：

1. 32 档间距相邻浮点值会使四个对角边界点一起加入或移出，得到 97/101 个有效瞳点。Apochromat2、Apochromat4、MIL 的差异可由该支持集变化复现；统一纳入边界则会让原 Cooke 等通过项退化。
2. 原生孔径仅乘 `1±1e-12`，Apochromat2、Apochromat4、MIL 的原生理想能量曲线分别出现约 **0.0132079、0.0132029、0.0132102** 的最大跳变。源镜头不保存，扰动请求与原请求分开记录。
3. 对原 19 镜头全部定义波长，采集主光线、四条边缘光线和四个对角点的三种邻近位置。在上述十个可比能量镜头的主波长控制中，临界对角光线均无追迹错误或遮拦。因此不能通过删孔径、放宽接受条件或伪造光线来修补曲线。
4. 24 份原生线性/实部/虚部 FFT 控制经正式 Core 逆 FFT 反演。复振幅模方与原生线性强度最大差低于 `3.4e-16`。Cooke 两个显式像面间距仅差一个浮点位，原生支持集就从 97 变为 101，实际累计曲线相对原控制最大差约 **0.024258**。这些显式间距控制是诊断，不替代原生能量分析的默认请求。

这些测量支持将当前残差定位到有限 FFT 网格及其边界舍入，而非几何通光或大幅光学误差；尚未找到同时复现原 32 档并保持所有旧通过控制的通用构造。微米/毫米换算次序、方向光锥、截止频率、统一边界及隔离 Snell 最后归一化的候选均未安全闭合，未进入产品计算。没有按镜头名、参考曲线、目标节点数或捕获值设置运行时分支。

Ansys 的 [FFT PSF 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/FFT_PSF.html)说明了显式像面间距会改变瞳面采样；[衍射包围能量说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v251/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Diffraction_enclosed_energy.html)说明采样会限制结果精度。上述具体浮点跳变来自本机 2026 R1 / build 260127 / 有效 Enterprise API 的实测，不作为官方通用内部算法声明。
