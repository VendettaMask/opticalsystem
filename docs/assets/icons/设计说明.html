功能图标设计规范 · 1.3

本套以实际功能名称和用户操作对象为设计依据。225 款图形覆盖 336 处界面引用与状态，其中 200 款新绘，25 款沿用已确认的专用原稿。

视觉语法

源网格为 32 × 32，普通线宽 1.65，端点及连接均为圆形。结构色用于对象边界、坐标、容器；主信息色用于动作或分析特征；辅助色用于参考线、方法标识、次要节点。保持透明背景，不把文字、按钮背景或下拉箭头画入 SVG。以 18、24、32 的真实界面尺寸检查。

先确定含义，再选择图形

先写清对象与动作，例如“对膜层锁定”“按波长观察 RMS”“导出图像”。相同对象的不同动作保留对象轮廓，以功能标记区分；不同分析则用该分析的数据结构、横向自变量和计算方法区分。常用添加、删除、保存、导航允许共享同语义图形。

MTF 的频率、穿焦、随视场不能共用折线：分别使用下降响应、穿焦峰值、视场点及场边变化。RMS 的最佳位置是最小值，穿焦 MTF 的最佳位置是最大值。傅里叶、惠更斯、几何采用采样频谱、次波圆弧与几何光线标识。PSF 用点峰与衍射环，圈入能量用包围圈与累积上升；光程差、波前图、干涉条纹、刀口检验分别采用对应结构。

主题与状态

Light 使用蓝青，Dark 使用黑洞暖灰/橙/砂金，Lumen 使用枪灰钢、冰蓝青光和分段 HUD，Isekai 以剑与魔法为背景，使用魔导书、卷轴、法阵及炼金器具，Pixel 使用深蓝/红/绿。普通、黑洞和像素保留原图；Lumen 与 Isekai 各有 225 款独立主题 SVG，保持功能含义。HUD 金属渐变与光晕只作用于图标，强调/禁用状态回退可读单色。程序保留禁用与强调状态适配；物理光线、曲线、材料和标志色不作为功能图标色更改。

长期主题方向与维护

光域固定为钢铁侠式科技 HUD：钢色金属结构、冰蓝青光、切角面板与分段仪表。异世界固定为剑与魔法世界：魔导书、卷轴、法阵、符文与古典炼金器具服务于实际功能；炼金属于该世界的器具语汇。不能仅换色或机械套同一徽章。
