# Windows 安装器：原位更新与修复

日期：2026-10-22。修复已有安装仍可通过改变安装目录建立第二份程序的问题。正式产品标识、当前用户安装范围、主程序及必装模块身份不变。

## 行为

| 已有安装与新包的版本关系 | 安装器行为 |
| --- | --- |
| 没有已有安装 | 首次安装，允许选择目录与快捷方式 |
| 版本相同 | 明确进入修复；同发布复用完整载荷、修复缺失或损坏文件；不同发布 ID 的重包仍标作修复 |
| 新包更高 | 明确进入更新，在原安装位置验证并切换新载荷 |
| 新包更低 | 拒绝，在复制或变更入口前停止 |

维护时锁定原安装目录、开始菜单组、“不创建开始菜单目录”和桌面快捷方式配置，并跳过相应选择页。`/DIR`、`/GROUP`、`/NOICONS`、`/TASKS`、`/MERGETASKS` 不能绕开；不同的请求在已有安装处维护，不在备用目录另建副本。中英文欢迎页、就绪页及按钮说明维护模式和版本关系。

识别使用当前产品的精确卸载注册键。注册目录字段不一致、无效版本、其他产品状态、载荷存在但注册信息缺失时，不猜测归属、不另建副本。仅有缺失载荷但仍保留有效注册记录，可在原目录重装修复。检测到全用户范围的同产品安装时，当前用户包停止，不静默改变安装范围。没有扫描其他用户配置或全盘搜索未知安装，也不自动认领、合并或清理历史孤立副本及无效卸载入口。

复制前重新核对身份，取得原有安装锁并恢复未提交事务，再核对注册版本和 `release-state.ini`。这让没有状态文件的平铺安装也受到注册版本的降级保护；两个版本记录都不能被用来绕开检查。现有清单校验、失败恢复、正常退出要求与用户数据保留机制继续有效；不调用旧卸载器、不递归删除旧目录。

`build-installer.ps1` 与 Inno 源入口限制自定义 `ProductAppId` 不长于生产标识的 56 字符。原生测试发现过长标识会被 Inno 改写注册键，不能让调用者指定这种标识后绕过精确查询。正常生产 ID 不改名；发布元数据新增维护策略源文件 SHA-256。

官方参考：[UsePreviousAppDir](https://jrsoftware.org/ishelp/topic_setup_usepreviousappdir.htm) 和 [UsePreviousGroup](https://jrsoftware.org/ishelp/topic_setup_usepreviousgroup.htm) 只描述沿用默认选择；本轮额外执行维护锁定。产品身份依据 [AppId](https://jrsoftware.org/ishelp/topic_setup_appid.htm)；安装前复核使用 [事件函数](https://jrsoftware.org/ishelp/topic_scriptevents.htm) 的准备阶段。

## 验证范围

Release `WindowsPackagingTests` 最终单次 **13/13**，原生安装矩阵最终单次 **49/49**。原生结果与源文件/夹具包哈希保存在下方机器账目；原始安装日志在 `artifacts/installation-policy-20261022-final/`，打包测试记录在 `artifacts/installation-policy-20261022-tests/packaging-final.trx`。

最终本轮验证汇总见[机器账目](validation/WINDOWS_INSTALLATION_POLICY_2026-10-22.json)。相关打包回归覆盖脚本、安全边界和构建参数；原生测试由 `scripts/verify-windows-installation-policy.ps1` 编译并实际运行生产安装脚本，使用随机的短独立 AppId、独立程序名和工作区目录，普通流程不启用故障开关，只有失败恢复包启用。载荷为明确不可启动的轻量夹具，不能冒充完整产品、光学计算或真实旧程序兼容认证。

矩阵包含首次安装、跨目录/菜单/图标参数维护、同版本重复与重包修复、新版本原位升级、平铺及版本布局降级拦截、状态与注册版本不一致、坏版本、目录记录冲突、缺失内置模块文件修复、激活失败后的原状态/原快捷方式恢复、唯一卸载入口以及工程/设置原字节保留。自建测试安装正常卸载，测试工程、设置和日志保留；正式安装不变。早期编译、初始化时机、长测试身份及错误快捷方式快照的失败记录保留，最终通过数不与迭代运行相加。

没有执行正式身份覆盖安装、全用户实装、ARM64 实机、图形向导人工验收、完整断电/强杀恢复矩阵、全仓库测试或签名认证。未修改安装器签名策略，也未清理用户现有的无效卸载入口。源码修复**不会改写已经下载的旧安装包**；本轮未重新发布完整产品安装包、上传、提交或推送，需后续打包才能分发给已安装用户。
