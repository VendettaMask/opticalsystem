# 无焦 Huygens 遮挡边界与快速相位积分

2026-10-31：继续在纯 C#、共享 Core 中改进明确可选的 `CheckedGaussianPupil`。本轮关闭平面光阑裁剪、中心遮挡、复合孔洞、窄小偏心孔及快速相位的独立控制；原 1e-10 强度分数门槛、参考振幅门槛及累计 100,000,000 积分工作量上限保持。默认 `NativeFiniteCell` 协议不变，不增加原生认证 Pass。

## 原因与修改

全圆瞳节点上的通光开关不能高效积分尖锐边界，小孔也可能落在方位臂之间。共享 Core 现在对无限远角视场的无光焦度、均匀介质平面前缀提取真实光阑预像：沿用正式发射器和共享表面追迹的几何探针，不复制光学引擎。圆/环/偏心圆要求预像为相似变换；矩形和多边形允许一般非退化仿射变换。布尔并、交、差沿用真实 `Contains` 语义。

积分按圆的切线、顶点和边界相交角分区，再沿每个方位切出实际通光径向区间。分区端点采用余弦映射，窄角区也随阶数细化。径向直接积分 r 并乘 2r 雅可比，避免 r² 变量在非对称复振幅中引入平方根端点。所有积分节点仍通过原物理口径追迹，几何探针不作为能量。

中心被遮挡时，高阶边界路径允许共享追迹给出未裁剪几何主光线，仅用于 OPD/方向基准；不补造通光主光线。诊断记录 `GeometricChiefReferenceUsed`。原公共波前及原生路径仍保留物理主光线要求。离轴积分和轴上归一化分别建立自己的真实光阑预像，不能用离轴裁剪瞳代替轴上参考。

快速相位原来无论误差方向都同时增加径向与方位，径向阶数默认上限仅 64。现在分别提升未稳定的方向，默认径向上限 512，仍受原累计预算限制；上限处使用相邻阶数确认，强度、参考振幅、独立方向及错位规则的验收阈值均未变。不能确认时仍返回 `Unavailable`，不输出最后粗网格。

真实相位面控制另发现，高阶积分只读几何光程而漏掉相位面光程。`GaussianPupil` 和 `CheckedGaussianPupil` 现直接读取追迹器已有的 `PhaseInclusiveOpticalPathLength`，没有再次实现或叠加相位函数。默认原生协议与普通波前接口保留。诊断明确记录光程约定及平面前缀分区范围。

## 独立精度控制

除圆相交行使用解析面积外，下表差值为峰值 1 标度的强度最大绝对差，统一要求不超过 1e-10。

| 控制 | 独立依据 | 最大差 |
| --- | --- | --- |
| 裁剪圆及两种中心遮挡环瞳 | 圆/环的 Bessel 傅里叶闭式解 | 6.22e-15 |
| 矩形减偏心圆孔及矩形孔，初始 N8/N16 | 各几何块解析复振幅相减 | 6.22e-15 / 2.22e-15 |
| 半径 0.003 mm、偏心约 0.987 mm 小孔 | 平移圆孔闭式解及解析面积 | 5.55e-16 |
| 旋转偏心多边形矩形 | 旋转矩形解析复振幅 | 2.00e-15 |
| 两组圆相交/单位瞳裁剪 | 圆相交解析面积，另查中心强度 | 1.67e-16（归一化面积） |
| 离轴双平面口径，停止瞄准开/关 | 独立区间交集及轴上参考面积 | 6.11e-16 |
| 离焦 40 / 100 / 180 的快速径向相位 | 复指数积分 sinc² | 9.63e-19 / 6.99e-19 / 1.15e-18 |
| 实际二次多项式相位面 | 独立 Cartesian 复数 Simpson/Fresnel 积分 | 2.85e-14 |

多项式控制采用 2 m 瞳孔、0.55 µm 波长，Φ=250(x/1000)²−130(y/1000)² rad，像面与相位面重合；检验真实共享追迹的相位光程和非径向积分，不额外认证相位面梯度方向模型或后续传播。其实际最终节点 69,760、累计工作量 8,510,528，不能标成只用初始 N8。

原 N8 宽窗口 Airy 控制由 4,320 降为 2,144 最终节点，累计工作量由 17,412,096 降为 10,727,424，误差仍约 8.36e-13。原 N16 控制保持 4,192 节点及相同门槛。裁剪圆和中心遮挡环瞳均在 PSF、截面和 MTF 三个应用入口通过；预算不足、阶数不足仍分别明确拒绝。
