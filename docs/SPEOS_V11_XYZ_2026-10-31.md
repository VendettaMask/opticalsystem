# Speos v11、镜面配准、White Specular 与 Zemax XYZ

2026-10-31。本阶段扩展自有 C#/.NET 共享 Core，并接通已有 NSC→光谱 W/像元→RAW/ISP、工程保存及冻结实验。最终定向回归 **229/229**，其中新增 **38** 项，零失败、零跳过；默认 Release App 和测试驱动零警告、零错误。范围、运行身份和截图见[证据](../validation/rechecks/2026-10-31/speos-v11-xyz/README.md)。没有全量测试、原生桌面验收、商业数值认证或安装包发布。

## 文件与数据模型

| 输入 | 已实现的入口与约束 |
| --- | --- |
| Speos `.anisotropicbsdf` v11 / v11.0 TEXT | BSDF 或投影量 `q=f·abs(cosθ)`、参考角 R/T 光谱、完整角表、可选 `End of file` |
| 同版本二进制 | 已核验的小端 archive-3、LZ4；标志 1 带双辅助表和 White Specular 尾记录，标志 0 为不带辅助表的已核验变体；附加字节必须为 0 |
| 镜面增强 | v7/v11 双辅助表的锥宽/高度，或界面显式锥；使用下述原生配准和分量定义 |
| White Specular | 文件开启或显式锥设置指定基准波长；镜面分量固定，漫散射保留原光谱 |
| Zemax XYZ | 三块 `TristimulusX/Y/Z`、各自 TIS 和原镜面中心角网格，须另选显式辐射度校准 JSON |

v11 保留可分的原角分布与独立 R/T 光谱，每瓣最多 256 个光谱点，避免按波长复制全部角度节点。550 nm 仅为内部角表标签，实际波长范围和响应来自保存的光谱，不是把测量当成 550 nm 单色。R/T 可有不同光谱采样，计算限于公共测量范围，不外推。仅有 0°/360° 且一致的旋转端点按各向同性解释；有内部旋转节点时保留固定材料轴。

自行查找并实际读取了本机两个 Covestro v11 文件：带辅助表材料保留 **125** 个光谱点，不带辅助表材料保留 **81** 个，均为 **40,002** 个冻结角度节点。30°、550 nm 下得到 R=0.8890626124870645 / 0.8766578737734314。这是当前导入器的结果，不是 Speos 数值对照。安装库文件不随仓库重新分发。另以官方 PySpeos 不变 v11 Gaussian 文本作正向格式回归，单正面冻结 36,290 节点，原件和 MIT 声明在测试 Fixtures。

归档中的额外有限正标量和辅助字节摘要保留在说明中；归一化与抽样表依照原角表、参考角及光谱重新计算。标量的归一化缓存含义属于本机样本的推断，公开文档未公布二进制负载，不据此声称任意同名二进制都兼容。未知标记、截断、非法压缩块、未知尾记录、未核验的活动布局明确拒绝。

## 镜面与漫散射的原生定义

锥参数与转换后的峰/背景分别冻结。显式高度为“原存储量的高度 / 本入射切片最大值”；文件高度按原表峰值换算到同一比例。锥内节点取 `vS=max(0,v−height·max(v))`，锥外取零，`vD=v−vS`。两部分分别沿原角网格插值，节点和不变且各自非负。锥边缘受原网格分辨率限制，不能恢复未采到的窄峰，不做隐藏降采样。

漫散射保持原材料坐标；镜面部分使用明确版本 **SlopePowerTransport/1**。令半球斜率 `s=(wx/abs(wz),wy/abs(wz))`，执行

` s_target = s_source + s_spec(actual input) − s_spec(measured input) `

由于 `dΩ=μ³ dsx dsy`，计算密度包含 `q_target=q_source·(μ_source/μ_target)³`，最后 `f=q_target/μ_target`。映射在有效半球内可逆，保留峰的积分功率，无截断再归一化或拒绝抽样。输入角/方位/波长和 R/T 分量按其功率联合选择；最终 PDF 是所有分量之和，权重 `f·abs(cosθ)/pdf` 等于该输入的 R+T。

反射中心取实际镜面方向，透射中心按声明 n1/n2 与 Snell 定律确定；实际介质比不匹配会拒绝。局部材料轴仍经过完整对象参考链。精确掠入射的非零峰、全反射/掠射透射中心不在此配准域内；普通无增强表格仍保留原边界行为。

这是有独立守恒与统计验证的**原生配准模型**。其斜率空间峰宽变化和锥内节点分解不等于已复现 Speos 私有的刚性峰旋转/连续锥分解，尚无开启增强/White Specular 的商业文件加原生计算结果的逐值认证。v7/v11 活动辅助表目前由独立合成归档验证，本机实际材料样本均未开启该选项；v8/v9 的活动内嵌布局继续拒绝。可对这些版本的无增强输入显式定义原生锥，完整保存声明，不隐藏忽略活动选项。

## White Specular 与能量

原生分解后，漫散射使用谱因子 `S(λ)`，镜面使用 `S(λbase)`。基准波长必须处于相关光谱范围，R/T 独立处理。非可分输入在保存的角/波长节点上固定峰值；v11 可分模型直接冻结基准谱因子。显式模式也可用于本程序支持的完整辐射度 BRDF，这是原生功能扩展，不表示原软件界面有同样的选项。

逐个输入切片和光谱分段端点校验 R+T≤1；凸插值约束整个支持域。White Specular 后超出 1 会拒绝，绝不缩放以掩盖无效测量/校准。吸收仍为剩余功率，不再叠加 Fresnel、第二次折射、探测器面积或波长权重。

## XYZ 校准契约

XYZ 不能唯一确定光谱。导入器保留原始三个通道及其 TIS，分别在实际出射半球归一化；随后应用**用户提供的非负辐射度校准映射**：

` f(λ,ω)=cX(λ)·fX(ω)+cY(λ)·fY(ω)+cZ(λ)·fZ(ω) `

三个 `fC` 指按原 TIS 归一化后的通道，不是未归一化文件行值。每个波长的积分同步组合并校验被动性；采样按通道功率联合选择。保留原镜面中心分布、BTDF 介质定义和固定轴约定。既不把 Y 当瓦特，也不经过 RGB 反演光谱。

校准 JSON 示例见 [synthetic-xyz-calibration.json](../samples/non-sequential/speos-v11-xyz/synthetic-xyz-calibration.json)。字段为 `Name`、`Observer`、`Illuminant`、`Units="radiometric-bsdf-per-normalized-XYZ"` 和 `Bands=[{WavelengthNanometers,X,Y,Z},…]`。最多 32 个波长，系数有限、非负；64 KiB 文件上限。源字节 SHA-256、完整系数、观察者/照明声明及原 XYZ 通道进入规范数据摘要和冻结载荷，重开不再依赖外部校准文件。

这是一种显式校准的响应模型，不是通用或唯一的 XYZ 光谱恢复；需要负系数的映射、缺少观察者/照明声明或校准的数据不受支持。程序校验结构、数学被动性及声明的完整性，无法由文件证明测量校准本身正确。仓库示例为合成测试，不能代替真实材料校准。

## 桌面与持久化

对象属性区增加校准路径/文件选择、显式镜面锥半角/相对高度、White Specular 基准，以及共用的入射/出射折射率。默认使用文件自带设置；显式锥会覆盖该设置。单独打开显式 White Specular 而未启用锥会拒绝，失败不修改原对象。Zemax 单色的波长/辐射度勾选仍仅用于单色；XYZ 使用校准，Speos 使用文件光谱。

这些模型使用 **MeasuredBsdfGrid/4**，STAROPT 写 **v12**；容器仍为 2，顺序快照仍为 6。包含新模型的低版本工程会拒绝，禁用对象也不会绕过版本选择。旧 v1/v2/v3 算法身份、摘要和冻结实验不升级。STARRDB 仍为 v1，协议头允许 4，原 S/B/R/T/D 筛选和介质事件保持。完整契约见 [STAROPT](STAROPT_FILE_FORMAT.md)。

文件≤32 MiB、解压≤128 MiB；Speos TEXT 原始节点≤262,144、二进制原始节点≤131,072；冻结角度节点（含峰或 XYZ 附加通道）≤131,072，文档总数≤262,144。普通网格入射角≤64、旋转≤65、输出极角≤129/方位≤257。超预算、孔洞、非负/极点/周期接缝不一致、支持域外输入明确拒绝。XYZ 沿用 Zemax 独立的 100/50/1000 维数上限和总节点预算。

## 验证与后续边界

新增 38 项包括：v11 两类归档、压缩/尾部拒绝、本机 81/125 光谱点材料与官方文本；峰移动、固定轴旋转、15°/45°/85° 独立解析密度、逆映射 Lambertian CDF/两阶矩；三波段 R/T 频数、White Specular 背景光谱及非被动拒绝；XYZ 三通道、校准/摘要/外推拒绝；两种 BTDF 在 1→1.5 介质中的账本/光程/数据库；v12 工程与低版本拒绝；四条三波段 RAW/ISP 完整链路及三条离屏控件路径。

每个解析密度控制 16,384 次采样，独立密度相对误差最大约 1.26e−11；统计以预定六倍标准差检查，不作为商业软件精度门槛。四条逐像元一次光子换算最大误差 **9.10e−13 e−**，删除源 BSDF、校准、场景和数据库后冻结 RAW/ISP 完全相等；包含新增的旧 grid3 实验，共五个历史冻结身份继续精确重放。最终运行前后 57 个范围内源码/夹具和 9 个二进制指纹一致。

尚未实现任意 Speos 二进制版本/活动 v8/v9 布局、Retroreflection 增强、delta 镜面瓣、未知 XYZ 自动光谱恢复、独立 Zemax R/T 双文件合并、逐面覆盖、体散射、偏振、相干、MIS 或角度 QE。没有将文件格式或内部解析验证当作 Speos/Zemax 数值一致性认证。
