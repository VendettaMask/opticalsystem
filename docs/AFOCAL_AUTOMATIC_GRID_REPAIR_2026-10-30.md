## 修改与依据

复合多边形系统的衍射尺度先前直接使用几何出瞳引擎的 stop-image 拟合显示半径。共享 `ImageSpaceAnalysisSupport` 现在沿用既有 0.001 归一化瞳孔探针，在主光线法向参考平面测量 chief→正 Y 光束的物理间隔，按探针尺度换算直径。几何拟合仍提供轴向位置，不提供衍射直径；显示半径、通用几何出瞳引擎和普通共轴近轴接口保持。

复合系统用单侧探针避免跨三角片接缝混合路径；采用间隔向量长度，避免像面坐标轴旋转改变物理直径。新增两配置像面仅绕 Z 旋转 90°的守卫，直径在原 1e-8 mm 检查内保持。普通折返系统原有分支保持。本轮没有增设镜头名、配置号、原生比值或拟合常数分支。

双筒计算直径为 3.7509448227177953 mm，诊断原生值约 3.7509447977 mm，仍有非零差。由轴间距反推的数值只记录在诊断中，不能进入产品计算。[原生出瞳位置说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Exit_Pupil_Position.html)说明顺序系统优先使用实光线近轴探针；[直径说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Exit_Pupil_Diameter.html)将其定义为光阑的近轴像。二者不公开任意复合系统的内部算法，不能据此宣称已复现私有遍历规则。

## 瞄准镜仍有两项网格不可比

0007 FFT 最大轴差 **1.095180861998557e-6 mrad**，最差超过原门槛 34.2725 倍；0008 Huygens 为 **2.8262731921469e-7 mrad**、28.2627 倍。坐标不合格时不计算强度 Pass，不能把固定角控制通过当成自动网格通过。

Core 近轴直径为 4.026656436147147 mm，既有实际 API 原生 EXPD 为 4.0266578161829365 mm。本轮额外用隐藏独立 ZOS-API 实例采集同一瞄准镜九条微小瞳孔/视场光线、18 面。一次首试在原生追迹后因诊断元数据缺 `originalKeys` 退出 2，原失败完整保留；补齐诊断元数据后重试退出 0，原 ZMX 哈希保持，未保存输入。这两次都不算正式光学验收 Pass。

有效重试显示，正 0.001 瞳孔光线在第一面的横向位置已差 2.8121655e-9 mm，STOP 处差 4.6756328e-10 mm，传播到共同像平面后差 7.0763805e-10 mm。Core 与原生的微小场主光线在第一面也已有差。这把最早可观察分歧缩到发射/瞳孔尺度链路，尚不足以断言是瞄准容差或某一内部插值规则。不能用原生直径替换 Core 计算值。

原生 `CurrentAndChief` 的最终面位置位于其无焦出瞳参考平面，Z=-8.23242459888831e-5 mm；Core 光线在像平面 Z=0。早期未经投影的诊断 JSON 保留但不用于同平面误差结论，后续诊断显式沿原生方向传播到共同像平面，并保留原始坐标。`image-geometry` 中 OPDMode=None 的路径列不是波前 OPD 误差。
