# 公差分析

## 范围

桌面公差工作流参考公开 Zemax 形态：向导生成、表格编辑、验证、双侧灵敏度、确定性 Monte Carlo、统计、定义保存和报告导出。实现为原生托管 CPU，不宣称覆盖全部 Zemax 选项或兼容专有 `.TOL`。

## 打开工作区

“公差”Ribbon 中的“灵敏度”和“Monte Carlo”聚焦同一公差文档。工具栏提供向导、新增、删除、验证、保存/加载公差、导出报告和运行。

## 公差向导

向导接受起止表面和商业、精密、高精密三个可编辑预设。预设是便利默认值，不是供应商保证。

| 代码 | 参数 | 单位 |
| --- | --- | --- |
| `TRAD` | 表面半径 | mm |
| `TCON` | 圆锥系数 | 无量纲 |
| `TTHI` | 厚度或空气间隔 | mm |
| `TSDX/TSDY` | 表面 X/Y 偏心 | mm |
| `TSTX/TSTY` | 表面 X/Y 倾斜 | 度 |
| `TIND` | 折射率 | 无量纲 |
| `TABB` | Abbe 数 | 无量纲 |
| `COMP` | 像距补偿 | mm |

平面跳过 `TRAD/TCON`；空气和反射过渡跳过 `TIND/TABB`。

## 数据编辑与验证

每行包含启用状态、代码、表面、最小/最大偏差、分布和注释。公差表本身可直接编辑；右侧属性面板是同步的逐行编辑辅助，不是唯一输入路径。类型列接受当前已实现的 Zemax 风格代码：`TRAD`、`TTHI`、`TCON`、`TSDX`、`TSDY`、`TSTX`、`TSTY`、`TIND`、`TABB` 和 `COMP`。分布列接受“正态/Normal/Gaussian”和“均匀/Uniform”。

验证拒绝：

- 不存在的表面；
- 非有限或倒置上下限；
- 活动零宽公差；
- 重复类型/表面对；
- 负物理厚度或像距；
- 非法折射率/Abbe 范围；
- 错误位置的像距补偿；
- 没有活动公差操作数的表格。

补偿行是控制行，不参与随机采样。

## 统计分布

- 正态：区间中点为均值，最小到最大覆盖 `6σ`，超界样本拒绝；
- 均匀：覆盖完整最小到最大区间。

固定随机种子使相同系统、表格和设置的 Monte Carlo 可复现。

## 评价准则

可选择视场/波长加权的 RMS 点列半径（mm）或 RMS 波前误差（waves）。内部优化仍使用加权残差平方和，但报告和良率始终使用物理准则。

## 灵敏度

每个活动操作数分别施加负端点和正端点；启用补偿时在每个端点优化补偿器。结果报告两端评价值、最坏评价值和相对名义变化，并按最坏绝对变化排序。每次端点计算后恢复系统。

## Monte Carlo

每个试验：

1. 从不可变名义快照构建独立 `Optic`；
2. 采样活动操作数；
3. 计算未补偿准则；
4. 可选优化补偿器；
5. 按原试验索引写回结果。

试验种子由全局种子和索引派生，因此串行与不同并行度产生相同有序序列。外层试验调度负责并行，内层追迹抑制嵌套并行。无有效评价光线的试验记为失败并计入良率。

统计包括名义值、均值、标准差、最小/最大、P50/P90/P95，以及提供非零限值时的估算良率。

## 保存与报告

“保存公差”写入 `*.startol.json`；加载时按当前光学系统重新验证。公差定义和结果与 `.staropt` 分开，保存工程不会静默嵌入研究。

报告为制表符分隔文本，包含摘要、统计、双侧灵敏度和全部试验。

## 当前限制

- 不支持 Zemax 专有 `.TOL`；
- 向导尚不生成面形、条纹、非球面系数、多配置和脚本操作数；
- 专用多变量补偿向导未完成；
- 元件刚体 `TEDX/TEDY/TETX/TETY` 需要显式元件分组，当前偏心/倾斜是表面级；
- 材料公差在参考折射率/Abbe 对附近使用 Abbe 近似；
- 计算只在快照上运行，不修改活动处方。

## 验证

回归覆盖向导、验证、双端点、变量恢复、种子重复性、并行度一致性、不同种子、取消、补偿改进、统计和良率输出。
