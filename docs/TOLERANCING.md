# 公差分析

## 范围

桌面公差工作流参考公开 Zemax 形态：向导生成、表格编辑、公差报告、验证、双侧灵敏度、确定性 Monte Carlo、统计、定义保存和报告导出。实现为原生托管 CPU，不宣称覆盖全部 Zemax 选项或兼容专有 `.TOL`。

## 打开工作区

“公差”Ribbon 分为两个主要入口：“公差数据编辑器”打开/聚焦公差操作数表，“公差分析”打开统一运行对话框。运行对话框按 Zemax 的工作流分为“设置”“评价标准”“Monte Carlo”“显示”四页，而不是把灵敏度和 Monte Carlo 做成两个内容相同的文档页。“公差数据可视化”分组提供公差数据查看器、直方图、良率和公差报告入口；它们按各自职责打开独立文档页签。公差数据编辑器只负责定义、验证、保存和加载公差，不再内嵌运行参数及结果页。

点击“运行”后，公差数据编辑器显示明确的执行中状态；计算成功后始终打开并刷新独立“公差报告”页。验证失败、计算异常或应生成的结果为空时进入统一错误提示，不再静默结束。“跳过灵敏度”与 `0` 次 Monte Carlo 不能同时使用，因为该组合没有任何可执行分析。

当前真正实现并公开的运行模式为：

- **灵敏度**：先计算补偿后的名义评价值，再逐项计算各公差的最小和最大端点；
- **跳过灵敏度**：不计算逐项端点，只执行 Monte Carlo。

逆向灵敏度和逆向增量尚未实现，因此界面不提供无效选项。Monte Carlo 次数可设为 `0`；此时只生成灵敏度结果，不伪造 Monte Carlo 统计。

## 公差向导

向导作为“公差数据编辑器”里的 Zemax/TDE 风格页面打开，而不是普通分析页设置浮层。界面由顶部工具条、左侧操作数/向导导航、中央分组参数区、底部操作按钮和下方操作数表组成。当前预设区显示供应商 `Generic` 与商用、精确、高精密三个可编辑精度等级。预设是便利默认值，不是供应商保证。

| 代码 | 参数 | 单位 |
| --- | --- | --- |
| `TRAD` | 表面半径 | mm |
| `TCON` | 圆锥系数 | 无量纲 |
| `TTHI` | 厚度或空气间隔 | mm |
| `TSDX/TSDY` | 表面 X/Y 偏心 | mm |
| `TSTX/TSTY` | 表面 X/Y 倾斜 | 度 |
| `TIND` | 折射率 | 无量纲 |
| `TABB` | Abbe 数 | 无量纲 |
| `COMP` | 像距补偿 | mm |

平面跳过 `TRAD/TCON`；空气和反射过渡跳过 `TIND/TABB`。

## 数据编辑与验证

每行包含启用状态、代码、表面、最小/最大偏差、分布和注释。公差表本身可直接编辑；右侧属性面板是同步的逐行编辑辅助，不是唯一输入路径。类型列接受当前已实现的 Zemax 风格代码：`TRAD`、`TTHI`、`TCON`、`TSDX`、`TSDY`、`TSTX`、`TSTY`、`TIND`、`TABB` 和 `COMP`。分布列接受“正态/Normal/Gaussian”和“均匀/Uniform”。

验证拒绝：

- 不存在的表面；
- 非有限或倒置上下限；
- 活动零宽公差；
- 重复类型/表面对；
- 负物理厚度或像距；
- 非法折射率/Abbe 范围；
- 错误位置的像距补偿；
- 没有活动公差操作数的表格。

补偿行是控制行，不参与随机采样。

## 统计分布

- 修正正态：区间中点为均值，最小到最大覆盖 `4σ`，即中心到任一公差极限为 `±2σ`；超界样本拒绝后重采样；
- 均匀：覆盖完整最小到最大区间。

固定随机种子使相同系统、表格和设置的 Monte Carlo 可复现。

## 评价准则

可选择视场/波长加权的 RMS 点列半径（mm）或 RMS 波前误差（waves）。内部优化仍使用加权残差平方和，但报告和良率始终使用物理准则。

公差评价按有效追迹光线统计。高 NA、遮拦或边缘采样导致个别光线未到达评价面时，只排除失败样本，并按原总权重对剩余有效样本重新归一化；只有所有加权样本均无效时才判定名义系统不可评价。串行灵敏度与并行 Monte Carlo 使用同一规则。

## 灵敏度

每个活动操作数分别施加负端点和正端点；启用补偿时，名义系统和每个端点都使用相同补偿设置。结果报告名义评价值、两端评价值、最坏评价值和相对名义变化，并按最坏绝对变化排序。每次端点计算后恢复系统。

RSS 预计变化按每个公差两端变化平方的平均值累加后开方：

`RSS = sqrt(sum((Δ最小² + Δ最大²) / 2))`

报告同时给出“名义值”“RSS 预计变化”和“预计评价值（名义值 + RSS）”。这属于灵敏度估计，不等同于 Monte Carlo 分布统计。

## Monte Carlo

每个试验：

1. 从不可变名义快照构建独立 `Optic`；
2. 在同一次试验中同时采样并施加全部活动操作数；
3. 计算未补偿准则；
4. 可选优化补偿器；
5. 按原试验索引写回结果。

试验种子由全局种子和索引派生，因此串行与不同并行度产生相同有序序列。外层试验调度负责并行，内层追迹抑制嵌套并行。无有效评价光线的试验记为失败并计入良率。

统计包括名义值、均值、标准差、最小/最大、P50/P90/P95，以及提供非零限值时的估算良率。设置中的“使用公差表分布”保留每个操作数自己的统计模型；也可以在本次运行中统一覆盖为修正正态或均匀分布。随机种子和并行度不改变有序试验结果。

## 公差报告

“1: 公差报告”是独立文档页签，不嵌在公差数据编辑器内部。报告采用 Zemax 风格等宽文本布局，包含文件名/路径、日期、单位说明、表面中心公差、表面偏心/倾斜公差、折射率/Abbe 公差和全部公差操作数。未运行分析时，报告仍可用于检查当前公差数据；运行后会按实际模式追加灵敏度 RSS 预计性能、逐项端点表、Monte Carlo 统计、试验表和良率。设置为零次 Monte Carlo 或关闭试验明细时，不显示相应伪结果。

报告页提供刷新、复制文本和导出文本。Ribbon 的“公差报告”会打开/聚焦该独立页签；编辑器里的“导出报告”直接写出当前报告文本。

## 公差数据可视化

“公差数据查看器”打开/聚焦公差数据编辑器文档页；“直方图”和“良率”分别打开独立图表页签，均使用分析模块的真实坐标绘图控件，支持滚轮缩放、拖动平移和双击复位，不再用字符条或统计文本冒充图形。

直方图读取最近一次 Monte Carlo 每个试验的补偿后评价值（缺失时回退到未补偿评价值），按样本量自动确定分箱数量并绘制柱状分布，同时显示样本数、均值、标准差和极值。良率图将同一批试验值排序后绘制经验累计分布曲线；设置非零“合格上限”时，图中增加阈值线，并显示实际通过样本数和估算良率。合格上限为 `0` 时仍显示累计分布，但不做通过/失败判定。未运行 Monte Carlo 或结果没有有效数值时，这两个页面只显示明确的空状态，不伪造分布或良率。

## 保存与报告导出

“保存公差”写入 `*.startol.json`；加载时按当前光学系统重新验证。公差定义和结果与 `.staropt` 分开，保存工程不会静默嵌入研究。

报告导出为 `.txt` 等宽文本，内容与报告页一致。

## 当前限制

- 不支持 Zemax 专有 `.TOL`；
- 尚未实现 Zemax 的逆向灵敏度和逆向增量模式；
- 向导尚不生成面形、条纹、非球面系数、多配置和脚本操作数；
- 专用多变量补偿向导未完成；
- 元件刚体 `TEDX/TEDY/TETX/TETY` 需要显式元件分组，当前偏心/倾斜是表面级；
- 材料公差在参考折射率/Abbe 对附近使用 Abbe 近似；
- 计算只在快照上运行，不修改活动处方。

## 验证

回归覆盖向导、验证、双端点、变量恢复、种子重复性、并行度一致性、不同种子、取消、补偿改进、统计，以及直方图分箱与良率累计分布输出。
