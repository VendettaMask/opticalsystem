## 范围

桌面公差工作流参考公开 Zemax 形态：向导生成、表格编辑、公差报告、验证、双侧灵敏度、确定性 Monte Carlo、统计、定义保存和报告导出。实现为原生托管 CPU，不宣称覆盖全部 Zemax 选项或兼容专有 `.TOL`。

## 打开工作区

“公差”Ribbon 分为两个主要入口：“公差数据编辑器”打开/聚焦公差操作数表，“公差分析”打开统一运行对话框。运行对话框按 Zemax 的工作流分为“设置”“评价标准”“补偿”“Monte Carlo”“显示”五页，而不是把灵敏度和 Monte Carlo 做成两个内容相同的文档页。“公差数据可视化”分组提供公差数据查看器、直方图、良率和公差报告入口；它们按各自职责打开独立文档页签。公差数据编辑器只负责定义、验证、保存和加载公差，不再内嵌运行参数及结果页。

点击“运行”后，公差数据编辑器显示明确的执行中状态；计算成功后始终打开并刷新独立“公差报告”页。验证失败、计算异常或应生成的结果为空时进入统一错误提示，不再静默结束。“跳过灵敏度”与 `0` 次 Monte Carlo 不能同时使用，因为该组合没有任何可执行分析。

每次公差运行都记录计算快照对应的工作区修订。修改公差定义或运行设置也会取消当前任务并清空已有结果，载入新的公差文件使旧结果失效。运行期间或结果生成后，只要处方、视场、波长、系统设置、配置或优化结果发生变化，正在运行的任务会被取消，已有表格和统计会标记过期并清空；报告导出还会再次核对修订，禁止把旧公差结果与当前系统参数写入同一份报告。

当前真正实现并公开的运行模式为：

- **灵敏度**：先计算补偿后的名义评价值，再逐项计算各公差的最小和最大端点；
- **反向极限**：逐项、逐侧收紧已有公差，直到端点评价值满足指定的绝对极限（RMS 上限，MTF 下限）；
- **反向增量**：逐项、逐侧收紧已有公差，直到端点评价值满足“RMS 名义值 + 正增量”或“MTF 名义值 − 正下降量”；逐视场 MTF 模式使用各场名义值；
- **跳过灵敏度**：不计算逐项端点，只执行 Monte Carlo。

两种反向模式都遵守只收紧、不放宽：如果现有端点已经满足目标，该端点保持不变；需要收紧时，在原端点到零扰动之间以有界二分搜索求允许值。反求后重新执行双端点灵敏度验证，并将调整后的公差表作为同一次运行的 Monte Carlo 输入。成功结果回写公差数据编辑器并标记未保存，报告保留原范围、调整后范围、端点状态和目标值。RMS 反向极限必须大于当前名义评价值，MTF 反向下限须低于名义值且逐视场均可满足，反向增量必须为正数，否则计算在修改公差表前终止。

Monte Carlo 次数可设为 `0`；此时只生成灵敏度或反向灵敏度结果，不伪造 Monte Carlo 统计。

## 公差向导

向导作为“公差数据编辑器”里的 Zemax/TDE 风格页面打开，而不是普通分析页设置浮层。界面由顶部工具条、左侧操作数/向导导航、中央分组参数区、底部操作按钮和下方操作数表组成。当前预设区显示供应商 `Generic` 与商用、精确、高精密三个可编辑精度等级。预设是便利默认值，不是供应商保证。

| 代码 | 参数 | 单位 |
| --- | --- | --- |
| `TRAD` | 表面半径 | mm |
| `TCON` | 圆锥系数 | 无量纲 |
| `TTHI` | 厚度或空气间隔 | mm |
| `TSDX/TSDY` | 表面 X/Y 偏心 | mm |
| `TSTX/TSTY` | 表面 X/Y 倾斜 | 度 |
| `TEDX/TEDY` | 显式起止面元件 X/Y 刚体偏心 | mm |
| `TETX/TETY` | 显式起止面元件 X/Y 刚体倾斜 | 度 |
| `TPAR` | 偶次、奇次或 Forbes Q 非球面参数 | 系数单位 |
| `TIND` | 折射率 | 无量纲 |
| `TABB` | Abbe 数 | 无量纲 |
| `COMP` | 像距补偿 | mm |

平面跳过 `TRAD/TCON`；空气和反射过渡跳过 `TIND/TABB`。桌面向导的“元件偏心/倾斜”按连续玻璃介质自动识别元件组并生成显式起止面，不再把“元件”标签映射成单表面操作数。胶合组会持续到下一空气边界。`TPAR` 只为已经存在的偶次非球面、奇次非球面和 Forbes Q 系数生成，参数序号从 `1` 开始。

## 执行按钮与禁用条件

“公差分析”的“运行”和公差向导的“确定”采用统一蓝色主要按钮。取消、重置、报告导出保持次级；公差向导同功能的“应用”也保留次级，避免两个并列主动作。

反求参数仅在反向极限/反向增量模式可用，补偿循环在选择 DLS 或坐标模式搜索补偿时可用；禁用控件提供可悬停查看的原因及无障碍说明。向导中保存/载入/验证等兼容占位入口指引回公差数据编辑器，不规则度和独立帮助等尚未实现的功能仍明确禁用。周围标签与解释维持正常文字对比度，计算规则和事件未变。验证见 [主动作与侧栏记录](PRIMARY_ACTIONS_AND_COMPACT_SIDEBAR_2026-09-27.md)。

## 数据编辑与验证

每行包含启用状态、代码、起始面、可选终止面、可选参数序号、最小/最大偏差、分布和注释。公差表本身可直接编辑；右侧属性面板是同步的逐行编辑辅助，不是唯一输入路径。类型列接受当前已实现的 Zemax 风格代码：`TRAD`、`TTHI`、`TCON`、`TSDX`、`TSDY`、`TSTX`、`TSTY`、`TEDX`、`TEDY`、`TETX`、`TETY`、`TPAR`、`TIND`、`TABB` 和 `COMP`。分布列接受“正态/Normal/Gaussian”和“均匀/Uniform”。

元件偏心会对组内所有表面的全局原点施加同一平移。元件倾斜以起始面顶点为枢轴旋转组内表面原点，并同步增加所有组内表面的对应姿态角；这与逐面独立倾斜不同。`TPAR` 通过重建同类型几何对象修改指定系数，双端点、反求和 Monte Carlo 后都从名义快照恢复。

验证拒绝：

- 不存在的表面；
- 元件终止面不在起始面之后或超出系统；
- `TPAR` 参数序号不属于目标面的已实现非球面系数；
- 非有限或倒置上下限；
- 活动零宽公差；
- 重复类型/表面对；
- 负物理厚度或像距；
- 非法折射率/Abbe 范围；
- 错误位置的像距补偿；
- 没有活动公差操作数的表格；
- 未知公差类型或概率分布；
- 超过 `1000` 行的操作数表。

补偿行是控制行，不参与随机采样。

## 统计分布

- 修正正态：区间中点为均值，最小到最大覆盖 `4σ`，即中心到任一公差极限为 `±2σ`；超界样本拒绝后重采样；
- 均匀：覆盖完整最小到最大区间。

固定随机种子使相同系统、表格和设置的 Monte Carlo 可复现。

## 评价准则

可选择视场/波长加权的 RMS 点列半径（mm）、RMS 波前误差（waves）或指定频率 MTF（无量纲）；MTF 显式选择 FFT/几何方法、方向、采样、波长和逐视场下限。内部优化仍使用加权残差平方和，但报告和良率始终使用物理准则。

公差评价按有效追迹光线统计。高 NA、遮拦或边缘采样导致个别光线未到达评价面时，只排除失败样本，并按原总权重对剩余有效样本重新归一化；只有所有加权样本均无效时才判定名义系统不可评价。串行灵敏度与并行 Monte Carlo 使用同一规则。

## 灵敏度

每个活动操作数分别施加负端点和正端点；启用补偿时，名义系统和每个端点都使用相同补偿设置。结果报告名义评价值、两端评价值、最坏评价值和相对名义变化，并按最坏绝对变化排序。每次端点计算后恢复系统。

RSS 预计变化按每个公差两端变化平方的平均值累加后开方：

`RSS = sqrt(sum((Δ最小² + Δ最大²) / 2))`

报告同时给出“名义值”“RSS 预计变化”和“预计评价值（RMS 名义值 + RSS，MTF 名义值 − RSS 并截断到 0）”。这属于灵敏度估计，不等同于 Monte Carlo 分布统计。

## 反向灵敏度

反向极限和反向增量都对每个活动公差操作数的最小、最大端点分别求解。算法只在比例区间 `[0, 1]` 内搜索，因此不会生成比输入更宽的公差；每次试算均从名义快照开始，应用同一补偿设置，完成后恢复系统。端点评价失效视为超过目标并继续收紧。每侧最多执行 `48` 次二分迭代，并按公差量级设置有限终止阈值。

调整后的端点会再次通过普通双端点灵敏度精确追迹，而不是把二分中间值直接冒充最终验证。RMS 点列和 RMS 波前按“数值越小越好”处理，MTF 按“数值越大越好”处理；逐视场 MTF 反求会核对每个视场而非只检查平均值。

## Monte Carlo

服务入口和公开 Core API 都将试验数限制在 `0` 到 `10000`。补偿迭代、并行度、有限数值、评价准则、运行模式和目标表面在创建工作快照与结果数组前验证；界面、导入文件和程序调用共享同一边界。

每个试验：

1. 从不可变名义快照构建独立 `Optic`；
2. 在同一次试验中同时采样并施加全部活动操作数；
3. 计算未补偿准则；
4. 可选优化补偿器；
5. 按原试验索引写回结果。

试验种子由全局种子和索引派生，因此串行与不同并行度产生相同有序序列。外层试验调度负责并行，内层追迹抑制嵌套并行。无有效评价光线的试验记为失败并计入良率。

统计包括名义值、均值、标准差、最小/最大、P05/P50/P90/P95，以及提供非零限值时的估算良率。设置中的“使用公差表分布”保留每个操作数自己的统计模型；也可以在本次运行中统一覆盖为修正正态或均匀分布。随机种子和并行度不改变有序试验结果。

## 公差报告

“1: 公差报告”是独立文档页签，不嵌在公差数据编辑器内部。报告采用 Zemax 风格等宽文本布局，包含文件名/路径、日期、单位说明、表面中心公差、表面偏心/倾斜公差、折射率/Abbe 公差和全部公差操作数。未运行分析时，报告仍可用于检查当前公差数据；运行后会按实际模式追加灵敏度 RSS 预计性能、逐项端点表、Monte Carlo 统计、试验表和良率。设置为零次 Monte Carlo 或关闭试验明细时，不显示相应伪结果。

报告页提供刷新、复制文本和导出文本。Ribbon 的“公差报告”会打开/聚焦该独立页签；编辑器里的“导出报告”直接写出当前报告文本。

## 公差数据可视化

“公差数据查看器”打开/聚焦公差数据编辑器文档页；“直方图”和“良率”分别打开独立图表页签，均使用分析模块的真实坐标绘图控件，支持滚轮缩放、拖动平移和双击复位，不再用字符条或统计文本冒充图形。

直方图读取最近一次 Monte Carlo 每个试验的补偿后评价值（缺失时回退到未补偿评价值），按样本量自动确定分箱数量并绘制柱状分布，同时显示样本数、均值、标准差和极值。良率图按原始值绘制经验通过率；RMS 上限取 ≤，MTF 下限取 ≥，逐视场 MTF 用最差视场验收余量和零边界。图中通过率分母包括失效试验。所有限值均为 `0` 时不做合格判定。未运行 Monte Carlo 或结果没有有效数值时，这两个页面只显示明确的空状态，不伪造分布或良率。

## 保存与报告导出

“保存公差”写入 `*.startol.json`。版本 3 保存操作数、评价准则、Monte Carlo 次数与种子、补偿迭代、RMS 良率上限或 MTF 下限、完整 MTF/逐视场设置、补偿算法与附加可调量、四种分析模式、反求值、分布覆盖、并行度和报告显示选项；版本 1/2 文件仍可读取并使用明确默认值补齐新增设置。加载时按当前光学系统重新验证。表格、右侧尚未应用的编辑草稿、评价准则和运行参数都会触发独立的未保存状态。新建、打开、从镜头库载入或退出时，统一确认窗口会分别保存 `.staropt` 和公差文件；重置系统布局、加载布局槽位或恢复已保存默认布局时，只检查可能被销毁的公差编辑器，并允许保存、放弃或取消。选择不保存后切换系统会重建当前系统的默认公差表。即使关闭公差页，未保存表仍保留在工作区缓存中，直到保存、明确放弃或退出。公差文件采用同目录临时写入和原子替换。

公差数据编辑器在宽窗口中并排显示操作数表和属性编辑器，低于响应式断点后改为上下排列并分别滚动。向导最小宽度为 640，窄窗口时导航移到参数区上方；这是已实现的布局行为，不代表移动端触控界面。

公差定义和结果与 `.staropt` 分开，保存工程不会静默嵌入研究。

报告导出为 `.txt` 等宽文本，内容与报告页一致。

## 当前限制

- 不支持 Zemax 专有 `.TOL`；
- 向导尚不生成面形、条纹、Zernike 不规则度、多配置和脚本操作数；
- 附加补偿页支持多个有界空气间隔及单表面 X/Y 偏心、倾斜；镜片组刚体补偿和近轴对焦尚未实现；
- `TPAR` 当前覆盖偶次/奇次/Forbes Q 的线性系数表，不覆盖任意几何的额外数据字典；
- 尚未实现 3 项/5 项多项式灵敏度拟合、缓存复用或跨配置联合反求；MTF 已支持逐视场反求；
- 材料公差在参考折射率/Abbe 对附近使用 Abbe 近似；
- 计算只在快照上运行，不修改活动处方。

## 镀膜实验室公差（独立流程）

上述镜头公差工作区与 `.startol.json` 不用于镀膜实验室。实验室“高级 → 公差复验”支持均匀 ±半范围与正态 1σ 的膜厚扰动，并可加入角度误差；厚度可逐层独立、同材料同步或全部同步。复用 Core `UniformSampler`/`NormalSampler`，记录种子、实际膜厚/角度、逐样本指标/错误、通过数和最差 merit。固定/变量标记控制优化自由度，不表示该层制造厚度没有公差。

所有扰动样本与名义复验使用相同的材料快照和共享薄膜求解器；公差结果保存进独立 `.coating.json` 并绑定输入哈希，参数变化后失效。未支持膜材料 n/k 误差、补偿或沉积控制，不宣称覆盖正式镜头公差的完整选项。详见[镀膜使用说明](../labs/CoatingDesign/README.md)。
