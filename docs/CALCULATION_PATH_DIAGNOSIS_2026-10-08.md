# 其他计算路径问题定位 2026年10月8日

后续修复已进行，当前行为和修复后数值见[计算路径修复与结果对比](CALCULATION_PATH_REPAIR_2026-10-08.md)。本文保留修复前诊断及原始证据；其中未修复描述不是当前实现状态。Huygens 最终只完成局部坐标一致性修复，传播模型升级候选未通过原生回归并撤回。

其他路径已经复现出独立问题，不能再把差异统一解释成采样数量不足。主要位置是分析入口的参数传递、FFT 的显示与计算网格耦合，以及 Huygens 传播中的坐标原点依赖。正式追迹引擎能够按指定设置返回一致结果，但部分分析入口没有使用同一套设置。

本轮只诊断，新增独立诊断工具和文档，没有修改产品计算、正式测试、冻结参考或容差。新增的明确证据是：有焦参考球也忽略系统瞄准；FFT 显示尺寸改变了计算间距；Huygens 离轴 PSF 不满足整体轴向平移不变性。上一轮已修复的 Wavefront Map 物理瞄准问题与这些旁路分开处理。

## Zernike 与参考球的瞄准遗漏

三份冻结镜头为 Cooke、Double Gauss、Relay，各使用轴上主波长和边缘短波长两组设置。每组分别开启、关闭系统瞄准；通用 Zernike 使用 8 个六角环、37 项拟合。控制结果调用同一个正式波前与拟合引擎，保持节点、拟合基函数、项数和环形遮拦不变，仅明确传入瞄准设置。

关闭系统瞄准时，三类通用 Zernike 共 18 个结果都与未瞄准控制完全一致；开启时仍与未瞄准控制一致，却与遵循系统设置的同节点拟合不同。以下是 Standard 系数的最大差，不是系数 RMS，也不是新原生 Zernike 误差：

| 设置 | 开启瞄准后的同节点系数最大差 waves |
| --- | ---: |
| Cooke 轴上 550 nm | 0.00268264448 |
| Cooke 20° 480 nm | 164.034436 |
| Double Gauss 轴上 587.6 nm | 0.00560465258 |
| Double Gauss 14° 486.1 nm | 105.104896 |
| Relay 轴上 587.5618 nm | 0.0000372808890 |
| Relay 2° 486.1327 nm | 0.0000903328622 |

Cooke 和 Double Gauss 的冻结原生设置本来关闭瞄准，主动开启是参数传递实验；大数值只能证明两条当前 Core 路径不同，不能当作开启瞄准后的 Zemax 标准答案。Relay 原始设置开启瞄准，但现有原生参考是 OPD 光扇，不是完整 Zernike 系数表。

Zernike 扫场的六组边缘控制在系统关闭时误差全部为零，开启时全部非零。与此同时，均匀网格 Fringe 图表与同节点拟合、均匀网格 Standard 操作数与同节点拟合，在两种瞄准状态下均完全一致。这说明遗漏在通用图表和扫场入口，不应把已经正确的 ZERN 操作数一并改回默认不瞄准。

还有独立的采样规则差异：桌面 Standard Zernike 通过六角环生成数据，ZERN 操作数通过均匀网格生成数据。Zemax Standard 文档要求归一化瞳面上的均匀网格，并明确瞄准关闭与开启分别在入瞳和 STOP 定义瞳坐标。因此，仅补传瞄准仍不能完成桌面 Standard 的原生对齐；应增加明确的 Zemax 采样入口，保留 Core 通用默认的边界。[Zemax Standard 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26101/zh-Hans/OpticStudio_User_Guide/OpticStudio_Help/topics/Zernike_Standard_Coefficients.html)

六组设置中的两个有焦参考球，切换系统瞄准后 RMS、参考光程和有效数量均保持完全相同；源码的发射和相位修正都固定使用默认 false。无焦分支则在合成模式控制中明确匹配未瞄准波前，而不匹配开启瞄准的波前。合成无焦控制只改变分析模式，不是六份原生无焦镜头捕获。球面、平面和不同参考球的 RMS 本来就可能不同，不能直接互比后据此判错；本轮比较的是每种参考定义内部的设置传递。

## FFT 光线与尺度使用不同约定

FFT 选择单元中心形式时，`pupilAimAtStop = cellCenteredPupil || aimAtStop` 会强制瞄准。工作 F 数却先按另一变量 `aimAtStop` 计算。Jones 光瞳还有相同合并。诊断使用偶数 Zemax 网格，使两次光瞳坐标逐点完全相同，排除了节点位置变化。

12 个控制中的自动 FFT 都与预先生成的瞄准波前结果完全一致。系统关闭时，相同节点的未瞄准波前仍被接口接受，却产生不同的 PSF；系统开启时也能通过单元中心分支传入不匹配的未瞄准波前，说明预计算输入检查不完整。正式应用目前没有在该入口传入预计算波前，这一项属于共享接口缺陷，不能据此说桌面已经使用了不匹配缓存。

Cooke 轴上关闭系统瞄准时，FFT 光线使用瞄准路径，而工作 F 数为未瞄准的 4.978219667；瞄准路径的 F 数是 5.050413644。两者使采样间距分别为 1.283447258 µm 与 1.302059768 µm。Double Gauss 边缘情况下，仅更换为同节点未瞄准波前，最大相对强度差为 0.1247770385。Jones 控制也显示：只切换单元中心标志便与瞄准控制一致，而 Cooke 边缘与未瞄准 Jones 分量最大差为 0.0151423912。

快速 FFT MTF 和零离焦辅助波前都固定瞄准。快速扫描在两种系统状态下输出相同，不能与已经遵循系统设置的波前图视为同一光瞳。冻结 OPD 光扇提供了更直接的外部控制：Cooke 边缘的零离焦辅助结果最大原生误差为 364.929953861 waves，而遵循捕获设置的普通波前为 2.624171760e-5 waves；Double Gauss 对应为 384.154817243 与 4.031837608e-5 waves。Relay 捕获设置本来开启瞄准，两条路径一致。这里沿用原 492 条光扇记录，逐点比较且保留缺失数量，没有插值或拟合。

这些结果足以要求统一各入口的物理瞄准与 F 数约定，但不能据此替代 FFT PSF、MTF 和高 NA 自动回退的原生验证。高 NA 回退当前还会自动更换瞄准方式，应显式记录实际使用的约定，不能静默当作输入设置没有变化。

## FFT 显示与计算网格混用

正式 Application 入口固定 Cooke、Sampling=64、轴上 550 nm，仅改变 Display：

| 请求 Display | 实际结果网格 | 实际像面间距 µm | 图中点数 |
| ---: | ---: | ---: | ---: |
| 32 | 64×64 | 1.875570803 | 4096 |
| 64 | 64×64 | 1.875570803 | 4096 |
| 128 | 128×128 | 0.937785401 | 16384 |

这是正式应用分派结果，不是替代构造器。Display=32 也没有得到 32×32 显示数据。Zemax 将 Display 用于选择已计算数据的显示范围，瞳采样后另行采用双尺寸零填充；显示选择不应改变像面计算间距。因此，该入口应先固定计算阵列，再裁切所需显示数据。[Zemax FFT PSF 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26101/zh-Hans/OpticStudio_User_Guide/OpticStudio_Help/topics/FFT_PSF.html)

Core 的另一个构造入口也需整理：未指定 `gridSize` 时，Sampling=64 会先降为 45，随后引擎再次按传入密度拉伸光瞳；指定 128 的计算阵列则保留 64。两种调用都返回 128×128 网格，但间距分别为 0.7756467264 与 0.9377854014 µm。这里是不同调用规则的复现，不是正式桌面默认路径的重新分类。应让名义采样、有效瞳节点、FFT 阵列和显示尺寸分别具有唯一含义。

负 Image Delta 也是兼容缺口：Zemax 将其定义为不拉伸、使用完整瞳网格的模式；当前构造器把负值压到零，本轮 -1 与 0 返回逐点相同结果。补齐该模式之前，不应把它呈现为已支持的设置。[同一 FFT PSF 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v26101/zh-Hans/OpticStudio_User_Guide/OpticStudio_Help/topics/FFT_PSF.html)

## Huygens 依赖坐标原点

最有力的新证据不依赖 Zemax API：把镜头所有表面坐标同时沿 Z 移动 1、10、100 mm，曲率、间隔、材料、孔径、视场、波长和瞄准均不改变。正常情况下只是换了坐标原点，相对于主光线的 PSF 应保持不变。

Cooke 离轴 20°、480 nm、32×32 瞳采样、32×32 像面、0.25 µm 像面间距的结果为：

| 整体 Z 平移 mm | Huygens 峰值相对强度 | 与原结果最大强度差 |
| ---: | ---: | ---: |
| 0 | 0.03784596230 | 0 |
| 1 | 0.03772862044 | 0.000117341858 |
| 10 | 0.03682916061 | 0.001016801690 |
| 100 | 0.03349369791 | 0.004352264387 |

100 mm 原点变化使峰值降低约 11.50%。相同实验中，有效掩膜完全一致，样本光强最大差为 1.11e-16、方向 Z 分量最大差为 3.34e-16，均为舍入量级；波前 OPD 最大差不超过 2.37e-10 waves，出瞳位置刚性平移残差不超过 5.43e-14 mm，像面中心残差不超过 3.56e-15 mm，FFT 强度最大差约 3.03e-12。它不是光线、参考球或采样发生了实质变化，也不能归结为舍入误差。

源码使用全局出瞳位置除以球半径计算倾斜因子，却没有扣除参考球中心。`image - pupil` 的传播向量平移后保持不变，但 `pupil / radius` 会随原点变化，正是引入原点依赖的位置。应传递正确参考球中心或几何法向，并新增整体平移控制；不能通过归一化、调比例或增加采样掩盖它。

Cooke 轴上和 MS-L7 轴上是负控制，Huygens 只出现约 1e-10 量级数值扰动。轴上归一化可能抵消这一错误，因此已有轴上测试通过不能覆盖离轴问题。Zemax 的 Huygens 说明以光线位置、方向、振幅和相位在像面上叠加为基础，并强调局部坐标变化下的适用性；本轮原点不变性是独立物理检查，不是声称复刻了其内部实现。[Zemax Huygens 与 FFT 说明](https://optics.ansys.com/hc/en-us/articles/42661795535251-What-is-the-difference-between-the-FFT-and-Huygens-PSF)

## 既有原生残差和兼容设置

重新运行现有冻结比较测试共 45 项，43 通过、2 失败、零跳过。通过的测试中含误差非回退检查，43 项通过不能等同于 43 项原生精度 Pass。失败身份、分类和数值与上一轮完整验收一致：

- MS-L7 Huygens PSF Cross Section：Close，NRMSE 0.0037256670590166724，最大强度差 0.005391581588203756。
- MS-L7 Diffraction Encircled Energy：Difference；衍射极限曲线 NRMSE 0.013875784968407625、最大差 0.0505309569642369；镜头曲线 NRMSE 0.011467280942848471、最大差 0.04068881984537476。后者超过既有非回退上界，因此测试失败。

两项捕获都是开启瞄准的 MS-L7 轴上设置，不能用本轮关闭瞄准时的 FFT 混用或 Cooke 离轴平移错误直接解释。它们的完整根因仍未关闭。Huygens 还需核对精确原生节点、传播方式和归一化；包围能量还需分别核对 PSF、中心窗口、像素面积积分和有限窗口总能量，不能只调整积分容差。

另外，Foucault 的 UsePolarization 开关只改变元数据。本轮开关两种状态返回完全相同的图中点，源码也没有将该参数接入追迹或强度计算。这应按未实现设置处理，不能表示偏振计算已经生效。

## 修复顺序与验证边界

1. 统一显式瞄准参数，覆盖通用 Zernike、扫场、两种有焦参考球及无焦回退；保留均匀 Fringe、ZERN、OPD 和已修复波前图的正确路径。桌面 Standard 的均匀采样另设明确入口，不全局改 Core 默认。
2. 将 FFT 名义采样、瞳节点、瞄准、工作 F 数、计算阵列、显示裁切分开。拒绝约定不匹配的预计算波前和偏振，记录自动回退；落实 Display 只裁切以及负 Image Delta 的明确支持或明确拒绝。
3. 修复 Huygens 倾斜因子的坐标参考，用轴上、离轴、整体平移和已有原生捕获共同验证，随后继续定位 MS-L7 截面与包围能量残差。
4. 未实现的 Foucault 偏振等设置应禁用并说明，或补齐正式计算及验证，不能仅回显输入参数。

最终 Debug 与 Release 的 12 组矩阵数值、FFT 网格、Application 显示结果和兼容参数结果完全一致；Huygens 平移问题也在两配置复现。固定检查的 10 个产品源文件及 10 个输入文件前后哈希不变。没有新原生捕获，没有重跑完整发布验收，现有完整测试结论仍以[波前图验收报告](WAVEFRONT_ACCEPTANCE_2026-10-08.md)为准；原六文件 132 项分类不变。
