# 高影响可靠性问题修复（2026-10-26）

按用户提供的实际影响顺序处理 10 组问题。工作基于当前共享工作区，保留已有 UI、CI、品牌资源和其他任务改动；本报告仅覆盖以下缺陷。没有修改冻结参考、放宽数值精度门槛或用替代算法掩盖失败。

完整编号清单到达后的复核更正：本阶段对 NEW-05、NEW-25 的根因覆盖不完整。v2 仅补了场景分帧、可见性和网格元数据，没有加入真实材料模型；处方替换失效也不能代替材料注册表变化失效。这两项已在[43 项清单续修](FULL_RELIABILITY_REPAIR_2026-10-26.md)中补齐，当前场景哈希为 v3。本页的 181 项结果仍保留为当时的阶段证据。

## 兼容性与范围

- 保存光线数据库需要选择新文件名；既有目标不会被覆盖。旧数据库仍可读取，但旧场景哈希与 v2 不同，会显示过期，需要重新追迹。
- 商业目录保留旧的无索引读取方式；有索引时仅加载有效文件。文件分别原子写入，整个目录不是事务，不能据此宣称任意中断下所有厂家同时提交。
- 负厚度修复无法恢复此前已保存成零的处方，需从原始 CODE V / OSLO 文件重新导入。
- 缓存身份排除工程名、视场/波长/表面显示标签及评价函数。插件组件无法形成序列化身份时关闭该处方的缓存，保留追迹功能。
- 内部介质验证覆盖已支持的封闭折射实体中的初始传播、全反射和嵌套退出；不据此宣称所有互相穿插的实体组合都已认证。
- 历史优化结果继续保留 `/1`，不会重写成新算法版本。

## 本地验证

默认输出目录、Release 配置的最终定向运行 **181/181 通过，0 失败，0 跳过**，其中本轮新增回归 26 项。选择范围包含两个新增测试类，以及非序列文档/杂散光、缓存、高性能追迹、既有审计修复、商业镜头库、导入边界、优化路线、相机服务和等价 GRIN 快照缓存测试。测试执行期间没有运行全套回归，也没有改动此前严格能量回归的门槛。
