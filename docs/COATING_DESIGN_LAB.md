当前 `target-violation-envelope/3`：优化以及有现有膜系的生成/搜索，均按原输入逐项目标超限保护候选。DLS 的峰值/截止未完成路径比较原尺度及相对超限两种通用方向；有密集起点时，以原验收选出的较好结果为基线，再执行 `pareto-target-correction/3`。每个sqrt(N)窗口结束时，若有新的正式保留收益，或同一目标的最近正式恢复误差仍至少减半，继续恢复方向并冻结最好正式结果的逐项超限。完成一项目标并交接下一项仍可按真实保留收益续算，不要求新目标先积累两次记录。随后从正式最好点做硬约束LS校正，每个保留点均成为下一点的逐项上界，正式拒绝的试探不推进该校正迭代。通带及每个截止带仍用Core实际透射峰细化补充极值点；峰值/截止已完成的带形恢复方向、其他优化器路径及默认协议保持。

设N=`MaximumIterations`。方向比较另≤N，分别以 `TargetComparisonRuns` / `TargetComparisonIterations` 记录。恢复含续算、硬约束LS和通带余量质量阶段共享额外N次；LS≤ceil(sqrt(N))；余量流程最多四个窗口（原质量、旧方向、修正方向、联合抛光），各≤ceil(sqrt(N))，合计≤4ceil(sqrt(N))且使用前面阶段剩余额度。`TargetRepairContinuationIterations`是`TargetRepairIterations`的子集，不能重复相加。这些工作**均在主调用≤N之外**，不称相同总计算量。共享不等式子问题、活动集限次、指导查询及密集调用分别计数。实际候选、各步上界、窗口授予原因、恢复误差和停止原因随实验保存并可复算；旧记录不补造字段。当前对照见[非线性约束修正](COATING_NONLINEAR_CORRECTION_2026-10-31.md)；上阶段见[余量优化报告](COATING_MARGIN_REFINEMENT_2026-10-31.md)，前阶段保留[进展续算](COATING_PROGRESS_ALLOCATION_2026-10-31.md)、[限次续算](COATING_CONSTRAINED_CONTINUATION_2026-10-31.md)与[权衡修复](COATING_TRADEOFF_REPAIR_2026-10-31.md)。

正式采样的提前收敛不能改变搜索的峰值括区。`search-peak-reference/2`独立重算既有搜索峰值采样，覆盖两条方向、恢复起点、目标交接及硬约束LS；实际查询计入指导工作量，不生成达标结论。正式候选始终使用当前`Evaluate`的指标、收敛和原Checks。`SearchPeakReferenceBatches`记录实际批次。不同用途的采样身份明确保存，禁止用指导采样的判定替代正式验收。

完整协议4的DLS窄带优化使用`passband-margin-quality/2`。正式主结果与输入保护完成后先保持原质量窗口，再从同一正式点比较旧余量方向和修正方向。只有修正方向在实际峰值、各截止OD、带宽误差、原逐项超限和已有采样/通过状态上支配旧方向才选用，否则保留旧方向；随后按剩余额度共同抛光。各窗口≤ceil(sqrt(N))、最多四窗口，与恢复及LS共享额外N，未扩大该共享上限。两个比较方向都计费，总成本增加，不称等成本胜出。峰值损失1−T、实际宽度偏差和每个截止带透过泄漏按阶段起点归一化，达标后仍有改善方向。共享Core提供所有光学值、带指标导数与数值步；每个保留点必须在正式复验中同时满足峰值T不降、距目标宽度的绝对误差不增、各截止OD不降、原逐项超限不增且不丢失已有采样收敛/通过状态。变量标记与厚度界保持。通过状态仍只来自原门槛，余量目标不替代验收，也不保证任意膜系存在共同改善方向。完整搜索候选调用相同Optimize流程；新增生成阶段精化按上文认证协议单列记录，不调用完整Optimize。

共享Core的`trial-constraint-correction/1`只生成试探点：在目标已有下降但非线性约束仍超界时，最多做两次带辅助上界的约束修正，以第一次修正的实测余项给第二次提供向内缓冲。高反额外度量阶段在首次可接受回溯步及前一拒绝步附近比较原试探与修正试探，始终保留更小的实际最差损失；窄带修正窗口每个阻尼尝试最多修正一次已有目标下降的试探。指导比较只容纳sqrt(machine epsilon)量级的归一化舍入误差，正式峰值、OD、带宽、超限和通过保护仍逐值严格执行。这不是完整光学Hessian或全局最优证明。

共享薄膜求解器的`WithThicknesses`可在同一私有材料快照内复用n/q准备工作，缓存键为精确波长与入射角；厚度、反射透射计算和导数仍重新计算。缓存按复数元素总数有界，并保留材料/界面/调整参数；不能跨材料快照复用。相关API逐值一致性及R/T/A独立复验见本阶段报告。

共享 Core 的 `coherent-scattering/2` 已提供 S/P 复振幅，并通过物理膜层模型接入正式顺序追迹及原生保存。镀膜设计是主程序必装内置模块，但“把实验结果显式应用到当前镜头”的 UI 流程仍未实现；这与物理模型是否接通是两个问题。物理契约见[膜层追迹与保存](COHERENT_COATING_TRANSPORT_2026-10-02.md)，历史定向计数留在该阶段报告，当前工程验证见[统一交付](BUILT_IN_MODULES_2026-10-13.md)。

当前具备材料表管理、有限结构搜索、1–5 腔设计、可复现公差、中文界面、保存重开与导出；原实测材料高反和窄带目标模板仍有未达标项；五套新参考处方不替代这些验收。每个实验有单独编辑状态，但属于同一个必装产品。原数值与失败记录见 [历史验收](../validation/coating/README.md)。

实验 JSON 的材料、膜层与截止波段数组不能含空元素，输入校验会明确拒绝。共享薄膜求解器最多读取 4097 个输入层来判定是否超过 4096 层上限，避免先完整枚举任意长度的输入；这不扩大实验编辑器原有的 200 层限制。CSV 文本使用共享公式保护规则，有限光谱数值保持原精度。

## 本地审计与复用

本地为 .NET 10 / C#、Avalonia 12.1.0、Dock.Avalonia 12.0.0.2。2026-10-13 起，镀膜 UI 位于主程序程序集，由 `IntegratedLaboratories` 创建同进程的受主窗口管理的工作区；没有独立进程或外部启动器。编辑状态不隐式访问当前镜头优化事务。Core 继续共享材料、复数计算、优化器、ComputationCancellation、AnalysisSeries 类型化轴、ComponentSnapshotFactory 与 BoundedFile 原子文件接口。Engine 定义目标/候选/流程，Modules 映射显示 DTO，App 负责交互。

原 `Coatings/CoatingModels.cs` 是明示实验性的经验起伏模型和兼容别名，不用于本实验室；新 `CoherentThinFilmSolver` 是共享 Core 中唯一的真实膜系计算实现。`IMaterial` 已提供 n/k；`CatalogGlassMaterial` 已支持 tabulated nk 和色散，无须复制材料公式。正式优化器已有独立变量与残差接口，首版使用真实 Damped Least Squares、Nelder-Mead、Coordinate Pattern Search，不迁入 TFStudio 的优化器实现。

## 计算契约

下面半无限基板和进入基板功率的定义适用于单面评价。整片评价扩展为正面相干膜层、非相干有限基板与背面相干膜层，T进入出射介质，A包含两面和基板；共享Core通过守恒横向波矢组合正反向功率，详细模式、原验收保持与版本身份见[双面计算契约](COATING_EDITOR_DUPLEX_2026-11-02.md#两面与评价对象)。

nm 为波长/物理厚度单位；角度为入射介质内相对法线的度数；层序为入射介质→膜层→半无限基板。复折射率 n+ik、时间因子 exp(-iωt)，k≥0。首版要求入射介质透明，材料各向同性、均匀、非磁性，全部有限膜层相干。T 为进入基板的功率，A 为有限膜层吸收，不包含半无限基板之后的传播吸收。

Core 使用只含衰减传播因子的向后散射递推；传输振幅在对数域累计。真实 T 与 log(T) 不按显示下限截断。OD=-log(T)/ln(10)，首版验收支持 OD≤12；超过显示范围必须标注饱和，不能把显示值作为计算值。完全全反射的 T=0 与数值下溢分别通过 log(T) 区分。精确临界角奇点当前明确拒绝，不用微扰伪装计算成功。一般接近临界角的有效点仍可计算。

峰位和 FWHM 采用共享 Core 的 `log-scaled-half-maximum/2`：从原始 log(T) 找峰，并在相对透射 `exp(log(T)−log(Tpeak))` 上线性定位半高交点，避免极小 T 的半值下溢。全反射出射端若全谱 log(T)=−∞，不生成 NaN 或虚构半高边缘；边缘缺失时 FWHM 为 null。绝对峰值 T、R/T/A、OD 和验收门槛保持，新计算的 `Result.SpectrumMetricsVersion` 记录测量身份。详见[边界修复和质量对照](COATING_SPECTRUM_EDGE_REVIEW_2026-10-30.md)。

材料快照保存真实公式或表格、有效波段与来源；没有 k 的目录模型明确按 k=0。原三项目标模板的薄膜材料数据来自 Rodríguez-de Marcos et al. (2016), DOI 10.1364/OME.6.003622，反应电子束蒸镀、300°C；不能视为所有工艺的通用膜材料常数。

## 必要接口与数据隔离

共享接口为 `CoherentThinFilmSolver`（含相位厚度生成）和 `ThinFilmSpectrum`（采样/指标/类型化曲线）；没有复制材料色散、薄膜公式、数值优化或原子文件实现。Engine 负责模板、目标残差、候选、验收与会话；主程序 App 内置交互和调度，并通过 Modules 接收共用映射器的类型化显示数据。根解决方案、主程序依赖图和标准安装包均强制包含该模块。

实验格式与 STAROPT 分开；后台深拷贝输入并冻结材料快照，用实验 ID、代次和取消令牌防旧结果写回。参数文字变化同步使结果失效，不依赖延迟的 UI 文本事件。预览、优化、公差和最终复验均走同一 Core 薄膜求解器；采样策略不同但材料和物理设置一致。材料快照重建后核对规范字段与系数，缺失数据拒绝默认补齐。保存结果须匹配输入 SHA-256；重开使用快照复算，缓存结果不能替代物理计算。

验证必须区分上游移植一致性、解析物理正确性、Workbench 回归与 GUI 截图检查。既有 Zemax 捕获只覆盖原文件/原设置，不能充当新增镀膜验证。Optiland 历史比较不新增、不再生成。

## 资源和材料限制

实验目标层数为 1–200；窄带截止区 1–8 个，不能与目标半高通带重叠。预览基础间隔 40–10000，优化基础间隔 20–2000；迭代次数 1–1000，公差样本 1–200，厚度均匀半范围或正态标准差 0–20%，角度误差 0–10°，结构搜索起点 1–32、扰动半范围 0–50%。实际密集复验点数可能高于基础间隔；每次共享光谱采样调用最多 200001 点。Core 单独求解上限 4096 层不能解读为界面允许 4096 层。

支持完整快照的 air、constant、cauchy、sellmeier、catalog_glass 和 polynomial_dispersion 模型；不支持的模型/缺失字段明确拒绝。普通目录材料按自身有效范围计算；五套参考示例显式声明的PCHIP端点规则按源模型执行并提示域外非实测，解析n模型仍在其自身有效域内；非目录材料在实验室捕获时保守限定为 300–2500 nm，实际可用波段为参与材料范围的交集。这是当前实验室的输入策略，不是所有材料或 Core 的通用物理范围。`MaterialTable` 支持有显式 nm/μm 单位的 CSV/TSV n/k 表导入、编辑和导出，复用 Application 单位换算和 Core 表格材料；2–10000 点、4 MiB 上限。材料更改只进入实验快照并清除旧结果。普通材料有效波段检查仅容许单位换算造成的相对 8×10⁻¹⁵ 浮点端点误差，不扩大材料物理适用范围。解析模型不会被隐式离散化。

保存使用 64 MiB 的共享光学文档上限，结果和公差必须匹配输入哈希。逐文件原子导出不等于整目录事务。完整文件含义、示例和误差阈值见[使用说明](../labs/CoatingDesign/README.md)及[验收记录](../validation/coating/README.md)。
