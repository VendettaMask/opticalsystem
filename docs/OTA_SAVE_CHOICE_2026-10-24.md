# 更新时独立选择是否保存

日期：2026-10-24。用户在真实更新后指出，未保存当前文件就不能继续更新。此修复只调整退出确认和更新说明，不改变光学计算或安装器安全检查。

## 行为

此前更新入口直接调用保存全部修改，关闭事件又要求保存一次，用户没有“不保存”的路径。现在按钮为“安装更新并重启”：主项目或公差数据有未保存修改时，显示“保存并继续 / 不保存 / 取消”。选择不保存可以继续更新，关闭阶段不会再次保存或询问；原工程文件保持原字节。无修改时直接继续。

选择取消，或选择保存后取消保存对话框/保存失败，不开始安装，保留当前编辑及已验证的下载。确认和保存对话框由“关于”窗口拥有。两个内置模块保留各自的退出保护，仍需正常退出、持久化工作区及恢复状态后，才在真实关闭事件交接到缓存辅助进程。签名、构建比较、文件哈希、占用检查和安装器参数保持原保护。

## 本地验证

默认 Debug 输出定向 22/22，默认 Release 输出定向 85/85，均无失败、无跳过；前者属于后者的交叉验证，不相加。新增 5 个真实 MainWindow/关于/确认窗口测试：中英日“不保存”、保存、取消。以测试独立目录中的实际 `.staropt` 核对不保存/取消不改原文件，保存写入修改；不保存继续到真实关闭准备，取消保留编辑、窗口和下载。测试在最终关闭前拦截原生关闭，不启动用户安装器。

85 项还覆盖既有下载取消、签名/哈希/票据检查、保存修订竞争及失败保护。三语更新说明与确认窗口使用真实 Skia 渲染目检。仅运行相关集合，没有重跑光学全套或扩大数值认证范围。
