# EFNO / RELI 剩余算法残差修复

日期：2026-10-16。**原四文件有限网格、逆映射和参考距离的算法差异已修正，并建立覆盖全部 256 项的严格回归。** EFNO 最大相对差从上一阶段 `2.5130017566e-5` 降至 `1.0912371007e-9`；RELI 最大绝对差从 `3.7464876934e-5` 降至 `3.5289874356e-9`。仍保留实际非零数值，不宣称逐位相同或任意镜头完全等价。

## 三处剩余约定

1. 原生有限网格使用**六阶完整二元多项式**将像方方向余弦映射到归一瞳坐标，而不是对每个节点迭代至真实逆映射。矩阵使用原始 L/M 单项式，SVD 以最大奇异值的 `1e-7` 为截断比例；先居中、缩放或强制满秩会改变该有限数值配置。该比例是算法的秩选择规则，不是比较容差。系数全部由共享 Core 粗网格光线求得，没有读取原生结果或按镜头拟合增益。
2. 像点参考距离沿**当前波长实际主光线**到标量出瞳参考平面测量，即轴向距离除以主光线的 Z 方向余弦。轴向投影和到轴上出瞳点的弦长均不是相同约定。
3. 该参考平面使用**系统主波长的近轴出瞳位置**。选择其他波长仍使用这个系统参考，但实际光线、像点与方向来自所选波长。此前按所选波长重算参考平面导致跨波长残差。

粗瞳范围、1% 扩展、`(2d+1)²` 节点、`d=min(Samp,100)` 和正弦平方边缘权重沿用[上一阶段已确认规则](ILLUMINATION_FINITE_GRID_REPAIR_2026-10-16.md)。原镜头瞄准设置、真实孔径及变迹继续生效；节点实际追迹仍由共享 Core 完成。通用自适应物理积分及 UniformImageCosine 的紧收敛逆解保留，图像模拟的物理功率默认不变。
