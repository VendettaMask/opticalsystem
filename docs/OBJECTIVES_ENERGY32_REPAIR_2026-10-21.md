# 原 32 档衍射包围能量修复

2026-10-21，Apochromat2、Apochromat4、Doublet using MIL number glasses 的原 **32/64** 请求全部从 Difference 修复为 Pass；七个原通过对照全部保持 Pass，包括 Apochromat。正式 Workbench 重算使用原捕获、原设置与原比较策略。原容差 SHA-256 为 `30c27e7976710867d0edc6dd4099edac54ca9e070245dea679b3afdd88fd28f5`，未修改。

## 原因与实现

低采样光瞳边界有四个临界结点，最后一位浮点差异可以使支持集在 97/101 点间跳变。仅移动频域坐标会让原通过 Apochromat 回退，因此早期候选已拒绝。最终修正从共享追迹到图像取样保留同一数值定义：

- 球面先推进至顶点平面，再用稳定的缩放二次式求交，沿用现有显式 sag 残差校验；将解析得到的入射余弦平方传给折射，避免先开方再平方及重复归一化。非单位或横向光线保留一般二次求交路径。
- 标准圆锥面使用解析单位法线，标准面反射直接保留反射方向余弦。独立原生控制的 8 个镜面交点和方向逐位相同。
- Zemax Sellmeier 2 色散先求三个共振项的和，再加 1。136 个独立原生折射率全部逐位一致；旧式加法顺序只有 96 个逐位一致。
- 32 档单波长、圆形工作光锥以微米形成图像间隔 `λ F / sqrt(32)`，再除以默认 FFT 间隔。先在默认基坐标比较半径平方，再缩放坐标。18 个原请求及孔径扰动控制的自动图像间隔全部匹配；162 个相邻双精度间隔控制的支持集全部匹配。
- 有瞄准时，工作光锥定标与实际 FFT 光瞳都使用现有缓存映射。Relay 因此前两者使用不同路径产生的退化已消除。原瞄准收敛容差保持。

实现位于共享 Core，使用纯 C#/.NET。原生调用、位模式审计和临时探针仅用于离线验证；没有产品内参考曲线、逐镜头规则或第二套计算引擎。其他采样数、多波长、非圆形或不完整光锥继续使用原有累计能量路径。准备光瞳的缓存身份同时检查新增的缩放除数与裁剪标志。
