## 行为变化与限制

- v3 哈希使旧数据库需要重追迹；同名材料改变也会使会话过期。没有完整序列化身份的自定义材料不能建立可复用的非序列数据库身份，不能用材料名称冒充模型。
- 工作台输出接口当前只承诺数据库会话；内存、摘要和布局采样应调用 Core。这里采用明确拒绝而非新增另一套未持久化工作台结果体系。
- 串行 Monte Carlo 的旧连续随机流改为每试验派生，升级后旧种子的串行序列会变化；历史结果不改写。
- CSV 文本保护会在有公式意义的文本前加入可见单引号，保证导出内容不会作为公式执行；不是原始逐字节交换格式。
- 配置集合的公开类型改为受限集合，保留索引、枚举和 Add/AddRange，但不再是可无界扩容的 List；本轮源代码调用方一起编译验证。
- 读取器校验单个分支/分段结构，不宣称完成任意跨分块分支图的全局拓扑证明。内部介质不扩展到任意穿插实体的认证。
- 恢复扫描保留固定数量候选，仍需检查全部合法会话以保证选出最新副本；没有新的大目录耗时基准。
- 路径与界面回归在本机 Windows 执行；macOS 查询分支未作本机原生运行验收。没有全套测试、安装包、远端 CI、提交或推送。

新用例集中在 FullReliabilityCoreTests、FullReliabilityServiceTests、FullReliabilityFileBoundaryTests 与 FullReliabilityLayoutTests，并保留上一阶段回归。扩展中间运行 292 项通过；最终运行、规则检查、冻结校验和源文件指纹统一见[本轮证据](../validation/rechecks/2026-10-26/full-reliability/summary.json)，最终计数以该账本为准，不累加重叠运行。

最终默认 Release 定向 **603/603 通过，0 失败，0 跳过**，其中新增 55 项；App、两个内置模块及测试使用默认构建输出。源码范围格式复核通过，发布引用正反向检查通过，冻结资料工作区与 HEAD 均为 2668/2668 一致。完整清单状态与原始 TRX 保存在上述账本。本轮没有执行 GitHub CI 或发布。

初次编译的命名空间/测试 API 拼写错误、共享重构期间的编译记录，以及首次回归中发现的公共导出器提取后仍用十位小数、名称未导出等失败日志均保留。修复生产路径后重跑，未删除失败证据，未放宽数值断言或改动冻结参考。原严格能量差异不在本轮门槛调整范围。

同期重构的文本快照仍断言旧的十位小数格式，与 NEW-13 的精度修复冲突；更新为精确的 G17 文本，并将半径往返比较从九位小数加强为 double 完全相等。该调整反映新的输出契约，不是降低精度门槛。

扩展到工作区 UI 回归时，两项工程图测试直接在没有 Avalonia 渲染服务的环境中构造矢量控件。测试改为与同类 UI 测试一致的独立真实 Skia 会话和 UI 线程派发，保留页面类型、文档标识及国标版本断言，不把品牌资源退回位图。
