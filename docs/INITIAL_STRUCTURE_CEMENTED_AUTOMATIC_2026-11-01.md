# 自主胶合结构调度与断点续跑

2026-11-01。自主搜索新增显式、带版本的胶合结构策略，接入主程序、检查点、三语入口和报告。原口径、像质与制造验收保持，F/4 固定外置光阑与面口径冲突继续拒绝。该项补齐[M3.1 共享界面基础](INITIAL_STRUCTURE_M3_1_2026-10-30.md)之后的自动调度；没有把空气分隔 SPC 当作胶合结构。

## 使用与范围

在 **AI 初始结构 → 自主拓扑设计** 勾选 **实验：自主胶合结构**，保持原任务的结构权限与预算，再开始任务。旧计划默认关闭。新策略优先枚举允许的胶合连接位置、原许可插片材料和正厚度；只有原插片权限、片数上限及空间均允许时才派发。默认最多双片胶合组；显式计划可声明最多三/四片及有界厚度组合，不会改动原总片数上限。

每个新增成员直接引用前一片的真实背面，原面型、净/机械口径及固定参考、光阑、像面保留；编译成一个玻璃—玻璃界面。胶合组可继续进行原许可的目录换料、共享曲率/轴向等连续补偿。共享面只绑定一次，任何所属成员受保护都冻结该面的几何；显式轴向成员选择也须同时允许全部所属成员。新任务复用旧方案时，新镜片 ID 会避开已有成员与表面 ID。

胶合成员不会送入旧的独立单片删除、拆分、合并或面型升级操作。空气分隔父结构的其他原许可分支仍保留。勾选胶合策略不会开启原本关闭的插片权限、修改材料白名单或绕过仅减片/固定拓扑模式；分支守卫只约束胶合增长，其他原许可分支独立执行。

调度沿用“构造 → 一阶恢复 → 实光线补偿 → 原完整独立验收”。胶合分支的一阶恢复使用真实共享变量；未恢复的结果及费用保留，再在剩余额度内尝试原目标物理补偿，不把一阶失败或部分光线计为达标。每片玻璃仍分别检查中心/边缘厚度、坡度、通光和全部像质门槛。

## 保存与恢复

使用原 `.autonomous.json` 主搜索检查点，无需另一套准备文件。点击 **停止并保存**，等待当前完整更新或原子阶段结束；重开记录后点击继续。保存内容包含原计划与限制、随机状态、种子/试验/成员变体游标、候选池和合格归档、待执行阶段、固定模板、变量与轴向窗口、Adam 坐标/矩/步长、已有评价、预约及累计预算。恢复不重新抽取随机数或重新计算已保存的完整更新。

检查点仍采用有界原子写入、写锁、内容校验与修订检查。历史事件、候选、合格归档、已用预算和调度游标不能回滚；数值身份不能重写。胶合续跑绑定 Core/Engine MVID、.NET、系统、架构和 SIMD 能力；环境不同可查看/导出，不能用新版本冒充原数值环境继续。强制结束进程留下的在途预约仍按原保守规则计费并放弃该阶段，不宣称精确崩溃恢复。

处方表、方案详情和报告共用逐物理面展示，玻璃—玻璃共享面只出现一次并显示真实后介质。报告与方案库从已保存结果生成，加载、重开和报告导出不触发追迹。
