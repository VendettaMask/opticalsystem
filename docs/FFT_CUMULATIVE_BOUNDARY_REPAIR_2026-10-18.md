## 原因与实现

本机重新采集的原四组控制与冻结参考逐点一致。原生 FFT 实部、虚部反变换确认 Relay 64 和 Offner 64 的光瞳为 193 个有效节点，Relay 128 为 401 个节点；缺失节点分别是四个轴向或对角边缘点。边缘光线审计没有发现相应位置存在真实通光截断，因此没有通过删孔径、放宽追迹接受条件或修改镜头数据来消除残差。

Offner 的像方光锥不对称。连续改变原生 FFT 的像面间距时，其光瞳节点会先从 193 变为 195，再变为 197，两个阈值分别对应弧矢和子午方向的平均边缘数值孔径。现将横、纵光瞳范围及坐标反向索引分别保存在共享光瞳网格中；波前生成、相位插值、复瞳构造与准备数据校验使用同一组坐标。合成 RMS 光锥仍用于像面间距，不能替代每个方向的光瞳范围。

扩展单波长网格先由截止频率确定像面间距，再将默认 FFT 网格按该间距缩放。保留默认间距、自动扩展和坐标生成的计算顺序，避免代数消约后改变临界节点。[Ansys 的 FFT PSF 说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/FFT_PSF.html)给出了默认网格扩展及显式像面间距改变光瞳采样的关系；本轮兼容路径由本机同设置测量和独立控制验证，不宣称获得了原生程序内部实现。

四条边缘光线的 RMS 数值孔径在半 ULP 附近会影响整组边缘节点。共享 Core 对这四个有限二进制输入保留精确平方和，用相邻浮点数中点的平方作比较，按就近偶数规则舍入 RMS。大整数操作仅用于每个波长的四个标量，不用于光线传播或整幅 FFT。该路径仍为纯 C#/.NET。

32 档、真正复色的共用网格，以及无法建立完整边缘光锥时的既有约定继续保留。把新单波长路径直接用于真正复色曾使 Relay 复色理想曲线达到 0.00327192535，超过原门槛；该候选已撤回，失败 TRX 和前后计算路径保留。没有按文件名、镜头类别、参考曲线或捕获节点数设置运行时分支。

## 独立控制与回归

另有六份有效独立控制全部通过：两份 Offner 坐标断点偏心变体，以及上一轮冻结的 Apochromat、Relay 各两份极小入瞳扰动。尤其保留了 Relay 两份原生节点状态会改变的微扰文件，避免以统一开边界或有限物距条件替代数值修复。

偏心为 -6 mm 的试验在原生程序中没有可追踪主光线，返回零条曲线，Core 同样无法计算；它保留为不可用控制，不计入六份有效对照或回归通过数。其余两份偏心控制完整冻结于[方向性夹具](../tests/OpticalSystemDesign.Tests/Fixtures/fft-cumulative-directional-zemax-2026-r1.zip)，四份微扰原件另存于[边界夹具](../tests/OpticalSystemDesign.Tests/Fixtures/fft-cumulative-boundary-perturb-zemax-2026-r1.zip)。原 48 份夹具和此前冻结档案未被覆盖。

新增 **49 项检查**：补齐原矩阵尚未纳入 Core 回归的 32 条曲线，加入四条偏心变体曲线、八条微扰曲线和五项临界 RMS 舍入检查。冻结任务开始时的 Core 对同样 44 条原生曲线为 **10 失败 / 34 通过**；反例只替换测试输出中的 Core，随后恢复当前构建并校验哈希。旧回归源码保持逐字节不变。

默认 Debug/Release 根解决方案各 19 项目构建均为零警告、零错误。最终 Release 相关集合 **910/910**，聚焦 Debug **197/197**，逐身份保留此前的 861/148 项；比较器相关两配置各 **5/5**，全部零失败、零跳过。逐测试身份、默认 Core 副本和源文件哈希见[机器账本](validation/FFT_CUMULATIVE_BOUNDARY_REPAIR_2026-10-18.json)。这不是完整全仓或完整 Debug 测试结论。

本轮原生诊断共执行 98 次，其中 87 份有可用数据、10 次早期请求类型错误、1 份原生不可用；可用份数包含重复捕获、采样阈值扫描和辅助 Huygens/复 FFT 控制，不代表 87 款独立镜头认证。完整原件、失败记录、前后 Core、源码及最终比较存于[证据档案](../validation/repairs/2026-10-18/fft-cumulative-boundary-evidence.zip)。

验收覆盖上述原 48 组及六份有效独立控制，采样到 128 档。更高档位、任意复杂光瞳和全部 FFT/Huygens 设置没有因此获得通用原生认证。未重打安装包、未提交或推送；独立 Cooke/Tessar 继续排除。
