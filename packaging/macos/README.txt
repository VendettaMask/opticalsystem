Optical System Design — Apple Silicon (M 系列) / arm64

将 Optical System Design.app 拖入 Applications（应用程序），然后从应用程序启动。
程序已包含 .NET、初始结构设计、镀膜设计和字体，不需要另装运行时或模块。
仅支持 Apple Silicon Mac，不提供 Intel 版。

当前包使用 ad-hoc 完整性签名，尚无 Apple Developer ID 签名和公证。
首次打开时 macOS 可能阻止运行；确认下载来源后，可在系统设置的“隐私与安全性”中批准打开。
请不要关闭系统安全保护或对整个下载/应用目录批量移除隔离属性。

更新：退出程序后，用新版 .app 替换旧版。卸载：将 .app 移到废纸篓。
工程与用户设置独立保存；替换或移除 .app 不删除这些数据。
Mac 版目前通过发布页手动下载更新；Windows 安装器 OTA 不适用于此包。
