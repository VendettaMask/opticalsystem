本次更新 Windows x64 的 1.0.4 测试安装包，包含最新分析、成像实验室与 AutoLens 调整。EXE 文件名以 `-Setup-xxxxxxxx.exe` 结尾，八位代码是本次实际构建的源码提交短码，发布标题同步显示；各平台来源以正文“构建来源”的逐项记录为准。Mac 安装包保留此前版本，本次没有重建。

旧客户端尚不识别带短码的安装包名称，请从本页下载 EXE 手动覆盖更新一次，无需卸载；新客户端同时兼容旧名称和带短码名称，继续校验原有签名、完整哈希与构建编号。每个 Windows 架构只保留一个 EXE，发布页地址不变。

- 分析图保持可读字号，窄窗口自动重排视场和完整光扇对；矩阵、离焦图保留行列关系，空间不足时可滚动。修复子图重叠、刻度拥挤和图注裁切，标题贴近对应图框。
- 底部摘要、指标和文件说明按内容增高与换行，最大字号也能完整访问。PNG 导出包含滚动区域外的完整图与图注，保留当前缩放、相机和勾选状态。
- 镜头数据、二维视图等文档页签标题加粗；材料列内容及编辑框右对齐；移除矩阵点列图旁多余的竖排共用尺度数字。
- 增加 Markdown 设计报告及配套分析图片导出；完善分析图例独立勾选、波前二维热图、相对照度坐标与实体模型显示。
- 相机成像实验室支持传感器参数与 QE 曲线导入、连续光谱积分、光源和场景反射率输入，以及分阶段图像和 A/B 对照。当前仍有明确的光谱、采样与物理模型范围，不等于已校准的实测相机。
- AutoLens 更新原版优化规则与阶段交接，保留共享 Core 光学计算和计算设备选择。原版规则对齐不代表完整默认配置的最终像质、成功率或速度已经认证。
- Windows 在线更新可选择保存、不保存并继续，或取消；更新与保存当前工程分开，不保存不会改写原文件。更新辅助进程从已校验的独立缓存运行，等待旧程序正常退出再安装和重启。
- 包含既有光学修复、字体、主题、二维/三维与实体模型功能，以及初始结构和镀膜两个必装内置模块；保留尚未解决的外部数值差异和模型边界。

Windows 用户可在“帮助 → 关于”检查更新，下载并校验后点击“安装更新并重启”；有未保存编辑时可自行选择处理方式。已知旧辅助进程存在占用故障的早期客户端，需先正常退出软件及失败更新提示，再从本页下载 EXE 手动覆盖安装一次，无需卸载。不会在后台强制安装或关闭程序，工程和设置保留。

Mac 用户下载 osx-arm64 的 DMG，将 Optical System Design.app 拖入“应用程序”。仅支持 Apple Silicon M 系列芯片，最低系统声明为 macOS 14；完整 .NET 运行时、两个内置模块、字体和许可随包交付。Mac 从发布页手动更新。

版本仍为 1.0.4 测试预发布，不标为正式 Latest。新 Windows 客户端通过已签名的云端构建编号识别同版本新包，拒绝旧构建；相同载荷可修复安装。包内源码提交与本页“构建来源”为实际代码来源，原测试标签保持不动，自动 Source code 压缩包不等于新安装包源码。
