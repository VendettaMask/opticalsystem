# 1.0.4 测试版更新记录

## 2026-10-27：三平台统一更新

Windows x64、Windows ARM64 和 Apple Silicon Mac 均从源码 `a31fb444` 重新构建，云端构建编号为 `40439094476`。原测试标签保持不动，具体完整源码、文件哈希和更新签名见下方构建来源。

- **真实干涉条纹**：干涉图改为共享 Core 根据两光束波前差计算的强度，提供灰度、伪彩色、等高线，以及光束/配置、采样、倍率、X/Y 倾斜、波长/视场、分析面、出瞳和子孔径设置。OPD 与相位数据分别保留；等强重合瞳等模型边界明确显示。
- **Zernike 分析入口整理**：保留 Fringe、Standard、Annular 三种具名系数表、拟合统计及系数随视场分析，移除通用重复入口和遗留报告项；波前分布仍通过“波前图”查看。
- **赛德尔柱形图自动量程**：最大像差范围设为 0 时，根据全部表面和总和系数使用对称范围并保留边距；正数手动范围和原有配色、图例、网格及布局保持。
- **Windows 粘贴异常保护**：功能搜索对剪贴板 COM、超时和访问拒绝受控处理，保留原查询和选区并提示重试；全局边界覆盖原生剪贴板粘贴异常，保留正常粘贴与撤销/重做。
- **Mac 布局保存崩溃修复**：将不符合 Apple Silicon 调用约定的路径查询改为固定参数接口；原崩溃导航用例及真实 Unicode 文件连续布局保存/读取通过原生 Mac 回归。
- **分析与光学修正**：包含最新图表可读排布、完整 PNG 导出及无焦分析的选定波长、角量纲和离焦传递等修正。未完成的数值比较与适用范围保留在[当前状态](https://github.com/VendettaMask/opticalsystem/blob/main/docs/CURRENT_STATUS.md)，不宣称全部外部数值认证完成。

三平台发布相关定向检查完整结束，公开下载的大小/SHA-256 全部匹配，两份 Windows 更新元数据通过内置公钥验签。Windows ARM64 为交叉构建；Mac 已做原生无界面包检查，不等于新包的完整实机 GUI/OTA 验收。完整范围见[交付记录](https://github.com/VendettaMask/opticalsystem/blob/main/docs/validation/CLOUD_RELEASE_2026-10-27.json)。

## 2026-10-26：Windows x64 更新（历史记录）

该批次更新 Windows x64 测试包，源码为 `45cce15b`；当时 Mac 安装包保留此前版本。以下为该阶段更新内容。

旧客户端尚不识别带短码的安装包名称，请从本页下载 EXE 手动覆盖更新一次，无需卸载；新客户端同时兼容旧名称和带短码名称，继续校验原有签名、完整哈希与构建编号。每个 Windows 架构只保留一个 EXE，发布页地址不变。

- 分析图保持可读字号，窄窗口自动重排视场和完整光扇对；矩阵、离焦图保留行列关系，空间不足时可滚动。修复子图重叠、刻度拥挤和图注裁切，标题贴近对应图框。
- 底部摘要、指标和文件说明按内容增高与换行，最大字号也能完整访问。PNG 导出包含滚动区域外的完整图与图注，保留当前缩放、相机和勾选状态。
- 镜头数据、二维视图等文档页签标题加粗；材料列内容及编辑框右对齐；移除矩阵点列图旁多余的竖排共用尺度数字。
- 增加 Markdown 设计报告及配套分析图片导出；完善分析图例独立勾选、波前二维热图、相对照度坐标与实体模型显示。
- 相机成像实验室支持传感器参数与 QE 曲线导入、连续光谱积分、光源和场景反射率输入，以及分阶段图像和 A/B 对照。当前仍有明确的光谱、采样与物理模型范围，不等于已校准的实测相机。
- AutoLens 更新原版优化规则与阶段交接，保留共享 Core 光学计算和计算设备选择。原版规则对齐不代表完整默认配置的最终像质、成功率或速度已经认证。
- Windows 在线更新可选择保存、不保存并继续，或取消；更新与保存当前工程分开，不保存不会改写原文件。更新辅助进程从已校验的独立缓存运行，等待旧程序正常退出再安装和重启。
- 包含既有光学修复、字体、主题、二维/三维与实体模型功能，以及初始结构和镀膜两个必装内置模块；保留尚未解决的外部数值差异和模型边界。

Windows 用户可在“帮助 → 关于”检查更新，下载并校验后点击“安装更新并重启”；有未保存编辑时可自行选择处理方式。已知旧辅助进程存在占用故障的早期客户端，需先正常退出软件及失败更新提示，再从本页下载 EXE 手动覆盖安装一次，无需卸载。不会在后台强制安装或关闭程序，工程和设置保留。

Mac 用户下载 osx-arm64 的 DMG，将 Optical System Design.app 拖入“应用程序”。仅支持 Apple Silicon M 系列芯片，最低系统声明为 macOS 14；完整 .NET 运行时、两个内置模块、字体和许可随包交付。Mac 从发布页手动更新。

版本仍为 1.0.4 测试预发布，不标为正式 Latest。新 Windows 客户端通过已签名的云端构建编号识别同版本新包，拒绝旧构建；相同载荷可修复安装。包内源码提交与本页“构建来源”为实际代码来源，原测试标签保持不动，自动 Source code 压缩包不等于新安装包源码。

Windows 安装包尚无 Authenticode 发布者证书，OTA 元数据验签不等于 Windows 发布者签名；Mac 使用 ad-hoc 完整性签名，尚无 Developer ID 签名或公证。首次运行可能需要系统确认。云端构建、定向测试和包内检查不替代新安装包的用户实机 GUI/OTA 验收。
