本次在同一 1.0.4 测试发布追加 Apple Silicon Mac 版，原 Windows 安装包保留原构建与 OTA 签名。

Mac 用户下载 `osx-arm64-AdHocTest.dmg`，将 Optical System Design.app 拖入“应用程序”。仅支持 M 系列芯片，最低系统声明为 macOS 14；包含 .NET、两个必装内置模块和字体。新 Mac 包包含思源黑体 / DM Sans / JetBrains Mono、12 DIP 停靠区圆角、表面角色与面型分侧对齐，以及统一右上侧的分析图例。

Mac 当前采用 ad-hoc 完整性签名，尚无 Apple Developer ID 签名/公证，首次打开可能需要系统批准；Mac 从发布页手动下载更新。下面的 OTA、修复和安装向导说明适用于 Windows EXE。

此前 Windows 测试包包含：

- 检查更新时显示滚动进度，完成后直接显示结果、无更新或错误提示；不再只藏在鼠标悬浮提示里。
- 默认包含测试版 OTA。云端为测试包签名构建编号，客户端、下载与安装交接共同拒绝旧构建；同版本的新构建可更新，已安装的构建不重复提示。可取消“包含测试版”仅检查正式版。
- 镜头数据表头加粗并居中，结构切换在整条工具栏中央；收窄表面类型列，普通面不再重复显示角色标签。
- 二维图顶部增加独立结构选择：默认跟随活动结构，手动选择只影响此视图；窄窗口自动调整工具栏布局。
- 三维镜片网格按各面的局部坐标生成，修复偏心、倾斜和非旋转对称面的实体显示及剖切封口；三维布局使用工程线框，实体模型单独提供实体、透明、线框和剖切。
- 软件内手动 OTA：在“帮助 → 关于”检查更新，确认后下载并校验签名和文件，保存工程后再正常退出、安装和重启；不会在后台自动安装或强制关闭程序。
- OTA 签名密钥与加密恢复备份由 GitHub 管理，不依赖打包电脑；更新校验签名不等于 Windows 发布者签名。
- 自动初始结构的系统/目标/搜索卡片、折叠高级设置、清晰的候选和光线预览分区，以及中英日与窄窗口适配。
- 五个 AutoLens 官方目标的原生预设；这是目标参数，不是已达标的官方处方。固定 CPU 协议此前达标 0/24，不能把功能或界面测试通过当作设计成功。
- 安装器原位维护：已有安装保留原目录和快捷方式，同版本修复、新版本更新、拒绝降级；工程和设置保留，不自动卸载旧安装或删除旧目录。
- 保留此前的光学修复与两个必装内置模块。本次不代表所有外部数值差异已经解决。

版本仍为 1.0.4，同版本覆盖安装走修复。旧客户端只认识稳定版更新，需先手动安装这一次支持测试 OTA 的引导包；之后同版本也可按更高云端构建编号在线更新。测试包仍明确标记为预发布，不提升为正式版。真实安装交接和重启仍需实机验收，不能用云端测试通过替代。

Windows 用户下载下方 EXE，保存工程并正常退出软件后安装；安装包没有 Windows 发布者证书，Windows 可能提示未知发布者。Mac 用户下载 DMG。底部 Source code 压缩包由 GitHub 自动生成，不是安装包。
