# 合成 Speos v8 文本格式控制

`synthetic.brdf` 和 `synthetic.anisotropicbsdf` 由本仓库独立测试夹具生成，验证文件格式与方向/能量约定。它们不是实测材料、商业软件导出参考或数值认证。

文件提供 400/700 nm、0/60/90° 入射、BRDF 与 BTDF。法向反射比例在 0.2/0.3 间、透射在 0.5/0.4 间变化；550 nm 时 R=0.25、T=0.45。各向异性文件的固定坐标 +X 方向具有较强出射分布，旋转轴改变方向；入射角与材料方向还改变总积分。两份文件都必须在导入时指定入射侧；演示 BTDF 时选“正反相同（显式声明）”，先配置折射交互与两侧介质。

建议对象局部材料轴从 `(1,0,0)` 改为 `(0,1,0)`，重新追迹，核对分布与相机材料方向统计。完整格式、版本和限制见[实现说明](../../../docs/COMMERCIAL_BSDF_AXES_2026-10-31.md)。
