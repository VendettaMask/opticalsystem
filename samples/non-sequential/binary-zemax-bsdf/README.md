# 二进制与 Zemax 辐射度合成控制

本目录三个文件为本仓库测试生成的解析合成数据，不是实测材料或商业数值认证。

- `binary.brdf`：Speos v8 archive-3/zlib 二进制；投影 BSDF 值；400/700 nm 的 R=0.2/0.3、T=0.5/0.4，550 nm 时 R=0.25、T=0.45。
- `zemax-r.BSDF`：Zemax 单色辐射度 BRDF，测量波长 550 nm，TIS=0.6，完整角表表示 Lambertian 物理半球。
- `zemax-t.BSDF`：同样的单色 BTDF 控制，TIS=0.6，正面入射/出射折射率均为 1。

使用正反相同（显式声明）。BRDF 选择反射交互，BTDF/混合示例选择折射交互并配置 Air/Air。导入 Zemax 示例时填 550 nm，并勾选原数据为辐射度；此声明只适用于这些明确生成的控制数据，不能拿来把厂商光度 Y 数据转成辐射度。

先完成 NSC 分析，再在相机中读取对应矩形探测器及 S/B/R/T 路径。支持的版本、数量类型、角度变换和预算见[实施说明](../../../docs/BINARY_ZEMAX_BSDF_2026-10-31.md)。官方 LZ4 二进制格式夹具单独位于测试 Fixtures，有明确来源和许可，不作为本目录的实测材质库。
