# BSDF/BTDF CSV 合成控制

`synthetic-r02-t05.bsdf.csv` 是明确标记的解析合成数据，不是仪器测量：正反两侧、400/700 nm、0/60/90° 入射、完整出射半球，BRDF=0.2/π sr⁻¹、BTDF=0.5/π sr⁻¹。因此 R=0.2、T=0.5、A=0.3。

在非序列矩形面属性先选择折射交互（空气/空气可作简单控制），应用后导入此文件；对象覆盖实际声明界面的全部反射/透射分布，不另外叠加 Fresnel 或 Snell。以源从 +Z 向 −Z 入射为例，上方探测器接 BRDF，下方探测器接 BTDF；`S2` 取方向散射，`B2` 专取透射散射。运行分析后在相机读取已保存路径，导入相应 QE，生成 RAW/ISP。

此目录是仓库样例，没有声称随安装包提供。原文件可删除，STAROPT v9 与完整相机实验内嵌数值及来源摘要。精确定义、预算、支持范围和回归证据见 [实测 BSDF/BTDF 契约](../../../docs/MEASURED_BSDF_BTDF_2026-10-31.md)。
