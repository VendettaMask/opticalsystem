# Independent holdout v1

These three targets and seeds 201–205 were frozen before the first v6 acceptance run. They are independent supplementary cases, not additions to the original twelve-specification denominator. Results remain separate, including every failed seed; no success threshold is inferred for this profile.

The profiles cover 42 mm monochromatic, 65 mm visible-spectrum, and 120 mm visible-spectrum with fixed back focus. Every run retains 10000 evaluations, 600 seconds, serial execution, and independent full-target Core validation with six fields and 97 pupil points per wavelength. The JSON specifications are authoritative for all physical targets.

Input hashes are retained in the [S2–S4 evidence](../s2-s4-20260926/README.md). Once observed, these cases are not fresh unseen evidence for subsequent development and must not be used to tune optical weights or physical thresholds. Run instructions are in the [benchmark tool README](../../tools/OptilandWorkbench.InitialStructure.Benchmarks/README.md).
