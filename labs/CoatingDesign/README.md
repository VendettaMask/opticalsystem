## 启动

安装标准 Optical System Design 后，通过“实验室 → 光学镀膜设计”打开；不需要安装额外模块，也不会启动其他进程。开发时只构建/运行根产品：

```sh
dotnet build OpticalSystemDesign.slnx -c Release
dotnet run --project src/OpticalSystemDesign.App/OpticalSystemDesign.App.csproj -c Release
```

模块使用主程序主题与显示设置。关闭主程序、切换示例或打开其他实验时，未保存修改仍有保存/放弃/取消保护；这不是模块安装提示。

## 使用

顶部使用单行桌面工具栏：打开、保存、导出；“示例”“设计”“优化”菜单；材料管理、“堆栈几何”、“结果”和“窗口”。设计目标与介质膜料设置位于“设计”，优化采样与公差设置位于“优化”，在同一设置窗口的对应页编辑。默认膜系编辑器与光学评价左右显示，堆栈几何和设计结果按需打开。四类页面可拖动标签排序、合并、四边分栏或拖出成浮窗，再拖回工作区；方向指引和灰色预览说明落位，Esc取消拖动。关闭页面后可从“窗口”重开，当前参数、选中层和曲线显示状态继续保留。顶部不显示实验名称，主界面不常驻候选、指标/公差或完成提示条；后台计算进度和真实错误保留紧凑反馈。

“窗口”提供当前面板浮动、全部停靠、左右/上下/标签布局、保存、恢复和重置。保存记录分栏、活动标签及浮窗位置和尺寸，后续打开镀膜工作区自动恢复最近保存的布局；重置后需再次保存才覆盖原保存。恢复时修正离屏位置，坏文件报告错误并保留当前布局。布局独立于镜头工作区与实验文件，不保存或重算光谱、膜层处方；浮窗支持原打开/保存/F5快捷键，主窗口关闭被取消时浮窗保留。实现阶段和验证范围见[停靠实施计划](../../docs/COATING_DOCKING_PLAN_2026-11-02.md)。

点击顶部“堆栈几何”打开独立分析页，原横向色条已移除。“绘图”按入射介质→膜层→基板→出射介质自上而下展示立体剖面：膜层有侧面和高光，基板采用玻璃质感；箭头表示设定入射方向，括号标出实际膜层总厚度与基板厚度。颜色沿用材料身份标记，不代表真实可见颜色或计算的透过率。纳米膜层放大、毫米基板压缩显示，使用分段示意比例；薄层保留最小可见高度，不把绘图像素当作物理厚度。

剖面支持点击膜层以及方向键/Home/End 选择；“膜层数据”列出全部层号、材料名称/ID 和实际物理厚度，与剖面选择同步。层数较多或字号较大时，图中只标注可读数量及选中层，完整几何仍保留，全部数值在数据页查看。修改膜厚、材料、基板厚度、波长或介质后，已打开的页即时更新；无效输入清除旧图并暂停 PNG 导出。分析页为只读，不触发设计优化或改变保存处方。PNG 使用当前选中层与图签，固定为 2404×1804，与窗口大小无关。

编辑器下方“介质与基板设置”可改入射介质、基板、出射介质、基板厚度（mm）、独立参考波长λ₀，并选择“计入基板与背面（非相干）”。λ₀用于厚度单位换算，不随设计中心变化或缩放物理膜厚。图形改为独立分析页不改变这组物理参数、光谱或正式验收。竖直图历史预览见[记录](../../validation/rechecks/2026-11-02/coating-vertical-stack/README.md)。

编辑器按用户提供的TFStudio截图重排：正/背面镀膜标签；“表面＋忽略另一面”一行；“＋膜层、反转、全部锁定、复制到另一面、工具”五项工具栏。材料在每一行下拉选择，行尾直接锁定、上下移动和删除。层表上方标基底、下方标入射/出射介质；界面从基底侧编号，文件与Core仍按外侧→基底物理顺序，打开/保存不会倒转处方。撤销、批量厚度、批量换材、剪贴板、公式及高级“表面与评价”放在工具菜单，介质设置保留底部折叠。窄窗口按行水平滚动，不堆按钮或缩小文字，浮窗保留配置字号。见[布局与参考说明](../../docs/COATING_EDITOR_LAYOUT_2026-11-03.md)。

“工具→堆栈公式”可预览`(HL)^4 H`、系数、分组和自定义材料符号，再原子应用到当前面并一步撤销。剪贴板保留物理膜厚精度与真实材料身份，不覆盖同名不同n/k。编辑停止1.5秒后自动保存独立恢复草稿，异常退出后可恢复错误文本、两面及模式，不覆盖原文件。顶部“恢复草稿”可再次检查。新启用双面默认选解析导数及恢复/质量v2，旧文件保持原v1；原密集验收不变。完整语法、快捷键、上限、恢复边界及阶段成本见[工程操作说明](../../docs/COATING_WORKFLOW_ANALYTIC_2026-11-02.md)。

未启用双面设计时，新工作区和新选取的示例默认显示整块基板光谱：前面薄膜相干，有限基板按非相干功率求和，包含真实吸收和裸背面反射。关闭“计入基板与背面”恢复前表面显示；旧文件缺字段时继续旧模式，原单面优化与验收不变。启用“双面设计”后，正背面分别编辑，可选择正面、背面或两面优化，评价正面、背面或整片；两面优化固定评价整片，对称模式将背面链接到正面。显示、优化、公差和正式验收统一读取该评价对象，不再把整片显示与单面目标混用。文件和计算中的两面数组各自从外侧向基板排列，编辑器通过反向视图从基底侧编号；堆栈图绘出实际穿过基板后反向经过背面的顺序。仍不模拟厚基板的相干条纹。完整约定见[联动编辑与双面设计](../../docs/COATING_EDITOR_DUPLEX_2026-11-02.md)。

光谱中凡使用域外端点延用数据的波段均加深背景；多个材料的域外区取并集，不重复叠加底色。标记仅依据实际膜层、入射介质、基板，以及整片模式的出射介质；未使用的备选材料不影响标记。底纹在明/暗主题、缩放、曲线筛选、nm/µm及百分比/比例/OD显示和PNG导出中保留。图下和域外点悬停提示仍说明“非实测”；严格有效域材料继续拒绝域外计算，不因底纹允许外推。见[底纹验证](../../validation/rechecks/2026-11-02/coating-domain-shading/README.md)。

1. 顶部“示例”菜单提供与参考截图一致的五套完整处方：四层宽带减反、20层边缘滤光、15层TiO₂/SiO₂高反、Ag银镜、单层MgF₂减反，选择后直接计算原膜系。分隔线下保留原“减反膜 / 高反膜 / 窄带滤光片”目标模板，用于重新生成和优化。材料框支持名称包含搜索；原处方、材料与范围说明见[五套参考示例](../../docs/COATING_REFERENCE_EXAMPLES_2026-11-01.md)。
2. 查看材料适用性诊断，点击“1 生成膜系”：窄带新流程比较镜段、腔阶、匹配层并短程优化；其他类型枚举模板。候选通过状态以实际正式认证记录为准，不能据粗筛宣称达标。顶部“结果”打开设计结果面板，可选择另一候选并点击“采用候选”，再复验；同一面板查看原逐项指标和公差结果。
3. 编辑膜层：d(nm)、OT、QW、FW四列均可编辑，OT=n(λ₀)d、QW=4OT/λ₀、FW=OT/λ₀，物理厚度仍是唯一存储值。换材料或参考波长保持物理膜厚并更新派生值；无有效折射率时禁止换算，非法文本阻止计算。Ctrl/Cmd加选、Shift连续选择或“全选”后，工具/右键中的复制、删除、所选上移/下移、替换材料、反转、固定/释放与厚度设定/倍率调整作用于全部所选层，错误批次不部分提交；行尾箭头只移动该行。工具/右键中的撤销/重做与Ctrl/Cmd+Z、Y或Shift+Z恢复整次编辑，在浮窗同样可用；打开文件清空历史。行尾锁定仅固定优化变量，不阻止手动编辑。材料圆点/完整名称/来源提示、数字右对齐、大字号和窄面板横向滚动保持。
4. 点击“2 优化”调整当前结构的变量膜厚，或用“结构搜索”比较不同结构与多个厚度起点；只需复算时点击“计算 / 复验”。所有计算使用输入和材料快照，修改输入立即清除过期结果。取消及切换实验后的旧任务不能写回。
5. 在光学评价中分别勾选 T / R / A 的“平均、s、p”，鼠标悬停显示最近实算采样及已选曲线的数值。平均为同一波长、同一角度的 `(s+p)/2` 功率，不是波段或多角度平均。s 为虚线、p 为圆头点线，单独选择 p、改变线宽及 PNG 导出均使用真实 p 数据；0°时 s/p 重合属于物理结果。目标线可切换，表示当前评价对象的设计目标，旧单面模式保持原正面定义；编辑打开原设计目标。图内“设置”独立控制评估角度、波段、步长、单位和纵轴，不改原设计或验收。出厂为 **0°、400–800 nm、步长 0.5 nm、Y=0–100%、不自动缩放**，包含端点共 801 行；支持 nm/µm、百分比/比例/OD、最多 16 个不同角度、保存及恢复默认。普通材料不覆盖评估波段时明确报错；参考示例显式声明的端点延用按原模型执行，并提示域外值非实测，原始n/k和有效域保持。顶部“结果”查看原逐项验收；“全部目标达标”仍要求原物理约束、指标和密集采样收敛同时满足。
6. 图下“结果”可展开数据表，按当前曲线选择、单位和所有评估角度显示全部评估点。“导出”提供 CSV / TSV / 复制全部，字段注明偏振、角度、单位，数值按完整双精度精度写出；表格舍入不改导出值。相机按钮导出当前图像 PNG，旁边“线宽”提供细/标准/粗，默认标准。顶部原“导出”仍导出正式膜层表、原验收光谱、指标、材料诊断、算法记录和实验快照。保存 `.coating.json` 保留原设计/材料并在重开时复算；评估默认设置单独存入当前用户的 `coating-plot-defaults.json`，只有“另存为默认 / 恢复默认”写入该文件，不写入实验设计字段。

“优化 → 优化设置”包含厚度限制、采样、实际算法、峰值/带宽容差、窄带腔数和搜索预算；制造公差位于“优化 → 公差设置”。设置直接编辑当前实验，点“完成”关闭；修改会立即使旧结果失效，关闭设置不恢复旧值。支持正式 Core 的 Damped Least Squares、Nelder-Mead、Coordinate Pattern Search。搜索采用结构枚举加多起点局部优化，不宣称全局最优或针插入。

“材料管理”可新建、复制、编辑实验内的 n/k 表格，导入/导出 CSV 或制表符表。首行为 `wavelength_nm,n,k` 或 `wavelength_um,n,k`，数值使用小数点；2–10000 行，波长严格递增、n > 0、k ≥ 0。填写来源与制备条件后保存到实验，再选择用途或替换膜层。解析色散模型不自动转换成近似采样表；如需替换，必须显式提供表格。没有全局材料库写入。示例格式明确标注为用户模型，不能当成测量数据。

公差支持均匀 ±范围或正态 1σ，厚度误差可逐层独立、同材料同步或全部同步，并可叠加入射角误差（°）。使用正式 `UniformSampler` / `NormalSampler` 和固定种子；每个样本使用原始材料快照做密集复验。固定膜层也参与制造公差。负厚度等无效样本记失败，不截断成有效值。每个样本的实际膜厚、角度、检查项和失败原因保存在实验与 `tolerance.json`，`tolerance.csv` 提供摘要。

键盘：Ctrl/Cmd+O 打开、Ctrl/Cmd+S 保存、F5 复验、Esc 取消，膜层表中 Delete 删除选中层。共享主程序 `ThemeRegistry`、Fluent/Blue 控件样式、标题栏、字号和数值格式；支持普通、暗夜、异世界、像素和跟随系统。显示设置由主程序宿主管理，变化同步到已打开的模块窗口。材料与设置窗口继承字体、字号与字形。左右工作区各自保留至少 300 DIP；窄窗口或大字号下膜层表可横向滚动，工具可换行，不缩小字号。设置页纵向滚动，较宽的标签/编辑器行保留完整输入空间。执行动作使用 `accent`，取消/导出保持中性，禁用按钮有原因提示与无障碍说明。显示舍入不损失存储精度。最新界面范围见[桌面工作区记录](../../docs/COATING_DESKTOP_WORKSPACE_2026-11-01.md)，早期版本见[历史改版](../../docs/LABORATORY_PRESENTATION_2026-10-24.md)。

## 数据与物理边界

用户输入的波长和膜厚为 nm，角度相对入射介质内法线，层序从入射侧到基板。吸收入射介质、精确临界角奇点和不完整材料快照会明确报错；参数变化会清除旧结果，采用候选后需重新复验。

当前支持各向同性相干膜层的单面评价，以及两面相干膜层与非相干有限厚基板组成的整片评价。单面T进入半无限基板，整片T进入出射介质；吸收、内部反射和所选评价对象随实验保存。OD 显示饱和不是原始数值钳制；密集采样未收敛不能判为达标。完整的复折射率约定、T/A/ln(T) 定义和采样限制见[计算契约](../../docs/COATING_DESIGN_LAB.md#计算契约)，新文件与优化路径见[双面说明](../../docs/COATING_EDITOR_DUPLEX_2026-11-02.md)。模型可计算不代表给定材料、模板和预算能满足任意目标。

实验文件与镜头文件分别保存，不隐式修改当前镜头；物理模型已进入正式顺序追迹，但实验结果应用到镜头的 UI 尚未实现。保存字段、指纹兼容和 CSV 含义见 [文件契约](../../docs/FILE_FORMATS_AND_PLUGINS.md#镀膜实验文件)，其余未支持能力见 [范围边界](../../docs/COATING_DESIGN_LAB.md#首版边界)。

## 参数上限与排错

“2 优化”只调标记为变量的厚度；“结构搜索”额外枚举有限模板和多起点。固定层会禁止结构变化，不会被搜索悄悄删改。允许的层数、腔数、材料波段、采样、优化和公差预算统一见 [资源和材料限制](../../docs/COATING_DESIGN_LAB.md#资源和材料限制)，本页不维护第二份数字表。

遇到“采样未收敛”应在“优化 → 优化设置”提高基础采样，或在“设计 → 设计目标设置”缩小计算范围；遇到“未全部达标”先查看具体 R、峰值、FWHM、截止 OD 和结构约束。缺失材料数据需补齐或改选有效材料，不能由名称查库或默认系数代替。延长优化不保证成功。
